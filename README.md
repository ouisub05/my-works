# my-works

정통 하이 판타지 세계관 설정집이다. 소설, 웹소설, 게임 어디에든 가져다 쓸 수 있는 판을 먼저 짜는 것이 목적이고, 특정 작품의 설정이 아니다. 설정은 모두 마크다운 문서로 쓴다.

세계 이름과 모든 국호는 미정이다. 국가 이름은 국호를 정하기 전까지 쓰는 임시 이름이다.

## 세계관 한눈에 보기

- 지구와 무관한 평행 우주다. 지형과 기후만 지구와 같고, 문서에 나오는 실제 지명은 위치를 가리키는 표시일 뿐이다. 세계 안의 이름은 따로 붙인다.
- 톤은 고전 하이 판타지다. 큰 축은 마족과 지상 종족의 싸움이고, 또 하나의 축은 국가 간 정치와 전쟁이다. 전선은 처절하고 후방은 궁정 정치가 중심이다.
- 신들은 창세 전쟁에서 이긴 뒤 하늘로 떠났고, 열두 마신 가운데 여섯이 지상에 봉인되어 있다.
- 세계를 대표하는 나라가 없는 다극 체제다. 중심부 문명은 중세 말-르네상스 초 수준이고, 마법과 마도구가 일부 분야를 끌어올린다.
- 창세력 기준으로 현재는 15,027년이다. 시대 구분은 `판타지세계관/역사/`에 있다.

핵심 정설의 요약은 [INDEX](판타지세계관/INDEX.md)에 있다.

## 읽는 순서

1. [`판타지세계관/INDEX.md`](판타지세계관/INDEX.md)의 "핵심 정설"을 읽는다. 대부분은 이것으로 충분하다.
2. 더 필요한 주제는 INDEX의 "폴더 맵"에서 해당 문서를 찾아 연다.
3. 특정 지역의 국가를 보려면 `판타지세계관/국가/<지역>/`에서 이름이 `_`로 시작하는 개요 파일부터 읽는다.

INDEX는 요약이므로 원본 문서와 다르면 원본이 맞다.

## 진행 상황

- 세계 공통 설정(우주론, 힘의 체계, 종족, 역사, 지리, 세계 질서): 1차 작성 완료.
- 국가: 아홉 개 지역, 207개 국가 파일. 서북부, 서남부, 남쪽 대륙, 대륙 북부, 대륙 중앙, 대륙 남부, 대륙 동부, 대륙 동남부, 동남쪽 섬들. 대륙 동부 이후 지역은 위치, 국가 형태, 종족 등 기본 항목만 채운 상태다.
- 미정: 서쪽 대륙 북부와 남부, 오스트레일리아, 해저, 극지의 국가. 교단 조직, 종족별 상세 설정, 정령, 고유 생물과 생태계, 경제와 화폐, 지명. 국호, 세계 이름, 국가별 기년법.

최신 현황은 [인수인계](인수인계.md)와 INDEX가 기준이다.

## 표기 규칙

- 정하지 않은 항목은 "미정"이라고 쓴다. 지어내서 채우지 않는다.
- 대화에서 나왔지만 확정하지 않은 아이디어는 각 문서 끝의 "확정 아님" 항목에 모은다.
- 실제 지명, 국가, 민족, 역사는 세계 안의 설정으로 쓰지 않는다.
- `판타지세계관/` 폴더는 Obsidian 볼트로 쓰며, 문서 사이는 `[[파일명]]` 위키링크로 잇는다. GitHub에서는 링크로 눌러지지 않으므로 파일 이름으로 찾는다.

## 공개 범위

공개 저장소이며 세계관 설정만 둔다. 외부 자료에서 추출한 작명 참고 자료는 이 레포에 포함하지 않는다.

## 라이선스

레포에 라이선스 파일이 없다. 사용 조건은 미정이다.
