# 과거 작업

지금의 `판타지세계관` 이전에 작업하다 그만둔 세계관들이다. 원본 파일은 이름과 폴더 구조를 그대로 두었고, 각 폴더의 `_보관메모.md`에 무엇이 들어 있는지 짧게 정리했다.

작업 순서(파일 날짜 기준)

| 순서 | 폴더 | 작업 기간 | 한 줄 요약 |
|---|---|---|---|
| 1 | `Orbis` | 2026년 3월 말 | 대륙마다 따로 만든 세계를 하나로 묶으려던 작업. 대륙마다 이름과 역법이 다름 |
| 2 | `Aether` | 2026년 4월~6월 | 지구 지형을 쓰는 평행세계. 에테르 체계, 대륙 여섯, 대륙별 국가와 인물 |
| 3 | `에테르 3차` | 2026년 6월 말~7월 초 | Aether의 기원(우주론, 신, 종족 뿌리, 고대 문명)을 다시 짠 작업 |
| 4 | `에테르 4차` | 2026년 9월 | 성력 1341년의 세계. 34권짜리 설정집과 위키 |

지금 작업 중인 세계관(`../판타지세계관`)은 이들과 별개의 새 설정이다. 이름이나 아이디어가 겹치는 곳이 있어도 이 폴더의 내용이 지금 설정의 정본은 아니다.

이미지 가운데 `BlankMap-Europe_no_boundaries.svg.png`처럼 이름에서 위키미디어 공용의 백지도로 보이는 파일이 있다. 외부에서 가져온 지도를 다시 공개할 때는 원본의 이용 허락 조건을 확인해야 한다.
