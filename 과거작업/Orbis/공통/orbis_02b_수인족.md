# Orbis — 전 대륙 공통 설정
# 항목 2-B: 수인족 통합 설정

---

## 개요

수인족은 동물의 특성을 공유하는 인간형 종족의 총칭으로, Orbis 전 대륙에 분포한다.
각 대륙의 생태계를 반영한 동물 기반 종족이 독자적으로 발전했으나,
공통된 생물학적 특성과 마나 운용 원칙을 공유한다.
수인족이 전 대륙에 분포하는 이유는 현시점에서 완전히 규명되지 않았다.

---

## 전 대륙 공통 특성

### 신체

| 특성 | 내용 |
|---|---|
| **기본 외형** | 인간형 신체에 해당 동물의 특징(귀·꼬리·비늘·깃털·발톱 등) 보유 |
| **감각 강화** | 해당 동물의 감각 기관 우월성 계승. 종류에 따라 후각·청각·시각·촉각 중 하나 이상 강화 |
| **신체 능력** | 해당 동물의 신체 특성 일부 계승. 속도·근력·유연성·수압 적응 등 종류별 상이 |
| **수명** | 종류별 상이. 대체로 인간보다 10~30년 길거나 비슷한 수준 |
| **성인 기준** | 종류별 상이. 인간보다 빠른 경우(고양이·토끼)와 느린 경우(상어·뱀) 혼재 |

### 마나

| 특성 | 내용 |
|---|---|
| **각성률** | 인간과 비슷하거나 약간 높음. 종류별 편차 있음 |
| **계열 친화성** | 종류별로 전투 계열 또는 마법 계열 친화성 경향 존재. 단 확정이 아닌 경향 |
| **마나 감지** | 비각성자도 마나 잔향을 감각적으로 탐지하는 능력 보유 종 다수 |

### 야성 해방 (Feral Surge / 전 대륙 공통 현상)

> 수인족 고유의 본능적 마나 폭발 현상. 대륙·종족마다 명칭은 다르나 동일한 현상.

| 항목 | 내용 |
|---|---|
| **정의** | 극한 상황(위기·감정 격화·특정 자극)에서 동물 본능이 마나와 결합해 폭발하는 현상 |
| **효과** | 신체 능력·마나 운용 효율 급상승. 해당 동물의 본능적 특성 극대화 |
| **부작용** | 이성 약화. 아군 피해 가능성. 제어 어려움. 종류별로 발동 조건·강도·지속 시간 상이 |
| **발동 유형** | 조건성(특정 자극 시) / 계절성(특정 시기 강화) / 희박성(드물지만 발동 시 강함) / 없음(일부 종) |
| **제어 훈련** | 고위 수인족 각성자는 야성 해방을 의도적으로 발동·제어하는 훈련 가능 |
| **각 대륙 명칭** | 아르덴티아: 야성 해방(Feral Surge) / 천원: 야화(野化) / 카우사이·이프리카·아엘루와: 세력별 고유 명칭 |

## 수인족 계열 분류 체계

> 전 대륙 수인족을 생태 특성에 따라 분류한 포괄 체계.
> 각 대륙은 이 분류를 공식적으로 사용하지 않는다. 독자·서술자 편의 기준.

### 1. 육지형 수인족

| 소분류 | 특성 | 전 대륙 분포 종 |
|---|---|---|
| **견과(犬科) 계열** | 무리 본능. 충성심. 후각 강화. 감정 표현 솔직 | 개·늑대·여우·자칼·하이에나 |
| **묘과(猫科) 계열** | 단독 포식자 본능. 은신·기습 특화. 유연성 | 고양이·표범·사자·호랑이·치타·재규어·쿠거 |
| **초식 계열** | 도약·도주 특화. 감수성 예민. 집단 의식 | 토끼·사슴·말·코끼리·코뿔소 |
| **파충류 계열** | 유연성 또는 갑각 방어. 독 운용. 장수 경향 | 뱀·악어·도마뱀·거북 |

### 2. 해양형 수인족

| 소분류 | 특성 | 전 대륙 분포 종 |
|---|---|---|
| **어류 계열** | 수압 적응. 유선형 체형. 마나 감지 특화 | 상어·고래·돌고래·만타 |
| **양서 계열** | 수륙 양용. 유연성. 물 속성 마나 친화 | 수달·비버·카피바라 |

### 3. 조류형 수인족

| 소분류 | 특성 | 전 대륙 분포 종 |
|---|---|---|
| **맹금 계열** | 완전 비행. 시각 극강화. 독립성 강함 | 독수리·매·올빼미·콘도르 |
| **지능형 계열** | 언어 모방. 집단 의식. 마법 계열 친화 | 까마귀·앵무·큰부리새 |

## 대륙별 수인족 종류 비교표

> 각 대륙에 존재하는 수인족 계열 개요. 세부 종은 각 대륙 파일 참조.

| 계열 | 아르덴티아 | 천원 | 아엘루와 | 카우사이 | 이프리카 |
|---|---|---|---|---|---|
| **견과 계열** | 개·늑대·여우 | 여우·늑대·너구리 | 미확정 | 일부 존재 추정 | 자칼·하이에나 |
| **묘과 계열** | 고양이·표범·사자·호랑이 | 호랑이·표범 | 미확정 | 재규어·쿠거 | 사자·표범·치타 |
| **초식 계열** | 토끼 | 토끼·사슴 일부 | 미확정 | 일부 존재 추정 | 코끼리·코뿔소 일부 |
| **파충류 계열** | 뱀(육지·사막형) | 뱀 일부 | 미확정 | 뱀·악어 일부 | 악어·왕도마뱀 일부 |
| **어류·양서 계열** | 상어·수달 | 없음(내륙 중심) | 미확정 | 없음~소수 | 없음~소수 |
| **조류 계열** | 독수리·까마귀 | 두루미·봉황 계열 일부 | 미확정(플루마 계열 존재) | 콘도르·앵무 일부 | 독수리·따오기 일부 |
| **대륙 고유** | — | 용족 혼혈 수인 일부 | 플루마(깃털 수인)·말 수인(에쿠스)·비늘 수인(스쿠아마) | 재규어 신성시 집단 | 세력별 미확정 |

## 수인족 혼혈 원칙

### 수인족 × 인간 혼혈

| 항목 | 내용 |
|---|---|
| **명칭** | 경혈 수인(Lightkin) — 아르덴티아 기준. 타 대륙 고유 명칭 존재 |
| **외형** | 수인족 특징 약화. 귀·꼬리 등 잔존하나 크기·선명도 감소 |
| **능력** | 야성 해방 발동 빈도 낮아짐. 감각 강화 약화. 수명은 두 종족 중간 |
| **마나** | 각성률 유지. 계열 친화성은 수인족 부모 쪽 경향 약하게 계승 |
| **세대 진행** | 3세대 이후 외형상 인간에 가까워짐. 수인족 특성 거의 소실 |
| **사회적 처우** | 대륙·세력별 극단적 편차. 아르덴티아 아타르발: 정식 구성원 / 케메트라: 차별 |

### 수인족 × 수인족 혼혈

| 항목 | 내용 |
|---|---|
| **가능 여부** | 가능. 단 부모 종 특성이 혼재해 불안정한 경우 多 |
| **외형** | 양 부모 종의 특성이 혼재. 예측 불가한 조합 발생 |
| **야성 해방** | 양쪽 본능이 충돌해 제어 난이도 상승. 발동 시 강도 강하지만 이성 약화 심함 |
| **마나** | 양쪽 계열 친화성 혼재. 불안정하지만 특화 시 강력 |
| **동계열 혼혈** | 같은 계열 내(견과×견과 등) 혼혈은 비교적 안정적 |
| **이계열 혼혈** | 다른 계열 간(묘과×조류 등) 혼혈은 불안정. 희귀 |

### 수인족 × 드래곤 수인 혼혈

| 항목 | 내용 |
|---|---|
| **가능 여부** | 드래곤 수인 저혈~흔적혈과 수인족 간 자연 혼혈 사례 존재 |
| **결과** | 드래곤 수인 외형 + 수인족 동물 특성 복합 |
| **희귀도** | 극희귀. 외형상 수인족과 구별 어려운 경우 많음 |

### 대륙 간 수인족 혼혈

| 항목 | 내용 |
|---|---|
| **발생 조건** | 교역로가 있는 대륙 간 접촉 지역에서만 발생 가능 |
| **현시점 사례** | 아르덴티아↔이프리카 접경부(아타르발↔팔람 해안)에서 소수 발생 |
| **결과** | 양 대륙 수인족 특성 혼재. 외형 불안정. 마나 친화성 예측 어려움 |

## 수인족의 사회적 위치 — 전 대륙 개요

> 수인족에 대한 처우는 대륙과 세력에 따라 크게 다르다.
> 아래는 전반적인 경향이며, 세부 내용은 각 대륙 파일 참조.

| 대륙 | 전반적 처우 | 특이사항 |
|---|---|---|
| 아르덴티아 | 국가별 극단적 편차 | 아타르발: 수인족 독립 국가 / 케메트라: 사실상 이등 시민 / 페락시스·카이저라트: 실력주의 |
| 천원 | 소수 부족 형태. 차별 존재 | 여우 수인 일부는 요괴(妖怪)로 신화화. 일부 세력에서 신성시 |
| 아엘루와 | 세력 파일 확정 후 추가 | 플루마·에쿠스·스쿠아마 등 고유 수인족 존재 |
| 카우사이 | 인간과 수인족 경계 유동적 | 재규어·독수리·뱀 계열은 일부 세력에서 신성시. 타완틴 의식과 연결 |
| 이프리카 | 세력별 상이 | 일부 세력에서 수인족 전사 계층. 사자·표범 계열 지도자 역할 사례 |

## 수인족 기원 — 미확정

> 수인족이 전 대륙에 분포하는 이유에 대해 각 대륙은 독자적 신화·설명을 보유한다.
> 공통 설정에서 진실은 열어둔다.

| 가설 | 내용 | 근거 |
|---|---|---|
| **고대 이동설** | 대붕괴 이전 단일 기원에서 전 대륙으로 분산 | 전 대륙 공통 특성(야성 해방 등) 존재 |
| **독립 발생설** | 각 대륙에서 독립적으로 발생. 마나 농도 영향 | 대륙별 동물 기반이 해당 대륙 생태계 반영 |
| **신화 기원설** | 각 대륙 신이 동물에게 인간의 형태를 부여 | 전 대륙 수인족 신화에 공통적으로 등장하는 서사 |
| **마나 변이설** | 고마나 농도 환경에서 동물이 마나를 흡수해 인간형으로 변이 | 마나 농도 높은 지역에 수인족 비율 높은 경향 |
