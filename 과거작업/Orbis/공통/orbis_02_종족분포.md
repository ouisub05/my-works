# Orbis — 전 대륙 공통 설정
# 항목 2: 종족 분포

---

## 개요

Orbis의 종족은 크게 **전 대륙 공통 분포 종족**과 **대륙 고유 종족**으로 나뉜다.
인간·수인족·드래곤류는 전 대륙에 존재하나, 각 대륙의 환경·문화에 따라 형태와 비율이 상이하다.
대붕괴(Ruina) 이전 고대에 대규모 이동과 분산이 있었던 것으로 추정되며,
현시점에서 그 이유를 완전히 규명한 대륙은 없다.

---

## 전 대륙 공통 분포 종족

### 1. 인간 (Human)

| 항목 | 내용 |
|---|---|
| **분포** | 전 대륙. Orbis 최다 종족 |
| **특성** | 마나 각성률·신체 능력은 종족 중 평균 수준. 적응력·번식력·사회 조직력이 뛰어남 |
| **대륙별 비율** | 아르덴티아·천원·카우사이·이프리카: 인구의 절대다수. 아엘루와: 압도적 주류 |
| **대붕괴 이전** | 현재보다 종족 다양성이 높았을 것으로 추정. 현재 인간 주류 구조는 대붕괴 이후 형성된 것일 가능성 있음 |

**대륙별 특이사항:**

| 대륙 | 특이사항 |
|---|---|
| 아르덴티아 | 15개 국가 대부분에서 인간이 지배 종족. 일부 국가(디르우드·베르단티스)는 엘프 주류 |
| 천원 | 12개 국가 전체에서 인간 주류. 수인족은 소수 부족 형태로 존재 |
| 아엘루와 | 9개 세력 전체 인간 단일 종족에 가까움. 비인간 종족 비율 극소 |
| 카우사이 | 인간 주류. 수인족적 특성을 가진 부족이 일부 존재하나 종족 경계 불명확 |
| 이프리카 | 인간 주류. 수인족과의 경계가 타 대륙보다 유동적 |

---

### 2. 수인족 (Beastkin / 獸人族)

> 동물의 특성을 공유하는 인간형 종족의 총칭. 각 대륙에서 독립적으로 발생했거나 고대에 분산된 것으로 추정.
> 외형·문화·사회적 위치는 대륙마다 크게 다르다.

| 대륙 | 명칭 | 종류 | 사회적 위치 |
|---|---|---|---|
| 아르덴티아 | 수인족 (獸人族) | 12종 (개·늑대·여우·고양이·표범·사자·호랑이·토끼·수달·독수리·까마귀·상어·뱀) | 독립 국가(아타르발) 보유. 타 국가 내 소수 거주 |
| 천원 | 수인족 (獸人族) | 세력별 상이. 호랑이·여우·뱀 계열 다수 | 소수 부족. 인간 국가와 공존. 일부 차별 존재 |
| 아엘루와 | 세력별 고유 명칭 | 아직 미확정 | 세력마다 상이 |
| 카우사이 | 별도 종족 경계 불명확 | 재규어·독수리·뱀 계열 특성을 가진 집단 존재 | 일부 세력에서 신성시 |
| 이프리카 | 세력별 고유 명칭 | 사자·표범·하이에나·코끼리 계열 등 | 세력마다 상이. 일부 세력에서 전사 계층 |

**공통 특성:**
- 해당 동물의 신체 능력 일부를 공유 (야간 시각·청각·후각 강화 등 종류에 따라 상이)
- 마나 각성률은 인간과 유사하거나 약간 높음
- 전 대륙에서 수인족의 동물 기반은 해당 대륙의 생태계를 반영

**고대 기원 가설:**
- 수인족이 전 대륙에 분포하는 이유에 대해 각 대륙은 독자적 신화·설명을 보유.
- 아르덴티아 일부 학자는 대붕괴 이전 단일 기원 후 분산설을 주장 (비주류).
- 진실은 미확정.

---

### 3. 드래곤류 (Dragon-kin)

> 드래곤 또는 드래곤과 유사한 거대 파충류형 존재. 전 대륙에 존재하나 형태·문화·사회적 위치가 크게 다르다.
> 아르덴티아의 드래곤 수인처럼 인간형 혼혈 형태가 있는 대륙도 있고, 순수 야생 생물로만 존재하는 대륙도 있다.

| 대륙 | 형태 | 특성 |
|---|---|---|
| 아르덴티아 | 드래곤 수인 5계통 (이그니스·글라치에스·풀멘·움브라·비리디스) | 인간형. 사회에 통합. 계통별 마나 속성 경향 |
| 천원 | 용족(龍族). 순수 드래곤형 + 인간형 혼혈 일부 | 신격화 경향. 황린 제국에서 용을 황실 상징으로 사용 |
| 아엘루와 | 세력별 상이. 대형 파충류형 존재 확인 | 일부 세력에서 신성시. 인간형 혼혈 여부 미확정 |
| 카우사이 | 깃털 달린 뱀(케찰코아틀형) 드래곤 존재 전승 | 타완틴·멜리와 신화에 등장. 현재 생존 여부 불명 |
| 이프리카 | 대형 파충류형. 인간형 혼혈 기록 없음 | 일부 지역에서 마물과 드래곤의 경계 불명확 |

**공통 특성:**
- 전 대륙에서 드래곤류는 일반 인간보다 강력한 마나 용량을 보유.
- 순혈 드래곤(비인간형)은 전 대륙에서 극히 드물거나 전설적 존재.
- 인간형 혼혈(드래곤 수인 등)은 대륙마다 사회적 통합 수준이 크게 다름.

## 대륙 고유 종족

### 아르덴티아 고유

| 종족 | 타 대륙 존재 여부 |
|---|---|
| 엘프류 (순혈·하프) | 아래 별도 항목 참조 |
| 드워프 | 아래 별도 항목 참조 |
| 정령 혼혈 | 아르덴티아 한정. 정령술 체계가 아르덴티아 고유이므로 |

### 천원 고유

| 종족 | 타 대륙 존재 여부 |
|---|---|
| 선인(仙人)족 — 수련을 통해 인간에서 분화된 존재 | 천원 한정 개념. 타 대륙에 동일 종족 없음 |

### 아엘루와·카우사이·이프리카

> 각 세력 파일에서 확정. 현시점 공통 설정에서는 미등록.

## 엘프류·드워프의 타 대륙 분포

> 아르덴티아의 엘프류·드워프는 타 대륙에도 동일 또는 유사 종족이 존재한다.
> "완전히 같은 종족"과 "유사하나 다른 종족" 두 경우 모두 해당한다.

### 엘프류

| 대륙 | 상태 | 비고 |
|---|---|---|
| 아르덴티아 | 순혈 엘프·하프 엘프. 독립 왕국 2개(디르우드·베르단티스) 보유 | 정령술 사용. 장수 |
| 천원 | **동일 종족** 극소수 존재. 고대 이동 흔적. '선계(仙界)의 존재'로 신화화 | 정령술 없음. 천원 술도 체계에 적응한 극소수 |
| 아엘루와 | **유사 종족** — 수목·자연과 깊이 연결된 장수 종족 존재 가능성. 세력 파일에서 확정 | 아르덴티아 엘프와 동일 종족 여부 불명 |
| 카우사이·이프리카 | 현시점 기록 없음 | |

### 드워프

| 대륙 | 상태 | 비고 |
|---|---|---|
| 아르덴티아 | 드워프 독립 왕국(우르단) 보유. 광산·단야 문화 | |
| 천원 | **유사 종족** — 산악 지대에 소규모 거주. 단야·석공 문화 유사. 천원에서는 '산쟁이(山矮人)'로 불림 | 아르덴티아 드워프와 동일 기원 여부 불명 |
| 아엘루와 | **유사 종족** 가능성. 세력 파일에서 확정 | |
| 카우사이·이프리카 | 현시점 기록 없음 | |

## 대륙 간 종족 이주·혼혈 이력

> 현시점(AN 845년)에서 대륙 간 이동이 가능한 경로는 아르덴티아↔천원 천사로(天絲路)뿐.
> 아엘루와는 마레티스 탐험대가 최근 발견. 카우사이·이프리카는 교역 경로 미개척.

### 아르덴티아 ↔ 천원

**이주 이력:**

| 방향 | 내용 | 현황 |
|---|---|---|
| 아르덴티아 → 천원 | 자하라트·인드라 경유 상인·외교관 소수 정착. 수 세대에 걸친 혼혈 발생 | 황린·인드라 접경부에 혼혈 인간 소수 거주. 외형 혼합. 마나 계열은 어느 쪽이든 선택 가능 |
| 천원 → 아르덴티아 | 황린·인드라 상인·학자 소수 정착. 자하라트 내 천원계 거주 구역 존재 | 자하라트 도시에 '동방인 거리' 비공식 존재. 혼혈 2~3세대 |

**비인간 종족 이주:**
- 드워프: 천원 산악지 유사 종족과 아르덴티아 드워프가 교역 경로에서 접촉. 혼혈 사례 극소수.
- 엘프류: 천원 내 극소수 아르덴티아 엘프 후손 존재(4~5세대). 정령술 상실. 천원 술도 계통으로 전환.
- 수인족: 교역 경로 내 일부 이주. 자하라트↔인드라 접경부에 혼합 거주.

**혼혈 원칙:**
- 대륙 간 인간 혼혈: 외형은 혼합. 마나 계열(전투/마법)은 부모 계통 무관하게 독립적으로 발현.
- 비인간 종족 간 혼혈: 세대가 내려갈수록 고유 종족 특성 희석. 3세대 이후 외형상 인간에 가까워지는 경향.

### 아르덴티아 ↔ 아엘루와

- AN 845년 기준 마레티스 탐험선이 카엘라노스 연해와 접촉 중.
- 교역 초기 단계. 이주·혼혈 이력 없음.
- 마레티스 선원 일부가 카엘라노스 해안에 단기 체류한 기록은 존재.

### 카우사이 ↔ 아엘루와

- 타이로나(카우사이)가 카엘라노스·멜리와(아엘루와)와 해상 교류 중.
- 해안 교역 수준. 정착·혼혈 이력 없음.

### 기타 대륙 간

- 현시점 교역 경로 없음. 이주·혼혈 이력 없음.

## 종족 분포 원칙 요약

| 원칙 | 내용 |
|---|---|
| 인간 주류 | 전 대륙에서 인간이 주류 종족. 비율은 대륙마다 상이 |
| 수인족 보편성 | 전 대륙에 동물 기반 종족 존재. 단 종류·문화·사회적 위치는 대륙마다 독자 발전 |
| 드래곤류 보편성 | 전 대륙에 드래곤 또는 드래곤형 존재. 인간형 여부·사회 통합 수준은 대륙마다 상이 |
| 엘프·드워프 확산 | 아르덴티아 고유 종족이지만 타 대륙에도 동일 또는 유사 종족 존재. 동일 기원 여부 불명 |
| 대륙 고유 종족 | 각 대륙마다 해당 대륙에서만 발견되는 종족 존재. 세력 파일에서 확정 |
| 대륙 간 혼혈 | 교역로가 존재하는 대륙 간(아르덴티아↔천원)에서만 발생. 다른 대륙 간은 현시점 없음 |
| 고대 이동 | 현 분포의 이유를 완전히 설명하는 이론 없음. 대붕괴 이전 고대 이동설이 비주류 학설로 존재 |
