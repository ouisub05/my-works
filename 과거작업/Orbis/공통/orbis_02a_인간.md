# Orbis — 전 대륙 공통 설정
# 항목 2-A: 인간 (Human) 통합 설정

---

## 개요

인간은 Orbis 전 대륙에 걸쳐 분포하는 유일한 종족이며, 모든 대륙에서 주류 종족 위치를 점한다.
적응력·번식력·사회 조직력이 타 종족을 압도하며, 마나 각성 시 어떤 계열·속성으로도 발전할 수 있는 유연성을 가진다.
수명이 짧은 대신 세대 교체가 빠르고, 이로 인해 문화·기술 변화 속도가 전 종족 중 가장 빠르다.

---

## 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 60~80년 (대륙별 편차 있음. 아래 참조) |
| **성인 기준** | 16~18세 (대륙·문화별 상이) |
| **신체** | 평균 키 155~190cm. 전 종족 중 체형 다양성 최대 |
| **마나 각성률** | 대륙별 편차 있음. 아래 참조 |
| **고유 능력** | 없음. 단 어떤 마나 계열·속성으로도 발전 가능한 유연성 보유 |
| **혼혈 가능 종족** | 전 종족과 혼혈 가능. 결과는 아래 참조 |

## 대륙별 수명·성인 기준

> 수명 차이는 유전적 차이가 아닌 환경·식생활·의술 수준 차이에서 비롯된다.
> 마나 각성자는 비각성자보다 평균 10~20년 수명이 길어지는 경향이 있다.

| 대륙 | 평균 수명 | 성인 기준 | 특이사항 |
|---|---|---|---|
| 아르덴티아 | 60~80년 | 16~18세 | 귀족·마법사 계층은 마나 영향으로 80~90년 가능 |
| 천원 | 60~80년 | 16~18세 | 기(氣) 수련자는 100년 이상 사례 존재. 선인(仙人) 경지 도달 시 수명 연장 |
| 아엘루와 | 60~80년 | 14~16세 (세력별 상이) | 고마나 농도 환경 영향으로 각성자 수명 아르덴티아보다 소폭 높다는 추정 |
| 카우사이 | 55~75년 | 14~16세 | 밀림·고원 환경의 혹독함으로 비각성자 평균 수명 낮음 |
| 이프리카 | 55~80년 | 14~16세 | 세력·지역별 편차 극심. 다하브 고원 거주자가 상대적으로 장수 |

---

## 대륙별 마나 각성률

> 각성률은 해당 대륙 인간 인구 중 마나를 운용 가능한 수준으로 각성한 비율.
> 잠재 각성(마나 보유하나 운용 불가)은 전 인류 공통. 아래 수치는 실질 각성 기준.

| 대륙 | 평균 각성률 | 특이사항 |
|---|---|---|
| 아르덴티아 | 약 12% | 공식 집계. 국가별 편차 존재. 마고리아·마레티스 높음 |
| 천원 | 약 10~15% | 수련 문화로 자연 각성보다 수련 각성 비율 높음 |
| 아엘루와 | 세력별 편차 큼 | 전체 평균 미산정. 고마나 농도 환경으로 아르덴티아보다 높을 것으로 추정 |
| 카우사이 | 세력별 편차 큼 | 의식 각성 비율 높음. 타완틴 신관 집단은 높은 각성률 유지 |
| 이프리카 | 세력별 편차 큼 | 전체 평균 미산정. 무칸다 밀림 고농도 지역 세력이 높은 편 |

**공통 원칙:**
- 마나 각성은 후천적 수련·자연 발현·의식 등 대륙마다 방식이 다르나 결과는 동일
- 각성률은 마나 농도가 높은 지역일수록 높아지는 경향
- 강제 각성은 전 대륙 금기. 각성률 통계에 포함되지 않음

## 인간의 전 대륙 주류 원인

> 인간이 Orbis 모든 대륙에서 주류 종족인 이유에 대해 각 대륙은 독자적 해석을 가진다.
> 공통 설정에서 확정된 물리적 이유는 아래와 같다.

| 특성 | 내용 |
|---|---|
| **적응력** | 극지·사막·밀림·고산 등 어떤 환경에서도 정착 가능. 타 종족 대부분은 특정 환경에 최적화 |
| **번식력** | 수명 대비 출산 주기가 짧고 다산 가능. 엘프·드워프 등 장수 종족과 비교 시 세대 교체 압도적으로 빠름 |
| **사회 조직력** | 대규모 집단 형성·분업·협력 체계 구축 능력. 타 종족보다 국가·제도 발전 속도 빠름 |
| **마나 유연성** | 각성 시 어떤 계열·속성으로도 발전 가능. 특정 계열에 고정된 종족보다 전략적 다양성 높음 |
| **단명의 역설** | 짧은 수명이 오히려 집중력·야망·변화 수용성을 높임. 수백 년 사는 종족보다 단기간 성취 지향적 |

## 인간 혼혈 원칙

> 인간은 Orbis에서 유일하게 거의 모든 종족과 혼혈이 가능한 종족이다.

### 혼혈 가능 종족 및 결과

| 혼혈 | 명칭 (아르덴티아 기준) | 결과 특성 |
|---|---|---|
| 인간 + 순혈 엘프 | 하프 엘프(Elvus Dimidius) | 수명 100~200년. 정령술 약화 보유. 마나 각성률 높음 |
| 인간 + 드워프 | 반석 혈통(Stoneblooded) | 드워프보다 키 크고 인간보다 단단. 룬 친화성 약화 |
| 인간 + 수인족 | 경혈 수인(Lightkin) | 수인족 특성 약화·안정화. 야성 해방 발동 빈도 낮음 |
| 인간 + 드래곤 수인 | 드래곤 수인 저혈~잠재혈 | 세대 거듭할수록 외형 인간에 가까워짐. 마나 총량은 평균 이상 유지 |
| 인간 + 정령 혼혈 | 극희귀. 명칭 미확정 | 사례 극소수. 정령 속성 약하게 외형에 발현 |

### 혼혈 공통 원칙

- 인간 혼혈은 세대가 내려갈수록 인간 특성이 강해지는 경향
- 마나 계열(전투/마법)은 부모 종족 무관하게 개인에 따라 독립적으로 발현
- 혼혈 자녀의 수명은 부모 두 종족 수명의 중간값에 가까움
- 혼혈에 대한 사회적 처우는 대륙·세력마다 극단적으로 다름

### 대륙별 혼혈 처우 개요

| 대륙 | 혼혈 처우 |
|---|---|
| 아르덴티아 | 국가별 극단적 편차. 디르우드(하프 엘프 차별) ↔ 베르단티스(완전 시민권) / 케메트라(혼혈 법적 보호 최소) |
| 천원 | 수인족 혼혈은 지역별 차별 존재. 엘프류 혼혈은 신성시 경향 |
| 아엘루와 | 세력 파일 확정 후 추가 |
| 카우사이 | 수인족 경계 자체가 유동적. 혼혈 개념 타 대륙보다 느슨 |
| 이프리카 | 세력별 상이. 전사 계층 혼혈은 전투력 기준으로 평가받는 경향 |

## 인간의 마나 각성 방식 — 전 대륙 비교

> 인간이 마나를 각성하는 방식은 대륙마다 다르게 발전했다.
> 어떤 방식이든 각성 결과(마나 운용 가능 상태)는 동일하다.

| 방식 | 주요 대륙 | 특징 |
|---|---|---|
| 자연 각성 | 전 대륙 공통 | 극한 감정·위기 상황에서 자연 발현. 가장 흔함. 폭주 위험 |
| 수련 각성 | 아르덴티아·천원 중심 | 체계적 훈련으로 안정적 각성. 시간 오래 걸림 |
| 의식 각성 | 카우사이·이프리카·아엘루와 | 샤먼·신관 의식 통해 발현. 방향성 고정되는 단점 |
| 계승 각성 | 아르덴티아·천원 일부 | 혈통 또는 스승의 마나로 각성 촉진. 수련 각성의 변형 |
| 강제 각성 | 전 대륙 금기 | 약물·외력으로 강제 발현. 회로 손상·폭주·사망 위험 |
