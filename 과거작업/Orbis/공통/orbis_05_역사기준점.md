# Orbis — 전 대륙 공통 설정
# 항목 5: 역사 기준점 및 연도 환산표

---

## 개요

Orbis의 5개 대륙은 **공통 역사 기준점을 공유하지 않는다.**
각 대륙은 자신의 역사에서 가장 중요한 사건을 원년으로 삼아 독자적인 역법을 발전시켰다.
대붕괴(Ruina)는 아르덴티아의 역사 기준점이며, 타 대륙에는 동등한 공통 사건이 존재하지 않는다.
각 대륙이 서로의 역법을 인지하는 정도도 교류 수준에 따라 다르다.

본 파일의 환산표는 **독자·서술자 편의를 위한 메타 정보**다.
세계 내 어느 대륙도 이 환산 기준을 공식적으로 채택하지 않았으며,
환산표 자체가 세계 내 존재하는 문서가 아니다.

---

## 각 대륙 역법 개요

| 대륙 | 역법명 | 약칭 | 원년 기준 사건 | 현재 시점 |
|---|---|---|---|---|
| 아르덴티아 | 아에타스 노바 (Aetas Nova) | AN | 대붕괴(Ruina) 직후 신기원 선포 | AN 845년 |
| 천원 | 천력 (天曆) | 천력 | 하늘이 열린 날 (開天節) | 천력 1847년 |
| 아엘루와 | 아엘루와력 | AE | 동부 세력(아오웨니) 최초 문명 기원년 | AE 미확정 |
| 카우사이 | 카우사이력 (Kawsay Nova) | KN | 타완틴 제국 건국 원년 | KN 612년 |
| 이프리카 | 이프리카력 (Ifriqah Nova) | IN | 균열기(Shaqq) 이후 대지맥 최초 안정년 | IN 412년 |

## 현재 시점 연도 환산표

> AN 845년을 기준으로 전 대륙 현재 시점 연도를 병기한 표.
> 아엘루와력(AE)은 원년 확정 전이므로 현재 미산정.

| 대륙 | 역법 | 현재 연도 |
|---|---|---|
| 아르덴티아 | 아에타스 노바 (AN) | **AN 845년** |
| 천원 | 천력 (天曆) | **천력 1847년** |
| 아엘루와 | 아엘루와력 (AE) | **미확정** |
| 카우사이 | 카우사이력 (KN) | **KN 612년** |
| 이프리카 | 이프리카력 (IN) | **IN 412년** |

## 역법 간 연도 환산 원칙

> 각 역법의 원년이 AN력 기준 몇 년에 해당하는지를 산출한 기준값.
> 이 기준값을 통해 어떤 연도든 상호 환산 가능.

| 역법 | 원년 = AN 몇 년? | 환산 공식 |
|---|---|---|
| AN (아에타스 노바) | AN 1년 = 기준 | — |
| 천력 (天曆) | 천력 1년 = AN −1002년 | **천력 N년 = AN (N − 1002)년** / **AN M년 = 천력 (M + 1002)년** |
| KN (카우사이력) | KN 1년 = AN 233년 | **KN N년 = AN (N + 232)년** / **AN M년 = KN (M − 232)년** |
| IN (이프리카력) | IN 1년 = AN 433년 | **IN N년 = AN (N + 432)년** / **AN M년 = IN (M − 432)년** |
| AE (아엘루와력) | 원년 미확정 | 미산정 |

### 환산 예시

| 사건 | 해당 대륙 연도 | AN 환산 | 비고 |
|---|---|---|---|
| 아르덴티아 대붕괴(Ruina) | AN 1년 | AN 1년 | 아르덴티아 역법 원년 |
| 천원 개천절(開天節) | 천력 1년 | AN −1002년 | 아르덴티아 대붕괴보다 1002년 이전 |
| 타완틴 제국 건국 | KN 1년 | AN 233년 | 대붕괴 후 233년 뒤 |
| 이프리카 균열기 안정 | IN 1년 | AN 433년 | 대붕괴 후 433년 뒤 |
| **현재 시점** | AN 845년 | AN 845년 | 전 대륙 공통 현재 |

## 각 대륙 역사 기준점 상세

### 아르덴티아 — 대붕괴 (Ruina)

| 항목 | 내용 |
|---|---|
| **사건명** | 대붕괴 (Ruina) |
| **AN 연도** | AN 1년 (기준) |
| **내용** | 고대 문명 7개가 공명탑 12개를 동시 가동하다 연쇄 폭발. 문명 붕괴 및 차원 균열(Fissura) 발생 |
| **타 대륙 인지** | 없음. 아르덴티아 내부 사건으로 인식. 단 전 세계적 현상일 가능성은 학자들 사이에서 논의 중 |
| **역법 의미** | 붕괴 이후 새 시대 선포. 생존 세력들이 공동으로 채택 |

---

### 천원 — 개천절 (開天節)

| 항목 | 내용 |
|---|---|
| **사건명** | 하늘이 열린 날 (開天節) |
| **AN 환산** | AN −1002년 (아르덴티아 대붕괴보다 1002년 이전) |
| **내용** | 천원 최초 문명이 기(氣)를 처음 인식하고 삼재(三才) 철학을 확립한 날. 신화적 기원 포함 |
| **타 대륙 인지** | 없음 |
| **역법 의미** | 천원 문명 전체의 기원으로 상징화. 황린 황실이 역법 권위 보유 |

---

### 카우사이 — 타완틴 건국

| 항목 | 내용 |
|---|---|
| **사건명** | 타완틴 제국 건국 (Kawsay Qallariy) |
| **AN 환산** | AN 233년 |
| **내용** | 타완틴 제국이 안데스 고원을 통일하고 카우사이력 원년을 선포 |
| **타 대륙 인지** | 없음 |
| **선대(Ñawpa Pacha)** | 건국 이전 시대. 단편적 기록만 존재. "대지의 울부짖음(Allpa Qaparir)"이 이 시대에 속할 가능성 있음 |

### 이프리카 — 균열기 이후 안정 (Shaqq 이후)

| 항목 | 내용 |
|---|---|
| **사건명** | 균열기(Shaqq) 이후 대지맥 최초 안정년 |
| **AN 환산** | AN 433년 |
| **내용** | 균열기라는 대규모 마나 재해 이후 이프리카 대지맥이 처음 안정된 해를 기원년으로 채택 |
| **균열기(Shaqq)** | 대지맥이 폭발적으로 불안정해진 시대. 사하라 공백지대 형성의 원인으로 추정. 아르덴티아 대붕괴와의 연관성 미확정 |
| **타 대륙 인지** | 없음 |

### 아엘루와 — 미확정

| 항목 | 내용 |
|---|---|
| **사건명** | 동부 세력(아오웨니) 최초 문명 기원년 (추정) |
| **AN 환산** | 미산정 — 아오웨니 세력 파일 확정 후 산정 예정 |
| **현황** | 마레티스 탐험대 역법 해독 미완. 아오웨니와 직접 접촉 없음 |

## 각 대륙의 타 대륙 역법 인지 수준

| 대륙 | 인지하는 타 대륙 역법 | 인지 수준 |
|---|---|---|
| 아르덴티아 | 천력(天曆) | 교역 중. 상인·외교관 수준에서 환산 가능. 학자들은 정밀 환산표 보유 |
| 아르덴티아 | 이프리카력(IN) | 케메트라·아타르발 교역 접점에서 부분 파악. 정밀 환산 미완 |
| 아르덴티아 | 아엘루와력(AE) | 마레티스 탐험대가 역법 존재 인지. 해독 미완 |
| 천원 | AN력 | 천사로 교역 접점에서 파악. 황린 황실 문서에 환산 기록 존재 |
| 천원 | IN력 | 인드라 경유 간접 파악. 정밀 환산 미완 |
| 이프리카 | AN력 (부분) | 케메트라·다하브 교역 접점에서 부분 파악 |
| 이프리카 | 천력 (간접) | 인드라 경유 천원 상품 교역 수준. 역법 자체는 미파악 |
| 아엘루와 | KN력 (부분) | 카엘라노스·멜리와↔타이로나 교류. 카우사이력 존재 인지. 정밀 환산 미완 |
| 카우사이 | AE력 (부분) | 타이로나↔카엘라노스 교류. 아엘루와력 존재 인지. 정밀 환산 미완 |

## 대붕괴와 타 대륙 재해의 연관성 — 미확정

> 아르덴티아의 대붕괴(AN 1년), 이프리카의 균열기(IN 1년 이전),
> 카우사이의 대지의 울부짖음(선대 시기), 아엘루와 고대 유적 봉인 현상이
> 동일한 사건 또는 연쇄 사건인지에 대해 현시점 어느 대륙도 확인하지 못했다.

| 대륙 | 재해 명칭 | AN 환산 시점 | 연관성 |
|---|---|---|---|
| 아르덴티아 | 대붕괴 (Ruina) | AN 1년 | 기준 사건 |
| 이프리카 | 균열기 (Shaqq) | AN 433년 이전 (정확한 시점 불명) | 대붕괴와 별개 사건으로 추정. 연관성 미확정 |
| 카우사이 | 대지의 울부짖음 (Allpa Qaparir) | KN 이전 (AN 233년 이전) | 구전만 존재. 연관성 미확정 |
| 아엘루와 | 고대 유적 봉인 현상 | 시점 불명 | 존재 확인만 됨. 연관성 미확정 |
| 천원 | 해당 기록 없음 | — | 천원 문헌에 대규모 마나 재해 기록 부재 |

> 베네눔 코르디스(아르덴티아 빌런 세력)가 대붕괴 재현을 시도 중이며,
> 신대륙(아엘루와)에도 대붕괴 흔적이 존재한다는 마레티스 극비 보고가 있다.
> 이것이 전 세계적 사건의 증거인지는 현시점 미확정.
