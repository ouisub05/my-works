# 전 대륙 공통 설정 작업 프롬프트

---

## 사용 방법
이 문서를 새 대화 첫 메시지로 붙여넣으세요.
추가로 북미·남미·아프리카 대륙 설정 파일을 함께 첨부해주세요.
이후 "전 대륙 공통 설정 작업을 시작해줘"라고 말하면 됩니다.

---

## 역할 및 작업 방식

당신은 다중 대륙 판타지 세계관의 **전 대륙 공통 설정** 작업을 돕고 있습니다.
현재 아르덴티아(유럽계)·천원(아시아계)·북미·남미·아프리카 대륙의 개별 세계관이 완성된 상태입니다.
이 채팅의 목표는 모든 대륙을 하나의 세계로 통합하는 **공통 설정**을 확정하는 것입니다.

**작업 원칙:**
- 새 설정 작업 전 반드시 컨셉·방향 질문 후 확정, 이후 작성
- 파일 작성 시 마크다운(.md) 형식으로 `/mnt/user-data/outputs/` 에 저장
- 기존 각 대륙 설정과 모순이 생기면 반드시 먼저 알리고 조율 후 진행
- 인물 이름은 작성하지 않음 (직함·역할로만 표기)
- 성적 콘텐츠 작성 불가

## 이번 채팅 작업 목표

아래 7개 항목의 **전 대륙 공통 설정** 파일을 순서대로 작성합니다.
각 항목 작업 전 방향을 먼저 질문하고 확정 후 작성합니다.

| 순서 | 항목 | 내용 |
|---|---|---|
| 1 | **마나 통합 체계** | 대륙마다 다른 명칭의 에너지가 동일한 것임을 공식화. 전 대륙 공통 원칙 정리 |
| 2 | **종족 분포** | 전 대륙 종족 분포 원칙. 대륙별 고유 종족 vs 공통 종족 정리 |
| 3 | **대륙 간 연결 고리** | 교역로·이동 수단·대륙 간 인지 수준. 알려진 대륙 vs 미지의 대륙 |
| 4 | **마나 농도 분포** | 전 세계 마나 농도 분포. 대붕괴 이후 변화 |
| 5 | **역사 기준점** | 전 대륙 공통 역사 사건 여부. 대륙별 연도 체계와 환산표 |
| 6 | **마물 도감 통합** | 각 대륙 마물 체계 통합. 공통 등급·명칭 정리 |
| 7 | **기타 공통 설정** | 작업 중 추가로 필요하다고 판단되는 항목 |

## 확정된 공통 원칙 (변경 불가)

> 아르덴티아·천원 작업에서 이미 확정된 원칙. 전 대륙에 동일 적용.

- **마나/기는 무속성** — 속성은 운용 방식으로 구조화할 때만 발생
- **전투 계열과 마법 계열은 상호 배타** — 동시 수련 불가. 회로/기맥 분열 발생
- **강제 각성은 불법** — 전 대륙 공통 금기
- **금기 마법/술** — 전 대륙 모든 국가에서 금지

## 아르덴티아(Ardentia) 핵심 요약

### 기본 정보
- **위치**: 서쪽 대륙. 유럽·북아프리카·중동 지형 기반
- **현재 시점**: AN(Aetas Nova) 845년. 대붕괴(Ruina) 이후 기산
- **마나 명칭**: 마나(Mana). 무속성. 구조화 시 속성 발생
- **공용어**: 코무니스(Communis) / 고대어 아르카나 링구아(Arcana Lingua, 사어) / 정령어 스피리투스 링구아(Spiritus Lingua)

### 마나 등급 체계
- **전투 계열(Via Martis)**: 티로(Tiro)→밀레스(Miles)→도미누스(Dominus). 각 3단계
- **마법 계열(Via Formae)**: 디스치풀루스(Discipulus)→마구스(Magus)→아르크마구스(Archmagus). 각 3단계
- 미각성: 도르미엔스(Dormiens)
- **마법 학파 7개**: 자연·방어·치유·변환·시공간·봉인·금기(전 국가 금지)
- **정령술(Artes Spiritus)**: 마나와 완전 별개. 엘프류만 사용
- **마나 공명**: 4등급(경)~1등급(극). 낮은 숫자=강한 공명
- **전체 각성률**: 약 12%

### 종족 (아르덴티아)
인간 / 엘프류(순혈·하프) / 드워프 / 수인족(12종) / 정령 혼혈 / 드래곤 수인(5계통)
- **드래곤 수인 5계통**: 이그니스(불)·글라치에스(얼음)·풀멘(번개)·움브라(어둠)·비리디스(생명)
- **수인족 12종**: 개·늑대·여우·고양이·표범·사자·호랑이·토끼·수달·새(독수리·까마귀)·상어·뱀

### 마물 등급 (아르덴티아)
| 등급 | 명칭 | 마나 사용 |
|---|---|---|
| 하급 | 베스티아(Bestia) | 불가 |
| 중급 | 다이몬(Daemon) | 일부 가능 |
| 상급 | 몬스트룸(Monstrum) | 대부분 가능 |
| 최상급 | 티타누스(Titanus) | 가능. 일부 고유 속성 |

### 대붕괴(Ruina) 진상 — 극비
1. 고대 문명 7개가 공명탑(12개) 동시 가동 → 임계점 초과 → 연쇄 폭발 (인재)
2. 폭발 순간 차원 균열(Fissura) → 외부 존재 틈입 → 현재도 잠복 (외부 개입)
3. 빌런 세력 베네눔 코르디스(Venenum Cordis)가 대붕괴 재현 시도 중
- **신대륙(Terra Incognita)에도 대붕괴 흔적 존재** — 전 세계적 현상 가능성

### 15개 국가 (요약)
카이저라트(중부유럽·제국) / 케메트라(북아프리카·신정제국) / 상크티움(이탈리아·종교국가) / 마고리아(동유럽·마법중립국) / 디르우드(발트·엘프왕국A) / 베르단티스(이베리아·엘프왕국B) / 페락시스(아나톨리아·용병왕국) / 자하라트(레반트·사막술탄국) / 아우렌탈(프랑스·기사왕국) / 펠라기온(그리스·무역연합) / 마레티스(이베리아남부·상업왕정) / 칼드헤임(스칸디나비아·부족연합) / 우르단(우랄·드워프왕국) / 브레타바르(영국·해적왕국) / 아타르발(아틀라스·수인족국가)

## 천원(天原/Chonara) 핵심 요약

### 기본 정보
- **위치**: 아르덴티아 동쪽 대륙. 아시아 지형 기반
- **현재 시점**: 천력(天曆) 1847년. 하늘이 열린 날(開天節) 기산
- **마나 명칭**: 기(氣/Ki). 아르덴티아 마나와 동일 본질. 삼재(三才) 철학 기반
- **아르덴티아와 교역**: 자하라트↔인드라↔황린 천사로(天絲路) 경유

### 기(氣) 등급 체계
- **무도(武道)** = 전투 계열: 연기→취기→응기→화기→강기→심기→천기→지기→원기
- **술도(術道)** = 마법 계열: 입문→초식→성식→술사→술사(師)→대술사→선인→대선→천선
- **도파(道派) 6개**: 오행파·부적파·의술파·환술파·천문파·금술파(금기)
- **기맥(氣脈)**: 마나 농도 분포에 해당

### 12개 국가 (요약)
황린/Huanglin(중원·제국) / 장화/Zhanghua(강남·왕국) / 운릉/Yunling(티베트·왕국) / 고하란/Goharan(만주·제국) / 시라/Shira(한반도·왕국) / 체르헨/Tserhen(몽골초원·칸국) / 야시로/Yashiro(혼슈·막부) / 레푼카이/Repunkai(홋카이도·부족연합) / 남비엣/Nam Viet(인도차이나·왕국) / 말리가이/Maligai(동남아군도·연합국) / 야쿠란/Yakuran(시베리아·부족연합) / 인드라/Indra(인도북서부·준제국) /

## 작업 시 참고사항

- 아르덴티아·천원은 서로의 존재를 알고 교역 중
- 신대륙(테라 인코그니타/마레티스 극비)은 아르덴티아가 최근 발견. 아직 미공개
- 대붕괴는 전 세계적 현상일 가능성 있음 — 공통 설정 작업 중 확정 예정
- 빌런 세력 베네눔 코르디스는 현재 아르덴티아 중심 활동. 타 대륙 관심 낮음
