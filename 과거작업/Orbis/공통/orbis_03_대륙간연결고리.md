# Orbis — 전 대륙 공통 설정
# 항목 3: 대륙 간 연결 고리

---

## 개요

AN 845년 기준, Orbis의 5개 대륙은 **완전히 연결된 상태가 아니다.**
아르덴티아↔천원 간 교역로가 가장 오래되고 안정적이며,
아르덴티아↔이프리카, 천원↔이프리카 간 교역도 존재한다.
아엘루와는 최근 마레티스가 발견했고, 카우사이는 아엘루와와 해상 교류 중이나
5개 대륙이 서로를 모두 아는 상태는 아니다.

---

## 이동 수단

### 기본 원칙

| 항목 | 내용 |
|---|---|
| **주요 수단** | 범선. 마나 보조 없는 순수 바람·조류 의존 항해 |
| **대륙 간 소요 시간** | 교역로에 따라 수 주~수 개월 |
| **마나 보조** | 일반 교역선에는 없음. 일부 군함·특수 선박에 마나 각성자 탑승하여 바람 조절·속도 향상 보조. 이 경우 항해 기간 단축 가능 |
| **육상 이동** | 대륙 내부 이동 및 대륙 간 육상 연결 구간에 한정. 낙타·말 등 축력 의존 |

### 경로별 이동 기간 (범선 기준)

| 경로 | 방식 | 소요 기간 |
|---|---|---|
| 아르덴티아 ↔ 천원 (천사로) | 자하라트→인드라→황린 육상+내해 혼합 | 편도 수 개월 |
| 아르덴티아 ↔ 이프리카 (북아프리카 육상) | 케메트라↔쿠시 육상 | 편도 수 주~수 개월 |
| 아르덴티아 ↔ 이프리카 (대서양·인도양 해상) | 아타르발↔팔람 해안 항로 | 편도 수 주~1개월 |
| 천원 ↔ 이프리카 (인도양 해상) | 인드라↔다하브 홍해·인도양 항로 | 편도 수 주~수 개월 |
| 아르덴티아 ↔ 아엘루와 | 마레티스 탐험선. 대서양 서진 | 편도 3~4주 |
| 카우사이 ↔ 아엘루와 | 타이로나↔카엘라노스·멜리와 해상 | 편도 수 일~수 주 |

## 교역로 상세

### 1. 천사로 (天絲路) — 아르덴티아 ↔ 천원

> Orbis에서 가장 오래되고 안정적인 대륙 간 교역로.
> 아르덴티아의 자하라트↔인드라↔천원의 황린을 잇는 육상·내해 혼합 루트.

| 항목 | 내용 |
|---|---|
| **경로** | 아르덴티아(자하라트) → 인드라(준제국) → 천원(황린) |
| **방식** | 사막 대상(隊商) + 내해·강 수로 혼합 |
| **주요 품목** | 아르덴티아→천원: 마법 도구·유리·양모·금속 가공품 / 천원→아르덴티아: 비단·도자기·향신료·한약재 |
| **역사** | 수백 년 운영. 현재도 활발 |
| **관리 세력** | 자하라트(아르덴티아 측) / 인드라(중간 거점) / 황린 상단(천원 측) |
| **위험** | 사막 구간 마물·산적. 산악 구간 악천후 |

---

### 2. 북아프리카 육상로 — 아르덴티아 ↔ 이프리카

> 케메트라(아르덴티아)↔쿠시(이프리카) 간 전통 육상 루트.
> 정치적으로 케메트라-쿠시 관계에 종속되어 있어 불안정 요소 내재.

| 항목 | 내용 |
|---|---|
| **경로** | 아르덴티아(케메트라) → 쿠시(이프리카) → 이프리카 내륙 |
| **방식** | 나일강 수계 + 사막 대상 |
| **주요 품목** | 상아·황금·향료 / 아르덴티아산 금속·직물 |
| **현황** | 쿠시 독립 준비로 인해 노선 안정성 불투명. 케메트라 상단 긴장 중 |
| **혼혈 발생** | 케메트라↔쿠시 접경부에 혼혈 인간 소수 거주 |

---

### 3. 대서양·서아프리카 해상로 — 아르덴티아 ↔ 이프리카

> 아타르발(아르덴티아 수인족 국가)↔팔람(이프리카 서아프리카) 간 해안 항로.
> 공식 외교보다는 상인 네트워크 중심의 비공식 교류.

| 항목 | 내용 |
|---|---|
| **경로** | 아르덴티아(아타르발·마레티스) → 서아프리카 해안 → 팔람 |
| **방식** | 해안 따라 남하하는 범선 항로 |
| **주요 품목** | 팔람 황금·상아 / 아르덴티아 금속·도구 |
| **현황** | 비공식 상인 네트워크 중심. 정기 교역선 존재 |
| **혼혈 발생** | 아타르발↔팔람 해안 접경부에 혼혈 수인족·인간 소수 거주 |

---

### 4. 인도양 해상로 — 천원 ↔ 이프리카

> 천원의 인드라↔이프리카의 다하브 간 인도양·홍해 해상 루트.
> 천사로의 연장선상에 있는 경로로, 인드라가 중간 거점 역할.

| 항목 | 내용 |
|---|---|
| **경로** | 천원(인드라) → 홍해·인도양 → 이프리카(다하브) |
| **방식** | 계절풍 이용 범선 항로 |
| **주요 품목** | 천원 비단·도자기·향신료 / 다하브 황금·상아·향료 |
| **현황** | 계절풍 의존으로 왕복 가능 시기 제한적. 연 1~2회 정기 교역 |
| **혼혈 발생** | 인드라↔다하브 교역 거점에 혼혈 인간 소수 거주 |

---

### 5. 대서양 서진로 — 아르덴티아 ↔ 아엘루와

> 마레티스 왕국 탐험대가 개척한 최신 항로. AN 845년 기준 극비.

| 항목 | 내용 |
|---|---|
| **경로** | 아르덴티아(마레티스) → 대서양 서진 → 아엘루와(카엘라노스 동남부 해안) |
| **방식** | 탐험선. 정기 교역선 미운영 |
| **소요 기간** | 편도 약 3~4주 |
| **현황** | 마레티스 왕실 극비. 아르덴티아 내 타 국가 미인지 |
| **교류 수준** | 카엘라노스 해안 세력과 물물교역 초기 단계. 언어 장벽 존재 |

---

### 6. 카리브·중미 해상로 — 카우사이 ↔ 아엘루와

> 타이로나(카우사이)↔카엘라노스·멜리와(아엘루와) 간 해상 교류.

| 항목 | 내용 |
|---|---|
| **경로** | 카우사이(타이로나) → 카리브해 → 아엘루와(카엘라노스·멜리와) |
| **방식** | 해안·도서 간 범선 항로 |
| **주요 품목** | 열대 산물·직물·마나 도구류 |
| **현황** | 정기적 교역. 양측 모두 상대 세력의 존재 인지 |

## 대륙 간 인지도 — AN 845년 기준

> ✅ 인지 / ⚠️ 부분 인지(존재는 알지만 규모·위치 불명확) / ❌ 미인지

|---|---|---|---|---|---|

| **천원** | ✅ 교역 중 | — | ⚠️ 인드라 경유 간접 인지 | ❌ | ❌ |
| **이프리카** | ✅ 케메트라·아타르발 접촉 | ⚠️ 인드라 경유 간접 인지 | — | ❌ | ❌ |

| **카우사이** | ❌ | ❌ | ❌ | ⚠️ 타이로나가 아엘루와 규모 대강 파악 | — |

### 인지도 상세 비고

| 관계 | 상세 |
|---|---|
| 아르덴티아 → 천원 | 수백 년 교역. 양측 모두 상대 대륙의 규모·국가 구조를 대략 파악 |
| 아르덴티아 → 이프리카 | 케메트라(쿠시 경유 육상)·아타르발(서해안 해상) 양 경로로 접촉. 사하라 이남 내륙 세력은 아르덴티아에 미상세 파악 |
| 천원 → 이프리카 | 인드라가 인도양 교역으로 다하브와 접촉. 황린 본토는 이프리카를 '인드라 너머의 교역 상대'로 간접 인지 |
| 이프리카 → 천원 | 다하브가 인드라 경유 천원 상품을 교역. 천원 본토 직접 인지는 없음 |
| 아르덴티아 → 아엘루와 | 마레티스만 인지. 카엘라노스 해안 한정 접촉. 내륙 세력 존재 미파악. 극비 |
| 아엘루와 → 아르덴티아 | 카엘라노스가 마레티스 탐험선 접촉. 아르덴티아 대륙의 규모·국가 수 미파악 |
| 아엘루와 ↔ 카우사이 | 카엘라노스·멜리와↔타이로나 해상 교류. 타이로나는 아엘루와의 대강 규모 파악. 카엘라노스는 카우사이를 '남쪽 대륙의 일부 세력'으로 인식 |
| 카우사이 → 이외 대륙 | 타이로나 제외 카우사이 세력은 대륙 외부 세계 인지 없음 |
| 이프리카 → 아엘루와·카우사이 | 전혀 미인지 |

## 대륙 간 교역 결제 수단

| 항목 | 내용 |
|---|---|
| **공통 화폐** | 없음. 대륙별 화폐는 해당 대륙 내에서만 통용 |
| **실질 기준** | 금·은의 중량. 전 대륙 공통으로 귀금속 중량이 교환 기준 역할 |
| **물물교역** | 교역 초기 단계 또는 화폐 체계가 다를 때 물품 직접 교환 |
| **금 기준재** | 아르덴티아·이프리카(팔람 황금) 교역에서 금 중량이 사실상 기준가 역할 |
| **천원 특이사항** | 천원 내부에서는 동전 화폐 사용. 대외 교역에서는 금·은 중량으로 환산 |

## 미지의 대륙·해역

| 항목 | 내용 |
|---|---|
| **아엘루와 내륙** | 마레티스 탐험대 미탐사. 아르덴티아에 완전 미지 |
| **카우사이** | 아르덴티아·천원·이프리카에 완전 미지. 아엘루와(타이로나)가 존재만 인지 |
