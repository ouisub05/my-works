# 🌿 카우사이(Kawsay) — 종족 분포 설정

---

## 개요

카우사이는 Orbis 대륙 중 종족 다양성이 가장 낮은 편에 속한다.
인간이 압도적 주류이며, 수인족은 소수이나 특정 세력·지역에서 일반 구성원으로 공존한다.
아르덴티아의 엘프·드워프에 해당하는 장수 고유 종족은 존재하지 않으며,
드래곤류 또한 현생 개체는 확인되지 않는다.

카우사이의 가장 큰 특징은 **인간과 수인족의 종족 경계가 타 대륙보다 유동적**이라는 점이다.
일부 세력에서는 수인족을 별개 종족으로 구분하지 않고 신성한 혈통 혹은 특수한 능력을 가진
공동체 구성원으로 인식하는 경향이 있다.

---

## 종족 구성 개요

| 종족 | 분포 | 사회적 위치 |
|---|---|---|
| **인간** | 전 세력. 압도적 주류 | 모든 세력의 지배적 구성원 |
| **재규어 수인** | 아마나·타완틴 중심 | 신성시. 의식·전사 계층과 연결 |
| **악어 수인** | 아마나 수계 중심 | 일반 구성원. 밀림 전사 역할 |
| **뱀 수인** | 카우사이 전역 산재 | 세력별 처우 상이. 대체로 일반 구성원 |
| **카피바라·수달 수인** | 카룸베 수로 중심 | 일반 구성원. 수로 교역 역할 |
| **드래곤류** | 없음 (현생 개체 미확인) | — |

## 인간

### 기본 특성

카우사이의 인간은 Orbis 공통 설정(orbis_02a)을 따른다.
대륙 고유 특이사항은 아래와 같다.

| 항목 | 내용 |
|---|---|
| **평균 수명** | 55~75년. 밀림·고원 환경의 혹독함으로 비각성자 평균 수명 낮음 |
| **성인 기준** | 14~16세 (세력별 상이) |
| **마나 각성률** | 세력별 편차 큼. 의식 각성 비율 높음 |
| **각성 방식** | 의식 각성(샤먼·신관 주도)이 주류. 자연 각성 병존 |

### 세력별 특이사항

| 세력 | 특이사항 |
|---|---|
| **타완틴** | 신관 집단의 의식 각성 체계가 발달. 각성자 비율 상대적으로 높음. 아푸 등급 도달자는 신격화 |
| **타이로나** | 황금 세공·마나 가공 기술 보유자 중 함피 계열 각성자 비율 높음. 아엘루와 문물 유입으로 각성 방식 다양화 중 |
| **아마나** | 자연 각성 비율 높음. 밀림 동화 전술 수련 과정에서 각성하는 사례 多 |
| **카룸베** | 아툰·함피 균형. 의식 각성보다 자연 각성·수련 각성 비율 높음 |
| **마푸** | 씨족 의례(Ngillatun) 연계 의식 각성 비율 높음. 기마 훈련 중 자연 각성 사례 存 |
| **체케** | 샤먼 왕 주도 의식 각성이 사실상 유일한 체계. 오로라 공명 의식 연계 각성 특이 사례 존재 |

## 수인족

> 카우사이의 수인족은 타 대륙과 달리 독립 국가·세력을 형성하지 않는다.
> 인간 세력 내에 일반 구성원으로 통합되어 있으며,
> 일부 세력에서는 신성한 혈통으로 특별히 처우된다.
> 인간과 수인족의 종족 경계가 유동적이어서 혼혈에 대한 개념도 타 대륙보다 느슨하다.

---

### 재규어 수인 (Jaguarete Kin)

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 반점 무늬 피부 또는 반점 패턴 문신과 유사한 피부. 동공 세로형. 발톱 |
| **신체 특성** | 근력·순발력 강화. 야간 시각. 은신·기습 본능 |
| **마나 성향** | 아툰 계열 강한 친화성. 밀림 동화 전술과 결합 시 극대화 |
| **야성 해방** | 카우사이 명칭: **야와리 포라(Yawari Pora)** — 재규어가 뛰어오르다. 발동 시 순발력·공격력 폭발적 상승 |
| **주요 분포** | 아마나(밀림 전사 계층), 타완틴(신관 의식 연계) |

**사회적 위치:**
- **아마나**: 흑재규어를 밀림의 주인으로 숭배하는 문화에서 재규어 수인은 대족장에 준하는 경외의 대상. 대족장 직속 전사단에 재규어 수인 비율 높음
- **타완틴**: 파차마마의 사자(使者)로 신성시. 신관단 내 재규어 수인은 별도 의식 전담. 황제와 독대 가능한 몇 안 되는 존재
- **기타 세력**: 소수 존재. 강인한 전사로 처우

---

### 악어 수인 (Yacare Kin)

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 비늘 패턴 피부(목·팔뚝·등 집중). 눈 황금빛. 턱 근육 발달 |
| **신체 특성** | 수압 적응. 수중 호흡 장시간 가능. 턱 악력 극강. 피부 방어력 높음 |
| **마나 성향** | 아툰 계열. 수계 환경에서 밀림 동화 전술 연동 가능 |
| **야성 해방** | 카우사이 명칭: **야카레 모티(Yacare Moti)** — 악어가 물다. 발동 시 악력·방어력 폭발적 상승. 수중 전투에서 특히 강함 |
| **주요 분포** | 아마나 수계 지역 중심 |

**사회적 위치:**
- **아마나**: 강 전투단(Ysyry Awqaq)의 핵심 전력. 수계 기동·수중 매복 전술 담당. 일반 구성원이나 전투에서 높은 신뢰를 받음
- **카룸베**: 소수 존재. 수로 경비대(Ysyry Jára)에서 활동하는 경우 있음

---

### 뱀 수인 (Amaru Kin)

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 비늘 피부(밀도 낮음). 혀 이분. 동공 세로형. 일부 개체 머리 후방 비늘 장식 |
| **신체 특성** | 유연성 극강. 독 분비(종에 따라 상이). 체온 조절 능력 특이. 마나 잔향 감지 능력 높음 |
| **마나 성향** | 계열 편차 있음. 아툰·함피 모두 가능. 함피 계열 시 독 마나 변환 특화 |
| **야성 해방** | 카우사이 명칭: **아마루 포라(Amaru Pora)** — 뱀신이 깨어나다. 발동 시 유연성·독 효과 극대화. 감각 폭발적 확장 |
| **주요 분포** | 카우사이 전역 산재 |

**세력별 분포 및 처우:**

| 세력 | 분포 | 처우 |
|---|---|---|
| 타완틴 | 소수. 신관단 내 점술·예언 역할 | 아마루(뱀신) 신앙 연계로 신성시 경향 |
| 아마나 | 밀림 전역 산재 | 독침 주술사(Hampi Ruvicha) 계열과 연계. 함피 수련자 多 |
| 카룸베 | 교역 거점 중심 소수 | 정보 수집·중개 역할. 마나 잔향 감지 능력 교역 첩보에 활용 |
| 타이로나 | 항구 도시 소수 | 일반 구성원. 외래 문물 접촉 창구 역할 일부 |
| 마푸·체케 | 극소수 | 초원·극지 환경 부적합으로 거의 없음 |

---

### 카피바라·수달 수인 (Kapiguara·Lutra Kin)

> 카우사이에서는 두 계열을 통칭해 **수로의 민(Ysyry Reko)**으로 부르기도 한다.
> 외형과 특성이 다르나 수로 문화권에서 함께 분류되는 경향이 있다.

#### 카피바라 수인 (Kapiguara Kin)

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 통통한 체형. 갈색 털 잔존(팔·다리). 이빨 발달. 온화한 인상 |
| **신체 특성** | 수압 적응. 장시간 수중 체류. 온화한 기질. 군집 본능 강함 |
| **마나 성향** | 함피 계열 소폭 친화. 전투보다 지원·치유 역할 |
| **야성 해방** | 발동 빈도 낮음. 발동 시 군집 본능 극대화 — 주변 동료 마나 공명 촉진 효과 |

#### 수달 수인 (Lutra Kin)

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 날렵한 체형. 갈색~검은 털 잔존(등·팔). 손발 수막 흔적 |
| **신체 특성** | 수중 기동성 최상. 유연성 높음. 호기심 왕성. 손재주 뛰어남 |
| **마나 성향** | 아툰·함피 균형. 수중 전투 및 교역 물품 감정 능력 활용 |
| **야성 해방** | 발동 시 수중 기동력·손재주 폭발적 상승. 수중 전투에서 특히 강함 |

**사회적 위치:**
- **카룸베**: 수로 교역 연합의 핵심 구성원. 수로 경비대·교역 선단 내 비율 높음. 수로 지형 지식 뛰어나 수로망 관리 담당
- **아마나**: 강 전투단 내 일부 존재. 악어 수인과 협력 관계
- **기타 세력**: 드묾

## 드래곤류

> 카우사이는 현생 드래곤류 개체가 확인되지 않는 대륙이다.

- 타완틴 신화에 **아마루(Amaru)** — 날개 달린 거대 뱀신 — 의 전승이 존재
- 아마나 구전에도 밀림 깊은 곳 거대 파충류 존재에 대한 언급 있음
- 현시점(KN 612년) 기준 실물 목격 기록 없음. 전설·신화 단계
- 타완틴 신관단은 아마루를 파차마마의 사자로 숭배하며 현생 여부에 대해 공식 입장 없음

## 혼혈 원칙

- 카우사이는 인간과 수인족의 종족 경계가 타 대륙보다 느슨하다
- 혼혈에 대한 사회적 낙인이 거의 없음 — 외형적 특성이 약화된 혼혈은 구분하지 않는 경우 多
- 혼혈 자녀는 수인족 특성 약화 형태로 발현. 야성 해방 발동 빈도 낮아짐
- 재규어·악어 수인 혼혈은 아마나에서 특별히 신성시되지 않음 — 순혈에 한해 신성 부여
