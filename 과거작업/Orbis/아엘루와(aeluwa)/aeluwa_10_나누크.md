## 지리적 특성

> 아엘루와 최북단 극한 환경. 혹한·극야·빙하가 나누크의 방어벽이자 삶의 터전.

**지형:**
- 북부: 극지 툰드라·빙하 지대. 연중 동토
- 서부: 태평양 북부 해안. 어업 거점 집중
- 남부: 타크와(타크와) 접경. 침엽수림 시작 지대
- 동남부: 아우베카(아우베카) 접경. 산악~극지 전이 지대
- 내부: 광활한 설원. 부족별 수렵 구역 분산

**기후:**
- 극한 혹한. 극야(겨울)·백야(여름) 주기
- 연중 대부분 영하. 여름 단기간만 지표 해빙
- 극지 폭풍 주기적 내습 — 외부 세력 접근 자연 차단

**마나 환경:**
- 마나 농도: 아엘루와 평균 수준. 극지 특성상 마나 흐름 안정적·완만
- 극야 마나 현상 — 극야 기간 오로라와 마나 공명. 토와·우와에 모두 증폭
- 빙하 마나 결정 — 고대 빙하 내부에 마나 결정 자연 형성. 나누크 고유 자원

## 정치 구조

> 통합 지도자 없음. 부족별 장로·샤먼이 자치 운영. 외부 위협 시 한시적 부족 협의.

**핵심 구조:**

| 직위 | 구성 | 역할 |
|---|---|---|
| **부족장 (Nanu)** | 각 부족 수장. 생존 능력·경험 기준 추대 | 부족 수렵 구역 관리·일상 결정 |
| **샤먼 (Qukai)** | 마나 각성 술사. 부족별 1~2인 | 오로라 의례·마나 감응·부족 간 중재 |
| **부족 협의 (Nanukai)** | 위기 시 부족장·샤먼 소집 | 외부 대응·대규모 수렵 구역 배분 |

**정치 특성:**
- 평시 부족 간 독립성 강함. 협의 소집은 비정기·비상시 한정
- 샤먼의 오로라 의례 해석이 부족 결정에 사실상 구속력
- 아오웨니 통용어는 키웨이 경유로 일부 부족만 부분 습득

---

## 군사

> 상비군 없음. 생존 기술과 극한 환경이 사실상 방어 전력.

**전력 특성:**
- 극한 환경 생존·이동 특화 — 외부 세력의 나누크 영역 침투 사실상 불가
- 소규모 부족 단위 기습·매복. 정면 전투 개념 없음
- 극지 폭풍·극야 기간 활용 — 외부 세력이 접근 불가한 시기 이동·사냥
- 대외 고립 기조 — 특정 세력과 적대 관계 없음. 영역 침범 시만 대응

**극야 마나 전술:**
- 오로라 마나 공명 시기 토와·우와에 동시 증폭 활용
- 샤먼(우와에) + 전사(토와) 혼성 소규모 부대 — 극야 기간 최대 전투력 발휘

**단계 체계 — 토와(Towa):**

| 단계 | 명칭 | 비고 |
|---|---|---|
| 비각성 | 누 (Nu) | 마나 미각성 |
| 1단계 | 나 (Na) | 입문. 단독 수렵 자격 |
| 2단계 | 나누 (Nanu) | 초급. 부족장 칭호와 동일. 생존 전사 기본 자격 |
| 3단계 | 카누 (Kanu) | 중급 |
| 4단계 | 나카이 (Nakai) | 상급 |
| 5단계 | 나누카이 (Nanukai) | 최고위. 부족 협의 칭호와 동일 어근. 극소수 |

**단계 체계 — 우와에(Uwae):**

| 단계 | 명칭 | 비고 |
|---|---|---|
| 비각성 | 누 (Nu) | 마나 미각성 |
| 1단계 | 쿠 (Ku) | 입문 |
| 2단계 | 쿠카 (Kuka) | 초급 |
| 3단계 | 쿠카이 (Kukai) | 중급. 샤먼 칭호와 동일 어근 |
| 4단계 | 나쿠카이 (Nakukai) | 상급 |
| 5단계 | 나누쿠카이 (Nanukukai) | 최고위. 극소수 |

## 경제

> 어업·수렵·채집이 전부. 교역은 극히 제한적.

**주요 산물:**
- 해양 포유류·어류 — 내부 식량 기반 전부
- 극지 모피·뼈 가공품 — 주변 세력 수요 있으나 교역 빈도 낮음
- 빙하 마나 결정 — 나누크 고유 자원. 존재 자체를 외부 세력 대부분 미파악

**교역 네트워크:**
- 교역 거의 없음. 아우베카·타크와와 간헐적 물물교환 수준
- 키웨이 경유 아오웨니 통용어 일부 전달 — 교역 소통 극히 제한

**화폐:**
- 화폐 개념 없음. 식량·모피 직접 교환
- 빙하 마나 결정은 가치 인지 없이 의례 도구로만 사용

## 마나·각성 체계

| 항목 | 내용 |
|---|---|
| **토와(Towa) 비율** | 약 55% |
| **우와에(Uwae) 비율** | 약 45% |
| **전체 각성률** | 약 13%. 극한 생존 압력과 마나 환경 영향 |
| **토와 특화** | 극한 환경 적응·지구력·냉기 저항 친화성 |
| **우와에 특화** | 오로라 마나 감응·빙하 마나 결정 운용·극야 감각 확장 |
| **고유 마나 현상** | 오로라 마나 공명 — 극야 오로라 발생 시 토와·우와에 동시 증폭. 나누크 고유 현상. 외부 미파악 |

## 아르덴티아(마레티스)와의 관계

> AN 845 기준 마레티스 미파악. 직접 접촉 가능성 최하위.

- 아엘루와 최북단 극지 위치 — 마레티스 탐험 경로상 접근 사실상 불가
- 빙하 마나 결정은 아르덴티아 어느 세력도 존재를 모르는 희귀 자원
- 오로라 마나 공명 현상은 아르덴티아 기준 전례 없는 마나 현상 — 마고리아가 알게 될 경우 즉각 탐사 시도 가능성
