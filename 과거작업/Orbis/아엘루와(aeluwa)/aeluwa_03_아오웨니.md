## 지리적 특성

> 아엘루와 동부 온대 삼림 지대. 대형 강 유역을 중심으로 문명 발달.

**지형:**
- 동부 해안~내륙 삼림 지대 전반
- 대형 강 2~3줄기가 남북으로 흐르며 농경·교역의 축
- 북부: 침엽수림 접경. 북방 세력과 완충 지대
- 남부: 카엘라노스 연해 방향 해안 평야. 교역 접점
- 서부: 대평원 세력(아보카)과 접경. 삼림~초원 전이 지대

**기후:**
- 온대. 사계절 뚜렷
- 강 유역 토양 비옥 — 아엘루와 최대 농업 생산 지대 중 하나

**마나 환경:**
- 마나 농도: 아엘루와 평균 이상. 강 유역·삼림 지대에 마나 집중
- 우와에(Uwae·마법 계열) 각성자 비율이 토와(Towa·전투 계열)보다 높음
- 강 유역 마나 흐름이 안정적 — 우와에 수련 환경 최적

## 역법 — 아오웨니력(曆)

> 아엘루와 대륙 공통 역법의 원형. 아오웨니가 제정하여 교역로를 통해 대륙 전반에 전파.

| 항목 | 내용 |
|---|---|
| **기준** | 태양력. 아오웨니 최초 문명 기원년을 원년으로 |
| **원년 사건** | "첫 번째 씨앗을 강에 뿌린 날" — 아오웨니 건국 신화 기반 |
| **구조** | 1년 = 4절기(節期) × 3달 = 12달. 태양 주기 기준 |
| **절기 명칭** | 씨앗의 절기·성장의 절기·수확의 절기·침묵의 절기 |
| **AN 845 환산** | 미확정 (마레티스 미파악) |
| **타 세력 수용** | 대부분의 아엘루와 세력이 아오웨니력 병용. 일부 세력은 자체 역법 병존 |

## 정치 구조

> 단일 군주 없음. 원로원과 민회가 권력을 분점하는 공화정.

**핵심 기구:**

| 기구 | 구성 | 역할 |
|---|---|---|
| **원로원 (Owani)** | 각 지역 대표 장로·명망가. 종신직 | 법률 제정·외교·전쟁 선포 |
| **민회 (Aeni)** | 자유민 대표. 임기제 | 예산·세금·내정 승인 |
| **집정관 (Towani)** | 원로원 추천·민회 인준. 2인 공동 임기제 | 행정 수반. 전시 군 통수 |

**정치 특성:**
- 집정관 2인 공동 체제 — 단독 권력 집중 방지. 상호 견제
- 원로원 우위 구조. 민회는 견제 역할
- 우와에(마법 계열) 고위 술사 집단이 원로원 내 별도 자문 기구 운영
- 지방은 각 도시 자치. 원로원에 대표 파견

## 군사

> 강성하나 단독 최강은 아님. 대평원 세력(아보카)과 서부 세력(아우베카)이 대립축.

**전력 특성:**
- 우와에(Uwae) 술사 부대가 주력 — 아엘루와 최고 수준의 조직화된 마법 전력
- 토와(Towa) 전투 계열 보병·궁병 병행. 비율은 우와에 우세
- 강 유역 수군 발달 — 내륙 수로 방어·보급 핵심
- 삼림 지형 활용 방어 전술 숙련

**우와에 술사 부대:**
- 아오웨니 고유 우와에 단계 체계로 편제
- 원로원 직속 술사 자문단(최고위 우와에) 별도 운영
- 대외 원정보다 방어·내정 안정 중심 운용

**단계 체계 — 우와에(Uwae):**

| 단계 | 명칭 | 비고 |
|---|---|---|
| 비각성 | 오에 (Oe) | 마나 미각성 |
| 1단계 | 아에니 (Aeni) | 입문 |
| 2단계 | 와오니 (Waoni) | 초급 |
| 3단계 | 엘루아 (Elua) | 중급 |
| 4단계 | 아오와 (Aowa) | 상급 |
| 5단계 | 우와에니 (Uwaeni) | 최고위. 원로원 자문단 자격 |

**단계 체계 — 토와(Towa):**

| 단계 | 명칭 | 비고 |
|---|---|---|
| 비각성 | 오에 (Oe) | 마나 미각성 |
| 1단계 | 토니 (Toni) | 입문 |
| 2단계 | 와토 (Wato) | 초급 |
| 3단계 | 오토와 (Otowa) | 중급 |
| 4단계 | 토와니 (Towani) | 상급. 집정관 칭호와 동일 어근 — 역사적 연원 |
| 5단계 | 에토와 (Etowa) | 최고위. 극소수 |

## 경제

> 아엘루와 동부 최대 농업 생산국. 교역로의 기원이자 중심.

**주요 산물:**
- 강 유역 곡물 — 아엘루와 동부·북부 세력 주요 공급처
- 삼림 목재·모피
- 도자기·직물 — 아오웨니 고유 공예. 대륙 전반 유통
- 우와에 술식 관련 재료·도구 — 독점적 기술 기반 수출

**교역 네트워크:**
- 아엘루와 광역 교역로의 원형 구축 주체
- 동부 해안 → 남부 카엘라노스 연해 방향 교역로 운영
- 서부 대평원 세력과 삼림~초원 접경 교역
- 북부 세력에 곡물 공급 — 정치적 영향력과 연동

**화폐:**
- 아오웨니 고유 교환 체계 존재. 대륙 표준에 가장 근접
- 곡물·직물 기반 가치 척도 + 마나 결정석 보조

| 세력 | 관계 |

## 아르덴티아(마레티스)와의 관계

> AN 845 기준 마레티스 미파악. 직접 접촉 없음.

- 마레티스 탐험대는 카엘라노스 연해 너머 내륙에 대규모 문명 존재를 간접 감지
- 카엘라노스 일부 거점이 "내륙의 오래된 나라"를 언급 — 마레티스 기록에 단편 존재
- 아오웨니어가 광역 통용어임을 마레티스는 전혀 인지하지 못함
- 마레티스 입장에서 최우선 접촉 대상이 될 세력 — 교역·언어·역법 모두 이 세력 기반
