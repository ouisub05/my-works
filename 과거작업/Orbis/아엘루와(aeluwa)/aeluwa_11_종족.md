# 🌎 아엘루와(Aeluwa) 종족 설정

---

## 종족 개요

아엘루와 대륙의 종족은 크게 **인간 계열**, **아엘루와 고유 종족**, **수인족**으로 구분된다.
아르덴티아·천원과 달리 엘프류·드워프에 해당하는 종족은 현시점 미확인이며,
드래곤류 존재 여부도 미확정이다.
아엘루와 전체 인구에서 인간 계열이 압도적 주류를 차지하며,
수인족과 고유 종족은 특정 지역에 집중 분포한다.

---

## 1. 인간 계열

---

### 🧑 테라이(Terrae) — 아엘루와 인간

> 아엘루와 전역에 분포하는 인간 종족. 아르덴티아·천원 인간과 동종이나 독자 문화 발전.
> 아엘루와 9개 세력 모두에서 주류 종족.

#### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 60~80년. 아르덴티아 인간과 동일 |
| **성인 기준** | 14~16세 (세력별 상이) |
| **신체** | 평균 키 160~185cm. 세력·환경별 체형 편차 큼 |
| **마나 각성률** | 세력별 편차 큼. 아르덴티아 평균(12%)보다 높을 것으로 추정 |
| **고유 능력** | 없음. 어떤 계열(토와·우와에)로도 발전 가능 |

#### 특징

- 아르덴티아 인간과 외형 거의 동일 — 마레티스 탐험대원이 처음 접촉 시 혼란을 겪은 원인
- 언어는 아르덴티아 코무니스·고대어와 완전히 다른 체계. 아오웨니어 기반 광역 통용어 사용
- 고마나 농도 환경 장기 적응으로 체력·생존력 아르덴티아 인간보다 강인한 경향
- 마나 각성자의 수명 연장 효과가 아르덴티아보다 소폭 높다는 추정 — 고마나 농도 환경 영향

#### 세력별 특이사항

| 세력 | 특이사항 |
|---|---|
| 아오웨니 | 우와에(마법 계열) 각성자 비율 높음. 각성률 약 18% |
| 아우베카 | 토와(전투 계열) 압도적. 각성률 약 20% — 전투 생존 압력 영향 |
| 아보카 | 토와 압도적. 기마 생활 환경이 하체·지구력 특화 각성 촉진 |
| 키웨이 | 토와·우와에 균형. 수렵 생존 환경이 균형 각성 유도 |
| 타크와 | 우와에 강세. 삼림·호수 마나 환경 영향. 각성률 약 19% |
| 토네카 | 태양 마나 고농도 환경. 각성률 약 22% — 아엘루와 최상위 |
| 멜리와 | 우와에 강세. 달 마나 야간 활성화 환경 영향 |
| 카엘라노스 | 토와 우세. 각성률 약 14% 추정 |
| 나누크 | 극한 환경 생존 압력. 각성률 약 13% |

### 🌊 마리니(Marini) — 해양 혼혈 종족

> 수인족(해양 계열)과 인간의 혼혈이 수세대에 걸쳐 독자 종족으로 정착한 계통.
> 현시점에서는 혼혈 흔적을 유지한 채 독자적으로 번식하는 안정된 종족.
> 아르덴티아 기준 경혈 수인(Lightkin)의 극단적 정착 사례에 해당.

#### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 80~120년. 인간보다 길고 수인족보다 짧음 |
| **성인 기준** | 15~18세 |
| **신체** | 인간형. 청록색~올리브색 피부. 손발에 물갈퀴 흔적. 아가미 흔적(목 측면). 인간보다 유선형 체형 |
| **마나 각성률** | 약 15~17% 추정. 수계 마나 환경 영향 |
| **고유 능력** | 수압 적응 — 수심 50~100m 활동 가능. 해류·수온 감지 능력 |

#### 특징

- 외형은 인간에 가깝지만 수인족 혼혈 흔적인 물갈퀴·아가미 흔적이 잔존
- 야성 해방 없음 — 수인족 혈통이 충분히 희석된 결과. 단 수계 마나 감응 능력은 유지
- 수중 활동 능력이 아르덴티아 수달 수인보다 약하지만 인간보다 압도적으로 우월
- 해상 교역·어업 문화 발달 — 거래 개념에 익숙. 마레티스 탐험대와 최초 물물교환을 성립시킨 배경
- 언어: 마리니어 독자 언어 보유. 아오웨니 통용어도 일부 사용

#### 마나 특성

| 항목 | 내용 |
|---|---|
| **계열 성향** | 우와에(마법 계열) 경향. 수계 마나 친화성 강함 |
| **고유 마나 현상** | 열대 폭풍 시 마나 공명 증폭 — 마레티스 탐험대 관측. 원인 미규명 |
| **운용 방식** | 술식 체계 없음. 수계 마나와의 공명 방식 감각적·본능적 |

#### 분포

- 카엘라노스 연해(세력 1번) 주축. 플로리다·쿠바·도미니카 해안·도서 지대
- 멜리와(세력 8번) 해안 지대 일부 거주

## 2. 아엘루와 고유 종족

---

### 🌿 아르보리(Arbori) — 수목 인족

> 아엘루와 동부 삼림 지대 고유 종족. 아르덴티아 엘프류와 외형 유사하나 완전히 다른 계통.
> 정령 계약 없이 식물과 직접 공생하는 독자 방식으로 발전.

#### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 200~400년 추정. 아르덴티아 엘프류보다 짧거나 유사 |
| **성인 기준** | 30~50세 추정 |
| **신체** | 인간형. 피부에 나뭇결 무늬. 피부에서 옅은 녹색 빛 발광. 귀 끝 뾰족. 키 165~190cm |
| **마나 각성률** | 높음. 아엘루와 비인간 종족 중 최상위 추정 |
| **고유 능력** | 식물 마나 감응 — 식물 성장 촉진·식물과 기초 의사소통 가능 |

#### 특징

- 외형은 엘프류와 유사하지만 정령 계약 능력 없음 — 아르덴티아 엘프의 정령술과 근본적으로 다름
- 식물과의 공생이 핵심 — 아르보리 거주지는 식물 마나 밀도가 주변보다 현저히 높음
- 드워프처럼 제조·건축 문화 발달하나 금속 아닌 살아있는 목재·식물 재료 위주
- 마나 운용 방식이 우와에(마법 계열)에 가깝지만 아엘루와 기준 술식 체계 없음 — 식물 공명 방식 독자
- 장수 종족 특성상 전통·기억 중시. 수백 년 된 숲의 역사를 구전으로 정확히 보존

#### 아르덴티아 엘프류와의 차이

| 항목 | 아르보리 | 아르덴티아 엘프류 |
|---|---|---|
| **정령술** | 없음 | 있음 (엘프 고유) |
| **자연 연결** | 식물과 직접 공생 | 자연 정령과 계약 |
| **발광** | 피부 발광 (녹색) | 없음 |
| **제조 문화** | 식물 재료 건축·가공 | 없음 (자연 그대로 선호) |
| **혼혈** | 인간과 혼혈 가능성 추정. 미확인 | 하프 엘프 확립 |

#### 마나 특성

| 항목 | 내용 |
|---|---|
| **계열 성향** | 우와에(마법 계열) 압도적 우세 |
| **자연 친화** | 아엘루와 기준 테라·아쿠아·벤투스 계열 친화성 강함 |
| **고유 마나 현상** | 군락 공명 — 아르보리 다수 집결 시 주변 식물 마나 밀도 급상승. 식물 급속 성장 |

#### 마나 운용 단계

> 아르보리는 아오웨니식 토와/우와에 단계 체계 사용 안 함. 독자 성장 단계 보유.
> 아르덴티아 기준으로는 우와에 계열에 준하나 명칭·구조 완전히 다름.

| 단계 | 명칭 | 비고 |
|---|---|---|
| 미각성 | 씨앗 (미파악 현지 명칭) | 식물 마나 감응 없음. 극소수 |
| 1단계 | 새싹 | 기초 식물 감응 |
| 2단계 | 가지 | 식물 성장 촉진 가능 |
| 3단계 | 수관 | 식물과 의사소통 가능. 광역 마나 감지 |
| 4단계 | 고목 | 군락 전체 마나 조율 가능 |
| 5단계 | 뿌리 | 극소수. 숲 전체와 공명. 군락 공명 의도적 발동 가능 |

#### 분포 및 대외 관계

- 아오웨니(미국 동부) 삼림 지대 중심. 타크와 삼림 지대 일부
- 아오웨니와 공존 — 삼림 보호 대가로 식물 재료·치유 약재 제공
- 마레티스 탐험대와 간접 접촉. 마나 감응으로 기초 의사소통 가능 — 언어 없이도 감정·의도 전달

## 3. 수인족

> 아엘루와 수인족은 아르덴티아·천원 수인족과 동일한 야성 해방(전 대륙 공통 현상) 보유.
> 아엘루와 고유 계통 3종. 아르덴티아·천원 수인족과 외형 유사한 종이 있으나 별개 계통으로 확정.
> 아엘루와 수인족은 토와(전투 계열) / 우와에(마법 계열) 체계를 사용하되
> 단계 명칭은 소속 세력 체계를 따른다.

---

### 🦅 플루마(Pluma) — 깃털 수인

> 아엘루와 고유 조류형 수인족. 아르덴티아 독수리·까마귀 수인과 외형 유사하나 별개 계통.

#### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 80~120년 |
| **성인 기준** | 15~18세 |
| **신체** | 인간형 기본. 선명한 깃털 머리카락. 등에 비행 가능한 날개. 발목 깃털 장식. 눈동자 선명한 원색. 키 160~180cm |
| **마나 각성률** | 높음. 아엘루와 수인족 중 최상위 추정 |
| **고유 능력** | 완전 비행 — 아르덴티아 독수리 수인보다 기동성 높음. 열대 기류 활용 장거리 활공 |

#### 특징

- 깃털 색상이 마나 상태 반영 — 각성·전투·감정 변화에 따라 깃털 색 변화·발광
- 아르덴티아 독수리 수인보다 화려한 색상 (열대·온대 조류 기반)
- 공중 거점 도시 건설 — 지상 세력과 분리된 고지대·수목 상층 거주
- 독립성 강함. 단일 세력에 통합되기보다 소규모 부족 단위 자치

#### 야성 해방

| 항목 | 내용 |
|---|---|
| **발동 유형** | 조건성 — 위기 시 비행 본능 폭발 |
| **효과** | 비행 속도·기동성 극대화. 공중 이탈 본능 폭발 — 위협에서 즉각 고공 이탈 |
| **부작용** | 지상 전투 능력 일시 저하. 이성적 판단보다 이탈 본능 우선 |
| **특이사항** | 아르덴티아 독수리 수인의 야성 해방(공격 폭발)과 반대로 방어·이탈형 |

#### 마나 특성

| 항목 | 내용 |
|---|---|
| **계열 성향** | 우와에(마법 계열) 강세. 마나 방출 계열 친화성 |
| **토와:우와에** | 약 35:65 |
| **고유 마나 현상** | 깃털 마나 발광 — 우와에 고단계일수록 깃털 발광 강도 증가. 마나 상태 외부 가시화 |

#### 분포

- 토네카(아즈텍 모티프) 삼림 고지대 중심
- 아오웨니·타크와 삼림 고지대 일부
- 마레티스 탐험대와 첫 공중 조우 — 초기 적대적 반응 후 차츰 호기심

### 🐴 에쿠스(Equus) — 말 수인

> 아엘루와 고유 말 기반 수인족. 아르덴티아·천원에 존재하지 않는 완전 신규 계통.

#### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 60~90년 |
| **성인 기준** | 14~16세 |
| **신체** | 인간형. 하반신 근육 극도 발달. 말 귀·갈기(머리카락 형태). 발굽형 발. 긴 꼬리. 키 175~200cm |
| **마나 각성률** | 인간과 유사. 신체 강화 계열 친화성 강함 |
| **고유 능력** | 주력(走力) — 지상 질주 속도 아엘루와 모든 종족 중 최상위. 지구력 탁월 |

#### 특징

- 아르덴티아·천원에 말 기반 수인족 없음 — Orbis 전 대륙 기준 완전 신규 계통
- 갈기 색상이 마나 상태 반영 — 각성·전투 시 갈기 발광
- 유목·이동 문화. 아보카(텍사스·멕시코 북부) 대평원 지배 세력의 핵심 구성
- 개인보다 무리 단위 행동 선호. 집단 전투력이 개인 전투력 합산 이상

#### 야성 해방

| 항목 | 내용 |
|---|---|
| **발동 유형** | 조건성·계절성 — 위기·번식기에 강화 |
| **효과** | 군마 본능 — 무리 집결·돌격 본능 폭발. 집단 전투력 극대화 |
| **부작용** | 단독 이성 판단 불가. 무리에서 이탈한 개체 극도의 불안 상태 |
| **특이사항** | 집단 야성 해방 동조 현상 — 무리 내 한 개체 발동 시 주변 개체 연쇄 발동 가능성 |

#### 마나 특성

| 항목 | 내용 |
|---|---|

#### 분포

- 마레티스 탐험대와 평원에서 첫 조우 — 초기 적대 후 교역 가능성 탐색 중

### 🐊 스쿠아마(Squama) — 비늘 수인

> 아엘루와 고유 파충류형 수인족. 아르덴티아 뱀 수인과 외형 유사하나 악어·도마뱀 기반 별개 계통.

#### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 100~200년. 아엘루와 수인족 중 최장수 |
| **성인 기준** | 20~30세 |
| **신체** | 인간형. 전신 비늘 덮임. 황록색~갈색. 긴 꼬리. 강인한 체형. 키 170~195cm |
| **마나 각성률** | 보통. 아엘루와 수인족 중 중간 수준 |
| **고유 능력** | 갑각 방어 — 비늘이 물리 방어 높음. 수중·육상 양서 능력. 강력한 악력 |

#### 특징

- 아르덴티아 뱀 수인의 유연성보다 강인한 체력·방어 중심
- 탈피 없음 — 대신 비늘이 서서히 갱신되며 강화. 고령일수록 비늘 경도 증가
- 장수 종족 특성상 느리고 신중한 의사결정 문화
- 수로 네트워크 장악 — 하천·늪지·해안 저지대 수로 이동 숙달

#### 야성 해방

| 항목 | 내용 |
|---|---|
| **발동 유형** | 희박성 — 드물게 발동하지만 발동 시 강도 강함 |
| **효과** | 악어 본능 — 악력·방어력·수중 기동력 폭발적 증가. 일격 필살 집착 |
| **부작용** | 이성 완전 차단. 아군 피해 가능성 높음. 지속 시간 짧음 |
| **특이사항** | 아르덴티아 뱀 수인 야성 해방(독 운용·유연성 극대화)과 방향성 다름 — 방어·힘 중심 |

#### 마나 특성

| 항목 | 내용 |
|---|---|
| **계열 성향** | 토와(전투 계열) 우세. 대지 계열 친화성 |
| **토와:우와에** | 약 65:35 |
| **고유 마나 현상** | 비늘 마나 경화 — 토와 고단계 시 비늘에 마나 축적. 물리 방어력 추가 증폭 |

#### 분포

- 카엘라노스 연해 하천·늪지 지대 중심
- 멜리와(마야 모티프) 하천 저지대 일부
- 마레티스 탐험대와 하천 교역로에서 접촉. 수로 안내자 역할 가능성 타진 중

## 5. 아르덴티아 기준 비교

> 마레티스 탐험대가 아엘루와 종족을 아르덴티아 기준으로 분류할 때의 혼란 요인 정리.

| 아엘루와 종족 | 마레티스 초기 오인 | 실제 분류 |
|---|---|---|
| 테라이 | 아르덴티아 인간과 동일 종족 | 동종. 독자 문화 발전 |
| 마리니 | 수인족(수달·상어 수인 계열) | 수인족×인간 혼혈 정착 종족 |
| 아르보리 | 엘프류 | 별개 계통. 정령술 없음 |
| 플루마 | 독수리·까마귀 수인 | 별개 계통. 더 화려하고 기동성 높음 |
| 에쿠스 | 미분류 — 아르덴티아 기준 없음 | 완전 신규 계통 |
| 스쿠아마 | 뱀 수인 | 별개 계통. 뱀보다 악어·도마뱀 기반 |
