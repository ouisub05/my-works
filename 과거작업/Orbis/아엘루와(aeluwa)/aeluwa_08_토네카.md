## 지리적 특성

> 아엘루와 남부 고원 지대. 고도와 태양 마나가 토네카 문명의 두 축.

**지형:**
- 중앙 고원: 광활한 고원 평지. 수도·신전 도시 집중. 마나 농도 아엘루와 최고 수준
- 북부: 아보카(아보카) 접경. 고원~초원 전이 지대. 팽창 충돌 핵심 지점
- 남부: 마야 세력(멜리와) 접경. 고원~정글 전이 지대. 패권 경쟁
- 동부: 카엘라노스 연해 방향 해안 사면. 간접 교역 접점
- 서부: 태평양 사면. 해안 접근 가능

**기후:**
- 고원: 건기·우기 뚜렷. 일교차 크고 태양 강렬
- 남부 사면: 열대 접경. 마야 세력과 기후 전이 지대

**마나 환경:**
- 마나 농도: 아엘루와 최고 수준. 고원 지형·강렬한 태양 에너지와 마나 공명
- 태양 마나 친화 — 일출·일몰·정오 시 마나 밀도 급등. 토네카 의례 시간과 일치
- 고원 마나 축적 현상 — 지형 특성상 마나가 고원에 집중·결집. 술식 위력 증폭

## 종교·신앙 체계

> 태양을 마나의 근원으로 숭배. 마나와 태양 에너지의 연결이 토네카 세계관 핵심.

| 항목 | 내용 |
|---|---|
| **핵심 신앙** | 태양신 숭배 — 태양이 마나를 대지에 내리고 신관이 이를 수집·운용한다는 교리 |
| **마나 해석** | 태양에서 흘러내리는 에너지의 지상 잔류물. 각성은 태양의 선택 |
| **의례** | 일출·정오·일몰 3회 마나 의례 필수. 주요 결정은 반드시 의례 후 진행 |
| **신관 계파** | 태양파(주류)·달파·별파 — 태양파가 대신관직 독점. 달파·별파는 보조 역할 |
| **토네카력** | 태양 주기 기반 독자 역법. 일식을 최고 성스러운 날로 기념 |

## 정치 구조

> 대신관이 최고 권력. 군사 귀족은 대신관 아래 복속.

**핵심 구조:**

| 직위 | 구성 | 역할 |
|---|---|---|
| **대신관 (Toneka-Kai)** | 태양파 최고위 우와에 술사. 선출제 (태양파 내부) | 국정 전반 통솔. 의례·외교·전쟁 최종 결정 |
| **신관 평의회 (Kaiwei)** | 태양·달·별파 고위 신관 집단 | 대신관 자문. 의례 집행. 파벌 간 균형 |
| **전사 귀족 (Tonwei)** | 세습 군사 귀족 가문 | 군사 지휘. 대신관 명령 이행. 영토 관리 |

**정치 특성:**
- 대신관 선출 시 태양파 내부 경쟁 — 우와에 단계와 의례 능력이 선출 기준
- 전사 귀족의 군사력이 신관 권력 견제 수단 — 양측 균형이 내정 핵심 변수
- 달파·별파의 대신관직 도전 시도가 반복적 내부 갈등 원인

## 군사

> 아엘루와 남부 최강 전력. 고원 지형·태양 마나 활용이 핵심.

**전력 특성:**
- 토와·우와에 균형 편제. 우와에 신관 부대와 토와 전사 귀족 혼성 운용
- 태양 마나 집중 시간대(정오) 전투 선호 — 마나 증폭 극대화
- 고원 지형 방어 숙련. 고도 차이를 이용한 압박 전술
- 북부 아보카 접경: 고원~초원 전이 지대 지배권 분쟁. 아보카 기마대 대응 전술 개발 중

**아보카와의 남북 충돌:**
- 고원 남부 진출을 노리는 아보카와 반복 충돌
- 아보카 기마 기동력 vs 토네카 고원 방어·마나 전력 — 전술 상호 억제 구도
- 완전한 승패 없이 접경 지대 소모전 지속

**단계 체계 — 우와에(Uwae):**

| 단계 | 명칭 | 비고 |
|---|---|---|
| 비각성 | 토카 (Toka) | 마나 미각성 |
| 1단계 | 네카 (Neka) | 입문. 신관 수련생 자격 |
| 2단계 | 토네 (Tone) | 초급. 의례 보조 자격 |
| 3단계 | 카이 (Kai) | 중급. 신관 평의회 칭호 어근 |
| 4단계 | 토카이 (Tokai) | 상급. 파벌 고위 신관 자격 |
| 5단계 | 토네카이 (Tonekai) | 최고위. 대신관 자격. 극소수 |

**단계 체계 — 토와(Towa):**

| 단계 | 명칭 | 비고 |
|---|---|---|
| 비각성 | 토카 (Toka) | 마나 미각성 |
| 1단계 | 웨이 (Wei) | 입문. 전사 귀족 수련 자격 |
| 2단계 | 톤웨이 (Tonwei) | 초급. 전사 귀족 칭호와 동일 어근 |
| 3단계 | 카웨이 (Kawei) | 중급 |
| 4단계 | 토카웨이 (Tokawei) | 상급 |
| 5단계 | 토네웨이 (Tonewei) | 최고위. 극소수 |

## 경제

> 고원 농업·교역 독점·마나 기술 수출이 경제 기반.

**주요 산물:**
- 고원 농산물 — 옥수수 계열 작물. 아엘루와 남부 최대 생산
- 마나 결정석 — 고원 마나 축적 현상으로 순도 높은 결정석 산출. 아엘루와 최고 품질
- 태양 의례 가공품 — 신앙 물품. 주변 세력 수요 높음
- 고원 희귀 약재 — 아르덴티아 미지의 품종 다수

**교역 네트워크:**
- 고원~해안 교역로 장악. 남부 교역 독점적 지위
- 마야 세력과 교역·패권 경쟁 병존
- 아보카에 마나 결정석 간접 유통 — 충돌 중에도 교역 채널 유지
- 카엘라노스 연해 방향 간접 교역 — 마레티스 물자가 카엘라노스→토네카 경로로 일부 유입 가능성

**화폐:**
- 마나 결정석 소량이 고가 교환재
- 태양 의례 가공품이 종교적 가치 척도 겸용

## 마나·각성 체계

| 항목 | 내용 |
|---|---|
| **토와(Towa) 비율** | 약 50% |
| **우와에(Uwae) 비율** | 약 50% |
| **전체 각성률** | 약 22% — 아엘루와 최상위. 고원 마나 집중 환경 영향 |
| **우와에 특화** | 태양 마나 감응·마나 결정화·의례 증폭 친화성 |
| **토와 특화** | 고원 지형 적응·지구력·마나 집중 신체 강화 |
| **고유 마나 현상** | 태양 마나 공명 — 정오 시 고원 전역 마나 밀도 급등. 우와에 술식 위력 평시 대비 1.5배 추정 |

## 아르덴티아(마레티스)와의 관계

> AN 845 기준 마레티스 미파악. 직접 접촉 없음.

- 카엘라노스 연해 교역 경로 너머 내륙 깊숙이 위치
- 고원 마나 결정석은 마레티스가 발견할 경우 최고 전략 자원으로 분류될 가능성
- 아르덴티아 기준 마고리아·상크티움이 가장 관심을 가질 마나 환경
- 태양 신앙 기반 마나 체계는 아르덴티아 어느 학파와도 유사점 없는 완전 독자 체계
