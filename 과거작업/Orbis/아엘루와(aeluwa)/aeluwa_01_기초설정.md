# 🌎 아엘루와(Aeluwa) 대륙 기초 설정

---

## 개요

| 항목 | 내용 |
|---|---|
| **대륙명** | 아엘루와 (Aeluwa) |
| **아르덴티아 측 명칭** | Terra Incognita (미지의 땅) — 마레티스 극비 문서 한정 |
| **위치** | 아르덴티아에서 대서양 서쪽 약 3~4주 항해 거리 (마레티스 탐험선 기준) |
| **규모** | 아르덴티아와 유사하거나 그 이상 추정. 내륙 대부분 미탐사 (AN 845 기준) |
| **세계 분류** | Orbis — 아르덴티아·천원과 동일한 세계 |

## 지리 개요

> 아르덴티아 기준 대서양 서쪽 대륙.
> 마레티스 탐험대는 AN 845 기준 동남부 해안 일부만 파악.
> 내륙·북부·서부 전역은 미탐사 상태.

**대륙 구분:**

| 지역 | 지형 모티프 | 특성 |
|---|---|---|
| 동남부 해안·도서 | 플로리다·쿠바·도미니카 일대 | 열대. 산호초·수로 발달. 마레티스 최초 접촉 지점 |
| 동부 삼림 | 미국 동부 | 온대 활엽수림. 최초 문명 발상지. 광역 통용어 발원지 |
| 중부 대평원 | 텍사스·멕시코 북부·미국 중부 | 광활한 초원·반건조 지대. 유목·기마 문화권 |
| 북부 삼림·호수 | 캐나다 내륙 | 침엽수림·대호수 지대. 혹한 환경 |
| 서부 산악·해안 | 미국 서부·캐나다 서부 | 고산·태평양 해안. 지형 다양 |
| 극북 | 알래스카·캐나다 극서북 | 설원·툰드라. 극야 환경 |
| 남부 고원 | 멕시코 중앙 고원 | 고원 문명권. 마나 농도 대륙 최고 수준 |
| 남부 정글 | 중앙아메리카·유카탄 | 열대 밀림. 고대 도시 문명 |

## 역법 — 아엘루와력(曆)

> 아엘루와 대륙 내 가장 오래된 문명인 동부 세력이 제정한 태양력.
> 광역 통용어와 함께 대륙 전반에 보급. 세력마다 자체 역법 병용.

| 항목 | 내용 |
|---|---|
| **명칭** | 아엘루와력 (아오웨니 작업 시 고유 명칭 확정) |
| **기준** | 태양력. 동부 세력 최초 문명 기원년을 원년으로 |
| **단위** | 연(年)·절기(節期) 기반. 태양 주기와 계절 분할 |
| **AN 845 환산** | 미파악 — 마레티스 탐험대 역법 해독 미완 |
| **원년 사건** | 아오웨니 작업 시 확정 |

## 언어 체계

> 아르덴티아의 코무니스, 천원의 공통어에 해당하는 광역 통용어 존재.

| 항목 | 내용 |
|---|---|
| **광역 통용어** | 동부 세력(아오웨니) 언어 — 교역·외교 공통어로 대륙 전반 보급 |
| **통용어 명칭** | 아오웨니 작업 시 확정 |
| **보급 경위** | 동부 세력 문명의 역사적 영향력. 교역로를 통해 자연 전파 |
| **사용 범위** | 교역·외교 장면 한정. 일상어는 세력별 고유어 유지 |
| **마레티스 현황** | 통용어 존재 미파악. 현지어 단어 수십 개 수준의 해안 세력어 습득에 그침 |

## 마나 환경

> 아르덴티아·천원 대비 마나 농도가 전반적으로 높은 대륙.

| 항목 | 내용 |
|---|---|
| **전체 마나 농도** | 아르덴티아·천원 평균보다 높음 |
| **고농도 지역** | 남부 고원(토네카)·동부 삼림·극북 설원 |
| **저농도 지역** | 중부 대평원 일부. 단 절대 수치는 아르덴티아 평균 이상 |
| **마나 특성** | 아르덴티아·천원과 본질 동일. 운용 방식·술식 체계는 세력마다 독자 발전 |
| **전투·마법 계열 구분** | 아르덴티아·천원과 동일 원칙 적용. 명칭·체계는 세력별 상이 |
| **각성률** | 세력마다 편차 큼. 대륙 통일 수치 없음 |

**마나 운용 방식 특성:**
- 아르덴티아식 술식 체계(Via Formae)나 천원식 도파(道派) 없음
- 세력별 독자 체계 발전 — 자연 환경·문화와 긴밀하게 결합
- 아르덴티아 기준 "감각적·직관적 운용" 비중 높음
- 문서화된 술식 체계는 남부 고원 문명(토네카)에서만 확인

## 마나 각성 체계 공통 원칙

> 아르덴티아의 Via Martis / Via Formae, 천원의 무도(武道) / 술도(術道)에 해당하는 Aeluwa 고유 계열 체계.

| 항목 | 내용 |
|---|---|
| **전투 계열** | 토와 (Towa) |
| **마법 계열** | 우와에 (Uwae) |
| **전투·마법 계열 상호 배타** | 아르덴티아·천원과 동일 원칙 적용 |
| **마나 무속성** | 속성은 운용 계열로 구조화할 때만 발생 |
| **각성 개념** | 존재. 각성 전 비각성자 구분 있음 |
| **단계 명칭** | 세력별 파일에서 각각 확정 |

## 아르덴티아와의 관계

> AN 845 기준. 마레티스 극비.

- 마레티스만 대륙 존재 파악. 아르덴티아 내 다른 국가 전혀 미인지
- 접촉 세력: 카엘라노스 연해(카엘라노스) 한정. 내륙 세력 직접 접촉 없음
- 내륙 세력 존재는 간접 정황으로만 인지
- 아우룸 라텐스(베네눔 코르디스) 정보 탐지 시도 중 — 마레티스 최대 경계 대상
