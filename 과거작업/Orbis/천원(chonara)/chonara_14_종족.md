# 👥 천원(天原) 종족 설정

---

## 개요

천원에 분포하는 종족은 크게 **인간**, **수인족(獸人族)**, **용족(龍族)** 세 가지로 나뉜다.
인간이 13개 국가 전체의 주류 종족이며, 수인족은 천원 전역에 분산된 소수 부족 형태로 존재한다.
용족은 특정 영역에 실질 거주하는 희소 종족으로, 인간 사회와 제한적으로 교류한다.

전 대륙 공통 설정(orbis_02)과의 연관:
- 천원 수인족은 orbis_02b의 수인족 공통 특성(야화·마나 감지·혼혈 원칙)을 따른다
- 천원 용족은 orbis_02의 드래곤류 항목과 연결되나 천원 고유 발전 형태를 가진다

## 1. 인간(人間 / Human)

### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 60~80년. 기(氣) 수련자는 100년 이상 사례 존재 |
| **성인 기준** | 16~18세 (국가·문화별 상이) |
| **신체** | 평균 키 155~185cm. 체형 다양성 최대 |
| **기 각성률** | 국가별 편차. 천원 전체 평균 약 10~15% |
| **고유 능력** | 없음. 단 무도·술도 어느 계열로도 발전 가능한 유연성 보유 |

### 천원 인간의 특이사항

- **수련 각성 비율 높음**: 아르덴티아 대비 자연 각성보다 수련을 통한 각성 비율이 높다. 도파·무도 유파 문화가 각성을 체계화
- **선인(仙人) 경지**: 술도 최고 단계(천선)에 도달한 극소수 인간은 수명이 수백 년에 달한다는 전승 존재. 사실 여부 불명확하나 역사적 기록 다수
- **혼혈**: 수인족·용족과의 혼혈 사례 존재. 세대가 내려갈수록 인간 특성 강화

### 국가별 각성률 참고

| 국가 | 각성률 | 주요 특이사항 |
|---|---|---|
| 운릉 | 약 22% | 고지대 고밀도 기맥. 천원 최고 |
| 고하란 | 약 18% | 동북 평원 기맥 풍부 |
| 시라 | 약 16% | 무도 유파 문화 영향 |
| 인드라 | 약 15% | 고산 기맥 집중지 |
| 장화·야시로 | 약 14% | 안정적 기맥 환경 |
| 황린·남비엣 | 약 12~13% | 넓고 균일 또는 열대 변동성 |
| 체르헨·말리가이 | 약 10~11% | 초원·해양 분산 기맥 |
| 레푼카이 | 약 9% | 해양 기맥 특수 환경 |
| 야쿠란 | 약 8% | 동토 봉인 기맥. 천원 최하 |

## 2. 수인족(獸人族 / Beastkin)

### 개요

동물의 특성을 공유하는 인간형 종족의 총칭.
천원 전역에 분산 분포하며, 특정 국가에 집중되지 않고 각 지역 환경에 맞는 종이 자연스럽게 거주한다.
외형은 **동물+인간의 혼합 형태** — 요괴나 정령이 아닌 생물학적 종족이다.
천원 인간 사회에서는 종종 요괴(妖怪)와 혼동되거나 신화적으로 해석되는 경우가 있으나, 수인족 스스로는 이를 구별한다.

### 공통 특성

| 특성 | 내용 |
|---|---|
| **외형** | 인간형 신체 + 해당 동물의 귀·꼬리·비늘·깃털·발톱 등 |
| **감각** | 해당 동물의 감각 강화 계승 (후각·청각·시각 등 종별 상이) |
| **신체 능력** | 해당 동물의 신체 특성 일부 계승 |
| **수명** | 종별 상이. 대체로 인간보다 10~30년 길거나 유사 |
| **기 각성률** | 인간과 비슷하거나 약간 높음 |
| **야화(野化)** | 전 대륙 공통 야성 해방 현상. 천원에서는 야화(野化)라 부름 |

### 야화(野化) — 천원 명칭

- 극한 상황에서 동물 본능이 기(氣)와 결합해 폭발하는 현상
- 효과: 신체 능력·기 운용 효율 급상승. 해당 동물 본능 극대화
- 부작용: 이성 약화. 제어 어려움. 아군 피해 가능성
- 고위 각성자는 야화를 의도적으로 발동·제어하는 훈련 가능
- 천원 인간들은 야화를 수인족의 위험성 증거로 보는 경향 — 차별의 근거 중 하나

### 천원 수인족 종류

천원의 수인족은 해당 대륙 생태계를 반영해 다음과 같은 종이 분포한다.

#### 묘과(猫科) 계열

| 종 | 분포 지역 | 특성 |
|---|---|---|
| **호랑이 수인** | 고하란·시라·야시로 산악 지대 | 천원 수인족 중 최강 전투력. 무도 계열 친화. 야화 시 압도적 근력·속도 |
| **표범 수인** | 운릉·장화 산악·밀림 | 은신·기습 특화. 고지대 적응 뛰어남 |

#### 견과(犬科) 계열

| 종 | 분포 지역 | 특성 |
|---|---|---|
| **여우 수인(구미호 계열)** | 황린·장화·시라 전역 | 천원에서 가장 신화화된 수인족. 술도 계열 친화 강함. 꼬리 수가 기 각성 수준의 지표로 여겨짐 (민간 전승). 인간과 가장 유사한 외형으로 혼혈 많음 |
| **늑대 수인** | 체르헨·야쿠란 초원·설원 | 무리 본능. 체르헨 유목 문화와 깊이 결합. 일부는 체르헨 부족 전사로 활동 |
| **너구리 수인** | 황린·장화 남부 | 환술파 친화 강함. 변신 능력이 있다는 민간 전설로 인해 환술사로 오해받는 경우 多 |

#### 조류(鳥類) 계열

| 종 | 분포 지역 | 특성 |
|---|---|---|
| **두루미·학 수인** | 황린·시라·야시로 | 천원에서 가장 고귀하게 여겨지는 수인족. 술도 천문파 친화. 일부 황린 귀족이 학 수인을 빈객으로 대우 |
| **봉황 계열** | 극히 희귀. 특정 지역 불명 | 실존 여부 불확실. 목격담은 존재. 천원 신화 속 상서로운 존재로 등장 |

#### 파충류(爬蟲類) 계열

| 종 | 분포 지역 | 특성 |
|---|---|---|
| **뱀 수인** | 남비엣·말리가이·인드라 남방 | 열대 환경 적응. 환술파·부적파 친화. 천원 북방에서는 요괴로 오해받는 경우 많음 |

#### 기타

| 종 | 분포 지역 | 특성 |
|---|---|---|
| **사슴·토끼 수인** | 시라·야시로·황린 내륙 | 소규모 분산 부족. 전투보다 술도·의술파 친화 |
| **수달·해달 수인** | 레푼카이·장화 해안 | 해양 환경 적응. 레푼카이와 교류 있음 |

### 국가별 수인족 처우

| 국가 | 처우 | 내용 |
|---|---|---|
| 황린 | **혼재** | 여우·학 수인은 일부 귀족의 빈객 대우. 뱀·늑대 계열은 요괴 취급. 법적 지위 불명확 |
| 고하란 | **실력주의** | 무도 실력 있으면 군 편입 가능. 호랑이 수인 일부가 철기군 내 비공식 전력 |
| 시라 | **무도 유파 통해 인정** | 무도 유파에 속한 수인족은 유파원으로 인정. 독립 부족은 차별 존재 |
| 체르헨 | **일부 통합** | 늑대 수인 일부가 체르헨 부족 구성원으로 통합. 부족장 아래 동등 대우 |
| 야쿠란 | **공존** | 일부 수인족 부족이 야쿠란 연합에 느슨하게 포함 |
| 운릉 | **연구 대상 또는 동등** | 술도 능력 있으면 원로회 관심 대상. 차별보다 활용 |
| 남비엣·말리가이 | **비교적 개방** | 열대 수인족 비율 상대적으로 높음. 인간과의 경계 타 지역보다 유동적 |
| 장화·인드라 | **상인·특기자로 대우** | 특기 보유 수인족은 상인·술사로 활동 가능. 공식 법적 지위는 미흡 |

### 혼혈 원칙

- 수인족+인간 혼혈은 천원에서 **반인반수(半人半獸)** 또는 속칭으로 불림
- 외형: 수인족 특징 약화. 귀·꼬리 잔존하나 크기·선명도 감소
- 야화: 발동 빈도 낮아짐. 제어 용이
- 세대가 내려갈수록 인간 외형에 가까워짐. 3세대 이후 거의 구별 불가
- 여우 수인 혼혈이 가장 많음 — 외형이 인간에 가장 유사해 혼혈 발생 빈도 높음

## 3. 용족(龍族 / Dragon-kin)

### 개요

용(龍)과 인간의 혼혈에서 비롯된 종족.
천원에서 용은 신성한 존재로 여겨지며, 황린 황실은 용을 통치 정당성의 상징으로 사용한다.
현시점에서 순수 용형(비인간형) 존재는 극희귀하거나 전설적 존재.
실질적으로 확인되는 용족은 **인간형 혼혈** 형태이며, 5대(代) 정도가 종적 기준점으로 여겨진다.

### 기본 특성

| 항목 | 내용 |
|---|---|
| **종적 기준** | 용과의 혼혈 5대 이내. 6대 이상은 기 특성만 남고 외형상 인간과 구별 어려움 |
| **외형** | 혼혈 대수에 따라 다름. 1~2대: 비늘 일부·동공 특이형·피부색 변이. 3~4대: 외형은 인간에 가깝되 기 용량 높음. 5대: 거의 인간 외형 |
| **수명** | 혼혈 대수에 따라 다름. 가까울수록 장수. 2대: 300~500년. 5대: 100~150년 |
| **기 특성** | 기 총량이 동 단계 인간보다 압도적으로 높음. 기 회복 속도 빠름 |
| **고유 능력** | 혈통 농도에 따라 용기(龍氣) 운용 가능. 3대 이후로는 잠재 능력으로 남음 |

### 용기(龍氣)

- 용족 고유의 기 운용 방식. 일반 기(氣)보다 밀도 높고 강력
- 무도·술도 계열 구분 없이 운용 가능한 특수 능력 — 계열 상호 배타 원칙의 예외적 존재
- 1~2대 용족만 완전 발현 가능. 3대 이후는 부분적으로만 발현
- 용기 발현 시 외형 변화 동반 (비늘 현현·동공 변화·기압 방출 등)

### 거주 지역

- 용족은 인간 국가 내에 흡수되어 사는 경우보다 **독자 영역을 유지**하는 경우가 많음
- **주요 거주 영역**:

| 지역 | 특성 |
|---|---|
| 황린 동부 산악 일부 | 황린 황실과 오랜 협약 관계. 황실 용 상징의 실질적 근거. 접근 제한 구역 |
| 운릉 고원 특정 봉우리 | 운릉 원로회와 비공식 관계. 금술 연구원과 간헐적 접촉 |
| 남비엣 밀림 내륙 | 뱀 수인족과 혼동되는 경우 있음. 인간 접촉 최소화 |
| 인드라 히말라야 고지 | 고산 새 수인과 영역 인접. 간헐적 접촉 |

### 천원 내 용족 인식

| 국가 | 인식 |
|---|---|
| 황린 | 황실 권위의 상징. 실질 접촉은 엄격히 통제. 용족을 황실 조상으로 신화화하는 전승 존재 |
| 고하란 | 경외의 대상. 군사 동맹 시도 역사 있으나 용족 측에서 거부 |
| 운릉 | 연구 대상. 원로회 일부가 용기(龍氣)와 기맥의 관계 연구 중 |
| 시라·야시로 | 전설 속 존재로 인식. 실존 여부에 대한 논쟁 있음 |
| 남비엣·말리가이 | 밀림·해양의 수호 정령으로 신앙화하는 경향 |

### 혼혈 원칙

- 용족+인간 혼혈은 자연 발생보다 역사적 협약·의례 결합에서 비롯된 경우 多
- 현시점 1~2대 용족은 극희귀. 대부분 3~5대
- 5대 이후부터는 기 용량이 높은 인간으로 분류되는 경우가 일반적
- 용족 혈통 보유자는 무도·술도 각성 시 동 단계 인간보다 기 총량 우위
