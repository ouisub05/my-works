# 🗺️ 아르덴티아 국가 간 외교 관계

---

## 외교 관계 분류 기준

| 분류 | 설명 |
|---|---|
| 동맹 | 공식 방위 조약·군사 협력 |
| 우호 | 활발한 교역·정치 협력. 공식 동맹은 아님 |
| 중립·교역 | 정치 개입 없이 교역만 유지 |
| 긴장 | 국경 분쟁·이념 갈등·경쟁 관계 |
| 냉전 | 직접 전쟁은 없으나 군비 강화·영향권 다툼 |
| 적대 | 공식 적대. 충돌 위험 높음 |

## 냉전 구도 핵심 축

```
카이저라트 ←──── 냉전 ────→ 케메트라
    │                              │
  동맹                          우호·긴장
    │                              │
 아우렌탈                       자하라트
```

**냉전 대리 경쟁 지역:**
- 중부 유럽 소국들 — 양측이 영향권 확보 경쟁
- 지중해 교역로 — 케메트라(남안) vs 카이저라트·아우렌탈(북안)
- 마고리아 마법사 파견 — 카이저라트 우세, 케메트라 불만

**완전 중립 세력:**
- 마고리아 — 표방 중립. 실용 협력
- 펠라기온 — 완전 중립 무역
- 페락시스 — 실용적 중립. 양측 모두 고용
- 우르단 — 교역만. 정치 불개입
