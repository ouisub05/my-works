# 🏙️ 아르덴티아 주요 도시·거점 설정 02 — 일반 국가

---

## 🌿 디르우드(Dyrwood)

### 심부 도시 코르 실바룸(Cor Silvarum)
> 디르우드 왕궁이 위치한 숲의 중심. 외부인 접근 완전 금지.

| 항목 | 내용 |
|---|---|
| **위치** | 발트·폴란드 침엽수림 심부 |
| **규모** | 순혈 엘프 약 3만 거주 추정 |
| **특색** | 나무 위·지면 혼합 건축. 수목 정령과 공존 |
| **분위기** | 고요하고 신성함. 외부인은 존재 자체를 모름 |

**국경 검문소:**
- 국경 수호선 — 숲 외곽 전체. 공식 검문소 없음. 수호대가 직접 차단
- 외곽 교역소(Margo Mercatus) — 유일한 외부 접촉 지점. 물자 교환만 허용

---

## 🌿 베르단티스(Verdantis)

### 녹엽 도시 키비타스 비리디스(Civitas Viridis)
> 베르단티스 수도. 엘프와 타 종족이 공존하는 개방적 도시.

| 항목 | 내용 |
|---|---|
| **위치** | 이베리아 북서부 숲 중심 |
| **규모** | 인구 약 6만 (엘프류 40%, 타 종족 60%) |
| **특색** | 나무 위·지면 혼합 건축. 활엽수 특유의 밝고 따뜻한 분위기 |
| **분위기** | 개방적이고 예술적. 공예·음악 문화 발달 |

**주요 시설:** 왕궁·녹엽 의회 의사당·정령 계약 의식 광장·베르단티스 공예 시장
**국경 검문소:** 마레티스 방면 남부 관문·북부 숲 경계(디르우드 접경)

## ⚔️ 아우렌탈(Aurenthal)

### 왕도 아우렌탈리스(Aurentalis)
> 아우렌탈 수도. 기사 문화의 중심지.

| 항목 | 내용 |
|---|---|
| **위치** | 프랑스 평원 중심부 |
| **규모** | 인구 약 12만 |
| **특색** | 기사단 훈련장·결투 문화·루멘 신앙 중심 |
| **분위기** | 명예롭고 격식 있음. 기사 서임식이 빈번한 활기찬 분위기 |

**주요 시설:** 왕성·검의 기사단 본부·대성당·결투 광장·기사 서임 의식 광장
**국경 검문소:**
- 동부 라인 관문 — 카이저라트 방면. 동맹 통로. 간소한 검사
- 북부 해협 요새 — 브레타바르 방면. 군사 요새. 해적 감시 24시간 운영
- 남부 알프스 관문 — 상크티움 방면. 순례자 통과 주요 루트

## ⚓ 펠라기온(Pelagion)

### 연합 수도 아드리아누스(Adrianus)
> 펠라기온 7개 도시국가 연합 의회 소재지.

| 항목 | 내용 |
|---|---|
| **위치** | 아드리아해 북부 해안 |
| **규모** | 인구 약 10만 |
| **특색** | 해상 무역 허브. 7개 도시 중 가장 번화. 다종족 상인 집결 |
| **분위기** | 분주하고 상업적. 항구 특유의 소음과 활기 |

**주요 시설:** 연합 의회 의사당·대형 항구·조선소·메르카토 금융 지부·마나 포격함 기지
**7개 도시 간략:**
- 펠라고스 — 조선·항해 기술 중심
- 리마니아 — 동방 교역 창구
- 이솔라 — 해군 기지 섬 요새
- 메르카토 — 금융·상업 중심
- 코린티아 — 동서 육상 교역로 통제
- 크레타리아 — 지중해 남부 거점

**국경 검문소:** 아드리아해 전 항구 (해상 검문 위주)·코린트 지협 육상 관문

## 🌊 마레티스(Marethis)

### 왕도 마레티아(Maretia)
> 지브롤터 해협 북안 항구 도시. 대서양·지중해 교역 허브.

| 항목 | 내용 |
|---|---|
| **위치** | 지브롤터 해협 북안 |
| **규모** | 인구 약 9만 |
| **특색** | 대서양·지중해 교차점. 탐험가·상인·수인족 혼재 |
| **분위기** | 모험적이고 국제적. 신대륙 탐험대 출항 기지 |

**주요 시설:** 왕성·지브롤터 해협 수비 요새·대형 조선소·탐험대 출항 부두(극비)·아타르발 교역 창구
**국경 검문소:**
- 지브롤터 해협 — 지중해↔대서양 모든 선박 통행세 징수
- 이베리아 북부 육로 — 베르단티스·아우렌탈 방면. 수인족 이민 통로

## ❄️ 칼드헤임(Kaldrheim)

### 대족장 거점 이스비에른(Isbiern)
> 칼드헤임 대족장 거점. 설원 부족 연합 중심지.

| 항목 | 내용 |
|---|---|
| **위치** | 스칸디나비아 중부 |
| **규모** | 인구 약 3만. 부족 연합 최대 집거지 |
| **특색** | 마물 가공품·모피 거래 중심. 마물 토벌 원정 출발 거점 |
| **분위기** | 거칠고 강인함. 연회와 전투 이야기가 넘침 |

**주요 시설:** 대족장 대전(大殿)·부족장 의회 천막·마물 가공 작업장·발트해 항구
**국경 검문소:**
- 남부 발트 항구 — 교역 방문자 출입 허용. 무기 신고 불필요
- 내륙 설원 경계 — 검문소 없음. 부족 전사가 직접 감시

## ⛏️ 우르단(Urdhavn)

### 지하 왕도 페트라(Petra)
> 우랄 산맥 심부 지하 도시. 외부인 입장 불가.

| 항목 | 내용 |
|---|---|
| **위치** | 우랄 산맥 깊숙한 지하 |
| **규모** | 드워프 약 10만 거주 추정 |
| **특색** | 발광석으로 채워진 지하 도시. 룬 장인 문화 집결 |
| **분위기** | 웅장하고 정밀함. 끊임없는 제조 소리 |

**지상 교역 관문(Porta Commercii):**
- 우르단 유일 외부 접촉 지점
- 교역 물자 수령·납품 전담
- 외부인은 관문 건물 내부까지만 접근 가능
- 드워프 교역 담당자 상시 배치

## 🏴 브레타바르(Brethavar)

### 왕도 브레타(Bretta)
> 영국 남부 해안 항구 도시. 약탈왕 거점.

| 항목 | 내용 |
|---|---|
| **위치** | 영국 남부 해안 |
| **규모** | 인구 약 4만 |
| **특색** | 해적 문화 중심. 약탈 전리품 유통. 비공식 거래 활발 |
| **분위기** | 무법적이고 활기참. 언제든 결투 가능한 긴장감 |

**주요 시설:** 약탈왕 성채·용선(Drakkar) 조선소·전리품 경매장·마레티스 비공식 거래 창구
**국경 검문소:** 없음 (해안 부족 자체 감시)

## 🦁 아타르발(Atharval)

### 연합 도시 아타르(Athar)
> 아타르발 의회 소재지. 유일한 대규모 혼합 종족 도시.

| 항목 | 내용 |
|---|---|
| **위치** | 아틀라스 산맥 이남 사바나 지대 |
| **규모** | 인구 약 5만 (10개 수인족 혼재) |
| **특색** | 각 수인족 구역 자연 형성. 의회 의사당 중심 |
| **분위기** | 야생적이고 자유로움. 종족 간 긴장이 있지만 공존 |

**주요 시설:** 종족별 대표 의회 의사당·마레티스 교역 거점·야성 의식 광장·각 종족 구역
**국경 검문소:**
- 아틀라스 산맥 마레티스 교역로 — 유일한 공식 출입 통로. 마레티스 상인만 허용
- 자하라트 사막 접경 — 병력 순찰. 공식 검문소 없음
