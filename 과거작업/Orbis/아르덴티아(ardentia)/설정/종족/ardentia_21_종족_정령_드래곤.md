# ✨ 아르덴티아 종족 설정 04 — 정령 혼혈 / 드래곤 수인

---

## 🌿 정령 혼혈(Spiritus Dimidius)

### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 200~400년 (정령 속성에 따라 차이) |
| **성인** | 30~50세 |
| **신체** | 부모 종(주로 엘프·인간)을 따르지만 정령 속성이 외형에 드러남 |
| **마나** | 각성률 극히 높음. 태어날 때부터 정령 속성 고정 |
| **고유 능력** | 정령 소환·융합 / 이중 감각 / 마나 직접 전달 |

### 발생 조건

- 주로 엘프+자연 정령이 마나 공명 상태에서 결합해 태어남
- 인간+정령 혼혈도 존재하나 극히 드묾
- 전 대륙 통틀어 수십 명 수준의 극소수

### 외형적 특징

- 정령 속성이 신체에 드러남
  - 바람 정령 혼혈: 머리카락이 항상 바람에 흩날림. 눈동자 흰빛
  - 불 정령 혼혈: 피부가 미세하게 발광. 체온 높음
  - 물 정령 혼혈: 피부 촉촉. 눈동자 깊은 청색
  - 땅 정령 혼혈: 피부에 나뭇결·암석 문양 나타남
  - 빛 정령 혼혈: 후광 효과. 눈동자 금빛

### 고유 능력

**이중 감각(Sensus Duplex):**
- 마나 흐름을 시각과 촉각으로 동시 인식
- 마법 계열 운용 정밀도 엘프 이상
- 주변 마나 변화를 24시간 무의식적으로 감지

**정령 소환·융합:**
- 자신의 속성과 같은 정령을 직접 소환 가능
- 정령 융합 시 해당 속성 마나 능력 대폭 증가
- 융합 지속 시 신체 부담 존재

**마나 직접 전달:**
- 피부 접촉으로 마나를 상대에게 직접 전달
- 치유 효과 동반 — 접촉 치유 능력

**신체 불안정:**
- 감정이 격해지면 속성 마나가 신체 밖으로 새어나오는 것을 제어하기 어려움
- 주변 자연 현상이 감정에 반응 (꽃이 피거나, 바람이 일거나 등)

### 사회적 위치

- 디르우드에서 불결한 혼혈로 취급. 최대 금기
- 베르단티스에서만 공식 인정
- 마고리아에서 연구 대상으로 주목
- 엘프와 정령 모두에게 완전히 속하지 못하는 경계인적 정체성

## 🐉 드래곤 수인(Draco-kin)

### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 500~1000년 (순혈 드래곤에 가까울수록 길어짐) |
| **성인** | 50~100세 |
| **신체** | 인간형 기본 + 뿔·비늘·날개·꼬리 등 드래곤 특징 잔존 |
| **마나** | 각성률 100%. 태어날 때부터 각성. 마나 총량 아르덴티아 최상위 |
| **고유 능력** | 드래곤 변신 / 브레스 / 마나 공명 극한 |

### 발생 배경

> 현재 아르덴티아에는 순혈 드래곤이 존재하지 않는다.
> 대붕괴 이전에 순혈 드래곤이 존재했다는 기록만 남아있으며
> 현재의 드래곤 수인은 모두 과거 드래곤과 타 종족 사이의 혼혈 후손이다.

- 드래곤+인간 혼혈이 대부분. 드래곤+엘프 혼혈도 일부 존재
- 혈통이 희석될수록 드래곤 특성 약화. 수백 세대를 거쳐도 특성 잔존
- 전 대륙에 수백 명 수준. 희귀 종족

### 외형적 특징

- 인간형 기본 외형 유지
- 개인마다 드래곤 특성 발현 정도 차이
  - 강한 혈통: 뿔+비늘+날개+꼬리 모두 발현. 변신 능력 강함
  - 약한 혈통: 눈동자 색·피부 질감 정도만 드러남
- 속성 색상: 드래곤 마나 속성에 따라 비늘·눈동자·브레스 색 결정
  - 불 속성 = 붉은 비늘·황금 눈동자
  - 얼음 속성 = 청백 비늘·은빛 눈동자
  - 번개 속성 = 황금 비늘·전기빛 눈동자 등

### 고유 능력

**드래곤 변신(Transformatio Draconis):**
- 인간형 ↔ 드래곤형 변신 가능
- 완전 변신: 순혈에 가까울수록 완전한 드래곤 형태 가능
- 부분 변신: 혼혈 대부분이 사용. 날개만·비늘만 발현 등 부분 강화
- 변신 시 마나 소모 극심. 장시간 유지 어려움

**브레스(Flatus Draconis):**
- 마나를 압축·방출하는 드래곤 고유 공격
- 속성은 보유 마나 속성과 동일
- 위력: 아르덴티아 최강 수준의 단일 공격
- 사용 후 마나 고갈 위험. 남용 불가

**마나 공명(Resonantia Magna):**
- 드래곤 수인과 마나 공명 발생 시 일반인은 마나 과부하 위험
- 드래곤 수인끼리의 공명은 주변 마나 흐름 자체를 변동시킴

**마킹(Sigillum Draconicum):**
- 드래곤 수인의 마킹은 브레스 마나 코팅 동반
- 반영구적 마나 보호막 형성 — 수인족 마킹 중 가장 강력
- 당사자 동의 + 공명급 마나 없이는 해제 불가

### 사회적 위치

- 희귀성으로 인해 어디서든 특별한 존재로 취급
- 마나 총량이 압도적이어서 어느 국가에서도 환영받지만 동시에 경계받음
- 케메트라는 드래곤 혈통을 신성시하는 경향 — 귀족 지위 부여 사례
- 페락시스에서는 최고 용병 대우
- 대부분 단독으로 행동하거나 소수 집단 형성
