# 👥 아르덴티아 종족 설정 01 — 인간 / 엘프류 / 드워프

---

## 🧑 인간(Homo)

### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 60~80년 |
| **성인** | 16~18세 |
| **신체** | 평균 키 165~185cm. 종족 중 가장 다양한 체형 분포 |
| **마나** | 각성 여부 개인차 큼. 전체 평균 각성률 |
| **고유 능력** | 없음 |

### 특징

- 아르덴티아에서 가장 수가 많은 종족. 대부분 국가에서 주류
- 적응력과 번식력이 타 종족 압도 — 어느 환경에서도 정착 가능
- 수명이 짧은 대신 세대 교체 빠름 — 문화·기술 변화 속도 가장 빠름
- 마나 각성 시 속성·계열 편차가 가장 넓음 — 어떤 계열이든 가능
- 타 종족과 혼혈 가능 — 하프 엘프·경혈 수인 등

### 문화적 다양성

- 국가·지역마다 문화 편차 극심. '인간 문화'로 통칭하기 어려움
- 엘프·드워프가 수백 년 전통을 고수하는 동안 인간은 수십 년 만에 문화를 바꾸기도 함
- 짧은 수명으로 인한 집중력과 야망 — 단기간에 큰 성취를 이루려는 경향

## 🌿 엘프류(Genus Sylvanus)

> 엘프류는 순혈 엘프와 하프 엘프를 통칭한다.
> 정령술은 엘프류 고유 능력. 하프 엘프는 능력이 약화된 형태로 보유.

---

### 순혈 엘프(Elvus Purus)

| 항목 | 내용 |
|---|---|
| **수명** | 300~600년 |
| **성인** | 50~80세 (외모는 인간 20대 수준에서 수백 년 유지) |
| **신체** | 평균 키 165~185cm. 인간보다 날렵하고 균형 잡힌 체형. 귀 끝 뾰족 |
| **마나** | 각성률 인간보다 높음. 마법 계열 친화성 강함 |
| **고유 능력** | 정령술(Artes Spiritus) — 자연 정령과 계약 가능 |

**특징:**
- 긴 수명에서 비롯된 깊은 기억과 전통 중시
- 마나 감응력이 인간보다 예민 — 마나 흐름을 직관적으로 감지
- 정령술과 마나를 동시에 보유 가능 — 단 별개의 능력으로 독립 운용
- 번식률 낮음 — 한 쌍이 수백 년 살아도 자녀 수 매우 적음
- 디르우드(순혈주의)·베르단티스(개방주의) 두 왕국 중심 분포

**정령술 특성:**
- 자연 정령과 계약해 힘을 빌리는 엘프 고유 기술
- 마나 각성 여부와 무관하게 사용 가능
- 계약 대가: 수명·기억·감정·감각 일부 제공
- 상세 내용 → 마나 운용 체계 파일 참조

---

### 하프 엘프(Elvus Dimidius)

| 항목 | 내용 |
|---|---|
| **수명** | 100~200년 (엘프 혈통 비율에 따라 차이) |
| **성인** | 20~30세 |
| **신체** | 인간과 엘프의 중간. 귀 끝이 약간 뾰족하거나 거의 없음. 개인차 큼 |
| **마나** | 인간보다 각성률 높음. 마법·전투 계열 모두 균형적 |
| **고유 능력** | 정령술 가능 — 단 순혈 엘프보다 약함. 계약 가능 정령 수 제한 |

**특징:**
- 인간·엘프 어느 쪽에도 완전히 속하지 못하는 경계인적 정체성
- 디르우드에서 공식 차별·거주 제한
- 베르단티스에서 시민권 완전 부여
- 인간 국가에서는 지역·문화에 따라 처우 다양
- 마고리아 마법사 중 하프 엘프 비율 상당

**혼혈 세분화:**
- 인간+순혈 엘프 = 하프 엘프
- 하프 엘프+인간 = 경혈 엘프(Quarter-Elf) — 외모·능력 모두 인간에 가까움
- 하프 엘프+순혈 엘프 = 3/4 엘프 — 외모 엘프에 가깝고 정령술도 비교적 강함

## ⛏️ 드워프(Nanus)

### 기본 특성

| 항목 | 내용 |
|---|---|
| **수명** | 150~300년 |
| **성인** | 40~50세 (외모는 인간 30~40대 수준에서 오래 유지) |
| **신체** | 평균 키 140~165cm. 밀도 높고 두꺼운 체형. 근력 체급 대비 최상위 |
| **마나** | 각성률 낮음. 단 각성 시 신체 강화 계열 친화성 강함 |
| **고유 능력** | 룬 공학 친화(Aptitudo Runica) |

### 특징

- 우르단(지하 왕국) 중심 분포. 일부는 지상 도시에서 장인·광부로 활동
- 극도로 발달한 공간 감각 — 지하 지형을 본능적으로 파악
- 암석·금속 감응 — 광물 매장 위치 감지 능력 본능적 보유
- 계약·명예 의식 강함 — 어떤 압력에도 계약 파기 않음
- 번식률 낮음. 씨족 단위 결속 극강

**룬 공학 친화:**
- 타 종족보다 룬 각인 학습 속도 빠르고 완성도 높음
- 마나 없이도 룬 효과 발동 가능. 마나 각성 시 효과 증폭
- 독점 능력이 아님 — 타 종족도 룬을 배울 수 있으나 드워프 수준에 미치지 못함

**혼혈:**
- 드워프+인간 = 반석 혈통(Stoneblooded) — 드워프보다 키 크고 인간보다 단단함. 룬 친화성 약화
- 드워프+수인족 = 철혈 수인(Ironkin) — 극히 드묾. 야성 해방과 룬 친화가 혼재해 불안정하지만 폭발적
