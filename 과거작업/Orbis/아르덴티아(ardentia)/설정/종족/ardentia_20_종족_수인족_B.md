# 🐾 아르덴티아 종족 설정 03 — 수인족 B (새 / 상어 / 뱀)

---

## 🦅 새 수인(Avis-kin)

> 새 수인은 날개를 보유한 수인족의 통칭이다.
> 완전한 비행 능력을 보유한 종과 활공만 가능한 종으로 나뉜다.

---

### 독수리 수인(Aquila-kin)

| 항목 | 내용 |
|---|---|
| **수명** | 80~120년 |
| **성인** | 16~20세 |
| **신체** | 날렵하고 단단한 체형. 등에 대형 날개. 발톱 강함. 눈동자 날카로움 |
| **마나** | 각성률 높음. 방출 계열 친화성 강함 |
| **야성 해방** | 조건성 — 비행 중 위협 시 발동. 공중 전투력 폭발적 상승 |

**특징:**
- 완전 비행 가능 — 장거리 비행 지속 능력 탁월
- 시력 인간의 8배 이상 — 수km 밖 목표 식별 가능
- 독립적이고 자존심 강함. 타인에게 복종하는 것을 극도로 꺼림
- 고도에서 마나 방출 정밀도 높음 — 공중 저격 특화
- 아타르발 중심 분포. 아르덴티아 내 희귀 종족

---

### 까마귀 수인(Corvus-kin)

| 항목 | 내용 |
|---|---|
| **수명** | 70~100년 |
| **성인** | 15~18세 |
| **신체** | 독수리보다 날렵하고 작은 체형. 검은 깃털. 지능적인 눈빛 |
| **마나** | 각성률 높음. 마법 계열 친화성 강함 |
| **야성 해방** | 희박성 — 드물지만 무리 집결 능력(Murmur) 발동 |

**특징:**
- 수인족 중 지능 최상위권 — 복잡한 계획·기억 능력 탁월
- 언어 모방 능력 — 들은 언어를 빠르게 습득
- 무리 의식 강함 — 동료가 위험에 처하면 즉각 반응
- 마고리아·마레티스 등 학문·교역 도시 분포

## 🦈 상어 수인(Squalus-kin)

| 항목 | 내용 |
|---|---|
| **수명** | 80~150년 (나이 들수록 체격·마나 총량 증가) |
| **성인** | 16~20세 |
| **신체** | 날렵하고 유선형 전투 체형. 청회색 피부에 미세 돌기 문양. 하단부 치아 다층 구조 |
| **마나** | 각성률 높음. 번개+물 속성 친화성 강함 |
| **야성 해방** | 없음 — 포식 본능 형태로 항상 잠재. 상대 마나 고갈 감지 시 폭발적 공세 |

**특징:**
- 수압 적응: 수심 200m까지 마나 소모 없이 활동
- 혈류 감지: 수백 미터 내 마나·혈류 흐름 감지 — 육지에서도 상대 마나 잔량·부상 파악
- 탈피 없음 — 지속 성장형. 나이 들수록 체격·마나 총량 증가
- 상어 피부의 미세 돌기: 물 속에서 저항 없이 이동. 육지에서 마찰·충격 방어
- 독립적이고 자유 지향 — 어떤 조직에도 완전히 속하기를 거부하는 경향
- 이빨 접촉 = 상어 수인 최고 신뢰 표현 (공격이 아닌 애정)
- 브레타바르·펠라기온 해상 세력 분포 多

## 🐍 뱀 수인(Serpens-kin)

> 뱀 수인은 육지형(코브라·킹스네이크 계열)과 사막형(모래 뱀 계열)으로 나뉜다.

---

### 뱀 수인 공통 특성

| 항목 | 내용 |
|---|---|
| **수명** | 100~200년 |
| **성인** | 18~25세 |
| **신체** | 극도로 유연하고 날렵한 체형. 피부에 비늘 분포. 갈라진 혀 |
| **마나** | 각성률 높음. 독+땅 또는 독+어둠 속성 친화성 |
| **야성 해방** | 없음 — 대신 탈피 주기 시 마나 2배 + 감각 극도로 과민 |

**공통 특징:**
- 갈라진 혀로 마나·감정·독 성분 즉시 감지
- 관절 없이 구부러지는 극도의 유연성 — 어떤 속박도 탈출 가능
- 탈피(Shedding): 월 1회 정도. 탈피 시기에 마나 총량 2배지만 감각 과민으로 양날의 검
- 한냉 환경에서 전투력 급락 — 체온 유지 어려움
- 독 운용 능력 — 독샘 마나 코팅으로 독 생성·강화 가능

---

### 육지형 뱀 수인(Serpens Terrestris-kin)

**추가 특징:**
- 비늘이 목·어깨·팔뚝에 집중 분포
- 도시·문명 환경 적응 — 자하라트·페락시스 등 분포
- 독 분석·제조 능력 특화 — 연금술사·암살자 직군 친화성 높음
- 차갑고 느릿한 말투. 급하지 않고 집요하게 목표 추구

---

### 사막형 뱀 수인(Serpens Arenae-kin)

**추가 특징:**
- 모래색 비늘 — 사막 위장 특화
- 사막 열기에 오히려 전투력 상승 — 체온 유지가 쉬운 환경
- 아타르발·자하라트 사막 지대 중심 분포
- 모래 속 이동 능력 — 지하 잠행 전투 특화
