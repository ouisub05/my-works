# 🌎 신대륙(Terra Incognita) 설정

---

## 보안 등급

> **마레티스 왕실 최고 기밀.**
> 아르덴티아 내 이 정보를 아는 자는 마레티스 왕·측근·탐험대원 일부뿐.
> 유출 시 타국 개입으로 독점 교역 루트 붕괴.
> 베네눔 코르디스 아우룸 라텐스가 정보 입수 시도 중.

---

## 발견 경위

| 항목 | 내용 |
|---|---|
| **최초 발견** | AN 720. 마레티스 대서양 탐험대 |
| **발견자** | 탐험대장 — 이름 기밀 보존. 현재 생존 여부 불명 |
| **공식 발표** | 없음. 극비 유지 |
| **현재 접촉 횟수** | AN 845 기준 약 15회 탐험 |
| **교역 단계** | 초기 물물교환 수준 |

## 지리적 특성

> 아르덴티아에서 대서양 서쪽으로 약 3~4주 항해 거리.
> 마레티스 탐험선 기준. 일반 선박은 더 오래 걸리거나 항로 파악 불가.

**대륙 규모:**
- 아르덴티아보다 크거나 비슷한 규모 추정
- 탐험 범위는 동부 해안 일부에 한정. 내륙은 미탐사

**지형 특성:**
- 동부 해안: 광활한 열대~온대 혼합 삼림
- 해안 평원: 아르덴티아보다 비옥한 농경지 추정
- 마나 농도: 아르덴티아와 유사. 일부 지역은 더 높은 것으로 감지

**기후:**
- 남부: 열대. 아르덴티아 기준 미지의 식물·약재 다수
- 중부: 온대. 아르덴티아와 유사한 환경
- 북부: 미탐사

## 신대륙 종족

### 🌿 아르보리(Arbori) — 수목 인족

> 마레티스 탐험대가 최초 접촉한 신대륙 종족.

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 피부에 나뭇결 무늬·녹색 빛 발광. 귀 뾰족. 엘프류와 유사하지만 다른 계통 |
| **수명** | 추정 200~400년 |
| **마나** | 각성자 비율 높음. 자연 계열(아르덴티아 기준 테라·아쿠아·벤투스) 친화성 강함 |
| **특성** | 식물 마나 감응 — 식물 성장 촉진·소통 가능. 아르덴티아 정령술과 유사하지만 다른 방식 |
| **분포** | 신대륙 동부 해안 삼림 지대 |
| **문명 수준** | 아르덴티아 중세 수준. 도시·국가 형태 존재. 마나 활용 기술 발달 |

**아르덴티아 종족과의 차이:**
- 엘프류처럼 보이지만 정령 계약 없음 — 식물과 직접 공생하는 독자 방식
- 드워프처럼 제조 문화 있지만 자연 재료 위주
- 마나 운용 방식이 아르덴티아와 유사하지만 술식 체계 다름

---

### 🌊 마리니(Marini) — 해양 인족

> 신대륙 해안에 서식하는 해양 특화 종족.

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 청록색 피부. 손발에 물갈퀴. 아가미 흔적. 아르덴티아 수달·상어 수인과 유사하지만 별개 계통 |
| **수명** | 추정 80~120년 |
| **마나** | 각성자 비율 중간. 물 계열 친화성 압도적 |
| **특성** | 수압 적응 — 수심 100m 이상 활동 가능. 해류 감지 능력 |
| **분포** | 신대륙 해안·도서 지역 |
| **문명 수준** | 부족 연합 수준. 해상 교역·어업 발달 |

**마레티스와의 관계:**
- 마레티스 탐험대와 가장 먼저 교류한 종족
- 해상 교역 경험 있어 거래 개념 이해. 물물교환 진행 중
- 언어 장벽으로 소통 제한. 몸짓·물건 교환 위주

---

### 🧑 테라이(Terrae) — 신대륙 인간

> 신대륙에 정착한 인간 종족. 아르덴티아 인간과 같은 종이지만 독자 문화 발전.

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 피부·머리카락 색상 다양. 아르덴티아 인간과 외형 거의 동일 |
| **수명** | 60~80년. 아르덴티아 인간과 동일 |
| **마나** | 각성률 아르덴티아 인간과 유사 |
| **특성** | 없음. 단 신대륙 환경 적응으로 체력·생존력 강인한 경향 |
| **분포** | 신대륙 해안~내륙 전반 |
| **문명 수준** | 아르덴티아 중세 수준. 도시·국가 형태 존재 |

**마레티스와의 관계:**
- 마리니를 통해 간접 접촉. 직접 교역 미성립
- 아르덴티아 인간과 외형 동일하여 탐험대원이 처음엔 혼란
- 언어 완전히 달라 소통 어려움

---

### 🦅 플루마(Pluma) — 깃털 수인

> 신대륙 고유 조류형 수인족. 아르덴티아 독수리·까마귀 수인과 유사하지만 별개 계통.

| 항목 | 내용 |
|---|---|
| **외형** | 인간형 기본. 선명한 깃털 머리카락·등 날개·발목 깃털. 눈동자 선명한 원색 |
| **수명** | 80~120년 |
| **마나** | 각성률 높음. 마나 방출 계열 친화성 강함 |
| **특성** | 완전 비행 가능. 아르덴티아 독수리 수인보다 기동성 높음. 열대 기류 활용 장거리 활공 |
| **분포** | 신대륙 열대~온대 내륙 삼림 고지대 |
| **문명 수준** | 부족 연합. 공중 거점 도시 건설 |

**아르덴티아 수인족과의 차이:**
- 독수리 수인보다 화려한 색상. 깃털이 마나 상태 반영
- 야성 해방 대신 비행 본능 강화 — 위기 시 공중 이탈 반응
- 마레티스 탐험대와 첫 공중 조우 — 적대적 반응 후 차츰 호기심

---

### 🐴 에쿠스(Equus) — 말 수인

> 신대륙 고유 말 기반 수인족. 아르덴티아에 존재하지 않는 계통.

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 하반신 근육 발달. 말 귀·갈기(머리카락 형태). 발굽형 발. 긴 꼬리 |
| **수명** | 60~90년 |
| **마나** | 각성률 인간과 비슷. 신체 강화(하체 특화) 친화성 강함 |
| **특성** | 주력(走力) 압도적 — 지상 질주 속도 아르덴티아 어느 종족도 따라오기 어려움. 지구력 탁월 |
| **분포** | 신대륙 중부 대평원·초원 지대 |
| **문명 수명** | 부족 연합. 유목 문화 발달. 광대한 평원 지배 |

**아르덴티아 수인족과의 차이:**
- 아르덴티아에 말 기반 수인족 없음 — 완전 신규 계통
| **야성 해방** | 군마 본능 — 위기 시 무리 집결·돌격 본능 폭발. 집단 전투력 극대화 |
- 갈기 색상이 마나 상태 반영 — 각성·전투 시 갈기 발광
- 마레티스 탐험대와 평원에서 첫 조우 — 초기 적대 후 교역 가능성 타진 중

---

### 🐊 스쿠아마(Squama) — 비늘 수인

> 신대륙 고유 파충류형 수인족. 아르덴티아 뱀 수인과 유사하지만 악어·도마뱀 기반.

| 항목 | 내용 |
|---|---|
| **외형** | 인간형. 전신 비늘 덮임. 황록색~갈색. 긴 꼬리. 강인한 체형 |
| **수명** | 100~200년 |
| **마나** | 각성률 보통. 테라 계열 친화성 |
| **특성** | 갑각 방어 — 비늘이 물리 방어 높음. 수중·육상 양서 능력. 강력한 악력 |
| **분포** | 신대륙 하천·늪지·해안 저지대 |
| **문명 수준** | 부족 연합. 수로 네트워크 발달 |

**아르덴티아 수인족과의 차이:**
- 뱀 수인의 유연성보다 강인한 체력 중심
- 탈피 없음. 대신 비늘이 서서히 갱신되며 강화
- 마레티스 탐험대와 하천 교역로에서 접촉. 수로 안내자 역할 가능성

## 신대륙 고유 자원

### 희귀 약재·식물

| 품목 | 특성 | 아르덴티아 활용 |
|---|---|---|
| 루나플로라(Lunaflora) | 달빛에 반응해 발광하는 식물. 치유 마나 농축 | 치유학파 마나 증폭 재료. 고가 |
| 아우룸헤르바(Aurumherba) | 황금빛 약초. 마나 회로 복구 효능 추정 | 재각성·회로 손상 치료 가능성 연구 중 |
| 테라 루베아(Terra Rubea) | 붉은 토양. 마나 결정화 촉매 | 연금술 고급 재료. 마레티스 비밀 유통 |
| 비타에 수쿠스(Vitae Sucus) | 특정 나무 수액. 강력한 신체 강화 효능 | 강화 포션 원료. 아르덴티아산보다 효능 3배 |

### 광물

| 품목 | 특성 |
|---|---|
| 신대륙 마나 결정석 | 아르덴티아산보다 순도 높음. 동방 마나 결정석과 유사 |
| 신대륙 황금(Aurum Novum) | 아르덴티아 금화에 사용하는 금과 동일 성분. 매장량 압도적 |
| 황금 합금(Aurum Mixtum) | 신대륙 고유 금속 합금. 마나 각인 효율 높음. 아르보리 제조 |

> **신대륙 황금(Aurum Novum) 전략적 가치:**
> 아르덴티아 금화(아우레우스)와 동일한 성분의 금이 신대륙에 대량 매장.
> 마레티스가 이 정보를 공개할 경우 아르덴티아 전체 화폐 가치 폭락 위험.
> 현재 소량만 반입해 극비 비축 중.
> 아우룸 라텐스가 이 정보를 입수하면 경제 공작에 즉각 활용 가능 — 마레티스 최대 기밀.

## 언어 장벽

> 신대륙 종족들의 언어는 아르덴티아 코무니스·고대어와 완전히 다른 체계.

**현재 소통 방법:**
- 몸짓·그림·물건 지시
- 마레티스 탐험대원 일부가 마리니 언어 단어 수십 개 습득
- 아르보리는 마나 감응으로 감정·의도 전달 가능 — 언어 없이도 기본 소통
- 에쿠스·스쿠아마는 몸짓·행동 소통 가능 — 전투적 의도 여부 파악 가능

**번역 시도:**
- 마레티스 탐험대가 마리니 언어 기초 사전 작성 중 (극비 문서)
- 마나 번역 술식 시도 — 마고리아 마법사 없이는 불가. 마레티스가 마법사 비밀 합류 요청 가능성

**장벽의 전략적 가치:**
- 언어 장벽이 마레티스의 독점을 간접 보호
- 타국이 신대륙에 접근해도 소통 불가로 교역 어려움

## 마레티스의 신대륙 전략

### 현재 단계 (AN 720~845)
- 탐험대 파견 약 15회. 해안 지도 작성 중
- 마리니와 물물교환 확립 — 아르덴티아 철기·직물 → 신대륙 약재·광물
- 아르보리와 간접 접촉. 직접 교역 미성립
- 신대륙 인간(테라이) 문명 확인. 직접 교역 미성립

### 향후 계획
- 해안 거점(교역소) 건설 시도
- 마리니 언어 완전 습득 후 아르보리 접촉
- 신대륙 마나 결정석 안정적 수급 루트 확보
- 신대륙 인간 문명 접촉 — 직접 교역 루트 확립 시도

### 위험 요소
- 탐험선 실종 증가 — 신대륙 항로 해저 11호 공명탑 마나 교란 영향
- 아우룸 라텐스(베네눔 코르디스) 정보 탐지 시도 — 마레티스 내부 정보 유출 위험
- 신대륙 종족이 아르덴티아 세력 확장을 적대시할 가능성

---

## 신대륙의 대붕괴 연관성

> 아르덴티아의 대붕괴가 신대륙에도 영향을 미쳤는가.

**마레티스 탐험대 관찰:**
- 신대륙에도 고대 문명 유적 존재 — 대붕괴와 유사한 파괴 흔적
- 아르보리·에쿠스 구전에 "하늘이 무너지던 날"이라는 표현 존재 (통역 추정)
- 신대륙 마나 농도 변화 패턴이 아르덴티아와 유사

**가설:**
- 대붕괴는 아르덴티아만의 사건이 아닌 전 세계적 현상이었을 가능성
- 공명탑 폭발이 대서양 너머까지 마나 충격파를 전달했을 가능성
- 신대륙에도 공명탑 존재 가능성 — 아르카나 베투스가 알게 되면 즉각 탐색 시도
