# 📅 아르덴티아 연표(Chronologia Ardentiae)

---

> **시대 구분**
> - 선대(Aetas Prima): 대붕괴 이전. 정확한 연도 불명
> - 붕괴기(Ruina): 대붕괴 발생. 기준점 0
> - 재건기(Aetas Nova, AN): 대붕괴 이후. AN ○○년으로 표기
>
> **현재 시점**: AN 840년대 (정확한 연도는 서사 진행에 따라 결정)

---

## 선대(Aetas Prima) — 대붕괴 이전

| 시기 | 사건 | 비고 |
|---|---|---|
| 선대 | 고대 문명 번성. 마나 운용 기술 현재보다 훨씬 발달 | 기록 대부분 소실 |
| 선대 | 드래곤이 아르덴티아 전역에 실존. 고대 문명과 공존 또는 충돌 | 순혈 드래곤 현재 멸종 |
| 선대 | 고대 언어·술식 체계 완성. 현재 마법 기초 | 일부 유적에서 단편 발견 |
| 선대 말기 | 고대 문명 내부 갈등 증가. 마나 남용·과도한 봉인 실험 기록 | 대붕괴 원인과 연관 가능성 |
| 선대 말기 | 아르덴티아 각지에 대규모 봉인 구조물 건설 — 목적 불명 | 현재까지 일부 봉인 유지 중 |

## 붕괴기(Ruina) — 기준점

| 시기 | 사건 | 비고 |
|---|---|---|
| Ruina 0 | **대붕괴 발생** — 고대 문명 전역에서 동시다발적 재앙 | 원인 불명. 최대 미스터리 |
| Ruina 0 | 드래곤 대부분 소멸 또는 봉인. 순혈 드래곤 이후 미출현 | 봉인된 드래곤 일부 현존 추정 |
| Ruina 0 | 아르덴티아 전역 마나 농도 급변. 일부 지역 비정상 상승 | 동유럽 평원 마나 농도 최고치 |
| Ruina 0 | 고대 봉인 일부 약화. 티타누스급 마물 다수 출현 | 대규모 마물 대발생 1차 |
| Ruina 직후 | 생존자들 종족·지역별로 흩어져 소규모 집단 형성 | 현재 15개 국가의 기원 |
