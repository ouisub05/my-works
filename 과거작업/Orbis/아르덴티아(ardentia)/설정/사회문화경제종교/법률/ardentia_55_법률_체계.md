# ⚖️ 아르덴티아 각국 법률 체계

---

## 개요

> 아르덴티아에는 전 대륙 공통 법률이 없다.
> 각 국가가 독자적 법률 체계를 운영하며
> 국경을 넘으면 법이 바뀐다.
> 길드 체계(헌터·용병)는 국가 법률과 별개로 자체 규율 운영.

---

## ⚙️ 공통 법률 원칙 (길드 체계)

> 국가 법률과 무관하게 아르덴티아 전역에서 통용되는 규범.

| 원칙 | 내용 |
|---|---|
| 계약 신성 | 길드 계약 파기는 전 길드 블랙리스트 등재 |
| 마물 처치 독점 | 미등록 마물 처치 후 보상 청구 불가 |
| 무기 신고 | 헌터·용병 증표 소지 시 무기 소지 대부분 허용 |
| 포로 몸값 | 전투 중 항복한 자는 즉살보다 몸값 협상 관례 |

---

## 🏰 카이저라트 — 실력주의 법전

### 기본 원칙
- 종족 불문 동등한 법적 지위
- 마나 등급이 형량 경감 요소 (기여도 인정)
- 선제후 의회가 법률 제정·황제가 최종 비준

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 마나 무허가 공격 | 마나 봉인 1~3개월 + 벌금 |
| 강제 각성 시도 | 마나 봉인 1년 + 추방 가능 |
| 금기학파 사용 | 마나 영구 봉인 또는 처형 |
| 인신매매 | 재산 몰수 + 10년 강제 노역 |
| 살인 (각성자) | 처형 또는 마나 영구 봉인 |
| 살인 (미각성자) | 처형 또는 15년 강제 노역 |
| 길드 계약 위반 | 벌금 + 길드 제명 |

**특이사항:**
- 결투(Duellum)는 합법 — 양측 동의 시 마나 결투 허용
- 마나 등급 높을수록 형량 경감 가능 — 국가 기여도 고려

---

## 🏺 케메트라 — 혈통 법전

### 기본 원칙
- 혈통에 따라 법적 지위 차등
- 파라오 칙령이 모든 법률 위에 존재
- 신관 계급이 법률 해석 독점

### 혈통별 법적 지위

| 계층 | 법적 지위 |
|---|---|
| 순혈 귀족 | 완전한 법적 보호. 타 계층 고발 권한 |
| 평민 인간 | 제한적 보호. 귀족 고발 불가 |
| 혼혈 인간 | 평민보다 낮은 보호 |
| 수인족 | 사실상 법적 보호 최소 |

### 주요 법률

| 범죄 | 처벌 (순혈 기준) |
|---|---|
| 혈통 위조 | 사형 |
| 타 혈통 위장 | 사형 또는 노예화 |
| 상위 혈통 모욕 | 채찍형 + 벌금 |
| 수인족 도주 | 재포획 + 추가 노동 |
| 마나 무허가 사용 | 계층에 따라 차등 처벌 |

---

## ⛪ 상크티움 — 신법(Lex Sancta)

### 기본 원칙
- 루멘 신앙 교리가 법률의 근거
- 교황이 최고 입법·사법권 보유
- 비신자는 별도 외국인법 적용

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 이단 행위 | 심판의 불꽃 심문 → 개종 또는 처형 |
| 금기학파 사용 | 즉각 처형 |
| 움브라 마나 각성 | 즉각 봉인 후 재교육 또는 처형 |
| 순례자 해치기 | 추방 + 파문 |
| 마나 남용 | 마나 봉인 + 속죄 의식 |
| 살인 | 종신 봉사형 또는 처형 |

**특이사항:**
- 파문(Excommunicatio): 상크티움 신자에게 최악의 처벌. 사후 구원 박탈 선언

---

## 🔮 마고리아 — 마나 법전(Lex Manae)

### 기본 원칙
- 마나 등급이 법적 발언권에 영향
- 원로회가 최고 사법 기관
- 연구 목적 면책 조항 존재 (단 금기학파 제외)

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 금기학파 연구 | 추방 또는 마나 영구 봉인 |
| 마나 무허가 실험 | 마나 봉인 1~6개월 + 연구 제한 |
| 미등록 각성자 활동 | 강제 등록 + 벌금 |
| 봉인 유적 무단 접근 | 마나 봉인 3개월 + 재산 몰수 |
| 마나 결정석 불법 거래 | 재산 몰수 + 추방 |
| 타인 마나 강제 봉쇄 | 동급 처벌 적용 |

**특이사항:**
- 마나 결투는 합법 — 단 아카데미 구역 내 금지
- 원로 등급 각성자는 재판 시 원로회 직접 심의

---

## 🌲 디르우드 — 정령법(Lex Spiritus)

### 기본 원칙
- 정령 원로회가 최고 사법 기관
- 정령 계약 위반이 최중죄
- 비엘프·하프 엘프는 별도 외국인 규정

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 정령 계약 파기 | 추방 + 정령 능력 봉인 |
| 하프 엘프 순혈 구역 침입 | 강제 추방 |
| 외부인 무단 입국 | 즉각 격퇴 또는 억류 |
| 수목 무단 훼손 | 중노역 + 복구 의무 |
| 정령술 남용 | 정령 계약 강제 해제 |

---

## ⚔️ 페락시스 — 검의 법(Lex Gladii)

### 기본 원칙
- 국경 기사단이 치안·사법 겸임
- 결투 문화 합법화 — 분쟁의 상당수를 결투로 해결
- 길드 자체 규율 우선 — 길드 내 분쟁은 길드가 처리

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 미등록 무기 소지 | 벌금 또는 무기 몰수 |
| 결투 거부 (도전받은 경우) | 사회적 불명예 (법적 처벌 없음) |
| 계약 위반 | 재산 몰수 + 길드 제명 |
| 강제 각성제 유통 | 재산 몰수 + 추방 |
| 금기학파 사용 | 처형 |
| 살인 (결투 외) | 추방 또는 처형 |

**특이사항:**
- 공식 결투(Certamen Iustum): 증인 앞 선언 후 진행. 결과는 법적 효력
- 암살은 불법이지만 증거 없으면 처벌 어려움

---

## 🏜️ 자하라트 — 술탄 칙령(Lex Sultani)

### 기본 원칙
- 술탄 칙령이 최고 법률
- 귀족 가문이 각 구역 자치 법률 운영
- 상업 분쟁은 상인 조합 중재 우선

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 오아시스 오염·훼손 | 사형 |
| 거래 사기 | 손 절단 (전통 처벌) 또는 재산 몰수 |
| 귀족 모욕 | 귀족 결정에 따라 |
| 독 무허가 소지·사용 | 귀족 재량 처벌 |
| 노예 도주 조력 | 재산 몰수 + 투옥 |

**특이사항:**
- 자하라트 전통법과 술탄 칙령이 충돌하는 경우 귀족 가문이 해석권 보유

---

## ❄️ 칼드헤임 — 부족법(Lex Tribuum)

### 기본 원칙
- 부족장 의회 결의가 최고 법률
- 부족 내 분쟁은 각 부족장이 처리
- 전투로 분쟁 해결하는 관습법 병존

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 부족 간 약탈 금지 위반 | 추방 또는 결투 |
| 마물 허위 토벌 보고 | 부족 제명 |
| 대족장 명령 거부 | 전투 심판 |
| 약자 보호 의무 위반 | 부족 내 불명예 |

**특이사항:**
- 전투 심판(Iudicium Armatum): 법적 분쟁을 1대1 전투로 해결. 패자가 유죄 인정

---

## ⛏️ 우르단 — 계약법(Lex Contractus)

### 기본 원칙
- 계약이 모든 법률의 기반
- 암석왕 칙령이 최고 법률
- 씨족 장로 회의가 1차 재판

### 주요 법률

| 범죄 | 처벌 |
|---|---|
| 계약 파기 | 씨족 제명 + 재산 몰수 |
| 룬 기술 무단 도용 | 추방 |
| 지하 무단 침입 | 억류 후 추방 |
| 광맥 훼손 | 복구 의무 + 노동 배상 |

**특이사항:**
- 드워프에게 계약 파기는 법적 처벌 이전에 사회적 사망 선고

---

## 공통 금기 — 전 국가 금지

> 어느 국가도 공식 허용하지 않는 행위.

| 금기 | 설명 |
|---|---|
| 금기학파 마법 사용 | 전 국가 처형 또는 영구 봉인 |
| 공명탑 재건 시도 | 알려진 경우 국가 차원 대응 |
| 강제 마물화 | 인체 실험 최중죄 |
| 봉인 유적 무단 파괴 | 마나 폭발 위험으로 전 국가 경계 |
