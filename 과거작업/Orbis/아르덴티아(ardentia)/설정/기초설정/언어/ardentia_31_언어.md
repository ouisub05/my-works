# 🗣️ 아르덴티아 언어 체계

---

## 개요

> 아르덴티아에는 세 가지 언어 체계가 존재한다.
> 공용어는 일상·교역·외교에 사용되고,
> 고대어는 학자·마법사만 해독하는 사어이며,
> 정령어는 엘프류가 정령과 소통하는 수단이다.

| 언어 | 명칭 | 사용 주체 | 용도 |
|---|---|---|---|
| 공용어 | 코무니스(Communis) | 전 종족 | 일상·교역·외교·마법 술식 |
| 고대어 | 아르카나 링구아(Arcana Lingua) | 학자·마법사·성직자 | 고대 기록 해독·의식 |
| 정령어 | 스피리투스 링구아(Spiritus Lingua) | 엘프류(정령 계약자) | 정령과 소통 |

---

## 공용어 — 코무니스(Communis)

### 기본 특성

> 아르덴티아 전역에서 통용되는 표준 언어.
> 라틴어 계통에서 발전한 언어로 대붕괴 이후 재건기에 표준화됨.
> 문자 체계는 고대어 문자를 간략화한 형태.

**특징:**
- 표준 코무니스(Communis Normalis): 카이저라트·마고리아 중심으로 확립된 표준어
- 문법 비교적 단순 — 재건기에 다종족이 소통하기 위해 간략화
- 글로 쓰는 문어체와 말로 하는 구어체 간 차이 존재
- 마법 술식 시전 시 코무니스 기반 발음 사용

### 지역별 방언(Dialectus)

| 지역 | 방언명 | 특징 |
|---|---|---|
| 카이저라트 | 카이저 방언 | 표준어에 가장 가까움. 딱딱하고 격식적 |
| 케메트라 | 케메트 방언 | 고대어 발음 잔재 다수. 억양 독특 |
| 자하라트 | 자하르 방언 | 동방 언어 영향. 어휘 풍부. 협상 표현 발달 |
| 페락시스 | 페락 방언 | 다종족 혼합으로 약어·속어 발달. 빠른 속도 |
| 베르단티스 | 베르드 방언 | 엘프어 영향. 부드러운 발음. 시적 표현 많음 |
| 칼드헤임 | 칼드 방언 | 짧고 직설적. 외래어 거부. 고유 어휘 많음 |
| 마레티스 | 마레 방언 | 항해·교역 용어 발달. 수인족 발음 혼재 |
| 아타르발 | 아타르 방언 | 수인족 발성 특성 반영. 표준어와 차이 큼 |

**방언 간 소통:**
- 표준 코무니스 교육 수준에 따라 소통 가능 여부 다름
- 교육받은 계층: 방언 차이 무관하게 소통 가능
- 비교육 계층: 인접 지역 방언까지만 소통. 먼 지역 방언은 어려움
- 아타르발 방언은 다른 지역과 차이가 커 통역이 필요한 경우 있음

### 종족별 언어 특성

| 종족 | 코무니스 사용 | 특이사항 |
|---|---|---|
| 인간 | 원어민 수준 | 지역마다 방언 차이 |
| 엘프류 | 유창 | 코무니스에 엘프 특유의 리듬감 첨가 |
| 드워프 | 유창하지만 딱딱함 | 드워프 고유어도 내부적으로 사용 |
| 수인족 | 종족마다 차이 | 발성 기관 차이로 일부 발음 어려움. 늑대·개 수인은 비교적 유창 |
| 정령 혼혈 | 유창 | 감정 상태에 따라 코무니스에 정령어가 섞이는 현상 |
| 드래곤 수인 | 유창 | 브레스 사용 후 잠시 발음 불명확해지는 부작용 |

## 고대어 — 아르카나 링구아(Arcana Lingua)

### 기본 특성

> 대붕괴 이전 고대 문명이 사용하던 언어.
> 현재는 완전한 사어(死語) — 일상에서 사용하는 자 없음.
> 고대 유적·유물의 기록이 이 언어로 작성됨.

**특징:**
- 현재 코무니스보다 훨씬 복잡한 문법·어휘 체계
- 마나 흐름을 언어 구조에 직접 반영한 독특한 체계
- 고대 술식은 이 언어로만 완전히 구현 가능
- 코무니스로 번역 시 의미 손실 발생 — 특히 마나 관련 개념

### 해독 수준별 분류

| 수준 | 해독 능력 | 해당 집단 |
|---|---|---|
| 1수준 | 기초 단어·숫자 인식 | 교양 있는 일반인 |
| 2수준 | 단순 문장 해독 | 일반 학자·성직자 |
| 3수준 | 복잡한 문서 해독 | 마고리아 마법사·상크티움 고위 성직자 |
| 4수준 | 완전 해독·술식 구현 | 아르덴티아 극소수. 마고리아 원로급·아르카나 베투스 상층부 |

**학습 난이도:**
- 마나 각성자가 비각성자보다 습득 빠름 — 마나 감응으로 언어 구조 직관
- 엘프류는 긴 수명 덕에 완전 습득 가능성 높음
- 드워프 룬 문자 체계가 고대어 문자와 연관 — 드워프는 문자 해독 상대적 쉬움

### 고대어 현재 사용처

- 마고리아: 고급 술식 시전 시 일부 고대어 구문 사용
- 상크티움: 최고 의식(교황 즉위·성인 추대)에서 고대어 구절 낭독
- 우르단: 룬 각인 시 고대어 문자 체계 일부 사용
- 디르우드: 정령 원로회 의식에서 고대 정령 계약 문구 인용
- 아르카나 베투스: 고대 공명탑 술식 재현을 위해 적극 연구 중

## 정령어 — 스피리투스 링구아(Spiritus Lingua)

### 기본 특성

> 자연 정령과 소통하기 위한 언어.
> 엘프류 정령 계약자만 사용 가능.
> 인간·드워프·수인족도 소리를 낼 수는 있지만 정령은 반응하지 않음.

**특징:**
- 음성 언어보다는 마나 진동과 감정을 결합한 복합 소통 방식
- 같은 단어라도 사용자의 마나 상태에 따라 의미가 달라짐
- 정령마다 선호하는 방언 존재 — 수목 정령과 바람 정령의 정령어 미묘하게 다름
- 완전히 배우기 위해서는 정령과 직접 교류하며 체득해야 함

### 정령어 습득 경로

| 경로 | 설명 | 소요 기간 |
|---|---|---|
| 자연 습득 | 어릴 때부터 정령과 접촉하며 자연스럽게 체득 | 10~20년 |
| 정령 계약 후 습득 | 첫 계약 정령이 기초 정령어 직접 전달 | 1~5년 |
| 정령 결합자 이상 | 정령과 의식 공유 수준에서 자동 습득 | 즉각 |

### 정령어와 코무니스의 혼용

> 하프 엘프·정령 혼혈은 일상 대화에서 코무니스와 정령어가 무의식적으로 섞이는 경우가 있다.

- 감정 격양 시 코무니스 대화 중 정령어 단어 삽입
- 정령 혼혈: 감정 상태에 따라 주변 자연 현상이 반응하는 것과 연동
- 이 현상을 주변 인간들이 불편하게 여기는 경우 있음 — 사회적 차별의 원인 중 하나

### 정령어로 소통 가능한 대상

| 대상 | 소통 가능 여부 | 조건 |
|---|---|---|
| 자연 정령 (계약 대상) | 완전 소통 | 계약 관계 성립 후 |
| 자연 정령 (비계약) | 제한적 소통 | 2등급(계약자) 이상 |
| 고대 정령 | 어려움 | 3등급(결합자) 이상. 고대 정령어 별도 학습 필요 |
| 심연 정령 | 불가 (위험) | 소통 시도 자체가 정신 침식 유발 |
| 마물 | 불가 | 마물은 정령어 인식 불가 |
| 드래곤 수인 | 제한적 | 드래곤 혈통에 정령 감응 미약하게 존재 |

## 언어 간 관계

```
고대어(Arcana Lingua)
    │
    └─ 단순화·구어화
         │
         └─ 코무니스(Communis) ── 지역화 ──→ 각 방언(Dialectus)
                  │
                  └─ 마나 술식에 일부 고대어 구문 혼용

정령어(Spiritus Lingua)
    │
    └─ 코무니스와 별개 체계. 혼용 현상만 발생
```

## 번역·통역 체계

**마법 번역:**
- 시공간학파 마법사 일부가 즉각 번역 술식 보유
- 효과 지속 시간 제한. 마나 소모 있음
- 방언 간 번역보다 언어 간 번역에 주로 사용

**전문 통역사:**
- 마레티스·펠라기온·페락시스 등 다문화 허브 도시에 전문 통역사 활동
- 아타르발 방언 통역사는 특히 희귀하고 고가
- 고대어 통역은 마고리아 의뢰 또는 독학 학자 의뢰

**드워프 고유어:**
- 우르단 내부에서만 사용하는 드워프 고유어 존재
- 외부에 공개하지 않는 것이 관례
- 룬 각인 의식에서 사용 — 외부인이 배우는 것을 드워프가 탐탁지 않게 여김
