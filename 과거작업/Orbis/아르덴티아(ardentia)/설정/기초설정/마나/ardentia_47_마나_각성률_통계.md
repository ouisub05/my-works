# 📊 아르덴티아 마나 각성률 통계

---

## 개요

> 마나 각성률은 전체 인구 중 마나를 각성한 비율.
> 종족·국가·환경·의식 제도에 따라 크게 차이.
> 수치는 추정값 — 정확한 통계는 마고리아에서만 부분 보유.

---

## 종족별 기본 각성률

| 종족 | 평균 각성률 | 비고 |
|---|---|---|
| 순혈 엘프 | 85~95% | 마나 감응 선천적으로 높음 |
| 하프 엘프 | 60~75% | 엘프 혈통 비율에 따라 차이 |
| 정령 혼혈 | 95~100% | 사실상 전원 각성 |
| 드래곤 수인 (고혈) | 100% | 태어날 때부터 각성 상태 |
| 드래곤 수인 (저혈~흔적혈) | 70~90% | 혈통 농도에 따라 차이 |
| 드워프 | 25~35% | 각성률 낮지만 전투 계열 친화성 강함 |
| 인간 | 15~25% | 아르덴티아 평균 수준 |
| 수인족 (고양이과·개과) | 30~45% | 종족마다 차이 |
| 수인족 (조류·파충류) | 40~55% | 독수리·뱀 수인 상대적 높음 |
| 수인족 (기타) | 20~35% | |

## 국가별 각성률

> 국가별 수치는 해당 국가 주류 종족 기준 평균.
> 다종족 국가는 혼합 평균.

| 국가 | 추정 각성률 | 주요 요인 |
|---|---|---|
| 마고리아 | 60~70% | 마나 농도 높은 환경. 수련 각성 체계화 |
| 디르우드 | 70~80% | 순혈 엘프 중심. 정령술 환경 |
| 베르단티스 | 55~65% | 엘프류+타 종족 혼합 |
| 상크티움 | 35~45% | 의식 각성 제도 발달. 룩살리아 고마나 환경 |
| 카이저라트 | 25~35% | 실력주의로 각성자 집중. 실제 각성률은 아르덴티아 평균 |
| 케메트라 | 20~30% | 혈통 중시로 마나 등급보다 혈통 우선. 각성 훈련 체계 미흡 |
| 페락시스 | 30~40% | 전투자 집결 특성상 각성자 비율 높음. 실제 각성률은 평균 |
| 자하라트 | 20~28% | 의식 각성 제도 없음. 자연 각성 위주 |
| 아우렌탈 | 25~35% | 기사 수련 각성 체계. 귀족 교육 기반 |
| 펠라기온 | 28~38% | 해양 수인족 포함으로 상대적 높음 |
| 마레티스 | 22~30% | 특별한 각성 제도 없음 |
| 칼드헤임 | 35~45% | 마물 조우 자연 각성 빈번. 의식 각성 병행 |
| 우르단 | 25~35% | 각성률 낮지만 룬 공학으로 보완 |
| 브레타바르 | 20~28% | 전투·생존 환경으로 자연 각성 |
| 아타르발 | 25~35% | 수인족 혼합으로 평균 수준 |

## 등급별 각성자 분포

> 전체 각성자 중 각 등급 비율 추정.

| 등급 | 명칭 | 전체 각성자 중 비율 | 비고 |
|---|---|---|---|
| 티로(Tiro) | 하급 전투 / 디스치풀루스 하급 마법 | 60~70% | 대부분의 각성자 |
| 밀레스(Miles) | 중급 전투 / 마구스 중급 마법 | 25~35% | 실전 전투원 수준 |
| 도미누스(Dominus) | 상급 전투 / 아르크마구스 상급 마법 | 1~3% | 극소수 |
| 도미누스 상급 이상 | 최상급 | 0.01% 미만 | 역사에 기록될 수준 |

## 특수 환경 각성률 보정

| 환경 | 각성률 변화 | 설명 |
|---|---|---|
| 마고리아 외곽 결계 내 | +15~20% | 마나 농도 1.5배 환경 |
| 상크티움 룩살리아 | +10~15% | 빛(Lux) 마나 고농도 |
| 대붕괴 유적 인근 | -5~+10% | 마나 잔향은 각성 자극. 오염은 회로 손상 |
| 마나 오염 지대 | -10~-20% | 오염 마나가 회로 형성 방해 |
| 마물 다발생 지역 | +5~10% | 극한 상황 자연 각성 유발 |
| 공명탑 잔해 인근 | +5~15% | 잔향 마나 자극 |

## 강제 각성 현황

> 아우룸 라텐스 강제 각성제 유통으로 인한 비공식 각성.
> 정확한 규모 파악 불가. 추정치.

| 항목 | 추정 수치 |
|---|---|
| 연간 강제 각성 시도 | 수백~수천 건 |
| 성공률 (정상 각성) | 약 30% |
| 회로 손상 각성 | 약 40% |
| 폭주·사망 | 약 20% |
| 각성 실패 | 약 10% |
| 마고리아 치료 의뢰 접수 | 연간 수십 건 (빙산의 일각) |

## 각성률과 국가 권력의 관계

> 마나 각성자 비율이 국가 권력 구조에 미치는 영향.

| 유형 | 국가 예시 | 특성 |
|---|---|---|
| 고각성률 국가 | 마고리아·디르우드 | 각성자가 사실상 시민 전부. 비각성자 소외 |
| 중각성률 국가 | 페락시스·칼드헤임 | 각성자가 엘리트. 비각성자도 역할 있음 |
| 저각성률 국가 | 케메트라·자하라트 | 각성자가 소수 특권층. 혈통·신앙으로 보완 |
| 제도적 각성 국가 | 상크티움·우르단 | 의식·룬으로 낮은 각성률 보완. 대신 방향성 고정 |
