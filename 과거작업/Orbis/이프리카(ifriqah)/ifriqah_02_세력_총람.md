# 🌍 이프리카(Ifriqah) — 세력 총람

---

## 대륙 개요

| 항목 | 내용 |
|---|---|
| **대륙명** | 이프리카 (Ifriqah) |
| **지형 기반** | 사하라 이남 아프리카 |
| **현재 시점** | IN 412년 = AN 845년 |
| **역법** | 이프리카력(IN) — 균열기 이후 대지맥이 처음 안정된 해를 기원년으로 삼은 태양력 |
| **이그 체계** | 타르가(Targa, 전투) / 이심(Isim, 마법). 무속성. 상호 배타 |
| **세력 수** | 5개 |
| **대외 교류** | 아르덴티아·천원·아엘루와·카우사이와 현시점 공식 교류 없음 |

---

## 5개 세력 일람

| 세력명 | 지역 모티프 | 정치 체제 | 타르가/이심 | 현시점 상태 |
|---|---|---|---|---|
| **팔람(Falam)** | 서아프리카 (말리·가나·요루바) | 신성 황제제 | 이심 우세 | 전성기 — 교역로 팽창 중, 내부 안정 |
| **다하브(Dahab)** | 동아프리카 (스와힐리·에티오피아) | 고원 왕조 중앙집권 | 타르가·이심 균형 | 안정기 — 교역 부유, 외부 압박 있음 |
| **무칸다(Mukanda)** | 중앙아프리카 (콩고 밀림) | 밀림 왕국 중앙집권 | 타르가 압도적 우세 | 전성기 — 밀림 영토 팽창 중 |
| **쿠시(Kushi)** | 누비아 (케메트라 대항축) | 신성 왕국 (왕정+신관단) | 타르가 우세 | 독립 준비 중 — 케메트라 지배에서 이탈 준비 |
| **은도보(Ndovo)** | 남아프리카 (줄루·코이코이·산족) | 기마 전사 왕국 중앙집권 | 타르가·이심 균형 | 안정기 — 기마대 강화 중, 대외 교류 제한적 |

---

## 세력 간 주요 관계

| 관계 | 상세 |
|---|---|
| **팔람 vs 무칸다** | 접경 긴장. 양측 모두 팽창 중이라 충돌 가능성 상존. 현재 직접 교전 없음 |
| **팔람 + 다하브** | 내륙 교역로 공유. 각자의 대외 교역 방향은 다름 — 팔람은 북부 육상·대서양 해상로, 다하브는 북부 케메트라 육상·홍해 인도양 해상로. 내륙 교역에서는 협력하나 이권 경쟁 내재 |
| **다하브 vs 무칸다** | 간접 위협 | 쿠시를 사이에 두고 간접 접경. 무칸다의 쿠시 압박이 다하브에 간접 위협. 쿠시 붕괴 시 직접 접경 위기 |
| **무칸다 vs 쿠시** | 접경·정복 대기 | 동부 접경 접함. 쿠시 독립 시 정복 원정 개시 계획. 접경부 원정대 대기 중 |
| **다하브 vs 쿠시** | 지리적 접경. 쿠시 독립 움직임으로 다하브-케메트라 북부 육상로 안정성 불투명. 다하브가 촉각을 세우는 중 |
| **쿠시 vs 케메트라(아르덴티아)** | 핵심 대립축. 쿠시는 케메트라의 위성 세력 위치에서 독립 준비 중 |
| **무칸다 vs 은도보** | 거리상 완충지대 존재. 현재 직접 접촉 없으나 무칸다 팽창 시 충돌 가능 |
| **은도보** | 현시점 타 세력과 교류 극히 제한적. 내부 강화에 집중 |

## 이그 환경 분포

| 지역 | 이그 농도 | 특성 | 해당 세력 |
|---|---|---|---|
| 서아프리카 사헬·초원 | 중간 | 광역·안정적. 맥점 다수 분포 | 팔람 |
| 동아프리카 고원·해안 | 중상 | 고원 농밀 + 해안 유동적 | 다하브 |
| 중앙아프리카 밀림 | 최고 | 혼탁하나 총량 최대. 정밀 제어 어려움 | 무칸다 |
| 누비아 고원·사막 접경 | 중간 | 고원 맥 + 사막 경계부 희박 | 쿠시 |
| 남아프리카 초원·고원 | 중간 | 광역·깊고 느린 흐름 | 은도보 |
| 사하라 맥 단절지 | 없음~극희박 | 균열기 흔적. 저주받은 땅 | 해당 세력 없음 |

## 대외 관계 — 타 대륙과의 접점

> IN 412년 현시점 기준. 이프리카는 타 대륙에 공식적으로 알려지지 않음.

| 접점 | 내용 |
|---|---|
| **쿠시 ↔ 케메트라(아르덴티아)** | 핵심 대립축. 쿠시가 케메트라의 영향권 아래 있었으나 독립 준비 중. 케메트라 입장에서 쿠시는 속령에 가까운 위성 세력. |
| **다하브 ↔ 케메트라(아르덴티아)** | 북부 육상로를 통한 교역 접점. 홍해·인도양 해협 경유 해상로도 병용. 쿠시 독립 움직임으로 인해 다하브-케메트라 육상로 안정성 불투명. |
| **팔람 ↔ 아타르발·마레티스(아르덴티아)** | 북부 육상로 및 대서양 해상로를 통한 교역 접점. 공식 외교보다는 상인 네트워크 중심의 비공식 교류. |
| **이프리카 세력 간 내륙 교역** | 팔람·다하브·무칸다·쿠시·은도보 간 내륙 교역로 존재. 황금·상아·향신료 등이 주요 품목. 팔람 황금이 사실상 기준 가치재. |
| 기타 | 아엘루와·천원·카우사이와 현시점 접점 없음 |

## 공통 문화 요소

### 이그와 신앙
이프리카 전 세력에서 이그는 단순한 에너지가 아니라 대지의 의지 혹은 조상의 숨결로 해석된다.
각성자는 세력에 따라 전사·신관·샤먼 등 다양한 방식으로 사회적 위계를 부여받는다.
맥점(Nuqta)은 모든 세력에서 성소로 취급되며, 맥점의 위치는 최고 기밀이다.

### 균열기 신화
균열기(Shaqq)에 대한 해석은 세력마다 다르며, 이것이 세력 간 신학 갈등의 원천이 되기도 한다.
팔람은 황제가 균열기를 봉합한 신의 대리자라 주장하고,
쿠시는 케메트라가 균열기를 일으킨 장본인이라는 전승을 내부적으로 유지한다.

### 교역 통화
이프리카 세력 간 교역에 통일된 화폐 체계는 없다.
물물교역·황금 중량 거래가 기본이며, 팔람의 황금이 사실상 기준 가치재 역할을 한다.
