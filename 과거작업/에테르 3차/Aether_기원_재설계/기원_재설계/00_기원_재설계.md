# 기원 엔진 요약 — 세계관의 숨은 척추

> **설계 노선: 1-B (확정형 + 자연/우주형)**
> 작가는 진짜 기원을 안다. 작중 인물·세력은 끝까지 추측만 한다.
> 신은 창조주가 아니며, 에테르는 자연적 우주의 장(場)이고, 단절은 물리·에테르적 사건이다.

---

## 한 줄 엔진

> **에테르는 이 행성에 깔린 "두 번째 자연 물리장(場)"이다.**
> 자연 물질이고, 구조화된 패턴(의지·룬·수련된 신체·다수의 믿음)에 **결합(coupling)** 한다.
> 신도, 정령도, 단절도, [E]마물도, 쌍도도 — 전부 이 하나의 장이 다르게 드러난 것일 뿐이다.

에테르가 다른 자연의 장(전자기·중력)과 단 하나 다른 점:
**구조화된 패턴에 결합한다.** 이 단 하나의 성질에서 세계관의 모든 것이 갈라져 나온다.

---

## 작중 미스터리 → 진짜 정체 (작가만 아는 정답)

| 작중 미스터리 | 작중 인식 (유지) | **진짜 정체 (확정)** |
|---|---|---|
| 무인 vs 마법사 | 원천이 다른 두 길 | 같은 장에 대한 **결합 방식 차이**. 무인=내부 위상결합 / 마법사=외부 패턴조작 |
| 신·신성력 | 신이 부여 / 실재 불명 | **신은 없다.** 신성력은 마법과 같은 원리지만 **다수의 믿음**이 패턴을 공급해야 발동하는 에테르의 한 형태 |
| 정령·정령력 | 신과 별개의 자연 의지체 | 동물 진화처럼 에테르에 적응·분화한 **생명 계통.** **엘프와 뿌리가 같아 소통됨** (인물은 모름) |
| "삼대 힘은 원리가 다르다" | 다른 계통 | 전부 같은 에테르장. **결합 주체만 다름** — 개인 / 다수신앙 / 자연생태 |
| 종족 기원 | 별개 종족 | 같은 에테르 적응 계통의 분화. **엘프–정령이 사촌뻘** |
| 고대 문명 | 재현 불가 초고대 | 대재앙 전 존재한 **복수의 국가·문명.** 지역별 잔존도 상이 |
| 대재앙 | 원인 불명 (5학설) | **무분별한 실험·과조작(환경오염 모티브)이 다가오던 천재지변을 촉진·증폭**한 복합 재앙 |
| 단절 | 대재앙과 동의어 | 그 **결과.** 천재지변+판 이동으로 대륙이 2~3개 → 6개로 갈라진 지질학적 단절 |
| 재현 불가 유물 | 소재·원리 불명 | **깃든 에테르가 세월 따라 고갈**돼 멈춘 것. 원리가 어려운 게 아니라 연료가 빠진 것 |
| 쌍도 | 도달 불가의 최고 경지 | **가능하다.** 깊이 공부하면 됨. 단 내·외 동시 운용이 **비효율**이라 대부분 끝까지 안 판다 |
| [E]마물 | 단절의 전조? / 유물 누출? | **복합.** 에테르에 **과다·장기 노출되거나 오염된** 생물의 과결합 변이 |

> 모든 실은 한 뿌리로 모인다 —
> **"행성 에테르장. 인간이 과조작으로 천재지변을 키웠고, 대륙이 갈라졌으며, 지금 그 흉터에서 [E]마물이 기어나온다."**

## 단절/대재앙 인과 (확정)

```
다가오던 천재지변(운석·화산·지진)
        │
        ▼  ← 고대 문명의 무분별한 에테르 실험·과조작이 촉진·증폭
   ┌─────────┐
   │  대재앙  │  = "왜" 일어났나 (인간 책임 + 자연)
   └────┬────┘
        ▼  ← 천재지변 + 판 이동
   ┌─────────┐
   │  단절   │  = "무엇이" 일어났나 (대륙 2~3 → 6 분리, 문명 끊김)
   └─────────┘
```

## 문서 읽는 법

각 토대 문서는 두 층으로 쓰여 있다.

- **〔작중 인식〕** — 작중 인물·세력·학자·교단이 믿거나 추측하는 것. 작품 표면에 노출 가능.
- **〔작가 전용·진실〕** — 의섭만 아는 정답. 작중에 직접 노출하지 않음. 복선 회수용.

| 번호 | 문서 | 다루는 것 |
|---|---|---|
| 00 | 기원 엔진 요약 | (이 문서) 숨은 척추 |
| 01 | 태초·우주론 | 세계와 에테르의 시작 |
| 02 | 에테르 본질 | 에테르가 무엇이며 어떻게 결합하는가 |
| 03 | 신·신성력의 진실 | 신은 없다. 믿음이 힘이 되는 원리 |
| 04 | 정령·엘프의 뿌리 | 정령과 엘프가 사촌인 비밀 |
| 05 | 종족 기원 | 모든 종족의 분화 계통도 |
| 06 | 고대 문명 (재설계) | 대재앙 전 문명과 지역별 잔존도 |
| 07 | 대재앙·단절 (재설계) | 종말의 진짜 인과 |
| 08 | 현재로의 연결 | [E]마물·쌍도·고대유물의 현재 |
