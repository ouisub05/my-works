# 03. 신·신성력의 진실

## 핵심 명제

> **신은 없다.** 창조주도, 영역을 다스리는 신격도 실재하지 않는다.
> 신성력은 **마법과 똑같은 에테르 운용**이며, 단지 발동에 **개인의 술식 대신 "다수의 믿음"** 이 필요할 뿐이다.

---

## 〔작가 전용·진실〕 — 믿음이 힘이 되는 원리

### 메커니즘

| 단계 | 내용 |
|------|------|
| 1. 공유 패턴 형성 | 다수가 같은 신·교리·기도문을 믿으면 **동일한 믿음 패턴**이 형성된다 |
| 2. 에테르 결합 | 에테르는 구조화된 패턴에 결합한다 → 믿음 패턴에도 결합한다 |
| 3. 출력 발생 | 패턴이 클수록(=신자가 많고 믿음이 깊을수록) 끌어오는 에테르가 커진다 |
| 4. 발동 | 사제·성기사는 그 공유 패턴에 "접속"해 에테르를 치유·정화·강화로 출력한다 |

> **즉 신성력은 "마법사가 자기 혼자 짜는 술식"을, "수백만 명이 대신 짜주는" 형태다.**
> 사제는 술식을 외우는 게 아니라 **거대한 공유 술식에 로그인**하는 셈.

### 마법 vs 신성력 — 같은 원리, 다른 연료

| 항목 | 마법 | 신성력 |
|------|------|--------|
| 패턴 공급원 | 시전자 본인의 술식 지식 | **다수 신자의 믿음** |
| 핵심 자원 | 마정석·지식 | 교세(신자 수·신앙 깊이) |
| 개인 역량 의존 | 큼 | 작음(접속자는 매개일 뿐) |
| 강해지는 법 | 더 공부·더 좋은 마정석 | **신도를 늘리고 믿음을 키운다** |

### 여기서 자동으로 따라오는 설정들

| 현상 | 진짜 이유 |
|------|----------|
| **큰 교단의 사제가 더 강한 기적을 쓴다** | 공유 패턴(교세)이 크니까. 개인 재능과 무관 |
| **잊힌 신의 신성력이 약해진다** | 신자가 줄면 패턴이 작아짐 |
| **이단이 탄압받는다** | 패턴이 분산되면 본교단 출력이 떨어짐 → 교단은 본능적으로 독점하려 함 |
| **신탁·현현 기록은 있으나 검증 불가** | 거대 패턴의 우연한 자기피드백이 "응답"처럼 보인 것 |
| **성흔(聖痕)** | 다수 패턴에 과접속한 신체에 결합 흔적이 남은 것. 신의 표식 아님 |

> **가장 위험한 진실:** 누군가 의도적으로 **새 신앙을 설계·전파**하면, 무에서 신성력을 만들어낼 수 있다.
> 이건 종교가 아니라 **무기 설계**가 된다. (장기 떡밥 후보)

---

## 〔작중 인식〕 — 신은 실재할지도 모른다

작중에선 진실을 모르며, 신성력이 **신 존재의 증거**처럼 받아들여진다.

| 원칙 (기존 04 문서 계승) | 작중 통념 |
|---|---|
| 신은 다수 존재 (pantheon) | 각자 영역(전쟁·죽음·지혜 등)을 가짐 |
| 신은 직접 개입 안 함 | 신탁·기적은 있으나 검증 불가 |
| 절대신 없음 | 모든 신을 압도하는 유일자는 없음 |
| 지역별 pantheon | 같은 신을 문화권마다 다르게 부름 |

> **작가 시점 재해석:** "같은 신을 다르게 부른다"가 사실인 이유 —
> 여러 문화가 비슷한 믿음 패턴을 각자 만들면, **에테르장 입장에선 비슷한 패턴**이라 호환된다.
> 그래서 다른 이름의 신끼리 신성력이 통하는 일이 생긴다. 사람들은 이를 "같은 신"이라 해석한다.
