# 04. 정령·엘프의 뿌리

## 핵심 명제

> **정령과 엘프는 같은 가지에서 갈라진 사촌이다.**
> 동물이 진화·분화하듯, 에테르에 적응한 생명 계통이 두 갈래로 갈라졌다 —
> 신체를 유지한 쪽이 **엘프**, 신체를 버리고 자연물에 결합한 쪽이 **정령**.
> 그래서 둘은 소통할 수 있다. **단, 작중 인물 누구도 이 사실을 모른다.**

---

## 〔작가 전용·진실〕 — 공통 조상에서의 분화

### 분화 과정

| 단계 | 내용 |
|------|------|
| 1. 공통 조상 | 심층·안정 결합 형질을 가진 에테르 적응 생명 (→ 05 계통도의 "심층결합 가지") |
| 2. 1차 분기 | 일부는 **신체를 유지**한 채 안정 결합을 극대화 → 장수·고감응 = **엘프 계통** |
| 3. 1차 분기 | 일부는 **신체를 점차 버리고** 장소·자연물(숲·강·산·불·바람)에 결합 = **정령 계통** |
| 4. 고착 | 두 계통이 수만 년 갈라지며 외형은 완전히 달라졌으나, **에테르 결합 구조의 기저는 동일하게 남음** |

> 비유: 늑대와 개가 다른 종처럼 보여도 같은 뿌리이듯,
> 엘프와 정령은 **에테르적으로 같은 "언어"** 를 쓴다.

### 정령력의 진짜 정체

| 항목 | 내용 |
|------|------|
| **정령** | 신비 의지체가 아니라 **자기조직화된 에테르 생명.** 자연물에 결합한 탈신체 생명 |
| **정령력** | 정령과의 "계약"이 만드는 힘이 아니라, **같은 결합 언어를 쓰는 생명끼리의 교감** |
| **왜 착취 불가** | 정령은 의지를 가진 생명이라 일방적으로 빨아쓸 수 없다. 교감·합의만 가능 |
| **엘프가 정령과 유독 잘 통하는 이유** | **사촌이라서.** 결합 기저가 같아 신호가 호환됨 |

### 작중에 심을 수 있는 "어렴풋한 흔적"

진실을 직접 말하지 않고도 독자에게 깔 수 있는 복선:

- 엘프만 특정 정령과 **말 없이 통한다**(다른 종족은 의식·매개 필요)
- 고대 엘프 유적과 정령 성지가 **같은 입지·같은 문양**을 공유
- 다크엘프화가 진행된 집단은 정령과의 교감도 함께 비틀린다(결합 기저가 변형됐으니까)
- 정령이 엘프의 죽음에 유독 반응한다는 전승

> 인물들은 이를 "엘프가 자연과 가깝다"는 **문화적 설명**으로 받아들인다. 혈연이라곤 상상도 못 함.

## 〔작중 인식〕 — 정령은 신과 별개의 자연 존재

기존 `05_정령_설정`·`04_세계관의_신` 계승:

| 통념 | 내용 |
|------|------|
| 정령은 신과 별개 | 일부 교단은 정령을 신의 사자·하위 존재로 해석. 정령 측은 부정·무관심 |
| 계약·교감 | 정령력은 정령의 의지에 의존. 일방적 착취 불가 |
| 종족과 무관 | 정령은 "자연이 낳은 것"이라 여김. **종족과 혈연이라는 발상은 없음** |

> 교단 vs 정령 신앙자 갈등(기존 설정)은 유지된다.
> 진실 층에선 이 갈등이 더 아이러니해진다 — **신성력(믿음형)과 정령력(혈연형)은 메커니즘부터 다른데**, 둘 다 "신앙"으로 뭉뚱그려져 싸운다.
