# 06. 고대 문명 (재설계)

## 핵심 명제

> **고대 문명은 "재현 불가의 초월 문명"이 아니다.**
> 대재앙 전에 존재했던 **여러 국가·문명**이며, 지금과 기술 차이도 크지 않았다.
> 다만 그들은 에테르를 **행성 규모로 과조작**했고, 그게 종말을 불렀다(→ 07).
> 유물이 안 돌아가는 건 원리가 어려워서가 아니라 **깃든 에테르가 고갈돼서**다.

---

## 〔작가 전용·진실〕

### 고대 문명의 실체

| 항목 | 내용 |
|------|------|
| **단일/복수** | 단일 통합 문명 아님. **복수의 국가·문명**이 교류·경쟁하며 공존 |
| **기술 수준** | 현재와 비슷. "재현 불가 초월 기술"은 환상 — 실은 **연료(에테르)가 빠졌을 뿐** |
| **에테르 인프라** | 증폭탑·제단·관개수로 등 행성 에테르를 다루는 대형 인프라 보유 |
| **치명적 차이** | 이 인프라를 **무분별하게 과조작**해 자연 재난을 키웠다(→ 07. 환경오염 모티브) |

### 유물이 멈춘 진짜 이유 (재현 불가의 정답)

| 작중 미스터리 | 진실 |
|---|---|
| "소재를 알 수 없다" | 시간이 지나며 결합 에테르가 **고갈**돼 기능만 멈춤. 소재 자체는 분석 가능 |
| "현재 술식으로 해석 안 됨" | 단절로 에테르장 성질이 약간 변해, 옛 장을 전제로 짠 술식이 지금 장에선 안 맞음 |
| "재현 불가" | 재현이 어려운 게 아니라, **다시 채울 에테르가 그만큼 없음.** 연료 문제지 기술 문제가 아님 |

> 다시 말해 — 고대 유물은 **"방전된 배터리"** 다. 회로는 멀쩡한데 충전이 안 된다.
> (왜 충전이 안 되는가 = 단절 후 에테르장이 옅고 불안정해졌기 때문. → 07·08)

## 지역별 잔존도 (확정)

> **노르테라(북아메리카)는 흔적도 없이 소멸, 수르테라(남아메리카)는 유적·유물이 남았다.**
> 베스테리아(이탈리아권)·아시란 동부(중국권)는 유물만, 아프라 케메트(이집트)·아시란 서부 아르다샤르(메소포타미아)는 명맥을 이었다.

| 권역 (현실 모티브) | 대재앙 후 상태 | 남은 것 |
|---|---|---|
| **노르테라 (북아메리카)** | **흔적도 없이 소멸** | 거의 없음. 현 문화는 대재앙 이후 새로 발생한 사람들 |
| **수르테라 (남아메리카)** | 문명은 끊겼으나 **유적·유물 잔존** | 피라미드형 증폭 구조물, 에테르 각인 장신구, 미해독 석판 |
| **베스테리아 (이탈리아권)** | 문명 끊김, **유물·유적만** | 매몰 유적, 마기스테리움 발굴품, 에이렌발트 심부 엘프 유적 |
| **아시란 동부 (중국권)** | 문명 끊김, **유물·유적만** | 고대 기록 잔편, 강티세 고산 동굴 기록(극비) |
| **아프라 케메트 (이집트)** | **명맥 이어옴** | 나일 유역 관개 시스템 부분 가동, 신전 증폭 구조물, 오벨리스크 |
| **아시란 서부 아르다샤르 (메소포타미아)** | **명맥 이어옴** | 끊기지 않은 고대 도시·기록 계통, 현 아르다샤르 제국의 뿌리 |
| 오세라 | 지각 변동으로 대부분 수몰 | 알체라 드림타임 성지에 미발굴 반응 |

> **충돌 정리:** 옛 `19_고대문명` 문서의 "수르테라가 전 세계 최대 밀집"은 부분만 유지된다.
> 이제 **아메리카 중 북부(노르테라)는 백지, 남부(수르테라)만 잔존**으로 갱신.
> 명맥을 이은 케메트·아르다샤르가 "가장 오래된 살아있는 문명"의 위상을 가진다.

## 〔작중 인식〕

| 통념 (기존 `08`·`19` 계승) | 내용 |
|---|---|
| 고대 = 이해·재현 불가의 초월기 | 유물 작동 원리 불명 |
| 고대 연구는 독자 학문 | 칠람 동맹이 해독 최전선 |
| 일부 명맥 문명의 자부심 | 케메트·아르다샤르는 "우리는 끊기지 않았다"는 정통성 주장 |

> 작중 학자들은 "왜 유물이 안 돌아가나"를 두고 소재론·술식론으로 다투지만,
> 정답("에테르 고갈")에 도달한 자는 아직 없다. — 도달하는 순간 **유물 재가동 = 위험**이 열린다(떡밥).
