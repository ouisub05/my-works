# 솔다텐라트 (용병 국가)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 튀르키예 일대. 흑해·지중해·아시란 접경 |
| 체제 | 의회 공화국. 각 길드 수장 대표 의회 |
| 국교 | 없음. 다신교·룩스 교단 등 복수 공존 |
| 주요 종족 | 인간 다수. 실력 있는 모든 종족 존재 |
| 군사력 | 상위권. 개인 전투력 평균 높음 |
| 에테르 기술 | 중상위권. 전투 특화 에테르 기술 발달 |

---

## 용병 국가가 된 이유

특별한 건국 이념이나 정복의 역사가 아님. 단순히 **용병 길드가 많이 모인 지역**이 국가 형태를 갖추게 된 것.

| 시기 | 내용 |
|------|------|
| 초기 | 동서 교역 요충지에 자연스럽게 용병·모험가 집결 |
| 중기 | 용병 길드 수 증가. 길드 간 분쟁 조율 필요성 대두 |
| 현재 | 길드 연합 의회가 자치 기구로 발전. 사실상 국가 기능 수행 |

> 국가 정체성보다 **길드 소속감**이 시민 의식의 중심

## 의회 구조

| 항목 | 내용 |
|------|------|
| 구성 | 등록 용병 길드 수장 전원 참여 |
| 행정 수반 | 의장 — 의회에서 선출. 임기 3년. 연임 가능 |
| 권한 범위 | 대외 외교·공통 법규·길드 간 분쟁 조율만 담당 |
| 길드 자율 | 길드 내부 운영·의뢰 수주·수익은 완전 자율 |

> 대형 길드 3~4개가 사실상 솔다텐라트 실권 장악

## 용병 수출 체계

| 항목 | 내용 |
|------|------|
| 의뢰 접수 | 베스테리아·아시란 양쪽에서 의뢰 접수 |
| 파견 범위 | 개인 용병부터 수백 명 규모 용병단까지 |
| 의뢰 종류 | 전쟁 참전·경호·마물 토벌·호위·정보 수집 등 |
| 중립 원칙 | 어느 세력 편도 들지 않음. 돈 주는 쪽이 고객 |
| 동시 의뢰 금지 | 같은 전쟁에서 양측에 동시 용병 파견 금지 — 유일한 불문율 |

## 실력 유일 기준

| 항목 | 내용 |
|------|------|
| 종족 무관 | 인간·수인·하프 엘프·다크 엘프 등 실력만으로 서열 결정 |
| 출신 무관 | 귀족·평민·노예 출신 불문. 솔다텐라트 내에선 과거 없음 |
| 등급 절대 | 무인 길드 등급이 사회적 지위 결정 |

> 솔다텐라트는 베스테리아에서 **타 종족이 가장 살기 편한 곳** 중 하나
