# 카이저라이히 (제국)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 독일·오스트리아·체코·폴란드·루마니아 직할. 헝가리·우크라이나 등 영향권 |
| 체제 | 황제 중심 제국 |
| 국교 | 상투스 임페리움 교단 — 현 황제와 갈등 중 |
| 주요 종족 | 인간 다수. 늑대·사자·호랑이·개 계열 수인. 독수리 계열 소수 |
| 군사력 | 베스테리아 최강 |
| 에테르 기술 | 베스테리아 최선진. 우르그룬트와 군사 기술 협력 |

## 영토 구조

| 구분 | 범위 | 내용 |
|------|------|------|
| 황제 직할령 | 독일·오스트리아·체코·폴란드·루마니아 | 황제 직접 통치. 제국법 적용 |
| 제후령 | 직할령 내 귀족 영지 | 황제 권위 아래 자치 |

| 완충 지대 | 영향권 외곽 | 타 세력과 접경. 분쟁 잦음 |

## 실력주의 체계

| 항목 | 내용 |
|------|------|
| 신분 상승 경로 | 군 복무·에테르 실력·공훈으로 귀족 작위 취득 가능 |
| 종족 무관 | 수인·하프 엘프도 실력으로 장교·귀족 가능 |
| 에테르 사용자 우대 | 등급 높은 에테르 사용자는 종족 불문 예우 |
| 한계 | 실력주의 표방이나 실제론 인간 귀족이 기득권 장악. 타 종족의 유리 천장 존재 |
| 노예제 | 존재하나 전쟁 포로·채무 중심. 종족 기반 노예제는 공식적으로 없음 |

## 군사력

| 병종 | 특징 |
|------|------|
| 황제 친위대 | 에테르 사용자 정예. 무인·성기사 혼합 구성 |
| 제국 중장보병 | 드워프 합금 방어구. 에테르 각인 무기 지급 |
| 기병대 | 에테르 강화 군마. 수인 기병 포함 |
| 마법사 부대 | 마기스테리움 출신 다수. 포격·결계 전담 |
| 독수리 정찰대 | 독수리 계열 수인 전담 부대. 공중 정찰·기습 |

## 현 황제와 신성왕국 갈등

| 항목 | 내용 |
|------|------|
| 현 황제 성향 | 팽창주의. 세속 권력 강화. 교단 영향력 축소 추진 |
| 갈등 원인 | 황제가 교단 임명권·세금 징수권 일부 환수 시도 |
| 신성왕국 반응 | 황제 파문 경고. 속국·영향권 국가에 반제국 여론 조성 |
| 현재 상태 | 공개 전쟁은 아니나 외교·경제·종교 전선 동시 긴장 |

> 제국 내부에서도 **교단 지지 귀족** vs **황제 지지 귀족**으로 분열
> 황제는 마기스테리움을 교단 견제 카드로 활용하려는 움직임

## 대외 관계

| 대상 | 관계 |
|------|------|
| 상투스 임페리움 | 현재 긴장·갈등. 역사적 협력 관계가 균열 중 |
| 레뇨 발로아 | 경쟁·견제. 표면상 평화. 완충 지대 분쟁 잦음 |
| 에이렌발트 | 냉전. 제국 팽창으로 숲 경계 침범 사례 증가. 전면전 직전 |
| 실바 아르카나 | 비교적 중립. 교역 관계 |
| 우르그룬트 | 군사 기술 협력. 제국의 최대 무기 공급처 |
| 마기스테리움 | 황제가 영입 시도 중. 마기스테리움은 독립 유지 선호 |
| 아시란·아프라 경쟁국 | 지중해·흑해 방면 무역로·영토 분쟁 |
