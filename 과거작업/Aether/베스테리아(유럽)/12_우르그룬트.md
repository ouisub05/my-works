# 우르그룬트 (드워프 국가)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 우랄 산맥 일대. 지하 왕국 중심 |
| 체제 | 왕정. 장인 조합 실질 권력 |
| 국교 | 없음. 조상 숭배·장인 정신이 사실상 신앙 대체 |
| 주요 종족 | 드워프 단일 |
| 군사력 | 중상위권. 최고급 장비 보유. 수적으론 열세 |
| 에테르 기술 | 룬 각인·에테르 기관 베스테리아 최고 수준 |

---

## 왕국 구조

| 항목 | 내용 |
|------|------|
| 왕 | 전사 계열 필수. 전투력·결단력으로 권위 유지 |
| 장인 조합 수장 | 왕에 버금가는 권위. 경제·기술 실권 장악 |
| 왕·조합 관계 | 왕은 대외·군사, 조합은 내부·경제 분담 |
| 지하 도시 | 우랄 산맥 내부 대규모 지하 도시 다수. 각 도시마다 특화 기술 존재 |

---

## 교역소 체계

| 항목 | 내용 |
|------|------|
| 위치 | 우랄 산맥 주요 입구마다 설치 |
| 출입 제한 | 외부인은 교역소 구역까지만 허용. 내부 지하 도시 진입 불가 |
| 예외 | 특별 초청장 보유자만 내부 진입 가능. 극히 드묾 |
| 거래 방식 | 현물·금화 거래. 신용 거래 없음. 계약서 필수 |

> 교역소에서 사기·계약 위반 시 **영구 거래 금지** — 사실상 경제적 사형 선고

---

## 순수 상업 원칙

| 항목 | 내용 |
|------|------|
| 핵심 원칙 | 이익이 되면 거래. 손해면 즉시 중단. 정치·감정 개입 없음 |
| 거래 대상 | 모든 세력과 거래. 전쟁 중인 양측에 동시 거래 가능 |
| 계약 절대 | 한번 맺은 계약은 반드시 이행 |
| 교역 중단 기준 | 대금 미지급, 계약 위반, 드워프 인원 피해, 수익성 악화 |

> **"우르그룬트는 친구도 적도 없다. 거래 상대만 있을 뿐"**
