# 레뇨 발로아 (기사 왕국)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 프랑스 일대 |
| 체제 | 전통적 봉건 왕국 |
| 국교 | 상투스 임페리움 교단 — 신성왕국과 긴밀 |
| 주요 종족 | 인간 다수. 개·고양이·여우·토끼 계열 수인 |
| 군사력 | 베스테리아 2~3위권. 기사단 중심 |
| 에테르 기술 | 중상위권. 기사단 에테르 전투 특화 |

---

## 봉건 체계

| 계층 | 내용 |
|------|------|
| 왕 | 명목상 최고 권력. 실제론 대귀족 눈치 봐야 함 |
| 대귀족 | 넓은 영지 보유. 독자 기사단 운영. 왕권 견제 |
| 기사 | 귀족 아래 전투 전문 계층. 에테르 사용자 비율 높음 |
| 평민 | 농민·상인·장인 |
| 수인 | 평민과 유사한 법적 지위. 기사단 입단 가능하나 희소 |

---

## 기사단 문화

| 항목 | 내용 |
|------|------|
| 기사단 종류 | 왕 직속 기사단, 대귀족 기사단, 교단 기사단 3종류 공존 |
| 에테르 전투 | 기사의 핵심 능력. 에테르 강화 무기·방어구 운용이 기사도의 일부 |
| 기사도 정신 | 명예·신앙·충성·용기. 에테르 실력만큼 정신 수양 중시 |
| 서임 조건 | 에테르 각성 + 기사도 정신 검증 + 귀족 추천 |
| 여기사 | 존재. 남녀평등 원칙상 서임 가능. 대귀족 가문 출신 여기사 다수 |

---

## 제국과의 관계

| 시기 | 관계 |
|------|------|
| 과거 | 오랜 전쟁·영토 분쟁. 베스테리아 패권을 두고 정면 충돌 반복 |
| 제국 팽창기 | 카이저라이히가 압도적 군사력으로 레뇨 발로아 압박. 사실상 굴복 |
| 현재 | 명목상 독립국이나 제국의 속국에 가까운 취급. 왕실 혼인으로 관계 형식적 안정 |

### 현재 레뇨 발로아의 고민
- 제국과 신성왕국 갈등 속에서 **어느 편을 들 것인가**가 최대 현안
- 왕실은 혼인 외교로 제국과 관계 유지하면서 동시에 신성왕국과 종교적 연대
- 대귀족들은 친제국파·친교단파로 분열

> **"레뇨 발로아는 항상 두 주인을 섬긴다"** 는 말이 베스테리아에 돌아다님
