# 프레이 아르키펠 (해적 국가)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 영국 제도 일대 |
| 체제 | 해적왕 중심 단일 지도 체제 |
| 국교 | 없음. 바다·폭풍 정령 신앙 비공식 존재 |
| 주요 종족 | 인간·상어·갈매기 계열 수인 중심 |
| 군사력 | 해상 전투력 베스테리아 최강. 육상 전투력 낮음 |
| 에테르 기술 | 해상 전투·항해 특화. 독자 발전 |

---

## 해적왕 체제

| 항목 | 내용 |
|------|------|
| 해적왕 | 최강 해적. 전투력·카리스마·전략으로 유지 |
| 권위 유지 | 실력으로만 유지. 약해지면 도전자 등장 |
| 해적단장 회의 | 주요 해적단장 비공식 회의 |
| 계승 | 해적왕 사망·패배 시 최강자가 자연스럽게 승계 |

> 현 해적왕은 포르타 콘소르티움과 거래를 트고 안정적 수입 확보한 실용주의자

---

## 해상 세력

| 병종 | 특징 |
|------|------|
| 주력 함대 | 에테르 추진 해적선. 속도·기동력 베스테리아 최고 |
| 상어 계열 수인 부대 | 수중 전투 특화. 선저 파괴·기습 잠수 공격 |
| 갈매기 계열 수인 부대 | 공중 정찰·기습. 적 함대 동향 사전 파악 |
| 에테르 포격대 | 원거리 마법 포격 |

> 프레이 아르키펠 함대와 정면 해전에서 이긴 세력 없음
> 육상 전투는 취약 — 본거지는 사실상 난공불락

---

## 포르타 콘소르티움과의 관계 — 매수

| 항목 | 내용 |
|------|------|
| 계약 내용 | 포르타 콘소르티움 선박·관련 상인 일절 건드리지 않음 |
| 대가 | 포르타가 정기적으로 마정석·금화·물자 제공 |
| 부가 조건 | 포르타가 지정하는 경쟁 세력 선박 우선 공격 |
| 계약 성격 | 비공식. 양측 모두 공식 인정 안 함 |

> 마레 콘소르티움이 이 관계를 눈치채고 증거 확보 시도 중
> 포르타 입장에선 **"해적 보험료"** 를 내는 셈

## 약탈 대상 및 방식

| 항목 | 내용 |
|------|------|
| 주요 타깃 | 카이저라이히·마레 콘소르티움 상선. 레뇨 발로아 해안 |
| 방식 | 기습·납치·몸값 요구·화물 탈취 |
| 선별 약탈 | 무차별 약탈 아님. 대응 전력 파악 후 선별 공격 |
| 밀수 | 교단 금지 물품·마물 소재 등 밀수 루트 운영 |

---

## 대외 관계

| 대상 | 관계 |
|------|------|
| 포르타 콘소르티움 | 비공식 매수 관계. 표면상 적대 |
| 카이저라이히 | 주요 약탈 대상. 제국 해군과 충돌 잦음 |

| 솔다텐라트 | 일부 용병 고용. 실무 관계 |
| 상투스 임페리움 | 교단 선박 약탈 사례 있음. 정화단 토벌 대상 |
