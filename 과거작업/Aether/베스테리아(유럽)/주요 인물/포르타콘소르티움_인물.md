# 포르타 콘소르티움 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 의장 (Presidente)

| 항목 | 내용 |
|------|------|
| **직위** | 포르타 콘소르티움 의장. 상인 이사회 수장 |
| **에테르** | 어뎁트 중 (2단계). 마법사 계열. 실용적 에테르 운용. 전투 무관 |
| **성격** | 100년 앞을 내다보는 전략가. 현재 손해를 감수하고 미래 독점을 준비. 냉정하고 비밀이 많음 |
| **현재 상황** | 노르테라 극비 탐험 프로젝트 총괄 지휘. 아프라 독점 유지와 병행 |
| **핵심 목표** | 노르테라 교역 독점권 선점. 베스테리아 최강 상업 세력 영구 지위 확보 |
| **갈등 요소** | 극비 프로젝트에 막대한 자원 투입으로 이사회 신중파 반발. 비밀 유지 한계에 가까워짐 |

### 세부 특성
- 노르테라 존재를 알고 있는 포르타 내부 인원은 손가락에 꼽을 정도
- 마레 콘소르티움 의장을 표면상 우호 대우. 실제론 아프라 직거래 시도 봉쇄 공작 병행
- 카이저라이히 제국 재상과 비밀 채널. 아프라 독점 정치적 보호막으로 활용
- 프레이 아르키펠에 정기적 자금 공급. 마레 상선 교란 의뢰 지속
- 탐험대장을 전폭 지지. 노르테라 프로젝트의 유일한 진짜 이해자

---

## 2. 이사회 수석 이사 (Direttore Principale)

| 항목 | 내용 |
|------|------|
| **직위** | 이사회 최고참 이사. 신중파 대표 |
| **에테르** | 없음. 범인. 수십 년 교역 경험의 현장 전문가 |
| **성격** | 현실주의. 검증된 것만 신뢰. 불확실한 모험보다 안정적 수익 선호. 의장을 존중하나 동의 않음 |
| **현재 상황** | 노르테라 프로젝트 자원 투입 규모에 반발. 아프라 독점 강화에 집중 주장 |
| **핵심 목표** | 현재 아프라 교역 독점 수익 극대화. 무리한 팽창으로 기존 기반 훼손 방지 |
| **갈등 요소** | 의장의 극비 프로젝트 전모를 모름. 알게 된다면 입장 바뀔 가능성도 있음 |

### 세부 특성
- 이사회 내 가장 오랜 경력. 포르타의 아프라 독점 구조를 직접 설계한 인물 중 하나
- 말리 술탄국 직거래 시도를 가장 예민하게 감시. 자한·바라타 움직임 주시
- 의장을 신뢰하나 정보 차단에 불만. 노르테라 존재 자체는 모름
- 마레 콘소르티움과 협력 모색파. 경쟁보다 분점이 안정적이라는 입장

## 3. 정보 수장 (Capo dell'Intelligence)

| 항목 | 내용 |
|------|------|
| **직위** | 포르타 비공식 정보 조직 수장. 의장 직속 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 에테르 위장·감청 특화 |
| **성격** | 존재감 없음이 최고의 능력. 이름조차 이사회 전원이 모름. 그림자 같은 인물 |
| **현재 상황** | 마레·말리·카이저라이히 동시 감시. 노르테라 탐험대 정보 보안 총괄 |
| **핵심 목표** | 노르테라 극비 유지. 포르타 이익 위협 세력 사전 차단 |
| **갈등 요소** | 탐험대장과 정보 공유 범위 갈등. 탐험대장이 노르테라 현지 정보를 독점하려는 경향 |

### 세부 특성
- 이사회 수석 이사조차 존재를 정확히 모름. 의장만 직접 지휘
- 마레 콘소르티움 수석 협상가가 포르타의 아메리카 진출을 눈치채고 있다는 정보 파악. 대응 중
- 프레이 아르키펠 해적 조직 내부에 요원 심어둠. 마레 교란 작전 지휘
- 타이노 해연이 포르타 탐험대와 접촉했다는 사실 인지. 와바나키 보고 여부 조사 중

## 4. 탐험대장 (Capitano degli Esploratori)

| 항목 | 내용 |
|------|------|
| **직위** | 노르테라 극비 탐험대 총사령관. 포르타 탐험 전담 조직 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 항해·생존 전투 특화 |
| **성격** | 탐험가 기질. 미지에 대한 열정. 상업적 계산보다 순수한 발견 욕구. 의장과 목표 일치하나 동기 다름 |
| **현재 상황** | 노르테라 해안 근접 완료. 타이노 해연과 첫 접촉 성공. 귀환 후 보고 준비 중 |
| **핵심 목표** | 노르테라 전체 지도 완성. 교역 가능 세력 파악. 포르타를 위한 교두보 확보 |
| **갈등 요소** | 의장은 순수 상업 목적. 본인은 탐험 자체에 가치 둠. 현지 세력과의 관계 방식 의견 차이 |

### 세부 특성
- 수년간 대서양 항해. 노르테라 해안선 일부 직접 확인한 유일한 베스테리아인
- 타이노 해연과 소규모 교역 성공. 현지 신뢰 구축 초기 단계
- 노르테라가 생각보다 발달한 세력이 있다는 것 감지. 의장에게 신중한 접근 권고할 예정
- 정보 수장의 극비 통제에 답답함. 탐험 현장 판단 자율성 원함
- 마우이 해연 탐험대의 존재를 항해 중 간접 흔적으로 감지. 아직 확신 없음

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **의장 → 탐험대장** | 전폭 지지. 프로젝트 핵심 |
| **의장 → 정보 수장** | 절대 신뢰. 유일한 완전 정보 공유 |
| **의장 → 수석 이사** | 존중하나 정보 차단. 관리 대상 |
| **수석 이사 → 의장** | 존중하나 불만. 전모 파악 시도 중 |
| **정보 수장 → 탐험대장** | 통제 시도. 정보 독점 갈등 |
| **탐험대장 → 정보 수장** | 답답함. 현장 자율성 원함 |
| **수석 이사 → 정보 수장** | 존재 자체 모름 |
| **포르타 → 타이노 해연** | 소규모 교역 중. 신뢰 구축 초기 |
