# 실바 아르카나 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 건국된 지 얼마 안 된 신생 왕국. 다종족 개방 정책 기조 확고. 내부 종족 갈등 없음.

---

## 1. 왕 (Rex Silvae)

| 항목 | 내용 |
|------|------|
| **직위** | 실바 아르카나 초대 국왕. 하프 엘프. 다종족 공존 왕국 건국자 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 하프 엘프 특유의 정밀한 술식 운용 |
| **성격** | 강한 이상주의. 흔들리지 않는 신념. 온화하나 원칙에서 타협 없음. 카리스마 있음 |
| **현재 상황** | 에이렌발트의 공개 비난에 대응 방안 내부 논의 중. 신생 왕국 외교 기반 구축 병행 |
| **핵심 목표** | 다종족 공존 왕국 모델 정착. 에이렌발트 순혈주의에 맞선 반론 제시 |
| **갈등 요소** | 이상 실현을 위한 시간이 필요하나 에이렌발트 압박이 신생 왕국 기반 흔들 위험 |

### 세부 특성
- 건국 자체가 에이렌발트 순혈주의에 대한 정치적 반론
- 에이렌발트의 비난을 정면 반박할 외교적·철학적 논리 준비 중
- 마기스테리움·마레 콘소르티움과 우호 관계 구축 중. 다종족 공존 가치 전파 목적
- 카이저라이히에 대해서는 실리적 외교. 직접 충돌 회피하나 종속 거부

## 2. 왕국 외교관 (Ambassadeur Royal)

| 항목 | 내용 |
|------|------|
| **직위** | 왕국 수석 외교관. 대외 교섭 전담 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 탐지·분석 특화 |
| **성격** | 언변 탁월. 상대방의 말 속 의도를 꿰뚫음. 논쟁에서 지는 법 없음. 냉정함 |
| **현재 상황** | 에이렌발트 비난에 대한 공식 반론문 작성 중. 베스테리아 각 세력에 실바 아르카나 입장 전달 |
| **핵심 목표** | 신생 왕국의 외교적 정당성 확립. 에이렌발트 고립화 |
| **갈등 요소** | 왕의 이상주의적 접근이 외교 협상에서 걸림돌이 될 때 내심 답답함 |

### 세부 특성
- 순혈 엘프·인간·하프 엘프 세 종족 언어 모두 모국어 수준
- 에이렌발트 내부 온건파와 비밀 채널 유지 시도 중
- 마기스테리움·마레 콘소르티움 방문 외교 경험 다수
- 왕에게 현실적 타협 필요성을 조심스럽게 건의하나 왕이 수용 안 함

## 3. 왕국 학술원장 (Directeur de l'Académie)

| 항목 | 내용 |
|------|------|
| **직위** | 왕국 공식 학술 연구기관 수장. 순혈 엘프 출신 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 술식·정령 연구 특화 |
| **성격** | 학자적 냉정함. 감정보다 논리. 다종족 공존을 이념보다 학술적 명제로 접근 |
| **현재 상황** | 에이렌발트 비난에 대한 학술적 반론 연구 중. 다종족 에테르 체계 비교 연구 |
| **핵심 목표** | 순혈주의가 학술적으로도 틀렸음을 증명. 다종족 공존의 에테르적 이점 입증 |
| **갈등 요소** | 순혈 엘프 출신이면서 순혈주의 비판. 에이렌발트로부터 배신자 취급 |

### 세부 특성
- 에이렌발트 출신. 순혈주의에 회의를 느끼고 자발적으로 실바 아르카나 합류
- 에이렌발트 내부 학자들과 학술 서신 교환 지속. 학문적 교류는 이어감
- 하프 엘프 에테르 체계가 순혈 엘프와 다른 독자적 강점 있음을 연구로 증명 시도
- 마기스테리움과 공동 연구 채널 구축 중

## 4. 근위대장 (Commandant de la Garde Royale)

| 항목 | 내용 |
|------|------|
| **직위** | 왕 직속 근위대 대장. 왕국 전투력 1위 |
| **종족** | 다크 엘프. 최근 왕국에 합류. 실력으로 근위대장 자리까지 승진 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 다크 엘프 특유의 어둠·환영 에테르와 결합 |
| **성격** | 왕에 대한 절대 충성. 과묵하고 행동 중심. 순혈·하프·인간 구분 없이 실력으로만 평가 |
| **현재 상황** | 왕 호위 및 왕국 방어 총괄. 에이렌발트 침입 대비 경계 강화 중 |
| **핵심 목표** | 왕과 왕국 수호. 다종족 공존 왕국이 외부 위협에 무너지지 않도록 |
| **갈등 요소** | 다크 엘프 출신이라는 이유로 일부 외부 세력의 불신. 에이렌발트가 특히 적대적 |

### 세부 특성
- 최근 합류했음에도 압도적 실력으로 근위대장까지 오름. 왕국 다종족 공존 이념의 살아있는 증거
- 다크 엘프 고유 에테르(어둠·환영)를 전투에 적극 활용. 기존 무인과 전혀 다른 전투 스타일
- 과거 불명. 어디서 왔는지 왕만 알고 있다는 소문
- 에이렌발트 입장에서 실바 아르카나 비난의 핵심 근거 중 하나. "다크 엘프를 근위대장으로 삼은 왕국"
- 근위대 구성: 하프 엘프·인간·수인 혼합. 왕국의 다종족 이념을 군사 조직으로 구현

## 에이렌발트 비난 대응 논쟁

실바 아르카나 내부의 핵심 현안.

| 입장 | 주장 인물 | 내용 |
|------|----------|------|
| **정면 반박** | 왕·학술원장 | 공개 성명·학술 논문으로 순혈주의 반론. 베스테리아 전체에 알림 |
| **무시·침묵** | 근위대장 | 비난에 반응하는 것 자체가 에이렌발트 격상. 실력으로 증명 |
| **외교적 대응** | 외교관 | 비난보다 지지 세력 확보. 마레·마기스테리움 연대로 에이렌발트 고립 |

> 현재 왕은 세 방향 모두 병행하는 방침. 외교관은 자원 분산 우려

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 근위대장** | 절대 신뢰. 건국 동지 |
| **왕 → 외교관** | 신뢰. 현실적 조언에 귀 기울이나 수용은 선별적 |
| **왕 → 학술원장** | 학술 연구 지지. 순혈 엘프 출신 합류에 상징적 의미 부여 |
| **외교관 ↔ 학술원장** | 협력. 각자 외교·학술 경로로 에이렌발트 대응 |
| **근위대장 → 외교관** | 존중하나 외교 우선 방침에 답답함 |
| **학술원장 → 에이렌발트** | 배신자 취급받으나 학술 교류는 지속 |
