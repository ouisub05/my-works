# 레뇨 발로아 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 왕 (Roi)

| 항목 | 내용 |
|------|------|
| **직위** | 레뇨 발로아 국왕. 명목상 독립 왕국 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 전투보다 정치·외교 특화 |
| **성격** | 온화해 보이나 속은 냉철. 굴욕을 참는 것이 전략임을 이해하는 인물. 감정 관리 탁월 |
| **현재 상황** | 제국 압박 표면 수용. 내부적으로 독립 세력 규합·실력 축적 중. 기회 대기 |
| **핵심 목표** | 제국으로부터 실질적 독립. 기사 귀족 통제권 강화. 룩스 교단과 적절한 거리 유지 |
| **갈등 요소** | 독립 의지와 현실적 한계 사이. 너무 빨리 움직이면 제국 응징. 너무 늦으면 친제국파가 왕권 잠식 |

### 세부 특성
- 즉위 초 제국에 강하게 저항했다 참패한 경험 있음. 이후 노선 완전 전환
- 겉으로는 제국에 고분고분. 실제론 독립파 귀족·기사단과 비밀 연계 유지
- 룩스 교단의 지원 제안을 받고 있으나 교단 개입이 또 다른 종속이 될 것을 우려
- 왕국 최강 기사를 개인적으로 신임. 군부 내 유일한 확실한 아군

## 2. 왕국 재무상 (Grand Trésorier)

| 항목 | 내용 |
|------|------|
| **직위** | 왕국 재정·행정 총괄. 친제국파 귀족 대표 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 경제·행정 전문가 |
| **성격** | 능글맞음. 항상 웃는 얼굴. 실리만 추구. 충성 대상은 왕국이 아닌 자신의 이익 |
| **현재 상황** | 제국과 교역로 독점 계약 체결. 왕국 재정 일부를 사실상 장악 |
| **핵심 목표** | 제국과의 관계 유지로 개인·가문 이익 극대화. 독립은 리스크로 인식 |
| **갈등 요소** | 왕이 독립 움직임 강화할수록 자신의 이익 기반 흔들림. 제국 정보국과 내통 의혹 |

### 세부 특성
- 왕국 귀족 중 제국 황제를 직접 알현한 몇 안 되는 인물
- 표면상 왕에게 충성하나 왕의 비밀 독립 준비를 제국에 흘릴 가능성
- 친제국파 귀족 10여 명의 실질적 대표. 의회 내 가장 큰 파벌
- 왕국 최강 기사를 경계. 기사가 왕의 군사력이 될까봐 방해 공작 시도

## 3. 독립파 수장 (Duc de la Liberté)

| 항목 | 내용 |
|------|------|
| **직위** | 왕국 남부 대영주. 독립파 귀족 연합 비공식 수장 |
| **에테르** | 엘리트 중 (5단계). 무인 계열 |
| **성격** | 불같은 성격. 직선적. 타협 모름. 제국 혐오감 노골적. 왕의 신중함에 답답해함 |
| **현재 상황** | 독립파 귀족 규합 중. 왕보다 더 빠른 속도로 독립 추진 원함 |
| **핵심 목표** | 제국으로부터 완전 독립. 상투스임페리움·마레와 군사 동맹 체결 |
| **갈등 요소** | 왕과 방향은 같으나 속도 차이로 갈등. 무모한 행동이 왕의 계획 망칠 위험 |

### 세부 특성
- 제국 원정군에 가족을 잃은 개인적 원한 있음. 감정이 판단을 흐리는 경우 있음
- 룩스 교단과 적극 연대 추진 중. 왕이 꺼리는 교단 개입을 오히려 환영
- 왕국 남부 요새 지대 실질 통제. 독립 전쟁 시 핵심 군사 거점
- 왕국 최강 기사를 존경. 독립 전쟁의 군사적 핵심으로 기대

## 4. 왕국 최강 기사 (Premier Chevalier)

| 항목 | 내용 |
|------|------|
| **직위** | 왕 직속 근위 기사단장. 왕국 전투력 1위 |
| **에테르** | 엑스퍼트 하 (7단계). 성기사 계열. 신성력+에테르 병행 |
| **성격** | 기사도 철저히 준수. 명예·의리 중시. 왕에 대한 충성심이 가치관 최우선 |
| **현재 상황** | 왕 직속으로 근위 기사단 통솔. 제국 압박 상황에서 왕국 방어선 핵심 |
| **핵심 목표** | 왕과 왕국 수호. 개인적으로는 진정한 기사도의 실현 |
| **갈등 요소** | 기사도 원칙과 현실 정치 사이. 왕의 굴욕 감내 전략이 기사도적으로 옳은지 내적 갈등 |

### 세부 특성
- 룩스 교단 정규 성기사 훈련 출신이나 교단보다 왕에게 충성
- 신성력·에테르 병행 운용. 완전 쌍도는 아니나 둘 다 어느 정도 운용하는 희귀 케이스
- 카이저라이히 검성·북부 대공과 실력 비교 대상으로 거론됨. 직접 맞붙은 적 없음
- 독립파 수장이 자신을 독립 전쟁 선봉으로 내세우려는 것에 부담감 느낌

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 최강 기사** | 유일한 확실한 아군. 개인적 신임 |
| **왕 → 재무상** | 불신하나 재정 능력 필요. 감시 중 |
| **왕 → 독립파 수장** | 방향 같으나 속도 차이로 갈등. 통제 필요한 아군 |
| **재무상 ↔ 독립파 수장** | 적대. 친제국 vs 독립파 갈등의 핵심 축 |
| **독립파 수장 → 최강 기사** | 존경·기대. 독립 전쟁 군사 핵심으로 원함 |
| **최강 기사 → 독립파 수장** | 목표 공감하나 무모함 경계 |
| **재무상 → 최강 기사** | 경계·방해. 왕의 군사력이 될까봐 견제 |
| **카이저라이히 황제 → 레뇨 발로아** | 속국으로 관리. 독립 움직임 주시 중 |
