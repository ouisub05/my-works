# 솔다텐라트 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 총독 (Generalkommandant)

| 항목 | 내용 |
|------|------|
| **직위** | 솔다텐라트 최고 행정·군사 수장. 용병 길드 대표 회의 선출 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 전투보다 지휘·행정 특화 |
| **성격** | 실용주의. 용병이 모이는 곳에 돈이 모인다는 철학. 이념 없음. 수익과 안정이 전부 |
| **현재 상황** | 베스테리아·아시란 양측 의뢰 균형 유지 중. 길드별 주도권 경쟁 중재 역할 |
| **핵심 목표** | 솔다텐라트를 전 세계 용병 허브로 유지. 어느 세력에도 종속되지 않는 중립 보장 |
| **갈등 요소** | 길드별 주도권 경쟁이 심화될수록 중재 비용 증가. 특정 길드 과도한 성장 억제 필요 |

### 세부 특성
- 용병 출신이 아닌 행정관 출신. 솔다텐라트 내 이례적 총독
- 세금·통행세·의뢰 수수료로 국가 재정 운영. 전쟁보다 경제 논리
- 베스테리아·아시란 양측 모두에 정보 팔지 않는다는 원칙. 신뢰도 높음
- 은퇴 용병을 솔다텐라트에 정착시킨 장본인. 온갖 예우로 설득. 최대 외교 성과로 자부

## 2. 황금 방패 길드 마스터 (Gildenmeister)

| 항목 | 내용 |
|------|------|
| **직위** | 베스테리아 최대 용병 길드 황금 방패 솔다텐라트 지부장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 사업가 기질. 의뢰 수익 극대화가 최우선. 실력 있는 용병 스카우트에 공격적 |
| **현재 상황** | 베스테리아 의뢰 물량 독점 시도. 아시란계 길드와 주도권 경쟁 심화 |
| **핵심 목표** | 황금 방패 솔다텐라트 지부를 전체 최대 길드로 키움. 총독직 간접 장악 |
| **갈등 요소** | 아시란계 길드 마스터와 노골적 경쟁. 총독의 중재에 표면 복종. 실제론 우회 |

### 세부 특성
- 카이저라이히·레뇨 발로아 전쟁 의뢰를 양측 모두에서 수주하는 양다리 전략
- 국경 기사단장을 자기 길드로 영입 시도했으나 거절당한 전례. 감정 앙금 남음
- 솔다텐라트 내 인간·수인 혼합 용병 다수 보유. 다종족 편견 없음. 실력만 봄

## 3. 아시란계 길드 마스터 (Doğu Gildesi Ustası)

| 항목 | 내용 |
|------|------|
| **직위** | 아시란 출신 용병 길드 연합 솔다텐라트 대표 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 사막·고원 전투 특화 |
| **성격** | 과묵하고 신중. 행동 전 철저히 계산. 베스테리아계 길드의 공격적 팽창에 냉소적 |
| **현재 상황** | 아시란 의뢰 물량 유지하며 베스테리아계 길드 견제. 총독과 협력 관계 |
| **핵심 목표** | 아시란계 용병 입지 유지. 베스테리아계 독점 저지 |
| **갈등 요소** | 황금 방패 길드 마스터와 노골적 경쟁. 총독의 중재 정책 지지하나 내심 유리한 쪽 원함 |

### 세부 특성
- 아르다샤르·텡그리 칸국 접경 의뢰 전문. 베스테리아계가 못 하는 아시란 내륙 의뢰 독점
- 수인 용병 다수 보유. 사막·초원 환경 특화 전투 집단
- 국경 기사단장과 개인적 친분. 아시란 출신 용병 중 기사단장에게 인정받은 몇 안 되는 인물

## 4. 국경 기사단장 (Grenzritter-Kommandant)

| 항목 | 내용 |
|------|------|
| **직위** | 솔다텐라트 국경 수비대 단장. 실질 방어 전담 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 국경 방어·진지전 특화 |
| **성격** | 원칙주의. 규율 철저. 용병 국가지만 국경 수비만큼은 군인처럼 운영 |
| **현재 상황** | 베스테리아·아시란 양측 접경 동시 관리. 은퇴 용병과 협력 관계 |
| **핵심 목표** | 솔다텐라트 영토 보전. 어느 세력도 무력으로 침범 못 하도록 |
| **갈등 요소** | 길드 마스터들이 국경 수비대 인력을 의뢰 병력으로 빼가려는 시도에 반발 |

### 세부 특성
- 용병 출신이나 현재는 완전히 수비대 지휘관 정체성
- 은퇴 용병을 깊이 존경. 조언 자주 구함. 실질적 사제 관계에 가까움
- 황금 방패 길드 마스터와 갈등. 수비대 인력 빼가기 시도 반복

## 5. 은퇴 용병 (Der Legendäre)

| 항목 | 내용 |
|------|------|
| **직위** | 공식 직위 없음. 솔다텐라트 거주 전설적 인물 |
| **에테르** | 마스터 하 (10단계). 무인 계열. 전성기엔 마스터 중 근접했다는 설 |
| **나이** | 고령. 전성기 지났으나 현역 최상위권 |
| **성격** | 욕심 없음. 싸움에서 완전히 물러서지 못하는 전사 기질. 후진 양성에 관심 |
| **현재 상황** | 은퇴 후 솔다텐라트 정착. 어느 조직에도 소속 안 됨. 그냥 살고 있음 |
| **핵심 목표** | 여생을 평온하게. 그러나 진정한 실력자가 나타나면 마지막 한 번 더 싸우고 싶은 마음 |
| **갈등 요소** | 각 길드의 영입 시도. 특정 세력 소속 자체를 거부. 자유로운 말년 원함 |

### 세부 특성
- 수십 년 전 베스테리아 전역을 누빈 전설적 용병. 황제·왕족도 의뢰한 전력
- 카이저라이히 검성·북부 대공이 어린 시절 한 번씩 찾아와 가르침 청한 전례
- 어느 세력에도 소속되지 않는 원칙. 총독이 온갖 예우로 솔다텐라트에 머물도록 설득 성공
- 황금 방패 길드 마스터의 영입 거절. 개인적 감정은 없음
- 진정한 강자 앞에서만 눈빛이 살아남. 카이저라이히 황제를 유일하게 인정하는 존재 중 하나
- 국경 기사단장의 실질적 스승. 공식 관계는 아님

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **총독 → 은퇴 용병** | 온갖 예우로 솔다텐라트 정착 설득 성공. 최대 외교 성과 |
| **총독 → 황금 방패 길드 마스터** | 중재 대상. 팽창 억제 필요 |
| **총독 → 아시란계 길드 마스터** | 협력. 균형추 역할 기대 |
| **황금 방패 길드 마스터 ↔ 아시란계 길드 마스터** | 노골적 경쟁. 의뢰 주도권 다툼 |
| **황금 방패 길드 마스터 → 은퇴 용병** | 영입 거절 앙금. 표면 존중 |
| **황금 방패 길드 마스터 → 국경 기사단장** | 인력 빼가기 시도. 갈등 |
| **아시란계 길드 마스터 → 은퇴 용병** | 개인적 친분. 유일하게 인정받은 아시란계 |
| **국경 기사단장 → 은퇴 용병** | 깊은 존경. 실질적 사제 관계 |
| **은퇴 용병 → 모든 길드** | 소속 거부. 개인 원칙 |
