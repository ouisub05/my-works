# 에이렌발트 주요 인물

## 1. 군주 (Waldherrscher)

| 항목 | 내용 |
|------|------|
| **직위** | 에이렌발트 군주. 순혈 엘프 왕국 수장 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 삼림 에테르 운용 특화 |
| **성격** | 냉혹한 강경주의자. 감정 없는 듯한 외면. 순혈 엘프의 우월성을 진심으로 믿음 |
| **현재 상황** | 카이저라이히 제국 압박 + 실바 아르카나 건국으로 이중 위기. 고립 유지 정책 강행 |
| **핵심 목표** | 에이렌발트 순혈 엘프 문화·혈통 순수 보존. 외부 오염 차단 |
| **갈등 요소** | 고립 정책으로는 제국 압박을 장기적으로 버티기 어렵다는 현실. 외교파 왕족의 도전 |

### 세부 특성
- 수백 년 된 순혈 엘프 혈통 명가 출신. 혈통의 순수성이 곧 권위의 근거
- 실바 아르카나를 단순한 왕국이 아닌 **엘프 문화 오염의 상징**으로 규정. 공개 비난 주도
- 다크 엘프 근위대장 임명을 에이렌발트 비난의 핵심 소재로 활용
- 외교파 왕족의 존재를 알면서도 숙청 않음. 필요 시 협상 카드로 활용 가능성
- 강경파 전사(궁수)를 군사적 상징으로 활용. 전투보다 정치적 도구

## 2. 외교파 왕족 (Prinz/Prinzessin des Waldes)

| 항목 | 내용 |
|------|------|
| **직위** | 군주의 직계 왕족. 외교파 비공식 수장 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 정령 친화 특화 |
| **성격** | 조용하고 관찰적. 말보다 행동. 순혈주의 자체는 부정 않으나 고립 정책에 회의적 |
| **현재 상황** | 표면상 군주 정책 따름. 내부적으로 외교파 귀족 규합 중. 실바 아르카나 연구 중 |
| **핵심 목표** | 에이렌발트 생존. 고립보다 선택적 외교로 제국 압박 완화 |
| **갈등 요소** | 군주(친족)에 반하는 행보. 순혈주의 포기 아닌 생존 전략이지만 강경파에게 배신으로 인식 |

### 세부 특성
- 군주와 혈연 관계. 숙청 않는 이유 중 하나
- 실바 아르카나 학술원장과 비밀 서신 교환 중. 학술 교류 명목
- 마기스테리움 방문 경험 있음. 외부 세계에 대한 이해도 에이렌발트 내 최고 수준
- 강경파 전사(궁수)와 관계 냉담. 서로 경계

## 3. 삼림 수호대 총사령관 (Oberkommandant der Waldwacht)

| 항목 | 내용 |
|------|------|
| **직위** | 에이렌발트 전군 총사령관. 삼림 방어 전담 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 삼림 전투 극한 특화 |
| **성격** | 군인 중의 군인. 전략가. 감정 철저히 배제. 에이렌발트 방어에 생을 바침 |
| **현재 상황** | 카이저라이히 북부 대공과 수십 년 대치. 방어선 유지 중 |
| **핵심 목표** | 에이렌발트 삼림 방어. 제국 침입 완전 차단 |
| **갈등 요소** | 고립 정책 지지하나 외교파 왕족의 주장도 군사적으로 이해. 중립적 위치 |

### 세부 특성
- 카이저라이히 북부 대공과 수십 년 대치한 숙적. 서로 실력 인정
- 강경파이나 현실적 군인. 외교파의 주장을 군사 전략 관점에서 수용 가능성 있음
- 강경파 전사(궁수)를 전술 자산으로 평가. 정치적 관계는 거리 유지
- 삼림 정령 연계 전술 운용. 에이렌발트 방어의 실질적 핵심

## 4. 강경파 전사 — 삼림의 궁수 (Waldschütze)

| 항목 | 내용 |
|------|------|
| **직위** | 에이렌발트 강경파 상징. 군주 직속 특수 전사 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 궁술·에테르 원거리 공격 극한 특화 |
| **성격** | 불같은 순혈 신념. 타 종족에 대한 경멸 노골적. 외교파를 배신자로 규정. 충동적 |
| **현재 상황** | 실바 아르카나 근위대장(다크 엘프)을 최우선 적대 대상으로 지목. 도발 반복 중 |
| **핵심 목표** | 순혈 엘프의 우월성 전장에서 증명. 다크 엘프 근위대장 타도 |
| **갈등 요소** | 군주의 정치적 계산을 이해 못함. 도발이 외교 상황 악화시킬 때 충돌 |

### 세부 특성
- 베스테리아 내 최고 수준의 궁술 실력. 에테르 각인 화살 운용 독보적
- 실바 아르카나 다크 엘프 근위대장을 직접 적대. 공개 결투 신청 이력 있음
- 총사령관 지휘 받으나 독단 행동 잦음. 군주만 통제 가능
- 외교파 왕족을 노골적으로 경멸. 왕족 신분이라 직접 충돌 자제하나 한계에 다가가는 중
- 수백 년 전 엘프 전사 명가의 마지막 후손이라는 자부심

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **군주 → 외교파 왕족** | 견제하나 숙청 않음. 협상 카드로 보유 |
| **군주 → 총사령관** | 신뢰. 방어선 유지의 핵심 |
| **군주 → 강경파 전사** | 정치적 도구로 활용. 통제 필요한 자산 |
| **외교파 왕족 ↔ 강경파 전사** | 냉담·상호 경계. 직접 충돌 일보 직전 |
| **총사령관 → 강경파 전사** | 전술 자산 인정. 정치적 거리 유지 |
| **총사령관 → 외교파 왕족** | 중립. 군사적으로는 외교파 주장 이해 |
| **강경파 전사 → 실바 아르카나 근위대장** | 최우선 적대. 결투 신청 이력 |
| **총사령관 ↔ 카이저라이히 북부 대공** | 수십 년 숙적. 상호 실력 인정 |
