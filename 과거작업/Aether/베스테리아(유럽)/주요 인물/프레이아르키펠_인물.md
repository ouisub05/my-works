# 프레이 아르키펠 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 해적왕 (Piratenkönig)

| 항목 | 내용 |
|------|------|
| **직위** | 프레이 아르키펠 해적왕. 해적 연합 최고 수장 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 해상 전투·기동 특화 |
| **성격** | 거칠고 자유분방한 겉모습. 속으로는 치밀한 전략가. 누구에게도 고개 숙이기 싫어함 |
| **현재 상황** | 포르타 자금 수령 중이나 독자 정보망·세력 기반 구축 병행. 독립 시기 조율 중 |
| **핵심 목표** | 포르타 종속 탈피. 북해·대서양 완전 독자 해상 패권 확립 |
| **갈등 요소** | 포르타 자금 끊으면 당장 운영 차질. 독립 전 충분한 기반 없이 움직이면 역풍 |

### 세부 특성
- 포르타 콘소르티움 정보 수장의 요원이 내부에 심어져 있다는 것을 알면서 모른 척
- 포르타에 마레 상선 교란 의뢰를 수행하면서 마레 정보도 수집. 양쪽 정보 축적
- 최강 해적 선장(상어 수인)을 통제하지 못함. 연합 내 가장 큰 리스크이자 최대 전력
- 와바나키 공화국이 북방 해상 감시 강화한다는 정보 입수. 포르타 진출 시기와 연관 주시

## 2. 해적왕 부관 (Erster Maat)

| 항목 | 내용 |
|------|------|
| **직위** | 해적왕 직속 부관. 연합 실무 총괄 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 항법·기상 술식 특화 |
| **성격** | 충성심 절대적. 해적왕의 의도를 말 없이 파악. 실무 능력 탁월. 감정 드러내지 않음 |
| **현재 상황** | 독립 준비 실무 총괄. 포르타 요원 역감시 담당 |
| **핵심 목표** | 해적왕 보좌. 독립 기반 조용히 구축 |
| **갈등 요소** | 최강 해적 선장 통제 불가. 선장이 독단 행동 시 수습 역할 떠안음 |

### 세부 특성
- 기상·해류 에테르 술식으로 항로 최적화. 프레이 아르키펠 항해 능력의 핵심
- 포르타 요원 동선 역추적 성공. 해적왕에게 보고했으나 해적왕은 알면서 방치 결정
- 최강 해적 선장과 관계 불편. 선장이 명령 무시할 때마다 충돌
- 마우이 해연 항해 기술에 관심. 동방 항로 연구 중

## 3. 선단 대표 회의 (Kapitänsrat) 의장

| 항목 | 내용 |
|------|------|
| **직위** | 각 해적 선단 선장 대표 회의 의장. 해적왕 다음 실질 영향력 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 노회한 협상가. 해적왕과 각 선단 사이 중간 관리자 역할. 자신의 선단 이익 최우선 |
| **현재 상황** | 포르타 의존 유지 주장. 독립 리스크를 현실적으로 계산 |
| **핵심 목표** | 자신의 선단 수익 극대화. 연합 내 영향력 유지 |
| **갈등 요소** | 해적왕 독립 노선에 반대. 그러나 공개 반발은 최강 해적 선장 눈치 봐서 자제 |

### 세부 특성
- 포르타 의존 유지파의 실질 대표. 자금 안정성 중시
- 각 선단 선장들 사이 중재 역할. 선단 주도권 경쟁 조율 시도
- 최강 해적 선장을 두려워함. 공개 언급은 하지 않음

## 4. 최강 해적 선장 (Weißer Hai)

| 항목 | 내용 |
|------|------|
| **직위** | 프레이 아르키펠 최강 선단 선장. 연합 내 전투력 1위 |
| **종족** | 상어 계열 수인. 백상아리 계열 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 수중·해상 전투 극한 특화 |
| **성격** | 순수한 전투 본능. 강한 자에 흥미. 약한 자에 무관심. 명령보다 본능 우선 |
| **현재 상황** | 독자 선단으로 북해 제압 중. 해적왕 명령도 흥미 없으면 무시 |
| **핵심 목표** | 강한 상대와 싸우는 것. 바다 위 최강자 증명 |
| **갈등 요소** | 연합 소속이나 실질 독립 세력. 해적왕도 직접 충돌 회피 |

### 세부 특성
- 상어 계열 수인 특성 극한 발현. 수중·해상 전투에서 타의 추종 불허
- 마레 콘소르티움 해군 대장과 수차례 교전. 유일하게 해군 대장을 후퇴시킨 전례
- 포르타 의뢰를 수행하다가 흥미 잃으면 중간에 이탈하는 경우 있음. 포르타 정보 수장 골칫거리
- 이스칼드 분트 설원 최강 전사의 소문 들음. 바다 아닌 육지 최강자에게 흥미 생김
- 해적왕이 독립 추진 시 자연스럽게 최대 전력이 될 것이나 통제는 불가능

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **해적왕 → 부관** | 절대 신뢰. 독립 준비 핵심 공유 |
| **해적왕 → 최강 해적 선장** | 통제 불가. 리스크이자 최대 전력. 자극 않고 방치 |
| **해적왕 → 선단 대표 회의 의장** | 관리 대상. 포르타 의존파 견제 |
| **부관 → 최강 해적 선장** | 통제 불가. 수습 역할 떠안음. 불편한 관계 |
| **선단 대표 회의 의장 → 최강 해적 선장** | 두려움. 공개 언급 회피 |
| **최강 해적 선장 → 마레 해군 대장** | 반복 교전. 유일하게 후퇴시킨 상대 |
| **최강 해적 선장 → 이스칼드 설원 최강 전사** | 흥미 생김. 미면 |
| **포르타 정보 수장 → 최강 해적 선장** | 골칫거리. 통제 불가 |
