# 마레 콘소르티움 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 의장 (Archon)

| 항목 | 내용 |
|------|------|
| **직위** | 마레 콘소르티움 의장. 상인 의회 수장. 임기제 선출직 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열. 탐지·분석 특화. 전투보다 협상 도구로 활용 |
| **성격** | 쾌활하고 개방적인 외면. 속으론 치밀한 계산. 모든 사람을 잠재적 거래 상대로 봄 |
| **현재 상황** | 새 교역 루트 개척 적극 추진. 포르타 독점 균열 시도. 자한·바라타와 직거래 협상 중 |
| **핵심 목표** | 지중해 교역 패권 강화. 포르타 콘소르티움의 아프라 독점 우회 루트 확보 |
| **갈등 요소** | 교역 확장이 카이저라이히·포르타의 이해와 충돌. 정치적 중립 훼손 우려 |

### 세부 특성
- 다크 엘프 상단주와 인간 상인파 사이에서 균형 유지하는 것이 의장직 핵심 과제
- 포르타 콘소르티움 의장과 표면상 우호. 실제론 아프라 루트를 두고 치열한 암투
- 카이저라이히 제국 재상과 비밀 채널 유지. 정보 거래 병행
- 연임 중. 교역 확장 실적으로 파벌 초월 지지 확보

## 2. 수석 협상가 (Protos Diplomatikos)

| 항목 | 내용 |
|------|------|
| **직위** | 대외 교섭 전담 수석 협상가. 의장 직속 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 에테르 감응·거짓말 탐지 특화 |
| **성격** | 말 한마디 허투루 하지 않음. 침묵도 협상 도구. 상대가 원하는 것을 먼저 파악하고 이용 |
| **현재 상황** | 자한 술탄국·바라타 연방과 직거래 협상 진행 중. 포르타 우회 루트 핵심 실무자 |
| **핵심 목표** | 마레 교역망 확장. 새 루트 확보로 포르타 의존도 축소 |
| **갈등 요소** | 다크 엘프 상단주와 정보 공유 범위 갈등. 서로 패를 숨김 |

### 세부 특성
- 에테르로 상대 감정·거짓말 감지. 협상 테이블에서 사실상 무패
- 탐문사 조합 백운과 연계. 정보 수집·교환 병행
- 포르타 콘소르티움의 아메리카 진출 극비 정보를 눈치채고 있다는 소문
- 다크 엘프 상단주와 경쟁 관계. 의장 후계 자리를 두고 장기전 중

## 3. 해군 대장 (Nauarchos)

| 항목 | 내용 |
|------|------|
| **직위** | 마레 콘소르티움 해군 총사령관. 지중해 항로 방어 전담 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 해상 전투 극한 특화 |
| **성격** | 호탕하고 직선적. 바다 위에서는 절대 권위. 육지 정치엔 관심 없음 |
| **현재 상황** | 지중해 교역로 해적 소탕 + 포르타 해군과 암묵적 긴장 관계 유지 |
| **핵심 목표** | 지중해 해상 패권. 마레 교역로 완전 장악 |
| **갈등 요소** | 교역 확장으로 새 항로 개척 시 방어 범위 확대. 전력 분산 우려 |

### 세부 특성
- 프레이 아르키펠 해적 출신. 마레에 귀순 후 실력으로 해군 대장까지 오름
- 포르타 콘소르티움 해군과 수차례 충돌 경험. 상대 전술 완전 파악
- 선원·해병 사이 절대적 인기. 파벌 경쟁과 무관한 독자 세력 기반
- 다크 엘프 상단주와 우호적. 해상 운송 협력 관계

## 4. 다크 엘프 상단주 (Megas Emporos)

| 항목 | 내용 |
|------|------|
| **직위** | 마레 콘소르티움 내 다크 엘프 상인 연합 수장. 연합 내 최대 자산 보유 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 환영·탐지 특화. 정보전 최강 |
| **성격** | 우아하고 격식 있음. 감정을 읽기 어려움. 장기적 이익을 위해 단기 손해를 감수 |
| **현재 상황** | 다크 엘프 상인 파벌 결속 강화. 의장 선거 다음 임기 출마 준비 중 |
| **핵심 목표** | 마레 내 다크 엘프 상인 지위 공고화. 의장직 획득으로 연합 주도권 장악 |
| **갈등 요소** | 수석 협상가와 의장 후계 경쟁. 인간 상인파의 견제 |

### 세부 특성
- 마레 내 다크 엘프 상인 조합 실질 운영. 연합 전체 교역량의 30% 이상 장악
- 에테르 환영 마법을 정보전에 활용. 위장 상인·이중 교섭 능숙
- 베스테리아 다크 엘프 전체 네트워크와 연결. 마레 이외 지역 정보 수집 능력 탁월
- 실바 아르카나 근위대장(다크 엘프)과 비공식 연결 가능성. 확인 안 됨
- 해군 대장과 우호적. 해상 운송 독점 계약 체결

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **의장 → 수석 협상가** | 신뢰. 교역 확장 핵심 실무자 |
| **의장 → 해군 대장** | 신뢰. 독자 세력 기반 인정 |
| **의장 → 다크 엘프 상단주** | 균형 유지. 견제하되 배제 않음 |
| **수석 협상가 ↔ 다크 엘프 상단주** | 의장 후계 경쟁. 상호 패 숨김 |
| **해군 대장 ↔ 다크 엘프 상단주** | 우호. 해상 운송 협력 |
| **해군 대장 → 수석 협상가** | 중립. 정치 무관심 |
| **다크 엘프 상단주 → 실바 아르카나 근위대장** | 비공식 연결 가능성. 미확인 |
