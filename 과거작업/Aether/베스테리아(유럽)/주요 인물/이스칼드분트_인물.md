## 1. 대족장 (Hochhäuptling)

| 항목 | 내용 |
|------|------|
| **직위** | 이스칼드 분트 대족장. 부족 연합 최고 수장 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 혹한·설원 환경 강화 특화 |
| **성격** | 강인하고 단호. 전통에 대한 자부심 강함. 변화를 두려워하진 않으나 신중히 접근 |
| **현재 상황** | 설원 문화·정령 신앙 고수하며 부족 연합 통합 유지. 왕국화 가능성 내부 논의 중 |
| **핵심 목표** | 이스칼드 분트 전통 수호. 동시에 느슨한 부족 연합의 한계 극복 방안 모색 |
| **갈등 요소** | 왕국화는 전통 부족 자율성 침해 가능성. 그러나 현 체제로는 외부 압박 장기 대응 한계 |

### 세부 특성
- 여러 부족장 중 가장 강한 실력과 카리스마로 대족장 자리 차지
- 룩스 교단의 북방 선교 시도를 수차례 물리침. 교단에 대한 적대감 뿌리 깊음
- 왕국화 논의는 극비. 부족장 일부만 알고 있음. 전통 수호파 부족장들 반발 예상
- 설원 최강 전사를 군사적 오른팔로 신뢰. 왕국화 시 군사 조직 개편 핵심 인물로 구상

## 2. 부족장 회의 의장 (Ratsvorsitzender)

| 항목 | 내용 |
|------|------|
| **직위** | 부족장 회의 의장. 연합 내 대족장 다음 서열 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 정령 연계 술식 특화 |
| **성격** | 노련한 중재자. 부족 간 이해관계 조율 전문. 대족장의 왕국화 구상에 가장 복잡한 심경 |
| **현재 상황** | 부족장 회의 운영 총괄. 왕국화 논의 극비 유지 협력 중이나 내심 반대 |
| **핵심 목표** | 부족 연합 체제 유지. 각 부족 자율성 보호 |
| **갈등 요소** | 대족장을 존중하나 왕국화는 부족 전통 해체라고 봄. 공개 반대는 못 하는 상황 |

### 세부 특성
- 수십 년간 부족 간 분쟁 중재 경험. 이스칼드 분트 내 인망 높음
- 룩스 교단 대응에서는 대족장과 완전히 일치. 온건 대응보다 강경 배척 지지
- 설원 최강 전사와 오랜 협력 관계. 전사를 신뢰하나 왕국화 논의에서 같은 편일지 불확실

## 3. 정령사 수장 (Geistbeschwörer)

| 항목 | 내용 |
|------|------|
| **직위** | 이스칼드 분트 정령 신앙 최고 권위자. 샤먼 계열 수장 |
| **에테르** | 엘리트 중 (5단계). 정령사 계열. 설원·빙설 정령 최고 친화도 |
| **성격** | 신비롭고 과묵. 정령과 대화하는 시간이 사람과 대화하는 시간보다 많음. 세속 권력 무관심 |
| **현재 상황** | 이스칼드 정령 신앙 의식 총괄. 설원 정령들의 이상 징후 감지 중 |
| **핵심 목표** | 정령 신앙 수호. 정령과의 계약 유지. 외부 에테르 오염 차단 |
| **갈등 요소** | 최근 설원 정령들이 불안해하는 징후 포착. 원인이 [E] 마물 급증과 연관 가능성 의심 |

### 세부 특성
- 왕국화 논의에 완전 무관심. 정령 신앙만 지켜진다면 어떤 체제든 상관없다는 입장
- 룩스 교단의 신성력과 정령력이 충돌한다는 것을 직접 경험. 교단 배척 신념 확고
- 설원 정령 이상 징후를 대족장에게 보고했으나 아직 원인 불명
- 이스칼드 분트 내 [E] 마물 목격 증가와 정령 불안 연관성 조사 중

## 4. 설원 최강 전사 (Eiskrieger)

| 항목 | 내용 |
|------|------|
| **직위** | 이스칼드 분트 최강 전투 직군. 대족장 직속 전사 |
| **에테르** | 엑스퍼트 상 (9단계). 무인 계열. 인간·수인 혼합 전투 방식 독자 개발 |
| **종족** | 인간과 수인(늑대 계열) 혼혈. 이스칼드 분트 혼합 문화의 상징적 존재 |
| **성격** | 자유롭고 호탕. 싸움을 즐김. 전통과 변화 모두 받아들이는 열린 사고 |
| **현재 상황** | 대족장 직속으로 연합 방위 총괄. 왕국화 논의에서 대족장 지지 |
| **핵심 목표** | 이스칼드 분트 수호. 개인적으로는 베스테리아 최강자들과 겨뤄보고 싶은 욕구 |
| **갈등 요소** | 왕국화 지지하나 부족장 회의 의장 등 전통파와 갈등 예상. 혼혈 출신이라 전통파 일부 반발 |

### 세부 특성
- 인간+늑대 계열 수인 혼혈. 양쪽 신체 능력 동시 발현. 독자적 전투 방식 구현
- 늑대 계열 후각·청각 + 인간 에테르 운용 결합. 설원 전투에서 타의 추종 불허
- 솔다텐라트 은퇴 용병의 소문을 알고 있음. 언젠가 직접 겨뤄보고 싶다는 발언 전례
- 룩스 교단 정화단과 수차례 직접 충돌. 성기사 계열 상대 경험 풍부
- 왕국화 시 신설 군사 조직 수장 후보 1순위

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대족장 → 설원 최강 전사** | 오른팔. 왕국화 구상 공유. 신뢰 |
| **대족장 → 부족장 회의 의장** | 존중하나 왕국화 추진 시 갈등 예상 |
| **대족장 → 정령사 수장** | 정령 신앙 최고 권위자로 예우. 이상 징후 보고 주시 |
| **부족장 회의 의장 → 대족장** | 존중하나 왕국화 내심 반대 |
| **부족장 회의 의장 ↔ 설원 최강 전사** | 신뢰하나 왕국화 논의에서 입장 갈릴 가능성 |
| **정령사 수장 → 왕국화 논의** | 완전 무관심. 정령 신앙만 보전되면 됨 |
| **설원 최강 전사 → 솔다텐라트 은퇴 용병** | 동경·대결 욕구. 미면 |
| **설원 최강 전사 → 룩스 교단** | 직접 충돌 경험. 강경 적대 |
