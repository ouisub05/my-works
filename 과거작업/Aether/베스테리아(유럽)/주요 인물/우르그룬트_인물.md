# 우르그룬트 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 왕 (Hochkönig)

| 항목 | 내용 |
|------|------|
| **직위** | 우르그룬트 드워프 왕국 고왕. 드워프 혈통 세습 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 드워프 특유의 단단한 신체 강화 |
| **성격** | 과묵하고 무뚝뚝. 말보다 행동. 드워프 기술에 대한 자부심이 정체성의 핵심 |
| **현재 상황** | 상업 중립 원칙 고수 중. 전통 보수파와 기술 혁신파 내부 논쟁 중재 |
| **핵심 목표** | 드워프 기술 최고 수준 유지. 상업 중립으로 전 세계 교역 파트너 관계 보전 |
| **갈등 요소** | 마루한 기관 기술이 드워프 기술 일부를 독자 발전시켰다는 사실. 자부심에 상처 |

### 세부 특성
- 드워프 장인 전통 명가 출신. 직접 룬 각인 가능한 왕. 역대 왕 중 장인 실력 최상위급
- 마루한 에테르 기관 기술을 인정하면서도 인정하기 싫어함. 내부적으로 긴장
- 카이저라이히 황제의 정치적 압박에 상업 중립 원칙으로 일관. 굴복 없음
- 전통 보수파 지지하는 편이나 기술 혁신파를 숙청하지 않음. 필요성 인식

## 2. 장인 총수 (Meisterhandwerker)

| 항목 | 내용 |
|------|------|
| **직위** | 드워프 장인 조합 총수. 우르그룬트 기술 체계 총괄 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 룬 각인·마정석 가공 에테르 극한 특화 |
| **성격** | 완벽주의. 기준 이하 작업물은 존재해서는 안 된다는 신념. 기술 외 관심사 없음 |
| **현재 상황** | 전통 보수파 수장. 외부 기술 도입 완강히 반대. 룬 기술 심화 연구 집중 |
| **핵심 목표** | 드워프 룬 기술 세계 최고 수준 유지. 외부 기술 오염 방지 |
| **갈등 요소** | 기술 혁신파 장인들이 마루한 기관 기술을 연구하는 것을 이단 취급. 조합 내 갈등 |

### 세부 특성
- 전 세계 마정석 가공 기술 최고 권위자. 드워프 감정사 중 최강
- 마루한 에테르 기관을 분석해본 결과 드워프 기술 기반이 아님을 확인. 더욱 경계 강화
- 고대 룬 문자 해독 진전 중. 고대 문명 기술이 드워프 룬의 기원일 가능성 연구
- 왕보다 장인 사회 내 실질 영향력 더 높다는 평가

## 3. 기술 혁신파 장인 (Innovator-Handwerker)

| 항목 | 내용 |
|------|------|
| **직위** | 기술 혁신파 대표 장인. 조합 내 혁신 연구 그룹 리더 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 에테르 기관·룬 융합 연구 특화 |
| **성격** | 호기심 왕성. 새로운 것에 흥분. 전통 보수파를 답답해하나 장인 총수를 존경 |
| **현재 상황** | 마루한 기관 기술·마기스테리움 에테르 이론 연구. 드워프 룬과 융합 시도 중 |
| **핵심 목표** | 드워프 기술 다음 단계 개척. 룬+에테르 기관 융합 기술 완성 |
| **갈등 요소** | 장인 총수와 지속 충돌. 왕은 묵인. 조합 내 배척 압력 받는 중 |

### 세부 특성
- 마루한 에테르 기관 제품을 분해·분석해 역설계 시도. 부분 성공
- 마기스테리움 개방파 교수와 비공식 서신 교환. 에테르 이론 참고
- 움코시 왕국 마정석 발견 소식에 가장 먼저 반응. 현지 탐사 지원 요청 중
- 장인 총수에게 쫓겨날 위기 수차례. 왕이 매번 보호

## 4. 교역소 방위대장 (Handelswacht-Kommandant)

| 항목 | 내용 |
|------|------|
| **직위** | 우르그룬트 전 세계 교역소 방위 총괄 대장 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 드워프 중장갑 전투·요새 방어 극한 특화 |
| **성격** | 철두철미. 규칙 절대 준수. 교역소 안전이 곧 드워프 신뢰도라는 신념 |
| **현재 상황** | 전 세계 교역소 보안 체계 총괄. 마물 위협 증가로 경계 강화 중 |
| **핵심 목표** | 교역소 완벽 방어. 드워프 신용과 안전 보장 |
| **갈등 요소** | [E] 마물 출현 증가로 기존 방어 체계 재검토 필요. 기술 혁신파 방어 기술 도입 검토 중 |

### 세부 특성
- 전 세계 교역소에 순환 배치되는 드워프 방위대 통합 지휘
- 솔다텐라트 은퇴 용병과 교역소 방어 협력 협약 체결 전례. 상호 존중
- [E] 마물 대응 과정에서 기존 방어술로 한계 경험. 기술 혁신파 방어 기술 비공식 검토 중
- 드워프 보복 문화의 실행자. 교역소 습격 세력에 대한 보복 원정 직접 지휘한 전례 다수
- 전통 보수파이나 현실 위협 앞에서는 실용주의. 장인 총수보다 유연함

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 장인 총수** | 실질 기술 권위 인정. 보수파 성향 공유 |
| **왕 → 기술 혁신파 장인** | 필요성 인식. 총수로부터 보호 |
| **왕 → 교역소 방위대장** | 신뢰. 드워프 신용의 실행자 |
| **장인 총수 → 기술 혁신파 장인** | 이단 취급. 쫓아내려 하나 왕이 막음 |
| **장인 총수 → 교역소 방위대장** | 기술 외 영역. 존중하나 교류 적음 |
| **기술 혁신파 장인 → 장인 총수** | 존경하나 답답함. 인정받고 싶음 |
| **교역소 방위대장 → 기술 혁신파 장인** | 비공식 접촉. 방어 기술 검토 |
| **교역소 방위대장 → 솔다텐라트 은퇴 용병** | 방어 협력 전례. 상호 존중 |
