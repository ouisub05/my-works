## 1. 원장 (Magister Supremus)

| 항목 | 내용 |
|------|------|
| **직위** | 마기스테리움 원장. 학술 위원회 수장 |
| **에테르** | 마스터 하 (10단계). 마법사 계열. 에테르 이론·술식 연구 최고 권위자 |
| **성격** | 학자 중의 학자. 정치·권력에 진심으로 무관심. 연구 방해받는 것을 가장 싫어함 |
| **현재 상황** | 에테르 사용 마물 급증 원인 연구 총괄. 외부 세력 개입 정황 극비 조사 중 |
| **핵심 목표** | 마기스테리움 학술 중립 유지. 에테르 사용 마물 원인 규명 |
| **갈등 요소** | 인간 전용 유지파·개방파 논쟁이 학술 분위기 훼손. 정치화되는 것을 막으려 하나 역부족 |

### 세부 특성
- 베스테리아 내 에테르 이론 최고 권위. 마법사 협회 은탑 설립 기여자
- [E] 마물 연구 결과를 공개 시 세계 정치 판도 직접 영향 우려. 극비 처리 결정
- 칠람 동맹 고대 유적 연구에 깊은 관심. 연구 협력 채널 구축 시도 중
- 쌍도 연구를 공식 금지하나 비공식 연구팀 존재 묵인. 본인도 가능성에 관심
- 수석 마법사 교수를 가장 신뢰하는 동료. 연구 파트너

## 2. 학술 위원회 부원장 (Vize-Magister)

| 항목 | 내용 |
|------|------|
| **직위** | 학술 위원회 부원장. 원장 다음 실권자. 인간 전용 유지파 대표 |
| **에테르** | 엑스퍼트 중 (8단계). 마법사 계열. 술식 체계·교육 과정 설계 특화 |
| **성격** | 원칙주의. 마기스테리움의 전통·순수성 수호에 집착. 변화를 위협으로 인식 |
| **현재 상황** | 개방파 교수들의 타 종족 입학 허용 주장에 조직적으로 반대. 위원회 내 다수파 유지 |
| **핵심 목표** | 인간 전용 전통 유지. 마기스테리움 학술 기준 수호 |
| **갈등 요소** | 원장이 개방파 논의 자체를 억압하지 않음에 불만. 수석 마법사 교수와 노선 대립 |

### 세부 특성
- 에이렌발트 순혈주의와 유사한 논리로 인간 전용 유지 주장. 스스로 비교 거부하나
- 카이저라이히 제국과 비공식 채널. 마기스테리움 졸업생 제국 우선 배치 조건 협상 중
- 수석 마법사 교수의 연구 성과를 인정하면서도 개방파 대표라는 이유로 견제

## 3. 개방파 교수 (Professor der Öffnung)

| 항목 | 내용 |
|------|------|
| **직위** | 마기스테리움 선임 교수. 개방파 비공식 수장 |
| **에테르** | 엑스퍼트 하 (7단계). 마법사 계열. 다종족 에테르 체계 비교 연구 특화 |
| **성격** | 열정적이고 직선적. 불합리한 것에 참지 못함. 학술적 논거로 싸움. 정치력 부족 |
| **현재 상황** | 하프 엘프·수인의 독자적 에테르 체계 연구 결과로 개방 논리 강화 중 |
| **핵심 목표** | 마기스테리움 타 종족 입학 허용. 에테르 연구 다양성 확대 |
| **갈등 요소** | 부원장과 정면 충돌. 원장이 중립 유지하는 것에 답답함. 실바 아르카나 학술원장과 연구 교류 |

### 세부 특성
- 실바 아르카나 학술원장과 서신 교환 지속. 하프 엘프 에테르 연구 공동 진행
- 마기스테리움 내 유일하게 타 종족 에테르 체계를 직접 연구한 인물
- 수석 마법사 교수와 연구 분야 겹침. 학술적으로 협력하나 정치적으론 같은 편
- 학생들 사이 인기 높음. 차세대 개방파 양성 기반 구축 중

## 4. 수석 마법사 교수 (Erster Magister-Professor)

| 항목 | 내용 |
|------|------|
| **직위** | 마기스테리움 최강 마법사. 에테르 전투 술식 교수 겸 연구원 |
| **에테르** | 엑스퍼트 상 (9단계). 마법사 계열. 전투 술식·고급 에테르 이론 동시 최고 수준 |
| **성격** | 냉철하고 건조. 감정 표현 극히 드묾. 학생에게 엄격하나 실력엔 공정. 연구에 집착 |
| **현재 상황** | 원장과 [E] 마물 공동 연구 중. 교수직 병행하며 다음 세대 마법사 양성 |
| **핵심 목표** | 에테르 전투 술식 극한 발전. [E] 마물 대응 술식 개발 |
| **갈등 요소** | 개방파로 분류되나 본인은 학술적 판단일 뿐. 정치적 진영 논리 혐오 |

### 세부 특성
- 원장과 오랜 연구 파트너. 마기스테리움 내 가장 신뢰받는 관계
- 부원장과 노선 대립하나 직접 충돌 자제. 연구에 집중
- 전투 경험 다수. 마물 토벌·에이렌발트 접경 경비 이력. 실전 파악 탁월
- 쌍도 비공식 연구팀 실질 리더. 원장이 묵인하는 것을 알고 있음
- 카이저라이히 검성이 어린 시절 마기스테리움 방문 시 조우한 전례. 강인한 인상 남김
- 마기스테리움 역사상 손꼽히는 천재. 원장과 함께 베스테리아 마법사 계열 최강급

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **원장 → 수석 마법사 교수** | 최대 신뢰. 연구 파트너 |
| **원장 → 부원장** | 존중하나 내심 경직됨 인식 |
| **원장 → 개방파 교수** | 연구 가치 인정. 정치화는 억제 |
| **부원장 → 수석 마법사 교수** | 연구 인정. 개방파로 분류해 견제 |
| **부원장 ↔ 개방파 교수** | 정면 대립. 위원회 내 반복 충돌 |
| **수석 마법사 교수 ↔ 개방파 교수** | 학술 협력. 정치 진영은 각자 |
| **개방파 교수 → 실바 아르카나 학술원장** | 연구 교류. 하프 엘프 에테르 공동 연구 |
| **수석 마법사 교수 → 카이저라이히 검성** | 어린 시절 조우. 강인한 인상 남김 |
