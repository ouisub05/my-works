# 상투스 임페리움 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 성왕 (Rex Sanctus)

| 항목 | 내용 |
|------|------|
| **직위** | 상투스 임페리움 성왕. 룩스 교단 최고 수장. 세속·종교 권력 일체 |
| **에테르** | 엘리트 중 (5단계). 성기사 계열. 신성력 운용 탁월 |
| **성격** | 카리스마 넘치는 웅변가. 대중 앞에서 완벽한 신의 대리인. 뒤에선 냉혹한 권력자 |
| **현재 상황** | 교단 부패 만연에도 외부엔 은폐. 내부 개혁 명목으로 반대파 숙청 진행 중 |
| **핵심 목표** | 룩스 교단 베스테리아 전역 영향력 강화. 카이저라이히 황제 파문 카드 준비 |
| **갈등 요소** | 교단 부패를 알면서도 이를 이용해 충성 확보. 진정한 개혁 의지 없음 |

### 세부 특성
- 교단 내 부패를 누구보다 잘 앎. 그러나 부패한 신관들이 자신에게 충성하기에 방치
- 진정한 신앙보다 권력 유지가 우선. 성검단장의 순수한 신앙심을 이용하는 면 있음
- 카이저라이히 황제를 공개 파문하는 카드를 준비 중. 시기 조율 중
- 레뇨 발로아 독립파를 지원하는 것은 제국 견제 수단. 순수한 연대 아님

## 2. 대추기경 (Grand Cardinal)

| 항목 | 내용 |
|------|------|
| **직위** | 추기경단 수장. 성왕 다음 실질 교단 권력자. 차기 성왕 유력 후보 |
| **에테르** | 엘리트 하 (4단계). 신성력 계열 |
| **성격** | 온화하고 학구적인 겉모습. 실제론 교단 부패의 핵심 당사자. 위선의 달인 |
| **현재 상황** | 교단 재정 횡령·성직 매매 주도. 성왕과 상호 약점 보유로 공존 중 |
| **핵심 목표** | 차기 성왕 자리 확보. 현재 부패 구조 유지 |
| **갈등 요소** | 성검단장의 개혁 의지가 자신에게 직접 위협. 성검단장 제거 시도 중 |

### 세부 특성
- 성직 매매 조직적 운영. 돈으로 주교·사제직 판매
- 교단 재정 일부를 개인 금고로. 드워프 교역소에 익명 계좌 보유 추정
- 표면상 성검단장을 높이 평가. 실제론 가장 위험한 존재로 인식
- 카이저라이히 제국 재상과 비밀 채널 보유. 양쪽 이익 거래

---

## 3. 교단 감찰관 (Inquisitor General)

| 항목 | 내용 |
|------|------|
| **직위** | 이단심문소 총수. 정화단 실질 지휘자 |
| **에테르** | 엘리트 중 (5단계). 성기사 계열. 신성력 탐지 특화 |
| **성격** | 광신적 열정. 이단·부정에 타협 없음. 그러나 방향이 잘못된 열정. 윗선 지시에 맹목적 복종 |
| **현재 상황** | 대추기경의 지시로 진짜 부패보다 힘없는 이단자·소수 종파 탄압에 집중 |
| **핵심 목표** | 교단의 순수성 수호라고 믿음. 실제론 대추기경의 도구 |
| **갈등 요소** | 진짜 부패가 대추기경 본인임을 모름. 알게 되는 순간 폭발적 반응 예상 |

### 세부 특성
- 이단 탐지 신성력 특화. 에테르 위장·거짓 신앙 감지 능력 탁월
- 성검단장과 관계: 같은 신앙이나 방법론 충돌. 감찰관은 강압·심문, 성검단장은 모범·감화
- 대추기경이 부패한 진실을 알게 된다면 교단 역사상 최대 숙청 일으킬 가능성
- 카이저라이히·다크 엘프·정령 신앙 탄압 앞장서나 성과는 미미

## 4. 성검단장 (Grand Master of the Holy Sword)

| 항목 | 내용 |
|------|------|
| **직위** | 성검단 단장. 성왕 직속 최정예 기사단 수장 |
| **에테르** | 엑스퍼트 중 (8단계). 성기사 계열. 베스테리아 성기사 중 최강 |
| **성격** | 진정한 의미의 신앙인. 순수하고 강직. 타협 모름. 부패에 분노하나 아직 참고 있음 |
| **현재 상황** | 교단 내부 부패를 눈으로 목격 중. 성왕에게 개혁 건의했으나 무시당함. 한계에 다가가는 중 |
| **핵심 목표** | 룩스 교단 본래 이상 실현. 진정한 신앙과 정의 |
| **갈등 요소** | 교단에 대한 충성과 눈앞의 부패 사이. 조직을 떠날지 내부에서 싸울지 기로 |

### 세부 특성
- 빈민 출신. 성기사로 신분 상승. 룩스 교단의 이상적 성공 사례이자 현재 교단 모순의 상징
- 성왕이 자신을 명예직으로 활용하면서 실권은 안 줌을 인식하기 시작
- 대추기경과의 갈등 심화 중. 부패 증거 수집 중이나 아직 행동 안 함
- 레뇨 발로아 왕국 최강 기사와 신앙·기사도 면에서 동지 의식. 간접 교류
- 카이저라이히 검성·북부 대공과 실력 비교 대상. 직접 대면 없음

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **성왕 → 대추기경** | 상호 약점 보유. 공존. 이용 관계 |
| **성왕 → 감찰관** | 도구로 활용. 진짜 부패는 감추고 엉뚱한 방향으로 활용 |
| **성왕 → 성검단장** | 명예직 활용. 순수성 이용. 실권 차단 |
| **대추기경 → 성검단장** | 최대 위협. 제거 시도 중 |
| **대추기경 → 감찰관** | 조종. 감찰관은 모름 |
| **성검단장 → 대추기경** | 부패 의심·증거 수집 중. 아직 확신 없음 |
| **성검단장 → 감찰관** | 같은 신앙. 방법론 충돌 |
| **감찰관 → 대추기경** | 맹목적 복종. 진실 모름 |
