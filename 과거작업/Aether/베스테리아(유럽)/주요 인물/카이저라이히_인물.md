# 카이저라이히 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 황제 (Kaiser)

| 항목 | 내용 |
|------|------|
| **직위** | 카이저라이히 황제. 제국 최고 권력자 |
| **에테르** | 마스터 중 (11단계). 무인 계열. 현재 제국 내 전투력 최상위권 |
| **성격** | 냉철한 현실주의자. 감정 노출 없음. 목표를 위해 수단 가리지 않음 |
| **현재 상황** | 강경 팽창 정책 추진 중. 에이렌발트·레뇨 발로아 동시 압박 |
| **핵심 목표** | 베스테리아 완전 통일. 군부 등에 업고 귀족 연합 장악 |
| **갈등 요소** | 군부 등에 업고 있으나 군부가 너무 강해질 경우 역풍 우려 |

### 세부 특성
- 즉위 전 수십 년간 직접 전장에 나가 싸운 장군 출신. 제국 내 전투력 최고위
- 전투력으로 군부 장악. 단순 정치적 황제가 아닌 **싸울 수 있는 황제**로 군부 신망 높음
- 문관 출신 귀족을 철저히 배제. 군부 귀족에게 작위 수여로 지지 기반 구축
- 상투스임페리움과 표면상 우호. 실제론 룩스 교단 영향력 제거 목표
- 정보국(검은 독수리) 직접 지휘. 측근 중 누구도 완전히 신뢰 안 함

## 2. 제국 원수 (Reichsmarschall)

| 항목 | 내용 |
|------|------|
| **직위** | 제국 전군 총사령관. 군부 수장 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열 |
| **성격** | 직선적. 전술·전략 천재. 정치에 관심 없음. 전쟁만 이해함 |
| **현재 상황** | 황제의 팽창 정책 적극 지지. 에이렌발트 원정 준비 총괄 |
| **핵심 목표** | 제국 군사력으로 베스테리아 전역 평정. 전쟁에서 이기는 것 |
| **갈등 요소** | 황제와 목표 일치하나 방법 충돌. 황제가 정치적 계산 넣으면 반발 |

### 세부 특성
- 전투 지휘관으로 시작. 수십 년 전장 경험. 병사들에게 절대적 신망
- 문관 귀족을 경멸. 전쟁을 모르는 자가 외교로 해결하려는 것을 이해 못함
- 인물 3(전투 대장)의 직속 상관이나 실질적으론 동급 대우
- 나이 많음. 은퇴 시기 논란 있음

## 3. 제국 검성 (Reichsschwert)

| 항목 | 내용 |
|------|------|
| **직위** | 황제 직속 최강 전투 직군. 비공식 칭호 검성(劍聖) |
| **에테르** | 엑스퍼트 상 (9단계). 무인 계열 |
| **나이** | 20대 중반~30대 초반. 젊은 나이에 엑스퍼트 상 달성으로 제국 내 화제 |
| **성격** | 과묵. 행동으로 말함. 전투 외 모든 것에 무심. 단 황제에게 절대 충성 |
| **현재 상황** | 황제 친위대 실질 수장. 제국 내 전투력 1위. 북부 대공과 라이벌 관계 |
| **핵심 목표** | 황제 보호. 개인적으로는 마스터 하 도달 |
| **갈등 요소** | 군부(원수)의 전략 자산으로 쓰이길 원하는 것과 황제 직속이라는 위치 충돌 |

### 세부 특성
- 베스테리아 내 손가락 안에 드는 전투력
- 북부 대공과는 어린 시절부터 경쟁 관계. 감정적 앙금 없음. 순수한 실력 경쟁
- 전투 방식: 에테르 강화 검술. 속도·정밀도 특화. 에이렌발트 엘프 상대 전법 보유
- 원수와 관계: 존경하나 지휘는 받지 않음. 황제 명령 우선

## 4. 북부 대공 (Nordherzog)

| 항목 | 내용 |
|------|------|
| **직위** | 에이렌발트 접경 북부 영토 대공. 제국 귀족 최고위 |
| **에테르** | 엑스퍼트 상 (9단계). 무인 계열. 검성과 동급 |
| **나이** | 20대 중반~30대 초반. 검성과 비슷한 연배 |
| **성격** | 냉소적. 귀족적 자존심 강함. 황제를 존중하나 복종은 아님. 실리적 |
| **현재 상황** | 에이렌발트 접경 방어 총괄. 실질적 북부 독립 영주에 가까운 권한 보유 |
| **핵심 목표** | 북부 영토 유지·확장. 에이렌발트 완전 복속. 개인적으로는 검성 타도 |
| **갈등 요소** | 황제의 중앙집권 강화가 자신의 영향력 축소로 이어질 것을 우려 |

### 세부 특성
- **아버지**: 귀족 외교부 출신. 문관 귀족의 대표적 가문. 재상 파벌과 연결
- 아버지와 달리 본인은 전투 직군 선택. 가문 내 이례적 행보
- 아버지의 외교 인맥을 물려받아 정치적으로도 능숙. 순수 무력파인 검성과 차이
- 에이렌발트 엘프와 수십 년 교전 경험. 엘프 전투 스타일에 정통
- 검성과 라이벌: 서로를 유일한 진짜 경쟁자로 인정. 황제 앞에서도 숨기지 않음
- 귀족 연합 내 군부파 대표 인물. 원수와 협력하나 파벌은 다름
- 북부 영토에 독자 정보망 보유. 황제 정보국과 별개

## 5. 제국 재상 (Reichskanzler)

| 항목 | 내용 |
|------|------|
| **직위** | 제국 행정 수반. 문관 귀족 대표 |
| **에테르** | 없음. 범인. 정치·외교 전문가 |
| **성격** | 유연함. 어느 쪽에도 적이 없어 보이나 실제론 철저히 계산적 |
| **현재 상황** | 황제 팽창 정책에 표면 협력. 실제론 속도 조절 시도 |
| **핵심 목표** | 문관 귀족 세력 보호. 군부 독주 견제. 제국 행정 장악 |
| **갈등 요소** | 황제·군부 양쪽 눈치를 보며 줄타기. 어느 쪽 과도한 승리도 원치 않음 |

### 세부 특성
- 베스테리아 최고 수준의 외교관 출신. 타 세력과의 협상 실적 다수
- 상투스임페리움·마레 콘소르티움과 비밀 채널 유지
- 황제가 가장 경계하는 측근. 그러나 행정 능력 때문에 제거 못함
- 정보국 감시 대상 1순위이나 정보국 내부에도 자신의 사람 심어둠

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **황제 → 원수** | 이용·지지. 군부 장악 도구. 황제 자신도 무인이라 상호 존중 |
| **황제 → 검성** | 절대 신뢰. 유일한 진심 측근 가능성. 직접 발탁 |
| **황제 → 북부 대공** | 경계·견제. 영향력 축소 시도 중. 전투력은 인정 |
| **황제 → 재상** | 불신하나 필요. 감시 중 |
| **검성 ↔ 북부 대공** | 라이벌. 순수 실력 경쟁. 감정 없음. 비슷한 연배 |
| **원수 ↔ 재상** | 대립. 군부 vs 문관 갈등의 축 |
| **원수 → 검성** | 아끼나 지휘권 갈등 |
| **북부 대공 → 재상** | 아버지 가문 연결. 표면 협력. 실제론 각자 이익 추구 |
| **재상 → 북부 대공** | 이용 가능한 카드. 황제 견제에 활용 |
