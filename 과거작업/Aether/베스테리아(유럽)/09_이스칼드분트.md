# 이스칼드 분트 (설원 부족 연합)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 스칸디나비아 반도 일대 |
| 체제 | 연합 수장 중심 부족 연합. 평시·전시 모두 강한 결속 |
| 국교 | 정령 신앙 중심. 설원·빙설 정령 숭배 |
| 주요 종족 | 인간·개·늑대 계열 수인 혼합 |
| 군사력 | 중상위권. 혹독한 환경에서 단련된 전사 집단 |
| 에테르 기술 | 독자 발전. 설원 환경 특화 에테르 기술 |

---

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| 최고 수장 | **얄링(Jarling)** — 전 부족 대표 수장. 전투력·지도력으로 선출 |
| 부족장 회의 | 각 부족장 참여. 주요 결정 공동 심의 |
| 선출 방식 | 부족장 회의 추천 + 전투 실력 검증. 혈통 무관 |
| 계승 | 도전자가 얄링을 이기면 수장 교체 가능 |

> 역사상 늑대 계열 수인 얄링 다수

---

## 혼합 문화

인간과 수인이 수백 년 공존하며 형성된 독자 문화.

| 항목 | 내용 |
|------|------|
| 언어 | 인간어·수인 방언 혼합된 독자 언어 사용 |
| 전투 | 인간 전술과 수인 본능적 감각 결합한 독자 전투 방식 |
| 신앙 | 정령 신앙 공유. 설원·폭풍·빙설 정령 숭배 |
| 가족 구조 | 인간·수인 혼합 가족 드물지 않음. 사회적 거부감 없음 |

> 베스테리아에서 **인간·수인 통합이 가장 잘 된 사회**
> 룩스 교단이 이 문화를 **"야만적"** 이라 규정 — 이스칼드 분트는 교단을 적대시

## 마물 다발 지대

| 항목 | 내용 |
|------|------|
| 발생 빈도 | 베스테리아 내 최고 수준. 연중 마물 토벌 필수 |
| 영향 | 전 부족민이 기본 전투 능력 보유 |
| 역설적 이점 | 마물 다발로 타 세력 침공 어려움. 자연 방어선 역할 |
| 마물 자원 | 마물 소재 채취·가공 기술 발달. 교역 품목으로 활용 |

### 주요 설원 마물

| 마물 | 등급 | 특징 |
|------|------|------|
| 프로스트 울프 | 3~4등급 | 거대 빙설 늑대. 무리 형성 시 5등급 |
| 블리자드 트롤 | 5~6등급 | 설원 환경 특화 트롤 |
| 아이스 와이번 | 7등급 | 빙결 속성 와이번. 이스칼드 분트 최대 위협 중 하나 |
| 설원 거인 | 6~7등급 | 극한 환경 적응 거인. 겨울에 더 강해짐 |

## 에테르 기술 — 설원 특화

| 기술 | 내용 |
|------|------|
| 빙결 강화 | 무기·방어구에 빙설 에테르 각인. 드워프 기술과 다른 독자 방식 |
| 체온 조절 술식 | 극한 추위에서 신체 보호 |
| 설원 정령 교감 | 빙설 정령과 친화력 높음. 정령사 비율 베스테리아 내 높은 편 |
