# 실바 아르카나 (엘프 왕국 1)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 이베리아 북부 |
| 체제 | 입헌 왕정. 왕 + 종족 대표 의회 |
| 국교 | 없음. 정령 신앙·룩스 교단 등 복수 신앙 공존 |
| 주요 종족 | 순혈 엘프·하프 엘프·다크 엘프·인간·토끼·사슴 계열 수인 |
| 군사력 | 중위권. 전투력보다 외교력이 강점 |
| 에테르 기술 | 엘프 고유 체계 중심. 외부 체계와 융합 연구 진행 중 |

---

## 다종족 공존 체계

베스테리아에서 가장 평등한 사회.

| 항목 | 내용 |
|------|------|
| 법적 평등 | 종족 불문 동일한 법 적용 |
| 참정권 | 모든 성인 종족에게 의회 참여권 부여 |
| 종족 대표 의회 | 순혈 엘프·하프 엘프·다크 엘프·인간·수인 각 대표 참여 |
| 왕의 권한 | 의회와 공동 결정. 왕 단독 결정 사항 제한적 |
| 혼혈 인정 | 어떤 혼혈이든 왕국 시민으로 완전 인정 |

> 차별받는 타 종족이 실바 아르카나로 이주하는 경우 많음
> 순혈 엘프 보수파는 이를 **"왕국의 정체성 희석"** 이라 우려

---

## 현 왕 — 하프 엘프

- 왕국 역사상 첫 비순혈 엘프 군주
- 즉위 과정에서 순혈 엘프 보수파의 강한 반발 존재했으나 의회 다수결로 선출

| 항목 | 내용 |
|------|------|
| 외교 노선 | 적극적 대외 외교. 베스테리아 중재자 역할 자임 |
| 내부 통합 | 다종족 공존 강화. 보수파 설득 지속 |
| 제국 관계 | 독립 유지 최우선. 제국 팽창 경계하나 직접 충돌 회피 |

> 베스테리아 각 세력이 실바 아르카나를 **중재 창구**로 활용하는 경우 증가 중

---

## 외교 중심 전략

| 전략 | 내용 |
|------|------|
| 다자 외교 | 어느 한 세력에 치우치지 않음. 모든 세력과 관계 유지 |
| 중재 역할 | 세력 간 갈등 중재. 협상 장소 제공 |
| 정보 우위 | 다종족 구성원 통해 각 세력 내부 정보 자연스럽게 수집 |
| 혼인 외교 | 왕족·귀족 혼인을 통해 각 세력과 연결 |
| 엘프 문화 수출 | 엘프 예술·마법·정령 지식을 외교 카드로 활용 |

## 대외 관계

| 대상 | 관계 |
|------|------|
| 카이저라이히 | 독립 유지 긴장. 교역 관계는 유지 |

| 마레 콘소르티움 | 우호. 다크 엘프 공통 거주로 연대 의식 |
| 포르타 콘소르티움 | 지리적 인접. 교역·외교 협력 |
