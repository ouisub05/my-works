# 상투스 임페리움 (신성왕국)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 이탈리아 반도 |
| 체제 | 신정 군주국. 성왕이 종교·세속 권력 일체화 |
| 국교 | 룩스 교단 — 빛·치유의 신 신앙 |
| 주요 종족 | 인간 단일. 타 종족 거주 극히 드묾 |
| 군사력 | 수적으론 열세. 성기사단 질적 수준 베스테리아 최고 |
| 에테르 기술 | 신성력 중심. 일반 에테르 기술은 중간 수준 |

---

## 룩스 교단 — 신앙 체계

| 항목 | 내용 |
|------|------|
| 신명 | **룩스(Lux)** — 빛의 신. 치유·정화·희망의 상징 |
| 신의 실재 | 불명. 교단은 실재한다고 주장. 신성력이 그 증거라는 입장 |
| 핵심 교리 | 빛은 어둠을 정화한다. 고통받는 자를 치유하라. 질서 속에 구원이 있다 |
| 금기 | 어둠·죽음 계열 에테르 사용 금지. 마물 인위 생성 금지. 정령 계약 이단 취급 |

> 다크 엘프를 **"어둠에 물든 존재"** 로 규정 — 입국 사실상 금지
> 정령사도 이단 취급 — 신성왕국 내 정령사는 숨어서 활동

---

## 성왕 선출 체계

| 항목 | 내용 |
|------|------|
| 선출 기관 | 추기경단 — 교단 최고위 성직자 집단 |
| 원칙 | 혈통 무관. 신앙·신성력·덕망으로 선출 |
| 현실 | 최근 수대에 걸쳐 특정 가문 출신 성왕 연속 선출 |
| 내부 갈등 | 혈통파 vs 원칙파 분열 |
| 성왕 칭호 | **렉스 상투스(Rex Sanctus)** |

> 현 성왕은 혈통파 지지로 선출됨 — 원칙파와 긴장 관계

## 성기사단

| 기사단 | 특징 |
|--------|------|
| 성검단(聖劍團) | 최정예 직속 기사단. 성왕 호위·중요 임무 전담 |
| 치유단(治癒團) | 신성력 치유 특화. 전장 지원·병원 운영 |
| 정화단(淨化團) | 마물 처치·이단 심문 전담. 가장 공격적 성향 |
| 순례단(巡禮團) | 베스테리아 각지 교단 시설 순회·보호 |

> 정화단은 다크 엘프·정령사·이단자 추적 특화 — 베스테리아 내 공포의 대상

## 제국과의 갈등

| 항목 | 내용 |
|------|------|
| 역사적 관계 | 상호 의존. 제국이 무력 제공, 신성왕국이 정통성 부여 |
| 갈등 원인 | 현 황제의 교단 임명권·세금 징수권 환수 시도 |
| 신성왕국 대응 | 황제 파문 경고 발령. 반제국 여론 조성 |
| 최대 무기 | 파문권 — 파문된 군주는 신하들의 충성 의무 해제 |
| 한계 | 군사력 열세. 직접 전쟁은 불리 |

> 현 황제의 **"신성력이 신에게서 온다는 증거가 없다"** 발언이 종교 논쟁 점화 중
