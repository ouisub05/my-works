# 에이렌발트 (엘프 왕국 2)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 제국 북부 침엽수림 일대 |
| 체제 | 왕정. 장로 회의 권한 강함 |
| 국교 | 정령 신앙. 외부 교단 일절 불인정 |
| 주요 종족 | 순혈 엘프 단일 |
| 군사력 | 중위권. 숲 지형 활용 전투 특화 |
| 에테르 기술 | 순혈 엘프 고유 체계. 외부 기술 일절 수용 안 함 |

---

## 순혈주의 체계

| 항목 | 내용 |
|------|------|
| 입국 | 순혈 엘프 외 일절 금지. 외교 사절도 숲 경계에서 처리 |
| 혼혈 | 왕국 내 혼혈 출생 즉시 추방. 부모도 책임 추궁 |
| 타 종족 접촉 | 왕국 외부에서 타 종족과 접촉한 엘프는 귀환 시 정화 의식 필요 |
| 문화 보존 | 외부 언어·기술·신앙 유입 금지 |

> 추방된 혼혈 중 일부가 실바 아르카나로 이주
> 에이렌발트는 이를 **"실바 아르카나가 순혈주의를 훼손한다"** 고 비판

---

## 이념적 순수주의

| 항목 | 내용 |
|------|------|
| 핵심 이념 | 엘프는 가장 오래된 종족. 혈통·문화 보존이 세계의 균형 유지 |
| 인간 인식 | 인간의 팽창은 세계 파괴로 이어진다는 인식 |
| 다크 엘프 인식 | **"단절의 오염을 입은 변질체"** — 같은 엘프로 인정 안 함 |
| 하프 엘프 인식 | **"순혈을 더럽힌 결과물"** — 존재 자체를 부정 |

### 내부 파벌
- **극단파** — 타 종족과의 모든 접촉 금지. 숲 침범자는 즉시 처형. 현재 장로 회의 주도권 장악
- **온건파** — 고립은 유지하되 외교 채널은 열어두어야 한다는 입장

## 제국과의 분쟁

| 항목 | 내용 |
|------|------|
| 분쟁 원인 | 제국 팽창으로 침엽수림 벌채·개간. 에이렌발트 영토 경계 침범 |
| 현재 상황 | 산발적 충돌 진행 중. 전면전 직전 긴장 |
| 에이렌발트 전술 | 숲 지형 활용 게릴라전. 정령과 연계한 숲 자체를 무기화 |
| 제국 전술 | 숲 벌채로 지형 이점 제거 시도. 마법사 부대 투입 |
| 교착 상태 | 제국이 숲 안으로 깊이 들어가면 손실 큼. 에이렌발트는 숲 밖 전투 불리 |

> 제국 병사들 사이에서 에이렌발트 숲은 **"들어가면 돌아오지 못하는 곳"** 으로 불림
