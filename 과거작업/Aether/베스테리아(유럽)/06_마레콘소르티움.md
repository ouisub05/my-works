# 마레 콘소르티움 (지중해 무역 연합)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 그리스 일대. 지중해 동부 항구 중심 |
| 체제 | 상인 공화국. 상인 의회가 실질 권력 |
| 국교 | 없음. 다신교·룩스 교단 등 복수 신앙 공존 |
| 주요 종족 | 인간·다크 엘프 중심. 고양이·여우·수달 계열 수인 |
| 군사력 | 하위권. 용병 고용력·정보력으로 보완 |
| 에테르 기술 | 중위권. 다크 엘프 어둠·환영 마법 기술 보유 |

---

## 국가 구조

| 항목 | 내용 |
|------|------|
| 최고 기관 | 상인 의회 — 대상인·길드 수장들로 구성 |
| 행정 수반 | 의장(執政官) — 의회에서 선출. 임기 5년 |
| 군사 | 상비군 소규모. 용병 길드와 장기 계약으로 보완 |
| 세금 | 교역 관세 중심. 소득세 없음 |

> **"돈이 곧 권력"** 인 사회
> 귀족 혈통보다 재력·신용이 사회적 지위 결정

---

## 다크 엘프 공동체

| 항목 | 내용 |
|------|------|
| 법적 지위 | 인간과 완전 평등 |
| 특구 | 항구 도시 내 다크 엘프 특구 존재. 자치 문화 유지 |
| 의회 참여 | 다크 엘프 상인도 의회 진출 가능. 실제로 의원 다수 |

> 베스테리아에서 **가장 큰 다크 엘프 밀집 지역**
> 에이렌발트 추방자·유랑 다크 엘프의 최종 정착지

---

## 교역 및 서비스

| 분야 | 내용 |
|------|------|
| 물자 중개 | 아프라 마정석·희귀 자원, 아시란 향신료·직물, 베스테리아 제품 등 중개 |
| 정보 거래 | 각지 정치·군사·경제 정보 수집·판매. 베스테리아 최대 정보 집산지 |
| 기술 거래 | 다크 엘프 마법 기술·술식 설계도 거래 |
| 용병 알선 | 베스테리아 각지 용병 길드와 연계 |
| 금융 | 대규모 대출·환전·보험 서비스 |
| 숙박·보급 | 장거리 이동 여행자·용병·상인 대상 네트워크 운영 |

> 마레 콘소르티움을 거치지 않고 베스테리아 동서 교역하기 매우 어려움
