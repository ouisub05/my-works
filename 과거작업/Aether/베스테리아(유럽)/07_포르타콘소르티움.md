# 포르타 콘소르티움 (지브롤터 무역 연합)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 이베리아 남부·모로코 북부. 지브롤터 해협 양안 |
| 체제 | 단일 국가. 양안 역할 분담 |
| 국교 | 없음. 실용주의 중심 |
| 주요 종족 | 인간·고양이·여우·수달 계열 수인 중심. 모로코 측 수인 비율 높음 |
| 군사력 | 중위권. 해군 강함. 육군은 보통 |
| 에테르 기술 | 중위권. 항해·교역 특화 에테르 기술 발달 |

---

## 양안 역할 분담

| 구역 | 위치 | 역할 |
|------|------|------|
| 북안 | 이베리아 남부 | 통행세 징수. 대규모 무역항. 창고·금융 중심 |
| 남안 | 모로코 북부 | 수인 이민 수용·직업 중개. 아프라 교역 전진 기지 |

### 남안 — 수인 이민 허브
- 아프라 각지에서 이주한 수인 이민자 집산지
- 수인 직업 중개 기관 다수 — 베스테리아 각지 취업 알선
- 이민자 대상 언어·문화 교육 시설 운영

---

## 아프라 말리 세력과의 무역

| 항목 | 내용 |
|------|------|
| 교역 품목 | 말리 측 — 금·마정석 원석·희귀 자원 / 포르타 측 — 에테르 기술 제품·무기·식량 |
| 독점 | 포르타가 말리와의 교역 사실상 독점. 타 세력 개입 차단 |

> 마레 콘소르티움이 이 루트를 탐내고 있어 갈등 원인 중 하나

---

## 아메리카 진출 — 극비

| 항목 | 내용 |
|------|------|
| 현황 | 극소수 탐험대가 대서양 횡단 성공. 노르테라 남부 해안 접촉 |
| 목적 | 새로운 교역 루트·자원 확보. 마정석 미발굴 지역 탐사 |
| 극비 이유 | 공개 시 경쟁 세력 개입 우려 |
| 현재 단계 | 정기 항로 개설 전 단계. 탐험·접촉 반복 중 |
| 노르테라 반응 | 일부 부족은 교역 시도. 대부분은 경계·적대 |

## 마레 콘소르티움과의 경쟁

| 항목 | 내용 |
|------|------|
| 공식 관계 | 표면상 협력. 교역로 분점 협약 존재 |
| 실제 관계 | 이면 경쟁. 상대 교역 루트 잠식 시도 |
| 경쟁 지점 | 말리 교역 루트, 아프라 마정석 유통권, 베스테리아 내 영향력 |
| 정보전 | 양측 모두 상대 내부에 정보원 심어둔 것으로 알려짐 |
