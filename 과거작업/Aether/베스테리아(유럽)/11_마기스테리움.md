# 마기스테리움 (마법사 양성 국가)

## 기본 정보

| 항목 | 내용 |
|------|------|
| 위치 | 조지아 산맥 일대 |
| 체제 | 학장 중심 단일 지도 체제. 학과별 학과장 보좌 |
| 국교 | 없음. 에테르 연구가 사실상 종교 대체 |
| 주요 종족 | 인간 압도적 다수. 타 종족 극소수 |
| 군사력 | 낮음. 대신 마법사 전투력 자체는 베스테리아 최고 |
| 에테르 기술 | 베스테리아 최선진. 이론·응용 모두 최고 수준 |

---

## 학장 체제

| 항목 | 내용 |
|------|------|
| 학장 | 마기스테리움 최고 권위자. 에테르 실력·학문 업적으로 선출 |
| 임기 | 종신. 단 심각한 과오 시 학과장 연합으로 탄핵 가능 |
| 권한 | 입학 정책·연구 방향·외교 방침 최종 결정 |
| 학과장 | 각 전공 수장. 학장 보좌. 실질적 학사 운영 담당 |

---

## 전공 체계

| 전공 | 성격 | 주요 연구 |
|------|------|----------|
| 에테르 이론학과 | 순수 학문 | 에테르 본질·원리 연구. 마정석 구조 분석 |
| 술식 공학과 | 실용 중심 | 룬·마법진·스크롤 설계. 산업용 술식 개발 |
| 전투 마법학과 | 실용 중심 | 공격·방어·결계 마법. 군사 응용 특화 |
| 고대 연구학과 | 순수 학문 | 고대 유물·유적 해석. 단절 이전 술식 연구 |
| 신성력 연구학과 | 혼합 | 신성력과 에테르 관계 연구. 교단과 갈등 소지 |
| 정령 연구학과 | 혼합 | 정령력·에테르 상호작용 연구. 소규모 |

> 고대 연구학과는 규모 작으나 **마기스테리움 내 최고 비밀 연구** 집결
> 신성력 연구학과는 상투스 임페리움의 항의로 존폐 위기 반복

## 입학 실태 — 공표와 현실의 괴리

| 항목 | 공표 | 현실 |
|------|------|------|
| 입학 기준 | 에테르 재능만 봄. 종족·신분 무관 | 심사 과정에서 인간 지원자 압도적 우대 |
| 타 종족 입학 | 가능하다고 공표 | 합격률 극히 낮음. 입학해도 보이지 않는 차별 |

> 타 종족 입학자는 **"마기스테리움이 공정하다는 증거"** 로 활용됨
> 입학 후 핵심 연구 접근 제한·기숙사 분리 등 차별 존재

## 정치적 위치

| 항목 | 내용 |
|------|------|
| 공식 입장 | 정치 중립. 어느 세력에도 속하지 않음 |
| 실제 | 황제 포섭 압박 지속. 독립 유지 선호 |
| 실질 의존 | 마정석 공급·학생 모집을 위해 카이저라이히 의존도 높음 |

> 마기스테리움의 독립은 **카이저라이히의 묵인**으로 유지되는 측면 있음
