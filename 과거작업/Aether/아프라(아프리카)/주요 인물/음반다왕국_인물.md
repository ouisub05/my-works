# 음반다 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 전사왕 (Mwami wa Vita)

| 항목 | 내용 |
|------|------|
| **직위** | 음반다 왕국 전사왕. 최강 전사가 곧 왕 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 밀림·근접 전투 극한 특화 |
| **성격** | 강함이 곧 정의. 약자는 강자에게 복종해야 한다는 신념. 누베트를 먹잇감으로 인식 |
| **현재 상황** | 누베트 흡수 시기 조율 중. 케메트 반응 주시하며 압박 강화 |
| **핵심 목표** | 누베트 흡수. 케메트와의 완충 지대 확보. 아프라 중부 패권 |
| **갈등 요소** | 케메트 성기사단장 겸 총사령관과의 전면전 회피 필요. 시기 조율이 핵심 |

### 세부 특성
- 고릴라 계열 수인과 혼합 부대 운용. 밀림 전투 아프라 최강
- 마물 사냥 의식을 국가 행사로 격상. 왕이 직접 5등급 이상 마물 사냥 참여
- 누베트 독립파 귀족 수장과 비밀 접촉 중. 군사 지원 조건 협상
- 마물 사냥 전설의 망명에 분노. 체면 손상으로 인식. 귀환 강요 시도 중
- 전통 수호파를 지지하나 현대화파를 숙청하지 않음. 전력 자원으로 활용

## 2. 전사 의회 수장 (Mkuu wa Baraza)

| 항목 | 내용 |
|------|------|
| **직위** | 음반다 전사 의회 수장. 왕 다음 서열 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열 |
| **성격** | 신중하고 전략적. 왕의 정복 의지 지지하나 속도 조절 주장. 전통 수호파 대표 |
| **현재 상황** | 누베트 흡수 신중파 입장. 케메트와 전면 충돌 시 감당 가능한지 계산 중 |
| **핵심 목표** | 음반다 전통 전사 문화 보전. 무리한 팽창으로 전통 훼손 방지 |
| **갈등 요소** | 현대화파가 외부 에테르 기술 도입 주장. 전통 방식 희석 우려 |

### 세부 특성
- 마물 사냥 전설과 오랜 동료. 망명에 가장 충격받은 인물
- 케메트 성기사단장 겸 총사령관의 전력을 가장 현실적으로 평가
- 누베트 군사 지원 조건에서 음반다 이익 극대화 조건 협상 대표
- 마물 사냥 전설 귀환 협상 비공식 채널 운영 중

## 3. 현대화파 전사 수장 (Mkuu wa Mageuzi)

| 항목 | 내용 |
|------|------|
| **직위** | 현대화파 전사 그룹 리더. 왕국 신식 부대 지휘 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 에테르 기술 접목 전투 연구 |
| **성격** | 개방적이고 실용주의. 강하면 된다는 왕국 철학을 외부 기술 도입으로도 실현 가능하다고 봄 |
| **현재 상황** | 솔다텐라트·말리 군단장 네트워크 통해 외부 전투 기술 수입 시도 |
| **핵심 목표** | 음반다 전투력 질적 향상. 케메트 성기사 계열 대응 전술 개발 |
| **갈등 요소** | 전사 의회 수장의 견제. 전통 방식을 버린다는 오해 불식 필요 |

### 세부 특성
- 케메트 성기사 계열 신성력·에테르 융합 전술 분석. 대응 방법 연구 중
- 말리 군단장과 직접 접촉. 전술 정보 교환
- 마물 사냥 전설의 기술을 문서화·전수받으려 했으나 망명으로 무산
- 전통 수호파와 대립하면서도 마물 사냥 의식 자체는 존중. 방법론 차이

## 4. 왕족 최강 전사 (Mkuu wa Familia ya Kifalme)

| 항목 | 내용 |
|------|------|
| **직위** | 전사왕의 직계 왕족. 왕국 전투력 2위 |
| **에테르** | 엑스퍼트 상 (9단계). 무인 계열. 전사왕과 유사한 전투 스타일 |
| **성격** | 왕에 대한 충성과 독자적 야심 공존. 왕을 존경하면서도 언젠가 넘어서고 싶음 |
| **현재 상황** | 왕 직속 친위대 수장. 누베트 접경 군사 압박 실무 담당 |
| **핵심 목표** | 왕국 수호. 개인적으로는 마물 사냥 전설을 넘어서는 것이 목표 |
| **갈등 요소** | 왕의 마물 사냥 전설 귀환 강요를 지지하나 방법에서 의견 차이 |

### 세부 특성
- 마물 사냥 전설에게 직접 사사한 경험. 망명에 배신감과 이해 공존
- 현대화파 수장과 비공식 협력. 왕 모르게 일부 외부 기술 연구
- 누베트 독립군 지휘관과 접경 교전 경험. 상대 전력 직접 파악
- 전사 의회 수장보다 공격적. 누베트 흡수 즉각파에 가까움

## 5. 마물 사냥 전설 (Mwindaji wa Hadithi)

| 항목 | 내용 |
|------|------|
| **직위** | 전 음반다 왕국 최강 마물 사냥꾼. 현재 망명 중. 공식 직위 없음 |
| **에테르** | 마스터 하 (10단계). 무인 계열. 마물 특성 분석·대응 세계 최고 수준 |
| **성격** | 자유로운 영혼. 왕국 정치에 염증. 강함 추구는 동의하나 정복을 위한 강함은 거부 |
| **현재 상황** | 망명 중. 거처 불명. 마물 사냥 단독 지속 |
| **핵심 목표** | 자유로운 마물 사냥. 왕국 귀환 의사 없음 |
| **갈등 요소** | 전사왕의 귀환 강요. 음반다 출신이라는 정체성과 현재 자유 사이 |

### 세부 특성
- 망명 이유: 전사왕의 정복 전쟁 도구로 이용당하는 것에 거부감
- [E] 마물 급증에 가장 먼저 주목한 인물. 독자 조사 중
- 전 세계 마물 다발 지대 이동하며 마물 사냥. 위치 추적 불가
- 솔다텐라트 은퇴 용병과 비공식 교류 있다는 소문. 미확인
- 왕족 최강 전사가 가장 귀환 설득 가능성 높은 인물로 거론됨

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **전사왕 → 왕족 최강 전사** | 신뢰. 누베트 압박 실무 위임 |
| **전사왕 → 전사 의회 수장** | 존중. 속도 조절 갈등 |
| **전사왕 → 마물 사냥 전설** | 분노. 귀환 강요 중 |
| **전사 의회 수장 → 마물 사냥 전설** | 오랜 동료. 귀환 협상 채널 운영 |
| **전사 의회 수장 ↔ 현대화파 수장** | 전통 vs 현대화 대립 |
| **왕족 최강 전사 → 마물 사냥 전설** | 배신감·이해 공존. 귀환 설득 가능성 |
| **왕족 최강 전사 ↔ 현대화파 수장** | 비공식 협력. 외부 기술 연구 |
| **마물 사냥 전설 → [E] 마물** | 독자 조사 중. 세계 최고 수준 분석 |
| **음반다 → 누베트 독립파** | 군사 지원 조건 협상 중 |
