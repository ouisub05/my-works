# 움코시 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 우르그룬트와 지리적으로 멀어 직접 협력 어려움. 드워프 기술자 개인 영입 또는 독자 개발 병행.

---

## 1. 왕 (Inkosi)

| 항목 | 내용 |
|------|------|
| **직위** | 움코시 왕국 국왕 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 실용주의적 자립 의지. 외부 의존을 최소화하되 필요한 것은 적극적으로 끌어옴. 장기 계획형 |
| **현재 상황** | 마정석 발견 극비 유지 중. 독자 개발팀 구성과 드워프 기술자 영입 병행 추진 |
| **핵심 목표** | 마정석 독자 가공 기술 확보. 외부 세력 접근 전 자립 기반 구축 |
| **갈등 요소** | 공개파의 협력 파트너 유치 주장 vs 비밀 유지파의 자립 완성 후 공개 주장 사이 결정 필요 |

### 세부 특성
- 마정석 발견 사실을 극소수만 앎. 공개 시 케메트·포르타·말리 동시 접근 예상
- 드워프 기술자 영입을 위해 특사 파견 준비 중. 우르그룬트 직접보다 개인 드워프 기술자 타겟
- 음반다 왕국과 거리 유지. 누베트 흡수 노리는 세력의 팽창이 다음 타겟될 가능성 우려
- 드워프 기술자(영입 성공)를 왕국 최고 대우로 처우. 자존심 있는 드워프가 남을 조건 제공

## 2. 왕국 재상 (Ndunankulu)

| 항목 | 내용 |
|------|------|
| **직위** | 움코시 왕국 재상. 행정·외교 총괄 |
| **에테르** | 없음. 범인. 외교·행정 전문가 |
| **성격** | 신중하고 보수적. 비밀 유지파 대표. 서두르다 다 잃는 것을 가장 두려워함 |
| **현재 상황** | 마정석 개발 극비 유지 주도. 외부 접촉 최소화 정책 집행 |
| **핵심 목표** | 외부 세력 접근 전 자립 기반 완성. 협상력 갖춘 후 공개 |
| **갈등 요소** | 공개파 귀족들의 협력 파트너 유치 압력. 드워프 기술자 영입도 정보 유출 위험으로 경계 |

### 세부 특성
- 케메트·포르타의 정보망을 가장 현실적으로 두려워하는 인물
- 드워프 기술자 영입에 반대했으나 왕 결정에 따름. 대신 기술자 행동 감시 강화
- 자한 술탄국과 비공식 외교 채널 유지. 마정석 공개 시 첫 협력 파트너 후보로 검토

## 3. 공개파 귀족 수장 (Induna Okhulumayo)

| 항목 | 내용 |
|------|------|
| **직위** | 공개파 귀족 연합 대표. 왕국 의회 내 발언권 강함 |
| **에테르** | 어뎁트 중 (2단계). 무인 계열 |
| **성격** | 적극적이고 낙관적. 마정석 발견을 왕국 도약의 기회로 봄. 리스크보다 기회에 집중 |
| **현재 상황** | 말리 술탄국 또는 자한 술탄국과 협력 파트너 유치 주장. 왕·재상 설득 시도 중 |
| **핵심 목표** | 마정석 개발 협력 파트너 확보. 왕국 경제 급성장 도모 |
| **갈등 요소** | 재상과 정면 충돌. 드워프 기술자 영입은 지지. 외부 세력 협력 범위에서 의견 차이 |

### 세부 특성
- 말리 술탄국 군단장(솔다텐라트 출신)의 네트워크를 통해 접촉 가능성 탐색 중
- 드워프 기술자가 왕국에 합류한 것을 공개파 논리 강화에 활용
- 포르타 콘소르티움이 마정석 정보를 이미 눈치챘을 수 있다는 정보 입수. 재상에게 전달

## 4. 에테르 기술 연구관 (Uchweuzi wa Aether)

| 항목 | 내용 |
|------|------|
| **직위** | 왕국 마정석·에테르 기술 연구 총괄. 왕 직속 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 에테르 분석·기술 개발 특화 |
| **성격** | 탐구적이고 열정적. 마정석 발견에 가장 흥분한 인물. 기술적 도전 즐김 |
| **현재 상황** | 독자 마정석 가공 기술 개발 중. 드워프 기술자와 협력 연구 진행 |
| **핵심 목표** | 움코시 독자 마정석 가공 기술 완성. 드워프 기술자로부터 최대한 배움 |
| **갈등 요소** | 재상의 드워프 기술자 감시에 연구 속도 제약. 신뢰 구축이 먼저라는 판단 |

### 세부 특성
- 마기스테리움 수학하지 않은 독학 에테르 연구자. 독자적 시각 보유
- 드워프 기술자와 가장 많은 시간 보냄. 신뢰 관계 형성 중
- 마정석 4등급 자체 가공 초기 성공. 3등급 가공이 목표
- 우르그룬트 기술 혁신파 장인의 연구 소문을 듣고 관심. 접촉 방법 모색 중

## 5. 드워프 기술자 (Fundi wa Ardhi)

| 항목 | 내용 |
|------|------|
| **직위** | 움코시 왕국 초빙 드워프 기술자. 왕국 기술 고문 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 룬 각인·마정석 가공 특화 |
| **종족** | 드워프. 음반다 왕국 인근 마물 다발 지대 출신 |
| **성격** | 고집스럽지만 호기심 많음. 우르그룬트 전통 보수파와 달리 새 환경에 적응력 있음 |
| **현재 상황** | 움코시 마정석 가공 기술 지도 중. 우르그룬트와 다른 독자 환경에서 새 가공법 연구 |
| **핵심 목표** | 움코시 마정석으로 새로운 가공 기술 개발. 우르그룬트에서 할 수 없던 연구 실현 |
| **갈등 요소** | 재상의 감시 불편. 드워프 자존심에 상처. 그러나 왕의 대우가 충분히 좋아 참는 중 |

### 세부 특성
- 음반다 왕국 마물 다발 지대 출신. 마물 소재와 마정석 결합 기술 연구 독자 발전
- 우르그룬트 장인 총수와 사이 나쁨. 독자 연구 시도로 조합에서 비공식 배제된 전례
- 기술 혁신파 장인과 비슷한 노선. 우르그룬트 탈출구로 움코시 택한 면 있음
- 음반다 마물 다발 지대 지식으로 마물 소재+마정석 시너지 연구. 세계 최초 시도 가능성
- 에테르 기술 연구관과 협력. 서로 다른 기술 체계 교차 연구 중

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 드워프 기술자** | 최고 대우. 독자 개발 핵심 |
| **왕 → 재상** | 신중론 존중. 공개 결정 유보 |
| **왕 → 에테르 기술 연구관** | 직속. 기술 개발 총괄 위임 |
| **재상 → 드워프 기술자** | 감시. 정보 유출 경계 |
| **재상 ↔ 공개파 귀족 수장** | 정면 충돌. 공개 시기 갈등 |
| **공개파 귀족 수장 → 드워프 기술자** | 공개파 논리 강화에 활용 |
| **에테르 기술 연구관 ↔ 드워프 기술자** | 협력. 신뢰 형성 중 |
| **드워프 기술자 → 우르그룬트 장인 총수** | 갈등 전례. 사실상 탈출 |
| **드워프 기술자 → 우르그룬트 기술 혁신파** | 유사 노선. 비공식 관심 |
