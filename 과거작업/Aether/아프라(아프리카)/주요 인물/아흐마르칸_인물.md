# 아흐마르 칸 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 수장 (Ra'is al-Ahmar)

| 항목 | 내용 |
|------|------|
| **직위** | 아흐마르 칸 최고 수장. 수인 부족 연합 대표 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 사막 기동전 특화 |
| **종족** | 사막여우 계열 수인 |
| **성격** | 불타는 저항 의지. 케메트에 대한 분노를 원동력으로. 그러나 무모하지 않음. 시기 조율 중 |
| **현재 상황** | 케메트 저항 기반 구축 중. 말리 술탄국과 연대 협상 진행. 후계 경쟁 내부 관리 필요 |
| **핵심 목표** | 케메트 착취 구조 타파. 아흐마르 칸 완전 독립 |
| **갈등 요소** | 차기 수장 경쟁이 독립 준비 집중력 분산. 포르타 중개업자의 이중적 행보 경계 |

### 세부 특성
- 사막여우 계열 특유의 청각·지략. 협상·정보 수집 탁월
- 케메트에 가족 잃은 개인적 원한. 그러나 감정이 전략 판단 흐리지 않도록 통제
- 말리 술탄국 알-와히드 신앙과 아흐마르 칸 정령 신앙 차이로 연대 협상 복잡
- 게릴라 수장의 존재를 공식 부인. 비공식 지원은 지속

## 2. 저항파 부족장 (Qa'id al-Muqawama)

| 항목 | 내용 |
|------|------|
| **직위** | 강경 저항파 부족 연합 수장. 차기 수장 후보 1순위 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 근접 전투 특화 |
| **종족** | 사자 계열 수인 |
| **성격** | 직선적이고 공격적. 현 수장의 신중함을 나약함으로 오해하는 경향. 즉각 행동 선호 |
| **현재 상황** | 차기 수장 자리 공공연히 노림. 케메트에 선제 타격 주장. 지지 부족 규합 중 |
| **핵심 목표** | 수장직 획득. 케메트에 즉각 저항 개시 |
| **갈등 요소** | 현 수장과 전략 충돌. 게릴라 수장과 협력하나 통제권 다툼 |

### 세부 특성
- 사자 계열 특유의 근력·위압감. 부족원들에게 강한 카리스마
- 현 수장보다 강한 전투력. 실력 면에서는 우위
- 포르타 중개업자를 불신. 외부 세력 개입 자체에 거부감
- 성급한 행동으로 케메트 보복을 유발한 전례 있음. 현 수장이 가장 우려하는 부분

## 3. 타협파 부족장 (Qa'id al-Sulh)

| 항목 | 내용 |
|------|------|
| **직위** | 현실 타협파 부족 연합 수장. 차기 수장 후보 2순위 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 탐지·협상 보조 에테르 특화 |
| **종족** | 사막여우 계열 수인 |
| **성격** | 냉정한 현실주의. 독립보다 착취 조건 개선이 현실적이라는 입장. 감정 배제 |
| **현재 상황** | 케메트와 협상 채널 유지. 착취 조건 완화 교섭 중. 차기 수장 경쟁에서 현 수장 지지 명목으로 영향력 확대 |
| **핵심 목표** | 현실적 조건 개선. 장기적으로 수장직 획득 |
| **갈등 요소** | 저항파 부족장과 노선 대립. 현 수장 사후 권력 공백 시 충돌 불가피 |

### 세부 특성
- 케메트 서기장과 직접 교섭 채널 보유. 현 수장도 이 채널 활용
- 포르타 중개업자와 비교적 우호적. 경제적 이익 공유
- 독립보다 조건 개선이 현실적이라는 주장이 부족원들에게 지지받지 못하는 딜레마
- 현 수장 사후 저항파 부족장과 권력 충돌 시 포르타 지원 기대

## 4. 게릴라 수장 (Qa'id al-Fedayeen)

| 항목 | 내용 |
|------|------|
| **직위** | 케메트 저항 비공식 게릴라 조직 수장. 공식 존재 부인 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 은신·기습·사막 생존 극한 특화 |
| **종족** | 치타 계열 수인 |
| **성격** | 냉혹한 실행자. 감정 없이 임무 수행. 현 수장에게만 충성. 다음 수장 경쟁에 무관심 |
| **현재 상황** | 케메트 보급선·정보망 교란 작전 지속. 현 수장 비공식 지원 받아 운영 |
| **핵심 목표** | 케메트 약화. 현 수장 독립 준비 시간 벌기 |
| **갈등 요소** | 저항파 부족장이 게릴라 조직 통제권 주장. 현 수장 명령 없이는 협력 거부 |

### 세부 특성
- 치타 계열 특유의 순간 속도. 사막 지형 활용 기습·이탈 전술 최강
- 케메트 성기사단장 겸 총사령관의 추적 대상 1순위. 수차례 포위망 탈출
- 포르타 중개업자를 감시 중. 정보 이중 판매 가능성 주시
- 공식 존재 부인이지만 케메트는 파악 중. 수장 입장 난처

## 5. 포르타 중개업자 (Wastit Porta)

| 항목 | 내용 |
|------|------|
| **직위** | 포르타 콘소르티움 아프라 지역 비공식 중개업자. 아흐마르 칸 거주 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열. 탐지·위장 특화 |
| **종족** | 인간 |
| **성격** | 능글맞고 친근함. 누구에게나 친구인 척. 실제로는 포르타 이익만 추구 |
| **현재 상황** | 아흐마르 칸과 케메트 양측에 정보 판매 중. 포르타 정보 수장 직속 |
| **핵심 목표** | 아프라 정세 정보 수집. 포르타 아프라 교역 독점 유지 지원 |
| **갈등 요소** | 양측 이중 플레이 발각 시 생명 위험. 게릴라 수장이 의심 중 |

### 세부 특성
- 포르타 정보 수장이 아프라에 심어둔 핵심 요원
- 아흐마르 칸 저항 계획 일부를 케메트에 판매. 전부는 아님. 균형 유지가 생존 전략
- 타협파 부족장과 우호적. 경제적 이익 공유 관계
- 말리 술탄국 직거래 시도 관련 정보를 포르타 의장에게 보고 중
- 게릴라 수장의 감시를 인지. 역감시 중

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **수장 → 게릴라 수장** | 비공식 지원. 유일한 충성 대상 |
| **수장 → 저항파 부족장** | 같은 목표. 속도 차이로 갈등 |
| **수장 → 타협파 부족장** | 채널 활용. 경계 |
| **수장 → 포르타 중개업자** | 이중 플레이 의심. 경계하며 활용 |
| **저항파 부족장 ↔ 타협파 부족장** | 차기 수장 경쟁. 노선 대립 |
| **저항파 부족장 → 게릴라 수장** | 통제권 주장. 게릴라 수장 거부 |
| **게릴라 수장 → 포르타 중개업자** | 감시 중. 이중 플레이 의심 |
| **타협파 부족장 ↔ 포르타 중개업자** | 우호. 이익 공유 |
| **게릴라 수장 → 케메트 성기사단장** | 추적 피해 다님. 수차례 탈출 |
