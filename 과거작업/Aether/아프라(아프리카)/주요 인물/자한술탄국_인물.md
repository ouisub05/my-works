# 자한 술탄국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 자한 술탄국은 상인 의회 체제. 내정은 분권. 외교·군사만 통합 지휘 체계 도입 추진 중.

---

## 1. 상인 의회 의장 (Ra'is al-Majlis)

| 항목 | 내용 |
|------|------|
| **직위** | 자한 술탄국 상인 의회 의장. 임기제 선출직 |
| **에테르** | 어뎁트 중 (2단계). 마법사 계열. 탐지·분석 에테르. 협상 보조 |
| **성격** | 합리적이고 균형 감각 탁월. 말리 연대와 독자 노선 사이에서 실용적 판단 추구 |
| **현재 상황** | 외교·군사 통합 지휘 체계 도입 논의 주도. 말리 연대 협상 중재 역할 |
| **핵심 목표** | 자한 상업 이익 극대화. 포르타 우회 인도양 직거래 루트 안정화 |
| **갈등 요소** | 말리 연대파와 독자 노선파 사이 균형 유지. 어느 쪽도 완전히 소외시킬 수 없음 |

### 세부 특성
- 바라타 연방과 인도양 루트 공동 운영 협상 실무 총괄
- 포르타 콘소르티움과 현재 교역 유지하면서 우회 루트 개척. 이중 전략
- 외교·군사 통합 지휘 체계 도입 시 제독을 군사 수장으로 공식화 구상
- 커피 교역 베스테리아 직수출 가능성 타진 중. 포르타 반응 주시

## 2. 말리 연대파 상인 수장 (Ra'is al-Ittihad)

| 항목 | 내용 |
|------|------|
| **직위** | 말리 연대 추진파 대표 상인. 의회 내 최대 파벌 수장 |
| **에테르** | 없음. 범인. 상업·금융 전문가 |
| **성격** | 알-와히드 신앙 독실. 신앙 연대가 경제 연대보다 더 확실한 기반이라는 신념 |
| **현재 상황** | 말리 술탄국과 직거래 루트 협상 병행. 알-와히드 신앙권 경제 블록 형성 시도 |
| **핵심 목표** | 말리·자한 알-와히드 신앙권 교역 연대. 포르타 의존 탈피 |
| **갈등 요소** | 독자 노선파가 말리 종속 우려 제기. 신앙 연대가 경제 자율성 침해할 수 있다는 반론 |

### 세부 특성
- 말리 대이맘과 신앙 채널 유지. 경제 협상 병행
- 자한 상인 중 가장 큰 선단 보유. 연대 성사 시 물동량 주도권 확보 가능
- 포르타 이사회 수석 이사의 현상 유지 제안을 거부한 전례

## 3. 독자 노선파 상인 수장 (Ra'is al-Istiqlaliyya)

| 항목 | 내용 |
|------|------|
| **직위** | 독자 노선 유지파 대표 상인. 의회 내 2위 파벌 수장 |
| **에테르** | 없음. 범인. 해상 교역 전문가 |
| **성격** | 냉정한 현실주의. 신앙보다 이익. 말리 연대가 자한을 말리 하위 파트너로 만들 것을 우려 |
| **현재 상황** | 바라타 연방과 독자 교역 루트 강화 추진. 말리 연대 견제 |
| **핵심 목표** | 자한 상업 독립성 유지. 바라타·누산타라와 다자 교역 네트워크 구축 |
| **갈등 요소** | 말리 연대파보다 세력 약함. 의장의 중립 지지가 유일한 버팀목 |

### 세부 특성
- 바라타 연방 상인 연합과 직접 채널 보유. 향신료 유통 협력
- 포르타와 현재 교역 유지가 독자 노선의 현실적 기반. 포르타 완전 배제 반대
- 누산타라 동맹과도 비공식 교역 채널 유지

## 4. 인도양 함대 제독 (Amiral al-Bahr al-Hindi)

| 항목 | 내용 |
|------|------|
| **직위** | 자한 술탄국 인도양 함대 총사령관 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 해상 전투·항법 에테르 특화 |
| **성격** | 과묵하고 결단력 강함. 상인 의회 정치에 무관심. 바다와 전투만 이해 |
| **현재 상황** | 인도양 교역로 방어 총괄. 포르타 해군과 암묵적 긴장 유지 |
| **핵심 목표** | 인도양 교역로 완전 장악. 자한 해상 패권 확립 |
| **갈등 요소** | 외교·군사 통합 체계 도입 시 의회 간섭 증가 우려. 지금의 독립적 지휘 선호 |

### 세부 특성
- 바라타 연방 해군과 인도양 공동 순찰 협약 체결. 실질적 해상 동맹
- 포르타 콘소르티움 해군 전력 직접 파악. 직접 충돌 시 호각으로 평가
- 프레이 아르키펠 최강 해적 선장과 교전 전례 없음. 항로 분리로 충돌 없어서
- 말리 연대·독자 노선 논쟁에 완전 무관심. 교역로 안전만 보장되면 됨
- 외교·군사 통합 체계에서 군사 수장으로 공식화되는 것에 양가감정

---

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **의장 → 말리 연대파** | 중재. 완전 소외 않음 |
| **의장 → 독자 노선파** | 균형추 역할 지지 |
| **의장 → 제독** | 군사 수장 공식화 구상. 제독 양가감정 |
| **말리 연대파 ↔ 독자 노선파** | 의회 내 주도권 경쟁 |
| **말리 연대파 → 말리 술탄국** | 직거래 루트 협상 병행 |
| **독자 노선파 → 바라타 연방** | 독자 교역 채널 강화 |
| **제독 → 바라타 해군** | 인도양 공동 순찰 협약 |
| **제독 → 포르타 해군** | 암묵적 긴장. 직접 충돌 없음 |
