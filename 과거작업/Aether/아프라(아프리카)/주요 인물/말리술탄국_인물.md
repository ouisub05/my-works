# 말리 술탄국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 술탄 (Sultan al-Mali)

| 항목 | 내용 |
|------|------|
| **직위** | 말리 술탄국 술탄. 세속·종교 권력 겸비 |
| **에테르** | 엘리트 상 (6단계). 성기사 계열. 알-와히드 신성력 운용 |
| **성격** | 웅대한 비전과 냉철한 실행력 공존. 알-와히드 신앙을 진심으로 믿으면서도 현실 정치에 능함 |
| **현재 상황** | 제국화 1단계 추진 중. 군사력 강화와 포르타 독점 타파 병행 |
| **핵심 목표** | 아프라 최강 제국 건설. 포르타 없이 베스테리아 직거래 루트 확보 |
| **갈등 요소** | 포르타 독점 타파 시도가 노골화될수록 포르타·카이저라이히 연합 대응 가능성 |

### 세부 특성
- 금·마정석 수익을 군비로 전환하는 속도 의도적으로 은폐. 포르타 눈치 채지 못하도록
- 자한 술탄국·바라타 연방과 인도양 루트 직거래 협상 극비 추진
- 아흐마르 칸 연대 협상 중. 알-와히드 신앙 차이가 걸림돌이나 공통 이해 충분
- 친위 기사단장 아흐마르 칸 출신 기용이 상징적 메시지. 아프라 수인 연대 의도

## 2. 대이맘 (al-Imam al-Akbar)

| 항목 | 내용 |
|------|------|
| **직위** | 말리 술탄국 최고 이맘. 알-와히드 신앙 권위자 |
| **에테르** | 엘리트 중 (5단계). 성기사 계열. 신성력 치유·보호 특화 |
| **성격** | 온화하나 신앙 원칙에서 타협 없음. 술탄의 제국화 야망을 신앙적으로 정당화하는 역할 |
| **현재 상황** | 포르타 독점 타파를 신앙적 정의로 규정. 알-와히드 신앙권 결속 강화 |
| **핵심 목표** | 알-와히드 신앙 아프라 전파 확대. 술탄 제국화에 종교적 정당성 부여 |
| **갈등 요소** | 아흐마르 칸 정령 신앙과의 연대 협상에서 신앙 정체성 타협 문제 |

### 세부 특성
- 포르타 교역 독점을 "불신자의 착취"로 규정하는 법령 발포
- 알-와히드 신앙권 전체 이맘 네트워크 장악. 자한 술탄국과 신앙 외교 채널
- 군단장(용병 출신)의 신앙 없는 전투 방식에 불만. 술탄이 중재

## 3. 재무장관 (Wazir al-Mal)

| 항목 | 내용 |
|------|------|
| **직위** | 술탄국 재정·교역 총괄. 포르타 현상 유지파 대표 |
| **에테르** | 없음. 범인. 금융·교역 전문가 |
| **성격** | 숫자로 세상을 봄. 리스크 계산 철저. 술탄 야망에 동조하나 속도에 반대 |
| **현재 상황** | 포르타 직거래 시도 속도 조절 주장. 현재 수익 구조 유지하면서 기반 강화 우선 |
| **핵심 목표** | 술탄국 재정 안정. 포르타와 충돌 최소화하며 교역 다변화 |
| **갈등 요소** | 술탄의 급격한 군비 확장이 재정 압박. 포르타 자극 시 보복 교역 봉쇄 우려 |

### 세부 특성
- 드워프 금고에 술탄국 재정 일부 분산 예치. 포르타 봉쇄 대비
- 포르타 이사회 수석 이사와 비공식 채널. 현상 유지파끼리의 소통
- 군단장 용병 비용이 재정에서 가장 큰 부담. 절감 요구 반복

## 4. 친위 기사단장 (Qa'id al-Haras al-Sultani)

| 항목 | 내용 |
|------|------|
| **직위** | 술탄 직속 친위 기사단장. 술탄국 전투력 1위 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 사막 전투·기습 극한 특화 |
| **종족** | 사막여우 계열 수인. 아흐마르 칸 출신 |
| **성격** | 과묵하고 충성스러움. 아흐마르 칸을 떠난 것에 부채 의식. 말리에서의 지위로 고향 독립에 기여하려는 마음 |
| **현재 상황** | 술탄 호위 및 친위 기사단 훈련 총괄. 아흐마르 칸과 비공식 연락 유지 |
| **핵심 목표** | 술탄 보호. 말리·아흐마르 칸 연대 연결 고리 역할 |
| **갈등 요소** | 아흐마르 칸 게릴라 수장과 과거 인연. 현재 다른 세력 소속이라는 복잡한 감정 |

### 세부 특성
- 아흐마르 칸 출신이라는 상징적 의미로 술탄이 직접 발탁
- 아흐마르 칸 수장과 비공식 연락. 연대 협상 비공식 중개 역할
- 게릴라 수장과 어린 시절 동료. 현재 다른 세력에 있으나 감정적 유대 남음
- 대이맘과 신앙 차이. 알-와히드 신앙이 아닌 수인 정령 신앙 유지. 술탄은 묵인
- 케메트 성기사단장 겸 총사령관과 직접 대결 시 호각이라는 평가

## 5. 군단장 (Qa'id al-Jaysh)

| 항목 | 내용 |
|------|------|
| **직위** | 말리 술탄국 정규군 총사령관. 용병 출신 |
| **에테르** | 엑스퍼트 상 (9단계). 무인 계열. 집단 전술·지휘 특화 |
| **종족** | 인간 |
| **성격** | 직업 군인 기질. 의뢰인이 술탄으로 바뀌었을 뿐 용병 시절과 마인드 동일. 돈보다 좋은 전쟁이 없다는 철학 |
| **현재 상황** | 말리 정규군 현대화 추진 중. 용병 시절 네트워크로 우수 용병 지속 충원 |
| **핵심 목표** | 말리 군사력을 아프라 최강으로 키움. 개인적으로 여기가 마지막 거처 |
| **갈등 요소** | 대이맘과 신앙 마찰. 재무장관의 비용 절감 압박. 용병 기질이 정규군 지휘와 충돌하는 부분 |

### 세부 특성
- 솔다텐라트 황금 방패 길드 출신. 전 세계 용병 네트워크 인맥 보유
- 말리 정착 이유: 전 세계 돌아다니다 가장 성장 가능성 높은 세력 선택. 순수한 직업적 판단
- 대이맘과 관계: 술탄이 중재하는 구도. 실질적으론 서로 분야 존중하며 협력
- 재무장관의 비용 절감 요구를 무시하다 술탄 중재로 타협 반복
- 아프라 내 마물 다발 지대 원정 경험 다수. 케메트 군사력 직접 관찰 기회 있음

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **술탄 → 친위 기사단장** | 전략적 상징+절대 신뢰 |
| **술탄 → 군단장** | 핵심 전력. 신앙 마찰 중재 |
| **술탄 → 대이맘** | 종교 정당성 의존 |
| **술탄 → 재무장관** | 속도 조절 갈등. 필요한 견제 |
| **대이맘 → 군단장** | 신앙 마찰. 술탄 중재 |
| **재무장관 → 군단장** | 비용 절감 압박. 반복 충돌 |
| **친위 기사단장 → 아흐마르 칸 수장** | 비공식 연락. 연대 중개 |
| **친위 기사단장 → 아흐마르 칸 게릴라 수장** | 과거 동료. 복잡한 감정 |
| **군단장 → 솔다텐라트** | 과거 소속. 인맥 활용 |
