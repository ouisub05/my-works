# 누베트 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 누베트 왕국은 자체 군사 조직 없음. 케메트가 국경 감시 중.

---

## 1. 왕 (Nesut-Nubet)

| 항목 | 내용 |
|------|------|
| **직위** | 누베트 왕국 국왕. 명목상 군주. 실질 권한 극히 제한 |
| **에테르** | 어뎁트 중 (2단계). 에테르 보유하나 운용 훈련 기회 없었음 |
| **성격** | 겉으로 복종적. 케메트 앞에서 완전히 굴종하는 듯 행동. 속으론 독립 염원. 그러나 행동할 용기 없음 |
| **현재 상황** | 케메트 파라오에게 정기 진상·보고 의무. 실질 결정권 없음. 허수아비 왕 |
| **핵심 목표** | 왕위 유지. 개인 안전. 독립은 원하나 직접 나서지 않음 |
| **갈등 요소** | 독립파 귀족들이 왕을 독립 명분으로 내세우려 하나 왕은 케메트 보복 두려워 거부 |

### 세부 특성
- 케메트 서기장이 직접 관리하는 속국 왕. 정기 보고 의무
- 음반다 왕국 연대 논의에서 공식 반대 입장. 비공식으론 묵인
- 독립군 지휘관의 존재를 알면서 모른 척. 발각 시 책임 회피 가능한 거리 유지
- 케메트 감시 하에 있어 독립파 귀족과 직접 접촉 피함. 간접 소통

## 2. 독립파 귀족 수장 (Qa'id al-Istiqlal)

| 항목 | 내용 |
|------|------|
| **직위** | 누베트 독립파 귀족 연합 비공식 수장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 열정적 독립 의지. 왕의 무기력함에 분노하나 왕을 버릴 수 없음. 명분이 필요 |
| **현재 상황** | 음반다 왕국 연대 적극 추진 중. 독립군 지휘관과 협력. 케메트 감시 피해 비밀 활동 |
| **핵심 목표** | 케메트 속국 탈피. 누베트 완전 독립 |
| **갈등 요소** | 음반다 연대 거부파와 충돌. 왕이 독립 명분으로 나서주지 않는 것에 좌절 |

### 세부 특성
- 케메트에 재산 몰수당한 전례. 개인적 원한 깊음
- 음반다 왕국과 비밀 서신 교환 중. 군사 지원 협상 초기 단계
- 케메트 서기장의 감시 대상 1순위 귀족. 직접 행동 극히 조심
- 독립군 지휘관에게 자금·정보 제공. 직접 관계는 부인

## 3. 친케메트파 귀족 (Qa'id al-Muwali)

| 항목 | 내용 |
|------|------|
| **직위** | 친케메트파 귀족 대표. 케메트 행정 협력자 |
| **에테르** | 어뎁트 중 (2단계). 에테르 운용 기초 수준 |
| **성격** | 냉정한 현실주의. 독립보다 케메트 체제 안에서 개인 이익 극대화 선택. 도덕적 고민 없음 |
| **현재 상황** | 케메트 서기장과 협력. 독립파 귀족 동향 보고 중 |
| **핵심 목표** | 케메트 지원으로 누베트 내 개인 권력 강화. 독립파 제거 |
| **갈등 요소** | 케메트가 누베트를 완전 흡수하면 자신도 필요 없어짐. 속국 유지가 자신의 존재 이유 |

### 세부 특성
- 케메트 서기장 직접 보고 라인. 독립파 귀족 동향 정기 보고
- 음반다 연대 시도를 케메트에 알릴 경우 독립파 귀족 수장 체포 가능
- 왕을 보호하는 척하면서 실제론 왕의 일거수일투족 감시
- 아이러니하게도 케메트 완전 흡수 반대. 속국 유지가 자신의 기득권 기반

## 4. 독립군 지휘관 (Qa'id al-Tahrir)

| 항목 | 내용 |
|------|------|
| **직위** | 누베트 비공식 독립 준비 전투 조직 수장. 공식 존재 부인 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 은신·게릴라전 특화 |
| **성격** | 조용하고 집중적. 말보다 행동. 독립을 위해서라면 무엇이든 감수 |
| **현재 상황** | 케메트 감시망 피해 독립 전투 조직 훈련 중. 자체 군사 조직 없어 비공식 민간 훈련 형태 |
| **핵심 목표** | 유사 시 즉각 전투 가능한 독립군 조직. 음반다 연대 시 핵심 전력 역할 |
| **갈등 요소** | 케메트 감시로 공개 훈련 불가. 소규모 분산 훈련만 가능. 전력 한계 인식 |

### 세부 특성
- 아흐마르 칸 게릴라 수장과 비공식 연락. 게릴라 전술 공유
- 케메트 성기사단장 겸 총사령관의 추적 대상. 아흐마르 칸 게릴라 수장보다 낮은 우선순위
- 음반다 왕국 전사들과 직접 접촉 시도 중. 연대 실무 담당
- 독립파 귀족 수장으로부터 자금 수령. 직접 관계는 양측 모두 부인
- 왕이 모른 척하는 것 알고 있음. 오히려 명분 확보 수단으로 활용

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 독립파 귀족 수장** | 간접 소통. 직접 접촉 회피 |
| **왕 → 친케메트파 귀족** | 표면 협력. 실제론 감시당함 |
| **왕 → 독립군 지휘관** | 모른 척. 발각 시 책임 회피용 거리 |
| **독립파 귀족 수장 → 독립군 지휘관** | 자금·정보 제공. 직접 관계 부인 |
| **독립파 귀족 수장 → 음반다 왕국** | 연대 협상 추진 중 |
| **친케메트파 귀족 → 케메트 서기장** | 독립파 동향 정기 보고 |
| **친케메트파 귀족 → 독립파 귀족 수장** | 감시·제거 시도 |
| **독립군 지휘관 → 아흐마르 칸 게릴라 수장** | 전술 공유. 비공식 연락 |
| **독립군 지휘관 → 음반다 왕국** | 직접 접촉 시도. 연대 실무 |
