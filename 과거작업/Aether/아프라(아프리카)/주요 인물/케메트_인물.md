# 케메트 주요 인물

> 이름 미정. 추후 작성.

## 1. 파라오 (Per-aa)

| 항목 | 내용 |
|------|------|
| **직위** | 케메트 파라오. 태양신 라-아텀의 아들. 세속·종교 권력 일체 |
| **에테르** | 엘리트 상 (6단계). 성기사 계열. 태양 에테르·신성력 융합 특화 |
| **성격** | 절대 권위에 대한 확신. 의심 없음. 자신이 신의 대리인임을 진심으로 믿음. 냉혹하나 일관됨 |
| **현재 상황** | 누베트 완전 흡수 추진 중. 금 수급 안정화가 현재 최우선 과제 |
| **핵심 목표** | 누베트 완전 복속으로 금광 직접 통제. 케메트 신성 제국 영속 |
| **갈등 요소** | 인간 우월주의 교리와 실제 수인 병력 활용의 모순. 신관 회의가 이를 신학적으로 정당화 시도 중 |

### 세부 특성
- 피라미드 의식 수행 시 신성력·에테르 일시 폭발적 강화. 케메트 내 상징적 존재
- 누베트 속국 상태를 넘어 직접 행정 편입 원함. 금광 수익 신관 회의 분배 구조 변경 목적도 있음
- 아흐마르 칸 수인들의 착취 구조를 알고 있으나 경제적 이유로 방치. 신학적 정당화 의존
- 성기사단장 겸 총사령관을 완전 신뢰. 유일하게 종족 혐오와 무관하게 실력으로 임명한 인물

## 2. 대신관 (Hem-netjer-tepi)

| 항목 | 내용 |
|------|------|
| **직위** | 라-아텀 신전 대신관. 신관 회의 수장 |
| **에테르** | 엘리트 상 (6단계). 성기사 계열. 신성력 의식 강화 특화 |
| **성격** | 교묘하고 신중. 파라오를 섬기면서도 신관 회의 권력 보호. 신학 해석으로 현실 정치 조율 |
| **현재 상황** | 인간 우월주의와 수인 활용 모순을 신학적으로 봉합 중. 누베트 흡수 과정에서 신관 수익 보전 협상 |
| **핵심 목표** | 신관 회의 영향력 유지. 누베트 금광 수익 분배 구조에서 신관 몫 확보 |
| **갈등 요소** | 파라오가 금광 직접 통제 원하는 것이 신관 회의 수익 기반 약화로 이어질 수 있음 |

### 세부 특성
- 수인을 "신이 만든 도구"로 규정하는 신학 해석 창안. 인간 우월주의·수인 활용 모순 봉합
- 고대 케메트 문자 해독 능력 보유. 고대 유물 신성력 해석 권위자
- 누베트 독립 시도에 대해 파라오보다 강경. 금광 수익이 신전 재정 핵심
- 성기사단장 겸 총사령관과 관계 복잡. 군사력 존중하나 신관 권위 도전으로 인식

## 3. 케메트 서기장 (Tjaty)

| 항목 | 내용 |
|------|------|
| **직위** | 케메트 행정 총책임자. 파라오 직속 최고 관료 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 수십 년 행정 경험 |
| **성격** | 실용주의자. 인간 우월주의에 동조하나 실제 행정에서는 능력 있으면 활용. 이중적 |
| **현재 상황** | 누베트 흡수 행정 절차 준비 중. 수인 병력 활용 확대 논의에서 현실적 입장 |
| **핵심 목표** | 케메트 행정 효율 극대화. 누베트 흡수 시 혼란 최소화 |
| **갈등 요소** | 인간 우월주의 교리와 행정 현실 사이에서 매일 타협. 공식적으론 우월주의 지지 |

### 세부 특성
- 아흐마르 칸 착취 구조의 실무 설계자. 도덕적 고민 없음. 경제 논리만
- 수인을 공식적으로 차별하면서 뛰어난 수인 행정관을 익명으로 활용하는 이중 구조 운영
- 누베트 독립 시도에 대해 가장 현실적 대응 설계. 경제 봉쇄·외교 압박 병행 전략
- 성기사단장 겸 총사령관과 업무적 협력. 개인적 관계 없음

## 4. 성기사단장 겸 총사령관 (Imy-r-mesha)

| 항목 | 내용 |
|------|------|
| **직위** | 케메트 성기사단 단장 겸 군사 총사령관. 파라오 직속 |
| **에테르** | 엑스퍼트 상 (9단계). 성기사 계열. 태양 신성력·무인 전투 융합 |
| **성격** | 충성과 실력이 전부. 종족 혐오 교리를 따르나 전투 능력에 대해서는 종족 무관 인정 |
| **현재 상황** | 누베트 복속 군사 작전 총괄. 음반다 왕국 견제 병행 |
| **핵심 목표** | 케메트 군사력 최강 유지. 파라오 명령 완수 |
| **갈등 요소** | 수인 병력이 순수 인간 병력보다 특정 전투에서 우월함을 알면서도 공식적으로 인정 못함 |

### 세부 특성
- 파라오가 유일하게 순수 실력으로 임명한 인물. 신관 회의 추천 없이 파라오 직접 발탁
- 태양 에테르 신성력 융합 전투. 낮 전투에서 베스테리아 성기사 계열 최강급
- 수인 병력 활용 현실을 가장 잘 아는 인물. 내부적으론 공식 교리에 회의감
- 음반다 왕국 전사들과 교전 경험 다수. 전술적으로 가장 위험한 상대로 평가
- 누베트 독립 지원 외부 세력 차단 임무도 병행. 음반다 왕국 움직임 주시

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **파라오 → 성기사단장** | 절대 신뢰. 유일한 실력 기반 임명 |
| **파라오 → 대신관** | 신학 권위 의존. 금광 수익 분배 갈등 잠재 |
| **파라오 → 서기장** | 행정 의존. 감시 없이 신뢰 |
| **대신관 → 성기사단장** | 군사력 존중. 신관 권위 침범 경계 |
| **대신관 → 서기장** | 협력. 수인 활용 신학 봉합 공조 |
| **서기장 → 대신관** | 신학 해석 이용. 실용주의적 협력 |
| **성기사단장 → 대신관** | 명목상 복종. 실질 독립적 |
| **성기사단장 → 서기장** | 업무 협력. 개인 관계 없음 |
