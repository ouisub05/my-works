# 아프라 조연 인물

> 성별·이름 미정. 추후 작성.
> 세력 소속 12인 + 독립 인물 3인 = 총 15인.
> 스토리 연결 포인트: 케메트 착취 구조 저항 / [E] 마물 급증 / 마정석 경쟁.

## 아프라 조연 관계망

| 연결 | 내용 |
|------|------|
| **1번 수인 행정관 → 3번 게릴라 신참** | 정보 전달 라인. 게릴라 수장 모르게 직접 접촉 시도 |
| **6번 마물 사냥 제자 ↔ 14번 신입 헌터** | [E] 마물 조우로 조우. 정보 합산 |
| **9번 탐사 안내원 → 10번 망명 학자** | 마정석 지역 고대 유적 에테르 패턴 정보 전달 |
| **10번 망명 학자 ↔ 15번 도굴꾼** | 지하 수로 발견으로 연결. 케메트 비밀 해독 가능성 |
| **13번 유랑 상인** | 아프라 전역 이동. 모든 조연과 연결 가능한 허브 |
| **3번 게릴라 신참 → 11번 경호 수장** | 같은 치타 수인 계열. 포르타 중개업자 의심 공유 가능성 |
