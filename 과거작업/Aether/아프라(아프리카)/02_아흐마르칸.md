# 아흐마르 칸 (수인 국가)

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 알제리 일대. 사막·초원 경계 지역 |
| **체제** | 정착 부족 연합. 칸 + 부족장 회의 |
| **국교** | 자연 정령 신앙. 사막·바람·태양 정령 숭배 |
| **주요 종족** | 사막여우·독수리 계열 수인 중심. 사자·치타·하이에나 계열 소수 |
| **군사력** | 중위권. 사막 전투 특화 |
| **에테르 기술** | 중하위권. 수인 본능 감각 + 에테르 결합 독자 발전 |

---

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| **칸** | 부족 연합 최고 수장. 전투력·지도력·중재 능력으로 선출 |
| **부족장 회의** | 각 정착 부족 수장 참여. 칸 결정에 거부권 행사 가능 |
| **정착 형태** | 오아시스·초원 거점 중심 정착. 완전 유목은 소수 |
| **부족 자율** | 각 부족 내부 문제는 완전 자율 |

## 주요 수인 종류

### 사막 중심 (다수)

| 종류 | 특화 능력 | 에테르 보유 |
|------|----------|-----------|
| **사막여우** | 청각 압도적. 사막 지형 감지. 정보·정찰 특화 | 10명 중 8명 |
| **독수리** | 시각 압도적. 비행. 광역 정찰·기습 | 10명 중 6명 |
| **전갈** | 독소 분비. 은신·기습 특화. 야간 전투 강함 | 10명 중 4명 |

### 초원 (소수)

| 종류 | 특화 능력 | 에테르 보유 |
|------|----------|-----------|
| **사자** | 근력·위압감. 정면 전투 강함 | 10명 중 4명 |
| **치타** | 순간 속도 압도적. 기습·추격 특화 | 10명 중 5명 |
| **하이에나** | 지구력·무리 전투. 심리전 특화 | 10명 중 5명 |

## 케메트와의 관계 — 착취 구조

| 항목 | 내용 |
|------|------|
| **병사 파견** | 케메트 요청으로 수인 병사 파견. 공식 명칭은 "전투 병기" |
| **처우** | 인간 병사 대비 낮은 급여. 위험한 임무 우선 배정 |
| **귀환 문제** | 전사해도 케메트는 보상 미흡. 부상자 방치 사례 다수 |
| **협상력 부재** | 케메트 식량 의존도 높아 거부하기 어려운 구조 |

### 내부 반응

| 파벌 | 입장 |
|------|------|
| **현실파** | 당장 먹고 살아야 함. 케메트 거래 유지 불가피 |
| **저항파** | 착취 구조 끊어야 함. 말리·포르타와 관계 강화로 케메트 의존 탈피 |
| **복수파** | 언젠가 케메트에 보복. 지금은 힘을 기를 때 |

## 포르타 콘소르티움·말리 술탄국과의 관계

### 포르타 콘소르티움
- 수인 이민·취업 알선 창구. 포르타 남안(모로코)이 창구
- 케메트 의존도 낮추는 대안 수입원
- 포르타도 결국 수인을 수단으로 봄. 착취 구조 완전 탈피는 아님

### 말리 술탄국
- 교역 + 군사 영입. 케메트보다 훨씬 평등한 관계
- 말리는 수인을 인격체로 대우
- 아흐마르 칸 입장에서 케메트 의존 탈피의 핵심 경로

---

## 대외 관계

| 대상 | 관계 |
|------|------|
| **케메트** | 착취 관계. 식량 의존으로 공개 반발 못함. 내부 반감 고조 |
| **말리 술탄국** | 우호. 평등한 교역·군사 관계. 케메트 탈피 경로 |
| **포르타 콘소르티움** | 실용적 관계. 이민·취업 알선. 완전한 우호는 아님 |
| **누베트 왕국** | 동병상련. 비공식 연대 의식 존재 |
| **자한 술탄국** | 중립적 교역 |
