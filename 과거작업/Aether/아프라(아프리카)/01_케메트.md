# 케메트

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 이집트 일대. 나일강 유역 중심 |
| **체제** | 세습 왕정. 파라오 + 신관 회의 공동 권력 |
| **국교** | 케메트 고유 다신교. 태양·나일·죽음 등 자연신 pantheon |
| **주요 종족** | 인간 단일 (공식). 비인간은 노예·피지배층 |
| **군사력** | 아프라 최강. 성기사 계열 중심 |
| **에테르 기술** | 에테르·신성력 융합 체계. 아프라 독자 발전 |
| **경제력** | 나일강 기반 압도적 농업 생산력. 식량 수출로 주변 세력 경제 장악 |

## 파라오 체제

| 항목 | 내용 |
|------|------|
| **파라오** | 세습 왕정. 혈통 최우선 |
| **초기 파라오** | 강력한 신성력 보유자. 신의 대리인으로 군림 |
| **현재 파라오** | 세대를 거듭하며 신성력 약화·소멸. 현 파라오는 신성력 없거나 미약 |
| **신관 회의** | 파라오 신성력 공백을 메우며 실권 장악 |
| **파라오 권위 유지** | 신성력 없어도 신의 혈통이라는 이념으로 권위 유지 |

> 현 파라오는 **사실상 신관 회의의 꼭두각시**에 가까움
> 신성력 있는 방계 혈통 등장 시 왕위 찬탈 가능성 존재
> 신관 회의 내부에서도 파라오 혈통 교체를 논의하는 파벌 존재

## 종족 혐오 체계

### 공식 이념
- **"인간만이 신의 피조물"** — 비인간은 짐승이거나 하급 존재
- 신관 회의가 이 이념을 종교적으로 정당화·강화

### 제도적 표현

| 제도 | 내용 |
|------|------|
| **법적 무권리** | 비인간은 법적 권리 없음. 재산·노예로 취급 |
| **거주 제한** | 비인간은 지정 구역에만 거주. 자유 이동 금지 |
| **직업 제한** | 비인간은 노동·전투 등 지정 직종만 허용 |
| **혼혈 금지** | 인간과 비인간의 혼혈 법적으로 금지. 적발 시 중형 |
| **공식 선전** | 비인간 혐오를 국가 교육·종교 의식에 포함 |

### 모순 — 수인 병사

| 항목 | 내용 |
|------|------|
| **공식 입장** | 수인은 짐승. 병사가 아닌 **"전투 병기"** 로 분류 |
| **실제 운용** | 아흐마르 칸에서 영입한 수인 + 용병 매수. 정예 전투력으로 활용 |
| **처우** | 인간 병사보다 낮은 급여·대우. 인격 공식 불인정 |
| **귀족 인식** | 실용적으로 활용하면서 공식적으로는 혐오 유지 |
| **평민 인식** | 혐오 그대로. 수인 병사를 불편하게 여김 |

## 나일강 기반 경제력

### 생산력

| 항목 | 내용 |
|------|------|
| **범람 주기** | 나일강 정기 범람으로 주변 농경지에 비옥한 토사 퇴적 |
| **에테르 활용** | 나일강 특유의 에테르 흐름을 농업에 적극 활용 |
| **생산량** | 아프라 전체 식량 생산량의 상당 부분 담당. 단일 지역 기준 세계 최고 수준 |

### 식량 수출 체계

| 항목 | 내용 |
|------|------|
| **주요 수출 대상** | 누베트 왕국(강제 교역), 자한 술탄국, 아흐마르 칸, 베스테리아 일부 |
| **식량 무기화** | 교역 중단 위협으로 주변 세력 압박. 케메트의 핵심 외교 카드 |

### 농업 에테르 기술

| 기술 | 내용 |
|------|------|
| **범람 예측 술식** | 나일강 범람 시기·규모를 에테르로 사전 감지 |
| **관개 에테르 기관** | 에테르 동력 관개 시설 |
| **성장 촉진 술식** | 작물 성장 가속. 연간 수확 횟수 증가 |
| **저장 술식** | 에테르로 식량 장기 보존 |

## 에테르·신성력 융합 체계

| 기술 | 내용 |
|------|------|
| **신전 에테르 증폭** | 거대 신전 구조물이 에테르·신성력 집적·증폭 역할 |
| **오벨리스크 각인** | 거대 석조물에 신성 술식 각인. 지역 에테르 흐름 조절 |
| **미라 기술** | 에테르·신성력으로 사체 보존 |
| **나일 에테르 활용** | 나일강 특유의 에테르 흐름을 농업·건설에 활용 |

## 군사력

| 병종 | 특징 |
|------|------|
| **파라오 친위대** | 성기사 정예. 케메트 최강 전력 |
| **신관 전투대** | 에테르·신성력 융합 술식 운용. 원거리 지원 |
| **일반 보병** | 인간 병사. 수적으로 가장 많음 |
| **수인 용병대** | 공식 명칭 "전투 병기대". 실질적 정예 전투 전담 |
| **전차대** | 에테르 강화 전차. 사막 평원 전투 특화 |
