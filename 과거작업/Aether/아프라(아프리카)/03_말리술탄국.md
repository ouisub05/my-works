| **에테르 기술** | 중위권. 금·마정석 자원으로 외부 기술 적극 도입 |

## 권력 이행 — 술탄 vs 상인 귀족

### 역사적 구조
- 말리 술탄국은 원래 **대상인 가문들의 연합**에서 출발
- 술탄은 상인 귀족들이 추대한 상징적 수장에 가까웠음
- 금·마정석 장악으로 경제력 폭발적 성장 → 술탄이 이를 바탕으로 권력 강화 시도

### 현재 권력 구도

| 항목 | 내용 |
|------|------|
| **술탄** | 군사·외교 주도권 장악. 상인 귀족 견제 중 |
| **상인 귀족** | 경제 실권 유지. 술탄 독주 저지 시도 |
| **갈등 핵심** | 교역로·마정석 수익 배분권. 술탄이 국가 통제 하에 두려 함 |
| **현재 균형** | 술탄 우위. 단 상인 귀족 완전 제압은 미완 |

> 상인 귀족은 술탄 군사력 강화를 경계하며 **외부 세력과 비밀 접촉** 중

## 알-와히드 신앙

| 항목 | 내용 |
|------|------|
| **신명** | **알-와히드(Al-Wahid)** — 유일신. 전지전능한 창조주 |
| **핵심 교리** | 유일신 앞에 모든 인간은 평등. 신의 뜻에 따른 번영 추구 |
| **타 종족 인식** | 공식적으로 비인간도 알-와히드의 피조물. 차별 금지 |
| **술탄 권위** | 술탄은 알-와히드의 대리인. 신정 권위 겸비 |
| **신학 논쟁** | 수인에게도 교리 적용하는지 논쟁 중. 진보파 vs 보수파 |

## 제국화 준비 — 동맹 우선 전략

| 전략 | 내용 |
|------|------|
| **경제 종속** | 금·식량 공급으로 주변 세력 경제 의존 유도 |
| **혼인 외교** | 술탄 가문과 주변 세력 왕족·귀족 혼인 연결 |
| **종교 전파** | 알-와히드 신앙 전파로 문화적 동질감 형성 |
| **군사 보호** | 약소 세력에 군사 보호 제공. 사실상 보호국화 |
| **포르타 활용** | 포르타 콘소르티움 독점 교역에 균열. 독자 교역로 개척 시도 |

> **"말리가 싸우지 않고 이기는 방법을 안다"** 는 평가가 아프라에 돌아다님
> 케메트만큼은 동맹 불가 — 이념·영토 충돌 불가피

## 경제력

| 항목 | 내용 |
|------|------|

| **자체 교역로** | 동부 자한 술탄국과 연계한 인도양 방면 교역로 개척 진행 중 |
