# 누베트 왕국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 누비아 지역. 나일강 상류 일대 |
| **체제** | 왕정. 실질적으론 케메트 속국 |
| **국교** | 케메트 영향받은 혼합 신앙. 고유 자연신 신앙 잔존 |
| **주요 종족** | 인간 중심. 소수 수인 거주 |
| **군사력** | 하위권. 케메트 견제로 자체 군사력 제한됨 |
| **에테르 기술** | 하위권. 케메트가 기술 유출 차단 |

---

## 조공 체제

| 항목 | 내용 |
|------|------|
| **조공 내용** | 정기적으로 금·마정석·노동력(노예) 케메트에 상납 |
| **케메트 감시관** | 케메트 파견 감시관이 왕궁 내 상주. 왕의 결정 감시·보고 |
| **왕의 권한** | 내정 자치 명목이나 실제론 감시관 승인 필요 |
| **군사 제한** | 누베트 독자 군대 규모 케메트가 제한 |
| **교역 제한** | 케메트 허가 없이 외부 세력과 독자 교역 금지 |

> 누베트 왕은 **"금관을 쓴 죄수"** 라는 표현이 아프라에 돌아다님
> 왕실 내부에서도 친케메트파·저항파로 분열

---

## 자원 — 케메트 수탈 대상

| 자원 | 내용 |
|------|------|
| **금** | 나일강 상류 사금·금광 매장. 케메트 복속의 핵심 원인 |
| **마정석** | 중부 마물 다발 지대 인접. 소규모 매장. 케메트가 채굴권 장악 |
| **노동력** | 케메트 대규모 건축·농업에 누베트 노동자 강제 동원 |

> **"우리 땅의 금이 우리 목을 조른다"** 는 말이 누베트 민간에 퍼져 있음

---

## 외부 접촉 — 독립의 실마리

| 세력 | 접촉 내용 |
|------|----------|
| **말리 술탄국** | 가장 적극적 접촉. 말리는 케메트 견제 목적. 누베트는 독립 지원 기대 |
| **자한 술탄국** | 교역로 통해 비밀 서신 교환. 경제 지원 타진 |
| **아흐마르 칸** | 동병상련. 비공식 연대 의식. 구체적 협력은 미약 |

### 접촉의 한계

| 한계 | 내용 |
|------|------|
| **케메트 감시** | 감시관 존재로 외부 접촉 극히 조심스러움 |
| **군사력 부재** | 독립 의지 있어도 싸울 군사력 없음 |
| **말리 신뢰 불확실** | 말리가 진정으로 독립 지원할지 의문. 케메트 대신 말리 종속 우려 |
| **음반다 위협** | 독립 시 음반다 왕국의 병합 시도 가능성 |

> 누베트 저항파의 딜레마 — **"케메트를 몰아내려면 외부 도움이 필요한데 외부 도움은 또 다른 종속"**

## 대외 관계

| 대상 | 관계 |
|------|------|
| **케메트** | 완전 복속. 공개 반발 불가. 내부 저항 은밀히 진행 |
| **말리 술탄국** | 비밀 접촉. 독립 지원 기대. 신뢰는 불완전 |
| **자한 술탄국** | 비밀 서신 교환. 경제 지원 타진 |
| **아흐마르 칸** | 동병상련. 비공식 연대 |
| **음반다 왕국** | 표면상 동병상련. 실제론 독립 시 흡수 병합 노림 |
