# 음반다 왕국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 콩고 일대. 밀림·초원 경계 지역 |
| **체제** | 전사왕 중심 왕정 |
| **국교** | 마물 사냥 기반 전사 신앙. 강한 자가 신의 뜻을 이룬다는 교리 |
| **주요 종족** | 인간 중심. 밀림·초원 수인 혼재. 일부 구역 엘프류 거주 |
| **군사력** | 상위권. 마물 상대 전투로 단련된 정예 전사 집단 |
| **에테르 기술** | 중위권. 전투 특화 독자 발전 |

---

## 전사왕 체제

| 항목 | 내용 |
|------|------|
| **전사왕** | 왕국 최강 전사. 마물 토벌 실적·전투력으로 권위 유지 |
| **계승 방식** | 전사왕 사망·은퇴 시 후계자 결투 대회. 혈통 무관 |
| **왕의 의무** | 정기적으로 직접 마물 사냥 참여 |
| **전사 귀족** | 마물 토벌 실적으로 작위 취득. 실적 없으면 작위 박탈 가능 |
| **여전사** | 존재. 실적만 있으면 전사 귀족·전사왕 후보 가능 |

---

## 마물 사냥 문화

| 항목 | 내용 |
|------|------|
| **기본 방침** | 마물 영역에 선제적으로 침투. 마물이 오기 전에 먼저 잡음 |
| **정기 원정** | 계절마다 대규모 마물 토벌 원정 편성. 왕족·귀족 의무 참여 |
| **마물 자원** | 마물 소재 채취·가공. 핵심 교역품으로 활용 |
| **성인식** | 청년이 단독으로 마물을 처음 사냥하면 성인으로 인정 |
| **마물 소재 장식** | 강한 마물 소재로 만든 장식·무기 보유가 명예의 상징 |

## 종족 구성

### 수인

| 종류 | 특징 | 왕국 내 역할 |
|------|------|------------|
| **고릴라** | 압도적 근력. 방어·돌격 특화 | 전위 전투 담당 |
| **표범** | 민첩·은신. 기습·암살 특화 | 정찰·기습 부대 |
| **뱀** | 독소·유연성. 은신·함정 특화 | 특수 작전 담당 |
| **독수리** | 시각·비행. 광역 정찰 | 공중 정찰·마물 감시 |

> 마물 앞에서 종족 따질 여유 없다는 인식 — 수인 차별 없음

### 엘프류 거주 구역

| 항목 | 내용 |
|------|------|
| **종류** | 하프 엘프 다수. 다크 엘프 소수. 순혈 엘프 극소수 |
| **관계** | 왕국과 공존. 마물 사냥 협력. 정령 지식 제공 |
| **독립성** | 내부 자치 인정. 왕국 법 적용받으나 자체 문화 유지 |
| **정령사** | 마물 다발 지대 탐색·분석에 기여 |

---

## 에테르 기술 — 전투 특화

| 기술 | 내용 |
|------|------|
| **마물 감응** | 마물의 에테르 기척 감지 특화 |
| **독소 에테르** | 뱀 계열 수인 독소와 에테르 결합. 무기에 독소 술식 각인 |
| **밀림 강화** | 밀림 환경에서 신체 능력 강화. 엘프류 영향 받은 독자 술식 |
| **마물 소재 가공** | 마물 소재에 에테르 각인해 무기·방어구 제작 |

## 대외 관계

| 대상 | 관계 |
|------|------|
| **말리 술탄국** | 동맹 타진 수용 검토 중. 마물 소재 교역 공통 이익 |
| **자한 술탄국** | 긴장. 마물 소재 채취권 협상 중. 자한 군사력 약세로 주도권 장악 |
| **케메트** | 냉담. 접점 적음. 종족 혐오 이념에 반감 |
| **누베트 왕국** | 표면상 동병상련. 실제론 케메트에서 독립 시 흡수 병합 노림 |
| **베스테리아 용병** | 솔다텐라트 등 외부 용병이 마물 사냥 의뢰로 방문하는 경우 있음 |
