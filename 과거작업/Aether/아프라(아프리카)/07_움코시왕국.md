# 움코시 왕국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 남아프리카 일대. 남부 산악·초원 지역 |
| **체제** | 부족 연합. 드워프 기술 협력 기반 급성장 중 |
| **국교** | 조상 숭배·자연 신앙. 드워프 영향으로 장인 문화 일부 흡수 |
| **주요 종족** | 인간 다수. 드워프 소수 거주. 수인 일부 |
| **군사력** | 중하위권. 드워프 기술 도입으로 장비 수준 급상승 중 |
| **에테르 기술** | 낮음 → 드워프 기술 도입으로 빠르게 성장 중 |

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| **연합 수장** | 가장 강력한 부족장이 연합 수장 역임. 추대·실력 혼합 |
| **부족장 회의** | 각 부족 수장 참여. 주요 결정 공동 심의 |
| **드워프 대표** | 거주 드워프 장인단 대표가 회의에 참관. 발언권 있으나 의결권 없음 |
| **결속력** | 최근 마정석 발견으로 부족 간 이해 충돌 시작. 연합 균열 가능성 |

## 드워프 기술 협력

### 드워프 거주 배경
- 우르그룬트 본국과 별개로 남부 산악 지대 탐사 나온 드워프 소규모 집단
- 남부 특수 광물·마정석 매장 가능성 감지하고 자발적 정착
- 움코시 부족 연합과 **상호 이익**으로 협력 관계 성립

### 기술 협력 내용

| 항목 | 내용 |
|------|------|
| **제공 기술** | 금속 가공·합금 기술. 기초 룬 각인. 에테르 기관 소형 버전 |
| **대가** | 움코시가 드워프 거주 안전 보장. 채굴 수익 일부 배분 |
| **기술 이전 범위** | 드워프 핵심 기술은 비공개. 응용 기술만 전수 |
| **우르그룬트 관계** | 본국 비공식 인정. 공식 교역소 설치 논의 중 |

> 우르그룬트 본국은 이 관계를 주시 중 — 남부 마정석 매장 정보 입수 시 직접 개입 가능성

## 남부 마정석 — 최근 발견

| 항목 | 내용 |
|------|------|
| **발견 경위** | 드워프 탐사단이 남부 산악 지대에서 에테르 반응 감지 |
| **채굴 규모** | 소규모 시험 채굴 단계. 본격 개발 전 |
| **등급 추정** | 하급 다수 확인. 중급 이상 존재 가능성. 미확인 |
| **외부 정보 유출** | 일부 상인 통해 소문 퍼지는 중 |
| **베스테리아 반응** | 포르타 콘소르티움·마기스테리움 탐문사 접근 시작 |
| **움코시 대응** | 외부 세력 경계. 드워프 조언으로 정보 통제 시도 |

> 마정석 발견은 움코시에게 **기회이자 위기**
> 기회 — 경제력 급성장. 아프라 내 발언권 확대 가능
> 위기 — 외부 세력 개입·침략 빌미. 내부 부족 간 갈등 심화

## 급성장의 징후

| 분야 | 내용 |
|------|------|

| **에테르 기술** | 기초 룬 각인 무기 생산 시작. 아직 초보적이나 성장 속도 빠름 |
| **경제** | 마정석 발견 소문으로 외부 상인 방문 증가 |
