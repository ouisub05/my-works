# 자한 술탄국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 에티오피아·탄자니아 일대. 동부 아프라 내륙·해안 |
| **체제** | 상인 공화국 → 통합 지도자 필요성 대두 중 |
| **국교** | 알-와히드 신앙 계통. 말리와 같은 계열 |
| **주요 종족** | 인간 다수. 수인 소수 |
| **군사력** | 하위권. 자체 군사력 약함 |
| **에테르 기술** | 중하위권. 교역 특화 에테르 기술 발달 |

---

## 체제 전환 배경

| 원인 | 내용 |
|------|------|
| **음반다 군사 위협** | 의회 분산 체제로는 군사 대응 한계 |
| **해양 무역 경쟁** | 새로운 교역로 개척에 빠른 의사결정 필요. 의회 합의 구조 속도 느림 |
| **내부 가문 갈등** | 대상인 가문 간 이해 충돌 심화 |
| **말리 술탄국 압박** | 서부 교역로 장악 위협 |

> 의회 내에서 **술탄제 도입 vs 의회 강화** 논쟁 진행 중
> 일부 가문은 자신이 초대 술탄이 되려는 야심 있음

## 특산품 및 교역

| 품목 | 내용 |
|------|------|
| **향신료** | 동부 고지대 특산. 베스테리아·아시란에서 고가 |
| **커피** | 자한 원산지. 아시란 서부까지만 유통. 베스테리아 미진출 |
| **마물 소재** | 음반다 왕국 견제로 소량만 유통. 소량 고가 전략 |

> 커피는 현재 아시란 서부까지만 유통. 베스테리아는 미진출
> 자한 술탄국이 커피 유통 경로를 확대하면 막대한 수익 예상

## 해양 무역 개척 — 중간 단계

| 항목 | 내용 |
|------|------|
| **개척 현황** | 인도양 방면 주요 항로 일부 개척 완료 |
| **아시란 서부 연계** | 아시란 서부 해안 세력과 교역 관계 수립. 향신료·커피 수출 |
| **항로 안정화** | 마물·해적 위협 있음. 호위 용병 고용으로 보완 |
| **베스테리아 직거래** | 목표이나 미달성. 포르타 콘소르티움 경유 중 |

> 자한 술탄국이 베스테리아와 직거래 성공하면 포르타 콘소르티움 타격
> 포르타는 이를 견제 — 자한 항로에 해적 사주 의혹 있음

## 군사력 — 약점과 보완

| 항목 | 내용 |
|------|------|
| **자체 군사력** | 하위권. 상인 도시국가 특성상 전투 문화 약함 |
| **용병 의존** | 외부 용병 고용으로 군사력 보완. 솔다텐라트 출신 다수 |
| **음반다 대응** | 직접 군사 대응 불가. 외교·경제 회유로 관계 유지 |

## 대외 관계

| 대상 | 관계 |
|------|------|
| **음반다 왕국** | 긴장. 마물 소재 채취권 협상 중. 군사 위협 의식 |
| **말리 술탄국** | 동맹 타진 수용. 교역로 연계 공통 이익. 같은 알-와히드 신앙 |
| **케메트** | 교역 관계. 식량 수입. 정치적 거리 유지 |
| **누베트 왕국** | 비밀 서신 교환. 경제 지원 타진 |
| **아시란 서부** | 핵심 교역 파트너. 인도양 항로 연계 |
| **포르타 콘소르티움** | 현재 교역 경유처. 직거래 추진으로 관계 긴장 가능성 |
