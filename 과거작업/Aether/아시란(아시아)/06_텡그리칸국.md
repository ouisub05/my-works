## 칸 체제 — 혈통 + 실력

| 항목 | 내용 |
|------|------|
| **칸 계승** | 칸의 혈통 우선. 단 후보 중 가장 강한 자가 계승 |
| **형제 경쟁** | 칸 사망 시 아들·형제 간 실력 경쟁. 패자는 복속 or 추방 |
| **쿠릴타이** | 주요 족장 회의. 칸 선출·중대 결정 참여 |
| **텡그리 가호** | 승리한 칸은 텡그리의 선택을 받은 자로 추앙 |

> 현 칸은 에테르 무인 계열 최상위권. 직접 전투에서 무패
> 30년 전만 해도 소규모 부족 연합이었음

## 에테르 기마 전술

| 전술 | 내용 |
|------|------|
| **에테르 돌격** | 기마 돌격 시 에테르로 속도·충격력 강화 |
| **산개 마법** | 소수 마법사가 기마대와 함께 이동하며 원거리 지원 |
| **정령 연계** | 말·독수리 계열 수인의 본능 감각 + 에테르 결합. 적 위치 실시간 파악 |
| **약탈 후 흡수** | 정복 지역 에테르 기술자 포획. 기술 강제 흡수 |

> 텡그리 기마대는 **"보이지 않다가 갑자기 나타난다"** 는 공포의 대상

## 중위안·마루한과의 관계

### 중위안
- 과거 중위안 북방 변경 반복 약탈. 현재 북방 위협 현실화
- 중위안은 방어선 강화. 텡그리 내부 분열 공작 시도

### 마루한
- 중위안 조공 체제 거부. 반중위안 공통 이해
- 암묵적 연대. 중위안 공격 시 마루한이 동쪽에서 동시 압박 기대
- 완전한 동맹은 아님. 텡그리가 강해지면 마루한도 위협
