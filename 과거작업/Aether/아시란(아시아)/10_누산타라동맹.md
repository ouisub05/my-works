# 누산타라 동맹

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 동남아시아 섬 일대. 수마트라·자바·보르네오 등 |
| **체제** | 느슨한 섬 연합. 맹주 존재하나 권한 제한적 |
| **국교** | 없음. 섬마다 다른 신앙 공존 |
| **주요 종족** | 인간 다수. 상어·문어·새 계열 수인 다수 |
| **군사력** | 중위권. 해상 전투 특화. 육상 전투 약함 |
| **에테르 기술** | 중하위권. 해양·항해 특화 에테르 기술 |

---

## 느슨한 섬 연합 구조

| 항목 | 내용 |
|------|------|
| **맹주** | 가장 강력한 섬 세력이 맹주 역임. 교체 잦음 |
| **맹주 권한** | 대외 교섭 대표. 공동 해적 대응. 그 외 간섭 없음 |
| **섬 자율** | 각 섬 내정·교역·종교 완전 자율 |
| **결속 조건** | 외부 세력 침략·해적 대규모 출현 시만 공동 대응 |

---

## 섬별 성격 — 무역·해적 혼재

| 유형 | 특징 |
|------|------|
| **무역 중심 섬** | 항구 도시 발달. 각지 상인 집결. 중립 유지 |
| **해적 중심 섬** | 약탈이 주수입. 특정 세력과 암묵적 거래 |
| **혼합 섬** | 낮에는 상인, 밤에는 해적. 상황에 따라 전환 |

> 누산타라 동맹 내 해적은 프레이 아르키펠과 달리 국가 차원의 조직 없음
> 개별 섬·집단 단위로 활동. 맹주도 통제 못함
