# 마루한 제국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 만주·연해주·시베리아 남부 직할. 한반도·몽골 동부 영향권 |
| **체제** | 황제 중심 제국. 군사 귀족 보좌 |
| **국교** | 없음. 조상 숭배·천신 신앙 혼합 |
| **주요 종족** | 인간 다수. 호랑이·곰·독수리·늑대 계열 수인 포함 |
| **군사력** | 동부 최강. 아시란 전체 최상위권 |
| **에테르 기술** | 상위권. 에테르 기관 기술 독자 발전. 군사·산업 특화 |

## 황제 체제

| 항목 | 내용 |
|------|------|
| **황제** | 절대 권력. 군사·정치 모두 장악 |
| **군사 귀족** | 전공으로 작위 취득. 세습 가능하나 전투력 유지 의무 |
| **상서성** | 행정 관료 집단. 중위안 관료제 모티프이나 군사 귀족이 실권 |

> 마루한은 **"문(文)보다 무(武)"** 가 기본 가치관
> 관료 출신보다 전장에서 공을 세운 자가 더 존경받음

---

## 에테르 기관 기술 — 독자 발전

드워프 기술과 독립적으로 발전. 드워프와 기술 교류 없음.

| 기술 | 내용 |
|------|------|
| **에테르 난방 기관** | 극한 혹한 환경 대응. 군영·도시 난방 시스템 |
| **에테르 추진 전함** | 강·해상 고속 이동 전함. 동부 해상 전력 핵심 |
| **에테르 동력 공성 기관** | 요새 공략용 대형 에테르 기관. 독자 설계 |
| **에테르 제련로** | 금속 정제·합금 에테르 기관. 무기 대량 생산 가능 |
| **통신 기관** | 에테르 신호 장거리 전달 기관. 군사 통신 특화 |

> 드워프 우르그룬트도 마루한 에테르 기관 기술을 주시 중
> 일부 기술은 드워프가 **"어떻게 이걸 독자 개발했지?"** 라며 놀랄 수준
