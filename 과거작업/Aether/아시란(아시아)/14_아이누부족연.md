# 아이누 부족연

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 홋카이도 일대 |
| **체제** | 부족 연합. 대장로 중심 |
| **국교** | 자연 정령 신앙. 카무이(신령) 숭배 |
| **주요 종족** | 인간 다수. 흰곰·흰여우·독수리 계열 수인 소수 |
| **군사력** | 하위권. 단 홋카이도 지형에서는 야마토 상대로 대등 |
| **에테르 기술** | 중하위권. 수렵·자연 특화 에테르 기술 |
| **인구** | 10만 이하. 다수 소규모 부족으로 분산 거주 |

---

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| **대장로** | 가장 경험 많고 존경받는 장로. 부족 연합 대표 |
| **부족 장로 회의** | 각 부족 장로 참여. 중요 결정 공동 심의 |
| **전시 수장** | 야마토 침공 시 전투 지휘 전담 수장 별도 선출 |

---

## 야마토 복속 압박 — 지형 활용 저항

| 요소 | 내용 |
|------|------|
| **혹한** | 겨울 극한 추위. 아이누는 적응했으나 야마토 병사는 취약 |
| **밀림·습지** | 대규모 군대 이동 어려움. 소규모 게릴라전에 유리 |
| **해안 복잡성** | 상륙 지점 제한. 대규모 상륙 작전 난항 |
| **마물 다발** | 홋카이도 내륙 마물 다발 지대. 야마토 군대 마물 피해 |

### 저항 전술

| 전술 | 내용 |
|------|------|
| **게릴라전** | 소규모 기습·매복. 정면 대결 회피 |
| **겨울 전술** | 겨울에 집중 반격. 야마토 병사 혹한 취약점 공략 |
| **마물 유인** | 야마토 군대를 마물 서식지로 유인 |
| **퇴각·잠적** | 압도 시 내륙 깊숙이 퇴각. 추격 차단 |

## 수렵 특화 에테르 기술

| 기술 | 내용 |
|------|------|
| **기척 소거** | 에테르로 자신의 존재감 희석 |
| **감각 강화** | 청각·후각 에테르 강화. 원거리 기척 감지 |
| **함정 술식** | 지형에 에테르 함정 각인 |
| **빙설 강화** | 눈·얼음 에테르 조작 |
| **마물 분석** | 마물 에테르 패턴 감지. 약점 파악 |

## 대외 관계

| 대상 | 관계 |
|------|------|
| **야마토 막부** | 저항 중. 완전 복속 거부. 교역은 일부 허용 |
| **마루한 제국** | 비공식 접촉. 야마토 견제 목적. 마루한은 완충 지대로 활용 |
| **타이가 부족연** | 북방 부족 연대. 비공식 교류. 수인 공통 문화 공유 |
