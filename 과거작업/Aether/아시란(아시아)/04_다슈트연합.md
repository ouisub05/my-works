# 다슈트 연합

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 카자흐스탄 일대. 중앙아시아 초원·사막 경계 |
| **체제** | 정착 부족 연합. 대표 수장 + 부족장 회의 |
| **국교** | 자연 정령 신앙. 초원·바람·말 정령 숭배 |
| **주요 종족** | 인간 다수. 말·독수리 계열 수인 소수 |
| **군사력** | 중위권. 기마 전투 특화 |
| **에테르 기술** | 중하위권. 이동·정찰 특화 에테르 기술 |

---

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| **대표 수장** | 가장 유력한 부족장. 아르다샤르 황제 승인 필요 |
| **부족장 회의** | 정기적으로 회합. 주요 결정 공동 심의 |
| **정착 거점** | 실크로드 교차점마다 정착 도시 형성 |
| **유목 부족** | 정착 도시 외곽 초원에서 목축·이동 생활 |

---

## 실크로드 운영

| 항목 | 내용 |
|------|------|
| **통행세** | 북방 육로 통과 상인에게 구간별 통행세 징수 |
| **보호 서비스** | 다슈트 기마대가 상인 호위. 별도 요금 |
| **카라반사라이** | 교역로 거점마다 숙박·보급소 운영 |
| **정보 수집** | 오가는 상인에게 각지 정보 자연스럽게 수집 |

> 다슈트 연합의 실질 수입원은 군사력보다 **실크로드 서비스업**

---

## 아르다샤르 종속 관계

| 항목 | 내용 |
|------|------|
| **공식 관계** | 아르다샤르 제국 북방 속령. 대표 수장 임명 황제 승인 |
| **실질 자치** | 내정·종교·교역 완전 자치 |
| **의무** | 정기 공물 납부. 전시 기마대 파견 |
| **이익** | 아르다샤르 군사력 배경으로 텡그리 칸국 압박 견제 |

> 텡그리 칸국이 강해질수록 아르다샤르 종속의 실익 증가
> 아르다샤르가 약해지면 독립 혹은 텡그리로 전향 가능성
> 다슈트의 충성은 **"힘센 쪽에 붙는다"** 는 현실적 판단

| 대상 | 관계 |
