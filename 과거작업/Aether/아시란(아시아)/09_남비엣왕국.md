# 남비엣 왕국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 베트남 일대. 메콩강 델타·해안 중심 |
| **체제** | 분권 왕정. 왕권 강화 중. 영주와 갈등 |
| **국교** | 조상 숭배·자연신 신앙. 중위안 영향받은 의식 혼합 |
| **주요 종족** | 인간 다수. 물고기·새 계열 수인 소수 |
| **군사력** | 중위권. 수전·밀림 전투 특화 |
| **에테르 기술** | 중위권. 농업·수전 특화 에테르 기술 발달 |

---

## 분권 왕정 구조

| 항목 | 내용 |
|------|------|
| **왕** | 명목상 최고 권력. 외교·전쟁 주도 |
| **지역 영주** | 델타·해안 각 지역 통치. 강한 자치권 보유 |
| **왕권 강화 시도** | 현 왕이 영주 견제·중앙 집권 추진 중 |
| **영주 반발** | 자치권 침해에 저항. 외부 세력과 접촉하는 영주 존재 |

> 일부 영주는 중위안 지지. 다른 영주는 독립 강화 지지
> 왕이 너무 강해지면 영주들이 외세 끌어들일 가능성

---

## 쌀 농업 기반 경제

| 항목 | 내용 |
|------|------|
| **생산량** | 메콩강 델타 비옥한 토지. 아시란 최고 쌀 생산량 |
| **에테르 농업** | 성장 촉진 술식·관개 에테르 기관 적극 활용. 연 3모작 가능 |
| **잉여 식량** | 대규모 잉여 발생. 아시란 전역에 쌀 수출 |
| **식량 외교** | 쌀 수출을 외교 카드로 활용 |

> 남비엣의 쌀 생산량은 아시란 식량 안보의 핵심
> 중위안이 남비엣을 완전히 복속하지 않는 이유 중 하나

## 기회주의적 대중위안 관계

| 상황 | 행동 |
|------|------|
| **중위안 강성 시** | 조공 충실히 이행. 중위안 문화·술식 적극 수용 |
| **중위안 약화 시** | 조공 축소·지연. 독립적 외교 행보 |
| **위협 시** | 중위안에 다시 밀착. 보호 요청 |
| **현재 상태** | 텡그리 칸국 성장으로 중위안 집중력 분산 → 남비엣 독립 행보 증가 중 |

## 군사력

| 병종 | 특징 |
|------|------|
| **수군** | 메콩강·해안 수전 특화. 소형 고속 선박 중심 |
| **밀림 전사** | 밀림 지형 활용 게릴라전. 에테르 은신 술식 발달 |
| **물고기 계열 수인** | 수중 전투·정찰 특화. 수군과 협력 |
| **독화살대** | 밀림 특산 독소 활용. 원거리 저격 |
