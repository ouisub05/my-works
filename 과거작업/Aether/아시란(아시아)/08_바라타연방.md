# 바라타 연방

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 인도 일대. 인도양 연안 중심 |
| **체제** | 단일 왕정. 마하라자(대왕) 중심 |
| **국교** | 다신교. 자연·창조·파괴신 pantheon |
| **주요 종족** | 인간 다수. 코끼리·뱀·공작 계열 수인 소수 |
| **군사력** | 중상위권. 해군 강함. 코끼리 부대 독특 |
| **에테르 기술** | 중상위권. 향신료·교역 수익으로 외부 기술 도입 활발 |

## 왕정 구조

| 항목 | 내용 |
|------|------|
| **마하라자** | 대왕. 종교·세속 권위 겸비. 신의 대리인 개념 |
| **지방 라자** | 각 지역 왕족이 지방 통치. 마하라자에게 충성 |
| **브라만 신관** | 종교 의식·교육 담당. 정치 자문 역할 |
| **상인 계층** | 경제력 바탕으로 발언권 강함 |

> 명목상 단일 왕정이나 지방 라자의 자치권이 강해 사실상 연방에 가까운 운영

## 경제력 — 향신료 독점 + 아프라 해상 무역

### 향신료 독점

| 항목 | 내용 |
|------|------|
| **생산량** | 세계 향신료 생산의 압도적 비중 차지 |
| **품목** | 후추·생강·계피·카다멈 등 다양 |
| **베스테리아 수요** | 베스테리아에서 향신료는 금과 맞먹는 가치. 귀족층 필수품 |
| **유통 경로** | 자한 술탄국 → 인도양 → 포르타 콘소르티움 → 베스테리아 |

### 아프라 해상 무역

| 항목 | 내용 |
|------|------|
| **교역 파트너** | 자한 술탄국 핵심. 아프라 동부 연안 세력 |
| **항로** | 인도양 남방 해로 핵심 거점. 자한과 공동 운영 |

> 포르타 콘소르티움이 이 루트를 탐냄 — 바라타·자한 직거래 견제 중

## 군사력

| 병종 | 특징 |
|------|------|
| **코끼리 부대** | 코끼리 계열 수인 기수. 에테르 강화 갑옷 착용. 돌격·심리전 압도적 |
| **해군** | 인도양 해상 전투 특화. 대형 전함 다수 보유 |
| **궁수대** | 원거리 전투 특화. 독화살·에테르 각인 화살 사용 |
| **뱀 계열 수인 특수대** | 독소·은신 특화. 암살·특수 작전 담당 |

---

## 신성력

- 독자적 신성력 발전 없음
- 다신교 신앙은 강하나 신성력 운용자 희소
- 에테르 기술과 종교 의식의 결합이 특징
- 브라만 신관의 의식 중 에테르 증폭 효과 나타나는 경우 있음
- 이것이 신성력인지 에테르인지 내부에서도 논쟁 중

## 대외 관계

| 대상 | 관계 |
|------|------|
| **자한 술탄국** | 핵심 교역 파트너. 인도양 항로 공동 운영 |
| **누산타라 동맹** | 동남아 해로 연계. 향신료 유통 협력 |
| **하이둥 상방** | 해상 교역 경쟁. 동아시아 시장 두고 갈등 |
| **포르타 콘소르티움** | 현재 교역 경유처. 직거래 시도로 긴장 가능성 |
| **강티세 동맹** | 고산 접경. 철학·교류 비교적 우호 |
| **중위안 제국** | 실크로드 교역. 문화 영향 받았으나 조공 거부 |
