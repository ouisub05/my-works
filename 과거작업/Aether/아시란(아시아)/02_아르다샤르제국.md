# 아르다샤르 제국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 메소포타미아·페르시아 일대 |
| **체제** | 황제 중심 제국 |
| **국교** | 없음. 피정복 지역 종교 흡수·공존 |
| **주요 종족** | 인간 다수. 수인 소수 |
| **군사력** | 아시란 서부 최강 |
| **에테르 기술** | 상위권. 베스테리아와 기술 교류로 발달 |

---

## 황제 체제

| 항목 | 내용 |
|------|------|
| **황제** | 절대 권력. 군사·외교·종교 모두 장악 |
| **총독 체제** | 피정복 지역마다 황제 직속 총독 파견. 현지 문화 유지 허용 |
| **군사 귀족** | 정복 공훈으로 작위 취득 |
| **종교 정책** | 피정복 지역 종교 금지하지 않음. 흡수해 제국 문화로 통합 |

> **"정복하되 파괴하지 않는다"** 는 통치 철학
> 알-와히드 신앙처럼 유일신 신앙은 흡수 거부 → 충돌 발생

---

## 군사력

| 병종 | 특징 |
|------|------|
| **불사대(不死隊)** | 황제 직속 정예. 항상 1만 명 유지. 결원 즉시 보충 |
| **전차·기병대** | 사막·평원 전투 특화. 에테르 강화 군마 |
| **공성 부대** | 에테르 기관 활용 공성 장비 |
| **마법사 부대** | 베스테리아 술식 체계 도입. 포격·결계 담당 |

---

## 베스테리아와의 관계

### 카이저라이히
- 흑해·지중해 동부 교역로 통제권. 솔다텐라트 주변 영향권 충돌
- 직접 전쟁은 아니나 대리전·영향권 경쟁 지속
- 솔다텐라트 용병을 양측 모두 고용하는 아이러니한 구도

### 케메트
- 레반트·시리아 일대 영향권 경쟁
- 냉전. 직접 충돌보다 대리 세력 충돌
- 케메트 식량 수입으로 완전 단절은 아님

---

## 대외 관계

| 대상 | 관계 |
|------|------|
| **카이저라이히** | 교역로·영향권 분쟁. 대리전 |
| **케메트** | 냉전. 레반트 영향권 경쟁. 식량 교역으로 완전 단절 아님 |
| **알-티자라 왕국** | 경제 의존 관계. 아라비아 교역로 통제 공유 |
| **다슈트 연합** | 북방 완충 세력. 실크로드 통행 협력 |
| **중위안 제국** | 실크로드 교역. 직접 충돌 없음 |
| **솔다텐라트** | 용병 고용. 카이저라이히와 같은 용병 쓰는 아이러니 |
