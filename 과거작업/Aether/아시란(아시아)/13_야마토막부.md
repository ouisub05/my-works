# 야마토 막부

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 일본 열도 일대 |
| **체제** | 쇼군 중심 막부. 천황은 명목상 권위 |
| **국교** | 없음. 자연신·조상신 신앙. 에테르 무인 숭배 문화 |
| **주요 종족** | 인간 다수. 여우·너구리 계열 수인 소수 |
| **군사력** | 중상위권. 개인 전투력 아시란 최고 수준급 |
| **에테르 기술** | 중상위권. 검술·무인 에테르 체계 극도로 발달 |

---

## 막부 구조

| 항목 | 내용 |
|------|------|
| **쇼군** | 실질 최고 권력자. 군사·행정 모두 장악 |
| **천황** | 명목상 권위의 원천. 쇼군 임명 형식적 승인 |
| **다이묘** | 지방 영주. 통일 후 쇼군에 복속. 독자 군사력 보유 허용 |
| **사무라이** | 에테르 무인 계층. 다이묘 직속 전투 집단 |

---

## 전국 통일 — 완전 통일 직후

| 항목 | 내용 |
|------|------|
| **통일 경위** | 현 쇼군이 수십 년 전국 시대 종식. 압도적 에테르 무력으로 제압 |
| **현 상태** | 모든 다이묘 복속 완료. 명목상 안정기 |
| **잠복 갈등** | 패배한 다이묘 잔당·불만 세력 잠복 |
| **쇼군 과제** | 불만 세력 에너지를 해외 팽창으로 돌리는 전략 채택 |

> **"칼을 녹슬게 하면 사무라이가 반란을 일으킨다"** 는 인식

|------|------|----------|

## 에테르 검술 — 주요 유파

| 유파 | 특징 |
|------|------|
| **무토류(無刀流)** | 에테르만으로 검 대체. 무기 없이 에테르 참격 발사 |
| **강기류(剛氣流)** | 에테르로 신체·무기 극한 강화. 단일 일격 특화 |
| **유수류(流水流)** | 에테르 흐름 제어. 상대 에테르 역이용. 반격 특화 |
| **뇌신류(雷神流)** | 에테르 속도 극한화. 신체 속도·반응 극대화 |

> 야마토 사무라이 개인 전투력은 아시란 최고 수준
> 단 집단 전투·기관 기술에서 마루한에 밀림

## 대외 관계

| 대상 | 관계 |
|------|------|
| **마루한 제국** | 경계. 대륙 진출 시 충돌 불가피. 현재 탐색 중 |

| **하이둥 상방** | 교역 경쟁. 동부 해로 통제권 갈등 |
| **아이누 부족연** | 복속 압박 중. 저항 지속 |
| **누산타라 동맹** | 남방 탐험 중. 교역 관계 수립 시도 |
