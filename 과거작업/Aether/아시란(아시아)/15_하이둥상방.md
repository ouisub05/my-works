# 하이둥 상방

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 베이징~광둥 해안 일대. 황해·동중국해 연안 |
| **체제** | 상인 공화국. 상인 의회 중심 |
| **국교** | 없음. 조상 숭배·해신 신앙 혼합 |
| **주요 종족** | 인간 다수. 물고기·게·새 계열 수인 소수 |
| **군사력** | 중위권. 해군 강함. 육군 약함 |
| **에테르 기술** | 중상위권. 교역·항해·생산 특화 에테르 기술 |

## 상인 공화국 구조

| 항목 | 내용 |
|------|------|
| **상인 의회** | 주요 항구 도시 대상인 대표 참여. 최고 의결 기관 |
| **집정관** | 의회에서 선출. 임기 3년. 대외 교섭·행정 수반 |
| **항구 도시 자치** | 각 항구 도시 내정 완전 자율 |
| **상단 연합** | 대형 상단이 사실상 정치 세력. 의회 내 파벌 형성 |

> **"하이둥은 만든다. 마레는 판다"** 는 말이 아시란에 돌아다님

## 생산력 기반 경제

| 항목 | 내용 |
|------|------|
| **제조업** | 도자기·비단·에테르 각인 공예품. 세계 최고 품질·물량 |
| **에테르 대량 생산** | 술식 각인 생활용품 대량 생산. 단가 낮음. 아시란 전역 유통 |

## 중위안과의 반독립 관계

| 항목 | 내용 |
|------|------|
| **공식 관계** | 중위안 영향권. 조공 형식 유지 |
| **독립 행동** | 중위안 허가 없이 독자 외교·교역 추진 |
| **중위안 반응** | 하이둥 경제력 때문에 강압적 복속 어려움. 묵인 |

> 하이둥은 **"중위안이 필요로 하는 생산력"** 이 최대 협상 카드

---

## 마루한과의 중립

- 직접 충돌 회피. 교역 우선
- 동부 해로를 마루한·하이둥이 암묵적으로 구역 분점
- 마루한 에테르 기관 제품 수입. 하이둥 생산품 수출
