# 강티세 동맹

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 티벳·위구르 일대. 고산·사막 경계 |
| **체제** | 문파 연합. 맹주 선출제 |
| **국교** | 없음. 문파별 독자 신앙 |
| **주요 종족** | 인간 다수. 설표·독수리 계열 수인 소수. 엘프류 일부 거주 |
| **군사력** | 중상위권. 개인 전투력 아시란 최고 수준 |
| **에테르 기술** | 상위권. 문파별 독자 체계. 개인 에테르 운용 극한 발전 |

---

## 문파 연합 구조

| 항목 | 내용 |
|------|------|
| **문파** | 고산·사막 각지에 위치한 독립 수련 집단 |
| **맹주** | 문파 대표들이 선출. 전체 연합 대표 역할 |
| **맹주 권한** | 대외 교섭·분쟁 조율만 담당. 각 문파 내부 간섭 불가 |
| **연합 의무** | 외부 세력이 강티세 전체를 위협할 때만 공동 대응 |

### 주요 문파 유형

| 유형 | 특징 |
|------|------|
| **내공 문파** | 무인 계열. 신체 에테르 극한 발전. 맨몸 전투 특화 |
| **술식 문파** | 마법사 계열. 고산 자연 에테르 활용. 독자 술식 체계 |
| **정령 문파** | 강티세 동맹 내 엘프류 거주 집단이 운영. 외부에 잘 알려지지 않아 오해 발생 |
| **혼합 문파** | 내공+술식 병행. 쌍도(雙道) 연구 중이나 고대 기록은 과장·왜곡 많음. 현재까지 진전 없음 |

---

## 은둔 고수

- 실재 여부 불명. **전설·소문으로만 존재**
- 목격담은 있으나 검증된 사례 없음
- 강티세 동맹 자체도 공식적으로 존재를 인정하지 않음
- 외부 세력이 강티세를 함부로 못 건드리는 이유 중 하나로 **"혹시 모를 은둔 고수"** 가 거론되는 정도

## 이득에 따른 행동 원칙

| 행동 유형 | 내용 |
|----------|------|
| **의뢰 수행** | 금전·마정석·희귀 자원 대가로 특정 임무 수행 |
| **기술 거래** | 독자 에테르 술식을 외부에 판매. 고가 |
| **제자 수용** | 재능있는 외부인을 제자로 받기도 함. 문파 독자 기준 |
| **개입 거부** | 이득 없으면 어떤 요청도 거절. 강대국도 예외 없음 |

> **"강티세를 완전히 아군으로 만든 자는 역사상 없다"**

## 에테르 기술 — 문파별 독자 체계

| 항목 | 내용 |
|------|------|
| **공통점** | 개인 에테르 운용 극한 발전. 세계 최고 수준의 개인 전투력 |
| **내공 계열** | 체내 에테르 경로 극한 개척. 신체 능력 초인적 강화 |
| **술식 계열** | 고산 에테르 흐름 직접 활용. 마정석 의존 없음 |
| **비전(秘傳)** | 각 문파 핵심 기술은 외부 유출 금지 |
