## 상인 왕정 — 절대 왕정 이행 고민

### 현재 체제
- 왕이 최대 상인 가문 출신. 귀족 전원 대상인 가문
- 왕의 권위는 **"가장 부유한 자"** 에서 나옴
- 주요 정책은 상인 귀족 합의로 결정

### 절대 왕정 이행 고민 배경

| 원인 | 내용 |
|------|------|
| **아르다샤르 압박** | 반독립 상태에서 아르다샤르 요구 증가. 빠른 대응 어려움 |
| **케메트 위협** | 서쪽 케메트 팽창. 군사적 대응 필요성 증가 |
| **내부 분열** | 상인 가문 간 이해 충돌 심화 |
| **현 왕 성향** | 권력 집중 의지 강함. 상인 귀족과 마찰 중 |

> 현 왕은 **"두 제국 사이에서 살아남으려면 왕권 강화가 필수"** 입장
> 상인 귀족은 **"왕권 강화는 우리 이익 침해"** 라며 반발

## 알-와히드 신앙

- 말리·자한 술탄국과 같은 알-와히드 계통
- 아라비아 특유의 **상업 윤리 강조** 변형
  - 정직한 거래는 신의 뜻. 사기·착취는 금기
  - 상인의 성공은 신의 축복의 증거라는 교리

## 아르다샤르와의 반독립 관계

| 항목 | 내용 |
|------|------|
| **공식 관계** | 독립국. 아르다샤르 황제 종주권 명목상 인정 |
| **실질 관계** | 교역로 수익 일부 아르다샤르에 납부. 군사 요청 시 협력 의무 |
| **자치 범위** | 내정·종교·상업 완전 자치. 외교는 아르다샤르 눈치 봐야 함 |
| **생존 전략** | 두 제국 사이에서 어느 쪽도 완전히 믿지 않고 양쪽 다 이용 |

## 교역 중심 경제

| 항목 | 내용 |
|------|------|
| **주요 교역품** | 향신료·유향·진주·낙타 등 아라비아 특산물 |
| **교역 루트** | 아라비아 루트 (베스테리아 직결) + 남방 해로 연결 |
| **금융** | 이슬람 금융 모티프. 이자 금지. 수익 분배 방식 독자 발전 |

## 대외 관계

| 대상 | 관계 |
|------|------|
| **아르다샤르 제국** | 반독립. 종주권 명목 인정. 내부 반발 존재 |
| **케메트** | 경계. 완전 적대는 아님. 아르다샤르 견제 카드로 활용 |
| **말리 술탄국** | 종교 연대. 직접 교류는 아르다샤르가 중간에서 제한 |
| **중위안 제국** | 실크로드 교역 |
| **바라타 연방** | 해상 교역. 향신료 공동 유통 |
