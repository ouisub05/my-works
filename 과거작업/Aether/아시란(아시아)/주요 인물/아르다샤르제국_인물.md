# 아르다샤르 제국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 황제 (Shahanshah)

| 항목 | 내용 |
|------|------|
| **직위** | 아르다샤르 제국 황제. 왕중왕(Shahanshah) |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 전통 페르시아 검술+에테르 강화 |
| **성격** | 신중하고 인내심 강함. 급격한 변화보다 점진적 강화 선호. 내부 통합에 집중 |
| **현재 상황** | 광대한 제국 내부 행정 정비 중. 알-티자라 종속 강화 vs 현상 유지 논쟁 중재 |
| **핵심 목표** | 제국 내부 통합·행정 효율화. 텡그리 칸국 압박 완충 체계 구축 |
| **갈등 요소** | 군사 귀족 팽창 요구와 내부 통합 우선 방침 충돌. 조로아스터 신관 영향력 견제 필요 |

### 세부 특성
- 즉위 후 수십 년간 영토 확장보다 통치 체계 정비에 집중. 군사 귀족 불만 누적
- 알-티자라 왕국을 종속 강화하면 저항 유발 가능성 계산. 현상 유지 쪽에 무게
- 텡그리 칸국 성장이 최대 외부 위협. 다슈트 연합 완충 체계 유지 필수
- 서부 방위대장과 동부 원수 모두 신임. 양측 균형 유지

## 2. 조로아스터 대신관 (Mobad Mobadan)

| 항목 | 내용 |
|------|------|
| **직위** | 아후라 마즈다 신앙 최고 신관. 제국 종교 수장 |
| **에테르** | 엘리트 하 (4단계). 성기사 계열. 아후라 마즈다 신성력 특화 |
| **성격** | 점잖고 학식 높음. 신앙의 순수성 수호를 최우선. 알-와히드 신앙 확산에 경계심 |
| **현재 상황** | 알-티자라·다슈트 연합의 알-와히드 신앙 확산 주시. 황제에게 종속 강화 압박 |
| **핵심 목표** | 조로아스터 신앙 제국 내 지위 보전. 알-와히드 신앙 세력 확장 차단 |
| **갈등 요소** | 황제가 종교 문제보다 실용적 통치를 우선. 신관 권위 무시당하는 느낌 |

### 세부 특성
- 알-티자라 종속 강화 주장의 배경 중 하나가 알-와히드 신앙 확산 차단
- 군사 귀족과 이해관계 일치하는 부분 있음. 종교적 명분으로 팽창 정당화 가능
- 황제의 내부 통합 우선 방침에 표면 지지. 실제론 종교 확장 기회 탐색

## 3. 알-티자라 종속 강화파 귀족 (Ispahbad al-Gharb)

| 항목 | 내용 |
|------|------|
| **직위** | 제국 서부 총독. 알-티자라 담당 |
| **에테르** | 엘리트 상 (6단계). 무인 계열 |
| **성격** | 공격적이고 야심적. 알-티자라 독립 성향을 제국 권위에 대한 도전으로 인식 |
| **현재 상황** | 알-티자라 왕에 대한 압박 강화 시도. 황제 허가 기다리는 중 |
| **핵심 목표** | 알-티자라 완전 복속. 아라비아 반도 교역 수익 직접 장악 |
| **갈등 요소** | 황제가 현상 유지 쪽으로 기울어 좌절. 신관과 연대해 황제 설득 시도 중 |

### 세부 특성
- 알-티자라 왕의 절대 왕정 이행 시도를 제국 약화 신호로 해석. 선제 복속 주장
- 케메트·말리 동시 견제 의도도 있음. 알-티자라 통제로 아라비아 루트 장악
- 서부 방위대장과 관계 냉담. 방위 중심 사고를 답답하게 봄

## 4. 제국 원수 (Spahbod-e Kol)

| 항목 | 내용 |
|------|------|
| **직위** | 아르다샤르 제국 전군 총사령관. 동부 전선 총괄 |
| **에테르** | 엑스퍼트 상 (9단계). 무인 계열. 대규모 집단 전투·기병 지휘 특화 |
| **성격** | 전략 천재. 전투 현장보다 전쟁 전체 그림을 봄. 황제의 내부 통합 방침 이해하나 동의 못 함 |
| **현재 상황** | 동부 텡그리 칸국 압박 대응 총괄. 다슈트 연합 완충 유지 관리 |
| **핵심 목표** | 텡그리 칸국 견제. 동부 전선 안정화 |
| **갈등 요소** | 황제의 팽창 자제 방침에 불만. 텡그리 성장 저지하려면 선제 행동 필요하다는 판단 |

### 세부 특성
- 텡그리 칸국 현 칸의 에테르 기마 전술을 직접 경험. 위협 현실로 파악
- 다슈트 연합 부족장들과 개인 관계 유지. 실크로드 안정화 비공식 협력
- 강티세 동맹 문파들과 비공식 접촉. 기술 거래 가능성 탐색
- 서부 방위대장과 상호 존중. 동·서 전선 분담 협력

## 5. 서부 방위대장 (Marzban-e Gharb)

| 항목 | 내용 |
|------|------|
| **직위** | 제국 서부 국경 방위 총사령관. 베스테리아 방면 담당 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 요새 방어·진지전 특화 |
| **성격** | 과묵하고 원칙적. 공격보다 방어를 예술로 보는 철학. 알-티자라 총독의 공격적 성향과 충돌 |
| **현재 상황** | 베스테리아 솔다텐라트와 접경 관리. 마기스테리움 동향 주시 |
| **핵심 목표** | 서부 국경 완벽 방어. 베스테리아 세력 침투 차단 |
| **갈등 요소** | 알-티자라 총독이 자신의 관할 지역 내 알-티자라 압박 주도하려는 것에 반발 |

### 세부 특성
- 솔다텐라트 국경 기사단장과 수년간 접경 관리 협력. 비공식 신뢰 관계
- 마기스테리움 졸업생이 카이저라이히 우선 배치되는 구도 경계
- 베스테리아 포르타 콘소르티움 아프라 독점이 아르다샤르 교역에도 영향 인식. 주시 중
- 황제의 내부 통합 방침 가장 충실히 지지. 방어 중심 방침과 일치

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **황제 → 제국 원수** | 신임. 동부 전선 위임 |
| **황제 → 서부 방위대장** | 신임. 내부 통합 방침 일치 |
| **황제 → 대신관** | 종교 권위 존중. 종교 우선 주장 견제 |
| **황제 → 알-티자라 총독** | 경계. 독단 행동 억제 |
| **대신관 ↔ 알-티자라 총독** | 연대. 종속 강화 공동 추진 |
| **알-티자라 총독 ↔ 서부 방위대장** | 냉담. 관할 갈등 |
| **제국 원수 ↔ 서부 방위대장** | 상호 존중. 동·서 전선 협력 |
| **제국 원수 → 텡그리 칸국** | 위협 현실 파악. 선제 대응 주장 |
| **서부 방위대장 → 솔다텐라트 국경 기사단장** | 비공식 신뢰 관계 |
