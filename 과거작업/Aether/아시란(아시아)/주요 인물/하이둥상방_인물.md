# 하이둥 상방 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 하이둥 상방은 세계 최강 생산력 보유 상인 공화국. 중립 교역 원칙. 야마토 침략 대응이 현재 최대 현안.

---

## 1. 집정관 (Zhizheng)

| 항목 | 내용 |
|------|------|
| **직위** | 하이둥 상방 집정관. 상인 의회 선출직. 임기제 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열. 탐지·분석 에테르. 협상 보조 |
| **성격** | 안정 지향. 하이둥 생산·교역 기반이 모든 것의 근본이라는 철학. 전쟁·갈등을 손실로만 봄 |
| **현재 상황** | 야마토 강경 대응파와 교역 유지파 갈등 중재 중. 마루한과 동부 해로 분점 협약 유지 |
| **핵심 목표** | 하이둥 교역 기반 안정. 어느 세력과도 전면 충돌 회피 |
| **갈등 요소** | 야마토 침략 피해 누적으로 강경 대응파 목소리 커짐. 유지 원칙 압박 증가 |

### 세부 특성
- 마루한·중위안·야마토 모두와 교역 유지. 정치 중립 철저
- 야마토 강경 다이묘의 상선 약탈에 공식 항의. 실질 보복 자제
- 중위안 수석 대학사와 관세 면제 협약. 뒤에서 뇌물 수수 사실 파악 중
- 마루한 에테르 기관 기술 수입으로 생산 효율 향상. 의존도 인식하나 현실 수용

## 2. 야마토 강경 대응파 상인 수장 (Duiwai Shangren)

| 항목 | 내용 |
|------|------|
| **직위** | 강경 대응파 상인 연합 수장. 의회 내 2위 파벌 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 해상 교역 전문가 |
| **성격** | 불같은 성격. 야마토 약탈로 직접 손실. 무력 대응 없이는 계속 당한다는 판단 |
| **현재 상황** | 마루한 군사 지원 요청 주장. 야마토 교역 전면 중단 주장. 의회 내 지지 확대 중 |
| **핵심 목표** | 야마토 침략 완전 차단. 피해 배상 요구 |
| **갈등 요소** | 집정관의 유지 원칙. 야마토 교역 중단이 다른 수입원도 감소시킬 수 있다는 반론 |

### 세부 특성
- 야마토 강경 다이묘 소속 선단에 직접 상선 약탈당한 전례. 개인 원한 강함
- 마루한 원수와 비공식 접촉 시도. 군사 지원 조건 탐색
- 누산타라 동맹과 야마토 대응 연대 논의

## 3. 야마토 교역 유지파 상인 수장 (Maoyi Shangren)

| 항목 | 내용 |
|------|------|
| **직위** | 교역 유지파 상인 연합 수장. 의회 내 최대 파벌 |
| **에테르** | 어뎁트 중 (2단계). 에테르 보유. 실무 활용 않음. 교역·금융 전문가 |
| **성격** | 냉정한 계산가. 야마토 침략 피해보다 야마토 교역 이익이 크다는 현실 계산 |
| **현재 상황** | 야마토 내정 다이묘와 교역 채널 유지. 강경 대응파 억제 시도 |
| **핵심 목표** | 야마토 교역 유지. 강경 대응이 하이둥 전체 손실로 이어지는 것 방지 |
| **갈등 요소** | 야마토 침략 피해 확대로 내부 설득 한계 다가오는 중 |

### 세부 특성
- 야마토 내정 다이묘와 직접 채널. 쇼군 팽창 속도 조절 정보 입수
- 마루한 기술 의존 축소 주장. 독자 생산 체계 강화 선호
- 강경 대응파가 마루한 군사 지원 받으면 하이둥이 마루한 군사 기지화 우려

## 4. 해상 경비대장 (Haishang Jingweidui Zhang)

| 항목 | 내용 |
|------|------|
| **직위** | 하이둥 상방 해상 경비대 총사령관 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 해상 전투·함대 지휘 특화 |
| **성격** | 원칙적이고 냉정. 교역로 보호가 최우선. 정치 파벌 무관심 |
| **현재 상황** | 야마토 해적 대응 최전선. 누산타라 교역 함대와 협력 |
| **핵심 목표** | 하이둥 해상 교역로 완전 보호. 야마토 침략 억제 |
| **갈등 요소** | 집정관 유지 원칙으로 야마토에 선제 대응 불가. 방어만 허용 |

### 세부 특성
- 마루한 원수와 동부 해로 분점 실무 협력. 야마토 정보 공유
- 야마토 강경 다이묘 선단과 수차례 교전. 전력 파악 완료
- 누산타라 교역 함대 제독과 협력. 남방 해로 공동 순찰
- 강경 대응파 지지 성향. 그러나 집정관 명령 이탈 않음

## 5. 도시 방위대장 (Chengshi Fangweidui Zhang)

| 항목 | 내용 |
|------|------|
| **직위** | 하이둥 항구 도시 방어 총사령관 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 요새·도시 방어 특화 |
| **성격** | 과묵하고 철두철미. 도시 방어가 곧 하이둥 경제 기반 보호라는 인식 |
| **현재 상황** | 항구 도시 방어 체계 강화 중. 마루한 에테르 기관 방어 장비 도입 검토 |
| **핵심 목표** | 하이둥 항구 도시 완전 방어. 어떤 외부 공격도 도시 침입 불허 |
| **갈등 요소** | 마루한 에테르 기관 방어 장비 도입 비용 vs 독자 방어 체계 강화 사이 예산 논쟁 |

### 세부 특성
- 드워프 우르그룬트 방어 기술 자문 요청 중. 드워프 요새 기술에 관심
- 중위안 감찰원이 하이둥 내 정보원 운용하는 것 파악. 역감시 중
- 마루한 철매의 기술 도면 탈취 시도 여러 차례 차단 경험
- 야마토 직접 침략 시 도시 방어 작전 계획 수립 완료

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **집정관 → 해상 경비대장** | 신임. 교역로 방어 위임 |
| **집정관 → 도시 방위대장** | 신임. 도시 방어 위임 |
| **집정관 → 강경 대응파** | 중재. 억제 시도 |
| **집정관 → 교역 유지파** | 협력. 현상 유지 공조 |
| **강경 대응파 ↔ 교역 유지파** | 야마토 대응 노선 대립 |
| **강경 대응파 → 마루한 원수** | 군사 지원 접촉 시도 |
| **교역 유지파 → 야마토 내정 다이묘** | 교역 채널 유지 |
| **해상 경비대장 → 마루한 원수** | 동부 해로 실무 협력 |
| **해상 경비대장 → 누산타라 교역 제독** | 남방 해로 공동 순찰 |
| **도시 방위대장 → 우르그룬트** | 방어 기술 자문 요청 중 |
