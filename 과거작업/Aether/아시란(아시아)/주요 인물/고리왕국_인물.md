# 고리 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 고리 왕국은 마루한·중위안·야마토 삼각 압박 속 독립 유지 중.
> 순혈 엘프 귀족 가문이 존재. 고대부터 한반도 일대 정착한 독자 엘프 계통.

---

## 1. 왕 (Wang)

| 항목 | 내용 |
|------|------|
| **직위** | 고리 왕국 국왕 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 중위안 술식 체계 기반 |
| **성격** | 신중하고 보수적. 중위안 문화·제도 기반에 안정감. 마루한 기술 도입은 정체성 위협으로 인식 |
| **현재 상황** | 중위안 조공 체제 유지. 마루한 접근 거리 조율 중. 야마토 남부 해안 침략 대응 압박 |
| **핵심 목표** | 중위안 조공 관계 유지로 마루한 압박 완충. 야마토 남부 피해 최소화 |
| **갈등 요소** | 중위안이 텡그리 압박으로 약화되는 상황. 중위안 의존 전략의 유효성 감소 중 |

### 세부 특성
- 중위안 황제로부터 책봉 받은 왕. 정통성 기반이 중위안 체제
- 마루한 황제 기술 수출 제안을 정중히 거절한 전례. 이후 마루한 압박 강화
- 엘프 귀족 가문을 왕국 내 독자 세력으로 인정. 통제는 어렵지만 배제 안 함
- 야마토 남부 해안 침략에 독자 대응 한계 인식. 마루한·중위안 양측에 지원 요청 중

## 2. 친중위안파 수석 대신 (Daesin)

| 항목 | 내용 |
|------|------|
| **직위** | 고리 왕국 수석 대신. 왕 최측근. 친중위안파 대표 |
| **에테르** | 어뎁트 중 (2단계). 에테르 보유. 실무 활용 않음. 외교·행정 전문가 |
| **성격** | 학식 높고 전통 중시. 중위안 문물이 고리 문화의 기반이라는 확고한 신념. 마루한 기술 도입을 오염으로 인식 |
| **현재 상황** | 중위안 황실과 외교 채널 유지. 중위안 수석 대학사와 비공식 접촉 중 |
| **핵심 목표** | 중위안 조공 체제 유지. 마루한·마루한파 귀족 영향력 차단 |
| **갈등 요소** | 중위안 내부 부패로 실질 보호 능력 약화. 중위안 의존 근거 흔들리는 중 |

### 세부 특성
- 중위안 수석 대학사와 뇌물 거래 의혹. 중위안 감찰원장 조사 대상
- 야마토 침략 대응 중위안 지원 요청했으나 중위안 내부 사정으로 지연 중
- 엘프 귀족 가문을 불신. 친마루한 행보를 왕국 안보 위협으로 인식

## 3. 기술 도입 주장 귀족 (Gisul Gwiju)

| 항목 | 내용 |
|------|------|
| **직위** | 고리 왕국 중견 귀족. 마루한 에테르 기관 기술 도입 주장파 대표 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 에테르 기관 기초 연구 독학 |
| **성격** | 현실주의. 야마토 침략 피해를 직접 입은 남부 영주. 기술 없이는 방어 불가 판단 |
| **현재 상황** | 마루한 에테르 기관 기술 도입 의회 청원 지속. 엘프 귀족과 연대 모색 |
| **핵심 목표** | 마루한 기술 수입으로 야마토 방어력 강화. 왕국 자립 기반 구축 |
| **갈등 요소** | 수석 대신의 방해. 왕의 보수적 성향. 마루한 의존이 또 다른 종속이 될 수 있다는 반론 |

### 세부 특성
- 야마토 해적·침략으로 남부 영지 피해 직접 경험. 감정적 동기 강함
- 마루한 강행파 장군의 비공식 접촉 대상. 장군의 내부 분열 공작 표적
- 마루한 에테르 기관 기초 연구 독학 중. 엘프 귀족의 에테르 이론 자문 구함
- 누산타라 동맹과 남부 해안 방어 협력 타진 중. 야마토 대응 다각화

## 4. 순혈 엘프 귀족 수장 (Yojeong Gwiju)

| 항목 | 내용 |
|------|------|
| **직위** | 고리 왕국 엘프 귀족 연합 수장. 독자 영지 보유 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 고리 삼림·자연 에테르 특화. 에이렌발트와 다른 독자 계통 |
| **종족** | 순혈 엘프. 고대부터 한반도 정착. 베스테리아 엘프와 별개 계통 |
| **성격** | 자부심 강하고 장기적 시각. 수백 년 왕국 흥망성쇠 목격. 인간 왕국 정치에 초연하나 이익 필요 시 개입 |
| **현재 상황** | 마루한 기술 도입 지지. 중위안 의존 탈피가 엘프 귀족 독립성에도 유리하다는 판단 |
| **핵심 목표** | 엘프 귀족 영지·문화 보전. 외부 세력 모두로부터 실질 자치 유지 |
| **갈등 요소** | 마루한 지지하나 마루한 완전 종속은 거부. 기술 도입 귀족과 목표 일부 일치하나 동기 다름 |

### 세부 특성
- 고리 왕국 건국 이전부터 한반도 정착. 역대 왕조 모두 경험. 정치적 조언자 역할
- 베스테리아 에이렌발트·실바 아르카나와 접촉 없음. 완전 독자 계통
- 수백 년 축적한 고리 삼림 에테르 연구 기록 보유. 외부에 비공개
- 마루한 철매가 엘프 귀족 동향 주시 중. 엘프 귀족도 철매 감시를 인지
- 야마토가 엘프 영지를 침략할 경우 독자 대응 능력 보유. 왕국 군대 불필요

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 수석 대신** | 절대 신임. 조종 가능성 |
| **왕 → 기술 도입 귀족** | 경청하나 채택 유보 |
| **왕 → 엘프 귀족** | 독자 세력 인정. 통제 어려움 |
| **수석 대신 ↔ 기술 도입 귀족** | 의회 내 대립 |
| **수석 대신 → 엘프 귀족** | 불신. 친마루한 경계 |
| **기술 도입 귀족 → 엘프 귀족** | 연대 모색. 에테르 자문 |
| **엘프 귀족 → 마루한 기술** | 지지. 단 완전 종속 거부 |
| **마루한 강행파 장군 → 기술 도입 귀족** | 내부 분열 공작 표적 |
| **마루한 철매 → 엘프 귀족** | 감시 중 |
