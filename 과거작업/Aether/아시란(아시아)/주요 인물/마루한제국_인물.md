# 마루한 제국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 이전 황제: 군사 팽창 중심. 현 황제: 에테르 기관 기술 패권으로 노선 전환.

---

## 1. 황제 (Hwangje)

| 항목 | 내용 |
|------|------|
| **직위** | 마루한 제국 황제. 하늘신의 후손 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 에테르 기관 운용 이해도 높음 |
| **성격** | 냉철하고 장기적. 무력 팽창 한계를 이전 황제를 보며 학습. 기술 우위가 더 지속 가능한 패권이라는 신념 |
| **현재 상황** | 에테르 기관 기술 독점 강화 추진. 고리 왕국 친마루한파 심기 점진 공작 선호 |
| **핵심 목표** | 에테르 기관 기술 세계 최고 수준 유지. 고리 자연 복속 유도. 야마토 견제 |
| **갈등 요소** | 군사 팽창파 원수와 노선 갈등. 에테르 기관 기술 유출 방지와 기술 수출 수익 사이 균형 |

### 세부 특성
- 이전 황제 시절 무력 팽창으로 타이가 부족연 저항 강화된 것을 반면교사
- 중위안 텡그리 압박 분산 틈 기회로 인식. 고리 공작 강화 지시
- 마루한 에테르 기관 기술 일부를 고리 왕국에 선별 공개. 기술 의존도 유도 전략
- 철매 정보 조직 직접 지휘. 중위안 내부 부패 정보 수집 중

## 2. 고리 복속 강행파 장군 (Daejang)

| 항목 | 내용 |
|------|------|
| **직위** | 마루한 제국 남방 군단장. 군사 팽창파 대표 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 집단 전투 지휘 특화 |
| **성격** | 직선적이고 공격적. 이전 황제 시절 전공 가득. 현 황제 점진 공작 방침에 답답함 |
| **현재 상황** | 고리 접경 주둔. 무력 복속 준비 완료 상태. 황제 명령만 기다리는 중 |
| **핵심 목표** | 고리 왕국 무력 복속 완성. 이전 황제 유업 계승 |
| **갈등 요소** | 황제의 점진 공작 방침. 자신의 준비된 전력이 썩어간다는 조급함 |

### 세부 특성
- 이전 황제 시절 타이가 원정·야마토 견제 작전 다수 참여. 전공 최다
- 타이가 부족연 저항 전술에 정통. 수인 전투 대응 경험 풍부
- 에테르 기관 전투 장비 활용엔 적극적. 기술 자체 관심보다 전투 도구로 활용
- 고리 왕국 자치권 수호 영주와 비공식 접촉 시도 중. 내부 분열 공작 독자 진행

## 3. 제국 원수 겸 에테르 기관 전투대장 (Wonsu-Gisul)

| 항목 | 내용 |
|------|------|
| **직위** | 마루한 제국 전군 원수 겸 에테르 기관 전투 부대 총사령관 |
| **에테르** | 마스터 하 (10단계). 무인 계열. 에테르 기관 전투 장비+신체 에테르 강화 완전 통합 |
| **성격** | 황제 방침 충실 이행. 기술과 전투의 융합을 추구. 군사 팽창파와 기술 발전파 사이 실질 조율자 |
| **현재 상황** | 에테르 기관 전투 부대 훈련 총괄. 야마토 견제 동부 해안 순찰 병행 |
| **핵심 목표** | 에테르 기관 전투 체계 완성. 마루한 군사력 질적 최강 유지 |
| **갈등 요소** | 강행파 장군의 독자 공작을 황제에게 보고할지 여부. 동료이나 노선 차이 |

### 세부 특성
- 에테르 기관 전투 장비를 전투에서 실전 활용하는 세계 유일에 가까운 수준
- 중위안 북방 원수와 비공식 정보 교환. 텡그리 공통 위협 인식
- 야마토 막부 팽창 동향 주시. 동부 해안 최전선 책임
- 움코시 왕국 마정석 발견 정보 입수. 철매를 통해 에테르 기관 기술 수출 가능성 검토 중

## 4. 에테르 기관 수석 기술자 (Gisul-Jang)

| 항목 | 내용 |
|------|------|
| **직위** | 마루한 제국 에테르 기관 연구소 수석 기술자. 황제 직속 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 에테르 기관 설계·개발 세계 최고 수준 |
| **성격** | 연구에 집착. 기술이 세상을 바꾼다는 신념. 군사 활용보다 기술 자체 발전에 관심 |
| **현재 상황** | 에테르 기관 기술 다음 세대 개발 중. 마정석 효율 극대화 연구 |
| **핵심 목표** | 에테르 기관 기술 극한 발전. 현재 마정석 의존도 절반으로 감소 목표 |
| **갈등 요소** | 군사 활용 목적 연구 요구와 순수 기술 발전 사이. 황제는 군사 응용 우선 원함 |

### 세부 특성
- 드워프 룬 기술과 마루한 에테르 기관 기술 비교 연구 중. 접점 발견 시도
- 움코시 왕국 마정석 발견 소식에 원수와 마찬가지로 큰 관심. 직접 탐사 요청 중
- 마기스테리움 수석 마법사 교수 연구를 원격으로 주시. 에테르 이론 교류 가능성 탐색
- 타이가 부족연 수인이 보유한 한대 마물 소재가 에테르 기관 효율 향상에 활용 가능하다는 가설 연구 중

## 5. 철매 수장 (Cheolmae Jang)

| 항목 | 내용 |
|------|------|
| **직위** | 마루한 제국 첩보 조직 철매(鐵鷹) 수장. 황제 직속 |
| **종족** | 매 계열 수인. 철매 조직 명칭의 기원 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 에테르 감청·위장·탐지 특화 |
| **성격** | 존재감 없음이 최고 능력. 황제 외 누구도 완전히 신뢰 않음. 정보가 곧 권력이라는 철학 |
| **현재 상황** | 고리 왕국 친마루한파·친중위안파 동향 동시 감시. 중위안 부패 구조 정보 수집 중 |
| **핵심 목표** | 마루한 이익 위협 세력 사전 차단. 기술 유출 방지 |
| **갈등 요소** | 강행파 장군의 독자 고리 공작이 점진 방침 훼손. 황제에게 보고 여부 고민 |

### 세부 특성
- 중위안 황실 감찰원장과 비공식 정보 교환 전례. 텡그리 공통 위협 한정
- 야마토 막부 내 마루한 첩자 다수 운용. 팽창 계획 실시간 파악
- 에테르 기관 기술 도면 유출 시도를 수차례 차단. 하이둥 상방 상인이 주요 루트
- 누산타라 동맹 교역 함대가 마루한 기술 정보 수집 의심. 감시 중

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **황제 → 원수** | 신임. 기술·군사 통합 위임 |
| **황제 → 기술자** | 직속. 기술 발전 총괄 위임 |
| **황제 → 철매 수장** | 직속. 완전 신뢰 |
| **황제 → 강행파 장군** | 군사 자산. 노선 갈등 관리 |
| **원수 ↔ 강행파 장군** | 같은 군인. 노선 차이. 독자 공작 인지 |
| **철매 수장 → 강행파 장군** | 독자 공작 감시. 황제 보고 여부 고민 |
| **기술자 → 원수** | 기술 공급. 군사 응용 요구 갈등 |
| **원수 → 중위안 북방 원수** | 비공식 정보 교환 |
| **철매 수장 → 중위안 감찰원장** | 텡그리 한정 비공식 교환 |
