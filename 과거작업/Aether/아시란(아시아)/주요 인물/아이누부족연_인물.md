# 아이누 부족연 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 아이누 부족연은 홋카이도 지형 활용 저항 특화. 마루한·야마토 양측 압박 속 독립 고수.

---

## 1. 대족장 (Ekashi)

| 항목 | 내용 |
|------|------|
| **직위** | 아이누 부족연 대족장. 부족 회의 선출 |
| **에테르** | 엘리트 상 (6단계). 정령사 계열. 삼림·설원 정령 친화 |
| **성격** | 강인하고 완고. 독립이 아이누의 존재 이유라는 신념. 외부 세력 어느 쪽도 믿지 않음 |
| **현재 상황** | 마루한·야마토 양측 압박 동시 대응. 지형 방어 체계 유지. 협력파 내부 설득 시도 대응 중 |
| **핵심 목표** | 아이누 부족연 완전 독립 유지. 외부 세력 어느 쪽도 영토 발 못 붙이게 |
| **갈등 요소** | 마루한 협력파 족장들의 현실론 압박. 야마토 팽창 가속으로 방어 한계 다가오는 중 |

### 세부 특성
- 아이누 삼림·설원 지형 완전 숙지. 외부 군대가 진입하면 반드시 소모됨
- 마루한 철매 접촉 시도를 수차례 거절. 정보 자체를 주지 않음
- 야마토 쇼군의 팽창 의지가 마루한보다 직접적 위협이라 판단. 그러나 마루한도 신뢰 않음
- 이스칼드 분트 정령 신앙과 유사점 있음. 간접 정보 교류 전례

## 2. 마루한 협력파 족장 (Kotan Korokkuru)

| 항목 | 내용 |
|------|------|
| **직위** | 아이누 부족연 내 최대 부족 족장. 마루한 협력 검토파 대표 |
| **에테르** | 엘리트 중 (5단계). 무인 계열 |
| **성격** | 현실적이고 유연. 독립 의지 있으나 방법론에서 대족장과 차이. 야마토가 더 큰 위협이라는 판단 |
| **현재 상황** | 마루한과 비공식 접촉 모색. 야마토 견제 한정 협력 조건 탐색 중 |
| **핵심 목표** | 아이누 생존. 야마토 침략 저지를 위해 마루한 활용 |
| **갈등 요소** | 대족장의 완전 독립 원칙. 마루한 협력이 결국 마루한 종속으로 이어질 것을 대족장이 경고 |

### 세부 특성
- 마루한 강행파 장군의 접촉 대상. 장군의 내부 분열 공작 표적
- 야마토 침략으로 자신의 부족 영지 일부 피해 경험. 감정적 반야마토 강함
- 대족장을 존경하나 현실론 포기 못함. 족장 회의에서 계속 협력 논의 제기

## 3. 정령사 수장 (Kamuy Tusukur)

| 항목 | 내용 |
|------|------|
| **직위** | 아이누 부족연 최고 정령사. 카무이(정령) 소통 최고 권위자 |
| **종족** | 하프 엘프. 에이렌발트에서 추방된 전례. 아이누 부족연에 정착 |
| **에테르** | 엘리트 상 (6단계). 정령사 계열. 홋카이도 삼림·설원·해양 정령 동시 친화 |
| **성격** | 신비롭고 과묵. 정령과의 대화가 삶의 중심. 외부 세력 개입을 땅의 오염으로 인식 |
| **현재 상황** | 아이누 정령 신앙 수호 총괄. 방어 의식 집행. 정령 이상 징후 감지 중 |
| **핵심 목표** | 아이누 정령 신앙 보전. 외부 오염 차단 |
| **갈등 요소** | [E] 마물 출현 증가와 정령 불안 연관 가능성 탐지 중. 원인 불명 |

### 세부 특성
- 에이렌발트 순혈주의에 의해 추방된 하프 엘프. 아이누 부족연에 정착 후 정령 신앙 깊이 습득
- 에이렌발트 엘프 정령 계통과 아이누 카무이 신앙의 정령 체계가 다름을 직접 경험. 독자 정령사 체계 구축
- 에이렌발트에 대한 감정은 복잡. 원망보다 초월한 상태. 아이누 정령 세계가 진정한 고향
- 홋카이도 삼림·설원 정령 네트워크로 외부 침입 감지. 조기 경보 체계
- 이스칼드 분트 정령사 수장과 정령 이상 징후 비교 정보 비공식 교환 시도
- 마루한 에테르 기관 기술이 정령 에테르 흐름 교란한다는 주장. 협력 반대 이유 중 하나
- 야마토 신토 신앙의 정령 개념과 유사점 있으나 근본적으로 다른 계통. 혼동 경계

## 4. 삼림 전사 수장 (Mosir Ekashi)

| 항목 | 내용 |
|------|------|
| **직위** | 아이누 부족연 전투 전담 수장. 지형 전투 총괄 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 삼림·설원 지형 전투 극한 특화 |
| **성격** | 과묵하고 실용적. 말보다 행동. 외부 세력 침입 시 가장 먼저 대응 |
| **현재 상황** | 야마토 침략 대응 최전선 지휘. 마루한 압박 북부 감시 병행 |
| **핵심 목표** | 아이누 영토 방어. 외부 침입 완전 차단 |
| **갈등 요소** | 양측 동시 압박으로 병력 분산. 협력파 족장의 마루한 접촉이 방어 전략 복잡하게 함 |

### 세부 특성
- 흰곰·흰여우 계열 수인 전사들과 협력. 수인 특수 능력 전투 통합 운용
- 야마토 최강 검사와 직접 교전 전례. 지형 이용으로 무승부 결과. 검사가 유일하게 흥미 느낀 전투
- 마루한 에테르 기관 전투 장비 대응 전술 연구 중. 지형 함정으로 기관 장비 무력화 가능성 탐색
- 정령사 수장과 긴밀 협력. 정령 경보·전사 대응 연계 전술 운용

---

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대족장 → 정령사 수장** | 신뢰. 정령 신앙 권위 존중 |
| **대족장 → 삼림 전사 수장** | 신임. 방어 총괄 위임 |
| **대족장 → 협력파 족장** | 경계. 현실론 압박 관리 |
| **협력파 족장 → 마루한 강행파 장군** | 접촉 피하려 하나 장군이 계속 접근 |
| **정령사 수장 → 협력파 족장** | 마루한 협력 반대. 정령 오염 논리 |
| **삼림 전사 수장 ↔ 정령사 수장** | 긴밀 협력. 연계 전술 |
| **삼림 전사 수장 → 야마토 최강 검사** | 직접 교전 전례. 무승부. 서로 기억 |
| **정령사 수장 → 이스칼드 분트 정령사 수장** | 이상 징후 정보 교환 시도 |
