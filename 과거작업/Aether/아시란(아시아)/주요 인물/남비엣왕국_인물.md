## 1. 왕 (Vua)

| 항목 | 내용 |
|------|------|
| **직위** | 남비엣 왕국 국왕 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 술식 운용 |
| **성격** | 강인한 왕권 의지. 영주들의 분권 저항에 인내심 있게 대응. 마루한·중위안 사이 외교 감각 탁월 |
| **현재 상황** | 왕권 강화 법령 단계적 통과 중. 중위안 조공 축소 타이밍 조율. 마루한 접근 카드 검토 |
| **핵심 목표** | 지방 영주 통제권 확립. 중위안 조공 감소. 남비엣 실질 독립 강화 |
| **갈등 요소** | 자치권 수호 영주들의 저항. 중위안 조공 축소가 마루한 의존으로 이어질 수 있는 딜레마 |

### 세부 특성
- 중위안 텡그리 압박 분산 틈을 타 조공 축소 시도 중. 타이밍이 핵심
- 마루한 제국과 비공식 접촉. 에테르 기관 기술 수입 가능성 탐색
- 농업 조합 수장과 협력으로 식량 외교 레버리지 강화 중
- 밀림 전사 수장을 왕권 강화의 군사적 기반으로 활용

## 2. 왕권 강화 지지 영주 (Chu-Hau Trung-Ap)

| 항목 | 내용 |
|------|------|
| **직위** | 왕도 인근 대영주. 왕권 강화 지지파 대표 |
| **에테르** | 엘리트 중 (5단계). 무인 계열 |
| **성격** | 실용주의. 중앙집권이 외부 위협 대응에 유리하다는 현실 판단. 왕 포섭에 가장 먼저 응함 |
| **현재 상황** | 왕권 강화 법령 통과 지원. 자치권 수호 영주 설득 시도 |
| **핵심 목표** | 왕실 사업 파트너로서 지위 확보. 중앙집권 후 왕도 인근 영주로서 영향력 극대화 |
| **갈등 요소** | 왕이 왕권 강화 완성 후 자신도 통제할 것을 알면서도 단기 이익 우선 |

### 세부 특성
- 왕도 인근 농지 대규모 보유. 농업 조합과 밀접한 경제 관계
- 중위안 친남비엣파 관료와 비공식 채널. 조공 축소 영향 미리 파악
- 자치권 수호 영주들이 마루한에 접근하는 것을 왕에게 보고

## 3. 자치권 수호 영주 (Chu-Hau Doc-Lap)

| 항목 | 내용 |
|------|------|
| **직위** | 남부 변경 대영주. 자치권 수호파 대표 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 밀림·수로 전투 특화 |
| **성격** | 완강하고 전통 고수. 영주 자치가 남비엣 강점이라는 신념. 왕권 강화를 침략으로 인식 |
| **현재 상황** | 왕권 강화 법령 의회 표결 반대 주도. 마루한 접근 카드를 역으로 왕 견제에 활용 시도 |
| **핵심 목표** | 영주 자치권 유지. 왕권 강화 속도 차단 |
| **갈등 요소** | 마루한과 접촉 시도가 왕에게 발각되면 역풍. 중위안도 남비엣 내분 이용 가능성 |

### 세부 특성
- 남부 변경 수로·밀림 완전 통제. 왕의 병력이 직접 진입하기 어려운 지형
- 마루한 에테르 기관 기술 수입 의사 있음. 왕보다 먼저 마루한 접촉 시도
- 누산타라 동맹과 비공식 교역. 왕 모르게 독자 수입원 보유

## 4. 밀림 전사 수장 (Tuong-Linh Rung)

| 항목 | 내용 |
|------|------|
| **직위** | 왕 직속 밀림 전사 부대 수장 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 밀림 은신·기습·독소 전투 극한 특화 |
| **성격** | 왕에 충성. 과묵하고 행동 중심. 밀림이 곧 자신의 영역이라는 자부심 |
| **현재 상황** | 왕 직속으로 자치권 수호 영주 영역 감시. 비공식 압박 임무 수행 |
| **핵심 목표** | 왕권 강화 군사 기반 역할. 남비엣 밀림 완전 장악 |
| **갈등 요소** | 자치권 수호 영주가 자신의 부대 움직임을 영토 침범으로 간주. 충돌 일보 직전 |

### 세부 특성
- 물고기 계열 수인 부하 다수 보유. 수로·밀림 동시 작전 가능
- 자치권 수호 영주의 마루한 접촉 시도를 탐지. 왕에게 보고
- 남비엣 밀림 마물 토벌 경험 다수. 독소 마물 소재 활용 전투 기술 독자 개발
- 누산타라 동맹 해적과 남부 해안에서 충돌 전례. 비공식 경계 협약 유지

## 5. 농업 조합 수장 (Truong-Nong)

| 항목 | 내용 |
|------|------|
| **직위** | 남비엣 왕국 농업 조합 연합 수장. 쌀 생산·유통 총괄 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 농업·유통 전문가 |
| **성격** | 온화하고 실용적. 쌀이 남비엣 최강 무기라는 철학. 어느 정치 파벌도 쌀 공급 끊으면 안 됨을 앎 |
| **현재 상황** | 왕권 강화·자치권 수호 양측 모두와 협력 유지. 쌀 공급을 외교 레버리지로 활용 |
| **핵심 목표** | 농업 조합 영향력 유지. 쌀 수출 확대. 남비엣 식량 패권 강화 |
| **갈등 요소** | 왕이 농업 조합을 중앙 통제 하에 두려는 시도. 독립적 운영 유지 원함 |

### 세부 특성
- 중위안·마루한·누산타라 모두에 쌀 수출. 어느 세력과도 적이 되지 않음
- 에테르 농업 기술 독자 발전. 연 3모작 가능한 관개 술식 개발
- 왕권 강화 지지 영주와 경제 협력. 자치권 수호 영주에게도 쌀 공급 유지
- 쌀 수출 가격 조정으로 중위안 조공 협상 간접 지원. 왕의 외교 카드 역할

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 밀림 전사 수장** | 군사 기반. 영주 감시 위임 |
| **왕 → 농업 조합 수장** | 식량 외교 협력 |
| **왕 → 왕권 지지 영주** | 포섭 성공. 활용 |
| **왕 → 자치권 수호 영주** | 견제·압박 |
| **왕권 지지 영주 ↔ 자치권 수호 영주** | 의회 내 대립 |
| **밀림 전사 수장 → 자치권 수호 영주** | 감시·충돌 직전 |
| **자치권 수호 영주 → 마루한 제국** | 비공식 접촉 시도 |
| **농업 조합 수장 → 양측 영주** | 쌀 공급 유지. 중립 |
