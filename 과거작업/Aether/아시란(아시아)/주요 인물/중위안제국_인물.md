# 중위안 제국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 황제 (Tianzi)

| 항목 | 내용 |
|------|------|
| **직위** | 중위안 제국 황제. 하늘의 아들(天子) |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 집단 술식 의식 특화. 전투 미숙 |
| **성격** | 학자형 황제. 시·서예·에테르 이론에 조예 깊음. 전쟁보다 문화로 지배하길 원함 |
| **현재 상황** | 문치 우선 방침 고수. 텡그리·마루한 군사 위협에도 군비 증강 제한. 관료 부패 진행 중 |
| **핵심 목표** | 중위안 문화 패권 유지. 조공 체제 정상화. 내부 안정 |
| **갈등 요소** | 군사 현실을 무시하는 문치 집착. 관료 부패 인지하지 못하거나 외면 중 |

### 세부 특성
- 즉위 초 뛰어난 군주였으나 장기 집권으로 현실 감각 퇴화
- 고리 왕국·남비엣 조공 관계 유지에 집착. 체면 외교 우선
- 마루한·텡그리를 여전히 "오랑캐"로 폄하. 위협 심각성 과소평가
- 환관 세력이 황제 측근 장악 시작. 관료 부패 구조 형성 중
- 북방 원수 실적을 인정하면서도 무관 세력 강화 경계

## 2. 수석 대학사 (Shouxi Daxueshi)

| 항목 | 내용 |
|------|------|
| **직위** | 중위안 최고위 문관. 황제 직속 수석 보좌관 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 술식 이론·행정 에테르 특화 |
| **성격** | 전형적인 문인 관료. 능력 있으나 현실보다 명분 중시. 군사 증강 반대론 선봉 |
| **현재 상황** | 황제 문치 방침 충실 지지. 북방 원수 군비 증강 요청 지속 차단 |
| **핵심 목표** | 문관 관료 체계 유지. 무관 세력 견제 |
| **갈등 요소** | 관료 부패에 본인도 연루 시작. 부패 척결보다 적당한 선에서 봉합 선호 |

### 세부 특성
- 과거 시험 최고 성적 출신. 관료 사회 내 최고 권위
- 환관 세력 성장에 경계심. 직접 충돌 피함. 황제 총애 빼앗길 위험
- 북방 원수를 "필요악"으로 인식. 공을 세우되 군사 정치화는 용납 않으려 함
- 고리 왕국 친중위안파와 정기 서신 교환. 조공 체제 유지 공작

## 3. 총관 환관 (Zong Guanshi)

| 항목 | 내용 |
|------|------|
| **직위** | 황실 총관 환관. 황제 측근 장악 실세 |
| **에테르** | 없음. 범인. 정보 수집·인사 개입 전문 |
| **성격** | 온화한 겉모습. 황제 앞에서 완벽한 충신. 실제론 인사권·정보망 장악해 관료 부패 구조 중심 |
| **현재 상황** | 황실 감찰원을 사실상 장악. 부패한 관료들과 이익 공유 구조 형성 |
| **핵심 목표** | 황제 측근 지위 영구화. 인사권 통한 관료 통제 |
| **갈등 요소** | 수석 대학사와 권력 경쟁. 북방 원수가 외부에서 황제에게 직접 보고하는 것 경계 |

### 세부 특성
- 황실 감찰원(금의위)을 문관 부패 척결이 아닌 정적 제거 도구로 활용
- 관료 부패 구조: 환관이 인사 추천권 행사 → 추천받은 관료가 뇌물 납부 → 환관이 황제에게 은폐
- 북방 원수의 군비 증강 요청이 황제에게 전달되지 않도록 중간 차단 시도
- 마루한·텡그리 위협 정보를 의도적으로 축소 보고. 외부 위협 강조 시 무관 세력 강화로 이어지기 때문

## 4. 북방 원수 (Beifang Yuanshuai)

| 항목 | 내용 |
|------|------|
| **직위** | 중위안 제국 북방 전선 총사령관. 텡그리 칸국 대응 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 대규모 집단 전투 지휘 특화 |
| **성격** | 냉철한 현실주의 군인. 문치 이념에 회의적이나 황제에 충성. 결과로 말하는 스타일 |
| **현재 상황** | 텡그리 칸국 북방 압박 최전선 대응. 군비 증강 요청 반복 차단당하는 상황 |
| **핵심 목표** | 북방 방어선 유지. 텡그리 칸국 팽창 저지 |
| **갈등 요소** | 군비 증강 요청이 환관·문관에 의해 차단. 현장 병력 부족으로 방어 한계 점근 중 |

### 세부 특성
- 텡그리 칸국 에테르 기마 전술 직접 교전 경험. 위협 가장 현실적으로 파악
- 황제에게 직접 보고 시도하나 환관 총관이 중간 차단. 우회로 모색 중
- 마루한 제국과의 동부 국경 분쟁도 병행 관리. 양면 전선 부담
- 중위안 내 무관파 실질 수장. 문관파 견제 속에서 군사 현실 반영 위해 고군분투
- 고리 왕국 친마루한파 동향 주시. 마루한과의 간접 대리 경쟁

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **황제 → 수석 대학사** | 신임. 문치 방침 공유 |
| **황제 → 총관 환관** | 총애. 실상 파악 못 함 |
| **황제 → 북방 원수** | 실적 인정. 군사 세력화 경계 |
| **수석 대학사 ↔ 총관 환관** | 권력 경쟁. 표면 공존 |
| **총관 환관 → 북방 원수** | 군비 요청 차단. 경계 |
| **북방 원수 → 황제** | 직접 보고 시도. 환관에 차단 |
| **수석 대학사 → 북방 원수** | 필요악 인식. 군사 정치화 견제 |
| **북방 원수 → 텡그리 칸국** | 직접 교전. 위협 현실 파악 |
