# 텡그리 칸국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 현 칸은 최근 즉위한 젊은 지도자. 전임 칸의 급격한 팽창 유산 정리 중.

---

## 1. 칸 (Khan)

| 항목 | 내용 |
|------|------|
| **직위** | 텡그리 칸국 칸. 쿠릴타이 선출. 텡그리의 선택을 받은 자 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 에테르 기마 전술 극한 특화 |
| **나이** | 20대 후반. 즉위한 지 얼마 되지 않음 |
| **성격** | 젊은 나이에 비해 신중하고 계산적. 전임 칸의 무모한 팽창 후유증 직접 목격. 내부 결속 우선 |
| **현재 상황** | 즉위 직후 내부 통합 주력. 팽창 강경파 족장들 달래며 시간 확보 중 |
| **핵심 목표** | 내부 결속 강화. 에테르 기마 전술 완성. 준비된 팽창 |
| **갈등 요소** | 팽창 강경파 족장들의 즉각 행동 압박. 젊은 칸에 대한 권위 의문 |

### 세부 특성
- 전임 칸과 형제 경쟁에서 승리해 즉위. 패배한 형제는 추방 상태
- 전투에서는 전임 칸보다 강하다는 평가. 전략에서는 아직 검증 중
- 다슈트 연합 수장의 비공식 서신을 받음. 반응 보류 중. 카드로 보유
- 에테르 기마 전술 개발자를 가장 중요한 자산으로 인식. 직접 사사

## 2. 팽창 강경파 대족장 (Noyan Daiichi)

| 항목 | 내용 |
|------|------|
| **직위** | 텡그리 칸국 최대 부족 족장. 팽창 강경파 대표 |
| **에테르** | 엘리트 상 (6단계). 무인 계열 |
| **성격** | 전임 칸 시대 팽창의 수혜자. 멈추면 약해진다는 유목 논리. 젊은 칸의 신중함을 나약함으로 오해 |
| **현재 상황** | 쿠릴타이에서 즉각 팽창 재개 주장. 칸과 갈등 심화 중 |
| **핵심 목표** | 중위안 북방 재침략. 다슈트 완전 복속. 전임 칸 유산 이어받기 |
| **갈등 요소** | 칸의 내부 통합 방침에 공개 반발은 못 하나 비공식 압박 지속 |

### 세부 특성
- 전임 칸 시대 최대 전공 보유. 병력 규모 칸 직속 다음으로 큼
- 에테르 기마 전술 개발자와 관계 냉담. 기술보다 수적 우위 추구
- 칸이 준비 완료 전 행동하면 자신이 주도할 수 있다는 계산

## 3. 내부 통합파 족장 (Noyan Neibu)

| 항목 | 내용 |
|------|------|
| **직위** | 텡그리 칸국 중견 부족 족장. 내부 통합파 대표 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 실용주의. 팽창보다 현재 획득한 영토 소화가 우선. 칸의 신중함 지지 |
| **현재 상황** | 칸 지지 파벌 결속 강화. 강경파 대족장 견제 |
| **핵심 목표** | 현재 영토 안정적 통치. 텡그리 칸국 장기 존속 기반 마련 |
| **갈등 요소** | 강경파 대족장 병력이 자신보다 훨씬 큼. 칸의 보호 없이는 억압당할 가능성 |

### 세부 특성
- 에테르 기마 전술 개발자와 우호적. 기술 발전이 수적 열세 보완한다는 공통 인식
- 다슈트 연합 유목 부족과 과거 교류 경험. 전향 시도 정보 파악
- 칸에게 강경파 대족장 견제 방법 조언 역할

## 4. 에테르 기마 전술 개발자 (Erdem-ch)

| 항목 | 내용 |
|------|------|
| **직위** | 텡그리 칸국 에테르 기마 전술 창시자. 칸 직속 전술 고문 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 에테르 기마 전술 세계 유일 개발자 |
| **성격** | 조용하고 탐구적. 전술 개발에 집착. 전투를 수학 문제처럼 분석 |
| **현재 상황** | 현 칸에게 에테르 기마 전술 완성본 전수 중. 전술 추가 발전 연구 |
| **핵심 목표** | 에테르 기마 전술 완성. 세계 어떤 군대도 대응 못 하는 전술 체계 구축 |
| **갈등 요소** | 강경파 대족장이 자신의 전술보다 수적 우위 선호. 전술 가치 무시당하는 것에 불만 |

### 세부 특성
- 에테르 기마 전술은 수인(말·독수리계열)과 인간 에테르 무인 결합 독자 개발
- 중위안 북방 원수·아르다샤르 제국 원수 모두 이 전술에 고전한 경험
- 강티세 동맹 문파 기술에 관심. 개인 수련 목적 접촉 시도 가능성
- 쌍도 관련 고대 기록 일부 입수했다는 소문. 미확인

## 5. 칸의 오른팔 장군 (Baatar)

| 항목 | 내용 |
|------|------|
| **직위** | 칸 직속 친위 기마대 장군. 칸의 군사 집행자 |
| **종족** | 말 계열 수인. 텡그리 칸국 기마 문화의 상징적 존재 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 돌격 전투 극한 특화 |
| **성격** | 칸에 대한 맹목적 충성. 전투 외 판단은 칸에게 위임. 단순하지만 강함 |
| **현재 상황** | 칸 호위 및 내부 통합 무력 집행 담당. 강경파 견제 실력 행사 역할 |
| **핵심 목표** | 칸 보호. 칸의 명령 완수 |
| **갈등 요소** | 강경파 대족장 병력과 충돌 가능성. 칸의 명령 없이는 행동 안 함 |

### 세부 특성
- 전임 칸 시대부터 현 칸을 수호한 충성 전사. 현 칸의 형제 경쟁 때 현 칸 편
- 강경파 대족장이 가장 경계하는 인물. 직접 충돌 회피
- 에테르 기마 전술 개발자와 협력. 전술 실행 역할 담당

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **칸 → 오른팔 장군** | 절대 신뢰. 내부 통합 무력 기반 |
| **칸 → 에테르 기마 전술 개발자** | 직접 사사. 최중요 자산 |
| **칸 → 강경파 대족장** | 달래며 관리. 직접 충돌 회피 |
| **칸 → 내부 통합파 족장** | 지지 기반. 견제 역할 |
| **강경파 대족장 ↔ 내부 통합파 족장** | 파벌 대립 |
| **강경파 대족장 → 오른팔 장군** | 경계. 직접 충돌 회피 |
| **에테르 기마 전술 개발자 ↔ 내부 통합파 족장** | 우호. 기술 발전 공통 인식 |
| **에테르 기마 전술 개발자 → 강경파 대족장** | 전술 무시에 불만 |
