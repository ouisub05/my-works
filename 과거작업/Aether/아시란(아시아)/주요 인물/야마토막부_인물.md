# 야마토 막부 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 야마토 막부는 전국 통일 직후. 쇼군 즉각 팽창 방침. 고리·중위안 정세 불안을 기회로 인식.

---

## 1. 쇼군 (Shogun)

| 항목 | 내용 |
|------|------|
| **직위** | 야마토 막부 쇼군. 전국 통일 완성자 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 야마토 검술+에테르 강화 |
| **성격** | 야망 넘치고 결단력 강함. 역사적 기회라는 확신. 중위안 약화·마루한 내부 노선 갈등을 정확히 파악 |
| **현재 상황** | 고리 남부 해안 침략 허가. 전면 침략 준비 중. 마루한 대응 속도 계산 중 |
| **핵심 목표** | 고리 왕국 복속. 중위안 조공 체제 탈피. 동부 아시란 독자 세력 확립 |
| **갈등 요소** | 마루한 제국 대응이 예상보다 빠를 경우 리스크. 내정 우선 다이묘들의 속도 조절 압박 |

### 세부 특성
- 전국 통일 과정에서 수십 개 다이묘 세력 병합. 정치·군사 천재
- 중위안 수석 대학사 부패 정보 입수. 중위안 실질 보호 능력 없다고 판단
- 마루한 황제 기술 패권 전환이 군사 팽창 억제로 이어진다고 분석. 지금이 기회
- 야마토 최강 검사를 전면에 내세워 상징적 효과 극대화 전략
- 철매 감시 인지. 역정보 흘리는 작전 운영 중

## 2. 팽창 강경 다이묘 (Daimyo Kyoko)

| 항목 | 내용 |
|------|------|
| **직위** | 야마토 최대 번 영주. 팽창 강경파 대표 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 호전적이고 직선적. 쇼군의 팽창 방침 전폭 지지. 내정 우선파를 겁쟁이로 봄 |
| **현재 상황** | 쇼군 팽창 작전 군사 자원 제공. 고리 남부 해안 침략 실무 지원 |
| **핵심 목표** | 팽창 전쟁에서 전공 확보. 번 영토·영향력 확대 |
| **갈등 요소** | 쇼군이 팽창 속도 조율하면 자신의 전공 기회 감소. 독단 행동 충동 |

### 세부 특성
- 전국 통일 전쟁 최대 전공자 중 하나. 쇼군 다음 실질 군사력
- 마루한 에테르 기관 기술 도입에 관심. 전투 도구로 활용 목적
- 하이둥 상방 상선 약탈 이력. 하이둥과 관계 최악

## 3. 내정 우선 다이묘 (Daimyo Nasei)

| 항목 | 내용 |
|------|------|
| **직위** | 야마토 중견 번 영주. 내정 우선파 대표 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 신중하고 현실적. 전국 통일 직후 내부 결속이 완전하지 않다는 인식. 마루한 반격 리스크 경계 |
| **현재 상황** | 쇼군 속도 조절 건의 반복. 공개 반대는 못 하고 우회 설득 중 |
| **핵심 목표** | 야마토 내부 경제·행정 기반 강화. 안정적 팽창 |
| **갈등 요소** | 쇼군 결단력 앞에서 목소리 약함. 강경 다이묘의 압박 |

### 세부 특성
- 전국 통일 전쟁 막판 합류 세력. 전공 없음. 정치적 입지 약함
- 하이둥 상방과 교역 관계 유지 중. 전면 충돌 원치 않음
- 마루한 기술 도입 비공식 지지. 전쟁 대신 기술 협력 방향 선호

## 4. 야마토 최강 검사 (Kensei)

| 항목 | 내용 |
|------|------|
| **직위** | 쇼군 직속 최강 전투 직군. 검성(剣聖) 칭호 보유 |
| **에테르** | 엑스퍼트 상 (9단계). 무인 계열. 야마토 독자 검술+에테르 극한 특화 |
| **성격** | 순수한 검사. 전쟁·정치 무관심. 강한 상대와의 검술 대결에만 관심. 쇼군에 충성하나 명령보다 검이 먼저 |
| **현재 상황** | 쇼군 직속 최강 전력으로 팽창 작전 상징 역할. 고리 남부 침략 선봉 |
| **핵심 목표** | 세계 최강 검사 증명. 마루한 원수·카이저라이히 검성과 언젠가 겨루고 싶다는 욕구 |
| **갈등 요소** | 정치·팽창 논리 이해 못 함. 쇼군 전략에 맞게 행동 제한받는 것 답답함 |

### 세부 특성
- 전국 통일 마지막 전투에서 적 장수 10여 명 단독 격파. 전설적 존재
- 야마토 독자 검술 체계가 에테르 기관 없이도 최고 수준 전투력 구현
- 마루한 제국 원수와 직접 대결 시 어느 쪽이 강한지 동부 아시란 최대 관심사
- 강티세 동맹 내공 문파 수장 소문 들음. 검술 vs 내공 대결 흥미

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **쇼군 → 최강 검사** | 전략 자산·상징. 통제 필요 |
| **쇼군 → 강경 다이묘** | 군사 기반. 독단 방지 관리 |
| **쇼군 → 내정 다이묘** | 속도 조절 의견 경청. 채택 유보 |
| **강경 다이묘 ↔ 내정 다이묘** | 팽창vs내정 노선 대립 |
| **강경 다이묘 → 최강 검사** | 전공 동반자로 기대 |
| **최강 검사 → 마루한 원수** | 대결 욕구. 미면 |
| **최강 검사 → 카이저라이히 검성** | 대결 욕구. 존재 인지 |
| **마루한 철매 → 야마토** | 역정보 공작에 당하는 중 |
