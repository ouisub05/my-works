# 타이가 부족연 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 타이가 부족연은 시베리아 한대 지형 활용 마루한 저항 중. 수인 다수 거주.

---

## 1. 대족장 (Velikiy Khan)

| 항목 | 내용 |
|------|------|
| **직위** | 타이가 부족연 대족장. 부족 회의 선출 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 한대 생존·전투 특화 |
| **성격** | 강인하고 완고. 타협은 곧 굴복이라는 신념. 한대 지형이 최강의 방어막이라는 자신감 |
| **현재 상황** | 마루한 압박 저항 유지. 복속 협상파 족장들 달래며 연합 결속 유지 |
| **핵심 목표** | 타이가 부족연 완전 독립 유지. 마루한 진입 완전 차단 |
| **갈등 요소** | 마루한 이전 황제 시절 대규모 원정으로 부족 일부 소실. 복속 협상파 세력 커지는 중 |

### 세부 특성
- 마루한 강행파 장군과 수차례 교전 경험. 지형 이용으로 격퇴 반복
- 한대 마물 다발 지대 인근 부족 통솔. 마물 소재 교역으로 독자 경제 기반 보유
- 마루한 에테르 기관 기술이 한대 지형에서 효율 저하된다는 것 파악. 방어 전략 핵심
- 아이누 부족연 대족장과 비공식 연대. 양측 모두 마루한·야마토 압박 공통

---

## 2. 복속 협상파 족장 (Stariy Bek)

| 항목 | 내용 |
|------|------|
| **직위** | 타이가 남부 접경 부족 족장. 복속 협상파 대표 |
| **에테르** | 엘리트 중 (5단계). 무인 계열 |
| **성격** | 현실적이고 피로함. 수십 년 저항으로 부족 인구 감소. 다음 세대에게 전쟁만 물려줄 수 없다는 입장 |
| **현재 상황** | 마루한 기술자 그룹과 비공식 접촉. 복속 시 자치권 보장 조건 탐색 |
| **핵심 목표** | 부족 생존. 조건부 복속으로 자치권 확보 |
| **갈등 요소** | 대족장의 저항 원칙. 협상 시도 발각 시 부족 내 배신자 취급 위험 |

### 세부 특성
- 마루한 에테르 기관 수석 기술자 그룹과 비공식 접촉. 기술 협력 조건 탐색
- 한대 마물 소재가 마루한 에테르 기관 효율 향상에 유용하다는 것 파악. 협상 카드
- 대족장 사후 권력 공백 시 복속 협상 추진 계획 구체화 중

## 3. 설원 유격대장 (Taiga Partizan)

| 항목 | 내용 |
|------|------|
| **직위** | 타이가 부족연 유격 전투 부대 총사령관 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 한대 은신·기습·보급선 차단 극한 특화 |
| **성격** | 냉혹하고 실용적. 정면 전투 거부. 소모전으로 마루한 의지 꺾는 전략 신봉 |
| **현재 상황** | 마루한 원정대 보급선 차단 작전 지속. 강행파 장군 부대 이동 경로 교란 |
| **핵심 목표** | 마루한 원정 비용 극대화. 경제적으로 침략 포기하게 만들기 |
| **갈등 요소** | 복속 협상파 족장의 협상 시도가 자신의 소모전 전략 효과 약화 우려 |

### 세부 특성
- 흰늑대·흰곰 계열 수인 전사들과 협력. 한대 지형 유격전 최강 조합
- 마루한 강행파 장군의 가장 큰 골칫거리. 정면 대결 안 하고 소모만 시킴
- 마루한 에테르 기관 기술 약점(한대 효율 저하)을 활용한 함정 전술 개발
- 음반다 마물 사냥 전설과 비공식 정보 교환 전례. 마물 대응 전술 공유
- 마루한 수석 기술자가 한대 마물 소재에 관심 있다는 정보 파악. 역이용 검토

## 4. 수인 전사 수장 (Zveryy Voin)

| 항목 | 내용 |
|------|------|
| **직위** | 타이가 부족연 수인 부족 연합 전사 수장 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 한대 근접 전투 특화 |
| **종족** | 흰늑대 계열 수인. 시베리아 한대 특화 종 |
| **성격** | 호전적이고 자부심 강함. 한대에서 수인 전사가 최강이라는 확신. 저항 고수 강력 지지 |
| **현재 상황** | 수인 부족 전사 통솔. 유격대장과 긴밀 협력. 마루한 직접 교전 최전선 |
| **핵심 목표** | 타이가 수인 부족 자유 수호. 마루한 진입 완전 차단 |
| **갈등 요소** | 인간 부족 복속 협상파와 수인 부족 저항파 사이 긴장. 수인 부족은 복속 협상 절대 반대 |

### 세부 특성
- 이스칼드 분트 설원 최강 전사(인간·수인 혼혈)와 소문으로 서로 인지. 대결 욕구
- 마루한 원수와 직접 교전 전례. 에테르 기관 장비 상대로 수인 신체 능력으로 호각
- 한대 마물 사냥 문화. 마물 소재로 전투 장비 제작. 타이가 전투력 핵심
- 복속 협상파 족장을 공개적으로 경멸. 대족장이 중재 역할

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대족장 → 유격대장** | 신임. 저항 전략 핵심 |
| **대족장 → 수인 전사 수장** | 신임. 전투 기반 |
| **대족장 → 복속 협상파 족장** | 달래며 관리. 발각 시 제재 |
| **유격대장 ↔ 수인 전사 수장** | 긴밀 협력. 유격·근접 분업 |
| **수인 전사 수장 → 복속 협상파 족장** | 공개 경멸. 대족장 중재 |
| **복속 협상파 족장 → 마루한 기술자** | 비공식 접촉. 조건 탐색 |
| **유격대장 → 마루한 강행파 장군** | 소모전 지속. 정면 회피 |
| **수인 전사 수장 → 이스칼드 설원 최강 전사** | 소문으로 인지. 대결 욕구 |
| **대족장 → 아이누 대족장** | 비공식 연대 |
