# 알-티자라 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 왕 (Malik al-Tijara)

| 항목 | 내용 |
|------|------|
| **직위** | 알-티자라 왕국 국왕 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 탐지·협상 보조 에테르 특화 |
| **성격** | 인내심 강하고 장기적. 급하게 서두르지 않음. 상인 귀족을 설득하면서 조금씩 기정사실화 |
| **현재 상황** | 상인 귀족 일부 포섭 성공. 왕권 강화 법령 단계적 통과 중. 아르다샤르 압박 증가에 외교 균형 고민 |
| **핵심 목표** | 절대 왕정 완성. 아르다샤르·케메트 사이 자율성 극대화 |
| **갈등 요소** | 아르다샤르 총독의 종속 강화 압박. 왕권 강화가 아르다샤르 자극 우려 |

### 세부 특성
- 아르다샤르와 케메트 사이에서 어느 쪽도 완전히 믿지 않는 외교 노선 유지
- 상인 귀족 저항파 핵심 인물을 왕실 사업 파트너로 끌어들이는 방식으로 포섭
- 자한 술탄국과 비공식 교역 채널 탐색 중. 아르다샤르 없는 독자 루트 확보 시도
- 상인 호위 병사 조직이 사실상 왕의 독립 군사 기반 역할도 겸하도록 육성 중

## 2. 왕실 수석 상인 (Ra'is al-Tujjar al-Maliki)

| 항목 | 내용 |
|------|------|
| **직위** | 왕실 직속 상인 조합 수장. 왕권 강화 지지파 대표 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 교역·금융 전문가 |
| **성격** | 실리적. 왕권 강화가 자신의 이익에도 부합한다고 계산. 왕의 포섭에 가장 먼저 응한 인물 |
| **현재 상황** | 왕권 강화 법령 통과 지원. 저항파 상인 귀족 고립 공작 |
| **핵심 목표** | 왕실 사업 파트너로서 독점적 지위 확보. 저항파 상인 귀족 약화 |
| **갈등 요소** | 왕이 완전한 절대 왕정 완성 후 자신도 통제할 것을 우려. 적당한 선에서 멈추길 원함 |

### 세부 특성
- 아르다샤르 교역 루트 의존도 낮추기 위해 케메트 방면 교역 탐색 중
- 자한 술탄국 말리 연대파와 비공식 접촉. 인도양 루트 가능성 탐색
- 왕의 완전한 신뢰를 얻지 못함을 알고 있음. 자신도 언젠가 교체될 것을 대비해 독자 재산 축적

## 3. 상인 귀족 저항파 수장 (Ra'is al-Nubala al-Tujar)

| 항목 | 내용 |
|------|------|
| **직위** | 전통 상인 귀족 연합 수장. 왕권 강화 저항파 대표 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열 |
| **성격** | 전통과 기득권 수호에 완강. 왕의 점진적 접근을 알면서도 막을 방법이 줄어드는 것에 초조 |
| **현재 상황** | 아르다샤르 총독과 비공식 접촉. 왕권 강화 견제를 위해 외부 압박 활용 시도 |
| **핵심 목표** | 상인 귀족 전통적 권한 유지. 왕권 강화 속도 차단 |
| **갈등 요소** | 아르다샤르 종속 강화 압박을 이용하려 하나 아르다샤르 완전 종속도 원치 않음 |

### 세부 특성
- 아르다샤르 총독과 접촉은 하나 완전한 협력은 아님. 서로 이용하는 관계
- 왕실 수석 상인이 포섭된 이후 세력 약화. 남은 귀족 결속 유지가 과제
- 왕이 상인 귀족을 하나씩 포섭하는 전략에 대응 방법 모색 중

## 4. 상인 호위 병사 수장 (Ra'is al-Haras al-Tujjar)

| 항목 | 내용 |
|------|------|
| **직위** | 알-티자라 왕국 상인 호위 전문 병사 조직 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 사막·해상 이동 전투 특화 |
| **성격** | 충성 대상이 명확한 직업 군인. 현재 왕에 충성. 이념 없이 보호 임무 집중 |
| **현재 상황** | 상인 교역로 호위 총괄. 왕의 독립 군사 기반으로 조직 확장 중 |
| **핵심 목표** | 교역로 완벽 보호. 조직 규모·전투력 향상 |
| **갈등 요소** | 상인 귀족 저항파가 자신의 조직을 왕의 사병으로 간주. 독립 호위 조직이라는 명분 유지 필요 |

### 세부 특성
- 솔다텐라트 출신 용병 다수 고용. 실전 전투력 보유
- 아르다샤르 서부 방위대장과 교역로 안전 협력 채널 보유
- 왕의 독립 군사 기반 역할을 수행하나 공식적으로는 상인 호위 조직으로만 존재
- 아라비아 사막·해안 지형 완전 숙지. 기습 방어·역기습 전술 특화

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 왕실 수석 상인** | 포섭 성공. 도구로 활용. 완전 신뢰는 아님 |
| **왕 → 상인 호위 수장** | 신뢰. 독립 군사 기반 육성 위임 |
| **왕 → 저항파 수장** | 포섭 또는 고립화 진행 중 |
| **왕실 수석 상인 ↔ 저항파 수장** | 상인 귀족 주도권 경쟁 |
| **저항파 수장 → 아르다샤르 총독** | 이용 관계. 완전 협력 아님 |
| **상인 호위 수장 → 아르다샤르 서부 방위대장** | 교역로 안전 협력 |
| **왕실 수석 상인 → 자한 술탄국** | 인도양 루트 탐색 |
