# 바라타 연방 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 마하라자 (Maharaja)

| 항목 | 내용 |
|------|------|
| **직위** | 바라타 연방 대왕. 비슈누 신의 지상 대리인 |
| **에테르** | 엘리트 상 (6단계). 성기사 계열. 비슈누 신성력 운용 |
| **성격** | 위엄 있고 균형적. 브라만과 상인 귀족 사이에서 왕권 유지. 향신료 패권에 강한 자부심 |
| **현재 상황** | 상업 패권 유지 기조 고수. 포르타 견제하면서 자한과 인도양 루트 공동 운영 강화 |
| **핵심 목표** | 향신료 독점 영속. 인도양 교역 패권 유지. 브라만·상인 귀족 균형 관리 |
| **갈등 요소** | 브라만 신관파와 상인 귀족파 갈등 중재. 어느 쪽 과도한 권력도 왕권 위협 |

### 세부 특성
- 포르타 콘소르티움과 현재 교역 유지하면서 직거래 루트 병행 탐색. 이중 전략
- 코끼리 부대 지휘관·인도양 제독 양측 균형 있게 신임
- 강티세 동맹과 철학·교류 우호 관계. 브라만 신관들의 강티세 성지 순례 허용
- 자한 술탄국 제독과 인도양 공동 순찰 협약 직접 승인

## 2. 대브라만 (Maha-Brahman)

| 항목 | 내용 |
|------|------|
| **직위** | 바라타 연방 최고 브라만. 종교 의식·왕권 정당성 담당 |
| **에테르** | 엘리트 하 (4단계). 성기사 계열. 의식 중 에테르 증폭 특화 |
| **성격** | 고귀하고 학식 높음. 상인 귀족의 세속 권력 확대를 신성 질서 교란으로 인식 |
| **현재 상황** | 상인 귀족파의 포르타 직거래 확대 주장에 종교적 명분으로 반대. 왕 신임 유지 |
| **핵심 목표** | 브라만 카스트 권위 유지. 종교 의식을 통한 왕권 정당성 독점 |
| **갈등 요소** | 상인 귀족파가 브라만 의식 없이도 신성력 유사 효과 에테르로 재현하려는 시도 경계 |

### 세부 특성
- 바라타 신성력과 에테르 융합 의식 최고 권위자. 의식 중 에테르 폭발적 증폭 가능
- 강티세 동맹 바라타 신앙 계통 문파와 비공식 철학 교류
- 신성력 원천 논쟁에서 "신앙이 원천"이라는 입장 확고. 마기스테리움과 대립 시각

## 3. 상인 귀족 수장 (Shreshthi)

| 항목 | 내용 |
|------|------|
| **직위** | 바라타 연방 최대 상인 가문 수장. 상인 귀족파 대표 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 교역·금융 전문가 |
| **성격** | 이익 극대화 추구. 향신료 교역 확장에 집착. 브라만 의식 비용을 낭비로 인식 |
| **현재 상황** | 포르타 우회 루트 확대 추진. 자한·마레와 직거래 채널 강화 |
| **핵심 목표** | 향신료 교역 이익 극대화. 포르타 수수료 절감. 브라만 의식 비용 축소 |
| **갈등 요소** | 대브라만과 지속 갈등. 마하라자가 브라만 권위 유지하는 한 직접 충돌 한계 |

### 세부 특성
- 마레 콘소르티움 다크 엘프 상단주와 비공식 교역 채널 보유
- 포르타 이사회 수석 이사와 현상 유지 협의. 급격한 변화 모두 원치 않는 공통점
- 바라타 향신료 생산량 60% 이상 자신의 가문 농장에서 생산. 경제적 레버리지 최강

## 4. 코끼리 부대 지휘관 (Gaja-Senani)

| 항목 | 내용 |
|------|------|
| **직위** | 바라타 연방 코끼리 부대 총사령관 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 코끼리 계열 수인과 연계 전투 특화 |
| **성격** | 전통 바라타 전사 문화 자부심. 코끼리 부대가 세계 최강 육상 전력이라는 확신 |
| **현재 상황** | 코끼리 부대 전투력 유지·강화. 내륙 마물 다발 지대 토벌 겸임 |
| **핵심 목표** | 코끼리 부대 세계 최강 육상 전력 유지. 바라타 영토 완전 방어 |
| **갈등 요소** | 상인 귀족파의 군비 절감 요구. 코끼리 부대 유지 비용 막대 |

### 세부 특성
- 코끼리 계열 수인 기수들과 수십 년 협력. 수인 처우 개선 주장. 상인 귀족파와 갈등
- 강티세 동맹 접경 지역 마물 토벌 경험. 강티세 전사들과 비공식 교류
- 음반다 전사왕과 육상 전투에서 맞붙으면 어느 쪽이 강한지 궁금해하는 것으로 유명

## 5. 인도양 함대 제독 (Sagara-Nayaka)

| 항목 | 내용 |
|------|------|
| **직위** | 바라타 연방 인도양 함대 총사령관 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 해상 전투·항법 특화 |
| **성격** | 실용적이고 직선적. 자한 제독과 오랜 협력으로 상호 신뢰 두터움. 포르타 해군에 경계심 |
| **현재 상황** | 자한 술탄국 제독과 인도양 공동 순찰 운영. 포르타 해군 동향 주시 |
| **핵심 목표** | 인도양 교역로 완전 보호. 포르타 해군 견제 |
| **갈등 요소** | 상인 귀족 수장이 해군 확장보다 교역로 보험 비용으로 대체 주장. 군비 vs 상업 논리 충돌 |

### 세부 특성
- 자한 술탄국 제독과 수년간 공동 작전 경험. 인도양 양대 해군 실질 동맹
- 포르타 콘소르티움 해군 전력 직접 파악. 단독 충돌은 호각. 자한과 연합 시 우위
- 바라타 뱀 계열 수인 특수대와 협력. 해상 기습·수중 공작 운용

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **마하라자 → 대브라만** | 왕권 정당성 의존. 균형 유지 |
| **마하라자 → 상인 귀족 수장** | 경제 기반 의존. 균형 유지 |
| **마하라자 → 코끼리 부대 지휘관** | 신임. 군사 기반 |
| **마하라자 → 인도양 제독** | 신임. 해상 패권 위임 |
| **대브라만 ↔ 상인 귀족 수장** | 권위 vs 이익 갈등 |
| **상인 귀족 수장 → 코끼리 부대 지휘관** | 군비 절감 압박 |
| **인도양 제독 ↔ 자한 술탄국 제독** | 오랜 협력. 인도양 공동 수호 |
| **인도양 제독 → 포르타 해군** | 경계. 단독 충돌 호각 인식 |
