# 누산타라 동맹 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

---

## 1. 맹주 (Maharaja Laut)

| 항목 | 내용 |
|------|------|
| **직위** | 누산타라 동맹 맹주. 가장 강력한 섬 세력 수장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 해상 전투 특화 |
| **성격** | 실용적 온건파. 해적 문화가 동맹 교역 이미지 훼손한다는 현실 인식. 장기적 교역 패권 지향 |
| **현재 상황** | 해적 중심 섬 활동 억제 시도. 교역 중심 섬 결속 강화. 하이둥·바라타와 협력 확대 |
| **핵심 목표** | 누산타라를 해적 연합이 아닌 교역 연합으로 전환. 동남아 해로 완전 장악 |
| **갈등 요소** | 해적 선장이 맹주 억제 정책에 비공식 저항. 해적 섬 연합 따로 결속 움직임 |

### 세부 특성
- 하이둥 상방 집정관과 동부 해로 분점 협약 유지 중
- 파푸아 동맹과 오세라 교역 창구 역할. 바라타·하이둥 연결
- 해적 선장을 완전 제거하면 동맹 내 해적 섬들 이탈 가능. 균형 유지 필요
- 프레이 아르키펠 최강 해적 선장 소문 접함. 누산타라 영역 진입 시 대응 계획 준비

## 2. 교역 섬 연합 수장 (Kepala Pedagang)

| 항목 | 내용 |
|------|------|
| **직위** | 교역 중심 섬 연합 대표. 맹주 지지파 핵심 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 교역·항로 전문가 |
| **성격** | 안정 지향. 해적 활동이 자신의 교역 이익 훼손한다는 직접 피해 경험. 맹주 억제 정책 적극 지지 |
| **현재 상황** | 맹주 지지 교역 섬 결속 강화. 해적 섬 경제적 고립 시도 |
| **핵심 목표** | 교역 이익 보호. 해적 활동으로 인한 상선 피해 제로화 |
| **갈등 요소** | 해적 섬들이 교역 섬 상선도 때로 약탈. 직접 피해 누적 |

### 세부 특성
- 바라타 연방 상인 귀족 수장과 직거래 채널 보유
- 하이둥 상방 집정관과 정기 교역 협약 갱신 담당
- 남비엣 왕국 자치권 수호 영주와 비공식 교역. 왕 모르게

## 3. 해적 섬 연합 수장 (Kepala Bajak Laut)

| 항목 | 내용 |
|------|------|
| **직위** | 해적 중심 섬 연합 비공식 수장. 맹주 억제 정책 저항 대표 |
| **에테르** | 엘리트 중 (5단계). 무인 계열 |
| **성격** | 강한 자가 살아남는 원칙. 맹주의 교역 전환 시도를 전통 파괴로 인식. 해적 선장에 의존 |
| **현재 상황** | 해적 섬 연합 결속 유지. 해적 선장을 정치적으로 활용 시도 |
| **핵심 목표** | 해적 전통 문화 유지. 맹주 교체 또는 억제 정책 철회 |
| **갈등 요소** | 해적 선장이 자신의 통제 밖. 선장을 이용하려 하나 선장이 명령 받지 않음 |

### 세부 특성
- 프레이 아르키펠과 비공식 해적 문화 연대 인식. 직접 교류는 거리상 어려움
- 맹주가 해적 활동 제한 법령 통과 시도 시 동맹 탈퇴 협박 카드 보유
- 해적 선장의 전투력 덕분에 맹주가 직접 제거 못 함을 알고 이용

## 4. 최강 해적 선장 (Kapten Hiu Putih)

| 항목 | 내용 |
|------|------|
| **직위** | 누산타라 동맹 내 최강 독자 선단 선장. 전투력 1위 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 해상·수중 전투 극한 특화 |
| **종족** | 상어 계열 수인 |
| **성격** | 강한 자에 흥미. 약한 자 무관심. 명령 거부. 자신이 흥미 있는 것만 함 |
| **현재 상황** | 독자 선단으로 동남아 해로 누비는 중. 맹주·해적 섬 수장 명령 모두 무시 |
| **핵심 목표** | 강한 상대와 싸우는 것. 더 강한 자 찾기 |
| **갈등 요소** | 프레이 아르키펠 최강 해적 선장(상어 수인) 소문 들음. 같은 상어 계열. 강한 흥미 |

### 세부 특성
- 바라타 연방 인도양 제독과 교전 전례. 호각. 누산타라 영역에서는 선장 우위
- 하이둥 상방 해군과 동부 해로 분쟁. 하이둥이 선장 영역 우회 항로 사용 중
- 프레이 아르키펠 최강 해적 선장이 같은 상어 계열 수인이라는 정보 입수. 만나고 싶다는 발언
- 맹주 억제 정책에 무관심. 흥미 없으면 아무것도 안 함. 해적 섬 수장의 이용 시도 인식하나 귀찮아서 방치

## 5. 교역 함대 제독 (Laksamana Dagang)

| 항목 | 내용 |
|------|------|
| **직위** | 누산타라 동맹 공식 교역 함대 총사령관 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 교역로 방어·항법 특화 |
| **성격** | 원칙적이고 맹주 충성. 해적 선장과 달리 조직과 명령 체계 중시 |
| **현재 상황** | 교역 함대 운영·교역로 방어 총괄. 해적 선장 활동 범위와 겹치는 구역 조율 고민 |
| **핵심 목표** | 교역로 완전 보호. 누산타라 공식 해군력 강화 |
| **갈등 요소** | 해적 선장이 공식 함대 명령 무시. 같은 해역에서 충돌 가능성 상존 |

### 세부 특성
- 파푸아 동맹과 오세라 방면 항로 개척. 마우이 해연과 간접 연결
- 바라타 연방 인도양 제독과 협력 관계. 남방 해로 공동 순찰
- 해적 선장 전투력이 자신보다 높음을 인정. 직접 충돌 회피
- 하이둥 상방 집정관과 동부 해로 분점 실무 협상 담당

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **맹주 → 교역 제독** | 신임. 교역 전환 군사 기반 |
| **맹주 → 교역 섬 수장** | 핵심 지지 기반 |
| **맹주 → 해적 선장** | 통제 불가. 균형 유지 필요 |
| **맹주 → 해적 섬 수장** | 견제. 동맹 탈퇴 협박 카드 관리 |
| **교역 섬 수장 ↔ 해적 섬 수장** | 노선 대립 |
| **해적 섬 수장 → 해적 선장** | 이용 시도. 선장 무시 |
| **해적 선장 → 교역 제독** | 명령 무시. 구역 충돌 |
| **해적 선장 → 프레이 아르키펠 최강 해적 선장** | 강한 흥미. 미면 |
| **교역 제독 → 바라타 인도양 제독** | 협력. 남방 해로 공동 순찰 |
