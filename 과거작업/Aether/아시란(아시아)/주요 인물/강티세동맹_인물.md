# 강티세 동맹 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 강티세 동맹은 맹주 권한 제한적. 각 문파 자율성 강함. 외부에 정보 일절 비공개.

## 1. 맹주 (Meng-zhu)

| 항목 | 내용 |
|------|------|
| **직위** | 강티세 동맹 맹주. 문파 대표 선출직. 대외 교섭·분쟁 조율만 담당 |
| **에테르** | 엑스퍼트 상 (9단계). 내공·술식 병행 수련. 쌍도에 가장 근접한 인물로 소문 |
| **성격** | 극도로 과묵. 말 대신 행동. 외부 세력 개입에 원칙적 거부. 그러나 세계 변화는 예의주시 |
| **현재 상황** | 고립 유지 원칙 고수. 문파 간 노선 갈등 중재 역할 병행. [E] 마물 이상 징후 주시 중 |
| **핵심 목표** | 강티세 동맹 독립성·비밀 유지. 외부 오염 차단 |
| **갈등 요소** | 문파 간 외부 의뢰 수행 여부 갈등 반복. 중재 한계에 다가가는 중 |

### 세부 특성
- 강티세 고산 동굴에 보관된 고대 기록 내용 파악. 내용은 외부에 절대 비공개
- 쌍도 연구 문파의 시도를 묵인. 직접 금지 않으나 공식 지원도 없음
- [E] 마물 급증이 고대 기록 내용과 연관 가능성 인식. 홀로 고민 중
- 중위안·마루한·텡그리 모두로부터 접촉 요청 받았으나 모두 거절

## 2. 최강 내공 문파 수장 (Neigong Zhangjiao)

| 항목 | 내용 |
|------|------|
| **직위** | 강티세 동맹 최대 내공 문파 수장 |
| **에테르** | 마스터 하 (10단계). 무인 계열. 체내 에테르 경로 극한 개척. 신체 능력 초인적 |
| **성격** | 전통 수련 철학 절대 신봉. 외부 기술 도입 거부. 강티세 고립이 순수성 유지의 조건이라는 믿음 |
| **현재 상황** | 쌍도 연구 문파의 활동을 이단으로 간주. 맹주에게 금지 압박 중 |
| **핵심 목표** | 내공 수련 극한 추구. 전통 방식으로 쌍도보다 높은 경지 가능하다는 것 증명 |
| **갈등 요소** | 쌍도 연구 문파 수장과 노선 대립. 외부 의뢰 수행하는 문파들에 강한 반발 |

### 세부 특성
- 강티세 동맹 내 현재 전투력 최상위. 맹주와 동급 혹은 그 이상이라는 설
- 텡그리 에테르 기마 전술 개발자가 접촉 시도한 인물. 거절
- 고대 기록 내용 일부를 맹주로부터 들었다는 소문. 이후 더욱 고립 지향
- 외부에 알려진 강티세 은둔 고수 전설의 가장 유력한 실체로 거론됨

## 3. 최강 술식 문파 수장 (Shu-shi Zhangjiao)

| 항목 | 내용 |
|------|------|
| **직위** | 강티세 동맹 최대 술식 문파 수장 |
| **에테르** | 엑스퍼트 상 (9단계). 마법사 계열. 고산 자연 에테르 직접 활용. 마정석 의존 없음 |
| **성격** | 탐구적이고 개방적. 고립 원칙은 지지하나 지식 자체는 외부와 교류 가능하다는 입장 |
| **현재 상황** | 쌍도 연구 문파와 협력 관계. 내공 문파 수장의 압박에 맞서 맹주에게 중립 유지 요청 |
| **핵심 목표** | 술식 체계 극한 발전. 고산 에테르 완전 제어 |
| **갈등 요소** | 내공 문파 수장과 노선 대립. 외부 의뢰 수행 허용 범위에서 입장 차이 |

### 세부 특성
- 마기스테리움 원장이 가장 접촉하고 싶은 인물. 강티세가 보유한 고산 에테르 이론에 관심
- 고대 통신 구슬 수신 신호에 대한 독자 분석 진행 중. 발신지 추적 시도
- 텡그리 에테르 기마 전술 개발자와 학술적 관심사 겹침. 비공식 서신 교환 가능성

## 4. 쌍도 연구 문파 수장 (Shuangdao Zhangjiao)

| 항목 | 내용 |
|------|------|
| **직위** | 강티세 동맹 내 쌍도 연구 전담 문파 수장 |
| **에테르** | 엘리트 상 (6단계). 내공·술식 병행 수련 중. 현재 병행 수준 강티세 최고 |
| **성격** | 집념의 연구자. 불가능하다는 말을 증명하는 것이 목표. 외부 기록 탐색에 적극적 |
| **현재 상황** | 맹주 묵인 하에 쌍도 연구 진행. 내공 문파 수장의 이단 압박 버티는 중 |
| **핵심 목표** | 쌍도 달성. 내외 에테르 충돌 문제 해결 |
| **갈등 요소** | 내공 문파 수장과 직접 대립. 맹주의 묵인이 사라지면 문파 해체 위험 |

### 세부 특성
- 강티세 고대 기록 중 쌍도 관련 구절 부분 해독 성공. 내용은 극비
- 칠람 동맹 고대 유적 연구와 연관 가능성 탐색. 비공식 접촉 시도 중
- 내공·술식 동시 수련으로 에테르 충돌을 극미량 수준에서 제어하는 데 성공. 아직 쌍도 미달
- 마기스테리움 수석 마법사 교수의 쌍도 연구팀 존재를 알고 있다는 소문

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **맹주 → 내공 문파 수장** | 존중. 전통 수련 권위 인정. 금지 않음 |
| **맹주 → 술식 문파 수장** | 신뢰. 중립 유지 협력 |
| **맹주 → 쌍도 연구 문파 수장** | 묵인. 공식 지원 없음 |
| **내공 문파 수장 ↔ 술식 문파 수장** | 노선 대립. 전통 vs 개방 |
| **내공 문파 수장 → 쌍도 연구 문파 수장** | 이단 압박. 맹주 통해 금지 요청 |
| **술식 문파 수장 → 쌍도 연구 문파 수장** | 협력. 연구 지지 |
| **맹주 → [E] 마물·고대 기록** | 연관 인식. 홀로 고민 중 |
| **술식 문파 수장 → 고대 통신 구슬** | 수신 신호 독자 분석 중 |
