# 다슈트 연합 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.

## 1. 대표 수장 (Bas-Khan)

| 항목 | 내용 |
|------|------|
| **직위** | 다슈트 연합 대표 수장. 아르다샤르 황제 승인 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 초원 기동전 특화 |
| **성격** | 극도로 실용적. 이념 없음. 생존과 이익만 봄. 아르다샤르·텡그리 양쪽 모두 믿지 않음 |
| **현재 상황** | 아르다샤르에 공물 납부 유지하면서 텡그리와 비공식 접촉 시도 중. 양쪽 눈치 병행 |
| **핵심 목표** | 다슈트 연합 생존. 실크로드 통행세 수입 유지. 어느 쪽이 강해지든 살아남기 |
| **갈등 요소** | 아르다샤르 의존파와 텡그리 전향 검토파 사이 내부 분열. 어느 쪽 선택도 위험 |

### 세부 특성
- 아르다샤르 황제 승인을 받았으나 실질적으로 황제 명령 최소한만 이행
- 텡그리 칸국 칸에게 비공식 서신 발송 전례. 아르다샤르에 발각 시 위험
- 실크로드 통행세를 아르다샤르에 일부만 납부. 나머지 비밀 적립
- 정착 부족·유목 부족 양쪽 지지 유지가 수장직 핵심 과제

## 2. 정착 부족 대표 (Ra'is al-Muqimin)

| 항목 | 내용 |
|------|------|
| **직위** | 실크로드 거점 정착 부족 연합 대표. 아르다샤르 의존파 수장 |
| **에테르** | 어뎁트 하 (1단계). 에테르 보유. 실무 활용 않음. 교역·행정 전문가 |
| **성격** | 안정 지향. 실크로드 거점 도시 유지가 최우선. 전쟁·혼란은 생존 기반 파괴 |
| **현재 상황** | 아르다샤르 종속 유지 강력 지지. 텡그리 전향 검토 자체를 위험으로 인식 |
| **핵심 목표** | 실크로드 거점 도시 안전. 아르다샤르 보호막 유지 |
| **갈등 요소** | 수장의 이중 외교가 아르다샤르 자극할까 우려. 텡그리와의 비공식 접촉 반대 |

### 세부 특성
- 카라반사라이 운영으로 가장 큰 통행세 수입 보유. 실크로드 경제 실질 장악
- 아르다샤르 다슈트 담당 관료와 직접 채널. 정기 보고·납부
- 텡그리 전향 검토파가 세력 키우면 자신의 경제 기반 흔들릴 것을 가장 두려워함

## 3. 유목 부족 대표 (Ra'is al-Ruhhal)

| 항목 | 내용 |
|------|------|
| **직위** | 초원 유목 부족 연합 대표. 텡그리 전향 검토파 수장 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 초원 기동·생존 특화 |
| **성격** | 직선적이고 현실적. 힘센 쪽에 붙는 것이 당연하다는 초원 논리. 아르다샤르보다 텡그리가 더 강해지고 있다고 판단 |
| **현재 상황** | 텡그리 칸국 사신과 비공식 접촉. 전향 시 조건 탐색 중 |
| **핵심 목표** | 유목 부족 생존·자유 유지. 더 강한 쪽과 함께 |
| **갈등 요소** | 정착 부족 대표와 노선 충돌. 텡그리 전향 시 정착 거점 포기 가능성 있음 |

### 세부 특성
- 텡그리 에테르 기마 전술 직접 관찰 경험. 아르다샤르 기병보다 강하다는 판단
- 유목 부족 특성상 텡그리 전향해도 거점 잃을 것 없음. 정착 부족과 이해관계 다름
- 수장의 이중 외교를 결국 텡그리로 전향하기 위한 시간 벌기로 해석

## 4. 실크로드 수호대장 (Qa'id al-Tariq al-Harir)

| 항목 | 내용 |
|------|------|
| **직위** | 다슈트 연합 실크로드 교역로 방어 총사령관 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 카라반 호위·요새 방어 특화 |
| **성격** | 원칙적. 교역로 안전이 최우선. 정치 논쟁에 거리 두되 교역로 위협 시 즉각 대응 |
| **현재 상황** | 텡그리 칸국 비공식 강탈 증가로 순찰 강화. 아르다샤르 지원 요청 중 |
| **핵심 목표** | 실크로드 완전 안전 보장. 어느 세력도 교역로 위협 못 하도록 |
| **갈등 요소** | 텡그리 전향 시 현재 방어 체계 무의미. 정착 부족 지지하나 군사 현실은 인정 |

### 세부 특성
- 아르다샤르 서부 방위대장·제국 원수 양측과 협력 채널 보유
- 솔다텐라트 황금 방패 길드와 카라반 호위 의뢰 계약 다수
- 스텝 거대 지네 등 실크로드 위협 마물 대응 경험 풍부
- 텡그리 기마대 전술을 직접 경험. 정면 대결 불리함 파악. 요새 방어 전술 강화 중

## 5. 초원 기마대장 (Qa'id al-Fursaan)

| 항목 | 내용 |
|------|------|
| **직위** | 다슈트 유목 부족 기마대 총사령관 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 초원 기동 전투 특화 |
| **성격** | 자유롭고 호탕. 초원 전투를 삶으로 봄. 정치보다 전투. 텡그리 기마대와 언젠가 정면 승부 원함 |
| **현재 상황** | 유목 부족 기마대 훈련 총괄. 텡그리 기마대 전술 분석·대응 연구 |
| **핵심 목표** | 다슈트 기마대를 텡그리와 대등한 수준으로 강화 |
| **갈등 요소** | 유목 부족 대표의 텡그리 전향 검토에 불만. 싸워서 이기면 된다는 입장 |

### 세부 특성
- 텡그리 에테르 기마 전술 대응 독자 개발 중. 아직 격차 큼
- 텡그리 칸국 칸의 전투 능력을 직접 목격한 경험. 현실 인정하면서도 투지 강함
- 이스칼드 분트 설원 최강 전사 소문 들음. 다른 대륙 최강자들에 흥미

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **수장 → 정착 부족 대표** | 경제 기반으로 협력. 이중 외교 반발 관리 |
| **수장 → 유목 부족 대표** | 이중 외교 파트너. 텡그리 전향 카드 활용 |
| **정착 부족 대표 ↔ 유목 부족 대표** | 노선 충돌. 이해관계 근본 차이 |
| **실크로드 수호대장 → 정착 부족 대표** | 교역로 안전 협력. 지지 |
| **초원 기마대장 → 유목 부족 대표** | 전향 검토 반대. 싸워서 이기자는 입장 |
| **실크로드 수호대장 ↔ 초원 기마대장** | 협력. 각자 방어·기동 전담 분업 |
| **실크로드 수호대장 → 아르다샤르 제국 원수** | 지원 요청 채널 |
| **수장 → 텡그리 칸국** | 비공식 접촉. 극비 |
