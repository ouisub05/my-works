# 타이가 부족연

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 시베리아 일대. 침엽수림·툰드라 지역 |
| **체제** | 부족 연합. 대샤먼 + 부족장 회의 |
| **국교** | 정령 신앙. 숲·눈·바람 정령 숭배. 샤머니즘 중심 |
| **주요 종족** | 인간·수인 혼합. 수인 비율 아시란 최고 |
| **군사력** | 중하위권. 극한 환경 생존 전투 특화 |
| **에테르 기술** | 낮음. 수렵·생존 특화 에테르 기술 |

---

## 주요 수인 종류

| 종류 | 특화 능력 | 에테르 보유 |
|------|----------|-----------|
| **흰늑대** | 후각·지구력·무리 전투. 혹한 환경 최적화 | 10명 중 5명 |
| **흰곰** | 압도적 근력·내구력. 혹한 저항력 | 10명 중 3명 |
| **순록** | 지구력·이동속도. 설원 이동 특화 | 10명 중 6명 |
| **올빼미** | 야간 시각·청각. 침묵 비행 | 10명 중 7명 |

---

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| **대샤먼** | 정령 신앙 최고 권위자. 부족 연합 정신적 중심 |
| **부족장 회의** | 각 부족 수장 참여. 군사·외교 결정 |
| **전시 수장** | 마루한 침공 시 전투 지휘 전담 선출 |

---

## 마루한 저항

| 전술 | 내용 |
|------|------|
| **극한 환경 활용** | 시베리아 혹한·밀림. 마루한 정규군 적응 어려움 |
| **게릴라전** | 소규모 기습·매복. 보급선 차단 |
| **광역 분산** | 넓은 시베리아에 분산 거주. 완전 토벌 불가 |
| **계절 전술** | 극한 겨울에 반격. 마루한 철수 시 영토 회복 |

> 마루한도 **"시베리아 전체 정복은 비용 대비 이익 없음"** 인식
> 현재는 주요 거점만 통합하고 나머지는 완충 지대로 방치

## 생존 기반

| 항목 | 내용 |
|------|------|
| **수렵·채집** | 극한 환경 적응 동물·식물 채취. 기본 생존 기반 |
| **마물 사냥** | 시베리아 특유 한대 마물 전문 사냥. 소재 채취 |
| **교역** | 마물 소재·모피·희귀 자원 → 마루한·아이누 경유 외부 수출 |

| 마물 | 등급 | 특징 |
|------|------|------|
| **영구 동토 트롤** | 5~6등급 | 극한 냉기 내성 |
| **빙설 와이번** | 7등급 | 시베리아 산맥 서식 |
| **툰드라 거인** | 6~7등급 | 겨울에 강화 |
| **백색 마룡** | 8등급 | 시베리아 최상위 포식자. 극희소 |

## 대외 관계

| 대상 | 관계 |
|------|------|

| **아이누 부족연** | 북방 부족 연대. 공통 수인 문화 공유. 비공식 교류 |
| **이스칼드 분트** | 문화·환경 유사. 간접 인식. 직접 교류는 거의 없음 |
| **하이둥 상방** | 마루한·아이누 경유 간접 교역 |
