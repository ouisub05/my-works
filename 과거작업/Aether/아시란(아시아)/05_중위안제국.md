# 중위안 제국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 중국 중앙 일대. 황하·양자강 유역 중심 |
| **체제** | 황제 + 관료제. 과거 시험 기반 |
| **국교** | 없음. 조상 숭배·자연신 신앙 복수 공존 |
| **주요 종족** | 인간 다수. 수인 소수. 하프 엘프 극소수 |
| **군사력** | 상위권. 아시란 중부 최강. 수적 우위 압도적 |
| **에테르 기술** | 상위권. 술식 체계 고도로 발달. 독자 이론 체계 보유 |

---

## 황제 + 관료제

| 항목 | 내용 |
|------|------|
| **황제** | 절대 권력. 하늘의 아들(天子) 개념. 모든 권위의 원천 |
| **과거 시험** | 신분 무관 에테르 실력·학문으로 관료 선발 |
| **관료 계층** | 황제 아래 방대한 관료 조직. 중앙·지방 행정 담당 |
| **귀족** | 존재하나 과거 출신 관료에게 실권 밀림 |
| **환관** | 황실 내부 권력. 관료·귀족과 견제 구도 |

> 순수 전투 특화 무인은 하급 취급 — 마루한 제국과 가치관 충돌 원인

## 조공 체제

| 항목 | 내용 |
|------|------|
| **기본 원칙** | 중위안이 세계의 중심. 주변 세력은 조공으로 문명 혜택 받음 |
| **조공 세력** | 고리 왕국, 남비엣 왕국, 일부 동남아 세력 등 |
| **조공 내용** | 특산물·인질·충성 서약 → 중위안이 작위·교역권·보호 제공 |
| **거부 세력** | 마루한 제국, 텡그리 칸국은 조공 거부. 오랑캐 취급 |

---

## 마루한 제국과의 적대

| 항목 | 내용 |
|------|------|
| **역사적 갈등** | 만주·중원 경계 지역을 두고 반복적 전쟁 |
| **이념 충돌** | 문화·관료제 중심 중위안 vs 군사·기술 중심 마루한 |
| **조공 거부** | 마루한은 중위안 조공 체제 거부. 대등한 국가 관계 주장 |
| **현재 상태** | 공식 전쟁은 없으나 국경 충돌 지속. 외교 단절 상태 |
| **대리 갈등** | 고리 왕국을 두고 양측이 영향력 경쟁 |

> 중위안은 마루한을 **"문명 없는 오랑캐"** 로 폄하
> 마루한은 중위안을 **"약한 문인들의 나라"** 로 폄하

## 에테르 기술

| 기술 | 내용 |
|------|------|
| **술식 이론** | 에테르를 음양·오행 개념으로 체계화. 독자 이론 |
| **집단 술식** | 다수 마법사가 협력하는 대규모 술식 발달. 군사 응용 |
| **연단술** | 에테르로 물질 변환·정제하는 독자 기술 |
| **기록·보존** | 방대한 술식 문헌 보유. 아시란 최대 마법 도서관 |
