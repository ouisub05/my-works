# 타이노 해연

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 카리브해 섬·플로리다 일대 |
| **체제** | 느슨한 섬 연합. 대추장 + 섬 추장 회의 |
| **국교** | 없음. 정령 신앙. 바다·바람·섬 정령 숭배 |
| **주요 종족** | 인간 다수. 상어·돌고래·앵무새 계열 수인 소수 |
| **군사력** | 중하위권. 해상 전투 특화. 육상 전투 약함 |
| **에테르 기술** | 중하위권. 해양·항해 특화. 최근 외부 기술 유입으로 성장 중 |

| 항목 | 내용 |
|------|------|
| **교역 품목** | 타이노 → 열대 과일·마물 소재·진주 제공. 포르타 → 베스테리아 에테르 제품·금화 제공 |
| **규모** | 소규모 비정기 교역. 정기 항로 미수립 |
| **섬별 온도차** | 적극 교역 섬도 있고 거부하는 섬도 있음 |
