# 코만치 연합

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 텍사스·멕시코 북부 일대. 평원·사막 경계 |
| **체제** | 부족 연합. 전쟁 수장 + 평화 수장 이원 체제 |
| **국교** | 없음. 정령 신앙. 평원·바람·버팔로 정령 숭배 |
| **주요 종족** | 인간·버팔로·코요테·독수리 계열 수인 혼합 |
| **군사력** | 중위권. 평원 기마 전투 특화 |
| **에테르 기술** | 중하위권. 기마·생존 특화 에테르 기술 |

---

## 이원 체제

| 항목 | 내용 |
|------|------|
| **전쟁 수장** | 전시 지휘 전담. 전투 실력으로 선출 |
| **평화 수장** | 평시 외교·내정 담당. 지혜·중재 능력으로 선출 |
| **부족장 회의** | 각 부족 수장 참여. 전쟁·평화 전환 결정 |

---

## 완충 지대 전략

| 전략 | 내용 |
|------|------|
| **다자 교역** | 세 세력 모두와 교역. 어느 쪽도 독점 거래 허용 안 함 |
| **동맹 거부** | 어느 세력의 공식 동맹 요청도 거절 |
| **실력 유지** | 완충 지대로서 가치 있으려면 스스로 강해야 함 |
| **정보 활용** | 세 세력 사이를 오가며 얻은 정보를 외교 카드로 활용 |

---

## 테노치 제국과의 적대

| 항목 | 내용 |
|------|------|
| **갈등 원인** | 테노치 북방 팽창. 코만치 영토 침범 시도 반복 |
| **전투 양상** | 평원 기마전. 코만치 기동력 vs 테노치 에테르 기술 |
| **현재 상태** | 국경 분쟁 지속. 전면전은 아니나 충돌 잦음 |
| **코만치 강점** | 테노치 군대가 평원 환경에 익숙하지 않음. 기동전 우위 |

---

## 혼합 문화

| 종류 | 역할 |
|------|------|
| **버팔로 계열** | 근력·지구력. 돌격 담당 |
| **코요테 계열** | 지략·은신. 정찰·정보 수집 |
| **독수리 계열** | 시각·비행. 광역 정찰 |
