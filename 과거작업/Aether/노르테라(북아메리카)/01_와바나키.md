# 와바나키 공화국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 미국 동부 해안 일대 |
| **체제** | 민주 공화정. 선출 대통령 + 부족·종족 대표 의회 |
| **국교** | 없음. 정령 신앙·자연신 신앙 복수 공존 |
| **주요 종족** | 인간·수인·하프 엘프 등 다종족 공존 |
| **군사력** | 노르테라 최강. 다종족 연합 전력 |
| **에테르 기술** | 중상위권. 독자 발전 |

## 민주 공화정 구조

| 항목 | 내용 |
|------|------|
| **대통령** | 전체 시민 직선 선출. 임기 5년. 연임 1회 가능 |
| **대표 의회** | 부족·종족·지역 대표 참여. 법률·예산 의결 |
| **종족 평등** | 모든 종족 동등한 참정권 |
| **사법부** | 독립 사법 기관. 대통령·의회 견제 |

> 다종족 이해관계 조율이 정치의 핵심
> 의회 내 종족 간 갈등이 정치 혼란 원인이 되기도 함

## 군사력 — 노르테라 최강

| 병종 | 특징 |
|------|------|
| **다종족 연합군** | 각 종족 특화 능력을 결합한 복합 전력 |
| **수인 특수 부대** | 동부 해안·삼림 환경 특화. 정찰·기습 담당 |
| **에테르 무인·마법사** | 공화국 직속 정예 에테르 사용자 부대 |
| **해안 방위대** | 동부 해안 방어 전담. 해상 위협 대응 |

## 식량 생산력

| 항목 | 내용 |
|------|------|

## 포르타 접근 인지 — 감시 체제

| 항목 | 내용 |
|------|------|
| **인지 경위** | 타이노 해연으로부터 이상한 외부 선박 정보 입수 |
| **현재 대응** | 동부 해안 정찰 강화. 포르타 선박 동향 파악 |
| **내부 의견** | 위협파(차단 주장) vs 교역파(접촉 가능성 탐색) 논쟁 중 |
| **공식 입장** | 아직 미결. 감시 유지하며 정보 수집 중 |
