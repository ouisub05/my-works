# 하우데노 연합

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 캐나다 동부 일대. 오대호·세인트로렌스강 유역 |
| **체제** | 부족 연합. 대평의회 중심 |
| **국교** | 없음. 정령 신앙. 숲·물·대지 정령 숭배 |
| **주요 종족** | 수인 다수. 인간·하프 엘프 소수 |
| **군사력** | 중위권. 삼림·수로 전투 특화 |
| **에테르 기술** | 중위권. 자연 에테르 활용 중심 |

---

## 대평의회 구조

| 항목 | 내용 |
|------|------|
| **대평의회** | 각 부족 대표 참여. 만장일치 원칙 |
| **수장** | 선출직. 대평의회 의장 겸임 |
| **여성 원로** | 부족 대표 선출권 보유. 수장 탄핵 가능 |
| **전사 회의** | 군사 결정 전담. 대평의회 승인 필요 |

> 만장일치 원칙으로 결정 느리나 한번 결정되면 강한 결속력
> 여성 원로 제도가 노르테라 내에서 독특한 정치 구조로 알려짐

| 종류 | 특화 능력 | 연합 내 역할 |

| **늑대** | 후각·무리 전투. 삼림 추적 특화 | 척후·순찰 부대 |

| **수달** | 수륙 양용. 수로 전투 특화 | 수상 전투·교역 담당 |
