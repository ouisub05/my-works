# 테노치 제국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 멕시코 중부 일대. 고원·열대 지대 |
| **체제** | 신정 제국. 황제(틀라토아니) + 신관 회의 |
| **국교** | 태양신·전쟁신 중심 다신교. 에테르와 신성력 융합 독자 체계 |
| **주요 종족** | 인간 다수. 재규어·독수리 계열 수인 소수 |
| **군사력** | 중상위권. 노르테라 남부 최강 |
| **에테르 기술** | 중상위권. 고대 유물 활용 독자 에테르 체계 |

---

## 신정 제국 구조

| 항목 | 내용 |
|------|------|
| **틀라토아니** | 황제. 태양신의 대리인. 종교·세속 권력 일체화 |
| **신관 회의** | 각 신 담당 신관 집단. 황제 보좌. 실질 행정 권력 |
| **전사 귀족** | 전투 실적으로 사회적 지위 결정 |
| **재규어 전사** | 정예 전사 계급. 재규어 계열 수인 포함 |
| **독수리 전사** | 공중 정찰·기습 특화 계급. 독수리 계열 수인 포함 |

> 테노치에서 **"전투는 신에게 바치는 의식"** 이라는 문화
> 적을 산 채로 포획하는 것이 죽이는 것보다 높은 명예

---

## 고대 유물 탐사

| 항목 | 내용 |
|------|------|
| **신관 탐사대** | 신관 회의 직속 유물 탐사·발굴 전담 조직 |
| **유물 분류** | 신성시 유물(신관 보관)·연구 유물(기술 활용)·위험 유물(봉인) |
| **연구 성과** | 고대 에테르 기관 일부 복원 성공. 독자 에테르 기술 급성장 원동력 |
| **이상 징후** | 일부 유물에서 에테르 사용 마물과 유사한 에테르 패턴 감지. 원인 불명 |

## 수르테라와의 적대

| 항목 | 내용 |
|------|------|
| **갈등 원인** | 고대 유물 매장지·고산 제국 영토 접경 분쟁 |
| **전쟁 양상** | 고원·밀림 국경 지대 산발적 충돌 |
| **현재 상태** | 전면전은 아니나 국경 분쟁 지속 |
| **핵심 쟁점** | 양측 모두 고대 유물 매장지 장악 원함 |

## 에테르·신성력 융합 체계

| 기술 | 내용 |
|------|------|
| **태양 에테르** | 태양 에너지를 에테르로 변환·증폭. 낮에 강화 |
| **피라미드 증폭** | 거대 석조 피라미드가 에테르·신성력 집적 구조물 역할 |
| **고대 유물 기관** | 발굴 유물 일부를 에테르 기관으로 재활용 |
| **의식 강화** | 종교 의식 수행 시 신성력·에테르 일시 강화 |
