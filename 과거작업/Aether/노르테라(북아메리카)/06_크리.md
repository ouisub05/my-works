# 크리 부족연

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 미국 중부 평원 일대. 고정 영토 없이 이동 |
| **체제** | 이동 부족 연합. 대족장 + 부족장 회의 |
| **국교** | 없음. 정령 신앙. 버팔로·평원·하늘 정령 숭배 |
| **주요 종족** | 버팔로 계열 수인 다수. 인간 소수 |
| **군사력** | 중하위권. 이동 전술·평원 기동 특화 |
| **에테르 기술** | 중하위권. 이동·생존·정령 특화 에테르 기술 |

---

## 이동 전술 — 생존 전략

| 원칙 | 내용 |
|------|------|
| **고정 영토 없음** | 계절·상황에 따라 이동. 어느 세력도 완전 포위 불가 |
| **예측 불가 경로** | 이동 경로 외부에 공개 안 함 |
| **분산 이동** | 소규모 집단으로 분산 이동. 전멸 위험 감소 |
| **합류 신호** | 위기 시 전 부족 합류하는 비밀 신호 체계 |

---

## 버팔로 문화

| 항목 | 내용 |
|------|------|
| **신체 특성** | 압도적 근력·내구력. 돌격 전투 특화 |
| **문화적 위상** | 크리 부족연의 상징. 족장은 버팔로 계열 수인이 대부분 |
| **식량** | 버팔로 사냥이 주요 식량원 |
| **재료** | 버팔로 가죽·뼈·내장 모두 활용. 의복·도구·에테르 재료 |
| **정령 신앙** | 버팔로 정령을 부족 수호 정령으로 숭배 |

## 하우데노 연합과의 관계 — 보호의 함정

| 항목 | 내용 |
|------|------|
| **하우데노 공식 입장** | 크리 보호. 독립 지원 |
| **크리 인식** | **"보호하는 척 흡수하려 한다"** — 강한 경계심 |
| **실제 우려** | 하우데노 영토 내 크리 정착 유도. 자치권 축소 시도 |
| **크리 대응** | 하우데노 영토 접근 최소화. 협상은 하되 의존 거부 |

> 크리 입장에서 하우데노는 **"가장 위험한 친구"**
