# 하우데노 연합 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 하우데노 연합은 수인 강세. 크리 부족연 흡수 추진 중. 와바나키 공화국과 경쟁·협력 관계.

---

## 1. 대의장 (Tadodaho)

| 항목 | 내용 |
|------|------|
| **직위** | 하우데노 연합 대의장. 6개 부족 연합 최고 합의 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 삼림·수로 전투 특화 |
| **성격** | 카리스마 있고 설득력 강함. 합의 도출 능력 탁월. 크리 흡수를 연합 확장의 자연스러운 수순으로 프레임 |
| **현재 상황** | 크리 부족연 접경 압박 강화. 와바나키 연대파와 독자 노선파 균형 관리 중 |
| **핵심 목표** | 크리 부족연 흡수로 하우데노 세력 확장. 노르테라 동부 주도권 확보 |
| **갈등 요소** | 크리 흡수 과정에서 와바나키 개입 여부. 와바나키가 크리 편들면 상황 복잡 |

### 세부 특성
- 크리 부족연에게 흡수가 아닌 연합 편입으로 프레이밍. 자발적 참여 명분 만들기 추진
- 와바나키 대통령의 노르테라 연합 체제 구상을 역으로 활용. 하우데노가 동부 대표로 편입 협상 시도
- 곰 계열 수인 부족들과 긴밀한 관계. 수인 전사 수장을 군사 기반으로 신임
- 포르타 위협보다 와바나키 주도 통합 체제를 더 직접적 위협으로 인식

## 2. 와바나키 연대파 부족장 (Skennon)

| 항목 | 내용 |
|------|------|
| **직위** | 남부 접경 부족 대표. 와바나키 연대파 수장 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열 |
| **성격** | 현실주의. 포르타 위협에 대응하려면 와바나키와 협력이 필수라는 판단 |
| **현재 상황** | 와바나키 자율파 의원과 비공식 채널 유지. 하우데노 연합 참여 조건 협상 모색 |
| **핵심 목표** | 포르타 위협 공동 대응. 와바나키와 대등한 연대 관계 구축 |
| **갈등 요소** | 대의장의 독자 노선 방침. 크리 흡수가 와바나키 자극할 것이라는 우려 |

### 세부 특성
- 와바나키 해안 경비대장과 비공식 정보 교환 전례. 포르타 탐험대 정보 공유
- 크리 흡수에 반대는 아니나 방식에서 대의장과 차이. 협상보다 압박 방식 비판
- 포르타 콘소르티움 타이노 접촉 정보를 가장 심각하게 받아들이는 하우데노 인물

## 3. 독자 노선파 부족장 (Skennenrahawi)

| 항목 | 내용 |
|------|------|
| **직위** | 북부 부족 대표. 독자 노선파 수장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 자존심 강하고 경쟁적. 와바나키에 종속되는 어떤 형태도 거부. 하우데노 독자 강대화 추구 |
| **현재 상황** | 대의장 크리 흡수 방침 지지. 와바나키 연대 반대 |
| **핵심 목표** | 하우데노 독자 세력화. 와바나키와 대등·이상의 위치 확보 |
| **갈등 요소** | 포르타 위협 현실화 시 독자 대응 한계. 연대파 주장 설득력 증가 우려 |

### 세부 특성
- 크리 부족연 일부 부족과 비공식 접촉. 하우데노 편입 회유 시도
- 틀링깃 동맹 [E] 마물 위협 정보 입수. 남하 가능성 경계 중
- 와바나키 통합파 의원의 노르테라 연합 구상을 하우데노 흡수 시도로 인식. 강경 반대

## 4. 수인 전사 수장 (Ayonwentah)

| 항목 | 내용 |
|------|------|
| **직위** | 하우데노 연합 최강 전투 직군. 수인 전사 부대 총수 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 수인 신체 능력+에테르 강화 융합 특화 |
| **종족** | 곰 계열 수인. 하우데노 수인 중 최강 |
| **성격** | 강직하고 직선적. 전투에서 정직함. 크리 흡수보다 실력으로 인정받는 방식 선호 |
| **현재 상황** | 크리 접경 군사 압박 총괄. 수인 전사 부대 훈련 강화 |
| **핵심 목표** | 하우데노 군사력 최강 유지. 수인 전사 문화 보전 |
| **갈등 요소** | 크리 흡수 압박 방식에 내심 불만. 강제 흡수보다 전투에서 이겨 복속시키는 방식 선호 |

### 세부 특성
- 곰 계열 수인 특성 극한 발현. 근력·내구력 초인적 수준. 에테르 강화로 더욱 극대화
- 와바나키 방위군 총사령관과 직접 비교 대상. 실력 비교 욕구 있으나 현재 연합 관계 상 자제
- 크리 부족연 최강 전사와 교전 전례. 승리했으나 상당한 전투였다고 내부 평가
- [E] 마물 출현 보고 접수. 틀링깃 방향 경계 강화 지시 내림

## 5. 삼림 전술 지휘관 (Deganawida)

| 항목 | 내용 |
|------|------|
| **직위** | 하우데노 연합 정규 전술 부대 지휘관. 인간 전투 직군 대표 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 삼림 게릴라전·매복 전술 특화 |
| **종족** | 인간 |
| **성격** | 냉철한 전략가. 수인 전사 수장과 전술적 파트너. 인간·수인 혼합 전투 체계 구축 주도 |
| **현재 상황** | 크리 접경 매복 전술 설계. 와바나키 방위군과 전술 비교 연구 중 |
| **핵심 목표** | 하우데노 인간·수인 혼합 전투 체계 완성. 삼림 전투 최강화 |
| **갈등 요소** | 수인 주도권 파가 인간 전술 지휘관 영향력 확대를 견제 |

### 세부 특성
- 인간·수인 혼합 전투 체계 독자 개발. 수인 감각+인간 전술 판단 시너지 극대화
- 와바나키 방위군 총사령관의 에테르 기반 삼림 전술 연구. 유사성·차이점 분석 중
- 크리 흡수 과정에서 군사 설계 총괄 역할. 최소 피해 흡수 방안 구체화
- 수인 전사 수장과 상호 존중. 전투 방식은 다르나 결과에서 시너지 확인

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대의장 → 수인 전사 수장** | 신임. 군사 기반 |
| **대의장 → 삼림 전술 지휘관** | 신임. 전술 설계 위임 |
| **대의장 → 와바나키 연대파** | 관리. 와바나키 연락 채널 활용 |
| **대의장 → 독자 노선파** | 핵심 지지 기반 |
| **와바나키 연대파 ↔ 독자 노선파** | 의회 내 대립 |
| **수인 전사 수장 ↔ 삼림 전술 지휘관** | 상호 존중. 전투 시너지 |
| **수인 전사 수장 → 와바나키 방위군 총사령관** | 실력 비교 욕구. 자제 중 |
| **와바나키 연대파 → 와바나키 자율파 의원** | 비공식 채널 |
