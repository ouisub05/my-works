# 크리 부족연 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 크리 부족연은 버팔로 유목 문화. 하우데노 흡수 압박 저항 중. 독립 유지 의지 강함.

---

## 1. 대족장 (Okimaw)

| 항목 | 내용 |
|------|------|
| **직위** | 크리 부족연 대족장. 부족 회의 선출 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 초원 기동전 특화 |
| **성격** | 강인하고 고집스러움. 크리의 자유로운 유목 문화가 편입으로 사라질 것을 두려워함. 타협은 굴복이라는 신념 |
| **현재 상황** | 하우데노 접경 압박 대응 중. 와바나키에 간접 지원 요청 타진 |
| **핵심 목표** | 크리 부족연 독립 유지. 하우데노 흡수 저지 |
| **갈등 요소** | 현대화파 부족장의 현실론 압박. 하우데노 전력 대비 크리 열세 현실 |

### 세부 특성
- 버팔로 계열 수인 부족과 수십 년 공존 협력. 혼합 전투 문화 형성
- 와바나키 대통령에게 하우데노 팽창 저지 협력 비공식 요청. 아직 답변 없음
- 하우데노 독자 노선파 부족장이 편입 회유 시도한 것 인지. 일언지하 거절
- 전통 수호파이나 버팔로 기마 전사 수장의 전투력 유지를 위해 일부 현대화 묵인

## 2. 전통 수호파 부족장 (Pimicikosiw)

| 항목 | 내용 |
|------|------|
| **직위** | 중부 부족 대표. 전통 수호파 수장 |
| **에테르** | 엘리트 하 (4단계). 정령사 계열. 초원 정령 소계약 |
| **성격** | 보수적이고 완고. 버팔로 이동 경로가 곧 크리의 삶이라는 신념. 정착은 죽음이라는 표현 사용 |
| **현재 상황** | 대족장 지지. 현대화파 억제. 버팔로 이동 경로 수호 |
| **핵심 목표** | 크리 유목 문화 순수 보전. 정착 시도 차단 |
| **갈등 요소** | 하우데노 압박으로 버팔로 이동 경로 일부 차단됨. 전통 수호의 실질적 기반 흔들리는 중 |

### 세부 특성
- 버팔로 계열 수인 샤먼들과 의식 공유. 초원 정령 네트워크 유지
- 이동 경로 차단이 버팔로 무리 감소로 이어진다는 위기 인식. 하우데노에 대한 분노 강함
- 와바나키 연대 요청에 소극적. 외부 세력 개입 자체를 경계

## 3. 현대화파 부족장 (Mistahi-maskwa)

| 항목 | 내용 |
|------|------|
| **직위** | 동부 접경 부족 대표. 현대화파 수장 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열 |
| **성격** | 현실적이고 유연. 유목 문화 존중하나 생존이 먼저라는 판단. 하우데노 편입도 옵션으로 열어둠 |
| **현재 상황** | 정착 거점 일부 시험 구축 중. 하우데노 조건부 편입 가능성 내부 검토 |
| **핵심 목표** | 크리 생존. 유목이든 정착이든 살아남는 방식 선택 |
| **갈등 요소** | 대족장·전통 수호파의 강경 반발. 배신자 취급 우려 |

### 세부 특성
- 하우데노 독자 노선파 부족장과 비공식 접촉. 편입 조건 탐색 중. 대족장 모름
- 와바나키 자율파 의원과 간접 연락. 크리 독립 지지 입장 확인 시도
- 버팔로 이동 경로 차단이 장기화되면 유목 유지 불가 현실 직시. 대족장에게 설득 시도 중

## 4. 버팔로 기마 전사 수장 (Pitikwahanapiwiyin)

| 항목 | 내용 |
|------|------|
| **직위** | 크리 부족연 최강 전투 직군. 버팔로 기마대 총수 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 버팔로 계열 수인 연합 기마 전투 특화 |
| **성격** | 전투에서 완전히 살아있는 전사. 하우데노 압박에 맞서 싸우는 것을 삶의 의미로 삼음. 항복 개념 없음 |
| **현재 상황** | 하우데노 접경 방어 최전선 지휘. 수인 전사 수장(하우데노)과 수차례 교전 |
| **핵심 목표** | 하우데노 접경 방어. 크리 독립 군사적으로 지켜내기 |
| **갈등 요소** | 전력 열세 현실. 버팔로 수인 전사들의 소모 감당 한계 도달 중 |

### 세부 특성
- 버팔로 계열 수인과 완전히 동화된 전투 방식. 수인 돌격+인간 에테르 지휘 시너지
- 하우데노 수인 전사 수장(곰 계열)과 수차례 접전. 전력 차 인정하나 지형 활용으로 선전
- 코만치 기마대 수장과 초원 기마 전투 방식 비교 대상. 직접 교류 없음
- 현대화파 부족장의 편입 협상 시도 알고 있음. 강하게 반대하나 대족장에게 직접 보고는 유보

---

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대족장 → 버팔로 기마 전사 수장** | 신임. 군사 기반 |
| **대족장 → 전통 수호파** | 핵심 지지 기반 |
| **대족장 → 현대화파** | 경계. 비밀 접촉 인지 못함 |
| **전통 수호파 ↔ 현대화파** | 대립. 생존 방식 근본 차이 |
| **현대화파 → 하우데노 독자 노선파** | 비밀 접촉. 편입 조건 탐색 |
| **버팔로 기마 전사 수장 → 하우데노 수인 전사 수장** | 반복 교전. 전력 열세 인정 |
| **버팔로 기마 전사 수장 → 현대화파** | 편입 시도 인지. 보고 유보 |
| **대족장 → 와바나키 대통령** | 간접 지원 요청 타진 중 |
