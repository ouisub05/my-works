# 코만치 연합 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 코만치 연합은 나바호·테노치 사이 완충 지대. 기마 전투 특화. 양측 균형 외교로 실리 추구.

---

## 1. 수장 (Paraibo)

| 항목 | 내용 |
|------|------|
| **직위** | 코만치 연합 최고 수장. 부족 회의 선출 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 기마 전투 특화 |
| **성격** | 교활하고 유연함. 어느 쪽에도 완전히 기울지 않는 것이 생존 전략임을 체화 |
| **현재 상황** | 나바호·테노치 양측과 교역 협약 유지. 포르타 존재 간접 인지. 직접 관계 없음 |
| **핵심 목표** | 완충 지대 지위 유지로 코만치 안전 보장. 양측에서 최대 실리 확보 |
| **갈등 요소** | 나바호 친화파와 테노치 친화파 내부 균열. 어느 쪽으로든 기울면 완충 지위 붕괴 |

### 세부 특성
- 나바호 왕에게는 동쪽 방어막 역할 강조. 테노치에게는 북방 완충 역할 강조. 양측 모두에서 존재 가치 인정받음
- 와바나키 연대 요청 거절. 특정 진영 편입은 완충 지위 손상
- 코요테 계열 수인 부족들과 연대. 초원 정보망 광범위하게 유지
- 기마대 수장을 절대 신임. 군사력이 완충 지위의 실질적 담보

## 2. 나바호 친화파 부족장 (Tuhukanuuh)

| 항목 | 내용 |
|------|------|
| **직위** | 북부 부족 대표. 나바호 친화파 수장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 안정 지향. 사막 문화 이해도 높음. 테노치 신정 체제를 신뢰하지 않음 |
| **현재 상황** | 나바호와 교역 확대 추진. 사막 마물 소재 공동 거래 협상 중 |
| **핵심 목표** | 나바호와 경제 연대 강화. 북부 부족 안정 |
| **갈등 요소** | 수장의 균형 방침과 충돌. 테노치 친화파와 의회 내 대립 |

### 세부 특성
- 나바호 사막 전사 수장과 개인적 친분. 전투 방식 상호 학습 전례
- 포르타 위협에 대해 와바나키보다 나바호를 통해 정보 입수
- 테노치 제국 팽창 성향을 가장 경계. 신정 국가 가치관과 코만치 유목 문화 충돌 우려

## 3. 테노치 친화파 부족장 (Ecueracapa)

| 항목 | 내용 |
|------|------|
| **직위** | 남부 부족 대표. 테노치 친화파 수장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 실용주의. 테노치의 강력한 경제·군사력을 현실로 수용. 교역 이익 우선 |
| **현재 상황** | 테노치와 교역 확대. 고대 유물 관련 정보 간접 수집 |
| **핵심 목표** | 테노치와 경제 연대. 남부 부족 이익 극대화 |
| **갈등 요소** | 수장의 균형 방침과 충돌. 나바호 친화파와 의회 내 대립 |

### 세부 특성
- 테노치 신관들과 비공식 교류. 고대 유물 관련 소문 수집 중
- 테노치 친화가 결국 테노치 종속으로 이어질 수 있다는 나바호 친화파 주장에 반박 논리 약함
- 포르타 위협보다 나바호 마정석 발견이 세력 균형 변화에 더 큰 영향이라 판단

## 4. 기마대 수장 (Tabbaquena)

| 항목 | 내용 |
|------|------|
| **직위** | 코만치 연합 기마대 총수. 연합 최강 전투 직군 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 기마 전투·초원 기동전 극한 특화 |
| **종족** | 인간. 코요테 계열 수인 혼합 부대 운용 |
| **성격** | 자유롭고 호탕. 초원이 곧 자신의 영역. 어느 세력도 코만치 영토 밟지 못하게 하는 것이 삶의 목표 |
| **현재 상황** | 나바호·테노치 접경 순찰 총괄. 양측 모두 코만치 영토 무단 진입 시 즉각 대응 |
| **핵심 목표** | 코만치 초원 완전 방어. 기마 전투 극한 수련 |
| **갈등 요소** | 나바호 사막 전사 수장과 비공식 경쟁. 테노치 전사와도 실력 비교 욕구 |

### 세부 특성
- 텡그리 칸국 에테르 기마 전술 소문 접함. 자신만의 기마 에테르 전술과 비교 욕구
- 나바호 사막 전사 수장과 접경에서 수차례 비공식 실력 대결. 현재 무승부 상태
- 코요테 계열 수인 기마 부대와 완벽한 팀워크. 수인 특유의 감각+인간 에테르 운용 시너지
- 수장의 완충 외교를 지지. 어느 쪽 편도 안 드는 것이 가장 자유로운 방식이라는 독자 논리

## 5. 정령사 수장 (Isatai)

| 항목 | 내용 |
|------|------|
| **직위** | 코만치 연합 정령사 수장. 초원 정령 신앙 최고 권위자 |
| **에테르** | 정령사 중급 (2단계). 초원·바람·번개 정령 계약 |
| **성격** | 예언자적 기질. 정령의 목소리를 전달하는 자로 자임. 양 파벌 모두에게 중립적 영향력 |
| **현재 상황** | 초원 정령 이상 징후 감지. 남쪽(테노치)과 서쪽(나바호) 방향 에테르 흐름 변화 주시 |
| **핵심 목표** | 코만치 초원 정령 신앙 수호. 정령 이상 원인 규명 |
| **갈등 요소** | 양 파벌 모두 정령사 수장의 예언을 자기편 논리로 해석하려 함 |

### 세부 특성
- 번개 계열 대정령과 소계약 단계. 기마대 수장과 번개 정령 연계 전술 운용 가능
- 나바호 정령사 수장·이스칼드 분트 정령사 수장과 유사한 정령 이상 징후 감지. 연관성 주목
- 테노치 신관들의 의식이 초원 에테르 흐름에 영향 준다는 주장. 테노치 친화파 견제 논리로 활용됨
- 수장이 예언을 가장 신임하는 조언자. 정치적 중립 덕분에 양 파벌 모두 수장에게 영향력 행사 못함

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **수장 → 기마대 수장** | 절대 신임. 군사 기반 |
| **수장 → 정령사 수장** | 가장 신임하는 조언자 |
| **수장 → 나바호 친화파** | 균형 관리 대상 |
| **수장 → 테노치 친화파** | 균형 관리 대상 |
| **나바호 친화파 ↔ 테노치 친화파** | 의회 내 대립 |
| **기마대 수장 → 나바호 사막 전사 수장** | 비공식 경쟁. 무승부 |
| **정령사 수장 → 양 파벌** | 중립 유지. 양측 해석 경쟁 |
| **정령사 수장 → 나바호·이스칼드 정령사** | 이상 징후 유사 감지. 연관성 주목 |
