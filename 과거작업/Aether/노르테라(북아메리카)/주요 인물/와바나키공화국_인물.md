# 와바나키 공화국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 노르테라 최강 세력. 포르타 콘소르티움 접근 감시 중. 현재는 관찰·정보 수집 단계.

---

## 1. 대통령 (Sagamore)

| 항목 | 내용 |
|------|------|
| **직위** | 와바나키 공화국 대통령. 선출직. 임기제 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 탐지·분석 특화 |
| **성격** | 신중하고 관찰적. 판단 전 충분한 정보 수집 원칙. 행동보다 앞서 전체 그림 파악 |
| **현재 상황** | 포르타 콘소르티움 타이노 해연 접촉 정보 입수. 공식 대응 유보하며 정보 수집 강화 |
| **핵심 목표** | 노르테라 독립 유지. 베스테리아 세력 의도 완전 파악 후 대응 결정 |
| **갈등 요소** | 통합 추진파의 노르테라 전체 주도권 요구. 자율파의 와바나키 우월주의 반발 |

### 세부 특성
- 외교관 출신. 국내 정치보다 대외 정세 파악에 강점
- 포르타 탐험대의 노르테라 해안 접근을 독자 정보망으로 파악. 타이노에 비공식 경고 전달
- 노르테라 내 다른 세력과 연락망 구축 중. 하우데노·나바호·테노치와 비공식 채널 유지
- 통합 추진 의지 있으나 강제보다 자발적 연대 방식 선호

---

## 2. 통합 추진파 의원 (Delegate Unifier)

| 항목 | 내용 |
|------|------|
| **직위** | 공화국 의회 통합파 수장. 의회 내 최대 파벌 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열 |
| **성격** | 적극적이고 야심적. 베스테리아 위협에 맞서려면 노르테라 전체가 하나여야 한다는 신념 |
| **현재 상황** | 노르테라 연합 체제 구성 의회 청원 지속. 포르타 접근을 통합 명분으로 활용 시도 |
| **핵심 목표** | 와바나키 주도 노르테라 연합 체제 수립 |
| **갈등 요소** | 다른 세력들이 와바나키 주도권 경계. 자율파의 내부 반발 |

### 세부 특성
- 포르타 콘소르티움 위협을 가장 강하게 주장하는 인물
- 테노치 제국·하우데노와 비공식 연대 협상 시도 중
- 대통령의 관찰 우선 방침에 답답함. 더 빠른 대응 원함
- 타이노 해연이 포르타와 교역 시작했다는 정보에 강하게 반발

---

## 3. 자율파 의원 (Delegate Autonomist)

| 항목 | 내용 |
|------|------|
| **직위** | 공화국 의회 자율파 수장. 의회 내 2위 파벌 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 원칙주의. 각 세력 자율성이 노르테라 강점이라는 신념. 통합보다 협력 관계 선호 |
| **현재 상황** | 통합 추진파 의원 견제. 대통령 관찰 방침 지지 |
| **핵심 목표** | 와바나키 공화국 체제 순수성 유지. 타 세력 자율성 존중 |
| **갈등 요소** | 포르타 위협이 현실화될수록 통합파 주장이 설득력 얻음. 반론 근거 약화 중 |

### 세부 특성
- 크리 부족연·코만치 연합과 우호 관계. 자율 원칙 공유
- 와바나키 내부 정치 안정 우선. 외부 확장에 소극적
- 포르타 위협보다 테노치 제국 팽창 성향을 더 경계

---

## 4. 방위군 총사령관 (War Chief)

| 항목 | 내용 |
|------|------|
| **직위** | 와바나키 공화국 방위군 총사령관 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 삼림·평원 지형 전투 특화 |
| **성격** | 냉정한 현실주의 군인. 정치 논쟁 무관심. 방어 준비만 철저히 |
| **현재 상황** | 동부 해안 방어선 강화. 포르타 상륙 대비 전술 수립 중 |
| **핵심 목표** | 노르테라 동부 완전 방어. 외부 세력 상륙 저지 |
| **갈등 요소** | 통합파·자율파 정치 논쟁이 방어 예산 결정 지연. 현장 준비 차질 |

### 세부 특성
- 에테르 기반 삼림 전투 전술 독자 발전. 베스테리아 전술과 다른 노르테라 고유 방식
- 하우데노 연합 전사들과 합동 훈련 경험. 연대 전술 보유
- 포르타 탐험대 규모·장비 수준 파악 완료. 현재 소규모지만 후속 대규모 진입 대비 중
- 대통령의 관찰 방침 지지. 정보 없는 선제 행동 반대

---

## 5. 해안 경비대장 (Coastal Warden)

| 항목 | 내용 |
|------|------|
| **직위** | 와바나키 동부 해안 경비대 총사령관 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 해안·수로 전투 특화 |
| **성격** | 경계심 강함. 해안 접근 모든 선박 철저 감시. 직관적 판단력 |
| **현재 상황** | 포르타 탐험대 선박 간접 관찰 중. 타이노 해연과 접촉한 선박 추적 기록 보유 |
| **핵심 목표** | 동부 해안 완전 통제. 포르타 침투 조기 탐지 |
| **갈등 요소** | 포르타 선박이 직접 와바나키 영역 접근 않아 선제 대응 명분 없음 |

### 세부 특성
- 포르타 탐험대 선박 2척 항로·속도·장비 수준 비밀 기록 보유
- 타이노 해연 지도자에게 포르타 위험성 직접 경고 전달 시도. 효과 미지수
- 누산타라 동맹 교역 함대 제독과 포르타 해군 관련 정보 간접 교환
- 방위군 총사령관과 긴밀 협력. 해상·육상 방어 연계 체계 구축

---

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대통령 → 방위군 총사령관** | 신임. 방어 준비 위임 |
| **대통령 → 해안 경비대장** | 정보 수집 핵심 |
| **대통령 → 통합파 의원** | 방향 공감. 속도 조절 |
| **대통령 → 자율파 의원** | 내부 균형추로 활용 |
| **통합파 의원 ↔ 자율파 의원** | 의회 내 주도권 경쟁 |
| **방위군 총사령관 → 통합파 의원** | 정치 무관심. 예산 지연에만 불만 |
| **해안 경비대장 → 포르타 탐험대** | 감시·추적 중 |
| **해안 경비대장 → 타이노 해연** | 경고 전달 시도 |
