# 틀링깃 동맹 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 틀링깃 동맹은 다크 엘프 주도. 단절 당시 고립·이주로 형성된 독자 문화.
> [E] 마물 급증으로 내부 전력 소모 심화. 고립 유지 불가 판단으로 외부 연대 모색 중.

---

## 1. 수장 (Aan Koowú)

| 항목 | 내용 |
|------|------|
| **직위** | 틀링깃 동맹 최고 수장. 씨족 대표 회의 선출 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 어둠·환영 에테르 특화 |
| **성격** | 현실적이고 자존심 강함. 고립 포기가 패배가 아닌 생존 전략임을 내부 설득 중 |
| **현재 상황** | [E] 마물 소탕 전력 손실 누적. 와바나키 공화국에 비공식 연락 시도 중 |
| **핵심 목표** | [E] 마물 위협 극복. 틀링깃 동맹 존속. 외부 연대로 전력 보충 |
| **갈등 요소** | 전통 수호파의 고립 유지 주장. 외부 연대가 다크 엘프 문화 오염으로 이어질 것이라는 내부 반발 |

### 세부 특성
- [E] 마물이 기존 마물과 다른 에테르 패턴 보유한다는 것 직접 확인. 인위적 개입 의심
- 와바나키 대통령에게 비공식 서신 발송. 내용: [E] 마물 정보 공유 조건으로 군사 협력 제안
- 에이렌발트 다크 엘프 추방자들과 달리 자발적 이주로 형성된 공동체라는 자부심. 외부 도움 요청이 자존심 상처
- 기술 발전파를 내심 지지. 전통 수호파 반발 관리를 위해 공식 중립 유지

## 2. 전통 수호파 씨족장 (Haa Shagóon)

| 항목 | 내용 |
|------|------|
| **직위** | 전통 수호파 씨족 연합 대표. 동맹 내 최대 씨족 수장 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 다크 엘프 전통 술식 특화 |
| **성격** | 완고하고 자부심 강함. 단절 이후 수백 년 독자 생존한 역사를 근거로 외부 불필요 주장 |
| **현재 상황** | 외부 연대 반대. 대신 [E] 마물 대응 전통 술식 강화 주장 |
| **핵심 목표** | 틀링깃 다크 엘프 고유 문화·술식 체계 순수 보전 |
| **갈등 요소** | [E] 마물이 기존 방식으로 대응 안 된다는 현실. 주장 근거 점점 약해지는 중 |

### 세부 특성
- 단절 이전 판게아 시절 기록 일부 보유. 고대 다크 엘프 술식 복원 연구 중
- 베스테리아 다크 엘프(마레 콘소르티움·실바 아르카나)와 다른 독자 계통 자부심
- [E] 마물 첫 출현 시 기존 술식으로 대응 시도. 효과 미미함을 직접 경험했으나 인정 안 함
- 기술 발전파 씨족장과 오랜 대립. 개인적 감정도 섞여있음

## 3. 기술 발전파 씨족장 (Wooch.een)

| 항목 | 내용 |
|------|------|
| **직위** | 기술 발전파 씨족 연합 대표. 동맹 내 2위 씨족 수장 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 에테르 분석·응용 특화 |
| **성격** | 탐구적이고 개방적. 다크 엘프 고유 에테르를 외부 기술과 결합해 더 강하게 만들 수 있다는 신념 |
| **현재 상황** | [E] 마물 에테르 패턴 분석 연구 중. 수장의 외부 연대 방침 지지 |
| **핵심 목표** | 틀링깃 에테르 기술 고도화. [E] 마물 대응 신술식 개발 |
| **갈등 요소** | 전통 수호파의 연구 방해. 외부 기술 도입 시 어디까지 허용할지 범위 문제 |

### 세부 특성
- [E] 마물 에테르 패턴이 마기스테리움 수석 마법사 교수 연구와 연관 가능성 추정. 접촉 방법 모색
- 다크 엘프 어둠·환영 에테르와 외부 에테르 체계 융합 실험 중. 일부 성과 있음
- 와바나키 연락에 가장 적극적으로 지지. 기술 교류 포함 요구
- 삼림 거미왕 마물 소재를 에테르 술식 재료로 활용하는 독자 연구 진행 중

## 4. 삼림 전사 수장 (Naakw)

| 항목 | 내용 |
|------|------|
| **직위** | 틀링깃 동맹 최강 전투 직군. 동맹 방위 총괄 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 다크 엘프 어둠·환영 에테르 전투 융합 |
| **성격** | 냉혹하고 효율적. 전통이든 기술이든 [E] 마물을 죽이는 데 효과적이면 그만이라는 실용 전투관 |
| **현재 상황** | [E] 마물 소탕 최전선 지휘. 전력 손실 가장 직접적으로 체감 |
| **핵심 목표** | [E] 마물 완전 소탕. 동맹 방어선 유지 |
| **갈등 요소** | 전통 수호파가 기존 방식 고집하는 사이 병력 계속 소모. 내부 논쟁이 전투 효율 저해 |

### 세부 특성
- [E] 마물이 어둠 에테르를 무효화하는 속성 보유 확인. 다크 엘프 고유 에테르에 특화된 대응이라는 의심
- 기술 발전파 씨족장과 협력. [E] 마물 소재·에테르 패턴 데이터 제공
- 수장의 외부 연대 방침 강력 지지. 정치 논리보다 전투 현실 때문
- 와바나키 방위군 총사령관과 실력 비교 대상으로 거론됨. 직접 대면 없음

## 5. 정령사 수장 (Kaa Yahaayí)

| 항목 | 내용 |
|------|------|
| **직위** | 틀링깃 동맹 정령사 최고 권위자. 삼림 정령 계약 |
| **에테르** | 정령사 상급 (3단계). 삼림·어둠·안개 정령 다수 계약. 다크 엘프 특유의 어둠 속성 정령 친화 |
| **성격** | 신중하고 관찰적. 정령의 목소리에 귀 기울임. 내부 파벌 논쟁보다 [E] 마물 원인 규명에 집중 |
| **현재 상황** | [E] 마물이 삼림 정령들을 기피·약화시키는 현상 포착. 원인 집중 분석 중 |
| **핵심 목표** | [E] 마물과 정령 약화의 연관성 규명. 삼림 정령 신앙 보전 |
| **갈등 요소** | 정령 약화로 방어 결계 효율 저하. 수장의 외부 연대 방침 지지하나 정령 신앙 오염 우려 |

### 세부 특성
- [E] 마물이 정령 에테르를 흡수·역이용하는 메커니즘 발견. 세계 최초 관찰 사례 가능성
- 이스칼드 분트·아이누 정령사 수장과 유사 현상 비교 필요성 인식. 접촉 방법 모색
- 어둠 속성 정령이 [E] 마물에 특히 약하다는 것 확인. 다크 엘프 대상 표적 가능성 보고
- 기술 발전파 씨족장의 [E] 마물 에테르 분석과 정령 약화 현상이 같은 원인일 수 있다는 가설 공유

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **수장 → 삼림 전사 수장** | 신임. [E] 마물 대응 최전선 |
| **수장 → 정령사 수장** | 신뢰. [E] 마물 원인 규명 기대 |
| **수장 → 기술 발전파 씨족장** | 내심 지지. 공식 중립 |
| **수장 → 전통 수호파 씨족장** | 관리. 반발 억제 필요 |
| **전통 수호파 ↔ 기술 발전파** | 장기 대립. 개인 감정도 포함 |
| **삼림 전사 수장 → 기술 발전파** | 협력. [E] 마물 데이터 공유 |
| **삼림 전사 수장 → 전통 수호파** | 불만. 논쟁이 전투 효율 저해 |
| **정령사 수장 → 기술 발전파** | 가설 공유. 공동 연구 가능성 |
| **정령사 수장 → 이스칼드·아이누 정령사** | 유사 현상. 접촉 모색 |
| **수장 → 와바나키 대통령** | 비공식 연락 개시 |
