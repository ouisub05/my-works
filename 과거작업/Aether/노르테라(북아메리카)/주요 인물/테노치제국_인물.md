# 테노치 제국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 테노치 제국은 신정 제국. 팽창 정복 추진 중. 고대 유물 탐사 병행.
> 전사 귀족 파벌은 고대 유물의 전투 활용 가치 없다고 판단. 순수 연구 지지.

---

## 1. 황제 (Huey Tlatoani)

| 항목 | 내용 |
|------|------|
| **직위** | 테노치 제국 황제. 우이칠로포치틀리 신의 지상 대리인 |
| **에테르** | 엘리트 상 (6단계). 성기사 계열. 전쟁신 신성력 운용 |
| **성격** | 강렬하고 야망적. 신의 뜻이 곧 정복이라는 확신. 고대 유물은 신성한 보물로 인식하나 전투 도구 아님 |
| **현재 상황** | 코만치 연합 남부 압박 강화. 고대 유적 탐사 병행. 포르타 타이노 접촉 소문 인지 |
| **핵심 목표** | 노르테라 중부·남부 복속. 태양신 제국 영역 확장 |
| **갈등 요소** | 신관 회의의 의식 우선 요구. 전사 귀족 팽창 속도 조율. 포르타 북상 시 대응 방침 미정 |

### 세부 특성
- 전쟁신 의식 집전으로 전사들의 전투력 신성력으로 강화. 대규모 전투 전 의식 필수
- 고대 유적 탐사는 신의 뜻 확인 목적. 연구 결과에 따라 팽창 방향 결정
- 코만치 연합을 첫 복속 대상으로 설정. 이후 북방 진출 계획
- 칠람 동맹과 고대 유물 관련 비공식 정보 교환 가능성 탐색 중

## 2. 대신관 (Cihuacoatl)

| 항목 | 내용 |
|------|------|
| **직위** | 테노치 제국 대신관. 신관 회의 수장. 황제 다음 실권자 |
| **에테르** | 엘리트 중 (5단계). 성기사 계열. 의식 에테르 증폭·신성력 치유 특화 |
| **성격** | 위엄 있고 냉철함. 전쟁보다 의식이 신을 기쁘게 한다는 신념. 팽창은 의식 준비 후에 |
| **현재 상황** | 팽창 속도 조절 황제에게 건의 중. 고대 유적 의식적 의미 분석 주도 |
| **핵심 목표** | 신관 회의 권위 유지. 의식 없는 전쟁 방지 |
| **갈등 요소** | 황제의 즉각 팽창 성향. 전사 귀족들의 의식 경시 |

### 세부 특성
- 고대 유적에서 발견된 에테르 패턴이 현재 신성력과 다른 원천이라는 연구 결과 보유. 극비 유지
- 칠람 동맹 대신관과 신앙 계통 비교 연구 비공식 채널
- 유물 연구자를 지지. 유물의 신성한 의미 해석을 신관 회의 권한으로 주장

## 3. 전사 귀족 수장 (Tlacaelel)

| 항목 | 내용 |
|------|------|
| **직위** | 전사 귀족 연합 수장. 테노치 군사 파벌 대표 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 집단 전투 지휘 특화 |
| **성격** | 호전적이고 직선적. 고대 유물을 전투에 못 쓰면 가치 없다는 실용론. 즉각 팽창 주도 |
| **현재 상황** | 코만치 방면 원정 준비 총괄. 황제 팽창 방침 적극 지지 |
| **핵심 목표** | 테노치 군사 영역 확장. 전사 귀족 권한 강화 |
| **갈등 요소** | 신관 회의의 의식 우선 요구. 유물 연구에 자원 낭비한다는 인식 |

### 세부 특성
- 고대 유물이 전투에 직접 활용 불가능하다는 입장 확고. 유물 연구 예산 삭감 주장
- 코만치 기마대 수장(엑스퍼트 하)을 가장 위험한 상대로 평가. 대응 전술 연구 중
- 근위대장을 경쟁자로 인식. 황제 신임을 두고 암묵적 경쟁

## 4. 황제 근위대장 (Cuauhtemoc)

| 항목 | 내용 |
|------|------|
| **직위** | 황제 직속 근위대 총수. 테노치 최강 전투 직군 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 전쟁신 신성력+무인 에테르 융합 특화 |
| **성격** | 황제에 절대 충성. 전투에서 신의 힘이 함께한다는 확신. 냉혹하고 결단력 강함 |
| **현재 상황** | 황제 호위 및 근위대 훈련 총괄. 코만치 원정 선봉 역할 내정 |
| **핵심 목표** | 황제 보호. 테노치 전투력 상징으로서 위상 유지 |
| **갈등 요소** | 전사 귀족 수장과 황제 신임 경쟁. 의식 전투 방식이 실전에서 효율적인지 내심 고민 |

### 세부 특성
- 전쟁신 신성력+무인 에테르 융합. 상투스임페리움 성검단장과 유사한 희귀 계열
- 코만치 기마대 수장과의 전투를 앞두고 기마 전투 대응 전술 집중 연구 중
- 유물 연구자에게 호기심 있음. 고대 유물이 전투에 쓸모없다는 전사 귀족 견해와 달리 가능성 탐색
- 나바호 사막 전사 수장과 실력 비교 대상으로 거론됨. 직접 대면 없음

## 5. 유물 연구자 (Tlamatini)

| 항목 | 내용 |
|------|------|
| **직위** | 테노치 제국 고대 유적·유물 연구 총책임자. 황제 직속 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 고대 에테르 패턴 분석 특화 |
| **성격** | 탐구적이고 신중. 유물을 전투 도구가 아닌 고대 문명의 열쇠로 봄. 결론 없이 공개 않는 원칙 |
| **현재 상황** | 고대 유적 에테르 패턴 분석 중. 케찰코아틀 신화와 에테르 구조 연관성 연구 |
| **핵심 목표** | 고대 유물의 본질 규명. 에테르 기술 복원 |
| **갈등 요소** | 전사 귀족의 연구 무용론·예산 삭감 압박. 연구 결과 공개 시기 황제와 이견 |

### 세부 특성
- 고대 유적 에테르 패턴이 현재 에테르 체계와 근본적으로 다르다는 것 확인. 전투 투입 불가 이유
- 칠람 동맹 이참나 대신관의 고대 문자 해독 연구와 연관 가능성 감지. 접촉 시도 중
- 고대 통신 구슬과 유사한 유물 테노치 유적에서 발견. 수신 신호 분석 중. 강티세 동맹 수신과 같은 원천일 가능성
- 대신관과 협력. 유물의 신성 의미와 에테르 분석 상호 보완 연구

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **황제 → 근위대장** | 절대 신임. 군사 기반 |
| **황제 → 유물 연구자** | 신성한 임무 부여. 연구 결과 기대 |
| **황제 → 대신관** | 의식 권위 의존. 속도 갈등 |
| **황제 → 전사 귀족 수장** | 팽창 방침 공유. 신임 경쟁 관리 |
| **대신관 ↔ 전사 귀족 수장** | 의식 vs 전투 대립 |
| **전사 귀족 수장 ↔ 근위대장** | 황제 신임 암묵적 경쟁 |
| **유물 연구자 ↔ 전사 귀족 수장** | 연구 무용론 vs 본질 규명 |
| **유물 연구자 → 대신관** | 협력. 상호 보완 연구 |
| **유물 연구자 → 칠람 동맹** | 접촉 시도. 고대 문자 해독 연관 |
| **유물 연구자 → 고대 통신 구슬** | 수신 신호 분석 중. 강티세와 같은 원천 가능성 |
