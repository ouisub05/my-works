# 나바호 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 나바호 왕국은 사막 지형 특화. 독자 자원 개발 우선. 마정석 매장 가능성 내부 조사 중.

---

## 1. 왕 (Naat'aanii)

| 항목 | 내용 |
|------|------|
| **직위** | 나바호 왕국 국왕 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 사막 환경 에테르 강화 특화 |
| **성격** | 과묵하고 자존심 강함. 외부 의존을 굴욕으로 인식. 나바호만의 방식으로 해결 고집 |
| **현재 상황** | 사막 지하 마정석 매장 가능성 독자 조사 중. 외부 세력 정보 유출 철저 차단 |
| **핵심 목표** | 나바호 사막 자원 완전 독자 개발. 외부 의존 없는 자립 체계 구축 |
| **갈등 요소** | 기술 도입파 귀족들의 외부 협력 압박. 와바나키의 연대 요청 거부 시 고립 우려 |

### 세부 특성
- 사막 지하 에테르 흐름 직접 감지 능력 보유. 마정석 매장 위치 추정 가능
- 와바나키 대통령의 연대 요청 정중히 거절. 정보 공유 없이 독자 노선
- 코만치 연합과 완충 지대 유지 협약. 사막 접경 안정화
- 포르타 콘소르티움 존재 인지. 타이노 해연과 거리 있어 직접 위협 낮게 평가

## 2. 전통 수호파 귀족 수장 (Hashkééjí Naat'aanii)

| 항목 | 내용 |
|------|------|
| **직위** | 전통 수호파 귀족 연합 수장. 왕 지지 핵심 |
| **에테르** | 엘리트 하 (4단계). 정령사 계열. 사막 정령 계약 보유 |
| **성격** | 완고하고 보수적. 나바호 사막 문화가 외부 기술 없이도 충분하다는 신념 |
| **현재 상황** | 기술 도입파 억제. 전통 사막 전술·정령 신앙 수호 |
| **핵심 목표** | 나바호 전통 문화 순수 보전. 외부 에테르 기술 오염 방지 |
| **갈등 요소** | 마정석 개발 시 기술 도입 없이 가공 불가 현실. 논리적 반박 어려워지는 중 |

### 세부 특성
- 사막 정령과 계약. 사막 지형 정보 수집·전투 지원 능력 보유
- 코요테 계열 수인 부족과 전통 의식 공유. 연대 관계
- 마정석 발견 시 드워프 기술자 영입 반대 가장 강경하게 주장할 인물

## 3. 기술 도입파 귀족 수장 (Hózhóójí Naat'aanii)

| 항목 | 내용 |
|------|------|
| **직위** | 기술 도입파 귀족 연합 수장. 왕에 대한 표면 충성 유지 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 에테르 탐지·분석 특화 |
| **성격** | 실용주의. 전통 존중하나 현실적 필요 우선. 외부 기술을 도구로만 봄 |
| **현재 상황** | 와바나키·테노치 기술 정보 수집 중. 마정석 개발 시 협력 파트너 사전 검토 |
| **핵심 목표** | 나바호 기술력 향상. 마정석 개발 주도권 확보 |
| **갈등 요소** | 왕의 독자 개발 방침. 전통 수호파의 강경 반대 |

### 세부 특성
- 테노치 제국 고대 유물 연구 정보에 관심. 간접 접촉 시도 중
- 와바나키 기술 도입파 의원과 비공식 정보 교환
- 움코시 왕국 마정석 독자 개발 사례 파악. 나바호 적용 가능성 연구 중

## 4. 사막 전사 수장 (Naabaahii)

| 항목 | 내용 |
|------|------|
| **직위** | 나바호 왕국 최강 전투 직군. 왕 직속 사막 전사 부대 수장 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 사막 기동전·열기 에테르 특화 |
| **성격** | 사막처럼 냉혹하고 인내심 강함. 극한 환경 전투를 즐김. 왕에 절대 충성 |
| **현재 상황** | 사막 방어선 총괄. 코만치 연합 접경 순찰 겸임 |
| **핵심 목표** | 나바호 사막 영토 완전 방어. 외부 침입 원천 차단 |
| **갈등 요소** | 독자 개발 방침으로 외부 군사 협력 없음. 단독 방어 한계 인식 |

### 세부 특성
- 사막 열기 에테르 전투 방식 독자 개발. 모래폭풍·열파 전술 운용
- 코만치 연합 최강 전사와 수차례 교전 전례. 상호 실력 인정 후 현재 비공식 경쟁 관계
- 포르타 정보 접했으나 사막 내륙이라 직접 위협 낮게 평가. 해안 세력 위협엔 관심 없음
- 테노치 제국 전사들과 실력 비교 대상으로 거론됨. 직접 대면 없음

## 5. 정령사 수장 (Hataałii)

| 항목 | 내용 |
|------|------|
| **직위** | 나바호 왕국 정령 신앙 최고 권위자. 왕실 의식 총괄 |
| **에테르** | 정령사 중급 (2단계). 사막·모래·열기 정령 다수 계약 |
| **성격** | 신비롭고 철학적. 사막이 살아있는 존재라는 신념. 세속 권력에 초연 |
| **현재 상황** | 사막 정령 이상 징후 감지 중. 지하 에테르 흐름 변화 주시 |
| **핵심 목표** | 사막 정령 신앙 수호. 지하 에테르 변화 원인 규명 |
| **갈등 요소** | 마정석 개발 시 사막 지하 에테르 흐름 교란 우려. 개발 자체에 반대적 |

### 세부 특성
- 사막 지하 에테르 흐름 변화가 [E] 마물 급증과 연관 가능성 감지
- 코요테 계열 수인 샤먼들과 정령 정보 공유. 광역 정령 네트워크 보유
- 전통 수호파 귀족 수장과 신앙적 연대. 기술 도입 반대 논리 공유
- 왕에게 지하 에테르 변화 경고 전달. 왕이 마정석 매장 조사와 연관 가능성 주목

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 사막 전사 수장** | 절대 신뢰. 방어 총괄 위임 |
| **왕 → 전통 수호파 귀족** | 방향 일치. 핵심 지지 기반 |
| **왕 → 기술 도입파 귀족** | 경계. 필요 시 활용 가능 자산 |
| **왕 → 정령사 수장** | 정령 신앙 권위 존중. 지하 에테르 경고 주시 |
| **전통 수호파 ↔ 기술 도입파** | 대립. 마정석 개발 방향 핵심 갈등 |
| **전통 수호파 → 정령사 수장** | 신앙적 연대 |
| **사막 전사 수장 → 코만치 전사** | 비공식 경쟁 관계 |
| **정령사 수장 → [E] 마물** | 지하 에테르 변화로 연관 감지 중 |
