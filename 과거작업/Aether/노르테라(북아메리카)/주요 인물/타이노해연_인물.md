# 타이노 해연 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 타이노 해연은 포르타 콘소르티움 최초 접촉 세력. 수장은 교역 수용파. 노르테라 내 독특한 위치.

---

## 1. 수장 (Kasike)

| 항목 | 내용 |
|------|------|
| **직위** | 타이노 해연 최고 수장. 섬 연합 대표 |
| **에테르** | 엘리트 중 (5단계). 성기사 계열. 타이노 수호 신앙 기반 신성력 |
| **성격** | 호기심 많고 개방적. 베스테리아 기술·물자에 강한 흥미. 위험보다 기회에 집중하는 낙관론자 |
| **현재 상황** | 포르타 탐험대와 해안 교역 진행 중. 내륙 접근은 차단 유지. 와바나키 경고 인지했으나 교역 중단 거부 |
| **핵심 목표** | 포르타 교역으로 타이노 물자·기술 수준 향상. 카리브해 최강 섬 연합 도약 |
| **갈등 요소** | 교역 반대+연대 찬성파의 와바나키 경고 수용 압박. 포르타 의도에 대한 불확실성 |

### 세부 특성
- 포르타 탐험대장을 직접 만남. 탐험대장의 순수한 탐험 열정에 신뢰감 형성
- 와바나키 해안 경비대장 경고를 받았으나 "직접 위협이 없으면 교역 중단 이유 없다"는 입장
- 포르타에서 받은 물자 중 마정석 가공품에 특히 관심. 타이노 내 에테르 기술 발전 기회 인식
- 교역 조건: 해안 교역소 한정. 섬 내부 지도 비공개. 타이노 전사 수 미공개

## 2. 교역 찬성·연대 반대파 수장 (Guacanagari)

| 항목 | 내용 |
|------|------|
| **직위** | 교역 찬성·연대 반대파 수장. 가장 큰 섬 족장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 실리적이고 독립 지향. 포르타 교역은 기회. 와바나키 연대는 종속의 시작이라는 판단 |
| **현재 상황** | 포르타와 교역 확대 주도. 와바나키 연락 거부 |
| **핵심 목표** | 포르타 교역 독점 유지. 타이노 내 영향력 확대 |
| **갈등 요소** | 포르타 정보 수장의 요원이 교역소에 있다는 것 모름. 정보 유출 중 |

### 세부 특성
- 포르타 탐험대와 가장 먼저 접촉한 섬 족장. 교역 이익 선점
- 와바나키를 베스테리아만큼 경계. "외부 세력은 모두 잠재적 위협"이라는 원칙론
- 포르타가 타이노 내부 정보 수집 중이라는 것 전혀 인지 못함
- 교역 반대파가 와바나키 연대 주장하는 것을 타이노 독립성 포기로 규정. 강하게 반대

## 3. 교역 반대·연대 찬성파 수장 (Anacaona)

| 항목 | 내용 |
|------|------|
| **직위** | 교역 반대·연대 찬성파 수장. 중간 규모 섬 족장 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 탐지·분석 특화 |
| **성격** | 신중하고 장기적 시각. 포르타 교역의 단기 이익보다 장기 종속 위험 우선 인식 |
| **현재 상황** | 와바나키 경고 심각하게 수용. 포르타 교역 중단·노르테라 연대 주장 |
| **핵심 목표** | 포르타 침투 차단. 와바나키와 연대로 타이노 독립 보장 |
| **갈등 요소** | 수장과 찬성파의 교역 이익 논리에 반박 어려움. 포르타 의도 증거 부족 |

### 세부 특성
- 와바나키 해안 경비대장과 비공식 연락. 포르타 선박 정보 입수
- 포르타 탐험대가 타이노 지형·인구·자원 정보 수집한다는 의심. 증거 수집 중
- 교역소에서 포르타 요원으로 추정되는 인물 행동 패턴 관찰 중
- 수장이 탐험대장의 개인적 인상에 너무 의존한다는 우려

## 4. 해상 전사 수장 (Caonabo)

| 항목 | 내용 |
|------|------|
| **직위** | 타이노 해연 최강 전투 직군. 카리브해 해전 총수 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 해상 전투·열대 지형 특화 |
| **종족** | 상어 계열 수인. 카리브해 해상 전투에서 타의 추종 불허 |
| **성격** | 전투적이고 경계심 강함. 포르타 교역에 내심 불편. 전사 본능으로 위협 감지 |
| **현재 상황** | 교역소 주변 경계 강화. 포르타 선박 동향 비공식 감시 중 |
| **핵심 목표** | 타이노 해역 완전 방어. 외부 세력 무력 침투 원천 차단 |
| **갈등 요소** | 수장의 교역 수용 방침으로 포르타 선박 접근 허용. 경계 강화 한계 |

### 세부 특성
- 카리브 해양 망령 마물 소탕 다수 경험. 해양 마물 대응 전문
- 포르타 탐험대 선박 수·무장 수준 정밀 관찰 완료. 현재 소규모이나 후속 대규모 가능성 경고
- 교역 반대파 수장과 비공식 협력. 포르타 정보 수집 의심 공유
- 프레이 아르키펠 해적 소문 간접 접함. 포르타와 연관 여부 조사 중

## 5. 섬 방어 수장 (Hatuey)

| 항목 | 내용 |
|------|------|
| **직위** | 타이노 섬 지형 방어 총괄 수장 |
| **종족** | 수달 계열 수인. 수중·해안·밀림 전환 이동 능력 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 열대 밀림·해안 지형 방어 특화 |
| **성격** | 과묵하고 실용적. 교역 찬반 논쟁보다 방어 준비에 집중. 최악 상황 대비 |
| **현재 상황** | 포르타 상륙 대비 섬 내부 방어 거점 비밀 구축 중. 어느 파벌에도 공식 입장 없음 |
| **핵심 목표** | 포르타 무력 침공 시 섬 방어 완벽 준비. 어떤 결과가 나와도 타이노 생존 |
| **갈등 요소** | 방어 준비가 수장의 교역 수용 방침과 충돌. 비밀 유지 필요 |

### 세부 특성
- 수장 모르게 내부 방어 거점 구축. 교역이 실패할 경우 대비
- 교역 반대파 수장과 가장 유사한 인식. 공식 연대는 안 하나 정보 공유
- 열대 밀림 지형 함정 설치 전문. 포르타 상륙부대 상대 게릴라전 체계 구상
- 와바나키 경고를 가장 진지하게 받아들인 인물. 수장에게 직접 전달했으나 수용 안 됨

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **수장 → 교역 찬성·연대 반대파** | 핵심 지지 기반 |
| **수장 → 교역 반대·연대 찬성파** | 관리. 와바나키 채널 유지 활용 |
| **수장 → 해상 전사 수장** | 신임. 경계 강화 위임 |
| **수장 → 섬 방어 수장** | 방어 위임. 비밀 준비는 모름 |
| **교역 찬성파 ↔ 교역 반대파** | 노선 대립 |
| **교역 반대파 ↔ 해상 전사 수장** | 비공식 협력. 포르타 의심 공유 |
| **섬 방어 수장 → 교역 반대파** | 정보 공유. 공식 연대 없음 |
| **해상 전사 수장 → 포르타 탐험대** | 비공식 감시 중 |
| **교역 반대파 → 와바나키 해안 경비대장** | 비공식 연락 |
| **포르타 정보 수장 → 타이노 교역소** | 요원 침투 중. 타이노 인지 못함 |
