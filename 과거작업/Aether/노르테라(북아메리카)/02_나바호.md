# 나바호 왕국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 미국 서부 일대. 사막·협곡·태평양 해안 |
| **체제** | 왕정. 왕 + 부족장 회의 |
| **국교** | 없음. 정령 신앙. 사막·바람·대지 정령 숭배 |
| **주요 종족** | 인간 다수. 수인·하프 엘프 소수 거주 허용 |
| **군사력** | 중상위권. 사막 전투 특화 |
| **에테르 기술** | 중위권. 사막 환경 특화 에테르 기술 독자 발전 |

---

## 왕정 구조

| 항목 | 내용 |
|------|------|
| **왕** | 최고 권력. 군사·외교 주도 |
| **부족장 회의** | 각 지역 부족장 참여. 내정 자문 |
| **신관 계층** | 정령 신앙 의식 담당. 왕에게 자문 |
| **전사 귀족** | 사막 전투 실적으로 작위 취득 |

---

## 인간 주도 체계

| 항목 | 내용 |
|------|------|
| **인간 비율** | 전체 인구 70% 이상 |
| **타 종족 처우** | 거주 허용. 법적 권리 제한적 |
| **수인** | 교역·전투 보조 역할. 시민권 취득 어려움 |
| **하프 엘프** | 통역·외교 역할. 비교적 우대 |
| **배척 대상** | 다크 엘프. 거주 금지에 가까운 제한 |

---

## 사막 전투 특화

| 병종 | 특징 |
|------|------|
| **사막 기마대** | 에테르 강화 말. 사막 지형 고속 기동 |
| **협곡 매복대** | 협곡 지형 활용 매복·기습 특화 |
| **모래폭풍 술식대** | 에테르로 모래폭풍 조작. 시야 차단·혼란 유발 |
| **수인 정찰대** | 독수리·코요테 계열 수인. 사막 정찰 담당 |

## 사막 에테르 기술

| 기술 | 내용 |
|------|------|
| **열기 조절** | 극한 더위에서 신체 보호 술식 |
| **수맥 탐지** | 사막 지하 수원 에테르로 감지 |
| **모래 조작** | 모래·흙 에테르 조작. 방어·공격 겸용 |
| **협곡 각인** | 협곡 암벽에 에테르 술식 각인. 방어 거점화 |
