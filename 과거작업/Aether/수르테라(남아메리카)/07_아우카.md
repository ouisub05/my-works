# 아우카 부족연

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 파타고니아 남단 일대. 극한 환경 |
| **체제** | 부족 연합. 대족장 중심. 독립 시도 진행 중 |
| **국교** | 없음. 바람·빙하·바다 정령 신앙 |
| **주요 종족** | 인간 다수. 펭귄·바다사자 계열 수인 소수 |
| **군사력** | 하위권. 극한 환경 생존 전투 특화 |
| **에테르 기술** | 낮음. 생존 특화 에테르 기술 |

## 속국에서 독립 시도로

### 독립 시도 배경

| 원인 | 내용 |
|------|------|
| **마정석 발견** | 자체 경제 기반 가능성 생김. 마푸 의존 탈피 희망 |
| **마푸 약화** | 마푸가 타완틴 저항에 집중. 아우카 통제 여력 감소 |
| **대족장 교체** | 최근 독립 의지 강한 새 대족장 선출 |

> **"마정석이 있다면 우리도 혼자 설 수 있다"** 는 인식 확산
> 단 마정석 규모가 확인되지 않아 독립 선언까지는 신중한 상태

---

## 마정석 — 미확인·중간 규모 예상

| 항목 | 내용 |
|------|------|
| **발견 경위** | 파타고니아 남부 산악 지대에서 에테르 반응 감지 |
| **현재 단계** | 소규모 탐사 중. 전체 규모 파악 안 됨 |
| **예상 규모** | 중간 규모. 하급 다수·중급 일부 가능성 |
| **확인 난항** | 극한 환경·마물 출몰로 탐사 어려움 |
| **마푸 차단** | 마푸가 정보 외부 유출 차단 시도. 아우카 영역 감시 강화 |

> 마정석 규모가 예상대로라면 아우카 독립의 경제적 기반 가능
> 예상보다 작다면 독립 시도는 마푸에 의해 쉽게 진압될 가능성

## 마푸와의 갈등

| 항목 | 내용 |
|------|------|
| **마푸 반응** | 아우카 독립 기미 감지. 통제 강화 시도 |
| **아우카 저항** | 조공 지연·감소. 마푸 감시단 비협조 |
| **현재 상태** | 공개 충돌 없음. 물밑 긴장 고조 |
| **딜레마** | 마푸는 타완틴 저항에 집중 중. 아우카에 본격 대응 여력 부족 |
