# 타완틴 제국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 안데스 산맥 일대. 페루·볼리비아 고산 지대 |
| **체제** | 황제(사파 잉카) 중심 신정 제국 |
| **국교** | 태양신(인티) 숭배. 고산 자연신 병존 |
| **주요 종족** | 인간 다수. 라마·독수리 계열 수인 소수 |
| **군사력** | 중상위권. 전성기 대비 쇠퇴 중 |
| **에테르 기술** | 중위권. 고산 에테르 흐름 활용. 고대 유물 선택적 활용 |

## 황제 체제

| 항목 | 내용 |
|------|------|
| **사파 잉카** | 황제. 태양신 인티의 아들. 종교·세속 권력 일체화 |
| **아우키** | 황족. 황제 보좌·지방 총독 역임 |
| **신관 집단** | 태양신 신전 운영. 고대 유물 관리 담당 |
| **아마우타** | 학자·관료 계층. 행정·기록·에테르 기술 담당 |

## 군사력 쇠퇴

| 원인 | 내용 |
|------|------|
| **내부 계승 분쟁** | 과거 황위 계승 전쟁으로 귀족·군사 세력 약화 |
| **과도한 팽창 후유증** | 전성기 급격한 영토 확장. 광역 통치 비용 증가 |
| **마푸 저항** | 남부 마푸 연합의 지속적 저항. 군사력 소모 |
| **국경 대치 부담** | 복수의 강대국과 동시 국경 대치. 전선 분산 |

> **"타완틴은 크지만 더 이상 강하지 않다"** 는 인식이 주변 세력에 퍼지는 중

|------|------|------|

| **남부** | 마푸 연합 | 조공 반발. 산발적 충돌 |
| **북서부** | 칠람 동맹 | 비교적 우호 |

## 고대 유물 — 선택적 활용

| 항목 | 내용 |
|------|------|
| **공식 입장** | 고대 유물은 태양신의 유산. 연구·분해 금지 |
| **실제 운용** | 군사 목적·의식 강화 목적으로만 선택적 활용 |
| **역설** | 유물 활용하면서 원리는 모름. 에테르 기술 발전 제한 요인 |

---

## 에테르 기술

| 기술 | 내용 |
|------|------|
| **고산 에테르 흐름** | 안데스 산맥 특유의 에테르 흐름 활용 |
| **태양 에테르** | 고산 태양광 에테르 변환 |
| **석조 각인** | 거대 석조 건축물에 에테르 술식 각인. 도시 방어 시스템 |
| **고지 강화** | 고산 환경에서 신체 능력 강화 술식 |
