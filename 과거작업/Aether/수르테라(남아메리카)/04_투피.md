# 투피 제국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 브라질 밀림 일대. 아마존 유역 중심 |
| **체제** | 황제 중심 제국. 부족장 연합 기반 |
| **국교** | 없음. 밀림 정령 신앙. 동물·식물·강 정령 숭배 |
| **주요 종족** | 인간 다수. 재규어·아나콘다·앵무새 계열 수인 다수 |
| **군사력** | 중상위권. 밀림 전투 최강 |
| **에테르 기술** | 중위권. 밀림 환경 특화 독자 발전 |

---

## 제국 구조

| 항목 | 내용 |
|------|------|
| **황제** | 최고 권력. 밀림 정령 신앙 최고 사제 겸임 |
| **부족장** | 각 지역 밀림 부족 수장. 황제 아래 자치 |
| **전사 계층** | 재규어 계열 수인 중심. 밀림 전투 정예 |
| **정령사 집단** | 밀림 정령과 교감. 에테르 기술·의식 담당 |

---

## 영토 현황

| 구역 | 내용 |
|------|------|
| **직할 지배** | 아마존 강 유역 주요 거점 |
| **부족 자치** | 밀림 내부 부족 영역. 황제 권위 인정하나 자치 |
| **미개척 야생** | 밀림 오지. 마물 다발 지대 |
| **무이스카에 잠식된 지역** | 북서부 일부. 무이스카 팽창으로 영토 손실 |

> 투피는 북서부 영토 잠식을 굴욕으로 인식. 수복 의지 강함

---

## 밀림 특화 에테르 기술

| 기술 | 내용 |
|------|------|
| **독소 술식** | 밀림 식물·동물 독소와 에테르 결합 |
| **밀림 감응** | 밀림 전체를 감각망으로 활용. 침입자 즉시 감지 |
| **식물 조작** | 에테르로 밀림 식물 성장·이동 조작. 통로 차단·함정 |
| **마물 연계** | 밀림 마물과 비공식 공존. 침입자에게 마물 유도 |

> 투피 제국 밀림은 **"들어가면 나오지 못한다"** 는 공포의 대상
