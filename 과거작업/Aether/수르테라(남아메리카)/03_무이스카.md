# 무이스카 왕국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 콜롬비아~수리남 일대. 해안·내륙 고원 |
| **체제** | 왕정. 군사력 강화로 제국화 준비 중 |
| **국교** | 없음. 황금·태양 신앙. 자연신 숭배 |
| **주요 종족** | 인간 다수. 재규어·앵무새 계열 수인 소수 |
| **군사력** | 중위권. 빠르게 성장 중 |
| **에테르 기술** | 중위권. 교역 수익으로 외부 기술 도입 중 |

## 왕정 + 군사 강화

| 항목 | 내용 |
|------|------|
| **왕** | 군사·외교 주도. 제국화 의지 강함 |
| **상인 귀족** | 교역 수익으로 왕국 경제 지탱 |
| **신설 군사 귀족** | 전공으로 작위 취득. 상인 귀족과 권력 균형 변화 중 |
| **갈등 요소** | 상인 귀족은 안정·교역 선호. 군사 귀족은 팽창·정복 선호 |

## 노르테라 교역 — 타이노 해연 경유

| 항목 | 내용 |
|------|------|
| **교역 경로** | 무이스카 해안 → 카리브해 → 타이노 해연 거점 → 노르테라 세력 |
| **교역 품목** | 무이스카 → 황금·에메랄드·향신료 수출. 노르테라 → 목재·모피·마물 소재 수입 |
| **관계 성격** | 비정기 교역. 타이노 중개 수수료 발생 |

## 베스테리아 인지 — 타이노 경유 정보

| 항목 | 내용 |
|------|------|
| **인지 경위** | 타이노 해연이 포르타 콘소르티움과 접촉한 사실 파악 |
| **파악 내용** | 동쪽 대양 너머 거대 문명권 존재. 에테르 기술 고도로 발달 |
| **내부 반응 — 위협파** | 외부 문명이 진출하면 수르테라·노르테라 전체 위협 |
| **내부 반응 — 기회파** | 교역 상대 확대. 에테르 기술 수입 기회 |
| **현재 대응** | 타이노를 통해 추가 정보 수집 중. 공식 대응 미결 |

> 무이스카는 베스테리아의 존재를 알지만 베스테리아는 무이스카를 모름

## 타완틴과의 관계 — 견제

| 항목 | 내용 |
|------|------|
| **공식 관계** | 표면상 우호. 직접 충돌 없음 |
| **실제 관계** | 타완틴 쇠퇴 주시. 영향권 잠식 준비 |
| **전략** | 타완틴 영향권 내 소세력과 비밀 접촉. 이탈 유도 |
