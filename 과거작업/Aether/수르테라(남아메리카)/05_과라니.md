# 과라니 공동체

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 파라과이 일대. 강변·초원 지대 |
| **체제** | 부족 공동체 연합. 장로 합의제 |
| **국교** | 없음. 강·대지 정령 신앙 |
| **주요 종족** | 인간 다수. 수달·카피바라 계열 수인 소수 |
| **군사력** | 하위권. 자체 전투력 약함 |
| **에테르 기술** | 낮음. 교역 중개로 외부 기술 일부 접촉 |

---

## 지정학적 위치 — 세 강대국에 둘러싸임

| 방향 | 접경 세력 | 관계 |
|------|----------|------|
| **북부** | 투피 제국 | 역사적 원한. 적대적 경계 |
| **서부** | 타완틴 제국 | 간접 압박. 조공 요구 간헐적 |
| **남부** | 마푸 연합 | 접경. 비교적 중립적 |

---

## 기회주의 생존 전략

| 전략 | 내용 |
|------|------|
| **다자 교역** | 세 강대국 모두와 교역. 어느 쪽도 독점 허용 안 함 |
| **동맹 거부** | 공식 동맹 요청 모두 거절 |
| **정보 장사** | 세 강대국 사이를 오가며 수집한 정보 판매 |
| **생존 우선** | 명분보다 실리. 강한 쪽에 일시적으로 기우는 것도 불사 |

---

## 투피와의 역사적 원한

| 항목 | 내용 |
|------|------|
| **과거** | 과거 투피 제국에 완전 복속. 착취·강제 노역 경험 |
| **독립 경위** | 타완틴 팽창기 투피 힘 분산 틈타 독립 쟁취 |
| **현재 감정** | 독립했으나 투피 압박 지속. 적대감 뿌리 깊음 |
| **투피 인식** | 과라니를 도망친 속국으로 인식. 재복속 기회 엿봄 |

> 과라니는 투피를 **"언제든 다시 삼키려는 존재"** 로 인식

---

## 교역 중개 — 생존 기반

| 항목 | 내용 |
|------|------|
| **중개 품목** | 투피 밀림 특산물 ↔ 타완틴 고산 자원 ↔ 마푸 초원 자원 교환 중개 |
| **수수료** | 중개 수수료로 국가 수입 유지 |
| **강변 교역로** | 파라과이 강·파라나 강 수로를 교역로로 활용 |

> **"과라니를 건드리면 교역이 끊긴다"** 는 인식이 생존 보호막

---

## 대외 관계

| 대상 | 관계 |
|------|------|
| **투피 제국** | 역사적 원한. 적대적 경계 |
| **타완틴 제국** | 간헐적 조공 압박. 기회주의적 순응 |
| **마푸 연합** | 비교적 중립. 공통 이해 존재 |
| **무이스카 왕국** | 간접 교역. 북쪽 강대국으로 인식 |
