# 수르테라 조연 인물

> 성별·이름 미정. 추후 작성.
> 세력 소속 12인 + 독립 인물 3인 = 총 15인.
> 갈등 중심 세력(타완틴·투피·무이스카) 2인씩. 나머지 세력 1인씩. 독립 3인.
> 스토리 연결 포인트: 타완틴-투피 전쟁.

## 수르테라 조연 관계망

| 연결 | 내용 |
|------|------|
| **1번 타완틴 전사 ↔ 3번 투피 척후병** | 전선에서 간접 인지. 직접 대면 가능성 |
| **2번 신관 견습 → 타완틴 대신관** | 신탁 조작 목격. 폭로 갈등 |
| **4번 정령사 견습 → 세계 [E] 마물 현상** | 인간 최초로 전체 연결 고리 인지 |
| **6번 무이스카 정보 요원 ↔ 9번 과라니 조수** | 정보 교차. 적대·동료 불분명 |
| **8번 마푸 정찰병 ↔ 10번 아우카 탐사원** | 마정석 방어 협약 실무 접점 |
| **7번 칠람 제자 ↔ 14번 베스테리아 탐사자** | 삼각 학술 연결 시도 |
| **13번 고산 길잡이** | 타완틴-투피 전쟁 최전선 객관적 증인 |
| **15번 음유시인** | 수르테라 전역 정세 가장 폭넓게 아는 민간 정보원 |
