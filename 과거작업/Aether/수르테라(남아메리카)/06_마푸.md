# 마푸 연합

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 아르헨티나·칠레 남부 초원·산악 일대 |
| **체제** | 부족 연합. 전쟁 족장(토키) 중심 |
| **국교** | 없음. 대지·바람·말 정령 신앙 |
| **주요 종족** | 인간 다수. 말·독수리 계열 수인 소수 |
| **군사력** | 중위권. 기마 전투 특화. 타완틴 상대로 우세 |
| **에테르 기술** | 중하위권. 기마·초원 생존 특화 |

---

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| **토키(전쟁 족장)** | 전시 지휘 전담. 전투 실력으로 선출 |
| **롱코(평화 족장)** | 평시 내정·외교. 지혜·중재 능력으로 선출 |
| **부족장 회의** | 각 부족 수장 참여. 전쟁·평화 전환 결정 |
| **인간·수인 공존** | 혼합 문화 형성 |

---

## 타완틴 조공 반발 — 저항 진행 중

| 단계 | 내용 |
|------|------|
| **과거** | 타완틴 전성기에 무력 복속. 조공 강요 수용 |
| **타완틴 쇠퇴 인지** | 조공 요구는 그대로인데 타완틴 보호 능력 감소 인식 |
| **현재** | 조공 일부 거부. 산발적 충돌 발생. 독립 의지 공개화 |

> **"왜 약해진 자에게 바쳐야 하는가"** 는 마푸 내부 공통 인식
> 현재 토키가 반타완틴 강경파. 롱코는 신중론 주장

---

## 기마 전투 — 타완틴 상대 우세

| 항목 | 내용 |
|------|------|
| **초원 기동력** | 팜파스 평원에서 타완틴 보병 압도 |
| **고산 한계** | 안데스 산맥 고지대에서는 타완틴이 지형·에테르 우위 |
| **전술** | 평원으로 타완틴 유인 후 기마 돌격. 고산 접근 회피 |

| 종류 | 역할 |
|------|------|
| **말 계열** | 기마 돌격·기동 전투 |
| **독수리 계열** | 전장 상황 파악·기습 |

## 아우카 부족연 관계

- 아우카는 마푸의 속국
- 마정석 발견 소문으로 마푸의 아우카 통제 강화 시도
- 아우카 독립 움직임 경계 중
