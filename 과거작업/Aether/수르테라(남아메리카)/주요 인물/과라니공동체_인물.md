# 과라니 공동체 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 과라니 공동체는 타완틴 이탈 후 독자 생존 중. 강자 편승 전략. 주변 세력 균형 변화에 극도로 민감.

---

## 1. 수장 (Ava Ruvicha)

| 항목 | 내용 |
|------|------|
| **직위** | 과라니 공동체 최고 수장. 부족 대표 회의 합의 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 탐지·위장 특화 |
| **성격** | 생존 본능이 모든 것 위에 있는 현실주의자. 충성이나 명예보다 공동체 생존. 도덕적 판단 유보 |
| **현재 상황** | 무이스카·투피·타완틴 세 방향 동시 탐색. 현재 무이스카가 가장 강해지는 중이라 판단 |
| **핵심 목표** | 과라니 공동체 생존. 가장 강한 세력 편에 서되 종속 최소화 |
| **갈등 요소** | 타완틴 복귀파와 독립 유지파 내부 분열. 어느 쪽이든 잘못 선택하면 공동체 붕괴 |

### 세부 특성
- 타완틴 이탈 시 현 영토 수호파 귀족과 비공식 교역 채널 유지. 완전 단절 않음
- 무이스카 왕국과 교역 시작. 아직 정치 편입은 유보
- 투피 제국과도 별도 채널. 무이스카·투피 양측 정보 비교하며 균형 탐색 중
- 마푸 연합 동향 주시. 타완틴 압박 받는 세력끼리 연대 가능성 탐색

## 2. 타완틴 복귀파 부족장 (Yaguaru)

| 항목 | 내용 |
|------|------|
| **직위** | 타완틴 복귀파 대표. 대규모 부족 족장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 전통 중시. 타완틴 체제 아래 안정적 삶이 이탈 후 불안정보다 낫다는 판단. 감상적 복귀 아닌 실리적 복귀 |
| **현재 상황** | 타완틴 현 영토 수호파 귀족과 비공식 재편입 조건 협상 탐색 중 |
| **핵심 목표** | 유리한 조건으로 타완틴 재편입. 부족 안정 확보 |
| **갈등 요소** | 타완틴이 현재 내부 분열 중이라 재편입 시기 판단 어려움. 독립 유지파의 강한 반발 |

### 세부 특성
- 타완틴 현 영토 수호파 귀족이 협상 채널 보유한 유일한 과라니 인물
- 무이스카 팽창 속도 보며 복귀 시기 역산 중. 무이스카가 더 강해지기 전에 타완틴 복귀해야 한다는 논리
- 수장의 균형 탐색 방침에 비공식 협력. 타완틴 정보 제공 대가 협상

## 3. 독립 유지파 부족장 (Karai)

| 항목 | 내용 |
|------|------|
| **직위** | 독립 유지파 대표. 소수 부족 연합 수장 |
| **에테르** | 엘리트 하 (4단계). 정령사 계열. 초원·밀림 경계 정령 소계약 |
| **성격** | 자유로운 영혼. 어떤 세력에도 속하지 않는 것이 과라니 본래 방식이라는 신념 |
| **현재 상황** | 수장의 무이스카 편승 방향에 반대. 독자 이동 경로 확보 시도 |
| **핵심 목표** | 어느 세력에도 속하지 않는 완전 독립 유지. 과라니 유목 전통 보전 |
| **갈등 요소** | 독자 생존 전력·자원 한계 현실. 수장의 현실론에 반박 논리 약해지는 중 |

### 세부 특성
- 마푸 연합과 비공식 연락. 타완틴 압박 받는 세력 연대 가능성 탐색
- 투피 제국 밀림 변두리 구역 비공식 활용. 투피 묵인하는 관계
- 무이스카 팽창이 결국 과라니 흡수로 이어진다는 경고 지속. 수장이 경청하나 수용 않음

## 4. 기습 전사 수장 (Tembe)

| 항목 | 내용 |
|------|------|
| **직위** | 과라니 공동체 최강 전투 직군. 기습·도주 전술 총수 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 기습·은신·고속 도주 전술 극한 특화 |
| **성격** | 싸움보다 살아남는 것이 승리라는 철학. 정면 전투 거부. 효율적 손실 최소화 전술 추구 |
| **현재 상황** | 무이스카·타완틴·투피 접경 순찰. 위협 조기 탐지 전담 |
| **핵심 목표** | 과라니 공동체 물리적 생존 보장. 어떤 세력의 공격도 최소 피해로 회피 |
| **갈등 요소** | 수장의 편승 전략이 실패할 경우 전투로 버텨야 하는 상황. 전력 열세 인식 |

### 세부 특성
- 초원·밀림 경계 지형 완전 숙지. 어떤 방향에서 공격 와도 3개 이상 도주 경로 준비
- 무이스카 원정군 사령관의 전술 분석 보고 독자 수집. 가장 위험한 상대로 평가
- 투피 밀림 전사 수장의 전투 방식 간접 학습. 밀림 기습 전술 일부 차용
- 수장의 어느 방침도 지지하지 않음. 오직 생존 가능성으로만 판단

## 5. 정보 수집가 (Araña)

| 항목 | 내용 |
|------|------|
| **직위** | 과라니 공동체 비공식 정보망 수장. 수장 직속 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 위장·에테르 감청 특화 |
| **성격** | 존재 자체가 비밀. 어느 파벌에도 공식 소속 없음. 수장에게만 보고 |
| **현재 상황** | 무이스카·타완틴·투피·마푸 동시 정보 수집. 수장의 균형 탐색 핵심 자원 |
| **핵심 목표** | 주변 세력 동향 실시간 파악. 편승 타이밍 최적화 |
| **갈등 요소** | 정보 과부하. 어느 방향이 옳은지 정보 자체로는 판단 불가. 해석은 수장 몫 |

### 세부 특성
- 무이스카 정보 수장의 과라니 요원 심기 시도 역탐지. 과라니 내부 침투 차단
- 타완틴 복귀파 부족장의 비공식 협상 채널 감시 중. 수장에게 보고
- 마푸 연합이 타완틴 압박에 저항 성공한 방식 분석. 과라니 독립 유지 참고 사례로 정리
- 무이스카 왕국 정보 수장과 서로 상대 요원 역탐지 중. 고양이·쥐 게임

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **수장 → 기습 전사 수장** | 신임. 생존 군사 기반 |
| **수장 → 정보 수집가** | 직속. 핵심 정보 의존 |
| **수장 → 타완틴 복귀파** | 정보 채널 활용 |
| **수장 → 독립 유지파** | 경청하나 수용 않음 |
| **타완틴 복귀파 ↔ 독립 유지파** | 방향 대립 |
| **독립 유지파 → 마푸 연합** | 연대 탐색 |
| **정보 수집가 → 복귀파 부족장** | 비공식 협상 감시 |
| **정보 수집가 ↔ 무이스카 정보 수장** | 상호 역탐지 |
| **수장 → 무이스카 왕국** | 교역 시작. 편입 유보 |
