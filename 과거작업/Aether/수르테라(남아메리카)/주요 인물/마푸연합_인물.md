# 마푸 연합 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 마푸 연합은 타완틴 조공 저항 성공 중. 독립 강화 추진. 과라니 공동체와 연대 가능성 고민 중.

---

## 1. 대족장 (Lonko Mapu)

| 항목 | 내용 |
|------|------|
| **직위** | 마푸 연합 대족장. 부족 연합 합의 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 고원·초원 전투 특화 |
| **성격** | 강인하고 독립 의지 확고. 타완틴 저항 성공이 자신감 기반. 이제 방어를 넘어 실질 세력화 원함 |
| **현재 상황** | 아우카 부족연 연대 협상 추진. 과라니와 남방 연대 망 구축 고민 중 |
| **핵심 목표** | 마푸 완전 독립 확립. 타완틴 재침략 완전 억지력 구축 |
| **갈등 요소** | 타완틴 협상파의 타협 압박. 과라니 연대 시 과라니 강자 편승 성향이 변수 |

### 세부 특성
- 타완틴 총사령관의 원정 준비 정보 입수. 선제 방어 강화 지시
- 아우카 마정석 발견이 연대 강화 계기가 될 수 있다는 판단. 마정석 공동 방어 협약 제안 구상 중
- 과라니 수장과 간접 연락. 과라니의 강자 편승 성향 인지. 연대 조건 신중 검토 중
- 타완틴 쇠퇴를 영구적으로 만들 기회라는 전략적 인식

## 2. 타완틴 협상파 족장 (Caupolicán-min)

| 항목 | 내용 |
|------|------|
| **직위** | 협상파 족장 연합 대표. 대족장 다음 서열 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 현실적이고 피로감 있음. 저항 성공했지만 전쟁 피해도 크다는 인식. 유리한 협상으로 항구적 평화 추구 |
| **현재 상황** | 타완틴 현 영토 수호파 귀족과 비공식 협상 채널 탐색 중 |
| **핵심 목표** | 타완틴과 조공 없는 평화 협정. 마푸 부족 일상 안정 회복 |
| **갈등 요소** | 대족장의 세력화 방침이 타완틴 자극해 재침략 유발 우려 |

### 세부 특성
- 타완틴 내부 분열 정보 파악. 지금이 협상 최적 시기라는 판단
- 과라니와 연대 시 타완틴 자극 더 커진다는 우려. 연대 반대 입장
- 아우카 연대는 찬성. 마정석 자원 확보가 협상력 강화에도 도움

## 3. 저항 고수파 족장 (Lautaro-min)

| 항목 | 내용 |
|------|------|
| **직위** | 저항 고수파 족장 연합 대표 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 불타는 독립 의지. 타완틴과 어떤 형태의 협상도 굴복이라는 신념. 대족장의 독립 강화 방침 전폭 지지 |
| **현재 상황** | 과라니·아우카 연대 모두 찬성. 남방 저항 연대망 구축 주도 |
| **핵심 목표** | 타완틴 완전 격퇴. 어떤 조공도 거부 |
| **갈등 요소** | 협상파의 현실론. 연대 세력(과라니)의 신뢰성 불확실 |

### 세부 특성
- 과라니 공동체 독립 유지파 부족장과 직접 연락. 남방 저항 연대 논의
- 투피 제국의 타완틴 전쟁을 마푸에 유리한 간접 압박으로 활용 주장
- 아우카 마정석 방어 협약 가장 적극 추진

## 4. 고원 전사 수장 (Colocolo)

| 항목 | 내용 |
|------|------|
| **직위** | 마푸 연합 최강 전투 직군. 타완틴 원정군 대응 전담 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 고원·초원 지형 방어·역습 전술 극한 특화 |
| **성격** | 전투에서 완벽주의. 타완틴 원정군을 수차례 격퇴한 경험. 냉정하고 자신감 강함 |
| **현재 상황** | 타완틴 접경 방어선 유지. 총사령관의 원정 재개 준비 정보 입수 후 대비 강화 |
| **핵심 목표** | 타완틴 원정군 완전 격퇴. 마푸 영토 수호 |
| **갈등 요소** | 협상파가 전투 성과를 협상 자산으로만 활용하려는 시도에 불만 |

### 세부 특성
- 타완틴 총사령관과 수차례 교전. 상대 전술 완전 파악. 고원 지형에서 타완틴 우위 상쇄 전술 보유
- 파타고니아 빙설 괴물 마물 소탕 다수 경험. 극한 환경 전투 전문
- 아우카 마정석 지대 인근 마물 밀집 정보 입수. 방어 협약 시 마물 대응도 포함 주장
- 과라니 기습 전사 수장의 전술 방식 간접 파악. 연대 시 보완 관계 가능성 평가

---

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대족장 → 고원 전사 수장** | 신임. 군사 기반 |
| **대족장 → 저항 고수파** | 방향 일치. 핵심 지지 |
| **대족장 → 협상파** | 경청하나 수용 않음 |
| **협상파 ↔ 저항 고수파** | 대립. 타완틴 대응 방식 |
| **저항 고수파 → 과라니 독립 유지파** | 직접 연락. 연대 논의 |
| **고원 전사 수장 → 타완틴 총사령관** | 반복 교전. 전술 완전 파악 |
| **고원 전사 수장 → 과라니 기습 전사 수장** | 연대 보완 관계 평가 |
| **대족장 → 과라니 수장** | 간접 연락. 신중 검토 중 |
| **대족장 → 아우카 부족연** | 연대 협상 추진 중 |
