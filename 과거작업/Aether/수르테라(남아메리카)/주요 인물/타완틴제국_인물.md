# 타완틴 제국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 타완틴 제국은 전성기를 지나 쇠퇴 중이나 황제는 이를 인정하지 않음.
> 내부적으로 현 영토 수호파와 잃어버린 영토 회복파가 대립.

---

## 1. 황제 (Sapa Inca)

| 항목 | 내용 |
|------|------|
| **직위** | 타완틴 제국 황제. 태양신 인티의 아들 |
| **에테르** | 엘리트 상 (6단계). 성기사 계열. 인티 신성력 운용 |
| **성격** | 자존심 강하고 현실 부정. 쇠퇴를 일시적 후퇴로 인식. 제국의 영광이 반드시 돌아온다는 확신 |
| **현재 상황** | 신관 집권파·군사 귀족파 갈등 중재 무력화. 두 파벌이 황제를 앞세우고 실권 다툼 |
| **핵심 목표** | 타완틴 제국 영광 유지라는 명분 고수. 실질적 결정권 회복 |
| **갈등 요소** | 쇠퇴 현실을 인정하지 않으니 근본 해결책 없음. 두 파벌 모두 황제를 도구로 활용 |

### 세부 특성
- 즉위 당시 이미 쇠퇴 진행 중이었으나 인지 못함. 선황의 영광을 그대로 이어받은 것으로 착각
- 마푸 연합 저항·과라니 이탈을 신하들의 무능 탓으로 돌림. 자신의 판단 오류 인정 없음
- 신관 집권파가 인티 신탁을 통해 황제 결정 유도. 황제는 신탁을 절대 신뢰
- 고산 전사 수장을 개인적으로 신임. 두 파벌 중 어느 쪽도 아닌 유일한 직속 신하로 인식

## 2. 신관 집권파 대신관 (Willaq Umu)

| 항목 | 내용 |
|------|------|
| **직위** | 타완틴 제국 대신관. 신관 집권파 수장 |
| **에테르** | 엘리트 중 (5단계). 성기사 계열. 의식·예언 신성력 특화 |
| **성격** | 신탁을 통해 황제를 조종하는 구조 설계자. 겉으로 경건하고 신중. 실제론 권력 수호가 최우선 |
| **현재 상황** | 현 영토 수호 방침 관철 시도. 신탁으로 황제 결정 유도 중 |
| **핵심 목표** | 신관 집권 구조 유지. 군사 귀족파 견제 |
| **갈등 요소** | 군사 귀족파의 영토 회복 시도가 자원 소모로 이어지면 신관 재정 기반 약화 |

### 세부 특성
- 파차마마 신앙과 인티 신앙 통합 해석으로 신관 회의 내 최고 권위 확보
- 고산 에테르 관련 고대 기록 일부 보유. 타완틴 쇠퇴와 고산 에테르 변화 연관 가능성 인지
- 아우카 부족연 마정석 발견 정보 입수. 세력 변화 경계 중
- 고산 전사 수장이 황제 직속이라는 것에 불만. 신관 영향력 밖

## 3. 군사 귀족파 총사령관 (Apu Suyuq Apun)

| 항목 | 내용 |
|------|------|
| **직위** | 타완틴 제국 군사 총사령관. 군사 귀족파 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 고산 집단 전투 지휘 특화 |
| **성격** | 직선적이고 호전적. 쇠퇴 원인이 신관들의 지나친 의식 의존 때문이라는 확신 |
| **현재 상황** | 마푸 연합 재복속 원정 준비 추진. 황제 승인 획득 시도 |
| **핵심 목표** | 잃어버린 영토 회복. 군사 귀족 권한 강화 |
| **갈등 요소** | 신관 집권파의 신탁 방해. 황제가 신탁에 의존하는 한 승인 어려움 |

### 세부 특성
- 마푸 연합 최강 전사와 직접 교전 경험. 전력 차 좁혀지고 있음 인식. 빠른 원정 필요 판단
- 아우카 부족연 마정석 발견이 마푸 세력 강화로 이어질 것 우려. 선제 행동 주장
- 고산 전사 수장을 경쟁자로 인식. 황제 직속이라는 위치 경계
- 과라니 공동체 이탈도 군사력으로 해결하려는 입장

## 4. 고산 전사 수장 (Qhapaq Ñan)

| 항목 | 내용 |
|------|------|
| **직위** | 황제 직속 고산 전사 부대 수장. 타완틴 최강 전투 직군 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 안데스 고산 환경·이야파 번개 에테르 특화 |
| **성격** | 충성스럽고 과묵. 파벌 논리보다 황제 직접 명령 우선. 쇠퇴 현실은 인정하나 발언 안 함 |
| **현재 상황** | 황제 호위 및 고산 방어선 총괄. 두 파벌 어느 쪽도 아닌 독립적 위치 유지 |
| **핵심 목표** | 황제 보호. 타완틴 핵심 영토 방어 |
| **갈등 요소** | 황제가 현실을 모르는 상태에서 내리는 명령 이행. 내심 갈등 |

### 세부 특성
- 안데스 고산 괴조 마물 소탕 다수 경험. 고산 마물 대응 전문
- 이야파 번개 에테르 전투 방식 독자 발전. 고산 폭풍 전술 운용
- 파벌 싸움 인지하고 있으나 개입 않음. 황제가 도구로 쓰이는 것 속으로 안타까워함
- 아우카 부족연 마정석 발견 관련 정보 독자 수집 중. 제국 안보 영향 평가

## 5. 현 영토 수호파 귀족 수장 (Qollana Apu)

| 항목 | 내용 |
|------|------|
| **직위** | 현 영토 수호파 귀족 연합 대표. 신관 집권파와 협력 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열 |
| **성격** | 현실적이고 보수적. 지금 있는 것을 지키는 것이 최선. 원정은 자원 낭비 |
| **현재 상황** | 신관 집권파와 연대. 군사 귀족 원정 저지 |
| **핵심 목표** | 현 영토 안정적 유지. 내부 경제 기반 강화 |
| **갈등 요소** | 아우카 마정석 발견이 세력 균형 변화 초래 시 현 영토 수호만으론 부족해질 수 있음 |

### 세부 특성
- 과라니 공동체와 비공식 교역 채널 유지. 이탈 이후에도 경제 관계 보전
- 아우카 부족연 독립 시도에 협상 통한 재편입 주장. 군사 원정 반대
- 칠람 동맹과 간접 무역 채널. 유적 정보보다 실질 교역 이익 중시

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **황제 → 고산 전사 수장** | 유일한 직속 신임 |
| **황제 → 대신관** | 신탁 의존. 조종당하는 중 |
| **황제 → 총사령관** | 군사 능력 인정. 파벌 경계 |
| **대신관 ↔ 총사령관** | 신관 집권 vs 군사 귀족 핵심 대립 |
| **대신관 → 현 영토 수호파** | 연대. 원정 저지 공조 |
| **총사령관 → 고산 전사 수장** | 경쟁자 인식. 경계 |
| **고산 전사 수장 → 황제** | 충성. 내심 안타까움 |
| **현 영토 수호파 → 과라니 공동체** | 비공식 교역 유지 |
| **총사령관 → 마푸 연합** | 재복속 원정 준비 |
