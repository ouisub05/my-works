# 칠람 동맹 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 칠람 동맹은 고대 유적 연구 중심. 타완틴 제국 압박은 무이스카 왕국이 완충 역할로 저지.
> 현재 유적 연구 결과를 외교 자산으로 활용하는 연대 외교 추진 중.

---

## 1. 맹주 (Halach Uinic)

| 항목 | 내용 |
|------|------|
| **직위** | 칠람 동맹 맹주. 도시국가 대표 회의 선출 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 고대 에테르 분석·술식 특화 |
| **성격** | 지적이고 외교적. 지식이 가장 강력한 외교 자산이라는 신념. 유적 정보를 협상 카드로 정밀하게 활용 |
| **현재 상황** | 테노치 제국·마기스테리움·강티세 동맹에 유적 연구 협력 제안 타진 중. 무이스카와 완충 관계 유지 |
| **핵심 목표** | 고대 유적 연구 결과로 수르테라 내 칠람 동맹 위상 확보. 외부 연구 파트너 확보 |
| **갈등 요소** | 비밀 유지파의 정보 유출 우려. 어느 세력에게 얼마나 공개할지 범위 결정이 핵심 과제 |

### 세부 특성
- 테노치 유물 연구자와 고대 통신 구슬 수신 신호 관련 비공식 연락 시작
- 마기스테리움 원장에게 고대 에테르 패턴 일부 공개 조건으로 에테르 이론 교환 협상 중
- 무이스카 왕국이 타완틴 압박을 막아주는 구도를 칠람이 유적 정보 제공으로 보답하는 비공식 협약 유지
- 칠람 보유 고대 유적 기록이 강티세 동맹 기록과 부분 일치한다는 것 발견. 연관성 연구 중

## 2. 비밀 유지파 대신관 (Ah Kin Mai)

| 항목 | 내용 |
|------|------|
| **직위** | 칠람 동맹 신관 회의 수장. 비밀 유지파 대표 |
| **에테르** | 엘리트 하 (4단계). 성기사 계열. 쿠쿨칸 신성력 특화 |
| **성격** | 신중하고 보수적. 고대 유적 지식은 함부로 나눌 수 없는 신성한 것이라는 신념 |
| **현재 상황** | 맹주의 외부 연대 방침에 부분 동의하나 공개 범위 제한 강경 주장 |
| **핵심 목표** | 고대 유적 핵심 기록 외부 유출 방지. 신관 회의 해석 권한 독점 |
| **갈등 요소** | 맹주가 협상 카드로 점점 더 많은 정보 공개 시도. 어디까지 허용할지 경계선 갈등 |

### 세부 특성
- 칠람 보유 가장 중요한 고대 기록인 "창세 판"을 신관 회의가 직접 보관. 맹주도 전체 열람 불가
- 테노치 유물 연구자와 연락 사실 인지. 정보 유출 범위 감시 중
- 고대 유적 에테르 패턴이 현재 신성력 원천과 연결될 수 있다는 연구 결과 보유. 극비

## 3. 유적 공개파 학자 수장 (Itzamna Ch'ul)

| 항목 | 내용 |
|------|------|
| **직위** | 칠람 동맹 학술 연구 집단 수장. 공개파 대표 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 고대 문자 해독 세계 최고 수준 |
| **성격** | 개방적이고 학구적. 지식은 공유될수록 발전한다는 신념. 신관 회의의 독점에 불만 |
| **현재 상황** | 마기스테리움 개방파 교수와 서신 교환. 고대 문자 해독 성과 일부 공유 |
| **핵심 목표** | 고대 유적 연구 세계적 공유. 칠람 동맹을 고대 문명 연구 중심지로 발전 |
| **갈등 요소** | 대신관의 독점 방침. 맹주가 중간 입장이라 완전 공개 추진 불가 |

### 세부 특성
- 고대 마야 문자 80% 이상 해독 성공. 세계 최고 수준
- 수르테라 석판(우르그룬트 설정 연관)과 칠람 유적 문자 비교 연구 중. 공통 원형 문자 존재 가설
- 강티세 동맹 고대 기록과 칠람 기록 비교 연구 강력 주장. 맹주 통해 접촉 요청 중
- 테노치 유물 연구자와 연구 교류 가장 적극적으로 원하는 인물

## 4. 유적 수호대장 (Ah Puch Nacom)

| 항목 | 내용 |
|------|------|
| **직위** | 칠람 동맹 유적 수호 특수부대 총수. 유적 방어 전담 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 고대 유적 내부 전투·함정 전술 극한 특화 |
| **성격** | 과묵하고 냉혹. 유적을 침범하는 모든 것을 적으로 간주. 고대 유적 마물 대응 전문가 |
| **현재 상황** | 유적 내 고대 유적 마물 출현 증가 대응 중. [E] 마물 징후 포착 |
| **핵심 목표** | 칠람 유적 완전 수호. 외부 세력 무단 접근 원천 차단 |
| **갈등 요소** | 공개파 학자들이 외부 연구자 유적 방문 허용 요구. 보안 원칙과 충돌 |

### 세부 특성
- 고대 유적 수호자 마물과 반복 교전 경험 최다. 고대 에테르 무기화 방어 기술 독자 개발
- 유적 내 [E] 마물 출현을 가장 먼저 보고한 인물. 기존 고대 유적 마물과 다른 패턴 확인
- 테노치 제국 유적 침범 시도를 수차례 저지. 테노치 근위대장을 가장 위험한 침범 가능 존재로 주시
- 마기스테리움·테노치와 연구 협력 시 유적 내부 접근은 절대 불가 원칙. 맹주와 갈등

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **맹주 → 유적 수호대장** | 신임. 유적 방어 전담 |
| **맹주 → 대신관** | 비밀 유지 범위 협상 중 |
| **맹주 → 공개파 학자** | 연구 성과 외교 자산 활용 |
| **대신관 ↔ 공개파 학자** | 공개 범위 대립 |
| **유적 수호대장 → 공개파 학자** | 외부 방문 허용 반대 |
| **공개파 학자 → 마기스테리움 개방파 교수** | 서신 교환. 연구 공유 |
| **공개파 학자 → 테노치 유물 연구자** | 연구 교류 희망 |
| **맹주 → 테노치 유물 연구자** | 비공식 연락 시작 |
| **맹주 → 강티세 동맹** | 기록 비교 연구 접촉 시도 |
| **무이스카 왕국 → 칠람 동맹** | 완충 역할. 비공식 유적 정보 협약 |
