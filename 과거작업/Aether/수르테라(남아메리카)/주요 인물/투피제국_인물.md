# 투피 제국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 투피 제국은 타완틴 제국과 현재 전쟁 중. 무이스카 북진 압박 병행.
> 타완틴전 지속 vs 중단 후 무이스카 대응이 핵심 내부 갈등.

---

## 1. 황제 (Maíra-Monan)

| 항목 | 내용 |
|------|------|
| **직위** | 투피 제국 황제. 투파 신의 선택받은 자 |
| **에테르** | 엘리트 상 (6단계). 성기사 계열. 투파 뇌전 신성력 운용 |
| **성격** | 강인하고 전투적. 타완틴에 먼저 뺏긴 영토 회복이 명예 문제라는 인식. 전략보다 기개 우선 경향 |
| **현재 상황** | 타완틴과 전쟁 지속 중. 무이스카 북진 압박 인지했으나 타완틴 반격 우선 방침 |
| **핵심 목표** | 타완틴에게 빼앗긴 남부 밀림 영역 회복. 투피 제국 위상 확립 |
| **갈등 요소** | 무이스카 북진 속도가 예상보다 빠름. 타완틴 전쟁 지속 시 양면 전선 위험 |

### 세부 특성
- 타완틴 고산 전사 수장과 직접 교전 경험. 고산 지형에서 밀림 전술 한계 경험. 그럼에도 반격 고집
- 무이스카를 타완틴보다 장기적으로 더 위험한 상대로 인식하면서도 눈앞의 타완틴 명예 회복 우선
- 정령사 수장의 밀림 정령 경보 보고 신뢰. 유일하게 전략 수정 가능성 열어둔 조언자
- 밀림 전사 수장의 무이스카 대응 전환 건의를 여러 차례 무시. 그러나 최근 흔들리는 중

## 2. 타완틴 전쟁 지속파 장군 (Ajuricaba)

| 항목 | 내용 |
|------|------|
| **직위** | 타완틴 원정 전선 총지휘관. 전쟁 지속파 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 밀림→고원 접경 전투 특화 |
| **성격** | 호전적이고 집념 강함. 타완틴에 한 번 밀린 것을 치욕으로 인식. 반드시 되갚겠다는 개인 동기 |
| **현재 상황** | 타완틴 접경 공세 지속. 황제 방침 충실 이행 |
| **핵심 목표** | 타완틴 남부 밀림 영역 탈환. 개인 명예 회복 |
| **갈등 요소** | 무이스카 북진 정보 알고 있으나 황제가 타완틴 우선 방침이라 전환 못함 |

### 세부 특성
- 타완틴 고산 전사 수장과 수차례 교전. 고산 지형 불리함으로 공세 한계 경험
- 무이스카 원정군 사령관의 전술 분석 보고 접수. 위험 인식하나 발언 않음
- 밀림 전사 수장과 전선 분담. 밀림 내 전투는 밀림 전사 수장 주도

## 3. 무이스카 대응 전환파 장군 (Cunhambebe)

| 항목 | 내용 |
|------|------|
| **직위** | 북부 방위 총사령관. 무이스카 대응 전환파 수장 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 밀림 방어·역습 전술 특화 |
| **성격** | 냉정하고 현실적. 두 개의 전선을 동시에 감당할 전력 없다는 판단. 황제에게 직언하는 몇 안 되는 인물 |
| **현재 상황** | 무이스카 북진 방어선 구축 중. 황제에게 타완틴 전쟁 중단 건의 반복 |
| **핵심 목표** | 무이스카 북진 저지. 투피 북부 영토 방어 |
| **갈등 요소** | 황제가 타완틴 명예 회복 고집. 전환파 목소리 점점 커지나 결정권은 황제 |

### 세부 특성
- 무이스카 원정군 사령관의 전술을 가장 정확히 파악한 인물. 직접 충돌 전례 없으나 정보 분석 충분
- 타완틴 쇠퇴 상황에서 전쟁 중단 시 타완틴이 오히려 협상 원할 수 있다는 전략적 논리 제시
- 정령사 수장의 밀림 정령 이상 징후 경보를 무이스카 대응 우선 논리에 연계. 황제 설득 시도

## 4. 밀림 전사 수장 (Abaiara)

| 항목 | 내용 |
|------|------|
| **직위** | 투피 제국 최강 전투 직군. 아마존 밀림 전투 총수 |
| **에테르** | 엑스퍼트 중 (8단계). 무인 계열. 아마존 밀림 전투 세계 최강급 |
| **성격** | 밀림 그 자체. 밀림 밖에서는 보통 전사이나 밀림 안에서는 모든 것이 무기. 과묵하고 본능적 |
| **현재 상황** | 타완틴 전선·무이스카 방면 양쪽 전선 지원. 전력 분산에 내심 불만 |
| **핵심 목표** | 아마존 밀림 절대 수호. 어떤 외부 세력도 밀림 깊숙이 침투 못하게 |
| **갈등 요소** | 두 전선 동시 지원으로 어느 쪽도 최선 다하기 어려움. 전환파 장군 지지 |

### 세부 특성
- 아마존 독수 여왕 마물 소탕 경험 다수. 밀림 마물 대응 전문
- 밀림 내 에테르 흐름 변화 감지 능력 보유. 정령사 수장의 이상 징후 경보 가장 먼저 체감
- 밀림 전술은 고산 지형에서 반감. 타완틴 전선 한계 직접 경험. 전환 필요성 확신
- 무이스카 원정군 사령관이 밀림 전술 연구 중이라는 정보 입수. 무이스카 대응 우선 더욱 강조

## 5. 정령사 수장 (Maíra-Ata)

| 항목 | 내용 |
|------|------|
| **직위** | 투피 제국 정령사 최고 권위자. 아마존 정령 신앙 수호 |
| **에테르** | 정령사 상급 (3단계). 아마존 밀림·강·독기 정령 광범위 계약 |
| **종족** | 하프 엘프. 단절 이전부터 아마존 일대 거주한 엘프 혈통 후손. 투피 내 유일한 비인간 고위직 |
| **성격** | 수천 년 밀림의 기억을 간직한 듯한 신비로운 존재감. 단절 이전 기억 단편 보유. 밀림의 변화에 극도로 민감 |
| **현재 상황** | 아마존 정령 이상 징후 심각한 수준으로 경보 발령. [E] 마물과 연관 가능성 분석 중 |
| **핵심 목표** | 아마존 밀림 정령 체계 보전. 이상 징후 원인 규명 |
| **갈등 요소** | 황제가 타완틴 전쟁 우선으로 경보 경시. 밀림 정령 이상이 전쟁 손실보다 더 큰 위협이라는 것 전달 어려움 |

### 세부 특성
- 단절 이전 엘프 혈통 기억 단편 보유. 고대 에테르 패턴과 현재 [E] 마물 에테르 패턴 유사성 인지
- 베스테리아 에이렌발트 엘프와 계통적으로 연결되나 수천 년 독자 발전. 엘프어 원형 일부 보유
- 강티세 동맹 술식 문파 수장·이스칼드 분트 정령사 수장과 유사한 이상 징후 동시 감지. 세계적 현상임을 인식
- 아마존 독소 마물이 [E] 마물화되는 사례 최초 보고. 틀링깃 정령사 수장 관찰 결과와 유사 패턴

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **황제 → 정령사 수장** | 유일한 전략 수정 가능성 조언자 |
| **황제 → 타완틴 전선 장군** | 방침 공유. 전쟁 지속 지지 |
| **황제 → 무이스카 대응 장군** | 직언 존중. 결정은 유보 |
| **황제 → 밀림 전사 수장** | 신임. 전선 지원 위임 |
| **타완틴 전선 장군 ↔ 무이스카 대응 장군** | 전략 방향 대립 |
| **밀림 전사 수장 → 무이스카 대응 장군** | 전환파 지지 |
| **정령사 수장 → 밀림 전사 수장** | 이상 징후 먼저 체감하는 연결 |
| **정령사 수장 → 강티세·이스칼드 정령사** | 세계적 [E] 마물 이상 징후 연관 인식 |
| **정령사 수장 → 에이렌발트 엘프** | 수천 년 독자 발전한 원계통. 연결 없음 |
