# 아우카 부족연 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 아우카 부족연은 마푸 연합의 속국. 마정석 발견으로 독립 시도 중.
> 대족장은 마정석 규모 확인 후 독립 선언 방침. 공개 범위가 핵심 내부 갈등.

---

## 1. 대족장 (Auka Lonko)

| 항목 | 내용 |
|------|------|
| **직위** | 아우카 부족연 대족장. 최근 교체된 독립 의지 강한 신임 대족장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 극한 환경 생존 전투 특화 |
| **성격** | 신중하고 계산적. 마정석이 독립의 열쇠라는 확신. 섣부른 행동이 마푸 진압을 부를 것을 경계 |
| **현재 상황** | 마정석 탐사 완료 전 독립 선언 유보. 마푸 감시 피해 탐사 진행 중 |
| **핵심 목표** | 마정석 규모 확인 후 독립 선언. 마푸 압박 전 기정사실화 |
| **갈등 요소** | 즉각 독립 시도파의 조급함. 마정석 공개 범위 내부 이견. 마푸 감시 강화로 탐사 난항 |

### 세부 특성
- 전임 대족장의 굴종 방침을 뒤집고 선출됨. 부족민 독립 열망 대표
- 마정석 규모가 중간 이상이면 독립 선언. 소규모면 마푸 재협상 방침으로 전환 예비 계획 보유
- 마푸 대족장의 연대 협상 제안을 호의적으로 검토 중. 그러나 독립 전제 조건 필수
- 파타고니아 빙설 괴물 마물이 마정석 탐사 최대 장애물이라는 보고 접수

## 2. 즉각 독립 시도파 족장 (Kalfukura-min)

| 항목 | 내용 |
|------|------|
| **직위** | 즉각 독립 시도파 부족 대표. 청년 전사 집단 수장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 열정적이고 충동적. 마정석 규모 불확실성보다 지금 이 순간 마푸가 약한 것이 더 중요하다는 논리 |
| **현재 상황** | 마푸 감시단 비협조 행동 주도. 대족장의 신중론에 답답함 |
| **핵심 목표** | 조기 독립 선언. 마푸 타완틴 대응 분산 틈 활용 |
| **갈등 요소** | 대족장의 확인 후 독립 방침. 마정석 탐사 완료가 언제가 될지 불명확 |

### 세부 특성
- 마정석 정보를 타완틴·무이스카에 일부 흘려 마푸 압박 강화 주장. 공개파 입장
- 마푸 연합 저항 고수파 족장과 비공식 연락. 연대 전선 구축 논의
- 마정석 지대 수호대장과 갈등. 수호대장의 비밀 유지 원칙에 반하는 행동 시도

## 3. 마푸 압박 이용파 족장 (Quilapayun-min)

| 항목 | 내용 |
|------|------|
| **직위** | 온건 협상파 부족 대표. 마푸 압박 이용 전략 수장 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열. 탐지·협상 보조 에테르 |
| **성격** | 현실주의. 마정석 카드로 독립보다 자치권 최대화가 현실적이라는 판단. 마푸와의 관계 완전 단절 반대 |
| **현재 상황** | 마정석 존재를 마푸에 간접 암시하여 자치권 재협상 타진 중 |
| **핵심 목표** | 마정석 협상 카드로 마푸 조공 조건 대폭 개선. 자치권 확대 |
| **갈등 요소** | 대족장의 독립 선언 방침. 즉각 독립파의 공개 압박 |

### 세부 특성
- 마푸 타완틴 협상파 족장과 간접 채널 보유. 아우카 자치권 협상 가능성 탐색
- 마정석 공개 범위에서 가장 제한적 입장. 마푸에만 선별 공개, 외부 세력 비공개
- 마정석 규모가 소규모로 판명될 경우 자신의 협상 방침이 유일한 현실 옵션이라는 계산

## 4. 설원 전사 수장 (Colo-Colo Auka)

| 항목 | 내용 |
|------|------|
| **직위** | 아우카 부족연 최강 전투 직군. 극한 환경 전투 총수 |
| **에테르** | 엘리트 중 (5단계). 무인 계열. 파타고니아 극한 환경·강풍 에테르 전투 특화 |
| **성격** | 과묵하고 극기적. 파타고니아 극한 환경이 자신의 영역. 외부 세력이 이 땅에 발붙일 수 없다는 자신감 |
| **현재 상황** | 마푸 감시단 접근 저지. 마정석 지대 외곽 방어 담당 |
| **핵심 목표** | 아우카 영토 완전 방어. 마푸 진압 시도 저지 |
| **갈등 요소** | 현재 전력으로 마푸 고원 전사 수장과 정면 대결 불리함 인식. 지형 이용이 유일한 대응책 |

### 세부 특성
- 파타고니아 빙설 괴물 마물 대응 경험 다수. 마정석 지대 주변 마물 지형 완전 파악
- 마푸 고원 전사 수장의 전술을 간접 파악. 파타고니아 극한 환경이 마푸 전술 무력화 가능하다는 분석
- 아우카 극한 환경 생존 전술을 전투에 완전 통합. 외부 침입자는 전투 전에 환경에 소모됨
- 마정석 지대 수호대장과 협력. 외곽 방어·내부 수호 분업 체계

## 5. 마정석 지대 수호대장 (Likanantai)

| 항목 | 내용 |
|------|------|
| **직위** | 마정석 매장 지대 방어 전담 특수부대 수장. 대족장 직속 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 에테르 탐지·마정석 감응 특화 |
| **성격** | 냉혹하고 원칙적. 마정석 비밀 유지가 독립의 핵심 조건이라는 확신. 정보 유출 시도 무관용 |
| **현재 상황** | 마정석 탐사 지원 및 지대 방어 총괄. 파타고니아 빙설 괴물 마물 대응 병행 |
| **핵심 목표** | 마정석 탐사 완료까지 완전 비밀 유지. 마물 소탕으로 탐사 환경 확보 |
| **갈등 요소** | 즉각 독립 시도파의 외부 공개 시도. 압박 이용파의 선별 공개 주장. 양측 모두 비밀 유지 원칙 위협 |

### 세부 특성
- 마정석 에테르 감응 능력 보유. 탐사 현장 직접 지원
- 현재까지 발견된 마정석 규모 3등급 다수·2등급 일부 확인. 대족장에게만 보고. 극비
- 파타고니아 빙설 괴물이 마정석 에테르 반응에 끌린다는 패턴 발견. 수르테라 파타고니아 마물 도감 연관
- 즉각 독립 시도파 족장의 정보 유출 시도 3차례 차단. 대족장에게 보고

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대족장 → 마정석 지대 수호대장** | 직속. 탐사 결과 독점 보고 |
| **대족장 → 설원 전사 수장** | 신임. 방어 기반 |
| **대족장 → 즉각 독립 시도파** | 조급함 억제. 시기 조율 |
| **대족장 → 압박 이용파** | 예비 옵션으로 경청 |
| **즉각 독립 시도파 ↔ 압박 이용파** | 공개 범위 대립 |
| **즉각 독립 시도파 → 마정석 지대 수호대장** | 정보 유출 시도. 3차례 차단 |
| **설원 전사 수장 ↔ 마정석 지대 수호대장** | 외곽·내부 방어 분업 협력 |
| **압박 이용파 → 마푸 타완틴 협상파** | 간접 채널 탐색 |
| **즉각 독립 시도파 → 마푸 저항 고수파** | 비공식 연락 |
| **대족장 → 마푸 대족장** | 연대 협상 호의적 검토 중 |
