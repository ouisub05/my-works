# 무이스카 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 무이스카 왕국은 제국화 준비 중. 타완틴 쇠퇴 공백 활용. 베스테리아 정보는 제국화 도움 여부에 따라 이행.

---

## 1. 왕 (Zipa)

| 항목 | 내용 |
|------|------|
| **직위** | 무이스카 왕국 국왕 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 열대 지형 전투·지휘 특화 |
| **성격** | 야망적이고 계산적. 타완틴 쇠퇴를 황금 기회로 인식. 베스테리아 정보도 제국화 도구로만 평가 |
| **현재 상황** | 타완틴 쇠퇴 공백 영역 편입 추진. 팽창 강행파·신중파 갈등 중재 |
| **핵심 목표** | 무이스카 제국 수립. 수르테라 패권 장악 |
| **갈등 요소** | 팽창 속도 내부 이견. 포르타 침투가 무이스카 제국화에 장애가 될 수 있다는 정보 수장의 경고 |

### 세부 특성
- 칠람 동맹을 완충·정보 제공자로 활용. 유적 정보가 제국화 명분에 도움될 수 있다는 인식
- 포르타 콘소르티움 존재 인지. 아직 직접 위협 아니라고 평가. 단 제국화 완성 후 접촉 시 협상력 필요 인식
- 타완틴 신관 집권파와 비공식 채널. 군사 귀족파 원정 저지 공동 이해
- 와바나키·테노치 양측 정보 동시 수집. 노르테라 패권 구도 파악 후 수르테라 독립 체계 구상

## 2. 팽창 강행파 귀족 수장 (Saguanmachica)

| 항목 | 내용 |
|------|------|
| **직위** | 팽창 강행파 귀족 연합 수장 |
| **에테르** | 엘리트 중 (5단계). 무인 계열 |
| **성격** | 공격적이고 기회주의적. 타완틴 약화 지금 이 순간이 다시 오지 않을 기회라는 확신 |
| **현재 상황** | 타완틴 접경 영역 즉각 편입 주장. 과라니 공동체 흡수도 병행 요구 |
| **핵심 목표** | 타완틴 공백 최대한 빠르게 편입. 무이스카 제국화 조기 달성 |
| **갈등 요소** | 신중파의 준비 부족 반론. 왕이 속도 조절 시도 |

### 세부 특성
- 타완틴 총사령관의 원정 준비 정보 입수. 먼저 움직여야 한다는 주장 강화
- 포르타 위협을 가볍게 봄. 아직 수르테라 내륙까지 올 세력 아니라는 판단
- 원정군 사령관과 팽창 방향 전략 공유. 실질 추진력 담당

## 3. 팽창 신중파 귀족 수장 (Nemequene)

| 항목 | 내용 |
|------|------|
| **직위** | 팽창 신중파 귀족 연합 수장 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 탐지·행정 에테르 특화 |
| **성격** | 장기적 시각. 빠른 팽창이 내부 통치 기반 없이는 붕괴로 이어진다는 역사 교훈 인식 |
| **현재 상황** | 편입 영역 행정 체계 구축 우선 주장. 포르타 위협 진지하게 검토 |
| **핵심 목표** | 내실 있는 제국화. 편입 후 안정적 통치 체계 확립 |
| **갈등 요소** | 강행파의 속도 압박. 타완틴 공백이 오래 유지되지 않는다는 반론 |

### 세부 특성
- 포르타 정보 수장의 베스테리아 분석 보고를 가장 진지하게 검토한 귀족
- 칠람 동맹 완충 역할 유지를 무이스카 안보에 필수 요소로 인식. 칠람 관계 강화 주장
- 과거 타완틴 급속 팽창 후 내부 분열 사례 연구. 신중론 근거로 활용

## 4. 원정군 사령관 (Tundama)

| 항목 | 내용 |
|------|------|
| **직위** | 무이스카 왕국 원정군 총사령관. 최강 전투 직군 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 열대·고원 접경 지형 전투 극한 특화 |
| **성격** | 냉정한 전략가. 팽창 강행·신중 논쟁보다 전투 준비 완성도 중시. 왕 명령이면 어느 방향이든 최선 다함 |
| **현재 상황** | 타완틴 접경 원정 준비 총괄. 과라니 방면 전술도 병행 연구 |
| **핵심 목표** | 원정 성공. 무이스카 군사력 수르테라 최강으로 유지 |
| **갈등 요소** | 강행파·신중파 양쪽 눈치 받음. 준비 완성도와 출발 시기 결정권 왕에게 일임 |

### 세부 특성
- 타완틴 고산 전사 수장을 가장 위험한 상대로 평가. 고산 환경 불리함 인식
- 투피 제국 밀림 전술 연구. 향후 남진 시 밀림 전투 대응 준비
- 포르타 탐험대 규모·능력 정보 수집 완료. 현재 단계는 위협 아님. 단 후속 진입 대비 필요 보고
- 강행파 귀족 수장과 전략 공유하나 독자 판단 유지

## 5. 정보 수장 (Bochica)

| 항목 | 내용 |
|------|------|
| **직위** | 무이스카 왕국 첩보 조직 수장. 왕 직속 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 에테르 위장·탐지·감청 특화 |
| **성격** | 존재감 없음이 최고 능력. 수집한 정보를 왕에게만 보고. 모든 세력을 잠재적 위협으로 인식 |
| **현재 상황** | 포르타·테노치·타완틴·칠람 동시 감시. 베스테리아 정보 분석 왕에게 정기 보고 |
| **핵심 목표** | 무이스카 위협 사전 차단. 제국화 과정 정보 우위 확보 |
| **갈등 요소** | 포르타 위협을 강조하나 왕이 제국화 우선으로 평가 절하. 보고 무게 줄어드는 중 |

### 세부 특성
- 포르타 정보 수장이 타이노에 요원 심었다는 정보 입수. 수르테라 침투 시도 가능성 경보 발령
- 테노치 유물 연구자가 고대 통신 구슬 수신 신호 분석 중이라는 정보 파악. 칠람과 연관 주목
- 타완틴 신관 집권파가 왕과 비공식 채널 유지한다는 것 알고 있음. 왕에게 보고했으나 왕은 인지 상태
- 투피 제국 밀림 방면 요원 심기 시도 중. 향후 팽창 방향 사전 준비

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 원정군 사령관** | 신임. 팽창 실행 기반 |
| **왕 → 정보 수장** | 직속. 정보 보고 의존 |
| **왕 → 강행파 귀족** | 방향 공유. 속도 조절 |
| **왕 → 신중파 귀족** | 내실 논리 균형추 활용 |
| **강행파 ↔ 신중파** | 팽창 속도 대립 |
| **강행파 → 원정군 사령관** | 전략 공유. 추진력 |
| **원정군 사령관 → 타완틴 고산 전사 수장** | 최위험 상대 인식 |
| **정보 수장 → 포르타** | 요원 침투 경보 발령 |
| **왕 → 칠람 동맹** | 완충·정보 제공 관계 |
| **왕 → 타완틴 신관 집권파** | 비공식 채널 |
