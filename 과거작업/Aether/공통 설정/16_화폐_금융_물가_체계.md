# 화폐·금융·물가 체계

## 화폐 체계

### 기본 구조

| 화폐 | 재질 | 통용 범위 | 발행 주체 |
|------|------|----------|----------|
| **금화** | 순금 규격 주조 | 전 세계 공통 | 각국 조폐 기관. 규격 동일 |
| **은화** | 순은 규격 주조 | 국가별 통용. 국경 넘으면 환전 필요 | 각국 조폐 기관 |
| **동화** | 구리 합금 | 지역 내 소액 거래 | 각국 조폐 기관 |

### 환율 기준

| 환산 | 내용 |
|------|------|
| **금화 1** | 은화 10~20 (국가별 상이) |
| **은화 1** | 동화 10~50 (지역별 상이) |
| **금화 1** | 동화 100~1,000 |

> 금화는 금 함량이 세계 표준으로 규격화됨. 위조 시 세계 공통 중범죄
> 은화·동화는 국가별 금속 함량·크기 다름 → 국경 통과 시 환전 필수

### 화폐 위조

| 항목 | 내용 |
|------|------|
| **금화 위조** | 세계 공통 금지 범죄. 발각 시 사형·재산 몰수 |
| **은화·동화 위조** | 국가별 처벌. 대부분 중형 |
| **탐지 방법** | 마정석 감응 검사. 드워프 감정. 공인 환전소 인증 |

## 금융 체계

### 주요 금융 기관

| 기관 | 역할 | 주요 거점 |
|------|------|----------|
| **대상인 은행** | 대출·예금·환전·보험 | 마레 콘소르티움·포르타·하이둥 상방 |
| **드워프 금고** | 귀중품 보관·감정·담보 대출 | 우르그룬트 교역소 전 세계 거점 |
| **교단 금융** | 이자 없는 신앙 기반 금융 | 알-와히드 신앙권(말리·자한·알-티자라) |
| **마정석 거래소** | 마정석 담보 금융·신용 발행 | 베스테리아·아시란 주요 도시 |

### 대출·신용 체계

| 항목 | 내용 |
|------|------|
| **이자율** | 일반 대출 월 2~5%. 위험 대출 월 10%+ |
| **담보** | 마정석·토지·선박·귀중품 |
| **신용 거래** | 대상인·귀족 한정. 장기 거래 실적 기반 |
| **알-와히드 금융** | 이자 금지. 수익 분배 방식. 말리·자한·알-티자라 통용 |
| **드워프 대출** | 계약 위반 시 영구 거래 금지. 신뢰도 최고 |

### 환전 체계

| 항목 | 내용 |
|------|------|
| **공인 환전소** | 도시 내 공인 기관. 환전 수수료 2~5% |
| **드워프 환전** | 금 함량 기준 정확한 환전. 수수료 3% 고정 |
| **암시장 환전** | 수수료 낮으나 위조화 위험. 불법 거래 연루 가능 |
| **대륙간 환전** | 금화는 전 세계 동일. 은화 이하는 반드시 환전 필요 |

## 지역별 물가 편차

| 지역 | 물가 수준 | 이유 |
|------|----------|------|
| **베스테리아 대도시** | 높음 | 에테르 기술 보급. 생활 수준 높음 |
| **아프라 케메트** | 중간 | 식량 풍부. 에테르 제품 수입 비쌈 |
| **아시란 하이둥** | 낮음(공산품). 높음(마정석) | 대량 생산력. 마정석 수입 의존 |
| **노르테라·수르테라** | 낮음 | 외부 교역 적음. 자급자족 중심 |
| **전쟁 지역** | 폭등 | 식량·무기 수요 급증 |
| **마물 다발 지대 인접** | 마물 소재 낮음. 일반품 높음 | 공급 과잉 vs 유통 비용 |

## 특수 결제 수단

| 수단 | 내용 | 사용 지역 |
|------|------|----------|
| **마정석 물물교환** | 소형 마정석을 화폐 대용으로 사용 | 외진 지역·변경 지대 |
| **마물 소재 결제** | 희귀 마물 소재로 직접 결제 | 마물 다발 지대 인근 |
| **에테르 서비스 교환** | 금화 대신 에테르 기술 서비스로 결제 | 마법사·무인 사회 |
| **드워프 신용장** | 드워프 금고 발행 신용 증서 | 대규모 교역 |
