# 전투 직군 등급 체계

## 등급 구조

총 12+1단계. 어뎁트(1~3) → 엘리트(4~6) → 엑스퍼트(7~9) → 마스터(10~12) → 초월자.

| 단계 | 공통 표기 | 희소도 |
|------|----------|--------|
| 1단계 | 어뎁트 하 | 흔함 |
| 2단계 | 어뎁트 중 | 흔함 |
| 3단계 | 어뎁트 상 | 어느 정도 흔함 |
| 4단계 | 엘리트 하 | 줄어듦 |
| 5단계 | 엘리트 중 | 드묾 |
| 6단계 | 엘리트 상 | 희소 |
| 7단계 | 엑스퍼트 하 | 매우 희소 |
| 8단계 | 엑스퍼트 중 | 극희소. 국가급 전력 |
| 9단계 | 엑스퍼트 상 | 사실상 전설. 제국 황제급 |
| 10단계 | 마스터 하 | 역사에 이름 남기는 수준 |
| 11단계 | 마스터 중 | 시대의 강자. 대륙 단위 존재 |
| 12단계 | 마스터 상 | 현 시대 최강급 후보 |
| 초월 | 초월자 | 전설로만 존재. 현재 시점 실재 불명 |

> 직군별 표기 예시: 무인 어뎁트 하 / 마법사 엘리트 중 / 성기사 엑스퍼트 하

---

## 직군별 공통 표기

| 직군 | 표기 방식 | 예시 |
|------|----------|------|
| 무인 | 무인 + 등급명 | 무인 어뎁트 하, 무인 엘리트 중, 무인 마스터 하 … |
| 마법사 | 마법사 + 등급명 | 마법사 어뎁트 하, 마법사 엘리트 중 … |
| 정령사 | 별도 단계 명칭 (하단 참조) | — |
| 성기사 | 성기사 + 등급명 | 성기사 어뎁트 하, 성기사 엘리트 중 … |
| 범인 | 범인 단일 | 세부 등급 없음 |

---

## 희소도 및 사회적 위상

| 등급대 | 희소도 | 사회적 위상 |
|--------|--------|-----------|
| 어뎁트 (1~3단계) | 흔함 | 일반 전투 직군. 생계 수준 |
| 엘리트 (4~6단계) | 4단계부터 줄어듦 | 실력자 대우. 국가 군사력 핵심 |
| 엑스퍼트 (7~9단계) | 매우 희소~전설 | 국가급 전력. 귀족 예우. 역사에 이름 남김 |
| 마스터 (10~12단계) | 극전설 | 대륙 단위 전력. 국가가 협상 상대로 대우 |
| 초월자 | 전설로만 존재 | 현재 시점 실재 불명. 고문서·신화에만 기록 |

## 계열별 능력 특성

### 무인 (武人)

| 항목 | 내용 |
|------|------|
| **에테르 운용 방식** | 신체 내부 에테르 경로 강화. 외부 방출 없음 |
| **핵심 능력** | 신체 능력 초월 강화. 근력·속도·내구력·반응속도 |
| **전투 특성** | 근접 전투 극강. 지속 전투력 높음. 회복력 우수 |
| **약점** | 원거리 대응 약함. 마물 마법 계열 공격에 상대적 취약 |
| **등급별 이정표** | 어뎁트: 일반인 3~10배 신체 능력 / 엘리트: 마물 직접 대응 가능 / 엑스퍼트: 소규모 군대 단독 대응 / 마스터: 물리 법칙 일부 초월 |

---

### 마법사 (魔法師)

| 항목 | 내용 |
|------|------|
| **에테르 운용 방식** | 외부 에테르 흡수·술식 연산·방출. 마정석 보조 활용 |
| **핵심 능력** | 광역 공격·원거리 공격·환경 조작·탐지·보조 술식 |
| **전투 특성** | 원거리 절대 우위. 광역 처리 탁월. 마정석 보유량에 따라 지속력 결정 |
| **약점** | 근접 전투 취약. 술식 연산 중 방해받으면 불발. 마정석 소진 시 급격히 약화 |
| **등급별 이정표** | 어뎁트: 단순 술식 1~3개 / 엘리트: 복합 술식 동시 운용 / 엑스퍼트: 환경 자체를 전장으로 전환 / 마스터: 술식 없이 에테르 직접 방출 |

---

### 성기사 (聖騎士)

| 항목 | 내용 |
|------|------|
| **에테르 운용 방식** | 신성력(신앙 기반) + 에테르 강화 병행. 두 힘의 융합 |
| **핵심 능력** | 치유·정화·신성력 공격·자기 강화. 언데드·마물 추가 효과 |
| **전투 특성** | 무인+마법사 중간 특성. 치유 능력으로 지속력 탁월. 신성력 특화 대상(언데드·타락 마물)에 압도적 |
| **약점** | 신앙심 흔들리면 능력 저하. 완전 무인·완전 마법사 각 극단에서 밀림. 성기사 수 자체가 희소 |
| **등급별 이정표** | 어뎁트: 경상 치유·신성력 소폭 발현 / 엘리트: 중상 치유·신성력 공격 가능 / 엑스퍼트: 광역 신성력 방출·대규모 치유 / 마스터: 신성력 완전 무기화 |

---

### 정령사 (精靈師)

정령사는 에테르 등급 체계와 다른 **정령 계약 기반 독자 단계** 사용.

#### 정령사 단계 체계

| 단계 | 명칭 | 계약 가능 정령 | 특징 |
|------|------|--------------|------|
| 1단계 | **정령사 하급** | 중위 정령 1~3체 정식 계약 | 속성 현상 발현. 정령 물질화 기초 |
| 2단계 | **정령사 중급** | 중위 정령 3~5체 정식 계약 | 다속성 동시 운용. 자연 환경 조작 |
| 3단계 | **정령사 상급** | 중위 정령 5~7체 + 대정령 소계약 | 자연 환경 대형 조작. 정령과 일시 동화 |
| 4단계 | **대정령** | 대정령 1체 이상 심계약 | 대정령 직접 소환. 자연 현상 대규모 발현 |
| 5단계 | **정령왕** | 대정령 복수 심계약 | 자연 자체와 일체화. 현 시대 실재 불명 |

> 정령사 단계는 에테르 등급으로 환산 시 대략적 기준:
> 정령사 하급 ≈ 엘리트 / 정령사 중급 ≈ 엑스퍼트 하~중 / 정령사 상급 ≈ 엑스퍼트 상~마스터 하 / 대정령 ≈ 마스터 / 정령왕 ≈ 초월자 수준

#### 정령사 전투 특성

| 항목 | 내용 |
|------|------|
| **핵심 능력** | 자연 환경 활용·정령 물질화·속성 현상 대규모 발현·탐지 |
| **전투 특성** | 자연 환경이 있는 곳에서 압도적. 정령 수만큼 다중 공격 가능 |
| **약점** | 자연 환경 없는 곳에서 급격히 약화. 정령이 거부하면 불발. 실내·도시 전투 불리 |
| **특수** | 정령 이상 징후 감지 능력. [E] 마물 조기 탐지 가능 |

## 등급의 효력

### 공식 자격

| 등급대 | 공식 권한 |
|--------|----------|
| 어뎁트 (1~3단계) | 기초 의뢰 수임. 마물 다발 지대 출입 일부 허용 |
| 엘리트 (4~6단계) | 중급 의뢰 수임. 위험 지역 출입. 일부 국가 군사 고문 자격 |
| 엑스퍼트 (7~9단계) | 고급 의뢰 수임. 국가 간 공식 자격 상호 인정. 특수 구역 출입 |
| 마스터 (10~12단계) | 특급 의뢰 수임. 국가가 개인 자격으로 협상 시도. 사실상 법 위 존재 |
| 초월자 | 공식 체계 밖. 국가가 개인으로서 협상 대상으로 취급 |

### 사회적 지위

| 기준 | 지위 |
|------|------|
| 엑스퍼트 하 이상 | 귀족에 준하는 예우. 일부 국가는 법적 특권 부여 |
| 엑스퍼트 상 (9단계) | 국가가 직접 예우. 작위 수여 시도 많음 |
| 마스터 (10~12단계) | 국가가 협상 상대로 대우. 어느 세력도 함부로 적으로 돌리지 않음 |
| 초월자 | 국가 위에 서는 존재로 인식 |

---

## 범인의 위치

- 에테르를 사용할 수 없는 자는 **범인** 단일 표기
- 아무리 강한 범인도 **에테르 사용자 어뎁트 하를 상대로 정면 전투에서 이기지 못함**
- 기습·지형·수적 우위 등 전술적 상황에서 어뎁트를 제압하는 경우는 있음
- 범인 중 극강자는 세계관 내에서 경이로운 존재로 회자됨

## 등급 인정 기관

| 직군 | 인정 기관 |
|------|----------|
| 무인 | 무인 길드 (등급 측정·인증 전담. 의뢰 중개 없음) |
| 마법사 | 마법사 협회 |
| 정령사 | 엘프류 자체 공동체 자율 관리 |
| 성기사 | 소속 교단 |

> 성기사 등급은 교단 자체 심사 — 타 직군에서 다소 불신하는 경향 존재
> 마스터 이상은 공식 인정 기관 사실상 무의미. 존재 자체가 증명
