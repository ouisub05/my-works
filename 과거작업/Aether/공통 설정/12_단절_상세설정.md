# 단절 상세설정

## 단절이란

세계관 역사상 가장 큰 사건. 고대 문명을 순식간에 붕괴시키고 현재의 세계를 만든 대재앙.
단절 이전 세계는 현재와 지형 자체가 달랐으며, 단절을 기점으로 대륙이 분리됐다.

---

## 단절 이전 세계

### 지형

| 항목 | 내용 |
|------|------|
| **대륙 수** | 2~3개 대륙. 현재보다 훨씬 넓게 연결된 육지 |
| **현재와의 차이** | 현재의 6대륙은 단절 이후 분리·고립된 결과 |
| **이동 가능성** | 대륙 간 육로 이동 가능. 해양 기술 없이도 교류 가능했음 |
| **다크 엘프 분포** | 연결된 대륙을 통해 이동한 엘프 집단이 각지에 거주. 단절 후 고립 |

### 문명 수준
- 현재와 비슷하거나 방향이 다른 수준
- 에테르 기술 체계·사회 구조는 다르나 기술력 차이는 크지 않음
- 현재 재현 불가능한 기술이 존재한다는 증거는 없음
- 단절 이전 마물도 존재했으나 수가 적었고 분포도 한정적

---

## 단절의 발생

### 원인 — 자연재해

| 항목 | 내용 |
|------|------|
| **공식 학설** | 대규모 자연재해 복합 발생. 화산 폭발·운석 충돌 등 |
| **현재 증거** | 각 대륙 지층에서 동일 시기 화산재·충격 지층 발견 |
| **에테르 연관** | 자연재해로 인한 지각 변동이 에테르 흐름 교란 유발 |
| **인위적 원인설** | 소수 의견. 증거 없음. 대부분의 학자들이 부정 |

### 붕괴 양상 — 순식간

| 항목 | 내용 |
|------|------|
| **속도** | 수일~수주 내 고대 문명 핵심 시설 대부분 붕괴 |
| **에테르 혼란** | 자연재해 충격으로 에테르 흐름 전면 교란. 에테르 기술 전면 불능 |
| **대륙 분리** | 지각 변동으로 연결된 육지가 갈라짐. 현재 6대륙 형태로 분리 |
| **생존자** | 에테르 기술 없이 생존 가능한 집단 중심 생존. 문명 대부분 소실 |

> 단절은 수백 년에 걸친 붕괴가 아닌 **한 세대 안에 끝난 사건**
> 살아남은 자들이 목격한 재앙. 구전으로 전해지나 기록 대부분 소실

## 단절의 결과

### 지형 변화

| 항목 | 내용 |
|------|------|
| **대륙 분리** | 2~3개 대륙 → 현재 6대륙으로 분리 |
| **해수면 변화** | 지각 변동으로 해수면 상승. 일부 저지대 수몰 |
| **새로운 지형** | 단절 충격으로 새로운 산맥·협곡·섬 형성 |
| **마물 서식지 변화** | 지형 변화로 마물 분포 재편 |

### 종족에 미친 영향

| 종족 | 영향 |
|------|------|
| **인간** | 가장 빠른 적응. 단절 이후 빠르게 세력 재건 |
| **순혈 엘프** | 고립된 집단은 단절된 대륙에 남음. 일부는 현재 거주지로 이동 전 정착 |
| **다크 엘프** | 단절 당시 각지에 흩어져 있던 엘프 집단. 환경 변화(극한 지형·에테르 혼란)에 장기 노출 → 다크 엘프화 진행 |
| **드워프** | 지하 거주 특성상 지표 충격 일부 흡수. 상대적으로 피해 적음 |
| **수인** | 지역별 편차 큼. 생존력 강한 종류 중심 개체 수 유지 |

---

## 다크 엘프화 — 환경 변화로 인한 변이

### 메커니즘

| 단계 | 내용 |
|------|------|
| **1단계** | 단절 이전부터 각지에 분산 거주하던 엘프 집단 |
| **2단계** | 단절로 대륙 분리. 본래 엘프 사회와 완전 고립 |
| **3단계** | 극한 환경(극한 추위·사막·밀림·에테르 혼란 지대)에 장기 노출 |
| **4단계** | 수 세대에 걸쳐 신체·에테르 체계 변화. 다크 엘프화 완성 |

### 다크 엘프화 조건
- 원래도 극한 환경에 노출된 소수 엘프는 존재했으나 개체 수 적었음
- 단절 이후 고립·환경 변화로 다크 엘프화 대상 집단 급증
- 지역별 환경에 따라 다크 엘프 특성 미세하게 다름
  - 극한 한대 노출 → 피부 더 창백, 한기 내성
  - 밀림 고립 → 독소 내성, 어둠 적응 강화
  - 에테르 혼란 지대 → 어둠·환영 계열 에테르 특화

> **다크 엘프는 단절의 산물이나 단절이 만들어낸 것은 아님**
> 원래도 존재했으나 단절이 그 수를 폭발적으로 늘린 것

## 단절에 대한 현재 인식

| 집단 | 인식 |
|------|------|
| **베스테리아 교단** | 신의 심판. 인간의 오만에 대한 경고 |
| **마기스테리움** | 자연재해 학설 지지. 에테르 흐름 교란 연구 중 |
| **강티세 동맹** | 고산 동굴 기록 보유. 내용 비공개 |
| **칠람 동맹** | 고대 유적이 단절 이전 것. 연구 중이나 성과 미비 |
| **드워프** | 지하 기록 일부 보유. 외부에 공개 안 함 |
| **일반 대중** | 대부분 신화·전설로 인식. 실제 역사로 인지하는 비율 낮음 |

---

## 단절과 에테르 사용 마물

- 단절 이전에도 마물은 존재했으나 에테르를 사용하는 마물은 없었음
- 현재 에테르 사용 마물 출현 증가는 단절과 별개의 새로운 이상 징후
- 일부 연구자는 단절의 원인과 에테르 사용 마물의 원인이 같은 뿌리일 가능성 제기
- 현재로선 추정에 불과. 증거 없음
