# 길드·조직 공통 설정

## 기본 구조

- 세계 단일 조직 없음
- **대륙마다 복수의 조직이 경쟁·공존**
- 같은 종류의 조직이라도 대륙·지역마다 다른 세력이 운영
- 대륙을 넘어 활동하는 자는 각 대륙 조직에 별도 등록 필요

---

## 조직 종류

### 전투 관련

| 조직 | 역할 | 정치적 위치 |
|------|------|-----------|
| 무인 길드 | 무인 등급 측정·인증 전담 (의뢰 중개 없음) | 실질 중립 |
| 마법사 협회 | 마법사 등급 심사·연구·술식 인증 | 명목 중립. 내부 파벌 존재 |
| 용병 길드 | 용병 등록·의뢰 중개·신원 보증 | 조직마다 다름 |

> 무인 길드와 용병 길드는 별개 조직
> 무인 길드는 실력 등급 중심, 용병 길드는 의뢰 수행 실적 중심

### 경제 관련

| 조직 | 역할 | 정치적 위치 |
|------|------|-----------|
| 상인 연합 | 교역로 관리·상인 신원 보증·분쟁 조율 | 명목 중립. 실제론 이해관계 복잡 |
| 마정석 거래소 | 마정석 등급 감정·공식 시세·거래 중개 | 명목 중립. 경제 권력과 유착 |
| 장인 조합 | 장인 기술 인증·기술자 등록 | 드워프 주도. 드워프 이익 우선 |

### 정보 관련

| 조직 | 역할 | 정치적 위치 |
|------|------|-----------|
| 정보 거래소 | 정보 수집·판매·중개 | 명목 중립. 실제론 가장 정치적 |
| 탐문사 조합 | 수배·추적·조사 전문 인력 중개 | 정보 거래소 연계. 조직마다 다름 |

### 종교 관련

| 조직 | 역할 | 정치적 위치 |
|------|------|-----------|
| 교단 | 신앙 유지·신성력 사용자 관리·성기사 육성 | 조직마다 극단적으로 다름 |
| 이단 심문소 | 공인 교단 외 신앙·술식 단속 | 교단 산하. 권력 남용 경향 |

---

## 조직의 정치적 위치 유형

| 유형 | 설명 |
|------|------|
| 실질 중립 | 정치적 줄 서지 않음. 의뢰인·고객 가리지 않음 |
| 명목 중립 | 중립 표방하나 내부 이해관계 존재 |
| 명확한 편향 | 특정 국가·세력·종족과 연계 |

---

## 조직 간 공통 불문율

| 불문율 | 내용 |
|--------|------|
| 의뢰인 비밀 보장 | 정보 조직 중심. 어기면 조직 신용 붕괴 |
| 등급 위조 금지 | 발각 시 해당 조직 전체 등급 정지 |
| 조직 간 분쟁 금지 | 조직 간 무력 충돌은 금기 |
| 민간인 피해 최소화 | 용병·무인 의뢰 수행 시 기준 |

> 불문율 강제 집행 기관 없음
> 어긴 조직·개인은 다른 모든 조직에서 배척당하는 구조로 자율 유지

## 조직 등록·활동 절차

### 개인 등록

| 절차 | 내용 |
|------|------|
| **신원 확인** | 이름·종족·출신지·에테르 여부 확인 |
| **능력 측정** | 무인 길드 등급 측정. 마법사는 마법사 협회 심사 |
| **등록비** | 조직별 상이. 금화 1~50 수준 |
| **대륙 이동 시** | 해당 대륙 조직에 재등록 필요. 타 대륙 등급증 제출 시 절차 간소화 |

### 의뢰 등급 기준

| 의뢰 등급 | 수임 자격 | 보수 기준 |
|----------|----------|----------|
| **일반** | 등록자 전원 | 금화 1~20 |
| **중급** | 엘리트 하 이상 | 금화 20~200 |
| **고급** | 엑스퍼트 하 이상 | 금화 200~협상 |
| **특급** | 엑스퍼트 중 이상 또는 특별 추천 | 협상. 국가 단위 의뢰 |
