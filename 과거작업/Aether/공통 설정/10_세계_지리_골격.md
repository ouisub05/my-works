# 세계 지리 골격

## 기본 설정

- 실제 지구와 지형·모양 동일
- 문화권 모티프만 차용. 세부는 창작
- 평행세계

---

## 대륙별 개요

### 베스테리아 (유럽)

| 항목 | 내용 |
|------|------|
| **기후** | 온대 중심. 북부 한대, 남부 지중해성 |
| **문화 모티프** | 중세 유럽. 기사도, 교단 문화, 봉건제 |
| **종족 구성** | 인간 다수. 엘프류·드워프 공존. 수인 소수 |
| **패권 구도** | 인간 국가 다수. 일부 지역 엘프 독립 영역 |
| **에테르 기술** | 가장 발달한 대륙 중 하나 |
| **주요 세력** | 12개 세력. 카이저라이히 패권. 상투스임페리움 종교 갈등 |

### 아프라 (아프리카)

| 항목 | 내용 |
|------|------|
| **기후** | 북부 사막, 중부 열대우림, 남부 사바나·온대 |
| **문화 모티프** | 북아프리카(중동·베르베르), 사하라 이남(부족 연합·왕국) |
| **종족 구성** | 인간 다수. 수인 비율 타 대륙 대비 높음 |
| **패권 구도** | 케메트(이집트) 북부 패권. 말리 술탄국 서부 성장 중 |
| **에테르 기술** | 마정석 산지이나 기술력은 중간. 외부 의존도 높음 |
| **특징** | 마물 다발 지대 다수. 마정석 매장량 풍부. 케메트 식량 패권 |
| **주요 세력** | 7개 세력. 케메트 북부 패권. 말리 성장 중 |

### 아시란 (아시아)

| 항목 | 내용 |
|------|------|
| **기후** | 다양. 동부 온대·냉대, 남부 열대·아열대, 중부 대륙성, 서부 건조 |
| **문화 모티프** | 동아시아(동부), 중동·페르시아(서부), 인도(남부), 스텝(중부) |
| **종족 구성** | 가장 다양. 인간·수인·엘프류·드워프 모두 존재 |
| **패권 구도** | 3강(아르다샤르·중위안·마루한) 패권 경쟁. 텡그리 신흥 강국 |
| **에테르 기술** | 지역 편차 극심. 마루한 독자 기관 기술 주목 |
| **특징** | 실크로드 교역 핵심 대륙. 세계 최대 세력 수 |
| **주요 세력** | 15개 세력. 서부·중부·동부 3권역 |

### 노르테라 (북아메리카)

| 항목 | 내용 |
|------|------|
| **기후** | 북부 한대·냉대, 중부 온대, 남부 아열대·건조 |
| **문화 모티프** | 북미 원주민 문화. 부족 연합·자연 신앙 중심 |
| **종족 구성** | 수인 비율 높음. 인간·엘프류 공존 |
| **패권 구도** | 와바나키 공화국 동부 패권. 테노치 제국 남부 강세 |
| **에테르 기술** | 독자 발전. 외부와 기술 체계 다소 다름 |
| **특징** | 포르타 콘소르티움 접근 중(극비). 정령 신앙 강함 |
| **주요 세력** | 8개 세력 |

### 수르테라 (남아메리카)

| 항목 | 내용 |
|------|------|
| **기후** | 북부·중부 열대우림, 서부 고산, 남부 온대·한대 |
| **문화 모티프** | 아즈텍·잉카·마야. 고산 문명·밀림 문명 |
| **종족 구성** | 인간 다수. 수인·엘프류 일부 |
| **패권 구도** | 타완틴 제국 쇠퇴 중. 무이스카 성장. 투피 밀림 장악 |
| **에테르 기술** | 고대 유물 활용 기술 독자 발전. 외부와 체계 이질적 |
| **특징** | 고대 유물·유적 밀집. 단절 이전 흔적이 가장 많이 남은 대륙 |
| **주요 세력** | 7개 세력 |

### 오세라 (오세아니아)

| 항목 | 내용 |
|------|------|
| **기후** | 중부 건조·사막, 북부 열대, 남부·동부 온대 |
| **문화 모티프** | 오세아니아·폴리네시아. 해양 문화·부족 사회 |
| **종족 구성** | 인간 다수. 수인 일부 |
| **패권 구도** | 쿠린 연합 최대 세력. 단일 패권 없음 |
| **에테르 기술** | 낮은 편. 해양·항법 기술 독자 발전 |
| **특징** | 세계에서 가장 고립된 대륙. 마우이 해연 노르테라 탐험 중 |
| **주요 세력** | 5개 세력 |

## 대륙 간 교류

| 교류 축 | 수준 | 비고 |
|---------|------|------|
| **베스테리아 ↔ 아시란** | 활발 | 실크로드. 솔다텐라트 접경 |
| **베스테리아 ↔ 아프라** | 활발 | 포르타 콘소르티움 독점 |
| **아시란 ↔ 아프라** | 중간 | 바라타·자한 인도양 루트 |
| **아시란 ↔ 오세라** | 중간 | 누산타라·파푸아 경유 |
| **베스테리아 ↔ 노르테라** | 극히 일부 | 포르타 극비 접촉 중 |
| **노르테라 ↔ 수르테라** | 중간 | 테노치·칠람 접경. 무이스카·타이노 교역 |
| **수르테라 ↔ 오세라** | 소규모 | 태평양 해로 |
| **오세라 ↔ 노르테라** | 극히 일부 | 마우이 탐험대 접근 중 |

## 세계 지리 핵심 포인트

| 포인트 | 내용 |
|--------|------|
| **고대 유물 밀집** | 수르테라 중심. 테노치 영역·칠람 동맹 주변 |
| **마정석 주산지** | 아프라(말리·움코시), 아시란 일부, 아우카 부족연(미확인) |
| **마물 다발 지대** | 아프라 중부, 아시란 고원·밀림, 노르테라 북부, 이스칼드 분트 |
| **에테르 사용 마물** | 전 대륙 증가 추세. 원인 불명. 세계적 이상 징후 |
| **정령 신앙 강세** | 노르테라·오세라·아시란 일부·이스칼드 분트 |
| **에테르 기술 선진** | 베스테리아·아시란 동부(마루한)·아시란 서부(아르다샤르) |
| **고립 문화권** | 오세라(야라·알체라), 에이렌발트, 수르테라 일부 |
| **외부 접촉 변수** | 포르타의 노르테라 접근. 마우이의 노르테라 접근. 동서 동시 진행 중 |
