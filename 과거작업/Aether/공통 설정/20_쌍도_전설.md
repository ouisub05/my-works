# 쌍도 전설

## 쌍도란

| 항목 | 내용 |
|------|------|
| **정의** | 무인(신체 내부 에테르 강화)과 마법사(외부 에테르 축적·술식 연산)를 동시에 완전히 운용하는 경지 |
| **현재 상태** | 완전 쌍도·부분 쌍도 모두 현재 달성 사례 없음 |
| **기술적 문제** | 내부 에테르 강화와 외부 에테르 연산은 서로 간섭. 동시 운용 시 에테르 흐름 충돌 발생 |
| **위상** | 에테르 사용자 사이에서 **도달할 수 있는 최고의 경지**로 인식 |

---

## 왜 불가능한가

### 에테르 충돌 원리

| 항목 | 내용 |
|------|------|
| **무인 에테르 방향** | 내부로 집중·순환. 신체 강화 특화 |
| **마법사 에테르 방향** | 외부로 방출·조작. 술식 연산 특화 |
| **충돌 현상** | 동시 운용 시 두 흐름이 충돌. 에테르 과부하 즉시 발생 |
| **현재 시도 결과** | 과부하 3~4단계 즉각 발생. 생명 위협 수준 |

> **"물이 동시에 두 방향으로 흐를 수 없듯. 에테르도 마찬가지다"**
> 마기스테리움 에테르 이론학과의 공식 입장

## 고대 기록

### 현존 기록

| 기록 | 출처 | 내용 | 신뢰도 |
|------|------|------|--------|
| **강티세 동굴 기록** | 강티세 동맹 (비공개) | 쌍도 수련자 존재 언급. 상세 불명 | 미확인 |
| **수르테라 석판** | 칠람 동맹 발굴 (해독 중) | 특정 인물이 에테르를 내외로 동시 다뤘다는 구절 | 해독 불완전 |
| **드워프 고문서** | 우르그룬트 (비공개) | 쌍도와 유사한 에테르 운용 방식 언급 추정 | 드워프 측 부인 |
| **마기스테리움 고문헌** | 마기스테리움 지하 서고 | 고대 에테르 사용자 일부가 내외 에테르 동시 운용 시도 기록 | 낮음. 과장 의심 |

### 기록의 한계

| 한계 | 내용 |
|------|------|
| **해독 불완전** | 대부분 고대 문자. 완전 해독 불가 |
| **과장·왜곡 가능성** | 구전에서 문자로 옮기며 과장됐을 가능성 |
| **맥락 손실** | 기록 전후 맥락 소실로 정확한 의미 해석 어려움 |
| **목격자 없음** | 현재 살아있는 자 중 쌍도 목격자 전무 |

> 마기스테리움 내부에서도 **"기록이 실제인지 상징적 표현인지"** 논쟁 중
> 강티세 동맹이 보유한 기록이 가장 구체적이라는 소문. 강티세는 공개 거부

## 쌍도에 대한 각 세력의 인식

| 세력 | 인식 | 태도 |
|------|------|------|
| **마기스테리움** | 이론적 불가능. 그러나 연구 가치 있음 | 공식 부정. 비공식 연구 진행 |
| **강티세 동맹** | 가장 깊은 정보 보유 추정. 태도 불명 | 완전 침묵. 질문 자체를 거부 |
| **무인 길드** | 도달할 수 없는 이상. 그러나 목표로 삼는 것을 금지 안 함 | 관심 있으나 공식 입장 없음 |
| **룩스 교단** | 신성력+에테르 융합이 쌍도의 다른 형태라는 해석 | 독자적 해석. 에테르 쌍도와는 다른 개념으로 봄 |
| **케메트 신관 회의** | 파라오 초기 선조가 쌍도 사용자였다는 교리 | 신앙으로 승화. 재현 시도 없음 |
| **야마토 막부** | 검술 유파 중 쌍도를 수련 최종 목표로 삼는 곳 있음 | 일부 유파에서 적극 연구 |
| **마루한 제국** | 군사적 관점에서 관심. 에테르 기관 기술과 결합 가능성 탐구 | 비공식 연구 중 |

## 쌍도 연구 현황

### 주요 연구 집단

| 집단 | 접근 방식 | 현재 성과 |
|------|----------|----------|
| **마기스테리움 혼합 문파** | 에테르 이론·술식 체계 통해 충돌 완화 연구 | 충돌 최소화 기법 일부 개발. 쌍도 미달 |
| **강티세 혼합 문파** | 내공+술식 병행 수련. 쌍도에 가장 근접했다는 소문 | 미확인. 공개된 성과 없음 |
| **야마토 뇌신류** | 에테르 속도 극한화로 내외 전환 빠르게 하는 방식 | 전환 속도 향상. 동시 운용은 아님 |

### 연구의 벽

| 벽 | 내용 |
|----|------|
| **에테르 충돌 근본 문제** | 내외 에테르 흐름 방향 자체가 반대. 근본적 해결책 불명 |
| **과부하 리스크** | 연구 중 에테르 과부하 4단계 사례 다수. 연구자 사망·영구 불능 |
| **기록 부재** | 고대 기록이 구체적 방법론을 담고 있지 않음 |
| **강티세 침묵** | 가장 앞선 것으로 추정되는 강티세가 정보 공유 완전 거부 |

## 희망의 전설로서의 쌍도

### 에테르 사용자 사회에서의 의미

| 의미 | 내용 |
|------|------|
| **최고의 경지** | 무인도 마법사도 아닌 **"에테르를 완전히 다루는 자"** 의 상징 |
| **동기 부여** | 달성 불가능하지만 그 방향으로 수련하는 것이 더 강해지는 길 |
| **전설의 힘** | "과거에 누군가 했다면 언젠가 다시 할 수 있다"는 희망 |
| **사회적 기능** | 무인·마법사 간 대립을 넘어 공통의 목표로 작용 |

### 쌍도와 관련된 속설

| 속설 | 내용 | 사실 여부 |
|------|------|----------|
| **쌍도 달성 시 초월자 자동 등극** | 쌍도 달성자는 9단계 초월자를 넘어선다는 설 | 불명 |
| **쌍도와 에테르 사용 마물** | [E] 마물이 쌍도에 근접한 에테르 운용을 한다는 관찰 | 일부 연구자 주목 중. 결론 없음 |
| **강티세 은둔 고수** | 강티세 어딘가에 쌍도 달성자가 숨어 있다는 전설 | 전설·소문 수준. 목격 사례 없음 |
| **고대 쌍도 유물** | 쌍도 달성자가 만든 유물이 수르테라 어딘가에 있다는 설 | 칠람 동맹이 탐사 중. 미발견 |

## 쌍도와 현재 세계의 연결

| 연결 고리 | 내용 |
|----------|------|
| **[E] 마물** | 에테르 사용 마물의 운용 방식이 쌍도와 유사하다는 분석. 인위적 개입의 목적이 쌍도 재현 시도일 가능성 제기 |
| **고대 유물 에테르 패턴** | 일부 고대 유물에서 내외 에테르 동시 각인 흔적 발견. 고대에 일부 성공했을 가능성 |
| **강티세의 침묵** | 쌍도에 대해 가장 잘 아는 집단이 침묵하는 이유가 무엇인가 — 세계관 미스터리 |
