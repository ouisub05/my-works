# 마물 공통 설정

## 마물의 본질

- 마물은 종족과 **별개로 원래부터 존재하던 생명군**
- 에테르와 본래 무관했으나 **최근 들어 에테르를 활용하는 마물이 출현** 중
  - 세계관 내에서 이상 징후로 인식. 원인 불명
  - 학자·국가 차원에서 조사 중이나 결론 없음
  - 단순한 자연 변화인지, 누군가 의도한 것인지 미지수

---

## 마물과 종족의 구분

| 항목 | 종족 | 마물 |
|------|------|------|
| 언어·의사소통 | 가능 | 불가 (예외적 지능형 마물 존재) |
| 사회·문화 | 존재 | 없음 |
| 공존 가능성 | 가능 | **원칙적 불가** |
| 에테르 구조 | 안정적 | 불안정 또는 이질적 |

> 공존 불가 — 마물은 협상·회유·교화 불가. 조우 시 기본 원칙은 격퇴 또는 회피

---

## 마물 도감

각 세력이 독자적으로 편찬. 공통 수록 항목:

| 항목 | 내용 |
|------|------|
| 명칭 | 지역마다 다른 이름 병기 |
| 외형 | 삽화 포함 |
| 위험 등급 | 개체·집단 등급 병기 |
| 서식지 | 지역별 분포 |
| 특성·약점 | 에테르 사용 여부, 유효한 대처법 |
| 비고 | 목격담, 미확인 정보 등 |

## 마물 발생

### 자연 발생
- 오래전부터 세계 곳곳에서 자연히 출현
- **마물 다발 지대** 존재 — 인간이 정착하기 어렵거나 포기한 지역
- 계절·기후·에테르 농도와 연관성 있다는 학설 존재. 미확인

### 인위적 생성

| 주체 | 목적 |
|------|------|
| 일부 마법사·흑마술사 | 연구, 실험, 개인 무기 |
| 특정 군사 세력 | 전쟁 병기 |
| 불명의 세력 | 미지. 최근 에테르 사용 마물과 연관 의혹 |

> 인위적 생성은 대부분의 국가에서 **금지**

## 마물 등급 체계

총 10단계.

| 등급 | 명칭 | 대응 전투 직군 | 비고 |
|------|------|--------------|------|
| 1등급 | 잡급(雜級) | 범인 단독 대응 가능 | 고블린·좀비 등 |
| 2등급 | 하급(下級) | 어뎁트 하~중 단독 | 오크·늑대 마수 등 |
| 3등급 | 중하급(中下級) | 어뎁트 상~엘리트 하 단독 또는 어뎁트 파티 | 트롤·미노타우로스 등 |
| 4등급 | 중급(中級) | 엘리트 하~중 단독 또는 어뎁트 상 파티 | 오우거·와이번 등 |
| 5등급 | 중상급(中上級) | 엘리트 중~상 단독 또는 엘리트 하 파티 | 특수 마물·아종 |
| 6등급 | 상급(上級) | 엘리트 상~엑스퍼트 하 단독 또는 엘리트 중 파티 | 강화형 마물 |
| 7등급 | 고급(高級) | 엑스퍼트 하~중 단독 또는 엘리트 상 정예 파티 | 드래곤 하위권 |
| 8등급 | 위급(危級) | 엑스퍼트 중~상 단독 또는 엑스퍼트 하 파티 | 드래곤 상위권 |
| 9등급 | 재앙급(災殃級) | 마스터 하 단독 또는 엑스퍼트 상 복수 | 알파 드래곤 등 |
| 10등급 | 멸세급(滅世級) | 마스터 중 이상 또는 이론상 초월자급 | 전 세계 연합도 불확실 |

> 드래곤은 개체에 따라 7~9등급 사이
> 10등급은 현재 시점 미확인

## 마물 등급 vs 전투 직군 등급 연동 기준

### 기본 원칙

| 원칙 | 내용 |
|------|------|
| **등급 동급** | 마물 N등급 ↔ 전투 직군 N단계가 기준 전투 상대 |
| **+1 우위** | 마물 N등급 상대로 N+1단계 전투 직군이 **안정적** 단독 처리 가능 |
| **-1 열세** | N-1단계 전투 직군은 N등급 마물에게 단독 전투 위험 |
| **파티 보정** | 동급 마물에 대해 파티 3인 편성 시 등급 +1 효과 |
| **[E] 마물** | 동급 [E] 마물은 +1~3등급 마물에 준하여 처리 |

### 구체적 기준

| 마물 등급 | 단독 처리 가능 직군 | 안정적 처리 직군 | 위험 직군 |
|---------|-----------------|---------------|--------|
| **1등급** | 범인 | 어뎁트 하 | 없음 |
| **2등급** | 어뎁트 하 | 어뎁트 중 | 범인 |
| **3등급** | 어뎁트 중~상 | 엘리트 하 | 어뎁트 하 이하 |
| **4등급** | 엘리트 하 | 엘리트 중 | 어뎁트 상 이하 |
| **5등급** | 엘리트 중 | 엘리트 상 | 엘리트 하 이하 |
| **6등급** | 엘리트 상 | 엑스퍼트 하 | 엘리트 중 이하 |
| **7등급** | 엑스퍼트 하 | 엑스퍼트 중 | 엘리트 상 이하 |
| **8등급** | 엑스퍼트 중 | 엑스퍼트 상 | 엑스퍼트 하 이하 |
| **9등급** | 엑스퍼트 상 또는 마스터 하 단독 | 마스터 중 | 엑스퍼트 중 이하 |
| **10등급** | 마스터 중 이상 복수 | 마스터 상·초월자 | 마스터 하 이하 |

### 예외 조건

| 조건 | 내용 |
|------|------|
| **지형 유리** | 해당 마물 서식지에서 전투 시 마물 실질 등급 +1 |
| **약점 활용** | 마물 약점 정확히 공략 시 등급 -1 효과 |
| **직업 아종** | 워로드·샤먼 등 직업 아종은 동급 대비 처리 난이도 상승 |
| **[E] 마물** | 기존 대응법 통하지 않는 경우 있음. 반드시 파티 편성 권장 |
| **야간·기상** | 야간·악천후 시 마물 감지 어려움. 실질 등급 +0.5 취급 |

## 개체·집단 등급 분리

| 유형 | 특징 |
|------|------|
| 군집형 | 개체는 약하나 수십~수백 단위로 몰려다님. 집단 등급 대폭 상승 |
| 무리형 | 소규모 무리. 집단 등급 소폭 상승 |
| 독립형 | 집단 형성 안 함. 개체·집단 등급 동일 |
| 군단형 | 수백~수천 단위. 집단 등급 최대 상승 |

도감 표기 예시: 고블린 [개체 1등급 / 집단 3등급]

---

## 에테르 사용 마물

- 에테르 사용 마물은 동일 종이라도 **등급 상향 조정**
- 도감 표기 시 **[E]** 마크 별도 표기

| 에테르 사용 수준 | 등급 상향 |
|----------------|----------|
| 미약 — 에테르 감응 수준 | +0~1등급 |
| 중간 — 단순 신체 강화 수준 | +1~2등급 |
| 고급 — 술식·마법 수준 | +2~3등급 |
| 불명 — 분석 불가 수준 | 별도 경보 발령 |

---

## 지역별 마물 분포 원칙

- 기반은 서양 판타지 (고블린, 오크, 트롤, 드래곤 등)
- 지역색 반영 — 동양풍 대륙엔 동양 마물, 사막 지역엔 사막 마물 등
- 드래곤은 개체에 따라 7~9등급. 별도 분류
