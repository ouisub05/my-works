# 세계 운영 공통 설정

## 화폐·경제 체계

### 화폐 단위

| 화폐 | 용도 | 비고 |
|------|------|------|
| 금화 | 고액 거래. 세계 공통 통용 | 유일한 세계 공통 화폐 |
| 은화 | 일반 거래. 국가별 발행 | 국가마다 도안·순도 다름 |
| 동화 | 소액 거래. 국가별 발행 | 국가마다 도안·순도 다름 |

> 금화만 세계 공통 — 어느 나라에서든 액면 그대로 통용
> 은화·동화는 타국에서 환전 필요하거나 할인 적용
> 금화 위조는 중형

### 화폐 발행 및 경제 권력

- **국가** — 은화·동화 직접 발행. 세금·관세·군비 등 공식 경제 운영
- **상인 연합** — 금화 순도·중량 검증, 환전·송금 서비스, 마정석 시세 결정, 국가 단위 대출

> 국가가 화폐를 발행하지만 **실질 경제 권력은 상인 연합**
> 전쟁 비용이 필요한 국가가 상인 연합에 손 벌리는 구도 흔함

### 마정석 경제

| 항목 | 내용 |
|------|------|
| 유통 경로 | 채굴 → 마정석 거래소 감정·등급 분류 → 도매 → 소매 상점 |
| 하급 마정석 | 소모품. 일반 상점에서 유통. 서민도 구매 가능 |
| 중급 마정석 | 전문 상점·거래소 중심 유통 |
| 상급 이상 | 경매·국가 간 거래 수준. 일반 유통 없음 |

## 전쟁 규칙

- 명문화된 협약 없음. **불문율**로 존재
- 지키는 국가도 있고 무시하는 국가도 있음
- 강대국이 어겨도 제재할 기관·세력 없음

### 전투원 보호 불문율

| 불문율 | 준수율 |
|--------|--------|
| 항복 인정 — 무장 해제·항복 의사 표시한 자는 즉시 죽이지 않음 | 중간 |
| 포로 대우 — 최소한의 생존 보장. 고문·학대 금지 | 낮음. 타 종족 포로는 무시 많음 |
| 부상자 처리 — 전투 불능 부상자는 공격 대상에서 제외 | 중간 |
| 사절 보호 — 협상·항복 사절은 공격 불가 | 높음. 이것만큼은 대부분 지킴 |
| 독·오염 금지 — 수원·식량 오염 금지 | 낮음 |

### 에테르·마법 관련 불문율

| 불문율 | 준수율 |
|--------|--------|
| 광역 술식 제한 — 도시·민간 거주지 대상 광역 마법 금지 | 낮음 |
| 마물 방사 금지 — 인위적 마물 전장 투입 금지 | 중간 |
| 에테르 오염 금지 — 지역 에테르 구조 영구 파괴 금지 | 높음. 자국도 피해를 보기 때문 |

## 연도·달력 체계

### 기본 구조
- 달력 물리적 구조는 실제 지구와 동일 — 12달, 365일, 24시간, 60분, 60초
- 연도 기준점은 **대륙별 독자 원년** 사용

### 대륙별 달력

| 대륙 | 원년 기준 | 표기 방식 |
|------|----------|----------|
| 베스테리아 | 교단 창설 혹은 최초 통일 왕국 수립 | 왕국력(王國曆) |
| 아시란 | 대륙별 독자 기준 복수 존재 | 국가·왕조별 기년법 |
| 아프라 | 최초 부족 연합 성립 | 연합력(聯合曆) |
| 노르테라 | 자연 순환 기준 | 세대력(世代曆) |
| 수르테라 | 고대 유물 발견·고산 제국 건국 | 제국력(帝國曆) |
| 오세라 | 해양 탐험·항로 개척 기준 | 항해력(航海曆) |

> 대륙 간 교류 시 연도 표기 혼란 — 상인 연합이 공용 환산표 운영

## 언어 체계

### 기본 구조
- 세계 공통 언어 없음
- 대륙마다 주요 언어 다름
- **통상어(通商語)** 가 사실상 국제 공용어 역할

### 통상어

| 항목 | 내용 |
|------|------|
| **기원** | 베스테리아·아시란 서부 교역 과정에서 자연 발생. 수백 년에 걸쳐 정착 |
| **사용 범위** | 교역·외교·용병 계약 등 실용적 소통 |
| **문자** | 상인 연합이 표준화 주도. 로마자 계통 모티프. 단순·실용적 구조 |
| **한계** | 감정·문화·미묘한 뉘앙스 전달 어려움 |
| **보급률** | 도시·항구·교역로 중심. 내륙 오지는 모르는 경우 많음 |
| **방언** | 대륙별 억양·어휘 차이 존재. 소통 가능하나 이질감 있음 |

> 통상어를 모국어처럼 쓰는 집단은 없음. 모두의 제2언어
> 하프 엘프가 통상어 능숙자 비율 가장 높음 — 외교·통역 직종 많은 이유

### 엘프어

| 항목 | 내용 |
|------|------|
| **사용자** | 순혈 엘프·하프 엘프. 다크 엘프는 방언화 진행 |
| **구조** | 복잡한 문법. 시제·감정·에테르 상태를 동시에 표현 |
| **에테르 친화** | 엘프어로 구성된 술식이 자연 에테르와 공명 |
| **희소성** | 인간이 배우기 매우 어려움 |
| **위상** | 학술·마법 연구에서 가치 높음. 고대 유물 해독에 필요한 경우 있음 |
| **방언** | 베스테리아 엘프어 / 틀링깃 다크 엘프어 / 마레 다크 엘프어 등 지역별 방언 존재 |

### 드워프 룬 문자
- 드워프는 거주 지역 언어 사용 — 고유 언어 없음
- 단 고유 **룬 문자 체계** 존재 — 기술 기록·각인 전용
- 드워프 장인들만 사용. 외부에 잘 공개 안 함
- 에테르 각인 효율이 다른 문자 체계보다 높다는 설 있음

### 고대 문자
- 단절 이전 문명의 문자 체계. 현재 해독 불가
- 엘프어·드워프 룬과 부분적으로 유사한 패턴 존재
- 칠람 동맹이 가장 많은 해독 진행. 마기스테리움 연구 중
- 에테르 반응을 포함한 복합 기록 방식. 단순 문자가 아님

## 법·형벌 공통 기준

### 세계 공통 금지 범죄

| 범죄 | 처벌 수준 |
|------|----------|
| 마물 인위 생성 | 중형~사형. 국가 단위 추적 |
| 사절 살해 | 국가 간 전쟁 사유. 가해자 인도 요구 |
| 금화 위조 | 중형. 상인 연합·국가 공동 추적 |
| 마정석 거래소 습격 | 중형. 다수 국가 공동 대응 |
| 에테르 오염 | 중형~사형 |

### 에테르 관련 법 — 공통 조항

| 조항 | 내용 |
|------|------|
| 에테르 폭주 책임 | 제어 실패로 인한 피해는 사용자 책임 |
| 에테르 강제 각성 | 타인에게 강제로 각성 유도 금지. 특히 미성년자 대상 |
| 마정석 불법 거래 | 상급 이상 마정석 무허가 거래 금지 |

### 형벌 체계 공통 유형

| 형벌 | 내용 |
|------|------|
| 벌금 | 경범죄 중심 |
| 노역 | 일정 기간 강제 노동 |
| 추방 | 국가·도시 추방 |
| 투옥 | 중범죄 |
| 에테르 봉인 | 에테르 사용자 범죄자에게 적용. 기술적으로 가능한 국가만 시행 |
| 사형 | 중대 범죄 |

| 유형 | 해당 국가 |
|------|----------|

| 인간 우선 | 인간 패권 국가 다수 |
| 종족별 법체계 | 일부 복합 국가 |
| 노예 무권리 | 노예제 인정 국가 |
