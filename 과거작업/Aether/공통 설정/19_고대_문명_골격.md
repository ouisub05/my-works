# 고대 문명 골격

## 단절 이전 세계 지형

| 항목 | 내용 |
|------|------|
| **대륙 구조** | 판게아 이후 분리 중이었으나 현재보다 훨씬 연결된 상태. 사실상 하나에 가까운 거대 대륙 |
| **현재와 차이** | 단절 시 자연재해(화산·운석)로 지각 변동. 현재 6대륙으로 최종 분리 |
| **교류 방식** | 육로 이동 가능. 대부분 지역이 연결. 해양 기술 없이도 전 세계 교류 가능 |
| **에테르 흐름** | 현재보다 안정적이고 강한 에테르 흐름. 대륙 연결 지점에 에테르 밀집 |

## 고대 문명 구조

### 기본 구조 — 복수 문명

단절 이전 단일 통합 문명은 없었음. 지역별 복수 문명이 교류·경쟁하며 공존.

| 문명권 | 대략적 위치 | 특징 |
|--------|-----------|------|
| **북방 문명** | 현재 베스테리아·아시란 북부 | 거대 건축·에테르 증폭 구조물 특화 |
| **남방 문명** | 현재 아프라·아시란 남부·수르테라 | 제사·의식 중심. 거대 제단 건축 |
| **해안 문명** | 현재 동남아·오세라 일부 | 교역·항해 중심. 장신구 에테르 기술 특화 |
| **내륙 문명** | 현재 아시란 중부·노르테라 | 소규모 분산. 자연 에테르 활용 |

> 문명권 간 경계는 현재처럼 명확하지 않았음
> 교역·전쟁·혼혈로 문화 혼합 광범위하게 발생
> 단절 이후 각 문명권이 고립되며 현재 각 대륙 문화의 기원이 됨

## 고대 에테르 기술 방향

### 거대 구조물

| 구조물 | 기능 | 현존 여부 |
|--------|------|----------|
| **에테르 증폭탑** | 지역 에테르 흐름 집중·증폭. 농업·건축·방어 활용 | 수르테라·아프라 일부 잔존 |
| **제사 피라미드** | 신성력·에테르 의식 장소. 대규모 에테르 방출 가능 | 수르테라·노르테라 다수. 아프라 일부 |
| **에테르 관개 시스템** | 대규모 농업용 에테르 수로. 지하 구조물 | 케메트 나일강 유역 일부 기능 유지 |
| **방어 결계 유적** | 도시 전체를 감싸는 에테르 결계 잔해 | 대부분 기능 정지. 잔해만 현존 |

### 장신구·소형 에테르 기술

| 품목 | 기능 | 현존 여부 |
|------|------|----------|
| **에테르 각인 장신구** | 착용자 능력 강화·보호·감지. 현재 마정석보다 효율 높음 | 희소. 유적 발굴 시 간헐적 출토 |
| **에테르 통신 구슬** | 장거리 에테르 신호 송수신. 현재 기술로 복제 불가 | 전 세계 극소수. 국보급 취급 |
| **에테르 저장 용기** | 에테르를 액체 형태로 저장. 현재 마정석과 다른 방식 | 미발굴 추정 다수. 확인된 것 소수 |
| **치유 부적** | 신성력·에테르 융합 치유 장신구. 자동 발동 | 발굴 사례 있으나 대부분 에테르 고갈 |

### 제사·의식 에테르

| 항목 | 내용 |
|------|------|
| **집단 의식** | 다수가 동시에 에테르·신성력 방출하는 대규모 의식 |
| **제물 에테르** | 생명 에테르를 의식에 활용. 현재 금지 기술 |
| **별자리 에테르** | 천체 배열에 따라 에테르 흐름 강화. 특정 시기에만 작동하는 유물 다수 |
| **현재 재현 가능성** | 의식 방식은 일부 교단에서 보존. 규모와 효과는 현재 재현 불가 |

## 대륙별 고대 유물 현황

### 수르테라 — 밀집 지역

| 항목 | 내용 |
|------|------|
| **현황** | 전 세계 고대 유물 최대 밀집. 단절 충격이 상대적으로 약했던 지역 |
| **주요 유물** | 피라미드형 에테르 증폭 구조물. 에테르 각인 장신구. 미해독 문자 석판 |
| **연구 주체** | 칠람 동맹(학술 연구). 테노치 제국(실용 활용) |
| **위험 요소** | 고대 유물 주변 마물 다발. [E] 마물 출현 증가와 연관 의심 |

### 아프라 — 중간 밀도

| 항목 | 내용 |
|------|------|
| **현황** | 케메트 나일강 유역에 일부 기능 유지 유물. 누베트 지하 유적 |
| **주요 유물** | 에테르 관개 시스템(부분 기능). 신전 에테르 증폭 구조물. 오벨리스크 |
| **연구 주체** | 케메트 신관 회의(신성시·선택적 활용) |
| **특이사항** | 케메트 신관들이 고대 에테르 기술을 신성력으로 오해하는 경우 있음 |

### 베스테리아 — 희소

| 항목 | 내용 |
|------|------|
| **현황** | 단절 충격 최대 지역 중 하나. 대부분 파괴·매몰 |
| **주요 유물** | 에이렌발트 심부 고대 엘프 유적. 마기스테리움 지하 발굴 유물 소수 |
| **연구 주체** | 마기스테리움(적극 연구). 에이렌발트(봉인·접근 금지) |
| **특이사항** | 에이렌발트가 고대 유적을 엘프 성지로 봉인. 외부 접근 차단 |

### 아시란 — 분산

| 항목 | 내용 |
|------|------|
| **현황** | 강티세 동맹 고산 동굴에 고대 기록 일부 보존. 아르다샤르 지역 유적 소수 |
| **주요 유물** | 강티세 고산 에테르 증폭 잔해. 고대 통신 구슬 1개(강티세 보유 추정) |
| **연구 주체** | 강티세 동맹(비공개). 마루한(발굴 시도) |
| **특이사항** | 강티세 동맹이 보유한 고대 기록 내용 극비. 외부에 단 한 줄도 공개 안 함 |

### 노르테라 — 중간 밀도

| 항목 | 내용 |
|------|------|
| **현황** | 테노치 제국 영역 내 고대 제사 유적 다수. 수르테라 문명과 연결된 것으로 추정 |
| **주요 유물** | 고대 제사 피라미드. 에테르 수호자 마물(유적 자동 방어 시스템) |
| **연구 주체** | 테노치 제국(적극 발굴·활용). 칠람 동맹(접경 지역 공동 연구 시도) |
| **특이사항** | 일부 유물에서 [E] 마물과 유사한 에테르 패턴 감지. 원인 불명 |

### 오세라 — 극희소

| 항목 | 내용 |
|------|------|
| **현황** | 지각 변동으로 대부분 해저 수몰 추정. 지상 유물 극히 드묾 |
| **주요 유물** | 알체라 부족연 드림타임 성지에 고대 에테르 반응 존재. 미발굴 |
| **연구 주체** | 없음. 알체라 접근 금지로 조사 불가 |
| **특이사항** | 알체라 꿈의 장로들이 드림타임을 통해 고대 기억 일부 접근 가능하다는 전설 |

## 고대 문자·기록

| 항목 | 내용 |
|------|------|
| **현존 기록** | 수르테라 석판. 강티세 동굴 기록. 드워프 지하 고문서 일부 |
| **해독 현황** | 칠람 동맹이 가장 앞섬. 일부 패턴 파악. 완전 해독 불가 |
| **언어 특성** | 에테르 반응 포함된 문자. 단순 문자가 아닌 술식과 결합된 기록 방식 |
| **드워프 고문서** | 드워프가 보유한 고대 기록 일부. 내용 비공개. 현재 드워프 기술의 일부 기원 가능성 |

| **강티세 극비 기록** | 강티세 동맹이 보유한 고대 기록의 내용 | 강티세가 절대 공개 거부 |
