# 마물 도감 — 아시란 특별 마물

## 개요

아시란에만 서식하는 고유 마물. 고원·밀림·사막·한대 지대 중심.

---

## 1. 고원 봉황수(鳳凰獸)

| 항목 | 내용 |
|------|------|
| **등급** | 6등급 |
| **서식지** | 강티세 동맹 고산 지대 |
| **신체** | 대형 조류형 마물. 화염 깃털. 고산 환경 특화 |
| **특징** | 화염 브레스. 사망 후 화염 폭발 재생. 고산 에테르 흡수로 강화 |
| **약점** | 냉기. 재생 중 취약 |
| **소재 가치** | 화염 깃털(고급 화염 술식 재료). 불사 심장(재생 에테르 연구 재료) |
