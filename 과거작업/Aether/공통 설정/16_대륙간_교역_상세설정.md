# 대륙간 교역 상세설정

## 교역 체계 개요

| 항목 | 내용 |
|------|------|
| **교역 중심 대륙** | 베스테리아·아시란. 가장 활발한 교류 |
| **교역 고립 대륙** | 오세라·노르테라·수르테라. 외부 교류 제한적 |
| **핵심 교역품** | 마정석·향신료·금·에테르 기술 제품·식량·마물 소재 |
| **교역 언어** | 통상어(공용어). 대규모 교역에서 표준 사용 |

## 주요 교역 루트

### 1. 북방 육로 (실크로드 주축)

| 항목 | 내용 |
|------|------|
| **경로** | 베스테리아 동부 → 솔다텐라트 → 다슈트 연합 → 텡그리 칸국 → 마루한 제국 |
| **주요 교역품** | 베스테리아 에테르 제품·무기 ↔ 아시란 비단·도자기·마정석 |
| **통제 세력** | 다슈트 연합(통행세). 텡그리 칸국(위협·압박) |
| **장점** | 육로. 기동성 높음. 마물 위협 낮음 |
| **단점** | 날씨 변수 큼. 텡그리 불안정으로 통행 위험 증가 |
| **통행세** | 다슈트 연합 구간별 금화 5~50. 텡그리 구역 비공식 통행료 |

### 2. 남방 해로 (인도양 루트)

| 항목 | 내용 |
|------|------|
| **경로** | 아프라 동부(자한) → 바라타 연방 → 누산타라 동맹 → 하이둥 상방 |
| **주요 교역품** | 향신료·커피·금 ↔ 에테르 제품·비단·마정석 가공품 |
| **통제 세력** | 바라타 연방(향신료 독점). 누산타라(동남아 해로 분점) |
| **장점** | 물동량 최대. 다품목 교역 가능 |
| **단점** | 해적·해양 마물 위협. 계절풍 영향 |
| **포르타 견제** | 베스테리아 직거래 차단 시도. 항로 해적 사주 의혹 |

### 3. 아라비아 루트

| 항목 | 내용 |
|------|------|
| **경로** | 알-티자라 왕국 → 아르다샤르 제국 → 솔다텐라트 → 베스테리아 |
| **주요 교역품** | 유향·진주·아라비아 특산물 ↔ 베스테리아 제품 |
| **통제 세력** | 알-티자라·아르다샤르 공동 |
| **특징** | 베스테리아와 아시란 서부의 직접 연결 루트 |

### 4. 아프라-베스테리아 루트

| 항목 | 내용 |
|------|------|
| **경로** | 아프라 말리 → 포르타 콘소르티움 → 베스테리아 전역 |
| **주요 교역품** | 금·마정석 원석·아프라 특산물 ↔ 에테르 기술 제품·무기 |
| **통제 세력** | 포르타 콘소르티움 독점 |
| **긴장 요소** | 말리 술탄국 독자 루트 개척 시도. 자한과 연계 가능성 |

### 5. 동해 루트

| 항목 | 내용 |
|------|------|
| **경로** | 하이둥 상방 → 고리 왕국 → 야마토 막부 |
| **주요 교역품** | 도자기·비단·에테르 제품 ↔ 마루한 기관 제품·야마토 철강 |
| **통제 세력** | 마루한·하이둥 암묵적 분점 |
| **긴장 요소** | 야마토 팽창으로 해로 통제권 분쟁 가능성 증가 |

### 6. 북방 모피 루트

| 항목 | 내용 |
|------|------|
| **경로** | 타이가 부족연 → 마루한 제국 → 하이둥 상방 |
| **주요 교역품** | 모피·한대 마물 소재·희귀 광물 ↔ 식량·에테르 제품 |
| **통제 세력** | 마루한 제국 중개 |
| **특징** | 소규모. 희귀 한대 자원 특화 |

## 교역 독점 구조

| 독점 | 세력 | 내용 | 도전 세력 |
|------|------|------|----------|
| **아프라 마정석·금** | 포르타 콘소르티움 | 말리→베스테리아 유통 독점 | 말리 술탄국 직거래 시도 |
| **향신료** | 바라타 연방 | 세계 향신료 생산 압도적 비중 | 누산타라 일부 생산 |
| **드워프 기술 가공** | 우르그룬트 | 최고급 마정석 가공·룬 각인 | 마기스테리움 자체 연구 중 |
| **동부 해로** | 마루한·하이둥 분점 | 동아시아 해상 교역 | 야마토 팽창으로 도전 |
| **실크로드 통행세** | 다슈트 연합 | 북방 육로 통행세 징수 | 텡그리 칸국 강탈 |

## 교역 분쟁·긴장 포인트

| 분쟁 | 당사자 | 현재 상태 |
|------|--------|----------|
| **아프라 직거래** | 말리 vs 포르타 | 말리·자한 연계 인도양 루트 개척 중 |
| **향신료 루트** | 바라타·자한 vs 포르타 | 베스테리아 직거래 시도. 포르타 견제 |
| **동부 해로** | 마루한·하이둥 vs 야마토 | 야마토 팽창으로 3자 긴장 |
| **북방 육로** | 다슈트 vs 텡그리 | 텡그리 통행세 강탈. 루트 불안정 |
| **마레 vs 포르타** | 지중해 교역로 패권 | 이면 경쟁. 표면 협력 |
| **커피 루트** | 자한 vs 포르타 | 커피 베스테리아 직수출 시도 |
