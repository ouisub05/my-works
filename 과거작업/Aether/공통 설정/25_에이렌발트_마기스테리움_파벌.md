# 에이렌발트·마기스테리움 내부 파벌 상세

---

## 에이렌발트 파벌 구도

### 개요

에이렌발트는 표면상 군주 1인 체제이나 내부적으로 **순혈 강경파 vs 외교 온건파** 2파벌 구도.
군주는 강경파 수장. 외교파 왕족은 왕족 신분으로 숙청 불가. 두 파벌 모두 순혈 엘프 우월성 자체는 부정하지 않음.
핵심 쟁점: **생존 방법론** — 고립으로 버틸 것인가, 선택적 외교로 압박을 완화할 것인가.

---

### 파벌 1 — 순혈 강경파

| 항목 | 내용 |
|------|------|
| **수장** | 군주 |
| **핵심 인물** | 군주·강경파 전사(궁수) |
| **지지 기반** | 귀족 고위층 다수. 오래된 혈통 명가. 전통 수호 의식 강한 장로층 |
| **핵심 이념** | 순혈 엘프 혈통 순수 보전이 에이렌발트 존재 이유. 외부 접촉은 오염의 시작 |
| **외부 정책** | 카이저라이히·실바 아르카나 모두 적대. 접촉 자체 거부 |
| **강점** | 위원회 다수파. 군주 권위 기반 강고. 전통 수호 명분 |
| **약점** | 외부 압박 장기화 시 대응 수단 없음. 군사력만으로 한계 |

#### 이념 상세
- 순혈 엘프는 에테르 친화도·수명·감각 능력에서 타 종족보다 우월하다는 사실을 정치적 논리로 활용
- 실바 아르카나를 엘프 문화 배신·오염의 상징으로 규정. 하프 엘프 왕 체제를 인정하면 에이렌발트 정체성 붕괴 시작
- 카이저라이히 제국 압박에 대해 삼림 방어가 충분하다는 입장. 총사령관의 방어 역량 신뢰
- 강경파 전사(궁수)를 순혈 엘프 전투 우월성의 살아있는 증거로 상징화

#### 내부 균열
- 군주: 정치적 계산 능력 있음. 외교파를 숙청 않고 협상 카드로 보유
- 강경파 전사: 정치 논리 이해 못함. 충동적 행동이 군주 방침과 충돌 가능성
- 장기 고립으로 인한 자원·인력 감소 현실. 일부 하위 귀족층 불만 누적

---

### 파벌 2 — 외교 온건파

| 항목 | 내용 |
|------|------|
| **수장** | 외교파 왕족 |
| **핵심 인물** | 외교파 왕족·총사령관(비공식 우호) |
| **지지 기반** | 접경 귀족. 외부 정보 접한 중견 엘프. 생존 현실주의자 |
| **핵심 이념** | 순혈 엘프 우월성은 인정. 단 고립이 아닌 선택적 외교로 그 우월성을 더 오래 유지 가능 |
| **외부 정책** | 실바 아르카나와 학술 교류 허용. 카이저라이히와 최소한의 협약. 마기스테리움과 비공식 접촉 |
| **강점** | 외부 세계 정보 우위. 왕족 신분으로 숙청 불가 |
| **약점** | 위원회 소수파. 강경파에게 배신자 이미지. 군주 의심 받음 |

#### 이념 상세
- 순혈주의를 포기하자는 것이 아님. 고립으로 결국 쇠약해지는 것이 더 큰 위협이라는 논리
- 실바 아르카나와 학술 교류: 하프 엘프 에테르 연구 결과를 역으로 활용해 순혈 엘프 우월성 재확인 가능
- 카이저라이히 협약: 군사 충돌 비용을 외교 비용으로 전환. 삼림 방어선 유지 보완
- 총사령관의 군사적 현실론과 암묵적 공감대 형성

#### 내부 균열
- 외교 범위에 대한 이견. 일부는 마기스테리움까지 허용 주장. 일부는 실바 아르카나 한정
- 외교파 왕족이 순혈주의를 진심으로 믿는지 파벌 내에서도 의문 있음

---

### 총사령관의 위치

순혈주의 강경파 소속이나 외교파 주장을 군사 전략 관점에서 이해하는 특수한 위치.
군주 명령에 충성하나 내심 외교파 왕족의 현실론에 공감.
두 파벌 모두 총사령관을 자기편으로 끌어들이려 하나 총사령관은 명시적 입장 표명 거부.
**에이렌발트의 실질적 안정 장치** — 총사령관이 어느 쪽 편도 들지 않는 한 내부 균열이 폭발하지 않음.

---

### 에이렌발트 파벌 관계도

```
군주 (강경파 수장)
├── 강경파 전사 (충성. 통제 어려움)
└── 총사령관 (명령 복종. 내심 중립)

외교파 왕족 (온건파 수장)
└── 총사령관 (비공식 공감대)

강경파 전사 ↔ 외교파 왕족: 직접 충돌 일보 직전
군주 → 외교파 왕족: 협상 카드로 보유. 숙청 않음
```

## 마기스테리움 파벌 구도

### 개요

마기스테리움은 표면상 학술 중립 기관이나 내부적으로 **인간 전용 유지파 vs 개방파** 2파벌 구도.
원장은 중립 유지 원칙. 실질 권력은 부원장(유지파) vs 수석 마법사 교수(개방파) 대립 구도.
핵심 쟁점: **마기스테리움 입학 자격** — 인간 전용 유지 vs 타 종족 개방.

---

### 파벌 1 — 인간 전용 유지파

| 항목 | 내용 |
|------|------|
| **수장** | 부원장 |
| **핵심 인물** | 부원장·보수 교수단 다수 |
| **지지 기반** | 오래된 마기스테리움 교수층. 카이저라이히 귀족 출신 졸업생 네트워크 |
| **핵심 이념** | 인간 에테르 체계가 마기스테리움 연구의 기준. 타 종족 체계 혼입은 학술 정확성 저하 |
| **외부 관계** | 카이저라이히 제국과 졸업생 우선 배치 협약 추진. 에이렌발트 순혈주의와 논리 유사(본인들은 부정) |
| **강점** | 위원회 다수파. 전통·기준 수호 명분. 카이저라이히 외부 지원 가능성 |
| **약점** | 연구 범위 자기 제한. 타 종족 에테르 체계 연구 공백. 원장이 억압하지 않는 한 개방파 성장 막기 어려움 |

#### 이념 상세
- 인간 마법사가 개발한 술식 체계는 인간 에테르 특성에 최적화. 타 종족 에테르 체계를 혼입하면 기존 이론 체계 붕괴 우려
- 마기스테리움 졸업장 가치 하락 경계. 타 종족 입학 허용 시 인간 졸업생 사회적 지위 영향
- 카이저라이히와 관계 강화: 제국이 마기스테리움 졸업생 수요 최대. 현실적 이해관계
- 에이렌발트 순혈주의와 논리 구조 유사하다는 비판에 "학술 기준과 혈통 순수는 다르다"고 반박

#### 내부 균열
- 부원장: 원장이 개방파 논의를 억압하지 않는 것에 불만. 원장 교체 시도 불가(원장 실력이 압도적)
- 카이저라이히 협약이 마기스테리움 학술 중립 원칙 위반 논란. 내부에서도 우려 있음

---

### 파벌 2 — 개방파

| 항목 | 내용 |
|------|------|
| **수장** | 수석 마법사 교수 (비공식. 본인은 정치 진영 혐오) |
| **핵심 인물** | 수석 마법사 교수·개방파 교수·차세대 교수 일부 |
| **지지 기반** | 젊은 교수층. 실전 경험 마법사. 타 종족 에테르 연구자 |
| **핵심 이념** | 에테르 연구는 모든 가능성을 탐구해야 완성됨. 인간 전용 체계는 자기 제한 |
| **외부 관계** | 실바 아르카나 학술원장과 연구 교류. 강티세 동맹 술식 문파와 접촉 시도 |
| **강점** | 연구 성과의 질적 우위. 원장의 묵인. 차세대 교수 양성 중 |
| **약점** | 위원회 소수파. 수석 마법사 교수가 정치 개입 혐오해 파벌 응집력 약함 |

#### 이념 상세
- 하프 엘프·수인 에테르 체계 연구 결과가 기존 인간 에테르 이론의 공백을 채운 사례 존재. 개방 근거
- 타 종족 입학 = 연구 다양성 확대. 마기스테리움이 세계 에테르 연구 허브로 성장 가능
- 실바 아르카나 협력: 하프 엘프 에테르 체계 직접 연구 기회. 개방파 학술 논거 강화
- 수석 마법사 교수의 쌍도 연구: 내공·술식 병행 가능성. 개방파 논리의 극한 형태

#### 내부 균열
- 수석 마법사 교수: 개방파로 분류되지만 정치 진영 논리 혐오. 파벌 수장 역할 거부
- 개방파 교수: 열정적이나 정치력 부족. 단독으론 부원장 당해내기 어려움
- 쌍도 연구를 어디까지 공개할지 이견. 수석 마법사 교수는 원장 묵인 범위 내 유지 원칙

---

### 원장의 위치

마스터 하(10단계). 마기스테리움 실질 상징. 두 파벌 어느 쪽도 원장의 명시적 지지 못 받음.
학술 중립이 원장의 원칙. 그러나 [E] 마물 연구·쌍도 연구팀 묵인 등 실질적으로 개방파에 가까운 행동.
원장이 명시적으로 어느 파벌 지지 선언 시 판도 즉각 결정. 따라서 양측 모두 원장 설득 시도 반복.
**마기스테리움의 실질적 안정 장치** — 원장 중립이 유지되는 한 두 파벌 균형 유지.

---

### 마기스테리움 파벌 관계도

```
원장 (공식 중립. 실질 개방파 친화)
├── 수석 마법사 교수 (신뢰. 연구 파트너)
└── 부원장 (존중. 경직성 인식)

부원장 (유지파 수장)
└── 보수 교수단

수석 마법사 교수 (개방파 비공식 수장. 본인 거부)
└── 개방파 교수 (공식 개방파 대표)

부원장 ↔ 개방파 교수: 위원회 내 반복 충돌
부원장 → 수석 마법사 교수: 견제하나 실력 인정
```

## 두 세력 간 연관 관계

| 관계 | 내용 |
|------|------|
| **에이렌발트 강경파 ↔ 마기스테리움 유지파** | 논리 유사. 직접 협력 없음. 서로 비교 거부 |
| **에이렌발트 외교파 왕족 → 마기스테리움** | 방문 경험. 개방파 교수와 비공식 접촉 가능성 |
| **마기스테리움 개방파 교수 → 실바 아르카나** | 서신 교환. 하프 엘프 에테르 공동 연구 |
| **실바 아르카나 학술원장 ← 에이렌발트 출신** | 에이렌발트 배신자. 마기스테리움과 협력 |
| **마기스테리움 부원장 → 카이저라이히** | 졸업생 배치 협약 추진. 에이렌발트 견제 간접 이해관계 |
| **에이렌발트 총사령관 ↔ 마기스테리움 수석 교수** | 접경 경비 이력 접점. 실력 상호 인지 |

### 외교파-개방파 잠재 연대

에이렌발트 외교파 왕족과 마기스테리움 개방파는 직접 연대 없으나 이해관계 상당 부분 일치.
외교파: 실바 아르카나 학술 교류 허용 → 마기스테리움 개방파와 같은 방향
개방파: 에이렌발트 타 종족 연구 허용 → 외교파가 집권하면 연구 접근성 향상
현재 두 파벌 모두 소수파. 양측이 연대하면 에이렌발트·마기스테리움 각각 내부 판도 변화 가능성.
