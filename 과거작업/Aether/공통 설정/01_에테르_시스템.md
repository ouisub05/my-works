# 에테르 시스템

## 에테르의 존재 형태
- **물질에 깃듦** — 광물, 식물, 일부 동물 등에 농축. 마정석(魔晶石)이 대표적
- **일부 생명체에 깃듦** — 에테르를 체내에 보유한 생명체 존재 (마물, 특수 동물 등)
- **특정 장소엔 흐름** — 유적, 대지의 맥(脈), 자연 이변 지역 등. 흐르는 에테르는 불안정하거나 강력함

---

## 에테르를 다루는 자의 조건

| 경로 | 설명 |
|------|------|
| 선천적 보유 | 태어날 때부터 체내에 에테르 존재. 인구의 상당수가 해당. 흔한 편 |
| 다루는 능력 | 보유와 별개. 에테르가 있어도 운용 능력이 없으면 그냥 일반인 |
| 각성 | 재능이 있는 자에 한해 수련 또는 외부 자극(스승, 의식, 유물)으로 개방 가능 |
| 수련 | 각성 이후 수련·실전으로 성장. 한계는 재능량에 비례 |

> **핵심 구분** — *에테르를 가진 자*는 많고, *에테르를 다루는 자*는 적고, *에테르를 잘 다루는 자*는 희소

---

## 무인 vs 마법사

| 구분 | 에테르 원천 | 운용 방식 | 핵심 자원 |
|------|------------|----------|----------|
| 무인 | 자기 신체 내부 | 신체·무기에 흘려 강화 | 체력, 정신력, 수련량 |
| 마법사 | 외부 에테르 축적 | 술식(룬·주문·마법진·스크롤)으로 연산 후 발동 | 마정석, 술식 지식 |

---

## 쌍도(雙道) — 무인·마법사 병행

- 이론상 가능. 과거 실재했다는 **전설·고문서 기록 존재**
- 현재 시점엔 성공한 자 없음. 재현 불가 수준
- 세계관 내에서 **"쌍도(雙道)"** 로 불리며 일종의 로망·금기 취급

## 마정석 등급 체계

| 등급 | 소모 여부 | 특징 |
|------|----------|------|
| 하급 | 완전 소모 | 사용 후 폐석. 가장 유통량 많음 |
| 중급 | 부분 소모 | 천천히 자연 충전. 시간 필요 |
| 상급 | 충전 가능 | 에테르 흐름 지역에서 빠른 회복 |
| 최상급 | 자체 충전 | 축적량 매우 크고 자력 회복. 희소. 국가급 자산 취급 |

> 마정석 등급은 곧 **경제·군사력의 척도**

## 에테르 외의 힘

| 힘 | 원천 | 특징 |
|----|------|------|
| **신성력 (Divine Power)** | 신, 신앙, 서약 등 | 에테르와 다른 결로 흐름. 성직자, 성기사 등이 사용 |
| **정령력 (Spirit Power)** | 자연 정령과의 계약·교감 | 정령의 의지에 의존. 일방적 착취 불가 |

- 에테르와 **병행 가능**
- 세 힘은 **원리가 다름** — 상호 간섭은 가능하나 완전히 통합되진 않음
- 힘의 **우열 없음** — 강약은 사용자의 숙련도와 상황에 따라 다름

## 에테르 각성 과정

### 각성 방법

| 방법 | 내용 | 빈도 |
|------|------|------|
| 자연 각성 | 수련·명상·극한 상황 등을 통해 스스로 각성 | 가장 흔함 |
| 스승에 의한 각성 | 숙련된 에테르 사용자가 제자의 에테르를 자극해 각성 유도 | 흔함 |
| 의식을 통한 각성 | 특정 종교·문화 의식을 통해 각성 유도 | 중간 |
| 유물에 의한 각성 | 강력한 에테르가 깃든 유물과 접촉해 각성 | 드묾 |
| 극한 상황 각성 | 생사의 기로에서 본능적으로 각성 | 드묾. 불안정 |

### 각성 연령

| 항목 | 내용 |
|------|------|
| 연령 제한 없음 | 이론상 어느 나이에든 각성 가능 |
| 최적 연령대 | 10대~20대 초반 |
| 나이 들수록 어려워짐 | 신체와 정신이 굳어갈수록 각성 난이도 상승 |
| 노년 각성 | 불가능하진 않으나 극히 드묾 |
| 유아·소아 각성 | 가능하나 신체 부담 큼. 의도적 유도는 금기 |

### 각성 직전 징후
- 체온 변화 (갑작스러운 발열 또는 오한)
- 감각 과민 (오감이 일시적으로 예민해짐)
- 에테르 감지 (주변 에테르가 희미하게 느껴지기 시작)
- 꿈·환각 (수면 중 이상한 꿈. 각성 직전 며칠간 지속)
- 감정 불안정 (이유 없는 흥분·불안·고양감)

### 각성 실패
- 각성 시도 실패 시 **아무 일 없음**
- 신체적·정신적 손상 없음
- 재시도 가능 — 단 나이가 들수록 성공 확률 낮아짐

## 에테르 과부하·부작용

### 과부하의 원인

| 원인 | 내용 |
|------|------|
| 한계 초과 | 자신의 에테르 용량을 넘는 운용 |
| 외부 에테르 역류 | 마정석·자연 에테르가 제어 불가 상태로 유입 |
| 강제 각성 | 준비되지 않은 상태에서 강제로 에테르를 열었을 때 |
| 술식 붕괴 | 마법사의 술식이 연산 도중 붕괴 |

### 과부하 단계

| 단계 | 증상 | 회복 |
|------|------|------|
| 1단계 — 경미 | 피로·두통·에테르 감각 둔화 | 휴식으로 회복. 1~3일 |
| 2단계 — 중등 | 출혈·고열·일시적 에테르 운용 불가 | 치료·휴식 병행. 수 주 |
| 3단계 — 중증 | 에테르 통로 손상·장기 손상·의식 혼탁 | 장기 치료 필요. 완전 회복 불확실 |
| 4단계 — 치명 | 에테르 통로 붕괴·장기 부전·사망 가능 | 회복 불가. 생존해도 에테르 운용 영구 불가 |

### 부작용 — 직군별

**무인 계열 — 신체 중심**

| 증상 | 내용 |
|------|------|
| 에테르 역화(逆火) | 신체 강화 에테르가 역류. 근육·혈관 손상 |
| 감각 마비 | 에테르 흐르는 부위 일시적 감각 상실 |
| 출혈 | 혈관 파열. 눈·귀·코 출혈 |
| 신체 한계 붕괴 | 에테르로 억지로 버티던 신체가 한꺼번에 무너짐 |
| 에테르 고갈 | 체내 에테르 완전 소진. 극도의 탈진 |

**마법사 계열 — 정신·신체 혼합**

| 증상 | 내용 |
|------|------|
| 술식 역폭(逆爆) | 연산 붕괴로 술식이 시전자에게 역방향으로 작용 |
| 에테르 중독 | 외부 에테르 과다 흡수로 신체가 에테르에 잠식 |
| 환각·환청 | 에테르 과부하로 감각 교란 |
| 인격 변화 | 장기 에테르 중독 시 성격·사고방식 변화 |
| 술식 고착 | 시전 중이던 술식이 해제 불가 상태로 고정 |

**정령사 계열 — 정신 중심**

| 증상 | 내용 |
|------|------|
| 계약 붕괴 | 과부하 시 정령과의 계약이 강제 파기 |
| 정령 잠식 | 정령의 의지가 정령사의 의식에 침투 |
| 감각 혼재 | 정령의 감각과 정령사의 감각이 뒤섞임 |

**성기사 계열**

| 증상 | 내용 |
|------|------|
| 신성력 소진 | 극도의 탈진·의식 불명 |
| 성흔(聖痕) | 신성력 역류로 신체에 흔적이 남음. 빛나는 문양·화상 형태. 일부는 신의 흔적이라 해석하기도 함 |
