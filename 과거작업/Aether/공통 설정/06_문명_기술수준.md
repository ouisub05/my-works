# 문명·기술 수준

## 기술 수준 기준점

- 전반적으로 **실제 중세보다 앞선 문명** — 에테르 기술이 문명 발전을 수백 년 앞당김
- 선진 지역 기준 **르네상스 후기 ~ 초기 근대** 수준
- 에테르 기술 미발달 지역·고립 지역은 실제 중세 수준도 존재
- **화약 없음** — 군사 기술의 발전 동력이 드워프 장인 기술과 에테르 쪽으로 흘렀기 때문

---

## 에테르 기술의 보급

| 분야 | 에테르 기술 적용 |
|------|---------------|
| 조명 | 마정석 램프, 에테르 발광체 |
| 난방·냉방 | 에테르 열석, 냉각 술식 각인 제품 |
| 의료 | 에테르 정수, 신성력 치유 보조 |
| 운송 | 에테르 추진 마차, 선박 보조 장치 |
| 통신 | 에테르 수정구, 각인 서판 (장거리 통신 가능. 고가) |
| 농업 | 에테르 정화수, 성장 촉진 술식 |
| 건축 | 에테르 강화 자재, 룬 각인 구조물 |

> 마정석 가격이 곧 물가의 척도 — 마정석 시세가 흔들리면 경제 전체가 흔들림

## 에테르 기술 발전 단계

| 단계 | 내용 |
|------|------|
| 초기 | 에테르 감지·채취 수준. 마정석 원석 활용 |
| 발전기 | 술식 체계 정립. 마법진·룬 각인 기술 발달 |
| 성숙기 (현재) | 에테르 기술의 산업적 활용. 표준화·대량생산 시작 |
| 미지의 영역 | 에테르 사용 마물 출현 등 새로운 변수 등장 |

## 군사 기술 — 에테르 + 드워프 장인 기술

### 드워프 장인 기술
- 금속 가공·합금 기술이 타 종족 압도
- 특수 금속 다루는 기술 보유
- 정밀 기계 구조 — 복잡한 연발 석궁, 공성 기관 등

### 에테르 군사 기술
- 에테르 각인 무기·방어구
- 마법사 부대 — 포격·결계·정찰
- 성기사·무인 부대 — 소수 정예

### 드워프 + 에테르 융합
- 현재 최고 품질 무기의 표준
- 생산 단가 높아 귀족·정예 부대 전용
- 드워프 장인과 마법사가 협업하는 **공방(工房)** 이 세계 각지에 존재
