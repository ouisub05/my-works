# 성기사·신관 체계

## 신성력 개요 및 에테르와의 차이

### 신성력 vs 에테르

| 항목 | 신성력 | 에테르 |
|------|--------|--------|
| **원천** | 신앙·신·신관의 믿음 (논쟁 중) | 세계에 존재하는 초월적 힘 |
| **각성** | 신앙 심화·신의 선택으로 발현 | 선천적 보유+훈련으로 각성 |
| **운용** | 기도·의식·신앙 행위 통해 발현 | 술식·신체 훈련으로 운용 |
| **특화** | 치유·정화·강화·언데드 퇴치 | 공격·방어·강화·마법 전반 |
| **한계** | 신앙심 약화 시 능력 저하 | 에테르 과부하 시 신체 손상 |
| **상호작용** | 에테르와 병행 가능. 일부 융합 사례 있음 | 신성력과 병행 가능 |

### 신성력 과부하

| 단계 | 증상 |
|------|------|
| **1단계** | 극도의 피로감. 신앙심 일시 흔들림 |
| **2단계** | 신성력 일시 불능. 의식 거행 불가 |
| **3단계** | 신체 쇠약. 수일~수주 회복 필요 |
| **4단계** | 신성력 영구 소실 가능. 극히 드묾 |

> 신성력 과부하는 에테르 과부하와 달리 **신앙심 회복**이 치유의 핵심
> 동료 신관의 기도·의식이 회복 가속화에 도움

## 성기사 공통 체계

### 성기사란
- 신성력을 전투에 활용하는 전사 계층
- 규모가 큰 교단 또는 신정 국가에만 존재
- 단순 병사가 아닌 교단의 **신앙 전사**. 전투력+신성력 동시 보유

### 성기사 훈련 체계

| 단계 | 내용 | 기간 |
|------|------|------|
| **견습** | 기초 전투·신앙 교육 동시 진행 | 3~5년 |
| **입단** | 신성력 첫 각성 확인 후 정식 성기사 인정 | — |
| **정규** | 교단 임무 수행. 전투·의식 병행 | 평생 |
| **상급** | 특수 임무·지휘 담당. 신성력 고도화 | 실적 기반 |
| **성검사(聖劍士)** | 최고위 성기사. 교단 최강 전력 | 극희소 |

### 성기사 vs 일반 무인

| 항목 | 성기사 | 일반 무인 |
|------|--------|----------|
| **전투력** | 신성력 강화로 동급 대비 높음 | 에테르 강화 |
| **치유** | 자가 치유·동료 치유 가능 | 불가 |
| **언데드** | 극도로 유효. 신성력 직격 | 일반 전투 수준 |
| **마물** | 신성력 정화로 추가 효과 | 일반 전투 수준 |
| **약점** | 신앙심 흔들리면 능력 저하 | 없음 |

## 교단별 상세 설정

### 1. 룩스 교단 (베스테리아 — 가톨릭 모티프)

#### 교단 개요

| 항목 | 내용 |
|------|------|
| **신** | 룩스(Lux) — 빛·치유·정화의 신 |
| **총본산** | 상투스 임페리움(이탈리아 반도) |
| **교세** | 베스테리아 최대 교단. 레뇨 발로아·솔다텐라트 등 광범위 신자 |
| **핵심 교리** | 빛은 어둠을 정화한다. 고통받는 자를 치유하라. 질서 속에 구원이 있다 |

#### 신관 위계

| 계층 | 명칭 | 역할 |
|------|------|------|
| 1 | **성왕(Rex Sanctus)** | 교단 최고 수장. 세속+종교 권력 |
| 2 | **추기경(Cardinal)** | 성왕 보좌. 성왕 선출권 보유 |
| 3 | **대주교(Archbishop)** | 광역 지역 교단 수장 |
| 4 | **주교(Bishop)** | 도시 단위 교단 수장 |
| 5 | **사제(Priest)** | 일반 신관. 의식·목회 담당 |
| 6 | **부제(Deacon)** | 견습 신관. 사제 보조 |
| 7 | **신자(Layman)** | 일반 신도 |

#### 성기사단

| 기사단 | 특징 | 규모 |
|--------|------|------|
| **성검단(聖劍團)** | 최정예 직속 기사단. 성왕 호위·중요 임무 | 소규모 정예 |
| **치유단(治癒團)** | 신성력 치유 특화. 전장 지원·병원 운영 | 중규모 |
| **정화단(淨化團)** | 마물 처치·이단 심문 전담. 가장 공격적 | 중규모 |
| **순례단(巡禮團)** | 베스테리아 각지 교단 시설 순회·보호 | 대규모 |

#### 신성력 특성
- 치유·정화·빛 계열 특화
- 어둠·죽음 계열 에테르와 충돌 — 상쇄 효과
- 언데드·다크 에테르 사용자 상대로 추가 효과

### 2. 알-와히드 신앙 (아프라·아시란 서부 — 이슬람 모티프)

#### 교단 개요

| 항목 | 내용 |
|------|------|
| **신** | 알-와히드(Al-Wahid) — 유일신. 전지전능한 창조주 |
| **분포** | 말리 술탄국·자한 술탄국·알-티자라 왕국 |
| **핵심 교리** | 유일신 앞에 모든 인간은 평등. 정직한 거래는 신의 뜻 |
| **성기사** | 없음. 신정 국가 규모 미달. 신앙 전사 개념은 존재 |

#### 신관 위계

| 계층 | 명칭 | 역할 |
|------|------|------|
| 1 | **대이맘(Grand Imam)** | 지역 최고 종교 권위자 |
| 2 | **이맘(Imam)** | 예배 지도자. 공동체 종교 수장 |
| 3 | **울라마(Ulama)** | 신학자·법학자. 교리 해석 |
| 4 | **무프티(Mufti)** | 종교 법령 발포 권한 |
| 5 | **신자(Mumin)** | 일반 신도 |

#### 신성력 특성
- 치유·보호 계열 중심
- 공격적 신성력보다 **수호·정화** 특화
- 신앙심과 신성력 연동이 다른 교단보다 직접적

#### 신학 논쟁
- 수인도 알-와히드의 피조물인가 — 진보파 vs 보수파 논쟁 중
- 신성력의 원천이 신인가 신앙력인가 — 내부 학파 분열

### 3. 케메트 신앙 (아프라 — 고대 이집트 모티프)

#### 교단 개요

| 항목 | 내용 |
|------|------|
| **신** | 태양신·나일신·죽음신 등 다신교 pantheon |
| **분포** | 케메트 제국 전역 |
| **핵심 교리** | 파라오는 신의 대리인. 나일의 범람은 신의 축복 |
| **성기사** | 존재. 태양신·전쟁신 신성력 기반 |

#### 신관 위계

| 계층 | 명칭 | 역할 |
|------|------|------|
| 1 | **대신관(High Priest)** | 각 신전 최고 수장. 신관 회의 구성 |
| 2 | **신관 회의** | 파라오 보좌. 실질 권력 행사 |
| 3 | **신관(Priest)** | 의식·신전 관리 담당 |
| 4 | **서기(Scribe)** | 기록·행정 담당 신관 보조 |
| 5 | **신자** | 일반 신도 |

#### 성기사단

| 기사단 | 특징 |
|--------|------|
| **파라오 친위대** | 태양신 신성력 기반. 최정예. 파라오 직속 |
| **신관 전투대** | 에테르·신성력 융합 술식 운용. 원거리 지원 |

#### 신성력 특성
- 태양 에테르·신성력 융합 독자 체계
- 낮에 능력치 상승. 밤에 소폭 저하
- 피라미드·오벨리스크에서 신성력 증폭 효과

---

### 4. 테노치 신앙 (노르테라·수르테라 — 아즈텍 모티프)

#### 교단 개요

| 항목 | 내용 |
|------|------|
| **신** | 태양신·전쟁신·비의 신 등 다신교 pantheon |
| **분포** | 테노치 제국 전역 |
| **핵심 교리** | 전투는 신에게 바치는 의식. 강한 자가 신의 뜻을 이룬다 |
| **성기사** | 존재. 재규어 전사·독수리 전사 계급 |

#### 신관 위계

| 계층 | 명칭 | 역할 |
|------|------|------|
| 1 | **신관 회의** | 틀라토아니(황제) 보좌. 의식·유물 관리 |
| 2 | **대신관** | 각 신 담당 최고 신관 |
| 3 | **신관** | 의식 집행·신전 관리 |
| 4 | **신자** | 일반 신도 |

#### 성기사단

| 기사단 | 특징 |
|--------|------|
| **재규어 전사단** | 신성력+전투 기술 융합. 포획 전투 특화 |
| **독수리 전사단** | 공중 기습+신성력. 수인과 협력 |

#### 신성력 특성
- 태양 에테르+신성력 융합. 케메트와 유사하나 독자 발전
- 의식 수행 시 일시적 신성력 폭발적 상승
- 피라미드 구조물에서 증폭 효과

### 5. 바라타 신앙 (아시란 — 힌두교 모티프)

#### 교단 개요

| 항목 | 내용 |
|------|------|
| **신** | 창조·유지·파괴신 등 다신교 pantheon |
| **분포** | 바라타 연방 전역 |
| **핵심 교리** | 각자의 의무(다르마)를 다하라. 순환하는 세계 속 균형 유지 |
| **성기사** | 없음. 신성력 운용자는 존재하나 전투 특화 조직 없음 |

#### 신관 위계

| 계층 | 명칭 | 역할 |
|------|------|------|
| 1 | **대브라만** | 지역 최고 신관. 왕에게 자문 |
| 2 | **브라만(Brahman)** | 의식·교육·자문 담당 |
| 3 | **푸자리(Pujari)** | 신전 의식 집행 |
| 4 | **신자** | 일반 신도 |

#### 신성력 특성
- 신성력보다 **에테르와 종교 의식의 결합** 특징
- 브라만 의식 중 에테르 증폭 효과 발생
- 신성력인지 에테르인지 내부에서도 논쟁 중

---

### 6. 드림타임 신앙 (오세라 — 원주민 신앙 모티프)

#### 교단 개요

| 항목 | 내용 |
|------|------|
| **신** | 조상령·자연 정령. 드림타임(꿈의 세계) |
| **분포** | 오세라 전역 (특히 알체라 부족연) |
| **핵심 교리** | 조상과 연결. 대지와 하나. 드림타임이 현실에 영향 |
| **성기사** | 없음. 소규모 부족 신앙 |

#### 신관 위계

| 계층 | 명칭 | 역할 |
|------|------|------|
| 1 | **꿈의 장로** | 드림타임 교감 최고 권위자 |
| 2 | **샤먼** | 정령 소통·의식 집행 |
| 3 | **부족원** | 일반 신도 |

#### 신성력 특성
- 신성력보다 **자연 에테르·정령력** 혼합 체계
- 드림타임 교감 시 일시적 강화 효과
- 룩스 교단 등 외래 종교와 충돌 없음

## 정령 신앙·자연 신앙 (기타 교단 — 간략)

| 교단 | 분포 | 성기사 | 특징 |
|------|------|--------|------|
| **이스칼드 정령 신앙** | 이스칼드 분트 | 없음 | 설원·빙설 정령 숭배. 룩스 교단 적대 |
| **에이렌발트 정령 신앙** | 에이렌발트 | 없음 | 삼림 정령 중심. 순혈 엘프 전통 |
| **텡그리 신앙** | 텡그리 칸국·다슈트 | 없음 | 하늘신 숭배. 샤머니즘 혼합 |
| **노르테라 정령 신앙** | 노르테라 각 세력 | 없음 | 대정령·자연신 숭배. 다양 |
| **음반다 전사 신앙** | 음반다 왕국 | 없음 | 강한 자가 신의 뜻. 마물 사냥 의식 |

## 교단간 관계

| 관계 | 당사자 | 내용 |
|------|--------|------|
| **적대** | 룩스 교단 vs 정령 신앙 | 이단 규정. 정화단 파견 |
| **경쟁** | 룩스 교단 vs 알-와히드 신앙 | 교세 확장 경쟁. 직접 충돌은 드묾 |
| **무관** | 바라타 신앙 vs 기타 | 타 종교에 관대. 충돌 없음 |
| **공존** | 케메트 신앙 vs 알-와히드 | 아르다샤르 제국 내 종교 흡수 정책으로 공존 |
| **신학 논쟁** | 신성력 원천 논쟁 | 신원론·신앙력론·제3원론·불가지론 전 교단 공통 |
