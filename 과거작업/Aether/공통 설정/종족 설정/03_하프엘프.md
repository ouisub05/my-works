# 하프 엘프

## 기본 스펙

| 항목 | 내용 |
|------|------|
| 인구 비율 | 전 세계 약 3~4% |
| 수명 | 150~200년대 |
| 에테르 보유 비율 | 10명 중 7명 |
| 외형 | 순혈 엘프와 거의 유사. 귀가 순혈보다 약간 짧음 |
| 출신 | 인간·엘프 교류 지역에서 자연 발생 |

---

## 신체적 특성 (순혈 엘프 대비)

| 항목 | 순혈 엘프 대비 |
|------|--------------|
| 시각·청각 | 약간 낮음. 그러나 인간보다는 우월 |
| 민첩·반응속도 | 약간 낮음. 인간보다는 우월 |
| 에테르 감응 | 낮음. 자연 에테르 직접 활용은 어려움 |
| 정령 친화 | 있음. 순혈보다 약하나 타 종족보다 높음 |
| 자연 친화 강화 | 약함. 순혈처럼 뚜렷하지 않음 |
| 노화 | 중년 이후부터 천천히 노화 |

---

## 사회적 위치

- 어느 사회에서도 **완전한 주류는 되기 어려움**
- 하프 엘프끼리의 공동체를 형성하는 경우도 있음

### 지역별 시선

| 지역 유형 | 시선 |
|----------|------|
| 다종족 혼거 도시 | 비교적 중립. 능력 있으면 인정받음 |
| 인간 순혈주의 국가 | 차별·편견 심함. 2등 시민 취급 |
| 개방파 엘프 왕국 | 조건부 수용. 엘프 문화 따르면 인정 |
| 보수파 엘프 왕국 | 입경 자체 제한. 사실상 배척 |

---

## 하프 엘프의 강점

| 강점 | 내용 |
|------|------|
| 언어·문화 적응력 | 인간·엘프 양쪽 문화에 익숙. 통역·중재 능력 자연스럽게 발달 |
| 수명과 경험 | 인간보다 긴 수명으로 더 많은 경험 축적 가능 |
| 에테르 운용 | 순혈 엘프 방식·인간 방식 양쪽 모두 입문 가능 |
| 정령 교감 | 타 종족보다 높은 정령 친화력 |
| 사회 침투력 | 양쪽 사회에 발 걸칠 수 있는 유일한 존재 |

---

## 주요 직종

| 직종 | 이유 |
|------|------|
| 용병·모험가 | 어느 사회에도 완전히 속하지 않으니 자유로운 활동 가능 |
| 외교관·통역 | 인간·엘프 양쪽 언어·문화 이해 |
| 상인 | 양쪽 사회 모두 거래 가능 |
| 정보원·스파이 | 어느 쪽 사회에도 침투 가능 |
| 마법사·정령사 | 양쪽 에테르 체계 접근 가능 |

---

## 혼혈 2세

- **쿼터 엘프** (하프 엘프 + 인간) — 외형은 인간에 더 가까움. 에테르 보유 비율·수명 모두 인간에 가까워짐
- 하프 엘프 + 순혈 엘프 — 순혈에 매우 가까운 외형. 순혈 엘프 사회 수용 여부는 왕국 정책에 따라 다름
