# 드워프

## 기본 스펙

| 항목 | 내용 |
|------|------|
| 인구 비율 | 전 세계 약 6% |
| 수명 | 평균 200년대 |
| 에테르 보유 비율 | 10명 중 3~4명 |
| 체형 — 남성 | 인간보다 키 작고 다부짐. 근력·체력 인간 상회 |
| 체형 — 여성 | 남성보다 인간 체형에 가까움. 키 차이 덜함 |

---

## 신체적 특성

| 항목 | 내용 |
|------|------|
| 신장 — 남성 | 인간 평균보다 머리 하나 정도 작음 |
| 신장 — 여성 | 인간 여성보다 약간 작은 정도 |
| 근력·체력 | 남녀 모두 인간 상회. 특히 남성은 압도적 |
| 내구력 | 피부·골격 밀도 높음. 타격 저항력 강함 |
| 감각 | 어둠 속 시야 인간보다 나음 |
| 민첩 | 낮음. 체형상 속도보단 힘 중심 |
| 수염 | 남성 드워프의 상징. 수염 길이·모양이 사회적 지위·경력 나타냄 |

> 드워프 여성은 수염 없음 (일부 문화권 예외)
> 인간과 외형 유사한 드워프 여성을 하프 엘프나 인간으로 오해하는 경우 있음

## 사회구조

### 왕정 + 장인 기술 중심

| 계층 | 내용 |
|------|------|
| 왕·왕족 | 전사 계열. 대외 군사·외교 주도 |
| 장인 조합 수장 | 기술 등급 최상위. 왕에 버금가는 권위 |
| 장인 | 기술 등급에 따라 사회적 지위 결정 |
| 전사 | 왕 직속 군사력 |
| 일반 시민 | 장인 수련 중이거나 비기술직 종사자 |

- **왕은 반드시 전사 계열** — 전투력 없는 왕은 인정받지 못함
- 왕위 계승 시 전투 능력 검증 과정 존재
- **기술 등급이 곧 신분** — 아무리 왕족이라도 기술이 없으면 존경 못 받음

## 에테르와 드워프

- 에테르 보유율이 낮은 것에 **열등감 없음**
- **"에테르에 의존하는 것은 불안정한 힘"** 이라는 인식
- 드워프 에테르 보유자는 장인 기술에 에테르를 결합하는 방향으로 특화

### 드워프 에테르 기술

| 기술 | 내용 |
|------|------|
| 룬 각인 | 무기·방어구·건축물에 에테르 술식 새김. 드워프 독자 체계 |
| 에테르 기관 | 에테르를 동력으로 쓰는 기계 장치 |
| 마정석 정제 | 마정석 품질 향상·가공 기술 |
| 합금 에테르 주입 | 제련 과정에서 에테르 직접 주입 |

> 드워프 룬 각인 체계는 인간 마법사 술식 체계와 근본적으로 다름

## 장인 문화

| 항목 | 내용 |
|------|------|
| 장인 등급 | 수습→견습→장인→명장→대장인→전설 장인 |
| 작품이 곧 명함 | 장인의 가치는 만든 물건으로 증명 |
| 사제 문화 | 스승→제자로 기술 전수 |
| 걸작 제작 | 일생에 한 번 최고의 작품 만드는 것이 꿈. **마스터피스** 문화 |
| 서명 각인 | 자신의 작품에 고유 문양 새김. 위조 불가 |

---

## 보복 문화

- **"드워프를 건드리면 반드시 되돌아온다"** 는 것이 세계 공통 인식
- 개인에 대한 피해도 씨족 단위로 기억하고 보복
- 보복은 즉각적이지 않을 수 있음 — 수십 년 후에 갚는 경우도 있음

|------|------|

| 다크 엘프 | 지하·폐쇄 환경 공유로 일부 교역 |
| 수인 | 지역에 따라 다름. 광산 지역 수인과 충돌 사례 있음 |
