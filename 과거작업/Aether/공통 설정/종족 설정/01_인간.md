# 인간

## 기본 스펙

| 항목 | 내용 |
|------|------|
| 인구 비율 | 전 세계 약 65% |
| 수명 | 평균 60~80세. 에테르 사용 여부와 무관 |
| 에테르 보유 비율 | 10명 중 5~6명 |
| 에테르 운용 능력자 | 보유자 중 일부. 무인·마법사·성기사 등 |
| 종족 특성 | 번식력·적응력·야망 |
| 사회 계층 | 국가마다 다름 |

---

## 인간의 위치

- 수명이 짧은 대신 **세대 교체가 빠름**
  - 빠른 인구 증가
  - 새로운 시도·변화에 적극적
- 에테르 성장 속도·한계 등 **특별한 재능 없음**
  - 순전히 수·적응력·야망으로 세계 패권 장악
- 인간끼리의 격차가 세계에서 가장 큼
  - 최빈국 평민부터 대제국 황제까지 모두 인간
