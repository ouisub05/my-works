# 순혈 엘프

## 기본 스펙

| 항목 | 내용 |
|------|------|
| 인구 비율 | 전 세계 약 5~6% |
| 수명 | 수백~천 년대 |
| 에테르 보유 비율 | 10명 중 8~9명 |
| 번식률 | 낮음. 평생 3~5명. 수명 덕에 인구 유지 수월 |
| 거주지 | 큰 숲 정착. 독립 왕국 형태 |
| 외형 | 귀 모양 외 인간과 유사. 내부적·능력적 차이는 큼 |

## 신체적 특성

| 항목 | 내용 |
|------|------|
| 귀 | 길고 뾰족함. 청각 인간보다 예민 |
| 시각 | 인간보다 훨씬 뛰어남. 야간 시야 보유 |
| 감각 전반 | 오감 모두 인간 상회. 자연 환경에서 극대화 |
| 신체 능력 | 근력은 인간과 유사하나 민첩·반응속도 우월 |
| 에테르 감응 | 선천적으로 높음. 자연·정령 에테르 흐름을 직관적으로 감지 |
| 자연 친화 | 숲·자연 환경에서 신체 능력 소폭 강화 |
| 노화 | 성인 외형에서 거의 변하지 않음. 수명 말기에 가서야 노화 징후 |

## 사회구조

### 기본 형태
- **큰 숲에 정착한 독립 왕국**
- 숲 전체가 곧 왕국 영토 — 경계는 숲의 끝
- 외부인 출입 엄격히 통제
- 왕정 기반이나 왕의 권한은 절대적이지 않음 — **장로 회의**와 공동 결정

### 보수파 vs 개방파

| 구분 | 입장 | 주도 세력 |
|------|------|----------|
| 보수파 | 숲 밖과 교류 최소화. 인간 팽창 경계. 전통 수호 | 장로 회의 다수 |
| 개방파 | 외부 교류·정보 수집 필요. 고립은 쇠퇴 | 젊은 층, 일부 왕족 |

---

## 에테르 및 정령

### 에테르
- 자연 친화적 마법 중심
- 파괴적 공격 마법보다 제어·지원·환경 조작 계열 선호
- 자연에 흐르는 에테르를 직접 활용하는 기술 발달 — 마정석 의존도 낮음

### 정령
- 왕국 내 정령과의 관계는 **공생에 가까움**
- 대정령이 존재하는 경우 왕국의 수호자 역할
- 정령과의 관계가 왕국의 건강함을 나타내는 척도

## 대외 관계

| 대상 | 관계 |
|------|------|
| 인간 | 경계·견제. 교류는 하나 신뢰하지 않음 |
| 하프 엘프 | 복잡. 자식으로 인정하는 왕국도 있고 배척하는 왕국도 있음 |
| 다크 엘프 | 단절·냉담. 역사적 사건으로 인한 감정 존재 |
| 드워프 | 중립적 교역 관계 |
| 수인 | 자연 친화 수인 종족과는 우호. 그 외 중립 |
