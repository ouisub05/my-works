# 수인

## 기본 설정

| 항목 | 내용 |
|------|------|
| **인구 비율** | 전 세계 약 12% |
| **외형** | 인형 중심. 기본 체형은 인간. 귀·꼬리·눈·피부 등 동물 특징 일부 나타남 |
| **기원** | 원래부터 존재한 종족. 인간·엘프와 동등한 위치 |
| **에테르 보유 비율** | 종류마다 다름. 상세는 15_수인_대륙별_분포.md 참조 |

---

## 외형 특성

- 기본 체형은 인간과 유사
- 동물 특징은 귀·꼬리·눈·피부·털 색·손발톱 정도로 나타남
- 전신이 털·비늘로 덮이는 경우는 드묾
- 같은 종이라도 개체마다 동물 특징 발현 정도 다름
- 혼혈(수인+인간, 수인+수인 다른 종) 가능. 부모 특징 무작위 발현

---

## 수인 공통 특성

### 본능적 감각

| 감각 | 내용 |
|------|------|
| **위험 감지** | 위험·적의를 본능적으로 감지 |
| **영역 의식** | 자신의 영역·공간에 대한 강한 인식 |
| **감정 감지** | 상대의 감정·긴장·공포를 본능적으로 읽음. 거짓말 탐지에 유리 |
| **자연 감각** | 날씨·지형 변화 감지. 길 찾기 능력 우월 |

> 본능적 감각은 훈련으로 더 예민하게 발달 가능
> 도시 생활이 길어지면 둔화되는 경향도 있음

### 신체 능력

- 기반 동물의 특성이 신체 능력으로 나타남
- 특화 능력은 반드시 인간보다 뛰어남
- 특화된 능력 외엔 인간과 유사하거나 열세인 경우도 있음

### 수명

- 종류마다 차이 있으나 대체로 인간과 유사한 수명
- 일부 장수 종(거북·용 계열 등)은 예외적으로 긴 수명 보유

## 에테르와 수인

- 에테르 운용 방향이 **신체 강화 계열**에 치우치는 경향
- 마법사보다 **무인 계열** 비율이 타 종족 대비 높음
- 에테르 마법사 수인은 희소하나 본능적 감각과 마법이 결합되면 독특한 전투 스타일 형성
- 에테르 보유 비율은 종류·환경에 따라 편차 큼

## 수인 사회 공통 구조

| 특징 | 내용 |
|------|------|
| **무리 의식** | 집단·가족·동료에 대한 유대감 강함. 배신을 극도로 혐오 |
| **실력 위주** | 대부분의 수인 사회에서 실력·능력이 지위 결정에 중요 |
| **구전 문화** | 문자 기록보다 구전·전통 중심 문화 많음 |
| **혈통·씨족** | 씨족·부족 단위 결속 강함 |

## 수인에 대한 세계의 시선

| 지역 | 인식 |
|------|------|
| **베스테리아** | 세력별 편차 큼. 실바 아르카나·이스칼드 분트는 평등. 케메트식 혐오는 없음 |
| **아프라** | 케메트에서 비인간 혐오. 아흐마르 칸·음반다는 공존. 말리는 평등 대우 |
| **아시란** | 마루한 제국 시민권 부여. 중위안은 소수 거주. 강티세 엘프류와 공존 |
| **노르테라** | 대부분 세력에서 인간과 동등. 와바나키 공화국 완전 평등 |
| **수르테라** | 투피·음반다 계열 문화에서 공존. 타완틴은 인간 중심 |
| **오세라** | 드림타임 문화 내 자연스러운 공존. 차별 개념 거의 없음 |
