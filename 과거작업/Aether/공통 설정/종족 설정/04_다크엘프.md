# 다크 엘프

## 기원 — 단절의 산물

- 대재앙(단절) 당시 순혈 엘프 일부가 **극단적 환경에 고립·적응**하며 변이한 결과
- 단절 이전엔 순혈 엘프와 **같은 종족**이었음
- 수백 년에 걸쳐 신체·에테르 구조가 환경에 맞게 변화
- 순혈 엘프와 **같은 뿌리**임을 양측 모두 알고 있음
  - 순혈 엘프는 인정하기 불편해하는 경향
  - 다크 엘프 측도 감정이 복잡함 — 동족의식과 반감이 공존

---

## 기본 스펙

| 항목 | 내용 |
|------|------|
| 인구 비율 | 전 세계 약 1~2% (엘프류 중 가장 희소) |
| 수명 | 순혈 엘프와 유사. 수백~천 년대 |
| 에테르 보유 비율 | 10명 중 7~8명 |
| 거주지 | 특정 숲. 일부는 타 종족과 공존 |

---

## 신체적 특성 (순혈 엘프 대비)

| 항목 | 내용 |
|------|------|
| 피부 | 어두운 색조. 회색~흑갈색 계열 |
| 눈 | 동공이 크고 야간 시야 순혈보다 뛰어남. 강한 빛에 약한 개체 있음 |
| 청각 | 순혈과 유사하거나 소폭 우월 |
| 근력 | 순혈보다 소폭 높음 |
| 민첩 | 순혈과 유사 |
| 자연 친화 | 어둠·그늘 친화 |
| 에테르 감응 | 순혈보다 낮으나 인간보다 높음 |

---

## 에테르 운용 방향

| 항목 | 순혈 엘프 | 다크 엘프 |
|------|----------|----------|
| 중심 계열 | 자연·식물·빛 계열 | 어둠·그림자·환영 계열 |
| 정령 활용 | 자연 정령과 공생 | 정령 관계 단절. 일부만 회복 |
| 마정석 의존 | 낮음 | 중간. 자연 에테르 감응 약화로 마정석 보조 활용 |

> 다크 엘프의 어둠·환영 마법은 세계 최고 수준

---

## 정령 관계

| 상태 | 내용 |
|------|------|
| 완전 단절 | 정령과 교감 불가. 정령 신앙 자체가 사라진 집단 |
| 뒤틀린 관계 | 어둠 속성 정령과만 교감 가능 |
| 회복 중 | 외부 접촉·교류를 통해 정령과의 관계를 서서히 회복하는 집단 |

---

## 거주지 유형

| 유형 | 내용 |
|------|------|
| 고립 숲 왕국 | 특정 숲 깊숙이 자리잡은 독립 공동체. 외부 접촉 최소화 |
| 타 종족 공존 | 인간·하프 엘프 등과 함께 사는 집단. 주로 도시 거주 |
| 유랑 집단 | 고정 거주지 없이 이동. 소규모. 용병·상인 형태 |

- 다크 엘프 전체를 아우르는 단일 국가·조직 **없음**

---

## 사회적 위치 및 대외 관계

- 어둠 계열 마법 사용으로 **"불길하다", "위험하다"** 는 인식 만연
- 노예로 전락한 경우 순혈·하프 엘프보다 많음

| 대상 | 관계 |
|------|------|
| 순혈 엘프 | 복잡한 감정. 동족이라는 인식과 반감 공존. 냉담이 기본값 |
| 하프 엘프 | 비교적 중립. 경계인끼리의 연대 의식 있는 경우도 있음 |
| 인간 | 집단마다 다름 |
| 드워프 | 지하·폐쇄 환경 공유로 일부 문화 유사성. 중립적 교역 |
| 수인 | 중립 |
