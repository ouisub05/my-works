## 고대 — 단절 이전

- 현재와 비슷하거나 일부 영역은 다른 방향으로 발전한 문명
- 현재 기술로 **이해·재현 불가능한 유물·유적 다수** 존재
  - 작동 원리 불명의 에테르 기관
  - 현재 술식 체계로 해석 안 되는 마법진
  - 소재 자체를 알 수 없는 건축물
  - 어떤 언어로도 해독 안 되는 문자 체계
- 고대의 종족 구성, 국가 형태, 에테르 사용 방식 등 **모든 것이 불명**
- 고대 연구 자체가 하나의 학문 분야로 존재

## 단절 — 대재앙

**원인 완전 불명**

| 결과 | 내용 |
|------|------|
| 문명 대부분 소멸 | 이전 국가·사회 구조 붕괴 |
| 인구 급감 | 종족 불문 대규모 사망 |
| 지형 변화 | 일부 지역 지형이 바뀐 흔적 존재 |
| 에테르 이변 | 단절 전후로 에테르 분포가 달라졌다는 학설 |
| 마물 대발생 | 단절 직후 마물이 폭발적으로 늘었다는 기록 |

### 단절 원인 학설

| 학설 | 내용 |
|------|------|
| 천재지변설 | 자연적 대재앙. 운석, 화산, 대지진 등 |
| 마법 실험 실패설 | 고대 마법사들의 실험이 통제 불능 상태가 됨 |
| 신의 심판설 | 교단 공식 입장. 신이 타락한 고대 문명을 멸함 |
| 마물 기원설 | 단절이 마물을 만들었거나 마물이 단절을 일으킴 |
| 외부 개입설 | 세계 외부의 무언가가 개입. 극소수. 이단 취급 |

## 현재 시점 — 복합 갈등

안정기처럼 보이지만 다층적 갈등이 동시 진행 중.

| 갈등 | 내용 |
|------|------|
| 인간 패권국 vs 타 종족 | 영토 팽창·노예화에 맞서는 구도 |
| 인간 국가 간 패권 경쟁 | 마정석 산지·교역로·기술 우위를 둘러싼 경쟁 |
| 종족 내부 분열 | 인간에 협력하는 엘프 vs 고립 노선 엘프 등 |
| 교단 간 갈등 | 신앙 해석 차이·세력 확장 경쟁 |
| 에테르 사용 마물 출현 | 원인 불명. 기존 질서에 새로운 변수 |
| 고대 유물 쟁탈 | 이해 불가 유물을 선점하려는 암투 |

### 현재 시점의 최대 미지수
- **에테르 사용 마물의 출현** 이 심상치 않음
- 일부 학자·세력은 이것이 **단절의 전조**와 유사하다는 주장 제기
- 대부분의 국가는 당장의 패권 경쟁에 집중하느라 경시
