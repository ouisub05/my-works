# 마물 도감 — 베스테리아 특별 마물

## 개요

베스테리아에만 서식하는 고유 마물. 이스칼드 분트·에이렌발트 북부 다발 지대 중심.

---

## 1. 프로스트 울프

| 항목 | 내용 |
|------|------|
| **등급** | 3등급. 무리 형성 시 4등급 |
| **서식지** | 이스칼드 분트 설원. 에이렌발트 북부 |
| **신체** | 거대 빙설 늑대. 일반 늑대 마수보다 크고 냉기 속성 강화 |
| **특징** | 숨결에서 냉기 방출. 무리 사냥 시 포위 냉결 전술 |
| **약점** | 화염. 화염 에테르 |
| **소재 가치** | 빙설 결정(냉기 술식 재료). 모피(방한 특수 소재) |

---

## 2. 블리자드 트롤

| 항목 | 내용 |
|------|------|
| **등급** | 5등급 |

| **신체** | 설원 트롤 최대형. 전신 빙설 결정 부착 |
| **특징** | 재생력 + 냉기 속성. 화염으로만 재생 차단. 눈보라 속 위장 |
| **약점** | 화염. 냉기 내성으로 얼음 공격 무효 |
| **소재 가치** | 빙결 심장(고급 냉기 마정석 대체 재료) |

# 마물 도감 — 아프라 특별 마물

## 개요

아프라에만 서식하는 고유 마물. 사막·밀림·초원 지대 중심.

---

## 1. 사막 지룡(地龍)

| 항목 | 내용 |
|------|------|
| **등급** | 5등급 |
| **서식지** | 아프라 북부·중부 사막 지대 |
| **신체** | 지하 굴착형 마물. 표면 이동 시 모래 위 빠른 이동 |
| **특징** | 지하에서 기습. 진동 감지 능력. 모래폭풍 유발 |
| **약점** | 지면 고정 에테르 술식. 물(사막 특성상 극희소 자원) |
| **소재 가치** | 지룡 비늘(사막 전투용 방어구). 진동 기관(탐지 에테르 기관 재료) |

---

## 2. 불꽃 하이에나

| 항목 | 내용 |
|------|------|
| **등급** | 2등급. 무리 시 3등급 |
| **서식지** | 아프라 사바나·건조 초원 |
| **신체** | 거대 하이에나. 등줄기에 화염 갈기 |
| **특징** | 화염 울음소리로 무리 소집. 무리 포위 후 화염 갈기 점화 |
| **약점** | 물·냉기. 무리 분산 전술 |
| **소재 가치** | 화염 갈기(화염 술식 재료). 발톱(무기 재료) |

---

## 3. 뼈 거인

| 항목 | 내용 |
|------|------|
| **등급** | 5등급 |
| **서식지** | 아프라 건조 내륙. 고대 유적 주변 |
| **신체** | 거대 골격형 마물. 언데드와 유사하나 별개 종 |
| **특징** | 뼈 재생. 분리된 뼈 원격 조작. 고대 유적 주변에서 더 강해짐 |
| **약점** | 신성력. 에테르 파쇄 술식 |
| **소재 가치** | 에테르 골격(고급 에테르 기관 재료). 희소성 높음 |

---

## 4. 밀림 포식자

| 항목 | 내용 |
|------|------|
| **등급** | 4등급 |
| **서식지** | 아프라 중부 열대밀림. 음반다 왕국 접경 |
| **신체** | 대형 카멜레온형 마물. 완전 투명화 가능 |
| **특징** | 완전 투명화로 육안 탐지 불가. 에테르 감지로만 발견 가능. 독 발톱 |
| **약점** | 에테르 광역 탐지. 물리 충격 시 일시 투명화 해제 |
| **소재 가치** | 투명 피부(은신 술식 재료). 독 기관(독 제조 재료) |
