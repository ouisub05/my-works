# 마루한 제국·고리 왕국 관계 상세

---

## 역사적 배경

### 단절 이후 초기 관계 (수백 년 전)

단절 이전 한반도·만주 일대는 같은 문화권에 가까운 연속 지역.
단절 후 대규모 자연재해로 지형 변화. 만주 일대에 마루한 제국 형성. 한반도에 고리 왕국 형성.
초기 수백 년: 양측 모두 내부 정비에 집중. 소규모 접경 교역·충돌 반복. 실질 지배 관계 없음.

### 마루한 팽창기 (약 200~100년 전)

이전 황제 시절 마루한 제국 급격한 군사 팽창.
타이가 부족연·야마토 방면 동시 압박. 고리 왕국에도 조공 요구 시작.
고리 왕국 당시 왕: 중위안 조공 체제에 편입하여 마루한 압박 완충 전략 선택.
**마루한 vs 중위안 대리 경쟁 구도 형성** — 고리가 중위안 편에 서면서 마루한과 공식 적대 관계.

### 이전 황제 vs 현 황제 전환점 (약 30~50년 전)

이전 황제: 고리 무력 복속 시도 2차례. 모두 실패.
- 1차 원정: 고리 산악·삼림 지형으로 마루한 에테르 기관 효율 저하. 장기전 불리. 철수.
- 2차 원정: 야마토 팽창 견제 필요로 병력 분산. 고리 완전 복속 전 중단.
이 경험이 현 황제에게 반면교사. **무력 복속 포기 → 기술 의존 복속 전략으로 전환.**

## 현재 관계 구도

### 마루한의 고리 전략 — 기술 의존 복속

| 전략 요소 | 내용 |
|----------|------|
| **기술 선별 공개** | 에테르 기관 기술 일부를 고리에 제공. 중위안 기술보다 우월함 시연 |
| **친마루한파 심기** | 고리 내부 기술 도입 귀족·엘프 귀족 지원. 점진적 세력 확대 |
| **강행파 장군 독자 공작** | 황제 방침 외 장군이 기술 도입 귀족에게 직접 접촉. 내부 분열 가속 시도 |
| **철매 정보망** | 고리 친마루한파·친중위안파 동향 동시 감시. 정보 우위 유지 |
| **야마토 압박 활용** | 야마토 남부 침략 → 고리 자체 방어 한계 → 마루한 의존 필요성 증대 |

> **핵심 논리:** 고리가 마루한 기술 없이는 야마토 막지 못한다는 인식 심기.
> 기술 의존 → 경제 의존 → 정치 복속의 단계적 시나리오.

### 고리의 대응 — 중위안 의존 vs 마루한 기술 사이

| 고리 내부 세력 | 마루한 대응 | 중위안 대응 |
|-------------|----------|----------|
| **왕·수석 대신(친중위안)** | 마루한 기술 제안 거절. 거리 유지 | 중위안 조공 체제 유지. 실질 보호 요청 |
| **기술 도입 귀족** | 마루한 기술 적극 수입 주장. 장군 접촉 표적 | 중위안 방침 반대. 독자 방어력 구축 우선 |
| **순혈 엘프 귀족** | 마루한 기술 도입 지지. 단 완전 종속 거부 | 중위안 의존 탈피 지지. 엘프 독자성 유지 |

## 핵심 파벌 교차 분석

### 마루한 황제 ↔ 고리 왕

| 항목 | 마루한 황제 | 고리 왕 |
|------|----------|--------|
| **목표** | 고리 자연 복속 유도. 무력 불사용 원칙 | 중위안 조공 유지로 마루한 완충 |
| **전략** | 기술 선별 공개·친마루한파 심기 | 중위안 약화 인지. 대안 모색 유보 |
| **약점** | 중위안 약화가 예상보다 빠름. 고리 왕 선택 시간 촉박 | 중위안 실질 보호 능력 감소. 전략 기반 흔들림 |
| **향후 변수** | 강행파 장군 독자 공작 발각 시 관계 악화 | 야마토 피해 심화 시 마루한 의존 불가피 |

### 강행파 장군 ↔ 기술 도입 귀족

마루한 황제 방침과 별도로 장군이 기술 도입 귀족에게 직접 접촉 중.
장군 목표: 고리 내부 친마루한 세력 강화 → 황제 방침과 별개로 복속 가속.
기술 도입 귀족 목표: 마루한 기술 수입으로 야마토 방어. 완전 종속 원치 않음.
**양측 이해관계 부분 일치·부분 충돌** — 장군은 종속 원하고 귀족은 기술만 원함.
마루한 철매 수장이 장군 독자 공작 감시 중. 황제 보고 여부 고민 핵심 변수.

### 마루한 철매 ↔ 고리 수석 대신

철매: 고리 친마루한파·친중위안파 동향 동시 감시. 정보 수집.
수석 대신: 중위안 수석 대학사와 뇌물 채널 보유. 중위안 감찰원장 조사 대상.
**역설적 구도** — 수석 대신이 마루한 견제 위해 의존하는 중위안 채널이 부패로 신뢰 불가 상태.
철매가 이 정보 보유 가능성. 고리 수석 대신 압박 카드로 활용 가능.

### 엘프 귀족 — 독자 변수

고리 왕국 내 순혈 엘프 귀족은 마루한·중위안 양측 모두와 다른 독자 이해관계 보유.
마루한 기술 도입 지지: 중위안 의존 탈피가 엘프 자치권 강화에 유리.
단 마루한 완전 종속 거부: 마루한이 고리 복속 시 엘프 귀족 위상 불명확.
**마루한 입장에서 엘프 귀족은 활용 가능한 중간 변수.** 기술 도입 귀족보다 더 신중하게 접근 필요.
마루한 철매가 엘프 귀족 동향 감시 중. 수백 년 고리 정착으로 독자 에테르 기록 보유 인지.

## 외부 변수

### 중위안 약화

| 영향 | 내용 |
|------|------|
| **고리 입장** | 중위안 의존 전략 기반 붕괴. 대안 없이 마루한 선택 강요받는 구도 |
| **마루한 입장** | 고리 복속 기회. 텡그리 압박 분산 틈 활용 |
| **타이밍** | 중위안이 얼마나 빨리 약화되느냐가 마루한·고리 관계 전환 속도 결정 |

### 야마토 팽창

| 영향 | 내용 |
|------|------|
| **고리 입장** | 남부 피해 심화 → 자체 방어 한계 → 마루한 의존 불가피성 증대 |
| **마루한 입장** | 야마토 견제 명목으로 고리에 군사 지원 → 자연스러운 군사 의존 심화 |
| **역설** | 마루한이 야마토를 완전히 막으면 고리의 마루한 의존 명분도 감소 |

### 텡그리 칸국 성장

| 영향 | 내용 |
|------|------|
| **마루한 입장** | 텡그리 견제에 집중 시 고리 복속 우선순위 하락 가능성 |
| **고리 입장** | 마루한이 텡그리에 묶이면 고리 독립 여유 시간 확보 |
| **변수** | 텡그리·마루한 충돌 규모에 따라 고리 전략 기회·위협 변화 |

## 관계 분기 시나리오

### 시나리오 A — 기술 의존 복속 성공

조건: 야마토 피해 심화 + 중위안 급격 약화 + 강행파 장군 공작 성공
결과: 기술 도입 귀족 주도로 마루한 기술 전면 수입 → 경제 의존 → 고리 사실상 복속
고리 왕·수석 대신 반발하나 내부 기반 붕괴로 실질 저항 불가

### 시나리오 B — 고리 독자 생존

조건: 텡그리 압박으로 마루한 고리 집중 불가 + 중위안 내부 개혁 성공 + 야마토 쇼군 내정 문제 발생
결과: 고리 왕·수석 대신 전략 유효성 회복. 기술 도입 귀족 세력 억제
마루한 기술 선별 수입하되 정치 독립 유지. 중위안·마루한 균형 외교 지속

### 시나리오 C — 엘프 귀족 독자 변수

조건: 고리 왕·수석 대신 파벌 약화 + 기술 도입 귀족 세력 성장 + 엘프 귀족 독자 행동
결과: 엘프 귀족이 마루한 종속 없이 독자 기술 협약 추진
마루한·중위안 모두 예상 못한 변수. 고리 내부 3파전 구도로 전환

### 시나리오 D — 강행파 장군 공작 발각

조건: 철매 수장이 장군 독자 공작 황제에게 보고
결과: 마루한 황제 점진 방침 유지 재확인. 장군 견제 강화
단기적 고리 관계 개선 가능성. 그러나 장기 복속 방향은 변화 없음

## 마루한·고리 관계 핵심 요약

| 항목 | 내용 |
|------|------|
| **현재 상태** | 마루한 기술 의존 복속 점진 추진 중. 고리 중위안 의존 전략 기반 약화 중 |
| **마루한 우위** | 기술·정보·군사력 압도적 우위. 시간이 마루한 편 |
| **고리 생존 변수** | 텡그리 압박 지속·중위안 내부 개혁·야마토 자체 문제 |
| **내부 핵심 변수** | 강행파 장군 공작 발각 여부·엘프 귀족 독자 행동·기술 도입 귀족 세력 성장 속도 |
| **결정적 타이밍** | 중위안 약화 속도 vs 마루한 텡그리 대응 자원 배분 |
