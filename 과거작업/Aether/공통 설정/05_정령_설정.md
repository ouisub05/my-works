# 정령 설정

## 정령의 본질

- 정령은 **자연 현상 자체가 의식을 가진 존재로 발현**
- 에테르와 **별개의 존재** — 에테르가 없는 곳에도 정령은 존재할 수 있음
- 자연이 존재하는 한 정령도 존재 — 완전한 소멸은 없음
  - 자연이 파괴되면 해당 정령은 **약화·잠면** 상태가 됨
- 정령은 **인격을 가짐** — 의지, 감정, 선호가 있음
- 신과의 관계는 **불명**

---

## 정령의 등급

| 등급 | 명칭 | 특징 |
|------|------|------|
| 상위 | 대정령 | 자연 현상 전체를 관장. 산 하나, 강 하나, 숲 전체에 깃든 수준. 계약 매우 어려움 |
| 중위 | 정령 | 자연의 일부에 깃든 존재. 정령사와 계약하는 대부분이 이 등급 |
| 하위 | 정령의 씨앗 | 아직 의식이 희미한 상태. 계약 대상 아님 |

> 대정령과 계약한 정령사는 세계관 내에서 전설급 취급

---

## 정령의 속성

| 분류 | 속성 | 비고 |
|------|------|------|
| 기본 4속성 | 불, 물, 바람, 대지 | 가장 흔함 |
| 자연 속성 | 숲, 번개, 빙설, 안개 | 중간 빈도 |
| 현상 속성 | 어둠, 빛, 시간, 공간 | 희소. 대정령급에서 주로 나타남 |
| 복합 속성 | 용암(불+대지), 嵐(바람+번개) 등 | 드묾. 강력 |

## 상호 계약

### 계약의 원칙
- 정령의 **동의 없이는 계약 불가**
- 강제 구속 술식은 존재하나 정령사 사회에서 **금기이자 금지**
- 계약은 **쌍방 조건 협의**

### 계약 조건 — 정령이 요구하는 것

| 요구 유형 | 내용 |
|----------|------|
| 자연 보호 | 계약자가 해당 정령의 자연 환경을 해치지 않을 것 |
| 공명(共鳴) | 정령사가 정기적으로 정령과 교감·대화할 것 |
| 행동 제약 | 특정 행위 금지 — 정령에 따라 다름 |
| 대가 제공 | 정령사의 에테르·생명력 일부를 정기 제공 |

### 계약의 깊이

| 단계 | 내용 |
|------|------|
| 임시 교감 | 계약 없이 일시적 협력. 효과 약함 |
| 소계약 | 단발성 협력 계약. 조건 이행 후 종료 |
| 정식 계약 | 지속적 동반자 관계. 정령사 등급 산정의 기준 |
| 심계약 | 정령과 정령사가 깊이 연결된 상태. 대정령과의 계약이 이에 해당 |

## 정령력 운용

### 정령사가 할 수 있는 것
- 계약 정령의 **속성 기반 현상 발현**
- 정령을 **물질화** 시켜 전투에 투입
- 정령의 **감각 공유** — 정찰·탐색에 유용
- 정령이 깃든 자연 환경에서 **강화 효과**

### 정령력 vs 에테르 마법 비교

| 항목 | 정령력 | 에테르 마법 |
|------|--------|-----------|
| 원천 | 정령의 의지·협력 | 마정석·외부 에테르 |
| 연산 방식 | 정령에게 요청 | 술식으로 직접 연산 |
| 유연성 | 정령 의지에 의존. 강제 불가 | 술식대로 정확히 발동 |
| 환경 영향 | 자연 환경에 크게 영향받음 | 상대적으로 환경 무관 |
| 한계 | 정령이 거부하면 불발 | 마정석 소진 시 불가 |

## 정령술 사용 가능 종족

| 사용 가능 | 조건 |
|----------|------|
| 엘프류 | 순혈 엘프, 하프 엘프, 다크 엘프 등 엘프 계통 전반. 개인차 있음 |
| 극히 일부 인간·타 종족 | 자연 친화적 소양 + 선천적 감응력 필요. 매우 희소 |

> 정령술은 에테르 재능과 별개
> 인간 정령사는 희소하기 때문에 세계관 내에서 특이한 존재 취급
