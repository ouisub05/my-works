# 에테르 사용 마물

## 개요

일반 마물과 달리 에테르를 능동적으로 사용하는 마물.
기존 마물 도감의 [E] 표기 개체. 현재 전 세계적으로 출현 빈도 급증 중.

---

## 발생 원인

### 자연 변이 — 원래부터 존재

| 항목 | 내용 |
|------|------|
| **발생 조건** | 에테르 밀집 지역에 수십~수백 년 장기 노출된 마물 |
| **발생 빈도** | 극히 드묾. 역사적으로 전설·소문 수준 |
| **특징** | 완만한 변이. 에테르 사용 방식이 서투름 |
| **사례** | 강티세 동맹 고산 에테르 밀집 지대 목격담. 아프라 마물 다발 지대 일부 기록 |

### 최근 급증 — 인위적 요인 의심

| 항목 | 내용 |
|------|------|
| **이상 시점** | 약 20~30년 전부터 출현 빈도 급격히 증가 |
| **급증 특징** | 자연 변이로 설명하기 어려운 속도·규모 |
| **인위적 요인 근거** | 특정 지역 집중 출현. 일부 개체에서 외부 에테르 각인 흔적 발견 |
| **의심 세력** | 불명. 국가·조직·개인 모두 가능성 열려있음 |
| **현재 상황** | 마기스테리움·마물 전문 헌터 길드 등 조사 중. 결론 미도출 |

> **"누군가 마물에 에테르를 심고 있다"** 는 소문이 헌터 사이에 돌고 있음
> 공식적으로 인정한 국가·조직은 아직 없음

## 에테르 사용 마물의 특성

### 강화형 (주류)

기존 마물이 에테르 능력을 추가로 획득한 형태.

| 항목 | 내용 |
|------|------|
| **외형** | 기존 마물과 유사. 에테르 발광·문양 등 시각적 변화 동반 |
| **등급 상승** | 기본 개체 대비 +1~2등급 상승 |
| **에테르 사용 방식** | 자기 강화·원거리 공격·방어막·감지 교란 등 |
| **지능** | 기존 개체보다 높아지는 경향. 함정·전술 사용 가능 |
| **기존 약점** | 일부 무효화. 화염에 약한 트롤이 에테르 방어막으로 보완하는 경우 |

### 신형 (극히 일부)

기존 마물과 전혀 다른 완전히 새로운 형태.

| 항목 | 내용 |
|------|------|
| **외형** | 기존 분류 불가. 에테르 자체가 형태 구성 요소 |
| **등급** | 확인된 사례 모두 5등급 이상 |
| **에테르 사용 방식** | 전신이 에테르 무기화. 주변 에테르 흡수·방출 |
| **발견 지역** | 아시란 고원 2건. 아프라 중부 1건. 베스테리아 북부 1건 |
| **현재 상태** | 전 4건 모두 토벌 완료. 연구 중 |

## 에테르 사용 마물 목격 현황

### 대륙별 출현 빈도

| 대륙 | 빈도 | 주요 출현 지역 |
|------|------|--------------|
| **베스테리아** | 중간 | 이스칼드 분트 북부. 에이렌발트 심부 |
| **아프라** | 높음 | 말리 마물 다발 지대. 중부 오지 |
| **아시란** | 높음 | 강티세 고원. 타이가 한대 지대. 투피 밀림 오지 |
| **노르테라** | 낮음 | 테노치 고대 유적 주변 |
| **수르테라** | 중간 | 칠람 유적 탐사 지역. 아마존 밀림 오지 |
| **오세라** | 낮음 | 파푸아 밀림. 호주 중부 사막 |

## 강화형 에테르 사용 마물 사례

### [E] 에테르 고블린

| 항목 | 내용 |
|------|------|
| **기반 마물** | 고블린 (기본 1등급) |
| **변이 등급** | 2~3등급 |
| **에테르 능력** | 에테르 함정 각인. 감지 교란 술식. 소형 에테르 투사체 |
| **위험도** | 기존 고블린 무리에 [E] 개체 포함 시 토벌 난이도 급상승 |
| **특징** | 무리 내 지휘관 역할. 다른 고블린 에테르 강화 지원 |

---

### [E] 에테르 트롤

| 항목 | 내용 |
|------|------|
| **기반 마물** | 트롤 (기본 3등급) |
| **변이 등급** | 5등급 |
| **에테르 능력** | 에테르 재생 가속. 물리·에테르 방어막. 에테르 충격파 |
| **위험도** | 최고위험. 기존 트롤 토벌법(화염) 통하지 않는 경우 있음 |
| **특징** | 화염에도 재생하는 사례 보고됨. 헌터 사망 사례 다수 |

---

### [E] 에테르 와이번

| 항목 | 내용 |
|------|------|
| **기반 마물** | 와이번 (기본 4등급) |
| **변이 등급** | 6등급 |
| **에테르 능력** | 브레스에 에테르 혼합. 광역 에테르 교란. 에테르 감지 역추적 |
| **위험도** | 국가 전력 투입 수준 |
| **특징** | 에테르 감지로 찾으면 역으로 위치 노출됨. 탐지 방법 재검토 필요 |
