# 오세라 조연 인물

> 성별·이름 미정. 추후 작성.
> 오세라는 비중이 낮은 대륙으로 인원 축소. 세력 소속 8인 + 독립 2인 = 총 10인.
> 갈등 중심 세력(쿠린·알체라) 2인씩. 나머지 세력 1인씩. 독립 2인.
> 스토리 연결 포인트: 쿠린 식량 패권.

---

## 세력 소속 조연 (8인)

---

### 1. 쿠린 연합 — 식량 배급 행정관

| 항목 | 내용 |
|------|------|
| **소속** | 쿠린 연합 맹주 직속 행정 조직 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열. 행정·기록 에테르 |
| **종족** | 인간 |
| **역할** | 야라·알체라·파푸아·마우이 식량 공급 실무 총괄. 의존 구조의 실질 설계자 |
| **성격** | 꼼꼼하고 계산적. 맹주의 전략을 가장 충실히 현장에서 구현. 그러나 의존 구조의 잔혹함을 가끔 자각 |
| **스토리 연결** | 알체라 마물 위협으로 식량 수요 급증 패턴 포착. 맹주에게 보고하며 알체라 상황 심각성 처음 전달 |

---

| 항목 | 내용 |
|------|------|
| **소속** | 없음. 누산타라-파푸아-쿠린 교역로 운영 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 교역·탐지 에테르 |
| **종족** | 인간. 누산타라 출신 |
| **역할** | 아시란 물자를 오세라 전역에 유통하는 독립 상인. 쿠린 식량 패권 구조의 외부 변수 |
| **성격** | 명랑하고 사교적. 오세라 정세를 가장 폭넓게 아는 외부인. 쿠린 의존 구조에 회의적 시각 제공 |
| **스토리 연결** | 야라 견제파에게 쿠린 대신 아시란 직거래 가능성 제안. 쿠린 식량 패권 구조의 균열 가능성 |

| **스토리 연결** | 알체라 견습(4번)과 비공식 교류. 세계적 [E] 마물 현상의 오세라 측 관찰자 역할 |

## 오세라 조연 관계망

| 연결 | 내용 |
|------|------|
| **1번 식량 행정관 → 맹주** | 알체라 위기 최초 보고 |
| **2번 청년 전사 ↔ 5번 야라 정찰병** | 접경 조우. 위협론 강화 자료 |
| **3번 외곽 수호 전사 → 비공개 수호파 원로** | 현실 호소. 제한적 공개파 공감 확산 |
| **4번 알체라 견습 ↔ 10번 떠돌이 정령술사** | 비공식 교류. 세계적 현상 인지 공유 |
| **7번 항법사 → 탐험 함대 제독** | 수르테라 방향 역추적 단서 |
| **9번 외부 상인 → 야라 견제파** | 쿠린 식량 패권 균열 가능성 제시 |
