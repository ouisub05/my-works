# 마우이 해연

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 뉴질랜드·태평양 섬 일대 |
| **체제** | 섬 연합. 대항해장 + 섬 추장 회의 |
| **국교** | 없음. 바다·별·바람 정령 신앙 |
| **주요 종족** | 인간 다수. 상어·갈매기·거북 계열 수인 소수 |
| **군사력** | 중하위권. 해상 전투 특화. 육상 전투 약함 |
| **에테르 기술** | 중하위권. 항해·해양 특화 에테르 기술 |

---

## 섬 연합 구조

| 항목 | 내용 |
|------|------|
| **대항해장** | 가장 뛰어난 항해사가 선출. 연합 대표 |
| **섬 추장 회의** | 각 섬 추장 참여. 주요 결정 공동 심의 |
| **섬 자율** | 각 섬 내정·자원 완전 자율 |
| **결속 기반** | 항해 기술 공유·태평양 항로 공동 운영 |

---

## 항해 기술 — 오세라 최강

| 기술 | 내용 |
|------|------|
| **별자리 항법** | 에테르로 별자리 에너지 감지. 야간·흐린 날 항법 가능 |
| **해류 감응** | 해류·조류 에테르 패턴 파악. 최적 항로 선택 |
| **바람 술식** | 에테르로 바람 방향·세기 조작. 역풍에서도 항해 가능 |
| **선박 에테르 강화** | 카누·선박에 에테르 각인. 내구성·속도 강화 |
| **수인 연계** | 상어·거북 계열 수인이 해류·수중 지형 안내 |

## 노르테라 방면 탐험

| 항목 | 내용 |
|------|------|
| **탐험 배경** | 동쪽 대양으로 항해 시 육지 흔적·새 이동 패턴 관찰 |
| **탐험 단계** | 1차 탐험대 파견 완료. 귀환 대기 중 |
| **발견 사항** | 노르테라 근접 섬 일부 발견. 본토 확인 직전 |
| **내부 반응** | 개방파(접촉 시도) vs 신중파(위험 경계) 논쟁 중 |

> 포르타 콘소르티움이 서쪽에서. 마우이 해연이 동쪽에서 노르테라 접근 중
> 양측 모두 서로의 존재를 모름
> 노르테라 입장에서 동서 양쪽에서 외부 세력 동시 접근이라는 상황
