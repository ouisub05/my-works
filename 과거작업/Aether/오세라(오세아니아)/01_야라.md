# 야라 왕국

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 호주 서부 일대. 사막·서부 해안 |
| **체제** | 부족 연합. 대장로 + 부족장 회의 |
| **국교** | 없음. 드림타임 신앙. 조상령·대지 정령 숭배 |
| **주요 종족** | 인간 다수. 딩고·캥거루 계열 수인 소수 |
| **군사력** | 하위권. 사막 생존 전투 특화 |
| **에테르 기술** | 낮음. 사막·대지 특화 에테르 기술 |

---

## 부족 연합 구조

| 항목 | 내용 |
|------|------|
| **대장로** | 정령 신앙 최고 권위자. 부족 연합 정신적 중심 |
| **부족장 회의** | 각 사막·해안 부족 수장 참여 |
| **결속 조건** | 외부 위협 시만 연합. 평시엔 각 부족 독립 생활 |

---

## 사막 자원

| 자원 | 내용 |
|------|------|
| **사막 마물 소재** | 서부 사막 특유 마물. 독소·갑각 소재 채취 |
| **희귀 광물** | 사막 지하 광물. 에테르 반응 있는 희귀 석재 |
| **약초·식물** | 사막 적응 식물. 의약·에테르 재료 활용 |

---

## 고립 전략

| 항목 | 내용 |
|------|------|
| **외부 접촉 최소화** | 오세라 내 다른 세력과도 교류 제한 |
| **고립 이유** | 드림타임 문화 오염 방지 |
| **자연 방어막** | 광대한 사막 지형. 외부 침략 사실상 불가 |
| **예외** | 쿠린 연합과 가끔 물자 교환. 완전 단절은 아님 |
