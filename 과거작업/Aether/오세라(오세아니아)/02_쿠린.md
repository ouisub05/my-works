# 쿠린 연합

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 호주 동부 일대. 동부 해안·내륙 평야 |
| **체제** | 부족 연합. 대의회 중심 |
| **국교** | 없음. 드림타임 신앙. 조상령·자연신 숭배 |
| **주요 종족** | 인간 다수. 캥거루·코알라·독수리 계열 수인 소수 |
| **군사력** | 중위권. 오세라 최대 규모 |
| **에테르 기술** | 중하위권. 농업·자연 특화 에테르 기술 |

---

## 대의회 구조

| 항목 | 내용 |
|------|------|
| **대의회** | 각 부족 대표 참여. 주요 결정 합의제 |
| **계절 회합** | 연 2회 전체 부족 대표 모임. 농업·교역·외교 결정 |
| **부족 자율** | 각 부족 내정 완전 자율 |
| **여성 원로** | 하우데노 연합과 유사한 여성 원로 제도 존재 |

---

## 농업 중심 경제

| 항목 | 내용 |
|------|------|
| **생산량** | 동부 해안·내륙 평야. 오세라 최대 식량 생산 |
| **에테르 농업** | 성장 촉진 술식·관개 에테르 기관 일부 활용 |
| **잉여 생산** | 오세라 내 다른 세력에 식량 공급. 교역 레버리지 |
| **식량 외교** | 야라·알체라에 식량 공급. 영향력 유지 수단 |

---

## 아시란과의 간접 연결

| 항목 | 내용 |
|------|------|
| **연결 구조** | 쿠린 → 파푸아 동맹 → 누산타라 동맹 → 아시란 |
| **교역 품목** | 쿠린 → 식량·동부 특산물 수출. 아시란 → 에테르 제품·마정석 수입 |
| **파푸아 의존** | 파푸아 없이는 아시란 접근 불가 |
| **직거래 시도** | 파푸아 경유 없이 아시란 직접 교역 시도 중. 아직 미달성 |

---

## 대외 관계

| 대상 | 관계 |
|------|------|
| **야라 왕국** | 식량 공급. 경제적 영향력 |
| **알체라 부족연** | 영적 순례 허용. 식량 제공 |
| **파푸아 동맹** | 핵심 교역 파트너. 아시란 연결 창구 |
| **마우이 해연** | 동부 해안 교역 관계. 비교적 우호 |
