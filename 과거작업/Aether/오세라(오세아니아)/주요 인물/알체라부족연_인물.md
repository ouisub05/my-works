# 알체라 부족연 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 알체라 부족연은 드림타임 성지 수호 완전 고립 세력.
> 내부 갈등: 성지 비공개 수호 vs 마물 증가로 인한 제한적 공개(외부 마물 퇴치 지원 요청) 필요성.

---

## 1. 대족장 (Altjira Kami)

| 항목 | 내용 |
|------|------|
| **직위** | 알체라 부족연 대족장. 드림타임 수호자 칭호 |
| **에테르** | 엘리트 중 (5단계). 정령사 계열. 드림타임 정령 다수 계약 |
| **성격** | 신비롭고 절대적. 드림타임 성지가 오세라의 에테르 원천이라는 확신. 외부 오염은 세계 자체를 해친다는 신념 |
| **현재 상황** | 완전 고립 유지. 사막 거인 마물 증가로 성지 방어 압박. 제한적 공개파 압박 점점 강해짐 |
| **핵심 목표** | 드림타임 성지 완전 순수 보전. 어떤 외부 접촉도 거부 |
| **갈등 요소** | 마물 증가로 자체 방어 한계 도달 중. 외부 지원 없이 성지 수호 가능한지 현실 직면 |

### 세부 특성
- 드림타임 정령과 의사소통 능력 보유. 성지 에테르 흐름 직접 감지
- 쿠린 자율 연합파 족장의 순례 허용 협약을 유일한 예외로 인정. 그 이상은 절대 불허
- [E] 마물 출현 감지. 드림타임 성지 에테르와 [E] 마물 에테르 패턴 충돌 현상 관찰 중
- 사막 거인 마물이 성지 주변에 증가하는 것이 자연 현상이 아닐 수 있다는 의심

## 2. 성지 비공개 수호파 원로 (Tjukurpa-elder)

| 항목 | 내용 |
|------|------|
| **직위** | 드림타임 성지 원로 수호자. 비공개 수호파 수장 |
| **에테르** | 엘리트 하 (4단계). 정령사 계열. 성지 특화 드림타임 정령 계약 |
| **성격** | 완고하고 전통 절대 고수. 외부인 한 명이라도 성지에 발을 들이면 드림타임이 오염된다는 확신 |
| **현재 상황** | 제한적 공개파 억제. 마물 증가에도 자체 해결 주장 |
| **핵심 목표** | 드림타임 성지 외부인 접근 영구 차단 |
| **갈등 요소** | 마물 소탕 전력 감소. 성지 일부 구역 마물에 잠식 위험 현실 |

### 세부 특성
- 수백 년 된 드림타임 성지 기록 보관자. 고대 에테르 패턴 지식 최고 권위
- 마물 증가가 성지 에테르 변화와 연관된다는 것 인지. 원인은 모름
- 자체 방어 한계를 인정하면서도 외부 개입보다 성지 일부 포기 선택 가능성 고려

## 3. 제한적 공개파 족장 (Wondjina-min)

| 항목 | 내용 |
|------|------|
| **직위** | 제한적 공개파 부족 대표. 마물 대응 외부 지원 요청 주장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 현실적이고 고통스러운 선택을 받아들이는 유형. 성지를 지키려면 일부를 잃어야 한다는 역설 수용 |
| **현재 상황** | 쿠린 자율 연합파에 마물 퇴치 지원 요청 타진 중. 대족장 허가 미획득 |
| **핵심 목표** | 마물 위협 제거. 성지 핵심 구역 보전. 비핵심 구역 외부 지원 허용 |
| **갈등 요소** | 수호파 원로의 강경 반대. 대족장 설득 핵심 과제 |

### 세부 특성
- 쿠린 자율 연합파 족장이 유일하게 신뢰하는 외부 연결 대상
- 마물 퇴치 지원 조건으로 성지 핵심 구역 외 접근 제한 협약 설계 중
- [E] 마물이 일반 마물과 다른 패턴이라는 것 전투에서 직접 경험. 외부 전문가 필요성 확신

## 4. 정령사 수장 (Mamu-tjukurpa)

| 항목 | 내용 |
|------|------|
| **직위** | 알체라 부족연 정령사 최고 권위자. 드림타임 정령 의식 총괄 |
| **에테르** | 정령사 대정령 (4단계). 사막·드림타임 대정령 심계약 보유. 알체라 최강 |
| **성격** | 현실과 드림타임 경계에 사는 존재. 정령의 언어로 사고. 외부 세계 개념 희박 |
| **현재 상황** | 드림타임 성지 에테르 이상 징후 집중 감지 중. [E] 마물과 에테르 충돌 패턴 분석 |
| **핵심 목표** | 드림타임 정령 체계 보전. 에테르 이상 원인 규명 |
| **갈등 요소** | 이상 징후 원인 규명에 외부 정보 필요할 수 있다는 인식. 고립 원칙과 충돌 |

### 세부 특성
- 드림타임 대정령과 심계약. 오세라 전역 정령 에테르 흐름 감지 가능
- 드림타임 성지 에테르가 [E] 마물에 의해 서서히 잠식되는 현상 포착. 투피 정령사 수장 유사 패턴과 동일 계통 가능성
- 오세라 전역 정령 에테르 변화가 전 세계적 현상의 일부일 수 있다는 인식. 그러나 외부 접촉 방법 모름
- 사막 거인 마물이 드림타임 에테르를 흡수하는 메커니즘 발견. 성지 에테르 고갈 경고 발령

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **대족장 → 정령사 수장** | 최고 신임. 성지 에테르 최종 판단 권위 |
| **대족장 → 수호파 원로** | 방침 일치. 핵심 지지 |
| **대족장 → 제한적 공개파** | 경청. 수용 유보 |
| **수호파 원로 ↔ 제한적 공개파** | 성지 공개 범위 대립 |
| **제한적 공개파 → 쿠린 자율 연합파** | 마물 지원 요청 타진 |
| **정령사 수장 → [E] 마물** | 드림타임 잠식 메커니즘 발견 |
| **정령사 수장 → 투피 정령사 수장** | 유사 패턴. 접촉 방법 모름 |
| **쿠린 자율 연합파 → 알체라** | 유일한 소통 채널 |
