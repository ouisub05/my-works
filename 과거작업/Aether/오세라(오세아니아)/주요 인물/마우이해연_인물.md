# 마우이 해연 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 마우이 해연은 태평양 탐험 선도 세력. 개인 탐험대가 수르테라를 이미 발견했으나 비밀 유지 중.
> 수장도 수르테라 발견 사실 모름.

---

## 1. 수장 (Ariki-nui)

| 항목 | 내용 |
|------|------|
| **직위** | 마우이 해연 최고 수장. 섬 연합 대표 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 해류·기상 에테르 특화 |
| **성격** | 탐험가 기질. 미지의 세계에 대한 강한 호기심. 마우이가 세계의 끝을 발견할 것이라는 확신 |
| **현재 상황** | 노르테라 방면 탐험 지속 지원. 파푸아 동맹과 탐험 경로 호위 협약 유지 |
| **핵심 목표** | 노르테라 접촉 성공. 마우이 해연을 세계 최대 항해 세력으로 발전 |
| **갈등 요소** | 오세라 연결 우선파의 탐험 자원 소모 반발. 개인 탐험대 행방 불명 구간 존재 |

### 세부 특성
- 파푸아 동맹 해상 경비대장과 탐험 경로 호위 협약. 경로 정보 일부 공유
- 개인 탐험대가 장기간 귀환 없음. 실종 가능성 우려 중. 실제론 수르테라 체류 중
- 쿠린 연합 방위 총사령관의 외부 세력 접근 경보를 인지. 마우이 탐험이 역방향 경로 개척임을 강조
- 오세라 연결 우선파 달래기 위해 파푸아·쿠린 정보 공유 협약 일부 체결

## 2. 노르테라 접촉 시도파 족장 (Tangaroa-min)

| 항목 | 내용 |
|------|------|
| **직위** | 노르테라 접촉 시도파 대표. 탐험 지지 최대 파벌 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 항법 에테르 특화 |
| **성격** | 낭만적 탐험가 기질. 노르테라 대륙 존재를 확신. 접촉 성공이 마우이 역사를 바꿀 것이라는 신념 |
| **현재 상황** | 탐험 함대 추가 편성 주장. 개인 탐험대 실종 구간 재탐사 계획 수립 |
| **핵심 목표** | 노르테라 공식 접촉. 새 교역 상대 발굴 |
| **갈등 요소** | 오세라 연결 우선파의 자원 반대. 개인 탐험대 실종 가능성이 추가 탐험 명분 약화 |

### 세부 특성
- 개인 탐험대 탐험 경로 마지막 보고 위치 파악. 재탐사 경로 설계 중
- 타이노 해연 존재 간접 인지. 노르테라 방면 교역 상대 후보로 거론
- 포르타 콘소르티움 존재 전혀 모름. 타이노와 접촉하면 포르타 정보 입수 가능성

## 3. 오세라 내 연결 우선파 족장 (Maui-min)

| 항목 | 내용 |
|------|------|
| **직위** | 오세라 연결 우선파 대표. 정착 기반 강화 주장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 현실적이고 보수적. 탐험 성과 없이 자원만 소모된다는 우려. 오세라 내 입지 강화가 우선 |
| **현재 상황** | 파푸아·쿠린과 연결 강화 추진. 탐험 예산 삭감 주장 |
| **핵심 목표** | 마우이 오세라 내 교역 입지 강화. 탐험 자원 오세라 내부 투자로 전환 |
| **갈등 요소** | 수장·탐험 지지파의 탐험 우선 방침. 개인 탐험대 실종 시 탐험 반대 논리 강화 |

### 세부 특성
- 파푸아 동맹 누산타라 협력 확대파와 비공식 교역 협의. 마우이 독자 교역 입지 강화
- 탐험대 실종이 확정되면 탐험 중단 주장 근거 확보 계획
- 수르테라 발견 사실 전혀 모름. 개인 탐험대가 귀환하면 탐험 가치 재평가 불가피

## 4. 탐험 함대 제독 (Kupe-toa)

| 항목 | 내용 |
|------|------|
| **직위** | 마우이 해연 탐험 함대 총사령관. 최강 전투 직군 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 태평양 원양 항해·해전 극한 특화 |
| **성격** | 바다가 곧 자신의 영역. 어떤 폭풍도 두렵지 않다는 자신감. 개인 탐험대를 경쟁자로 인식 |
| **현재 상황** | 탐험 함대 운영 총괄. 노르테라 방면 탐험 경로 개척 중 |
| **핵심 목표** | 노르테라 최초 공식 접촉. 개인 탐험대보다 먼저 도달 |
| **갈등 요소** | 개인 탐험대 실종 구간 정보 없음. 경로 불명확으로 탐험 속도 지연 |

### 세부 특성
- 태평양 해양 거북왕 마물 수차례 조우. 우회 경로 개발로 피해 최소화
- 파푸아 해상 경비대장과 호위 협약. 파푸아 해역 통과 시 협력
- 개인 탐험대가 자신보다 앞서 노르테라 방면에 있다는 것 직감. 경쟁심 강함
- 수르테라 방향 해류 패턴 분석 중. 개인 탐험대 경로 역추적 시도

## 5. 개인 탐험대장 (Rata-voyager)

| 항목 | 내용 |
|------|------|
| **직위** | 마우이 해연 비공식 개인 탐험대 수장. 공식 직위 없음 |
| **에테르** | 엘리트 상 (6단계). 마법사 계열. 항법·해류·바람 에테르 극한 특화 |
| **성격** | 자유로운 탐험가. 규칙·명령 거부. 미지를 향한 순수한 탐험 욕구. 발견한 것을 독점하려는 욕심 |
| **현재 상황** | 수르테라 남부 해안 발견. 칠람 동맹 방향 해안선 탐사 중. 마우이 귀환 유보 |
| **핵심 목표** | 수르테라 전체 해안선 탐사 완료. 귀환 시 최대 협상력 확보 |
| **갈등 요소** | 수르테라 현지 세력(마푸·아우카 인접 해안) 발각 위험. 자원 소모 한계 |

### 세부 특성
- 수르테라 남단 파타고니아 해안 발견. 아우카 부족연 영역 인접 해안 탐사 완료
- 마푸 연합 해안 지형 일부 관찰. 현지 세력 존재 파악. 접촉 시도 않고 관찰만 유지
- 탐험 함대 제독이 경로 역추적 중임을 모름. 귀환 전 최대한 탐사 완료 계획
- 수르테라 발견 정보를 마우이 귀환 시 최대 가치로 협상하려는 계획. 수장·연합 내 자신의 위상 극대화 목표

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **수장 → 탐험 함대 제독** | 신임. 탐험 기반 |
| **수장 → 노르테라 접촉 시도파** | 방침 공유 |
| **수장 → 오세라 연결 우선파** | 달래기. 일부 협약 체결 |
| **노르테라 접촉 시도파 ↔ 오세라 연결 우선파** | 탐험 vs 정착 대립 |
| **탐험 함대 제독 → 개인 탐험대장** | 경쟁자 인식. 경로 역추적 |
| **개인 탐험대장 → 수르테라** | 비밀 탐사 중 |
| **개인 탐험대장 → 마우이 수장** | 귀환 유보. 수장 모름 |
| **수장 → 파푸아 해상 경비대장** | 호위 협약 |
