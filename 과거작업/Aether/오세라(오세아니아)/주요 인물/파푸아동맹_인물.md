# 파푸아 동맹 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 파푸아 동맹은 오세라-아시란 교역 창구. 맹주는 교역 확대파.
> 내부 갈등: 누산타라 의존 축소+오세라 연결 강화 vs 누산타라 협력 확대+독자 교역.

---

## 1. 맹주 (Hiri-Moale)

| 항목 | 내용 |
|------|------|
| **직위** | 파푸아 동맹 맹주. 부족 대표 회의 선출 |
| **에테르** | 엘리트 하 (4단계). 마법사 계열. 탐지·협상 보조 에테르 특화 |
| **성격** | 활발하고 개방적. 교역이 곧 파푸아의 생존이라는 철학. 어느 방향이든 더 많은 교역이 답이라는 신념 |
| **현재 상황** | 누산타라 교역 확대와 오세라 내 연결 강화 동시 추진. 두 파벌 조율 중 |
| **핵심 목표** | 파푸아를 오세라-아시란 교역 허브로 발전. 교역 다각화 |
| **갈등 요소** | 오세라 연결 강화파와 누산타라 협력 확대파 방향 충돌. 자원 배분 한계 |

### 세부 특성
- 쿠린 연합 맹주와 오세라 내 식량·교역 협약 체결. 쿠린 식량·파푸아 외부 정보 교환 구조
- 누산타라 교역 함대 제독과 정기 교역 협약. 아시란 물자 오세라 유입 창구
- 알체라 부족연 제한적 공개파 족장의 마물 지원 요청 인지. 쿠린 자율 연합파 통해 간접 파악
- 마우이 해연 탐험 경로가 파푸아 교역망 확장 기회라는 인식

## 2. 누산타라 의존 축소·오세라 연결 강화파 수장 (Gogodala-min)

| 항목 | 내용 |
|------|------|
| **직위** | 오세라 연결 강화파 대표. 파푸아 내륙 부족 수장 |
| **에테르** | 어뎁트 상 (3단계). 무인 계열 |
| **성격** | 오세라 정체성 강함. 파푸아가 오세라 내 다른 세력을 연결하는 역할을 해야 한다는 신념. 누산타라 의존이 파푸아 자율성 침해라는 우려 |
| **현재 상황** | 쿠린·야라·알체라 연결망 강화 주도. 누산타라 협약 재협상 주장 |
| **핵심 목표** | 파푸아 오세라 게이트웨이 역할 확립. 누산타라 의존도 감소 |
| **갈등 요소** | 누산타라 없이 아시란 물자 확보 대안 부재. 협력 확대파의 현실론 반박 어려움 |

### 세부 특성
- 쿠린 교역로 수호대장과 협력. 오세라 내 교역로 공동 관리 체계 구축
- 알체라 마물 위협 정보 파악. 파푸아 밀림 방어와 연계한 오세라 방어망 구상
- 누산타라 해적 섬 수장의 파푸아 선박 약탈 전례에 강한 불신. 협약 신뢰성 문제 제기

## 3. 누산타라 협력 확대·독자 교역파 수장 (Sepik-min)

| 항목 | 내용 |
|------|------|
| **직위** | 누산타라 협력 확대파 대표. 해안 부족 수장 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열 |
| **성격** | 실용주의. 누산타라 교역이 파푸아 최대 수입원이라는 현실 직시. 오세라 내부 연결은 장기 과제 |
| **현재 상황** | 누산타라 교역 함대 제독과 협약 확대 협상 진행 중. 아시란 직거래 가능성 탐색 |
| **핵심 목표** | 누산타라 협력 심화. 독자 아시란 교역 루트 개척 |
| **갈등 요소** | 오세라 연결파의 누산타라 불신 논리. 맹주의 균형 방침 |

### 세부 특성
- 누산타라 교역 함대 제독과 직접 채널 보유. 아시란 물자 정보 입수
- 바라타 연방 인도양 제독과 파푸아 방면 간접 접촉 가능성 탐색 중
- 마우이 해연 탐험 경로가 새 교역 루트 가능성. 독자 탐험 지원 주장

## 4. 해상 경비대장 (Lakatoi-guard)

| 항목 | 내용 |
|------|------|
| **직위** | 파푸아 동맹 해상 경비대 총사령관. 최강 전투 직군 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 해상 전투·열대 해역 특화 |
| **성격** | 경계심 강하고 원칙적. 교역 찬반 논쟁 무관심. 파푸아 해역 안전이 유일한 관심사 |
| **현재 상황** | 파푸아 해역 순찰 총괄. 누산타라 선박 동향 감시. 밀림 독안개 마물 해안 출몰 대응 |
| **핵심 목표** | 파푸아 해역 완전 통제. 교역 선박 안전 보장 |
| **갈등 요소** | 누산타라 해적 섬 선박이 교역선과 구별 어려움. 협약 있어도 의심 지속 |

### 세부 특성
- 밀림 독안개 마물 해안 출몰 대응 전문. 파푸아 해안 마물 분포 완전 파악
- 누산타라 교역 함대 제독과 협력하나 해적 섬 선박엔 독자 감시 유지
- 마우이 해연 탐험 선박 파푸아 해역 통과 시 호위 조건 요구. 탐험 안전 보장 대가 정보 공유
- 산호 마물 파푸아 연안 분포 완전 파악. 쿠린 교역로 수호대장에게 정보 제공

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **맹주 → 해상 경비대장** | 신임. 해역 방어 기반 |
| **맹주 → 오세라 연결 강화파** | 방향 지지. 속도 조율 |
| **맹주 → 누산타라 협력 확대파** | 현실 기반 인정. 균형 유지 |
| **오세라 연결 강화파 ↔ 누산타라 협력 확대파** | 방향 대립 |
| **오세라 연결 강화파 → 쿠린 교역로 수호대장** | 협력. 오세라 교역망 구축 |
| **누산타라 협력 확대파 → 누산타라 교역 제독** | 협약 확대 협상 |
| **해상 경비대장 → 누산타라 선박** | 협약 있어도 독자 감시 |
| **해상 경비대장 → 마우이 해연** | 호위 조건 정보 교환 |
| **맹주 → 쿠린 맹주** | 오세라 내 협약 파트너 |
