# 야라 왕국 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 야라 왕국은 호주 서부 사막 중심. 고립 유지 원칙. 쿠린 연합과 경쟁·협력 갈등.

---

## 1. 왕 (Baal-Baal)

| 항목 | 내용 |
|------|------|
| **직위** | 야라 왕국 국왕. 세습 왕정 |
| **에테르** | 엘리트 하 (4단계). 무인 계열. 사막 생존·전투 특화 |
| **성격** | 과묵하고 자존심 강함. 야라 사막이 최고의 방어막이라는 자신감. 외부 필요 없다는 원칙 |
| **현재 상황** | 고립 유지 원칙 고수. 쿠린 연합 견제와 협력 사이 내부 갈등 관리 |
| **핵심 목표** | 야라 독립 유지. 사막 자원 독자 관리. 쿠린 주도권 배제 |
| **갈등 요소** | 쿠린 연합의 오세라 패권 시도. 협력파의 쿠린 연대 압박 |

### 세부 특성
- 파푸아 동맹과 최소한의 간접 교역 채널 유지. 외부 정보 수집 목적
- 쿠린 연합 맹주와 수차례 회의 참석. 표면 협력하나 실질 독자 노선 유지
- 아우카 마정석 발견 소문 간접 입수. 오세라 내 자원 가치 재평가 계기
- 알체라 부족연의 완전 고립 방침을 극단적으로 보나 이해는 함

## 2. 쿠린 견제파 귀족 수장 (Mirning-min)

| 항목 | 내용 |
|------|------|
| **직위** | 쿠린 견제파 귀족 연합 수장. 왕 지지 핵심 |
| **에테르** | 어뎁트 상 (3단계). 무인 계열 |
| **성격** | 강경하고 자존심 강함. 쿠린이 야라를 흡수하려 한다는 의심 확고. 협력 자체를 위협으로 인식 |
| **현재 상황** | 쿠린 연합과 모든 협력 협약 재검토 주장. 왕의 지지 기반 |
| **핵심 목표** | 야라 완전 자립. 쿠린 의존 제로화 |
| **갈등 요소** | 협력 없이 자원 개발 한계. 현실론에 반박 어려움 |

### 세부 특성
- 쿠린 연합 내부에 야라 정보 수집 요원 있다는 의심. 근거 불충분
- 파푸아 동맹과 교역 확대 주장. 쿠린 대신 파푸아 통해 외부 연결
- 알체라 부족연과 비공식 연락. 고립 원칙 연대 공감

---

## 3. 쿠린 협력파 귀족 수장 (Noongar-min)

| 항목 | 내용 |
|------|------|
| **직위** | 쿠린 협력파 귀족 연합 수장. 의회 내 2위 파벌 |
| **에테르** | 어뎁트 상 (3단계). 마법사 계열 |
| **성격** | 실용주의. 쿠린 연합과 협력이 야라 자원 개발·외부 위협 대응에 유리하다는 현실 판단 |
| **현재 상황** | 쿠린 연합 맹주와 비공식 채널 유지. 협력 조건 탐색 중 |
| **핵심 목표** | 쿠린과 대등한 협력 관계 구축. 야라 자원 개발 가속 |
| **갈등 요소** | 왕·견제파의 고립 원칙. 협력이 종속으로 이어진다는 반론 |

### 세부 특성
- 쿠린 연합 맹주와 개인적 친분. 맹주의 야라 흡수 의도 없다는 것 신뢰
- 파푸아 동맹 교역에도 찬성. 다각 연결망 구축 선호
- 마우이 해연의 외부 탐험 정보에 관심. 오세라 외부 세계 정보 수집 필요성 주장

## 4. 사막 전사 수장 (Wandjina-naom)

| 항목 | 내용 |
|------|------|
| **직위** | 야라 왕국 최강 전투 직군. 사막 전투 총수 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 호주 서부 사막 극한 환경 전투·열기 에테르 특화 |
| **성격** | 사막처럼 건조하고 직선적. 사막이 곧 방어막이라는 확신. 외부 세력이 야라 사막에서 살아남지 못한다는 자신감 |
| **현재 상황** | 사막 방어선 총괄. 쿠린 연합 접경 순찰 겸임 |
| **핵심 목표** | 야라 사막 영토 완전 방어. 어떤 외부 세력도 사막 내부 침투 불허 |
| **갈등 요소** | 협력파가 쿠린과 공동 방어 훈련 제안. 독자 방어 원칙과 충돌 |

### 세부 특성
- 호주 대형 유대 마수 소탕 경험 다수. 사막 마물 대응 전문
- 나바호 왕국 사막 전사 수장과 간접 비교 대상. 직접 교류 없음
- 사막 열기 에테르 전술 독자 발전. 외부 침입자 전투 전 환경에 소모시키는 방식
- 쿠린 연합 최강 전사와 실력 비교 대상으로 거론됨. 직접 대면 없음

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **왕 → 사막 전사 수장** | 신임. 방어 기반 |
| **왕 → 쿠린 견제파** | 핵심 지지 기반 |
| **왕 → 쿠린 협력파** | 경청. 수용 않음 |
| **쿠린 견제파 ↔ 쿠린 협력파** | 의회 내 대립 |
| **쿠린 견제파 → 알체라 부족연** | 고립 원칙 연대 |
| **쿠린 협력파 → 쿠린 연합 맹주** | 비공식 채널 |
| **사막 전사 수장 → 협력파** | 공동 훈련 반대 |
| **왕 → 파푸아 동맹** | 간접 교역 최소 유지 |
