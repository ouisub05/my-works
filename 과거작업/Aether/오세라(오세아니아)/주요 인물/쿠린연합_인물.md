# 쿠린 연합 주요 인물

> 모든 인물 성별 미정.
> 이름 미정. 추후 작성.
> 쿠린 연합은 오세라 최대 세력. 식량 패권 기반 실질 패권 유지. 통합 강행보다 의존 구조 선호.

---

## 1. 맹주 (Baiame)

| 항목 | 내용 |
|------|------|
| **직위** | 쿠린 연합 맹주. 6개 농업 부족 연합 대표 |
| **에테르** | 엘리트 중 (5단계). 마법사 계열. 농업 에테르·기상 조작 특화 |
| **성격** | 여유롭고 자신감 넘침. 식량이 곧 권력이라는 철학. 강제보다 의존 구조가 더 오래간다는 신념 |
| **현재 상황** | 야라·알체라·파푸아·마우이 모두에 식량 공급 채널 유지. 쿠린 없이는 오세라 운영 안 된다는 구조 구축 중 |
| **핵심 목표** | 쿠린 식량 패권으로 오세라 실질 지배. 강제 통합 없이 자연스러운 의존 구조 심화 |
| **갈등 요소** | 통합 강행파의 속도 압박. 야라의 완강한 독립 고집이 식량 의존 구조 완성 방해 |

### 세부 특성
- 기상 조작 에테르로 오세라 농업 생산량 최대화. 가뭄 시 유일한 식량 공급원 역할
- 야라 왕과 표면 협력 관계 유지. 야라 협력파 귀족과 비공식 채널 별도 운영
- 파푸아 동맹과 교역 협약. 아시란 물자·정보 오세라 내 유일 창구 역할
- 마우이 해연 탐험 정보를 오세라 내 독점 수집. 외부 세계 변화 파악 우위

## 2. 통합 강행파 족장 (Daramulun-min)

| 항목 | 내용 |
|------|------|
| **직위** | 통합 강행파 대표. 가장 큰 농업 부족 족장 |
| **에테르** | 엘리트 하 (4단계). 무인 계열 |
| **성격** | 공격적이고 조급함. 식량 의존 구조만으로는 부족. 정치적 통합이 완성이라는 주장 |
| **현재 상황** | 야라·알체라 강제 통합 편입 주장. 맹주 방침에 답답함 |
| **핵심 목표** | 오세라 완전 통합. 쿠린 주도 단일 체제 수립 |
| **갈등 요소** | 맹주의 점진 의존 방침. 야라 사막 전사 수장의 저항력 과소평가 지적 받음 |

### 세부 특성
- 야라 사막이 실제 얼마나 방어적인지 직접 경험 없음. 과소평가 경향
- 알체라 부족연 완전 고립 방침을 가장 이해 못하는 인물. 강제 편입 시도 주장
- 마우이 해연 외부 탐험 정보를 쿠린 확장 명분으로 활용 주장

## 3. 자율 연합파 족장 (Bunjil-min)

| 항목 | 내용 |
|------|------|
| **직위** | 자율 연합파 대표. 소규모 농업 부족 연합 수장 |
| **에테르** | 엘리트 하 (4단계). 정령사 계열. 초원·농지 정령 소계약 |
| **성격** | 온건하고 협력 지향. 오세라 각 세력 자율성 존중하며 느슨한 연합이 강제 통합보다 지속 가능하다는 신념 |
| **현재 상황** | 맹주 방침 지지. 통합 강행파 견제. 야라·알체라와 우호 관계 유지 시도 |
| **핵심 목표** | 느슨한 오세라 자율 연합 유지. 강제 통합 저지 |
| **갈등 요소** | 외부 세력 접근 시 자율 연합으로는 대응 한계. 통합파 주장 설득력 증가 가능성 |

### 세부 특성
- 야라 협력파 귀족 수장과 우호 관계. 야라 내부 협력 확대 가교 역할
- 알체라 부족연 성지 순례 허용 협약 유지. 유일하게 알체라와 소통하는 쿠린 인물
- 파푸아 동맹과 교역 확대 찬성. 강제 통합 대신 교역망 확대로 연결 강화 주장

## 4. 방위 총사령관 (Ngurunderi-sen)

| 항목 | 내용 |
|------|------|
| **직위** | 쿠린 연합 방위군 총사령관. 최강 전투 직군 |
| **에테르** | 엑스퍼트 하 (7단계). 무인 계열. 농업 지대 방어·평원 전투 특화 |
| **성격** | 원칙적이고 균형적. 통합·자율 논쟁보다 오세라 전체 방어 준비에 집중. 외부 위협 주시 |
| **현재 상황** | 쿠린 방어선 유지. 파푸아 동맹 통해 외부 세계 군사 동향 간접 파악 중 |
| **핵심 목표** | 쿠린 농업 지대 완전 방어. 오세라 외부 위협 조기 탐지 |
| **갈등 요소** | 마우이 해연 외부 탐험이 외부 세력 오세라 접근 경로 개척일 수 있다는 우려 |

### 세부 특성
- 호주 대형 유대 마수 대응 경험 다수. 오세라 마물 전반 파악 완료
- 파푸아 동맹 해상 경비대와 협력 채널. 외부 선박 동향 공유
- 야라 사막 전사 수장의 전투력 간접 파악. 강제 통합 시 상당한 소모 예상. 통합 강행파 견제 논리 제공
- 마우이 해연 탐험 경로가 아시란 교역 세력에게도 오세라 접근 경로가 될 수 있다는 경보 발령

---

## 5. 교역로 수호대장 (Mimi-guard)

| 항목 | 내용 |
|------|------|
| **직위** | 오세라 내 교역로 방어 전담 수장. 맹주 직속 |
| **에테르** | 엘리트 상 (6단계). 무인 계열. 교역로 순찰·호위 전투 특화 |
| **성격** | 실용적이고 정보 지향. 교역로가 곧 쿠린 패권의 동맥이라는 인식. 교역로 차단은 곧 쿠린 몰락 |
| **현재 상황** | 오세라 내 모든 교역로 순찰 총괄. 야라·파푸아·마우이 방면 교역로 안전 확보 |
| **핵심 목표** | 오세라 교역로 완전 통제. 쿠린 식량 패권 물류 기반 보호 |
| **갈등 요소** | 야라 측 교역로 구간에서 야라 협조 없이 순찰 한계. 야라 고립 방침과 충돌 |

### 세부 특성
- 산호 마물 오세라 연안 출몰 대응 다수 경험. 해상 교역로 마물 대응 전문
- 파푸아 동맹과 해상 교역로 공동 관리 협약 운영
- 마우이 해연 탐험 경로가 새 교역로 가능성 평가. 맹주에게 선점 제안 보고
- 알체라 부족연 성지 주변 교역로 우회 경로 독자 개발. 알체라 자극 없이 물자 이동

## 인물 관계도

| 관계 | 내용 |
|------|------|
| **맹주 → 방위 총사령관** | 신임. 방어 기반 |
| **맹주 → 교역로 수호대장** | 직속. 식량 패권 물류 기반 |
| **맹주 → 통합 강행파** | 속도 조절. 점진 방침 |
| **맹주 → 자율 연합파** | 방침 공유. 균형추 |
| **통합 강행파 ↔ 자율 연합파** | 오세라 통합 방식 대립 |
| **자율 연합파 → 야라 협력파** | 가교 역할 |
| **자율 연합파 → 알체라 부족연** | 유일한 소통 채널 |
| **방위 총사령관 → 파푸아 동맹** | 외부 동향 정보 공유 |
| **교역로 수호대장 → 파푸아 동맹** | 해상 교역로 공동 관리 |
| **맹주 → 야라 협력파 귀족** | 야라 내부 비공식 채널 |
