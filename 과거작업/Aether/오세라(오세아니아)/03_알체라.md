# 알체라 부족연

## 기본 정보

| 항목 | 내용 |
|------|------|
| **위치** | 호주 중부 내륙. 광대한 사막 지대 |
| **체제** | 부족 연합. 꿈의 장로 협의체 |
| **국교** | 드림타임 신앙. 오세라에서 가장 순수하게 보존 |
| **주요 종족** | 인간·수인 혼재. 딩고·도마뱀·독수리 계열 수인 다수 |
| **군사력** | 중하위권. 수인 전사 중심. 사막 전투 특화 |
| **에테르 기술** | 중하위권. 사막 자연 에테르 특화 |

---

## 꿈의 장로 협의체

| 항목 | 내용 |
|------|------|
| **꿈의 장로** | 드림타임과 교감하는 최고 영적 권위자 |
| **부족 장로** | 각 부족 원로. 협의체 구성 |
| **결정 방식** | 만장일치. 느리나 강한 결속 |
| **외부 접촉 원칙** | 협의체 전원 동의 없이 외부 접촉 금지 |

---

## 완전 고립

| 항목 | 내용 |
|------|------|
| **고립 이유** | 드림타임 문화 오염 방지 |
| **자연 방어막** | 광대한 사막 지형. 외부 세력 접근 자체가 어려움 |
| **예외** | 쿠린·야라 부족의 영적 순례 목적 방문만 허용 |
| **오세라 불문율** | 알체라 침범 시 오세라 전체 부족 공동 적으로 간주 |

---

## 자연 에테르 특화

| 기술 | 내용 |
|------|------|
| **대지 감응** | 사막 대지의 에테르 흐름 직접 감지·활용 |
| **열기 조절** | 극한 더위 에테르로 조절. 사막 생존 핵심 |
| **수맥 탐지** | 사막 지하 수원 에테르 감지 |
| **모래폭풍 감지** | 에테르로 기상 변화 사전 감지 |

## 수인 군사 구성

| 종류 | 특화 능력 | 군사 역할 |
|------|----------|----------|
| **딩고 계열** | 후각·지구력·무리 전투 | 사막 추적·순찰 |
| **도마뱀 계열** | 은신·열기 내성·독소 | 매복·함정 특화 |
| **독수리 계열** | 시각·비행·광역 정찰 | 사막 감시·기습 |
