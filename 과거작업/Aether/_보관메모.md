# Aether 보관 메모

작업 기간: 2026년 4월~6월 (파일 날짜 기준)

지구와 지형이 같은 평행세계에 문화권 모티프를 빌려 온 세계관이다. 대륙은 베스테리아(유럽), 아프라(아프리카), 아시란(아시아), 노르테라(북아메리카), 수르테라(남아메리카), 오세라(오세아니아) 여섯이다.

## 들어 있는 것

- `공통 설정`: 에테르 체계(무인과 마법사, 쌍도), 전투직군 등급, 마물, 신, 정령, 문명과 기술 수준, 길드, 역사와 지리의 골격, 경제·법·언어, 마정석, 화폐와 물가, 성기사와 신관, 첩보 조직, 고대 문명과 유적, 대륙별 신 목록, `종족 설정`
- 대륙별 폴더: 나라마다 파일 하나, 세력 관계도, 조연 목록, `주요 인물` 폴더

## 지금 설정과 다른 점

- 힘의 이름이 에테르이고, 무인(몸 안의 에테르)과 마법사(바깥 에테르와 술식)로 나뉜다. 지금 설정은 마나에서 오러와 마법으로 나뉜다.
- 신은 여럿이지만 실재하는지 세계 안에서도 알 수 없다. 지금 설정에서는 신들이 실재했고 하늘로 떠났다.
- 실제 문화권의 이름을 빌린 나라가 많다. 지금 설정은 실제 지명과 민족 이름을 쓰지 않는다.
