# 에테르 세계관

성력 1341년. 신이 있는지 아무도 모르는 세계의 설정집.

## 이 저장소를 쓰는 법

**고치는 곳은 `1_설정집` 하나뿐입니다.** `2_위키`는 파생물이며 설정집에서 다시 뽑습니다.

```
1_설정집/     ← 원본 (34권)
2_위키/       ← 파생물. 손대지 않는다
3_보관/       ← 날짜별 스냅숏 (Git을 쓰면 불필요)
```

어디에 무엇이 있는지는 [`1_설정집/00_인덱스.txt`](1_설정집/00_인덱스.txt)를 보십시오.
용어는 [`98_용어사전.txt`](1_설정집/98_용어사전.txt), 이력은 [`99_변경이력.txt`](1_설정집/99_변경이력.txt)에 있습니다.

## 정본 규칙 — 값이 어긋나면 누가 이기는가

| 무엇 | 정본 |
|---|---|
| 종족·인구 수치 | `15` |
| 물가·화폐 값 | `20` [II] |
| 국가별 법의 세 줄·승계 | `27` (해설은 각 대륙 파일) |
| 신분의 지형·예속민·경칭 | `20b` [III-A] |
| 작위·서임·성직 서열 | `26` |
| 고유명·지명 | `08` |
| 도량형 | `21` [IV] |
| 시한폭탄 코드 | `14` |
| [미정] 목록 | `06` |
| 등급·척도 | `16` |
| 이력 | `99` |

**파일 말미의 `[연쇄 반영]` 블록은 이력이지 값이 아닙니다.**
값을 고쳤으면 반드시 정본의 본문·표에 손을 대십시오.
블록에만 적어 두어 값이 두 곳에 살았던 전례가 있습니다 (`99` 참조).

## 작업 규칙

인수인계 문서의 `[0] 작업 규칙`이 전부입니다. 요지만 옮기면:

1. **질문은 한 번에 하나.** 여러 개를 몰아 묻지 않는다.
2. **사용자 대신 답하지 않는다.** 지어낸 것은 `[위임 창작분(변경 가능)]`으로 표시한다.
3. **고치면 연쇄를 따라간다.** 한 파일만 고치고 끝내지 않는다.
4. **세션이 끝나면** `99`와 `HANDOFF`를 갱신한다.

## 커밋 메시지

```
[모순] 별급 인구 통일 — 16을 정본으로 (23·15·05·13·14·24)
[미정] 여성 작위 보유자의 경칭 확정 (20b-III-A-6)
[설계] 수리아 계급 눈금 신설 (26-XVII-B)
[위키] HTML 갱신 + 마크다운 재생성
[정리] 참조 번호 오기 6건
```

앞의 대괄호를 이슈 라벨과 맞춰 두면 나중에 찾기 쉽습니다.
