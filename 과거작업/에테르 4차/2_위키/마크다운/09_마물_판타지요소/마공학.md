# 마공학

**魔工學**

| | |
|---|---|
| **보급** | 꽤 퍼짐 — 변두리 여관에도 마법등 하나쯤 |
| **동력** | 등불류는 거의 안 닳고, 통신구·병기는 마정석을 먹음 |
| **병기** | 사람이 우위 · 공성과 함포 자리에만 |
| **격차 조건** | 마정석 × 드워프·노움의 자유 × 국가의 후원 |

| **연동** | [골렘](골렘.md) · [아카데미](아카데미.md) · [유적](유적.md) |

## 개요
- 과학보다 마법이 빨리 자란 문명의 얼굴. 13~14세기 수준의 세상인데 변두리 마을 여관에도 촛불 대신 마법등이 걸려 있다. [노움](../02_종족/노움.md)이 각지 도시에 섞여 사는 한 안 퍼지는 쪽이 되레 이상하다.
- 선 긋기
  - · 켜고 끄는 물건은 흔하되, **스스로 움직이는 물건**([골렘](골렘.md))은 아직 최전선이다
  - · ∴ 사람들은 마공학을 신기해하지 않는다 — 마법등은 익숙하고 걸어 다니는 돌덩이는 낯설다
  - · 그것이 아케르부스가 마물 취급을 받는 이유이기도 하다
- 파생 — 마법등이 흔하다는 것은 밤에 일할 수 있다는 뜻이다
  - · 길드 야간 근무, 밤에도 도는 항구, 밤샘 필사

## 동력 — 품목마다 다르다
- 두 갈래
  - **등불류** — 거의 닳지 않는다. 한 번 만들면 오래 가는 살림살이다. 단 영구는 아니며 수십 년에서 백 년에 걸쳐 서서히 스러진다
  - **힘을 쓰는 물건**(통신구·병기 등) — 마정석을 먹는다. 쓰는 만큼 사라진다
- [카람](../04_마슈리크/카람/카람.md) 술탄국 국부의 실제 원천이 여기서 확정된다
  - · 여관 등불이 아니라 **군대·통신·공방**이다
  - · ∴ 마정석 수요는 평시에 잔잔하고 전시에 폭발하는 성질을 가진다
- 전쟁의 성격이 바뀐다
  - · 통신구를 쓰는 쪽은 명령을 빨리 내리는 대신 마정석을 태운다
  - · 길어지면 부유한 쪽이 이긴다 → 보급선이 곧 마정석선인 나라가 생긴다
- 룬 각인 구조와 정합한다
  - · 전용 광석 = 오래 머금는 그릇 / 마정석 = 태워 쓰는 연료 쪽
  - → 마정석이 더 값진 이유가 설명된다
- 파생
  - · 등불은 유산으로 물려주고, 통신구는 유지비를 못 내 팔아 버리는 집이 생긴다 (가난한 영주가 통신구를 창고에 처박아 둔다)
  - · 아케르부스가 몇 해가 지나도 그 자리에 서 있는 이유 — 버려진 룬 조각은 오래 머금는 쪽이기 때문이다

## 군용 마법 병기 — 사람이 우위다
- 봉화급 하나가 병기 여럿보다 낫다
  - · 병기는 어디까지나 보조이며, 사람과 겨루는 관계가 아니다
  - · 역할이 다르다 — 공성·함포처럼 **사람이 못 하는 자리**에만 병기가 선다
  - · [에테르](../01_세계관_코어/에테르.md)의 "고위 능력자 = 국가 전략 자산"이 흔들리지 않는다. 이 세계는 아직 사람이 최강의 병기인 시대다
- 병기의 자리는 성벽과 바다다
  - · ∴ 공성전과 해전이 마정석을 가장 많이 태우는 자리가 된다
- 일부러 비켜 간 것
  - · "병기가 기사를 밀어내는 전환점"은 채택하지 않았다
  - → 이 세계의 긴장은 여전히 사람과 사람 사이에 있다
- 파생 — 왕과 영주의 힘 차이가 굳는다
  - · 공성 병기는 값도 마정석도 국가 규모라 영주가 살 수 없는 물건이다
  - · 성이 옛날만큼 든든하지 않게 된다
  - · 뒤집으면 성을 못 부수는 나라는 전쟁을 오래 끌 수밖에 없다 (십자군이 세 번 갔다 오고도 결판이 안 난 사정과 결이 맞는다)

## 격차의 조건 — 곱셈 구조
- 세 조건이 모두 갖춰져야 한다
  - · 하나라도 빠지면 앞서지 못하는 곱셈 구조다
  - **1)** 마정석이 많을수록
  - **2)** [드워프](../02_종족/드워프.md)·[노움](../02_종족/노움.md)이 자유로울수록
  - **3)** 나라가 밀어줄수록
- "자유로울수록"의 무게
  - · 종족을 억누르는 나라는 도덕적으로 나쁜 것이 아니라 **기술적으로 뒤처진다** — 훈계가 아니라 결과로 벌을 받는 구조다
  - · 뒤집으면 노움을 붙들어 공방에 밀어 넣으면 정책은 채우되 자유를 깎는다
  - → '밀어주는 것'과 '묶어 두는 것'의 경계가 그 나라 마공학의 천장이 된다
- 자원만으로는 아무것도 아니다
  - · 캐서 파는 나라와 만들어 파는 나라는 다르다
  - · 반대로 산도 광도 없는 나라도 앞설 수 있다 — 마정석은 사 오면 된다
  - → 상업 도시가 마공학 도시가 되는 길이 열린다
  - · **귀결: 마공학 지도는 광산 지도와 다르게 그려진다**

## 대륙별 선두 — 뚜렷한 세계 선두는 없다
- 명단
  - 수리아 — [해솔](../06_수리아/해솔/해솔.md)
  - 아우로라 — [페라리크](../03_아우로라/페라리크/페라리크.md)
  - 아자니아 — [자한](../05_아자니아/자한/자한.md)
  - 마슈리크 — [카람](../04_마슈리크/카람/카람.md) (그나마)
  - 노르카엔 — [테스카론](../07_신대륙/테스카론/테스카론.md)
  - 파차라 — [지파라](../07_신대륙/지파라/지파라.md)
- 페라리크가 선두인 구조
  - · 베르크슐레가 한몫하고, 나머지가 다른 데를 본다
  - · 콜레기움 마그눔 = 순수 학문이라 물건을 만들지 않는다
  - · 에콜 도레 = 귀족 중심의 과시 — 보여 주는 곳이지 만드는 곳이 아니다
  - · [라 로사](../08_전세계_통합/라_로사.md) = 해양 중심으로 배와 항해에 특화되어 있다
  - · 상세 편성은 [아카데미](아카데미.md) 참조
- ◈ 정통성 다툼의 결이 달라진다
  - · 정통성을 다투는 두 나라 중 마공학 선두는 페라리크다
  - · [솔라티움](../03_아우로라/솔라티움/솔라티움.md)은 과거의 증거(문서고)를, 페라리크는 미래의 물건(공방)을 쥔다
- "그나마 카람"이 곱셈 구조의 증명이다
  - · 마정석 국부를 쥐고도 겨우 대륙 선두다
  - · 자한·테스카론·지파라가 각 대륙 선두라는 것은 마공학이 문명의 중심을 따라 흐르지 않는다는 뜻이다

## 제작 주체 — 노움만의 재산이 아니다
- 드워프+노움 분업은 세계 표준이 아니다
  - · [해솔](../06_수리아/해솔/해솔.md) 사례는 한 갈래일 뿐이며, 노움 단독으로도 충분히 만든다
  - · 드워프 협업은 선택지 중 하나다
- 품목이 갈린다
  - · 룬이 깊이 들어가는 물건([골렘](골렘.md)·병기) = 드워프가 필요하다
  - · 등불류 = 노움만으로 된다
- 노움이 아니어도 된다
  - · 제작 재능이 있거나 교육을 받으면 만들 수 있는 물건이 있다
  - · [종족 총론](../02_종족/종족_총론.md)의 대전제와 정합 — "특화는 종족적 경향이지 개인의 한계가 아니다"
  - → **마공학은 종족의 재산이 아니라 배울 수 있는 학문이다**
  - · 노움이 6%뿐인데 변두리 여관에 등불이 걸린 이유가 여기서 완결된다
- 골렘이 여전히 희귀물인 이유도 같은 자리에서 나온다
  - · 드워프가 필요하고, 드워프는 산에 있으며, 산은 아무 데나 있지 않다
- 해솔과 페라리크는 정반대 길로 같은 자리에 올랐다
  - · 해솔은 **조직** (바우둔 드워프 + 공방 편성), 페라리크는 **교육** (학교)
  - → 세 조건을 채우는 길이 하나가 아니라는 증명이다

## 교육 — 두 길을 한 지붕 아래 둔 곳
- [아카데미](아카데미.md) 학과와 공방 도제가 둘 다 주류다
  - · 실습이 가장 중요한데, 아카데미에서 실습을 해내는 곳은 아직 베르크슐레뿐이다
- 페라리크 선두의 최종 증명
  - · 베르크슐레는 두 길을 한 지붕 아래 둔 유일한 곳이다
  - · 다른 곳의 학생은 이론을 배운 뒤 공방에서 처음부터 다시 배워야 한다
  - → 같은 세월에 두 배를 얻는 구조라 격차가 벌어질 수밖에 없다
- 콜레기움 마그눔이 밀린 이유
  - · 순수 학문이라 손을 대지 않는다 → 이론은 앞서도 물건이 안 나온다
  - · [세라니르](../03_아우로라/세라니르.md)의 연구 구조와 같은 모양이다 — 저 학교는 늘 한 발짝 앞에서 멈춘다
- 에콜 도레는 원리상 실습이 불가능하다
  - · 귀족이 손을 더럽히지 않으므로, 물건을 보여 주는 곳이 물건을 만들지 못한다
- ◈ 파생
  - · 베르크슐레 졸업장 = 세계에서 가장 값나가는 종이. 타국의 인재 빼가기 대 페라리크의 단속 → 정통성 다툼에 두뇌 유출 전선이 추가된다
  - · 따라잡는 길은 하나뿐이다 — **학교에 공방을 붙이는 것**. 첫 번째 모방자가 누구냐는 아직 정해지지 않았다
- 학부 편성
  - · 마공학은 **마공학부**로 독립한다 — 마공학 학과 + 룬 각인 학과
  - · 룬 각인이 정령학이 아니라 마공학과 한 학부에 든 이유는 골렘 = 룬 각인 + 마공학이기 때문이다
  - · 상세는 [아카데미](아카데미.md)
