# 마물 명단
> A~F 갈래별

**1차 확정**

| | |
|---|---|
| **갈래** | A 흔한 종 / B 중형 / C 대형종 / D 고유종 / E 지성 의심군 / F 마물이 아닌 것 |
| **위력 표기** | 불빛 사다리 환산 (토착 계통은 비교용) |
| **성격** | 통용 가칭 · 열린 목록 |
| **총론** | [마물](마물.md) |

## 읽는 법
- 이름은 통용 가칭이며 권역별 현지명은 필요할 때 더한다. 위력은 불빛 사다리 환산이되, 토착 계통은 [에테르](../01_세계관_코어/에테르.md)를 쓰지 않으므로 비교용 표기다. 총론은 [마물](마물.md) 문서를 보라.
- 표기 규칙
  - · 포화(변질)한 개체는 원래 칸에서 대체로 한 칸 오른다
  - · '없음'은 사다리에 걸리지도 않는 것들이다 (벌레·작은 짐승류)

## A. 흔한 종 — 세계의 바닥 (없음 ~ 등불)
- 명단
  - **이끼거북** **(없음)** — 등에 이끼가 자라는 대형 거북. 완전 무해
    - · "무해한 토착 생물을 뭐라 부르는가"라는 미정 항목의 실물 표본이다
  - **가시토끼** **(없음~불씨)** — 밭을 결딴내는 농촌 해수
    - · [하플링](../02_종족/하플링.md) 자치 마을의 최대 골칫거리
    - · 귀족 사냥터에 풀어놓는 것도 대개 이것이다
  - **슬라임** **(없음~불씨)** — 점액질 무척추 생물. 습지·하수·동굴. 부식성 체액
  - **밤귀** **(불씨)** — 동굴·갱도의 대형 박쥐형. 광산이면 어디에나 있다
  - **바위굼벵이** **(불씨~등불)** — 광맥 틈의 굼벵이형. 마정석 부스러기를 먹는다
    - · 급격 포화의 단골 — [자우하르](../04_마슈리크/자우하르.md)·[그라니타](../06_수리아/그라니타/그라니타.md)·[스카르둔](../07_신대륙/스카르둔.md) 광부들의 실질적 공포
  - **독혀** **(등불)** — 늪지 도롱뇽형. 독액. 시골 사망 원인 상위
  - **그렘린** **(불씨)** — 금속·장치를 갉고 훔치는 소형 잡식종. 까마귀 정도의 잔꾀가 있다
    - · [마공학](마공학.md) 도시·[해솔](../06_수리아/해솔/해솔.md)·[유적](유적.md)의 상시 골칫거리
    - · 솔교권 민간에서는 이것을 '임프'(작은 악마)라 부른다 → 오칭

## B. 중형 — 토벌대의 일감 (등불 ~ 화톳불)
- 명단
  - **케르베로스형** **(등불~화톳불)** — 대형 견형 고유종. 개가 아니다. 무리 사냥
    - · 대상로·변경의 상시 위협
  - **하피** **(등불)** — 대형 맹금. 앵무처럼 사람 소리를 흉내 낸다
    - · "말하는 마물" 소문의 진원이며, 지성 의심군 논쟁을 흐리는 훼방꾼이다
  - **가고일** **(등불~화톳불)** — 석회질 외피의 절벽 활공 짐승
    - · 웅크리면 바위와 구분되지 않는다. 성벽·유적에 앉는 습성
  - **늪구렁** **(등불~화톳불)** — 대하·삼각주의 거대 뱀형
    - · [케메트](../05_아자니아/케메트/케메트.md) 하피르강·[냐사연맹](../05_아자니아/냐사연맹/냐사연맹.md) 호수 연동
  - **행군떼** **(군체 화톳불)** — 곤충 군체
    - · 개체가 아니라 재해로 취급되는 유일한 예다
  - **미노타우로스 / 식인 거인** **(화톳불)** — 대형 유인원 계열 짐승
    - · 두 발로 서되 언어·문화가 없다
    - · [오크](../02_종족/오크.md)(지성 종족)와 겹치지 않도록 주의
  - **오거** **(화톳불)** — 별격 처리
    - · 지능은 있다 (도구와 꾀를 쓴다). 그러나 지성 여부는 아직 모른다
    - · 단독 개체만 목격된다 → 저희끼리 말하는 것을 엿들을 수 없으므로 언어 관측 자체가 불가능하다
    - · ◈ 학자들의 가설이 끝내 닿지 못하는 사각지대
    - · 식인을 즐기므로 설령 지성이 밝혀져도 윤리 문제로 번지지 않을 것이다 — 이 세계의 윤리가 '지성 유무'가 아니라 '우리를 먹느냐'로 갈린다는 증거
  - **바실리스크** **(화톳불)** — 신경독 안개를 뿜는 대형 파충류
    - · 맞으면 근육이 굳은 채 죽으므로 사람들이 "돌이 되었다"고 부른다 (석화는 오인)
  - **트롤** **(화톳불)** — 생물학적 고속 재생 보유
    - · ◈ "짐승은 팔이 도로 자라는데 사람은 왜 안 되는가"
  - **미믹** **(등불)** — 의태형 매복 포식자
    - · '상자로 변신'이 아니라 궤짝·바위 틈에 몸을 맞춰 숨는 점착성 포식자이며, 소라게처럼 남의 껍데기를 뒤집어쓰기도 한다
    - · 유적 탐사와 궁합이 좋다
  - **코카트리스** **(등불~화톳불)** — 독을 지닌 대형 조류형
    - · 부리·발톱에 독이 있어 물리면 굳어 죽는다
    - · 바실리스크와 사촌 취급을 받으나 계통이 다르다 (파충류·독 안개 / 조류·독 발톱)
    - · 석화는 양쪽 다 오인이다 — 시선 석화는 존재하지 않는다
  - **팔카르** **(등불 (무리면 화톳불급))** — 사람 키 남짓한 무리 사냥형 파충류
    - · 낫처럼 휘어진 발톱에서 이름을 땄다 (아우렐어 '낫')
    - · 2층 명명 — 학자·길드 장부는 **팔카르**, 변경 사냥꾼들은 **'낫발'**이라 부른다
  - **거대 거미** **(등불~화톳불)** — 숲·동굴 서식. 그물과 독. 유적·갱도에서도 발견된다

## C. 화톳불급 대형종 — 포화하면 봉화가 되는 후보군
- 명단
  - **와이번** **(화톳불)** — 절벽·산악. 브레스는 마법이 아니라 기관이다
  - **드레이크** **(화톳불)** — 대형 지상 포식자
    - · [용족](../02_종족/용족.md) 목격담이 전부 이 이름으로 분류된다
  - **그리핀** **(화톳불)** — 고원·산맥의 대형 맹금형
  - **히드라** **(화톳불)** — 다두형 수생 대형종. 트롤과 같은 생물학적 재생
  - **해룡** **(화톳불)** — 원양 항로 위협. 실무급 해상 위험
    - · 바하리아의 '지켜주는 바다' 신앙과 [마리스텔라](../03_아우로라/마리스텔라/마리스텔라.md) 항해에 직결된다
  - **레비아탄** **(화톳불 (목격 극소))** — 대양 심해의 초대형종. 사실상 전설급
    - · 해룡 = 실무, 레비아탄 = 전설로 층을 나눈다

## D. 대륙·지형 고유종
- 명단
  - **등딱지짐승** **(등불~화톳불 / [신대륙](../07_신대륙/신대륙.md))** — 거대 갑주 초식종
    - · ◈ 가죽 한 장이 구대륙 학자의 의문을 부른다 — [마리스텔라](../03_아우로라/마리스텔라/마리스텔라.md) 비밀의 구멍
  - **그늘사냥꾼** **(화톳불 / 아자니아 밀림)** — [음웰루](../05_아자니아/음웰루/음웰루.md) 사냥 생업의 주 대상
  - **모래헤엄이** **(등불 / 아즈간 사막)** — 모래 속을 이동한다. 티네리 대상로 위협
  - **흰뿔** **(화톳불 / 극지·툰드라)** — [오크](../02_종족/오크.md)·[노르가르드](../03_아우로라/노르가르드/노르가르드.md)권 사냥 문화와 연결
  - **눈그림자** **(등불~화톳불 / 데바단 산맥)** — 캉리 수행자 전승의 단골
    - · [용족](../02_종족/용족.md) 서식지와 겹쳐 목격담이 뒤섞인다
    - · 2층 명명 — 학자·기록은 '눈그림자', 산사람들은 '예티'라 부른다

## E. 지성 의심군 — 윤리 뇌관
- 명단
  - **고블린** **(등불, 무리 / 숲·변경)** — 도구와 무리 생활. 언어 보유 의심군
    - · [음웰루](../05_아자니아/음웰루/음웰루.md)가 사냥하는 대상에 섞여 있다 → 가설이 굳으면 나라의 생업과 국방이 도덕 문제가 된다
    - · [오크](../02_종족/오크.md)와 겉보기가 겹쳐 변경의 오인·차별 소재가 된다
  - **코볼트** **(등불, 무리 / 지하·갱도)** — 도구를 쓰고 함정을 판다. 언어 보유 의심군
    - · ◈ 하필 광산에서 해마다 죽인다 — 그 광산이 [자우하르](../04_마슈리크/자우하르.md)·[그라니타](../06_수리아/그라니타/그라니타.md)·[스카르둔](../07_신대륙/스카르둔.md)이다
    - → 국부가 나오는 자리에서 학살이 벌어지는 구조

## F. 마물이 아닌 것 — 분류 정정
- 작중에서는 마물로 불리기도 하나, 실제로는 아니다.
- 인공물
  - **골렘**(정식) — 인공물이다. 상세는 [골렘](골렘.md)
    - · 룬 각인(드워프) + [마공학](마공학.md)(노움)의 산물이며 [해솔](../06_수리아/해솔/해솔.md) '인형'과 같은 계열이다
    - · 아직 소수의 희귀물
  - **아케르부스** — 마물형 골렘. 분류는 애매하나 작중 판정은 마물 취급
    - · 룬을 새긴 뒤 버린 조각들이 뭉쳐 골렘화한 폐기물의 응집체다
    - · 위험도 불씨~등불 고정. 조종 불가. 상세는 [골렘](골렘.md)
- 자원·식물
  - **맨드레이크** — 식물 자원이다. 약재·연금술 교보재
    - · [아카데미](아카데미.md) 연금술 학과와 직결된다
- 사람을 마물이라 부르는 이름들
  - **리저드맨** — 변경 파충류 [수인](../02_종족/수인.md) 부족을 부르는 멸칭
    - · 실체는 지성 종족이다. 여섯째 오해의 가장 아픈 실례
    - · 드라킨이 숨기에 가장 좋은 이름이기도 하다
  - **워울프** — 오칭. 사람은 변신하지도 포화하지도 않는다
    - · 실체 ⓐ 포화한 늑대 / ⓑ 늑대형 수인에 대한 모함
    - · 변경 마을의 수인 마녀사냥 소재
  - **몽마**(서큐버스·인큐버스) — 존재하지 않는다
    - · 실체는 핑계이자 마녀사냥의 명목이다. 애꿎은 사람·짐승에게 뒤집어씌운다
    - · 근거 — 인간형 변신은 [용족](../02_종족/용족.md)만 가능하고, 정신 조작·정기 흡수는 이 세계의 힘 체계에 없다
    - · 워울프·리저드맨과 다른 점: 저 둘은 표적이 수인으로 정해져 있으나 몽마는 아무나 지목할 수 있다
    - · ◈ 교단의 이단심문에 편리한 구실
- 그 밖
  - **드래곤** — [용족](../02_종족/용족.md)을 가리키는 세간의 이름
    - · 실제 피해 사례가 없는데도 신화적 공포 때문에 마물로 분류된다
    - · "피해를 준 적 없는데 가장 무서운 마물"이라는 자리
  - **임프** — 별개 종이 아니라 그렘린류를 솔교권 민간에서 부르는 이름 (오칭)
    - · "작은 악마가 대장간을 뒤집어 놓았다" 식의 민담. 악마는 이 세계에 존재하지 않는다
  - **언데드**(스켈레톤·구울) — 존재하지 않는다
    - · 신이 없고, 마법은 없는 것을 만들지 못하며, 생명 계통은 몸이 이미 하는 작용만 증폭한다
    - → 시체는 하는 작용이 없으므로 일으킬 방법이 한 줄기도 없다
    - · 파생 — 사령술·강령술 계통도 존재하지 않는다. 그런 학과·직업·전설도 두지 않는다
