# 정합성 세션
> 모순 해소와 구조 재편의 기록

**Consistency Pass**

| | |
|---|---|
| **성격** | 새 창작이 아니라 확정된 것끼리의 충돌 정리 |
| **검사 범위** | 번호 파일 전권 · 마크다운 위키 341편 · HTML 위키 496편 |
| **해소한 모순** | 별급의 수 · 영구 작동 물건 · 통신구의 벽 · 기사 비율 |
| **구조 재편** | 신분·계급 / 통화·문화 / 수리아 분할 + 정본 규칙 명문화 |
| **이상 없던 것** | 인구 합계 · 역병 연표 · 십자군 연대 · 종족 분포 합계 |
| **연동** | [등급 체계](등급_체계.md) · [전쟁과 군제](../11_제도_전쟁_역병/전쟁과_군제.md) · [역병과 의료](../11_제도_전쟁_역병/역병과_의료.md) · [마법의 일상 활용](../11_제도_전쟁_역병/마법의_일상_활용.md) · [물가](../10_문화_통화_축제/물가.md) |

## 왜 만들었는가
- 설정집이 서른 권 가까이 쌓이는 동안, 확정된 것끼리 부딪히는 자리가 생겼다. 정합성 세션은 새로 만든 것이 거의 없고 이미 확정된 것 가운데 어느 쪽이 이기는지를 정해 준 작업이다
- 검사 범위
  - 번호 파일 전권
  - 마크다운 위키 341편
  - HTML 위키 496편
- ◈ 원칙 — 창작으로 메우지 않고, 충돌하는 두 서술 중 **근거가 더 구체적인 쪽**을 정본으로 삼았다

## 해소한 모순 넷
- 별급의 수 — [등급 체계](등급_체계.md)가 이긴다
  - 등급 체계는 별급을 **세계 전체에 현재 한둘, 없을 수도 있음**이라 적고 역사를 통틀어도 스물 남짓이라 했다
  - 그런데 [전쟁과 군제](../11_제도_전쟁_역병/전쟁과_군제.md)는 별급을 **한 세대에 몇**이라 적었다. 한 세대를 스물다섯 해로 잡으면 성력 1341년까지 백쉰 명이 넘어 양립하지 않는다
  - 또 [역병과 의료](../11_제도_전쟁_역병/역병과_의료.md)·[전세계 관계도](../08_전세계_통합/전세계_관계도.md)는 대역병마다 **교단의 별급이 통째로 갈려 나간다**고 적어, 한 교단이 별급을 여럿 가진다는 전제를 깔고 있었다
  - → 별급은 층이 아니라 **단발의 상실**로 고쳤다. 한 사람이 끊겨도 한 세대가 통째로 비므로 무게는 오히려 더 무겁다
- 영구 작동 물건은 없다
  - 마법등·온석·정수돌은 거의 안 닳는다고 적혀 있었으나, [마법의 일상 활용](../11_제도_전쟁_역병/마법의_일상_활용.md)은 자연 충전이 없다 하고 [세계의 기초](세계의_기초.md)는 일반 과학이 그대로 적용된다 한다
  - 채워지지 않는 그릇이 영원히 열과 빛을 내놓으면 세계 대원칙을 어긴다
  - → **수십 년에서 백 년 수명**을 붙였다. 사람 일생보다 길어 안 닳는 것처럼 보일 뿐이다
  - 얻은 것 — 이 물건들은 유산으로 물려받는 품목이 되고, 대를 넘길 무렵 빛과 열이 옅어지므로 “할아버지의 등이 어두워졌다”가 살림의 시계 노릇을 한다
  - 옛 유적에서 나온 등이 아직 켜지는 일은 드물고, 그 자체가 값이 된다
- 통신구의 벽은 값이 아니다
  - 통신구는 나라와 대상단의 물건이라 했는데 [물가](../10_문화_통화_축제/물가.md)의 값은 금 25로 마공 물레방아(금 80)보다 싸다
  - → 벽의 근거를 **유지비와 충전대 접근권**으로 옮겼다. 살 수 있는 자와 계속 쓸 수 있는 자가 갈린다
  - 가난한 영주가 통신구를 창고에 처박아 두는 그림이 바로 이것이다
- 기사 비율은 봉건제에만
  - 인구 1천 명당 기사 하나를 그대로 곱하면 관료제 제국 [화련](../06_수리아/화련/화련.md)에 기사 십만이 넘게 나온다
  - → **봉건제를 쓰는 나라에 한함**이라는 단서를 붙였다. [비봉건 체제와 성직 서열](../11_제도_전쟁_역병/비봉건_체제와_성직_서열.md)에는 기사 칸 자체가 없다

## 설정집 쪽의 구조 재편
- ◈ 이 절은 **설정집(번호 파일)의 사정**이며 위키 문서 구성에는 영향이 없다
- 파일이 갈라졌다
  - 신분·계급 2,539줄 → **이론편** + **국가별 기입표** 둘로
  - 통화·문화·축제 → **통화·물가** + **문화·생활·축제** 둘로
  - 수리아 1,734줄 → **동아시아·초원** / **남아시아·해양** / **내륙·산맥** 셋으로
  - 절 번호와 권역 번호를 그대로 보존했으므로 기존 참조는 하나도 깨지지 않았다
- 정본 규칙이 명문화되었다
  - 값이 어긋나면 누가 이기는지를 파일마다 못 박았다
  - 국가별 법의 세 줄과 승계는 **기입표가 값을 갖고** 각 대륙 파일은 **해설만 갖는다**
  - 파일 말미의 연쇄 반영 블록은 **이력이지 값이 아니다** — 값을 고쳤으면 정본 표에 손을 대야 한다
- 새로 생긴 문서
  - 인덱스 (파일 지도)
  - 용어 사전
  - 변경 이력

## 검산하여 이상 없던 것
- 대륙별 인구 합계 — 아우로라 6,310만 · 마슈리크 2,450만 · 아자니아 3,010만 · 수리아 2억 4,410만 · 신대륙 2,945만. 총 3억 9,125만으로 약 4억과 맞는다
- 역병 연표 — 성력 140년에서 600년까지 460년, 지금은 2차로부터 741년째. 전부 맞는다
- 십자군 3차가 성력 1316년, 지금으로부터 스물다섯 해 전인 것도 맞는다
- 종족 분포표의 권역별 합계가 모두 100이다
- HTML 위키 496편의 내부 앵커는 깨진 것이 하나도 없었다
- ◈ 이 설정집의 문제는 창작이 아니라 **관리**에 있었다. 훌륭한 내용물이 잘못된 서가에 꽂혀 있었을 뿐이다
