# 마슈리크의 공통 배경

## 마슈리크는 3국으로 구성. 종교 정통성과 성지 관할을 
- [마슈리크](마슈리크.md)는 3국으로 구성. 종교 정통성과 성지 관할을 두고 다투는 사촌 나라들

## 관계
- 관계** 이합집산 — [솔라티움](../03_아우로라/솔라티움/솔라티움.md) 십자군이 오면 연합, 평시엔 정치·영토·성지 관할권으로 다툼
  - 3국은 서로를 이단시하지 않음 (같은 알 딘 신앙의 형제). 다툼은 세속적인 것

## 십자군 과거사
- 십자군 과거사** 총 3회, 마지막은 약 25년 전
  - 연대: 1차=성력 1209년경 / 2차=1252년경 / 3차=1316년경 (현재=성력 1341년)
  - 1차 살렘 4년 점령 후 축출(→[미슈마르](미슈마르/미슈마르.md) 요새 전통의 기원) / 2차 격전 끝 후퇴 /
    - 3차 [아케메니아](아케메니아/아케메니아.md) 합세로 상륙도 못 하고 후퇴(→아케메니아 명성의 밑천)
  - "십자군이 오면 연합"은 3회 실전으로 검증된 관례

## 종교
- 종교** 마슈리크 3국이 공유하는 신앙. 유일신 '와히드(Wahid)' 숭배
  - 솔라티움의 솔교와 '같은 신(이름만 다름)·같은 예언자·같은 성지' 뿌리를 공유하나 해석이 다름
  - 종교 뿌리·분열 상세는 참조
  - 이단시 구도: 솔라티움 교단 ↔ 마슈리크(알 딘)가 '서로'를 이단시함
    - (솔라티움 교단은 알 딘을, 마슈리크는 솔라티움 교단을 이단으로 봄)
  - 마슈리크 3국끼리는 이단시하지 않음 (한 형제 신앙). 아브라함 계열 종교 평행
  - 종교사: 한 예언자·한 성지에서 시작 → 해석 차이로 분열
    - → 한 [갈래](../01_세계관_코어/갈래.md)는 서쪽으로 가 아우렐 제국의 국교가 됨(현 솔라티움)
    - → 나머지 갈래들은 발상지(마슈리크)에 남아 서로도 갈라짐
  - ∴ 솔라티움과 마슈리크 3국은 모두 한 뿌리의 사촌 → 성지가 겹쳐 십자군 발생

## 알 딘 3학통
- 알 딘 3학통
  - '종파 분열'이 아닌 해석 학통의 차이. 셋 다 핵심 신조 공유 —
    - "와히드는 유일신, 이샤르는 그 말을 전한 가장 위대한 [인간](../02_종족/인간.md)" → 서로 이단시하지 않는 근거
  - [카람](카람/카람.md) = 전승파 (아사리야): 예언자 언행 전승의 문자적 준수가 정통.
    - 하람(예언자 출생지) 관할 = 전승의 물리적 근거지 → "우리가 정통" 주장의 교리적 뼈대.
    - 순례·대중 신앙 친화, 신자 수 최대 학통
  - [바벨리아](바벨리아/바벨리아.md) = 이성파 (아클리야): 경전은 상징, 이성·논증으로 해석 (무타질라 평행).
    - 다르 알히크마가 본산. 전승파를 "생각을 멈춘 신앙"이라 낮잡아 보나 이단시는 안 함
  - 미슈마르 = 실천파 (아말리야): 믿음은 행위와 파수(把守)로 증명.
    - 살렘 수호 자체가 신앙 행위. "하람보다 살렘" 위상 주장의 교리적 표현
  - 상호 인식: "틀린 형제가 아니라 게으른·별난 형제"
  - 주변부(아케메니아 등): 학통 혼재, 대체로 전승파 다수

## 종족
- 종족** 인간 중심. 사막·오아시스엔 환경형 [수인](../02_종족/수인.md)(낙타·매·사막여우 계열),
  - 다크[엘프](../02_종족/엘프.md)는 도심에만 소수. [드워프](../02_종족/드워프.md) 없음, 엘프 없음

## 서쪽 관문
- 서쪽 관문** [미세아](../03_아우로라/미세아/미세아.md)(용병 왕국)가 유럽-마슈리크 사이의 완충 회랑 (양쪽 다 미세아에서 칼을 삼)
