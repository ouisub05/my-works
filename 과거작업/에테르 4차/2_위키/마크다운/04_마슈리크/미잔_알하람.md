# 미잔 알하람
> 미잔 알하람 (Mizan al-Haram, '성역의 저울') — 자우하르 반출 판정 제도

| | |
|---|---|
| **소속** | 카람 술탄국 |
| **대륙** | 마슈리크 |
| **유형** | 제도·관습 |
| **성격** | 자우하르에서 캐낸 마정석을 미프타흐로 보낼지 무카르로 돌릴지를 정하는 판정 제도 |

## 개요
- [카람](카람/카람.md)의 지명. 자우하르 반출 판정 제도
- 성격** [자우하르](자우하르.md)에서 캐낸 마정석을 [미프타흐](미프타흐.md)로 보낼지 [무카르](무카르.md)로 돌릴지를 정하는 판정 제도
- 단일 실패점** 판정이 술탄 개인에게 붙음 →
  - 술탄이 병들거나 자리를 비우면 국부의 물류가 멎음.
  - 준비 없이 즉위한 젊은 군주에게 걸린 구조적 급소
- 미정** 칙령 지연을 실무에서 어떻게 메우는지 (사전 지침형인지, 사후 재가형인지)

## 정치적 무게
- 판정 권한** 술탄 직결. 성도 하람의 정청 [다르 알물크](다르_알물크.md)에서 결정됨
  - 어느 궤짝을 어느 길로 보낼지가 예배당 옆방에서 정해지는 나라
  - 판정이 성역 안에서 내려진다는 사실을 제도명에 그대로 못 박은 이름 →
    - [라시드](라시드.md)의 미봉합 모순이 국부 운영 방식으로 확대됨
- 총독 무력화** 무카르 총독 [이드리스](이드리스.md)는 우회로의 종착지를 쥐고도 판정권을 갖지 못함
  - [부슈라](부슈라.md)로 명분을 잃고 미잔 알하람으로 실리마저 못 쥠 →
    - 라시드가 선왕의 유산을 두 번 연속 무력화한 형태
