# 바브 알샴
> 바브 알샴 (Bab al-Sham, '북쪽 문') — 미슈마르 북부, 미세아 회랑 접점

| | |
|---|---|
| **소속** | 미슈마르 |
| **대륙** | 마슈리크 |
| **유형** | 교통로 |
| **성격** | 군사 대치선 + 용병 고용 시장 겸비 |

## 개요
- [미슈마르](미슈마르/미슈마르.md)의 지명. 미슈마르 북부, [미세아](../03_아우로라/미세아/미세아.md) 회랑 접점
- 성격** 군사 대치선 + 용병 고용 시장 겸비
  - → 적이 올 길목에서 그 적을 막을 사람을 사는 구조. [하리산](하리산.md) 용병이 걸어 들어오는 문

## 군사
- 맞은편** 미세아 동방 국경 요새 [바르단](../03_아우로라/바르단.md)

## 갈등과 불씨
- 이야기 씨앗** 어제 고용한 용병이 내일 십자군 편에 서서 돌아옴
