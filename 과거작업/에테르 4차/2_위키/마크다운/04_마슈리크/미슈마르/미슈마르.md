# 미슈마르
> 미슈마르 (Mishmar) — 성지국, 가나안/예루살렘 대응

**Mishmar**

| | |
|---|---|
| **위치** | 마슈리크 · 예루살렘 대응 |
| **인구** | 약 150만 |
| **종족 구성** | 인간 76 / 수인 15 / 하플링 5 / 노움 2 / 오크 2 |
| **종교** | 알 딘 3국 + 솔라티움/헬라디아 동방교회 모두에게 성스러운 공유 성지 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [마슈리크](../마슈리크.md)에 속한 세력. 군정 성지국. 토착 군벌이 대대로 성지 살렘을 통치·수호
- 정체성** 군정 성지국. 토착 군벌이 대대로 성지 살렘을 통치·수호
  - 작지만 누구도 함부로 못 하는 나라 (다섯 세력의 신앙이 겹치는 성지를 깔고 앉음)

## 군사
- 생존 방식** 순례 통행세 + 요새 — 험준한 요새와 정예 군대, 순례 수입으로 자립
  - 작지만 단단한 나라

## 사회
- 국명** 미슈마르(Mishmar, '수호·파수') / 성지·수도: 살렘

## 종교
- 성지 살렘
  - 알 딘 3국 + [솔라티움](../../03_아우로라/솔라티움/솔라티움.md)/[헬라디아](../../03_아우로라/헬라디아/헬라디아.md) 동방교회 모두에게 성스러운 공유 성지
  - 십자군이 노리는 핵심 표적
- 종교** 기본적으로 3국과 같은 알 딘 신자
  - 단 [카람](../카람/카람.md)에 대한 미묘한 불만: "진짜 축복받은 성지는 우리 살렘인데,
    - 왜 저쪽 하람(메카)이 더 인기가 많은가?" (종파 갈등 아님, 성지 위상 경쟁·자존심)
  - 순례객과 돈이 하람으로 쏠리는 데 대한 서운함

## 법의 세 줄과 승계
- 법의 꼭대기 — 종교법
- 조문에 종족 — 아니오
- 조문에 성별 — 예
- 승계 — 장자 · 아들만
- 비고
  - 알 딘권의 여성 성직은 솔라티움보다 더 제한적이다
  - 같은 뿌리에서 갈라진 두 신앙이 같은 곳에서 같은 선을 긋되 한쪽이 더 세게 긋는다. 선의 위치가 계시가 아니라 해석에 따라 움직인다는 물증이다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조

## 승계
- 가장 가까운 혈족 — 수평 우선이다. [카람](../카람/카람.md)과 같은 꼴이며, 마슈리크의 두 종교법국이 같은 결을 공유한다
- ◈ [미슈마르](미슈마르.md)는 세습 신정국이다. 신정국이면서 성직 서열이 아니라 혈통으로 가며, 선출과 임명으로 가는 [솔라티움](../../03_아우로라/솔라티움/솔라티움.md)과 정반대다
- 수평 우선은 후보가 넓어 분쟁이 잦되 대가 잘 끊기지 않는다. 역병에도 계보가 마르지 않으므로 재난 뒤 왕권이 강해지지 않는다
- [카람](../카람/카람.md)과 나란히 승계 때마다 흔들리므로 두 종교법국이 동시에 흔들릴 수 있다
