# 미흐란
> 사령관

| | |
|---|---|
| **소속** | 아케메니아 |
| **대륙** | 마슈리크 |
| **지위** | 사령관 |

## 개요
- [아케메니아](아케메니아/아케메니아.md)의 사령관.
- 위상** 미흐란의 군대가 크테시아 성벽에 닿으려면 반드시 먼저 넘어야 하는 B1의 첫 성벽
- 미흐란이 "돈을 이름에 바르지 말라"고 할 두 번째 자리

## 생애
- 군부-내실파 균형의 수명** 미흐란(노장)이 살아 있는 동안은 균형 유지 —
  - 그가 죽으면 군부가 더 과격한 세대로 넘어갈 수도, 반대로 개전파가 힘을 잃을 수도
- 아케메니아가 [키샨](키샨.md)을 삼키면 곧바로 [카람](카람/카람.md)과 마주 앉게 됨** 아케메니아가 키샨을 삼키면 곧바로 카람과 마주 앉게 됨 → 미흐란 조기 개전론의 숨은 비용
- 미흐란(아케메니아 개전파)에게는 "저들이 우리를 두려워한다"는 증거로 읽힘
