# 무카르
> 무카르 (Mukhar) — 카람 남부 항구 [아덴/예멘 대응]

**Mukhar**

| | |
|---|---|
| **소속** | 카람 술탄국 |
| **대륙** | 마슈리크 |
| **유형** | 항구 |
| **지구 대응** | 아덴/예멘 대응 |

## 개요
- 카람 술탄국의 지명. 카람 남부 항구 [아덴/예멘 대응]
- 소속** [카람](카람/카람.md) 영토(남부 주) / 통치: 술탄이 임명하는 총독령(직할)

## 기능
- 기능
  - ① 인도양 향료 중계항 — 판디라 해로의 [마슈리크](마슈리크.md) 쪽 종착점 (인도양 축)
  - ② 카람 마정석·황금의 해상 수출 관문 — [티네리](../05_아자니아/티네리/티네리.md) 사하라 육로와 별개인 바닷길 창구
  - ③ [아자니아](../05_아자니아/아자니아.md) 방면 연결점 (마다크 해협 건너편)
  - ※ 본래 해상 순례 관문을 겸했으나, 그 기능은 신설 항구 [부슈라](부슈라.md)로 넘어감

## 경제와 산업
- 경제 구조** ②자원=국가 독점 / ①향료 중계=국민의 상업 영역
  - → 렌티어 구조가 한 항구 안에서 이중으로 겹침

## 주민
- 종족 구성
  - [인간](../02_종족/인간.md) 53 / [수인](../02_종족/수인.md) 35 / [하플링](../02_종족/하플링.md) 5 / [노움](../02_종족/노움.md) 4 / [오크](../02_종족/오크.md) 3 ([엘프](../02_종족/엘프.md)=도심 다크엘프 극소)
  - 골격은 카람 표준(인간 66/수인 26)이나 항구 체류 인구가 수인 비중을 끌어올림
  - 토착 수인=사막·오아시스 계열 / 체류 수인=판디라·[악수미아](../05_아자니아/악수미아/악수미아.md)·[바하리아](../06_수리아/바하리아/바하리아.md)계 해양 수인 상인
  - 마슈리크에서 '바다 쪽 수인'을 일상적으로 볼 수 있는 유일한 도시

## 갈등과 불씨
- 이야기 씨앗** 순례를 빼앗긴 총독
  - 순례객이 부슈라로 빠진 뒤 이 부두에는 마정석 궤짝과 향료 자루만 쌓이는데,
    - 총독 [이드리스](이드리스.md)는 여전히 순례를 말함
  - 선왕이 임명한 유산이라 말을 바꿀 수 없고, 바꾸는 순간 제 존재 이유가 사라짐.
    - 신앙의 명분은 남았으나 신앙의 물증이 없는 자리
  - 술탄 [라시드](라시드.md)가 "그래서 총독은 어느 순례객을 지키고 계시오"라고 묻는 날 무너지는 구조 —
    - 방패를 빼앗는 데 칼이 필요하지 않았음

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. 하플링과 노움이 특히 많다
- 신전** 예언자의 출생지이자, 신자라면 생애 한 의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 마정석 계량소** 마정석의 무게와 순도를 재어 값을 매기는 관영 시설
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
