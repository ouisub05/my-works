# 마슈리크
> 마슈리크 — 대륙 개요

| | |
|---|---|
| **지구 대응** | 중동 대응 |
| **세력 수** | 4 |
| **인구** | 약 2,450만 |

## 개요
- 중동 대응 대륙. 등재 세력 4.
  - 09. 마슈리크 (Mashriq) — 중동 대응 권역
  - 종족 재설정(7종 체제) 일괄 반영
- 기본 종족 7종** [인간](../02_종족/인간.md)/[수인](../02_종족/수인.md)/[하플링](../02_종족/하플링.md)/[노움](../02_종족/노움.md)/[드워프](../02_종족/드워프.md)/[엘프](../02_종족/엘프.md)/[오크](../02_종족/오크.md) + [용족](../02_종족/용족.md)·[혼혈](../02_종족/혼혈.md)(하프엘프·드라킨)
- 전 세계 공통** 농촌·도시에 하플링 혼재(도시는 길드에 다수) / 도시에 노움 소수 혼재(마공학) /
  - 도시에 오크 전사·용병 소수 (단 북방·툰드라권 — [노르가르드](../03_아우로라/노르가르드/노르가르드.md)권·에조라·[신대륙](../07_신대륙/신대륙.md) 북방 — 은 오크 다수)
- 다크엘프 = 엘프의 [갈래](../01_세계관_코어/갈래.md)
- 개별 서술과 구성표가 어긋날 때는 개별 서술을 따름
  - ※ 통칭: 마슈리크(Mashriq, '해 뜨는 동쪽'). [아우로라](../03_아우로라/아우로라.md)에서 본 동방
  - ※ 어감: 셈·아랍·페르시아풍 + 한글 음차 / 종족: 인간 중심(엘프 없음, 드워프 없음)

## 공통 배경
- 마슈리크는 3국으로 구성. 종교 정통성과 성지 관할을 두고 다투는 사촌 나라들

## 마다크
- 성격** 중계만 가능 — 물건은 건너가되 사람은 통과·정착 불가
  - 봉쇄 주체는 [카람](카람/카람.md)이 아니라 [케메트](../05_아자니아/케메트/케메트.md) (외부인을 노예로조차 들이지 않음)
  - C2 설명: [티네리](../05_아자니아/티네리/티네리.md) 수인 북상 이주가 서쪽 사하라를 돌아 [마리스텔라](../03_아우로라/마리스텔라/마리스텔라.md)로 간 이유 —
    - 동쪽 지협은 애초에 통과가 막힌 길이라 이주로가 될 수 없었음
  - 사하라 축([자한](../05_아자니아/자한/자한.md) 황금 ↔ 카람 마정석, 티네리 운송)이 육로인 이유도 같음

## 마즈마
- 양측이 서로의 땅을 밟지 않고 물건만 교환하는 국경 장터
- 오가는 것은 물건과 소문뿐 → C3(케메트 신전 전초기지 방화) 소식이
  - 마슈리크로 넘어오는 통로
