# 미프타흐
> 미프타흐 (Miftah, '열쇠') — 두 강 하구의 항구

| | |
|---|---|
| **소속** | 카람 술탄국 |
| **대륙** | 마슈리크 |
| **유형** | 항구 |
| **기능** | 키샨에서 내려온 바벨리아의 곡물과 물자가 바다로 나가려면 반드시 통과하는 문 |

## 개요
- 카람 술탄국의 지명. 두 강 하구의 항구
- 소속** [카람](카람/카람.md). [나흐르 샤르크](나흐르_샤르크.md)와 나흐르 가르브가 합류해 만으로 빠지는 하구를 쥠
- 리산·마다크에 이어 카람이 쥔 세 번째 길목

## 기능
- 기능** [키샨](키샨.md)에서 내려온 [바벨리아](바벨리아/바벨리아.md)의 곡물과 물자가 바다로 나가려면 반드시 통과하는 문

## 정치적 무게
- 정치적 무게** 바벨리아는 이 항구 때문에 바다에 닿지 못하는 나라가 됨.
  - 카람은 남의 나라 문을 잠근 채 그 문을 '열쇠'라 부르니, 카람에게는 자랑이고
  - 바벨리아에게는 조롱인 이름

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 신전** 예언자의 출생지이자, 신자라면 생애 한 의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 마정석 계량소** 마정석의 무게와 순도를 재어 값을 매기는 관영 시설
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
