# 하리산
> 하리산 (Harisan, '파수꾼들') — 미슈마르 해안 요새선

| | |
|---|---|
| **소속** | 미슈마르 |
| **대륙** | 마슈리크 |
| **유형** | 요새·군사시설 |

## 개요
- [미슈마르](미슈마르/미슈마르.md)의 지명. 미슈마르 해안 요새선
- 현 상태** 전부 현역 — 상륙 차단선으로 뒤집어 사용 중

## 위치와 지형
- 위치** 해안 상륙로 차단선
  - → 파생: 미슈마르는 해안선을 보유한 나라임

## 역사
- 기원** 1차 십자군(성력 1209년경, 살렘 4년 점령)이 상륙로 확보용으로 지은 요새들
  - → 축출 후 미슈마르가 접수

## 군사
- 수비** 고용 용병 — [미세아](../03_아우로라/미세아/미세아.md) 시장 용병 + [마슈리크](마슈리크.md) 부족 용병 혼합

## 종교
- 흔적 처리** 십자군의 무구·군기를 성벽에 내걸어 전시 (경고물)
  - 살렘은 [솔라티움](../03_아우로라/솔라티움/솔라티움.md)·[헬라디아](../03_아우로라/헬라디아/헬라디아.md) 동방교회에도 성지 → 그쪽 순례객은 제 조상의 군기 아래를 지나 입국
  - A4(십자군 재점화) 시 가장 먼저 불붙을 자리
- 교리 처리** 실천파(아말리야) 교리와 충돌하나
  - "재물을 성지 수호에 바치는 것 또한 신앙 행위"로 재해석해 정당화
  - 파수 개념이 '손수 지킴' → '지킬 수 있게 함'으로 확장됨
  - 파생: 순례세를 내는 행위 자체가 신앙 행위가 됨
    - → [카람](카람/카람.md)과의 성지 위상 다툼에 쓰는 논리
    - ("하람 순례=은혜를 받는 일 / 살렘 순례=지키는 일에 동참하는 것")
