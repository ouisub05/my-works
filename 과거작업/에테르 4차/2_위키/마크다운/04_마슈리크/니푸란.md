# 니푸란
> 니푸란 (Nippuran) — 바벨리아 발상지 평원의 옛 고도 / 다르 알히크마 소재지

**Nippuran**

| | |
|---|---|
| **소속** | 바벨리아 |
| **대륙** | 마슈리크 |
| **유형** | 도시 |
| **성격** | 자율 학자 공동체 (왕권과 별개) + 재정까지 완전 자립 |

## 개요
- [바벨리아](바벨리아/바벨리아.md)의 지명. 바벨리아 발상지 평원의 옛 고도 / 다르 알히크마 소재지
- 성격** 자율 학자 공동체 (왕권과 별개) + 재정까지 완전 자립

## 위치와 지형
- 위치** 나흐르 가르브 중상류. 고농도 [에테르](../01_세계관_코어/에테르.md) 평원 위
  - → 에테르 이론 체계화의 본산이 세계 최고 농도 평원 중 하나에 서 있는 배치

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 신전** 세속 우위파의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 대상 숙소** 낙타와 짐을 함께 재우는 안뜰형 숙소. 먼 길의 소문이 가장 먼저 닿는 자리
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
