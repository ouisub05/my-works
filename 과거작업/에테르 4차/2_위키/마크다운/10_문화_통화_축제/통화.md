# 통화

**Currency**

| | |
|---|---|
| **층 구조** | 금·은·동 3층 + 마정석(준화폐) + 물물교환 |
| **국제 통화** | 금화 — 금화만 통일, 은·동은 나라마다 제각각 |
| **교환비** | 금 1 = 은 12 = 동 144 (아우로라 기준) |
| **값의 연쇄** | 산지 → 유통자 → 등급 판정자 → 국가 → 시장가 |
| **신용** | 어음·환 존재 (상인 길드망 + 도시 상관) |
| **이자** | 솔교·알 딘 모두 금지 → 투자·환전으로 위장 |
| **연동** | [물가](물가.md) · [길드](../09_마물_판타지요소/길드.md) · [마공학](../09_마물_판타지요소/마공학.md) |

## 층 구조
- 이 세계의 값은 금·은·동 세 층 위에서 셈해지며, 그 위에 준화폐인 마정석이 얹히고, 바깥에는 여전히 물물교환이 굴러간다.
- 기본 = 금·은·동 3층 + 마정석
  - · 마정석은 정식 화폐가 아니라 준화폐다
  - · 13~14세기 상당이므로 물물교환의 병존은 자연스럽다
- 금화만 통일 / 은화·동화는 나라마다 제각각
  - · 금화는 어디를 가도 금화이며, 국경을 넘는 값은 전부 이 층에서 매겨진다
  - · 은·동은 국내용이라 국경을 넘으면 금속 덩어리 취급이거나 헐값에 환전된다
  - → 환전상의 본업이 정해진다. 국경 도시·항구·오아시스 도시마다 반드시 있어야 하는 직업이다
  - → 서민은 평생 국제 통화를 만지지 못한다
- 같은 금화라도 살 수 있는 것이 다른 까닭
  - · 금화의 무게는 같고 구매력이 다르다. 물가차란 곧 금화 대비 은·동 교환비의 차이다

## 마정석 — 준화폐
- 세 층 전부에서 통용된다
  - · 위층 = 국가 간 결제 + 대상인·길드 고액 거래
  - · 특수 용법 = 시장에서 대량 구매를 했는데 금·은화가 모자랄 때 괜찮은 마정석을 맞춰 값을 치른다. 임시변통이 아니라 관행이다
  - · 아래층 = 등급이 매우 낮은 것과 부스러기가 저잣거리 잔돈으로 돈다
- 셈하는 방식이 층마다 갈린다
  - · 부스러기는 무게로 잰다. 액면이 없는 계량 화폐다
  - · 온전한 결정에는 시세가 있다
  - → 저잣거리에서 저울을 가진 자가 곧 잔돈을 다루는 자가 된다. 눈금을 쥔 쪽이 미세하게 이득을 본다
- [마물](../09_마물_판타지요소/마물.md) 전리품과의 연결
  - · 마물 체내 결정은 양이 적고 질은 쓸 만한 수준이라 시장을 흔들지 못하는데, 그것이 흘러가는 곳이 바로 이 아래층이다
  - · 용병이 마물 배에서 긁어낸 부스러기가 그날 저녁 밥값이 된다
  - · 산지 구도는 흔들리지 않는다. 카람·그라니타가 쥔 것은 위층이고 마물이 내놓는 것은 아래층이라 두 시장이 겹치지 않는다

## 값이 붙는 다섯 단계
- 마정석의 값은 한 사람이 정하지 않는다. 산지 → 유통자(교역) → 등급 판정자 → 국가 → 시장가를 거치며 마디마다 한 번씩 얹힌다.
- 단계마다 마진이 붙는다
  - · 산지 코앞의 값과 저잣거리 값이 크게 벌어지고, 그 차이는 전부 누군가의 몫이다
- '등급 판정자'는 이 세계 네 번째 판정 권력이다
  - · 담가는 신용을, 마물 판정은 무력을, 학위는 권한을 판정한다. 여기에 값을 판정하는 자가 더해진다
  - · 앞의 셋과 달리 이 자리는 직접 돈이 된다
- 국가가 유통자 다음이 아니라 판정자 다음에 온다
  - · 나라는 값을 처음부터 만들지 않고, 이미 매겨진 것에 도장을 찍고 세를 매긴다
  - · 카람의 [미잔 알하람](../04_마슈리크/미잔_알하람.md)은 반출 판정이므로 산지와 유통자 사이를 쥔 것이며, 술탄이 사슬의 가장 윗목을 직접 잡고 있는 구조다

## 감정인 — 등급 판정자
- 소속은 셋으로 갈린다
  - · 독립 / 길드 소속 / 국가 소속
  - · [길드](../09_마물_판타지요소/길드.md) 성립 3경로(국가 승인·도시 영주·개인 사업)와 같은 꼴이다. 세계가 같은 구조를 세 번째로 반복한다
- 되는 길도 셋이 병존한다
  - · 도제식 / 길드 인증 / 학위 계통
  - · 서로 인정하지 않는 것은 아니다. 경로가 다를 뿐 감정인은 감정인이다
  - · 서로 부정한다면 값이 붙는 연쇄가 그 자리에서 끊긴다. 상거래는 서로를 인정해야 굴러가므로 부정 구조는 애초에 살아남지 못한다
- **인정과 신뢰는 다르다 — 도장의 무게**
  - 도제식 — 가장 흔하고 실무 눈이 가장 밝다. 다만 보증할 조직이 없어 개인의 평판이 전부다
  - 길드 인증 — 인장이 곧 보증이며 문제가 생기면 길드가 책임을 진다. 그래서 가장 널리 쓰인다
  - 학위 계통 — 수가 적고 값이 비싸며 국가·대상인 층위에 선다. 학위가 권한 판정이므로 관직으로도 이어진다
- **수를 제한하는 것 셋**
  - 눈을 기르는 데 걸리는 세월
  - 물건을 만져 볼 기회 — 상급 마정석은 희소하므로 실물을 본 자가 적다
  - 기존 감정인의 진입 통제 — 수가 늘면 몫이 줄어드니 일부러 좁힌다
  - 셋이 서로를 먹여 살린다. 물건이 희소해 기회가 적고, 기회가 적으니 세월이 더 걸리며, 세월이 걸리니 이미 된 자들은 문을 좁혀도 티가 나지 않는다
  - → 세 번째 이유가 앞의 둘 뒤에 숨을 수 있다. "우리가 막는 것이 아니라 원래 어려운 일"이라 말할 수 있기 때문이다
- ◈ 감정인을 사는 편이 광산을 사는 것보다 싸다
  - · 감정인은 등급을 매길 뿐 아니라 진짜와 가짜를 가르는 자이므로, 없는 값을 있게 만들 수도 있다
  - · 귀해서 한 도시에 몇 없으니 실제로 살 수 있다. 살 사람이 많으면 못 사지만 셋뿐이면 살 수 있다
  - · 좋은 감정인은 산지에서 나온다. 실물을 가장 많이 만진 자들이기 때문이며, 산지가 곧 국부인 나라들이 그들을 붙들어 두려 한다
  - · 변경·소도시에는 자칭 감정인이 산다. 검증할 자가 없으니 그자가 곧 판정자가 된다

## 어음과 환
- 값을 옮기는 데 반드시 금화를 실어 나를 필요는 없다. 어음과 환이 존재하며, 그것으로 부를 쌓아 올린 자들이 실제로 있었다.
- 발행 기반은 둘이 병존한다
  - · 상인 길드망 기반 — 지부 사이에서 통용된다. 국외 지부의 분포가 곧 지급망의 지도가 된다
  - · 도시 유력 상관 기반 — 그 도시의 신용에 기댄다
  - · 두 지급망이 겹치는 도시에서는 수수료 싸움이 벌어진다
- 물리적 형태가 층에 따라 다르다
  - · 기본 = 증서 + 인장. 국내·권역 내 거래에 쓴다
  - · 국가 간 = 증서 + 룬 각인 표식 돌. 각인석을 딸려 보내 증서와 짝을 맞춘다
  - → 룬 각인품은 값이 나가므로 형태 자체가 금액 구간의 표지가 된다. 각인석이 딸려 온 어음은 열어 보기 전에 이미 큰 건임을 알 수 있다
  - → 룬 각인품이 시장에 나오는 통로는 지상 교류 마을의 길드뿐이므로, 금융업이 [드워프](../02_종족/드워프.md) 길드에 줄을 서는 구조가 된다. 어느 산맥의 각인석을 쓰느냐가 발행처의 격이다
  - → 신대륙 드워프는 룬 각인 기술을 갖지 못하므로 이 방어를 쓸 수 없다. 구대륙과의 신용 격차가 여기서도 벌어진다
  - · 약점 — 각인석은 돌이라 무겁고 잃을 수 있으며, 무엇보다 돌만 훔치면 반쪽을 쥔 것이 된다
- **지급 절차**
  - 기본은 네 사람의 관계다. 발행인 / 다른 도시에서 실제로 내줄 지급인 / 수취인 / 증서를 들고 가는 자
  - 이름이 적힌다 — 소지자 지급이 아니라 수취인 특정이 원칙이라 도난당해도 남이 받지 못한다
  - 인수(引受) — 내밀면 바로 주지 않는다. 확인 뒤 정해진 유예를 두고 지급하며, 그 사이 발행처끼리 조회할 시간을 번다
  - 배서(背書) — 넘길 때마다 뒷면에 서명을 얹어 손을 거친 이력이 남는다. 문제가 생기면 배서한 자들이 줄줄이 책임진다
  - → 어음이 화폐처럼 돌 수 있는 이유이자, 한 명이 무너지면 줄이 통째로 흔들리는 이유다
  - 대조 장부 — 발행처가 사본을 두고 지부와 맞춘다. 다만 파발이 어음보다 느릴 수 있어 큰 건에만 한다
- 부도가 나면
  - · 배서를 거슬러 올라가며 앞사람에게 물린다
  - · 발행처의 신용에 흠이 남고 그 지부의 어음 할인율이 오른다
  - · 신용망이 통째로 무너지는 일은 아직 멀었으나, 작은 규모로는 지금도 늘 일어나고 있다
- [마공학](../09_마물_판타지요소/마공학.md)이 신용에 값을 매기는 자리
  - · 통신구는 값이 비싸고 마정석을 먹으므로 아무나 쓰지 못하나, 대길드·대상관은 조회에 쓸 수 있다
  - → 통신구를 가진 발행처의 어음이 더 안전하고 더 비싸게 쳐진다

## 이자 — 두 종교가 같은 죄를 피하는 두 방식
- 솔교·알 딘 양쪽 모두 이자를 금한다
- 알 딘권 — 계약의 이름을 바꾼다
  - · '투자'라는 명목으로 둘러대면 허용된다. 손실을 함께 진다는 형식만 갖추면 실질이 이자여도 통과된다
  - · 3학통(전승파·이성파·실천파)마다 어디까지가 투자이고 어디부터가 죄인지의 판정이 갈린다
  - → 법학이 곧 금융업의 하부 구조가 된다
- 솔교권 — 업종의 이름을 바꾼다
  - · 값을 빌려주는 것이 아니라 통화를 바꿔 준 삯을 받는 형식, 즉 환전 수수료로 위장한다
  - · 금화만 통일이고 은·동이 제각각인 세계이므로 환전은 반드시 필요한 정직한 노동이다. 위장할 껍데기가 이미 실재하는 진짜 업종인 셈이다
  - → 교단도 쉽게 건드리지 못한다. 환전을 죄라 할 수는 없기 때문이다
  - → 수수료율이 곧 이자율이며, 오르내려도 교리 위반이 아니라 시세로 읽히므로 감시가 구조적으로 불가능하다
  - · 어음에서도 같은 일이 벌어진다. "몇 날 뒤 지급"이라는 유예 기간에 이자가 숨는다
- ◈ 환전상은 사실상의 은행이다
  - · 저잣거리에서 부스러기를 재는 저울잡이부터 대상인 신용업자까지 하나의 직업이 위아래로 길게 뻗어 있다

## 위조 — 층마다 대상이 다르다
- 세 층 전부에 존재한다
  - · 서민층 — 주화 위조. 순도를 깎거나 도금한다
  - · 상인층 — 마정석 위조. 등급을 속이거나 가짜 결정을 판다
  - · 큰손층 — 어음 위조. 종이는 베끼기 쉽다
  - · 지금 없는 형태가 있더라도 언젠가는 생긴다. 값이 붙는 곳에는 반드시 따라붙기 때문이다
- 단속 주체가 층마다 다르다
  - · 주화는 국가가, 마정석은 감정인이, 어음은 발행처가 제 손으로 지켜야 한다
  - → 어음 위조에는 국가가 나서 주지 않는다. "국경 밖에서는 길드가 국가 노릇을 대신한다"가 여기서도 되풀이된다

## 연동 떡밥
- 값을 물릴 수 있는 자만이 등급을 부를 수 있다
  - · 마물 편의 "잡을 수 있는 자만이 마물이라 부른다"가 통화 쪽에서 그대로 반복된다
- 빚이 사람을 삼킬 수 있는 세계
  - · 자국민이 노예가 되는 경로는 대개 부채와 형벌이므로, 신용업의 무게가 인신 예속과 직결된다
  - · 술값 외상 → 노름빚 → 환전상 → 부채 노예로 이어지는 사다리가 이미 전부 깔려 있다
- ◈ 신용망 붕괴 — 씨앗
  - · 발행처 하나가 무너지면 지급망을 타고 도미노가 된다
  - · 다만 크게 터지려면 두어 세기는 더 엮여야 하므로 지금의 정세 폭탄이 아니라 세계가 기울어 가는 방향의 표지다
