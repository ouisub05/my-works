## 파일명 규칙

괄호·`※`·`—`·`·`·공백은 전부 정규화했습니다.
마크다운 링크는 `](` 다음 첫 `)`에서 끊기므로, **파일명에 괄호가 있으면 링크가 불가능합니다.**

- `(` → `_` / `)` → 삭제
- `·` → `-` / 공백 → `_`
