# 남화
> 남화 (南華) — 화련 제2 도시 [강남 대응]

| | |
|---|---|
| **소속** | 화련 |
| **대륙** | 수리아 |
| **유형** | 도시 |
| **성격** | 문화·유흥의 실질 중심 (수도 화징은 정치·관료제의 중심) |
| **지구 대응** | 강남 대응 |

## 개요
- [화련](화련/화련.md)의 지명. 화련 제2 도시 [강남 대응]
- 성격** 문화·유흥의 실질 중심 (수도 [화징](화징.md)은 정치·관료제의 중심)

## 갈등과 불씨
- 파생 정합
  - 경제 순환("화련이 문화를 팔고 → [위장](위장/위장.md)이 쌀을 팔고 → 번 돈이 화련 유흥으로 회귀")의
    - 회귀 도착점이 남화로
  - "실속을 알고 너무 자주 오는" [해솔](해솔/해솔.md) 조공 사절이 실제로 향하는 곳
  - 화련의 무게중심 이원화: 화징=정치 / 남화=돈과 문화 [태정제](태정제.md) 씨앗 3)(천명이 떠난다 = 실은 믿음이 식는 것) 연동 —
    - 번영의 실물이 수도가 아니라 남화에 있으므로, 남화가 흔들리면 천명이 흔들림

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 신전** 하늘이 황제에게 천하 질서를 맡겼다는 국의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 대상 숙소** 낙타와 짐을 함께 재우는 안뜰형 숙소. 먼 길의 소문이 가장 먼저 닿는 자리
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
