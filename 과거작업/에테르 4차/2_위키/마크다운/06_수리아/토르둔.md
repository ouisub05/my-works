# 토르둔
> 그라니타 왕

**Thordun**

| | |
|---|---|
| **소속** | 그라니타 드워프 왕국 |
| **대륙** | 수리아 |
| **능력** | 감응 체질 — 제련·단조 가호 보유 (명장 왕) |

## 개요
- [그라니타](그라니타/그라니타.md)의 그라니타 왕.
- 이름** 토르둔 (Thordun)

## 능력
- 능력** 감응 체질 — 제련·단조 가호 보유 (명장 왕)
  - 제련·단조 가호는 손끝의 기술 가호라 나이로 무뎌지지 않음 — 수백 년 두드린 손에 축적됨
  - 권위의 이중 구조: 왕관 반 + 모루 반.
    - 통치는 후계에게 넘기면서도 대장간은 놓지 못하는 노인
  - 왕 자신이 살아 있는 가호의 증거 → 대장장이 신 신앙의 밀도가 왕국 안에서 저절로 유지됨
    - ([신대륙](../07_신대륙/신대륙.md) [일바렌](../07_신대륙/일바렌/일바렌.md) [아엘리온](../07_신대륙/아엘리온.md)과 같은 '왕의 몸=신앙의 증거' 계열. 단 일바렌은 생명·재생 가호)

## 갈등과 불씨
- 약점·이야기 씨앗
  - **1)** [B] 초원이 통일되는 날
  - [코르타이](코르타이/코르타이.md) 통일 후 구상 ③서방 원정이 실현되면, 산맥 지하왕국인 그라니타 자체는
    - 정복 대상이 되기 어려우나 남쪽 관문 타쉬둔의 아랄샨 교역이 통째로 끊김
  - 남관문은 실크로드와 가까워 두 관문 중 더 큰 쪽 — 교역 구조의 절반이 길 하나에 걸려 있음
  - D7(실크로드 호황의 취약성)의 [드워프](../02_종족/드워프.md) 측 당사자 자리 **2)** [C] 마정석이라는 저울 [카람 [라시드](../04_마슈리크/라시드.md) 씨앗 C와 대구]
  - 카람과 함께 세계 마정석 양대 산지 — 한쪽의 산출·가격이 다른 쪽 사회 구조를 흔듦
  - 토르둔에게는 그럴 의도가 없음(적절한 규모로 수출하는 기존 방침 유지)
  - 그러나 장부를 쥔 [브레간](브레간.md)에게는 그것이 '기회'로 보임 —
    - 승계 자체가 카람 렌티어 구조(라시드 씨앗 C)의 방아쇠가 될 수 있음
  - 서방 창구 [아르카디아](../03_아우로라/아르카디아/아르카디아.md)([바흐탄](../03_아우로라/바흐탄.md))가 값의 통로
