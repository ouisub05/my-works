# 백사
> 백사 (白沙) — 위장의 해항

| | |
|---|---|
| **소속** | 위장 |
| **대륙** | 수리아 |
| **유형** | 항구 |
| **성격** | 바하리아 해적의 상시 표적지 (쌀 수출항 아님) |

## 개요
- 위장의 지명. 위장의 해항
- 성격** [바하리아](바하리아/바하리아.md) 해적의 상시 표적지 (쌀 수출항 아님)
  - 기존 설정 "바하리아가 [앙사라](앙사라/앙사라.md) 편을 들려고 자국 해적의 [위장](위장/위장.md) 약탈을 묵인
    - (표적 관리형)"의 그 표적이 백사
  - D6(위장의 처지)의 지리적 실물 — [화련](화련/화련.md)에 삼켜질 땅으로 여겨지고,
    - 앙사라와 쌀로 경쟁하고, 항구 하나는 상시로 털리는 나라

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 신전** 감응 체질의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
