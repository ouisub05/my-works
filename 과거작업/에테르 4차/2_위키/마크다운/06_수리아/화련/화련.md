# 화련
> 화련 (Hwaryeon) — 마법 관료제 대제국 (중국 중앙 대응)

**Hwaryeon**

| | |
|---|---|
| **위치** | 수리아 · 중국 중앙 대응 |
| **수도** | 화징 |
| **국가원수** | 태정제 (황제) |
| **정치체제** | 명목상 누구나 가능. 그러나 응시료 탓에 사실상 귀족 또는 엘프 정도만  |
| **인구** | 약 1억 1000만 |
| **종족 구성** | 인간 30 / 수인 45 / 하플링 10 / 엘프 8 / 드워프 4 / 노움 2… |
| **종교** | 하늘이 황제에게 천하 질서를 맡겼다는 국가 이념형 신앙 |
| **경제** | 해솔 / 앙사라 / 바하리아 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [수리아](../수리아.md)에 속한 세력. 문화 중심의 마법 관료제 대제국
- 정체성** 문화 중심의 마법 관료제 대제국

## 역사
- 왕조 상태** 안정기. 단 [코르타이](../코르타이/코르타이.md)(초원 유목 세력)의 잦은 침략이 골칫거리

## 지리
- 황제 강력형** 황제가 실권. 마법 관료제는 황권의 도구

- 하플링** 곡창 농촌 + 도시 길드 / 노움: 대도시 공방 / 오크: 도시 용병·군문 소수
- 엘프가 응시 가능 계층인 이유** 장수(부 축적) + 정령술의 희귀 가치 + 특정 산업(유흥 문화 일부) 장악
- 드워프** 5% 중 2%p 자국민, 3%p 외부 영입. 전원 장인·기술 관료 계열
- [위장](../위장/위장.md)** 별개 국가. 문화·유흥의 주요 고객
- 코르타이** 방어선·화친·토벌 사이에서 고민 중. 시도해 본 것은 토벌 원정 → 실패
- [아신](../아신/아신.md) 국가** 짜증나는 존재
- [히노와](../히노와/히노와.md)** 소식 자체를 못 들음. 국가로 인식하지 않음
- [캉리](../캉리/캉리.md)** 고농도 에테르가 탐나지만 지형이 험해 가지 않음
- 코르타이·아신에게** 살찐 먹잇감

## 갈등과 불씨
- 태정제 약점·이야기 씨앗
  - **1)** '늑대가 온다'는 경고 : 삭방대공의 "이번 것은 다르다"가 계속 할인되는 구조 —
    - 침공이 시작되는 날, 유일하게 준비된 자는 가장 무시당하던 자
  - **2)** 중앙-변경의 긴장: 병력을 쥔 방계 대공의 경고가 무시될수록 —
    - 최악의 경우 침공 전에 내부 균열이 먼저 올 수도
  - **3)** 천명의 그늘 : 황제 본인이 발현자가 아님 — 전쟁 패배 등으로 민심·믿음이
    - 식으면 종친 발현자들의 가호부터 약해지고, "천명이 떠난다"는 소문이 왕조를
    - 안에서부터 무너뜨리는 구조 (신성력 법칙의 왕조 붕괴 시나리오)
  - **4)** 균형 감각의 배신: 파벌 논쟁을 균형으로 즐기는 통치술 — 평시의 명수가 전시엔
    - 결단 지연이 됨. "잘 다스리는 능력"과 "위기에 대응하는 능력"이 다름

## 법의 세 줄과 승계
- 법의 꼭대기 — 국가법
- 조문에 종족 — 아니오
- 조문에 성별 — 예
- 승계 — 장자 · 아들만
- 비고
  - 천명 사상이 있으나 국체를 쥔 것은 율령과 관료제다
  - 과거제 5개 트랙과 황위가 성별로 닫혀 있다
  - 바벨리아의 동방판이되 더 서늘하다. 사람을 시험으로 골라 뽑는 제도를 이미 손에 쥐고도 절반을 시험장에 들이지 않는다
  - 남녀의 능력 차가 크지 않다는 세계 대원칙 아래이므로, 이 선은 자연이 아니라 선택이다
  - 조공국인 해솔은 반대로 열어 두었다. 종주국의 선이 조공 체제를 타고 아래로 내려가지 않았다
  - 체제상으로는 과두정도 부족국도 아닌 관료제형이다. 작위는 실재하나(삭방대공) 그 근거가 땅도 전사 수도 아니라 황제와의 거리다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
