# 판디라 · 인드라바
> 판디라 (Pandira) 대왕국 + 인드라바 (Indrava) 속국들 (남·북인도 대응)

**Pandira**

| | |
|---|---|
| **위치** | 수리아 · 남·북인도 대응 |
| **수도** | 마두란 |
| **정치체제** | 여러 소왕국으로 분열. 각각 판디라에 신속 |
| **국가원수** | 마하젠 |
| **인구** | 약 6,000만 |
| **종족 구성** | 인간 33 / 수인 54 / 하플링 8 / 엘프 2 / 드워프 2 / 노움 1 |
| **종교** | 판디라 신앙 40%(정복 후 이식) / 산 신앙 30% / 불교 대응 신 |
| **경제** | 향신료 + 인도양 해상 교역 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [수리아](../수리아.md)에 속한 세력. 남쪽이 북쪽을 지배하는 역전 구도. 향신료의 원산지
- 정체성** 남쪽이 북쪽을 지배하는 역전 구도. 향신료의 원산지

## 역사
- 내력** 인드라바(당시 하나의 제국)가 먼저 판디라를 정복하려다 밀려서 역으로 속국화됨
  - → 판디라가 인드라바 제국을 여러 소왕국으로 분열시킴 (분열시켜 지배)

## 사회
- 판디라** [인간](../../02_종족/인간.md) 33% / [수인](../../02_종족/수인.md) 54% / [하플링](../../02_종족/하플링.md) 8% / [엘프](../../02_종족/엘프.md) 2% / [드워프](../../02_종족/드워프.md) 2% / [노움](../../02_종족/노움.md) 1%
  - (정글·사바나 환경, 수인 다수·엘프 희소. 하플링=농촌·도시 길드)
- 인드라바** 인간 36% / 수인 40% / 드워프 13% / 하플링 8% / 엘프 2% / 노움 1%
  - (히말라야 인근, 드워프 고비율)
- 판디라** 카스트 대응 신분제 존재. 단 종족과 얽히지 않음 (같은 종족 안에 전 계급 존재)
- 인드라바** 농업 + 광산 + 수공업
- 수탈** 판디라는 주로 광산 산물을 뜯어감. 식재는 부족할 때만
- 판디라** 다신교 판테온 (힌두 대응)
- 앙사라** 향신료 가격 경쟁에서 판디라 우세
- 북방** 거의 없음. 있어도 중앙아시아 쪽, 그마저 [아케메니아](../../04_마슈리크/아케메니아/아케메니아.md)(페르시아)를 거쳐야 함
- 앙사라에게** 이길 수 없는 상대
- 서쪽 고객들(마슈리크·악수미아·유럽)에게** 향신료의 원산지이자 부유한 나라라는 착각
  - (실제로는 그 정도 아님 — 소문이 실체를 앞서는 나라)

## 법의 세 줄과 승계
- 법의 꼭대기 — 종교법 (교단 우위형)
- 조문에 종족 — 아니오
- 조문에 성별 — 예
- 승계 — 장자 · 아들만
- 비고
  - 카스트 대응 신분제가 있으되 종족과 얽히지 않는다. 나누되 종족으로는 막지 않는 나라다
  - 인드라바 소왕국들은 판디라 신앙 이식분을 꼭대기에 두며 승계 방식은 같다
  - 소왕국의 왕관 자체가 종주가 나눠 준 것이다. 재교부의 국제판 사례이며, 쪼개어 여럿에게 준 형태라 정통성 다툼이 제도적으로 설계되어 있다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
