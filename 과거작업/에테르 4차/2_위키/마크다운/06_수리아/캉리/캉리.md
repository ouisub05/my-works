# 캉리
> 캉리 (Kangri) 고원 — 수련의 땅 (티벳·위구르 대응)

**Kangri**

| | |
|---|---|
| **위치** | 수리아 · 티벳·위구르 대응 |
| **정치체제** | 작은 도시국가나 마을 수준 (통일 세력 없음) |
| **인구** | 약 200만 |
| **종교** | 산령(山靈)의 가호 — 약하고 드묾 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [수리아](../수리아.md)에 속한 세력. 국가 없는 고원. 고농도 에테르 + 방해받지 않는 고요함 때문에
- 정체성** 국가 없는 고원. 고농도 [에테르](../../01_세계관_코어/에테르.md) + 방해받지 않는 고요함 때문에
  - 외부 수행자들이 흘러드는 수련의 땅 (인프라는 좋지 않으나 그래서 좋아함)

## 지리
- ※ 히말라야 자체는 이 권역에서 제외 ( — 상단 완료 목록 참조** 세계 최대 에테르 요지,
  - 누구의 땅도 아님, 접근은 기슭까지)
- 판로** 주 고객 = 찾아온 수행자들(수련 보조용 현지 소비).
  - 소량이 부탄·[화련](../화련/화련.md) 방면 행상으로 흘러나감. 물량이 적어 열강이 탐낼 규모가 아님
  - — 화련이 탐내는 것은 마정석이 아니라 고농도 에테르 땅 그 자체
- 신앙이 그렇게 강하지 않음

## 행정구역
- 수행자 상대 접객 + 목축·약초·소금 채집 주력 + 고원 농사 부업

## 정치
- 정치** 작은 도시국가나 마을 수준 (통일 세력 없음)

## 군사
- 계통** 무력만 / 마법만 / 둘 다 — 각자 하고 싶은 분야를 수련
  - 무력+마법 동시 수련 도전자도 자연스럽게 섞여 있음. 아무도 말리지도 특별 취급하지도 않음
    - ('전설적 예외'가 나올 수 있는 토양이지만, 그게 목적인 땅은 아님)
