# 앙사라
> 앙사라 (Angsara) — 엘프 신정 왕국 (인도차이나 대응)

**Angsara**

| | |
|---|---|
| **위치** | 수리아 · 인도차이나 대응 |
| **수도** | 앙사푸라 |
| **정치체제** | 하플링·노움·오크 없음 — 폐쇄적 엘프 신정 왕국이라 |

| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [수리아](../수리아.md)에 속한 세력. 개방형 농업 엘프 신정 왕국. '농사짓는 엘프'의 나라
- 정체성** 개방형 농업 [엘프](../../02_종족/엘프.md) 신정 왕국. '농사짓는 엘프'의 나라
  - (기존 엘프국 유형 — [실바리스](../../03_아우로라/실바리스/실바리스.md)=은둔, [마르네스](../../03_아우로라/마르네스/마르네스.md)=해상, [야쿠아라](../../07_신대륙/야쿠아라/야쿠아라.md)=밀림 제국, [일바렌](../../07_신대륙/일바렌/일바렌.md)=은닉 — 과 모두 다른 새 유형)

## 행정구역
- 왕(세속 군주) / 사제단(종교 권위, 왕을 승인·견제** 왕(세속 군주) / 사제단(종교 권위, 왕을 승인·견제, 별도 조직) / 엘프 대가문 귀족 평의회
- 신자 눈에는 "정령신이 힘을 더 내려주는 것"으로 보여
  - 교리가 검증되는 것처럼 보임. 실제로는 [에테르](../../01_세계관_코어/에테르.md)+믿음이 정령술에 얹힌 것
  - (최대 떡밥의 정령판 사례. 정령술과 [신성력](../../01_세계관_코어/신성력.md)이 섞여 있어 진실 규명이 더 어려운 땅)

## 사회
- 엘프 92% / [수인](../../02_종족/수인.md) 6% / [인간](../../02_종족/인간.md) 2%
- 엘프 92% 중 85%p = 농민
- 수인·인간** 고된 노동이나 귀찮은 일을 맡음 (사실상 하층)
- 향신료 가격 경쟁에서는 판디라가 우세
- 판디라** 향신료 가격 경쟁 상대 (판디라 우세)
- 바하리아에게** 최우선 파트너
- 판디라에게** 딱히 안중에 없음

## 법의 세 줄과 승계
- 법의 꼭대기 — 종교법 (교단 우위형)
- 조문에 종족 — 예
- 조문에 성별 — 아니오
- 승계 — 장자 · 모두 가능
- 비고
  - 사제단이 왕을 승인·견제하는 구조가 그대로 법의 꼭대기가 된다
  - 왕가·사제단·귀족 평의회가 전부 엘프이므로 자리가 잠긴 나라다
  - 판디라와 정반대다. 이쪽은 나누지 않는 척하며 자리를 잠그고, 저쪽은 대놓고 나누되 종족으로는 막지 않는다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
