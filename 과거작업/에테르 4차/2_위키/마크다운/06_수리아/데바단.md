# 데바단
> 데바단 (Devadan, '신들의 이빨') — 히말라야 대응 산맥

| | |
|---|---|
| **소속** | 캉리 |
| **대륙** | 수리아 |
| **유형** | 자연지형 |

## 개요
- [캉리](캉리/캉리.md)의 지명. 히말라야 대응 산맥
- 세계 최대 [에테르](../01_세계관_코어/에테르.md) 요지 (최고봉 등). 누구의 땅도 아님
- 접근은 기슭 정도, 가끔 도전자 발생 — 돌아온 자는 전부 중간 포기자
- [용족](../02_종족/용족.md) 서식지 중 하나

## 이름의 유래
- 이름은 있으나 주인은 없는 산맥 — 세계에서 가장 강한 힘이 고인 곳에 국경이
