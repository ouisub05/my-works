# 노움

## 노움
- 특화** 마공학·공학
- 수명** 150년 안팎 ([인간](인간.md)의 2배쯤)
- 외형** [하플링](하플링.md)보다 조금 더 작은 키, 마른 체형. 눈이 특징적 (정밀 작업 적성)
- 분포** 독자 왕국·집단 거주지 없음 —
  - 실제 세계에서 인종이 섞여 있듯, 각지 도시에 섞여 삶
- 세계 문명 수준 연동** 노움이 있는 곳마다 마공학 보유 — 세계의 마공학 수준 전반 상향
  - [해솔](../06_수리아/해솔/해솔.md) '인형'은 해솔 거주 노움 집단의 작품으로 수정 —
    - 개발 구조: [드워프](드워프.md)(바우둔) 설계 + 노움 제작 협업
  - 인형의 위상: 세계 유일이 아니라 여러 마공학 성과 중 하나
