# 드워프

## 드워프
- 특화** 대장장이 — 특히 룬 각인 — + 도끼 전사
- 룬 각인** 마법을 특수한 돌에 새기는 기술 (마법 계통의 드워프식 응용)
  - 새기는 돌: 마정석 + 마정석과는 다른 별도의 광석 (마정석 쪽이 더 가치가 높음)
- 큰 산맥 근처에 많음. 보통 지하에 거주. 지상에는 타종족과 교류하는 마을을 만
- 수명** 200~300년
- 산맥 = 고농도 [에테르](../01_세계관_코어/에테르.md) 지대이므로, 드워프는 에테르 요** 산맥 = 고농도 에테르 지대이므로, 드워프는 에테르 요지의 주인인 셈 (교역·갈등의 핵)
- 산맥마다 독립된 지하왕국
  - [그라니타](../06_수리아/그라니타/그라니타.md) 산맥(우랄 대응): 최대 규모·개방형. 관문 2개(베스가르·타쉬둔), 왕도 [그란둠](../06_수리아/그란둠.md)
  - 몬스 페라 산맥(알프스 대응): 소규모, 지상 교역이 생존 전략 → [베르가동맹](../03_아우로라/베르가동맹/베르가동맹.md)의 대등한 동반자
- 종교** 대장장이 신 + 조상 숭배
