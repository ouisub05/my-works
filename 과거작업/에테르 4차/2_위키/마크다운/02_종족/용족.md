# 용족

## 용족
- 최장수 종족. 7종 체제 밖의 별개 존재로 유지
- 규모** 세계 전체 약 3천
- 거주** 4할은 정체를 숨긴 채 타종족 사회에 섞여 삶
  - / 나머지 6할은 타종족이 오지 않는 오지에 서식
- [인간](인간.md)으로 변신 가능. 강할수록 용족의 흔적이 남지 않음
  - (약하면 변신 시 뿔, 짧은 꼬리, 작은 날개, 약간의 비늘이 보일 수 있음)
- 은둔 이유** 무관심·초연. 타종족 일에 관심이 없음. 섞여 사는 것은 개인 취향
  - (박해나 율법 때문이 아님. 섞여 사는 개체는 종족 내에서 별난 취향 취급)
- 서식지
  - 그린란드 대응 / 극지 / 히말라야(최고봉 등에만) / 파타고니아 남쪽([아오니아](../07_신대륙/아오니아/아오니아.md) 너머)
  - 크레타 대응 섬 — 숨은 서식지 (사람들은 험한 무인도로 앎)
  - 히말라야는 다른 서식지와 동급 (세계 최대 [에테르](../01_세계관_코어/에테르.md) 요지라는 지리 속성과 별개. 특별 위상 없음)
  - [시브란](../06_수리아/시브란/시브란.md) 유목 부족은 극지로 가지 않음 → 극지 서식과 충돌 없음
- 사회 형태** 완전 개별 — 무리·조직 없음. 서식지는 그냥 겹칠 뿐
- 타종족의 인지** 전설 취급이 다수. 목격담·역사서 기록은 존재하나
  - 사람들은 목격한 용을 다른 마물(드레이크 등)로 여김
  - → '용족'이라는 종족의 존재 자체는 알려지지 않음 (목격담은 전부 마물 기록으로 분류. 떡밥 소재)
