# 카즈나르
> 카즈나르 (Kaznar) — 카즈렌의 마정석 광산 도시

**Kaznar**

| | |
|---|---|
| **소속** | 카즈렌 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |
| **성격** | 주인 있는 통제 산지 |

## 개요
- 카즈렌의 지명. 카즈렌의 마정석 광산 도시
- 성격** 주인 있는 통제 산지
  - [스카르둔](스카르둔.md) = 최대 산지이나 주인이 없어 누구나 퍼 감 (물량은 많고 값은 눌림, 관리 부재)
  - 카즈나르 = 규모는 그에 못 미치나 [드워프](../02_종족/드워프.md)가 통제 —
    - 캐는 양이 아니라 다듬어 내보내는 값으로 먹고사는 도시
  - → [카즈렌](카즈렌/카즈렌.md)은 [신대륙](신대륙.md)에서 유일하게 마정석 가격을 신경 쓰는 세력
    - = 누군가 스카르둔을 삼키려 드는 날의 예비 당사자 (스카르둔 폭탄 등재는 현재 보류)

## 종교
- 룬 각인** 신대륙 드워프의 대장 기술은 보통 수준.
  - 두르가른·카즈렌은 구대륙 드워프와 같은 신을 섬기면서도
  - 룬 각인을 갖지 못함 → 갈라진 세월의 길이를 보여주는 지표.
  - 신앙은 남고 기술은 잃음 — '같은 조상' 떡밥에 시간의 깊이가 붙음
