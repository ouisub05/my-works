# 셀루아
> 셀루아 (Selua) — 강변 도시국가 연합 (몬트리올·뉴욕·토론토 대응)

**Selua**

| | |
|---|---|
| **위치** | 신대륙 · 몬트리올·뉴욕·토론토 대응 |
| **정치체제** | 강변 도시국가들의 연합 (수로 교역으로 묶임) |
| **인구** | 약 90만 |
| **종족 구성** | 수인 49 / 인간 44 / 엘프 3 / 하플링 2 / 노움 1 / 오크 1 |
| **종교** | 강·물길 신앙 (독자) |
| **경제** | 셀룬 (Selun) / 연합 회의지: 미르하 (Mirha) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 정치
- 정치** 강변 도시국가들의 연합 (수로 교역으로 묶임)

## 경제
- 최대 교역도시** 셀룬 (Selun) / 연합 회의지: 미르하 (Mirha)
- 경제 기반** 수로 교역 + 농경 (대서양~오대호 물길 회랑)

## 종족 구성
- 종족** [수인](../../02_종족/수인.md)+[인간](../../02_종족/인간.md) 다수
- 종족 역할** 유동적

## 종교
- 종교** 강·물길 신앙 (독자)
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 정화·치유 가호 (물의 정화력)
  - ※ 치유 계열 가호 — 구대륙에서 솔교 교단이 독점한 '기적'을 신대륙 독자 신앙이 보유
    - (진실을 아는 시점에선 "가호는 믿음을 따를 뿐"의 방증)

## 외교
- 대외 관계** 이웃들과 대체로 평화적 교역 관계

## 대외 인식
- 대외 인지** 이웃 + 수로를 따라 넓게 인지 (넬바 대호~대서양안)
