# 초케
> 초케 (Choke) — 지파라의 잠식 변경 [지파라 → 야쿠아라]

**Choke**

| | |
|---|---|
| **소속** | 야쿠아라 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |
| **성격** | 지파라만 이름을 붙인 땅 (야쿠아라에는 이 지대를 부르는 이름조차 없음) |

## 개요
- 야쿠아라의 지명. 지파라의 잠식 변경 [지파라 → 야쿠아라]
- 성격** [지파라](지파라/지파라.md)만 이름을 붙인 땅 ([야쿠아라](야쿠아라/야쿠아라.md)에는 이 지대를 부르는 이름조차 없음)
  - 제 영토인데 이름이 없다 = 통치가 닿은 적 없다는 증거 / 장부에 적어야 하는 쪽만 이름을 지음
    - → 이름이 있는 쪽이 실제 주인
  - 위치: [우루비](우루비.md)의 배가 닿지 않는 지류 안쪽

## 종교
- 변방 부족의 자각** 자신이 야쿠아라 소속이었다는 사실을 아예 모름
  - → [카우아리](카우아리.md)가 진실을 알아도 마주할 것은 배신자가 아니라 처음 보는 사람들
    - ("너희는 원래 내 백성이다" → "당신이 누구시오")
    - = 빼앗긴 것이 분명한데 되찾을 명분이 없는 상실 (정복 군주에게 가장 모욕적인 패배 형태) → [티스케](티스케.md) 씨앗 1(운 가호의 함정)과 연동: 초케의 잠식은 사실
    - 야쿠아라가 너무 넓어 저절로 굴러온 몫인데 티스케는 제 수완으로 여김
    - (남이 흘린 것을 주우며 스스로를 사냥꾼이라 믿는 왕)
