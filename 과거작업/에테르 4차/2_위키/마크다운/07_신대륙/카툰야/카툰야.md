# 카툰야
> 카툰야 (Katunya) — 도시국가 동맹 (마야 대응)

**Katunya**

| | |
|---|---|
| **위치** | 신대륙 · 마야 대응 |
| **정치체제** | 도시국가 동맹 (테노치아와의 전쟁으로 결속이 묶임) |
| **국가원수** | 이츠칸 |
| **인구** | 약 350만 |
| **종족 구성** | 수인 45 / 인간 36 / 엘프 16 / 하플링 1 / 노움 1 / 오크 1 |
| **종교** | 독자 다신교 (천체·자연신) |
| **경제** | 화전 농경 중심 (옥수수 평행) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 법의 세 줄과 승계
- 법의 꼭대기 — 종교법 (셈이 꼭대기형)
- 조문에 종족 — 아니오
- 조문에 성별 — 아니오
- 승계 — 도시별 · 전시 통수권자는 임시직
- 비고
  - 종교법의 세 번째 유형이 여기서 나왔다. 왕도 교단도 아닌 력(曆)과 하늘의 셈이 법의 꼭대기에 있다
