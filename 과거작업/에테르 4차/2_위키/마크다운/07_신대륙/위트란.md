# 위트란
> 위트란 (Witran) — 아라우카 → 테우엘라 약탈 통로 [E1]

**Witran**

| | |
|---|---|
| **소속** | 아라우카 |
| **대륙** | 신대륙 |
| **유형** | 자연지형 |
| **성격** | 산 → 초원 내리막형 (카우첸에서 초원으로 떨어지는 골짜기 입구들) |

## 개요
- [아라우카](아라우카/아라우카.md)의 지명. 아라우카 → 테우엘라 약탈 통로 [E1]
- 성격** 산 → 초원 내리막형 ([카우첸](카우첸.md)에서 초원으로 떨어지는 골짜기 입구들)
  - 내려가긴 쉽고 가축을 몰고 되오르기는 무거움
    - → [야텔](야텔.md)의 답은 초원에서 싸우는 것이 아니라 골짜기 입구에서 기다리는 것
    - (목자를 전사로 만들지 않고 가능한 유일한 수)
- E1 남부 톱니** 겨울 = [테우엘라](테우엘라/테우엘라.md)가 [아이켄](아이켄.md)에 모이고 / 위트란이 열리고 /
  - 카우첸에서 빼돌린 광물이 창이 되고 / [하난타](하난타.md)에서 통행세가 샘 — 계절 하나에 네 자리가 동시에 움직임

## 이름의 유래
- 명칭** 아라우카 측 단일 호칭 (약탈하는 쪽만 이름을 붙였다는 사실 자체가 관계를 말함)

## 군사
- 통행 시기** 겨울에만 열림 (아이켄 집결기와 연동)
  - 눈이 쌓이면 못 넘고, 녹으면 초원은 이미 흩어져 있음 → 약탈에는 때가 정해져 있음
