# 스카르둔
> 스카르둔 (Skardun) — 스카르드 산맥의 마정석 채굴 거점

**Skardun**

| | |
|---|---|
| **소속** | 스카르드산맥 스카르둔 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |

## 개요
- [스카르드산맥_스카르둔](스카르드산맥_스카르둔/스카르드산맥_스카르둔.md)의 지명. 스카르드 산맥의 마정석 채굴 거점
- 소속** 어느 세력의 것도 아닌 독립 채굴 마을
- 규모** [신대륙](신대륙.md) 최대 마정석 산지
  - 인근 세력들은 물론, 대륙 반대편의 [테스카론](테스카론/테스카론.md)까지 원정 채굴을 옴
  - → 테스카론의 국력·원거리 물류 능력을 보여주는 지표이기도 함

## 정치적 무게
- 주인 없는 땅이 대륙 최대의 자원을 깔고 앉은 구조 —
  - 현재는 아무도 소유하지 않아 모두가 드나들지만, 어느 세력이든 삼키려 드는 순간
  - 여러 세력이 동시에 얽히는 분쟁지가 됨 (신대륙판 무주공산 화약고 후보)
