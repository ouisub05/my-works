# 차쿠아
> 차쿠아 (Chakua) — 관목지 부족연합 (차코 대응)

**Chakua**

| | |
|---|---|
| **위치** | 신대륙 · 차코 대응 |
| **정치체제** | 느슨한 부족 연합 (티네리 유사형. 통일 왕권 없음) |
| **국가원수** | 냐우케 |
| **인구** | 약 40만 |
| **종족 구성** | 수인 47 / 엘프 33 / 인간 18 / 기타 2 |
| **종교** | 자연·정령 신앙 |
| **경제** | 수렵·채집 중심 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 국호와 상징
- 국명 어원** 차코('사냥터') 변형

## 정치
- 정치** 느슨한 부족 연합 ([티네리](../../05_아자니아/티네리/티네리.md) 유사형. 통일 왕권 없음)

## 국가원수
_(내용 없음)_

## 군사
- 회합지** 테콰라 (Tekuara, '모두의 터')
  - 상설 도시가 아니라, 부족들이 필요할 때(큰 사냥 뒤·전쟁 결의·분쟁 중재 등) 모이는
    - 고정된 회합 터 — 관목지 한가운데의 큰 물웅덩이 지대
  - 평시에는 소수의 터지기(관리 부족)만 머묾 ("도시 없음" 확정과 충돌하지 않음)

## 경제
- 경제 기반** 수렵·채집 중심

## 사회
- 도시 없음
- 발전 수준** 약세

## 종족 구성
- 종족** [수인](../../02_종족/수인.md)+[엘프](../../02_종족/엘프.md) 다수, [인간](../../02_종족/인간.md) 존재
- 종족 역할** 구분 없음 — 모두가 전사 가능 ("모두의 숲을 모두가 지킴")

## 종교
- 종교** 자연·정령 신앙
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 생존·은신 가호

## 외교
- vs [인티마라](../인티마라/인티마라.md)** 정복 시도를 격퇴한 적대 관계
  - 격퇴 비결: 혹독한 환경 + 기동 게릴라전 / 전사 문화·기습 전통

## 대외 인식
- 대외 인지** 접경지 + 교역 상대 인지 (남미를 넘지 못함)
  - 교역 상대: 근처 국가들
  - [지파라](../지파라/지파라.md)와는 교역 불가 — [야쿠아라](../야쿠아라/야쿠아라.md) 제국의 팽창으로 가는 길이 막힘
