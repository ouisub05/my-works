# 테스빈
> 테스빈 (Tesvin) — 스카르둔 원정 채굴대의 보급 거점 [테스카론]

**Tesvin**

| | |
|---|---|
| **소속** | 테스카론 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |
| **성격** | 곡식을 마정석으로 바꾸는 자리 |

## 개요
- 테스카론의 지명. 스카르둔 원정 채굴대의 보급 거점 [테스카론]
- 근거** 기존 설정 "대륙 반대편의 [테스카론](테스카론/테스카론.md)까지 [스카르둔](스카르둔.md)에 원정 채굴을 옴 —
  - 국력·원거리 물류 능력의 지표"의 실물
- 성격** 곡식을 마정석으로 바꾸는 자리
  - 원정대는 [나칼리](나칼리.md)의 잉여 곡물을 싣고 가 사람을 먹이고 물자를 삼
    - → 테스카론의 원거리 물류란 곧 곡식과 마정석의 교환 사업

## 경제와 산업
- 물류 축 완성** 나칼리(곡식) → 테스빈(보급) → 스카르둔(마정석) → 테스카르(회수)
