# 인티마라
> 인티마라 (Intimara) — 안데스 신성제국 (잉카 대응)

**Intimara**

| | |
|---|---|
| **위치** | 신대륙 · 잉카 대응 |
| **정치체제** | 쿠스카 (Kuska) — 안타라 산중의 왕도, 인티냔의 결절점 |
| **국가원수** | 아탄쿠르 |
| **인구** | 약 900만 |
| **종족 구성** | 인간 32 / 수인 30 / 드워프 19 / 엘프 15 / 하플링 2 / 노움 … |
| **종교** | 태양 신앙 (태양신을 정점에 둔 신앙. 인티 평행) |
| **경제** | 농업(계단식 농경) + 마정석(산맥 채굴) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 국호와 상징
- 국명 어원** '태양의 나라' (인티=태양)

## 지리
- 추월 분야** 일부 기술력 — 인티냔(Intiñan, '태양의 길'. 제국 도로망)
  - 험준한 안타라 산맥을 관통하는 정교한 도로·교량 토목 기술 → 이 분야에서 구대륙을 앞섬
  - 산맥의 주인 [드워프](../../02_종족/드워프.md)의 토목 기술이 제국 도로망을 떠받침 (드워프 왕 + 도로 제국)

## 정치
- 수도** 쿠스카 (Kuska) — 안타라 산중의 왕도, 인티냔의 결절점
- 정치** 중앙집권 신성제국. 단 현재 약해지는 중

## 경제
- 경제 기반** 농업(계단식 농경) + 마정석(산맥 채굴)

## 종족 구성
- 종족** [인간](../../02_종족/인간.md)·[수인](../../02_종족/수인.md)·[엘프](../../02_종족/엘프.md)·드워프 공존 (다종족 제국). 현재 왕은 드워프
  - 안타라 산맥(안데스 대응)이 배경 → 드워프의 존재·토목 기술이 자연스러움
- 종족 역할 분담
  - 드워프: 토목·채굴 (산맥의 주인. 인티냔·광산 담당 → 드워프 왕과 연결)
  - 엘프: 지략 (참모·전략)
  - 수인: 노동·농사
  - 인간: 정치·노동

## 종교
- 종교** 태양 신앙 (태양신을 정점에 둔 신앙. 인티 평행)
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 활력 가호

## 외교
- 약화의 이유** 외부 압력
  - [야쿠아라](../야쿠아라/야쿠아라.md)·[지파라](../지파라/지파라.md)의 강세 (밀림·북방 신흥 세력)
  - 속국들의 조공 반발 → 변방부터 무너지는 쇠퇴기

## 대외 인식
- 대외 인지** [카이리제도](../카이리제도/카이리제도.md)만 앎. 그 너머 [마리스텔라](../../03_아우로라/마리스텔라/마리스텔라.md)·구대륙의 존재는 모름

## 법의 세 줄과 승계
- 법의 꼭대기 — 종교법 (신 바로 아래형)
- 조문에 종족 — 아니오 (관습으로만)
