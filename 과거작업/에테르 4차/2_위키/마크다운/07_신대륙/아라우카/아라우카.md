# 아라우카
> 아라우카 (Arauka) — 남부 수장국 (마푸체 대응)

**Arauka**

| | |
|---|---|
| **위치** | 신대륙 · 마푸체 대응 |
| **정치체제** | 단일 수장국/왕국 |
| **국가원수** | 라우탄 |
| **인구** | 약 60만 |
| **종족 구성** | 수인 47 / 인간 43 / 드워프 6 / 엘프 2 / 기타 2 |
| **종교** | 조상·전사 숭배 |
| **경제** | 목축 + 광산 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 국호와 상징
- 국명 어원** 아라우카니아 변형

## 정치
- 정치** 단일 수장국/왕국

## 국가원수
- 수장좌** 템쿠라 (Temkura)

## 경제
- 경제 기반** 목축 + 광산

## 종족 구성
- 종족** [수인](../../02_종족/수인.md)+[인간](../../02_종족/인간.md) 다수, [드워프](../../02_종족/드워프.md) 약간
- 종족 역할** 원래는 역할 분담 → 현재는 모두가 전사 가능 (봉기 준비로 인한 총동원 태세)

## 종교
- 종교** 조상·전사 숭배
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 전투 가호 ([노르가르드](../../03_아우로라/노르가르드/노르가르드.md) 유사)

## 외교
- vs [인티마라](../인티마라/인티마라.md)** 종속 관계 — 현재 조공에 반발 중
  - 반발 단계: 무장 봉기 준비 중
  - ※ 인티마라 설정의 "속국들의 조공 반발 → 변방부터 무너지는 쇠퇴기"의 구체 사례

## 대외 인식
- 대외 인지** 이웃 직접 인지 + 소문 등으로 남미 전반 인지
