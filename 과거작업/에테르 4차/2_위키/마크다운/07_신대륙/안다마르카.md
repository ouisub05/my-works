# 안다마르카
> 안다마르카 (Andamarka) — 계단식 농경 + 마정석 광산 관구

**Andamarka**

| | |
|---|---|
| **소속** | 인티마라 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |
| **성격** | 계단식 농경지와 마정석 광산이 한 관구로 묶임 |

## 개요
- [인티마라](인티마라/인티마라.md)의 지명. 계단식 농경 + 마정석 광산 관구
- 성격** 계단식 농경지와 마정석 광산이 한 관구로 묶임
  - → 기존 설정 경제 기반("농업 + 마정석") 전체가 이 관구 하나에 들어감

## 정치적 무게
- 관할** 사제단 관할 ([드워프](../02_종족/드워프.md) 토목 관할 아님)
- 구조적 귀결** [아탄쿠르](아탄쿠르.md)는 나라의 지갑을 남에게 맡긴 왕
  - 그는 가호 없음 + 세습 아님 + 토목 공훈 추대 1대 왕 → 신성한 정통성이 없어 신성한 관구에 못 댐
  - 그가 쥔 것은 도로([하난타](하난타.md))뿐, 본전은 사제단 손안
    - → 쇠퇴기 재정 대책이 전부 변방 쥐어짜기로 흐름
    - = [아마루](아마루.md)의 강경 조공 노선의 근본 원인 (안을 못 건드리니 바깥을 조임) → E1을 키움
  - 아탄쿠르의 '왕조화를 부추기는 주변'의 정체가
    - 사제단일 수 있음 — 손대기 쉬운 왕을 오래 앉혀 두려는 계산
