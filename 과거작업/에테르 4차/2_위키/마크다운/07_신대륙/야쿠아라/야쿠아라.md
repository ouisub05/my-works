# 야쿠아라
> 야쿠아라 (Yakuara) — 밀림 신생 제국 (아마존 대응)

**Yakuara**

| | |
|---|---|
| **위치** | 신대륙 · 아마존 대응 |
| **정치체제** | 이전엔 도시국가들이었고, 현재 통일한 지 얼마 안 된 신생 제국 |
| **국가원수** | 카우아리 |
| **인구** | 약 150만 |
| **종족 구성** | 수인 45 / 엘프 41 / 인간 12 / 하플링 1 / 오크 1 |
| **종교** | 자연·정령 신앙 |
| **경제** | 밀림, 사냥 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 국호와 상징
- 국명 어원** '물'(야쿠)+재규어(야과라) 어감

## 지리
- 수도** 마나우아 (Manaua) — 파라나수 강변의 통일 수도
- 영역** 카아과 대밀림 (Kaagua, '거대한 숲'. 아마존 밀림 대응) + 파라나수 강 (Paranasu, '바다 같은 큰 강')

## 행정구역
- 통일을 이끈 주체** 한 [엘프](../../02_종족/엘프.md) 부족의 일원이 주도

## 정치
- 정치** 이전엔 도시국가들이었고, 현재 통일한 지 얼마 안 된 신생 제국
  - [인티마라](../인티마라/인티마라.md)(늙어가는 중앙집권 신성제국)와 대비되는 '떠오르는 젊은 제국'
  - 통일의 열기·팽창 의지 → 약해지는 인티마라를 압박
  - 통일된 지 얼마 안 됨 → 내부 결속은 아직 다져지는 중 (팽창하되 안으로는 취약 여지)
