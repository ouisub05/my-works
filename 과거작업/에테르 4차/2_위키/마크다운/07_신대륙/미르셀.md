# 미르셀
> 미르셀 (Mirsel) — 셀루아·넬바라 공유 물 신앙 성소 [성소]

**Mirsel**

| | |
|---|---|
| **소속** | 셀루아 |
| **대륙** | 신대륙 |
| **유형** | 성지·종교시설 |

## 개요
- [셀루아](셀루아/셀루아.md)의 지명. 셀루아·[넬바라](넬바라/넬바라.md) 공유 물 신앙 성소 [성소]

## 이름의 유래
- 어원** 셀루아 대표 도시 [미르아](미르아.md)와 어원이 닿음 (물 신앙권의 소리를 한 계열로 묶음)

## 정치적 무게
- 구조
  - 이곳에서는 진짜 치유가 일어남 —
    - 치유 마법이 응급처치가 한계인 세계에서, 교단·예언자·이단심문 없이
    - 강가의 성소가 재생·질병 치유를 해냄
    - → 구대륙 솔교의 "기적은 교단을 통해서만 내린다"에 정면으로 어긋나는 물증
  - 현재는 제국이 거들떠보지도 않음 → 물증이 아무도 모르는 채 놓여 있는 상태
    - (뇌관: [테스카론](테스카론/테스카론.md)이 이 자리를 알아채는 날 — 가호 없는 신왕의 나라에서
    - 백성이 진짜 기적을 찾아 국경 밖으로 걸어 나가기 시작함)
  - 넬바라에게는 숨구멍 — [테스나르 관고](테스나르_관고.md)에서 제국 병사를 보며 사는 나라가
    - 여기서만은 종속국이 아니라 신앙의 동등한 지분자로 섬
  - 셀루아가 "이웃들과 대체로 평화적"인 이유: 무력이 아니라 아픈 자를 받아 주는 자리를 쥠

## 종교
- 자리** 두 나라 사이 물길 요지 / 소유: 주인 없는 공동 성소
  - (양쪽 사제가 함께 씀, 국경 없는 순례지)
- 순례 범위** 셀루아·넬바라 두 나라 안에서만
