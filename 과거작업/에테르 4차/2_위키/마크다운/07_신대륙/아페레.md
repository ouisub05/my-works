# 아페레
> 아페레 (Apere) — 이타마라 화전 전선 [이타마라 ↔ 야쿠아라]

**Apere**

| | |
|---|---|
| **소속** | 야쿠아라 |
| **대륙** | 신대륙 |
| **유형** | 요새·군사시설 |
| **성격** | 해마다 밀려 올라가는 선 (고정 국경 아님) |

## 개요
- 야쿠아라의 지명. 이타마라 화전 전선 [이타마라 ↔ 야쿠아라]
- 성격** 해마다 밀려 올라가는 선 (고정 국경 아님)
  - 화전은 지력이 다하면 옮기는 농법 → [이타마라](이타마라/이타마라.md)의 밭이 해마다 밀림 쪽으로 파고듦
  - → '침범한 날'이 없는 분쟁. [야쿠아라](야쿠아라/야쿠아라.md)의 항의는 늘 뒤늦고 이타마라의 변명은 늘 그럴듯함
    - (엘바/켈드 = 악의 없는 분쟁 / 아페레 = 시점 없는 분쟁) → [카우아리](카우아리.md)에게는 언제든 꺼낼 수 있는 기성 명분. [이타엘](이타엘.md) 씨앗 1은 새 사건이 아니라
    - '카우아리가 마음먹는 날' 시작됨
  - 얄궂은 대비: 야쿠아라는 제 변방도 못 세면서([우루비](우루비.md)) 남이 태운 숲만은 정확히 셈
    - (정령 신앙의 나라라 숲에 관해서만 눈이 밝음)

## 군사
- 이타마라가 태우는 사정** 절박함이 아니라 더 벌기 위해 (확장형)
  - → 이타엘의 "숲보다 사람이 먼저"는 거짓말은 아니되 전부도 아닌 말 —
    - 굶는 백성을 먹이려가 아니라 더 팔기 위해 태움 = 탐욕에 가까운 계산이자 연합을 묶는 정치 구호 → 기존 설정 씨앗 2(화전 도시 vs 어로 도시)가 날카로워짐:
    - 절박한 생존이라면 어로 도시도 참으나, 남의 벌이를 위해 전쟁 위험을 뒤집어쓰는 일은 참을 이유가 없음
    - → 이타엘이 먼저 무너질 곳은 국경이 아니라 연합 회의장
  - → 정령술 상위자의 아이러니 완성: 숲의 목소리를 가장 잘 듣는 자가 더 벌기 위해 태우자고 말함
