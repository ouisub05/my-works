# 그림둔
> 그림둔 (Grimdun) — 두르가른 지하 왕도 카르둔의 대장장이 신 대신전 [건물]

**Grimdun**

| | |
|---|---|
| **소속** | 도르베나 · 두르가른 |
| **대륙** | 신대륙 |
| **유형** | 성지·종교시설 |

## 개요
- [도르베나_두르가른](도르베나_두르가른/도르베나_두르가른.md)의 지명. 두르가른 지하 왕도 카르둔의 대장장이 신 대신전 [건물]
- ※ 룬 각인은 부결

## 종교
- 동시 (세계 설정) — 두르가른의 가호 형태
  - 구대륙 [그라니타](../06_수리아/그라니타/그라니타.md)의 제련·단조 가호와 비슷하되 결이 미미하게 다름
  - 그라니타 = 쇠를 다루는 순간의 정확성·강도 / 두르가른 = 불을 살려 두고
    - 물건이 오래 버티게 하는 지속·내구 쪽으로 무게가 기움
  - 근거: 이쪽 [드워프](../02_종족/드워프.md) 신앙에는 "산을 뚫고 그 길을 유지한다"는 내용이 섞임
    - ([벨하른](벨하른.md)=산맥의 문) → 믿음의 내용이 다르면 가호도 그만큼 어긋난다는 법칙 그대로

## 갈등과 불씨
- 떡밥 값어치** 두 대륙의 가호가 완전히 같았다면
  - "같은 신이 양쪽에 힘을 내린다"로 설명되어 교단에 안심 소재가 되었을 것.
  - 그러나 같은 신을 같은 방식으로 섬기는데 힘의 결이 어긋난다면 출처는 신일 수 없음
  - → 남는 답은 "믿는 내용이 힘을 빚는다" — 두 대장간을 다 본 자는 신학이 아니라
