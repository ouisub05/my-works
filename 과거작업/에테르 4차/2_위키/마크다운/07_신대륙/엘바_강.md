# 엘바 강
> 엘바 강 / 켈드 강 (Elva / Keld) — 발니아르·케다른 사이의 한 강 두 이름

| | |
|---|---|
| **소속** | 발니아르 |
| **대륙** | 신대륙 |
| **유형** | 자연지형 |
| **성격** | 어장 + 유송로 충돌형 |

## 개요
- 발니아르의 지명. 발니아르·케다른 사이의 한 강 두 이름
- 성격** 어장 + 유송로 충돌형
  - 상류 = [케다른](케다른/케다른.md)의 벌목지 — 삼나무를 베어 통나무를 강에 띄워 내려보냄 (조선업의 젖줄)
  - 하류 = [발니아르](발니아르/발니아르.md)의 연어 어장 (농경 없이 부유한 나라의 밥줄)
  - → 위쪽이 부유해질수록 아래쪽 물이 흐려짐. 한쪽의 생업이 다른 쪽의 생업을 망가뜨리는데
    - 어느 쪽도 악의가 없는 분쟁 (전쟁 명분으로는 초라해 더 질기게 이어짐)
- 현재 온도** 항의·말다툼 수준 (유혈 사건 없음)
  - → 두 나라 다 "언젠가 정리할 일"로 미뤄 둠 = 훗날 큰일이 터졌을 때 가장 먼저 갈라질 이음매

## 이름의 유래
- 두 이름 장치** 케다른은 상류를 보고 켈드, 발니아르는 하류를 보고 엘바라 부름
  - 두 나라의 지도를 나란히 놓으면 같은 강이 둘로 그려짐 —
    - 협상 전에 이미 이름부터 합의가 안 되는 사이 / 어느 이름을 쓰느냐가 곧 어느 편이냐
