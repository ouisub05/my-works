# 도르베나 · 두르가른
> 도르베나 (Dorvena) & 두르가른 (Durgarn) — 해안 왕국 + 산맥 드워프 왕국 (애팔래치아+동해안 대응)

**Dorvena**

| | |
|---|---|
| **위치** | 신대륙 · 동해안 대응 |
| **정치체제** | 카르둔 (Kardun) |
| **인구** | 약 20만 |
| **종교** | 산 신앙 (해안 왕국이 산을 섬김 — 광물 교역 국가다운 신앙) |
| **경제** | 농경 + 어로 + 드워프 광물 교역 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 지리
- 두르가른 — 도르반 산맥(애팔래치아 대응) [드워프](../../02_종족/드워프.md) 지하왕국
- 산맥 = 고농도 [에테르](../../01_세계관_코어/에테르.md) 지대 규칙 적용. 산맥마다 독립 왕국 규칙의 신대륙 사례
- 규모** 도르반 산맥의 절반 정도를 차지

## 정치
- 도르베나 — 동해안 단일 왕국
- 지하 왕도** 카르둔 (Kardun)

## 경제
- 경제 기반** 농경 + 어로 + 드워프 광물 교역
- 성향** 개방·교역형 (몬스 페라형) — 도르베나가 관문 역할

## 사회
- 수도** 도르벨 (Dorvel) — 산기슭의 관문 도시
- [넬바라](../넬바라/넬바라.md) 드워프의 출신지

## 종족 구성
- 종족** [엘프](../../02_종족/엘프.md)+[수인](../../02_종족/수인.md)+드워프 + [인간](../../02_종족/인간.md) 소수
  - 드워프는 지하왕국이 뚫은 통로로 산맥을 왕래 (산맥이 장벽이 아니라 '문')
  - 역할 분담(명확): 드워프=광·공방 / 엘프=사제·학자 / 수인=농·어로 / 인간=잡역

## 종교
- 종교** 산 신앙 (해안 왕국이 산을 섬김 — 광물 교역 국가다운 신앙)
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 견고·수호 가호 (산처럼 굳음)
- 종교** 대장장이 신

## 외교
- 도르베나와의 관계** '연합' — 두르가른이 뚫은 통로로 도르베나가 산맥을 지나다님

## 대외 인식
- 대외 인지** 이웃 + 해안을 따라 [벨사르](../벨사르/벨사르.md)까지

## 법의 세 줄과 승계
- 법의 꼭대기 — 국가법
- 조문에 종족 — 도르베나=아니오 / 두르가른=적을 상대 없음
- 조문에 성별 — 아니오
- 승계 — 장자 · 모두 가능
- 비고
  - 두르가른은 단일 종족 왕국이라 종족을 적을 상대가 없다. 실바리스·일바렌에 이은 세 번째 사례다
  - 같은 드워프 왕국이라도 그라니타는 섞여 사는데도 적지 않는다. 경로가 정반대다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
