# 헤스라
> 헤스라 (Hesra) — 헤르바나의 겨울 목영지대

**Hesra**

| | |
|---|---|
| **소속** | 헤르바나 |
| **대륙** | 신대륙 |
| **유형** | 자연지형 |
| **성격** | 흩어짐형 — 겨울이면 무리가 물과 풀을 따라 잘게 흩어짐 |

## 개요
- 헤르바나의 지명. 헤르바나의 겨울 목영지대
- 자리** [헤르바나](헤르바나/헤르바나.md) 북부 (대집회 초원 헤르카 = 모이는 곳 / 헤스라 = 흩어지는 곳)
- 성격** 흩어짐형 — 겨울이면 무리가 물과 풀을 따라 잘게 흩어짐
  - [조르가트](조르가트/조르가트.md) 경기병은 한 덩어리를 덮치는 데는 무적이나, 흩어진 수십 무리를
    - 겨울 초원에서 개별 추격하는 것은 수지가 맞지 않음
    - → 헤르바나는 지지 않는 방식으로 계속 지고 있는 나라 (약탈당하나 멸망하지 않음)
  - 북쪽 선택의 의미: 남하하면 따뜻하나 조르가트가 가깝고, 북상하면 혹독하나 창에서 멂
    - — 추위를 택하는 대신 약탈을 피하는 겨울
  - 기존 설정 가호(시야·추적 가호 = 평원의 눈) 연동: 흩어진 무리끼리 서로를 찾는 데 쓰임
    - → 이 나라에서는 가호가 전투력이 아니라 생존 기술로 발현 ([신성력](../01_세계관_코어/신성력.md) 형태 다양성 사례) [하르간](하르간.md) 씨앗 B 연동: 북쪽 표적이 절멸하지 않고 살아남음 →
    - 표적들이 서로를 알아보는 날 헤르바나가 증언자로 남음
