# 조르가트
> 조르가트 (Zorgat) — 남하하는 전사 왕국 (텍사스 대응)

**Zorgat**

| | |
|---|---|
| **위치** | 신대륙 · 텍사스 대응 |
| **정치체제** | 자르켈 (Zarkel) |
| **국가원수** | 하르간 |
| **인구** | 약 40만 |
| **종족 구성** | 수인 41 / 인간 28 / 오크 28 / 기타 3 |
| **종교** | 전쟁신·전사 신앙 (노르가르드 평행 — 신대륙 독자 발생) |
| **경제** | 농경 + 목축 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 정치
- 왕도** 자르켈 (Zarkel)
- 정치** 단일 왕국/수장국

## 국가원수
_(내용 없음)_

## 군사
- 군사** 기동력·경기병 (초원 전술) + 왕권 중심의 조직력 (동원 체계)
- 팽창 노선** [테노치아](../테노치아/테노치아.md) 공격 중 (영토 확장 겸 약탈. 테노치아 양면 전쟁의 북쪽 축)
  - [카툰야](../카툰야/카툰야.md)도 계속 정복·약탈할 예정 — 남방(중미) 전체가 표적

## 경제
- 경제 기반** 농경 + 목축

## 종족 구성
- 종족** [수인](../../02_종족/수인.md)+[인간](../../02_종족/인간.md)+[오크](../../02_종족/오크.md) 혼합
- 종족 역할** 모두가 전사 가능

## 종교
- 종교** 전쟁신·전사 신앙 ([노르가르드](../../03_아우로라/노르가르드/노르가르드.md) 평행 — 신대륙 독자 발생)
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 돌격·기동 가호 (기병 특화)

## 대외 인식
- 대외 인지** 이웃 직접 인지 + 소문. 교역은 하지 않음
  - 이 왕국의 약탈 소문이 주변에 널리 퍼져 있음

## 법의 세 줄과 승계
- 법의 꼭대기 — 관습법
- 조문에 종족 — 아니오
- 조문에 성별 — 아니오
- 승계 — 거느린 전사 수 (분배자형)
- 비고
  - 봉건 작위가 땅으로 서열을 잰다면 이쪽은 사람으로 잰다
  - 나눠 줄 것이 없으면 거느린 전사가 줄어드니 신분이 곧장 깎인다. 멈추면 무너지는 수레바퀴의 신분 쪽 얼굴이다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
