# 일바렌
> 일바렌 (Ilvaren) — 세계수의 숨은 엘프 왕국 (북동부 삼림 대응)

**Ilvaren**

| | |
|---|---|
| **위치** | 신대륙 · 북동부 삼림 대응 |
| **정치체제** | 일바노르 (Ilvanor) — 세계수 일바 밑동의 도시 |
| **국가원수** | 아엘리온 |
| **인구** | 약 40만 |
| **종족 구성** | 엘프 88 / 수인 11 / 인간 1 |
| **종교** | 세계수 신앙 |
| **경제** | 제한적 접촉 — 소규모 교역은 허용 (실바리스보다 유연) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

- 정치** [엘프](../../02_종족/엘프.md) 중심 숨은 왕국 ([실바리스](../../03_아우로라/실바리스/실바리스.md)형의 신대륙 평행)

## 종족 구성
- 종족** 엘프 다수 + [수인](../../02_종족/수인.md) 소수
  - 역할: 엘프=지도자·궁수 / 수인=교역·노동·근접 전투(검사 등)

## 종교
- 종교** 세계수 신앙
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 생명·재생 가호 (세계수 '일바'의 숨결)
  - 세계수 일바(Ilva): 실재하는 거대한 나무. 단, 일반적인 판타지의 기능은 없음 (그냥 큰 나무)
    - → 나무 자체엔 아무 힘이 없는데 신자들의 가호는 진짜로 발현
    - = "신성력은 [에테르](../../01_세계관_코어/에테르.md)+믿음일 뿐"이라는 세계 최대 떡밥의 완벽한 사례

## 대외 인식
- 대외 인지** 이웃 + 교역 상대를 통해 소문 인지

## 법의 세 줄과 승계
- 법의 꼭대기 — 국가법
- 조문에 종족 — 적을 상대 없음
- 조문에 성별 — 아니오
- 승계 — 장자 · 모두 가능
- 비고
  - 세계수 신앙이 있으나 국체를 쥐지는 않는다. 실바리스와 같은 칸이며, 엘프 왕국 둘이 법의 세 줄을 통째로 공유한다
