# 벤도르
> 벤도르 (Vendor) — 도르베나의 광물 전용 수출 해항

**Vendor**

| | |
|---|---|
| **소속** | 도르베나 · 두르가른 |
| **대륙** | 신대륙 |
| **유형** | 항구 |
| **성격** | 광물·가공품 전용 수출항 (어로 겸용 아님) |

## 개요
- [도르베나_두르가른](도르베나_두르가른/도르베나_두르가른.md)의 지명. 도르베나의 광물 전용 수출 해항
- 성격** 광물·가공품 전용 수출항 (어로 겸용 아님)
  - 수도 도르벨은 산기슭 관문이라 비어 있던 바다 창구를 채움
  - 동맥 완성: [그림둔](그림둔.md)의 불 → [벨하른](벨하른.md)(산맥의 문) → 도르벨 → 벤도르 → 바다

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 신전** 산 신앙 (해안 왕국이 산을 섬김의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 마정석 계량소** 마정석의 무게와 순도를 재어 값을 매기는 관영 시설
- 곳간** 세곡과 비축 식량을 쌓아 두는 관영 창고. 흉년의 마지막 방벽
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
