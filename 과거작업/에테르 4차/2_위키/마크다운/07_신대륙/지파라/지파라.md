# 지파라
> 지파라 (Zipara) — 황금·교역 통일 왕국 (콜롬비아 대응)

**Zipara**

| | |
|---|---|
| **위치** | 신대륙 · 콜롬비아 대응 |
| **정치체제** | 통일 왕국 (콜롬비아~기아나 대응에 걸친 영역) |
| **국가원수** | 티스케 |
| **인구** | 약 120만 |
| **종족 구성** | 인간 34 / 수인 32 / 엘프 17 / 드워프 13 / 하플링 2 / 노움 … |
| **종교** | 자연 신앙 (강하진 않음) |
| **경제** | 부(황금과 교역) + 군사력 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 국호와 상징
- 상징** 과타비 호 (Guatavi) — 황금 봉헌 의식의 호수 ('황금의 나라' 소문의 진원)
- 국명 어원** 무이스카 군주 칭호 '지파' 변형

## 정치
- 정치** 통일 왕국 (콜롬비아~기아나 대응에 걸친 영역)
- 통치 구조** 연합 왕권

## 국가원수
_(내용 없음)_

## 경제
- 힘의 원천** 부(황금과 교역) + 군사력
- 경제 기반** 황금 채굴 및 세공 + 중계(교역)

## 사회
- 수도** 바카타 (Bakata) — 황금 세공의 도시
- ※ [인티마라](../인티마라/인티마라.md)를 압박하는 북방 세력 중 하나

## 종족 구성
- 종족** [인간](../../02_종족/인간.md)·[수인](../../02_종족/수인.md)·[엘프](../../02_종족/엘프.md)·[드워프](../../02_종족/드워프.md). 단 드워프는 서쪽 산맥에만
- 종족 관계** 역할 분담 + 평등 공존

## 종교
- 종교** 자연 신앙 (강하진 않음)
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 운(행운) 가호

## 대외 인식
- 대외 인지** [카이리제도](../카이리제도/카이리제도.md)와 교역 중 알게 됨 (파차라 문명 중 카이리와 가장 연결됨)
