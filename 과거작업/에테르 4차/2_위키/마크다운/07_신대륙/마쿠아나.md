# 마쿠아나
> 마쿠아나 (Makuana) — 카이리 제도의 환산 장부 회관 [건물 / E5 원점]

**Makuana**

| | |
|---|---|
| **소속** | 카이리 제도 |
| **대륙** | 신대륙 |
| **유형** | 제도·관습 |
| **성격** | 력법 + 통역 + 도량·값 환산의 종합 회관 |

## 개요
- [카이리제도](카이리제도/카이리제도.md)의 지명. 카이리 제도의 환산 장부 회관 [건물 / E5 원점]
- 성격** 력법 + 통역 + 도량·값 환산의 종합 회관
  - ① 력법 환산 — 장주기력([카툰야](카툰야/카툰야.md))·순환력([테노치아](테노치아/테노치아.md)·[테스카론](테스카론/테스카론.md))·태양 관측력([인티마라](인티마라/인티마라.md))
    - + 계절·구전까지 나란히 놓고 옮겨 적음
    - → [신대륙](신대륙.md)에서 '같은 날'이 성립하는 유일한 장소 ('환산 장부' 문화의 실체)
  - ② 통역·중개 — 카이리어(대륙 간 중개 공용어. )가 만들어지고 가르쳐지는 곳
  - ③ 도량·값 환산 — 금·소금·마정석·곡물의 문명별 환산 실무
