# 일세린

**Ilserin**

| | |
|---|---|
| **소속** | 일바렌 |
| **대륙** | 신대륙 |
| **유형** | 성지·종교시설 |
| **성격** | 일상 참례형 성림 (의례일 한정 개방 아님) |

## 개요
- [일바렌](일바렌/일바렌.md)의 지명. 일바 밑동의 성림 [성소]
- 성격** 일상 참례형 성림 (의례일 한정 개방 아님)

## 정치적 무게
- 구조 — [아엘리온](아엘리온.md) 씨앗 A의 계측 지점
  - 법칙: [신성력](../01_세계관_코어/신성력.md)은 믿는 자가 많은 환경에서 잘 발현됨
    - → 일세린에 모이는 사람 수가 곧 왕의 가호 세기와 연동
  - 왕이 실리로 교역의 문을 넓히면 백성은 바깥일에 바빠져 참례가 줄고,
    - 그 결과가 왕 자신의 몸에서 힘이 빠지는 형태로 돌아옴
  - 외부인 허용의 이중 효과: 성림에 사람은 늘되 믿지 않는 자들이 서게 됨
    - → 머릿수는 늘고 믿음의 밀도는 묽어짐. 왕은 "숲이 붐비는데 어찌 힘이 주는가"를 풀지 못함
  - 아엘리온은 원인을 알 수 없음 → 힘이 옅어지는 것을 세계수가 시드는 탓으로 해석하게 됨
    - (아무 힘도 없는 나무를 붙들고 원인을 묻는 왕 — 답은 나무가 아니라 텅 비어 가는 빈자리에 있음) 씨앗 D 종착: [벤도르](벤도르.md)발 소문이 상인들의 입을 타고 성림 안까지 흘러듦
