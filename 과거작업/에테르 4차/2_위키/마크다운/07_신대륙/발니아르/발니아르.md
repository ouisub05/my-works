# 발니아르
> 발니아르 (Valniar) — 거목 숲의 엘프 과두정 (캘리포니아 북부 해안, SF~레드우드 대응)

**Valniar**

| | |
|---|---|
| **위치** | 신대륙 · 레드우드 대응 |
| **정치체제** | 엘프가 지도자인 과두정 |
| **인구** | 약 45만 |
| **종족 구성** | 수인 48 / 엘프 45 / 인간 6 / 기타 1 |
| **종교** | 거목 신앙 (일바렌의 세계수 신앙과 다른 독자 계열) |
| **경제** | 풍요로운 수렵채집 (도토리·연어 평행 — 농경 없이도 부유) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 정치
- 정치** [엘프](../../02_종족/엘프.md)가 지도자인 과두정

## 경제
- 경제 기반** 풍요로운 수렵채집 (도토리·연어 평행 — 농경 없이도 부유)
- 대외 성향** 개방적 (이웃과 교역)

## 사회
- 중심지** 발로라 (Valora) — 거목 사이의 평의 숲

## 종족 구성
- 종족** 엘프+[수인](../../02_종족/수인.md) 혼합 (역할 유동적, 지도층만 엘프)

## 종교
- 종교** 거목 신앙 ([일바렌](../일바렌/일바렌.md)의 세계수 신앙과 다른 독자 계열)
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 수호·결계 가호 (숲의 보호)

## 대외 인식
- 대외 인지** 접경 이웃만 인지

## 법의 세 줄과 승계
- 법의 꼭대기 — 국가법
- 조문에 종족 — 예 (조문에 기입)
- 조문에 성별 — 아니오
- 승계 — 작위 없음 (과두정)
- 비고
  - 역할이 유동적이어도 지도층이 엘프로 닫혀 있으므로 조문에 적는다
  - → 조문에 종족이 적히는 기준은 역할 분담이 아니라 자리의 잠금 여부다
  - 과두정이므로 작위는 없다. 다만 신분은 있다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
