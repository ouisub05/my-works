# 테노치아
> 테노치아 (Tenochia) — 호수 삼국 동맹 (아즈텍 대응)

**Tenochia**

| | |
|---|---|
| **위치** | 신대륙 · 아즈텍 대응 |
| **정치체제** | 호수 도시 중심의 삼국 동맹 |
| **국가원수** | 시우코 |
| **인구** | 약 400만 |
| **종족 구성** | 수인 52 / 인간 44 / 엘프 1 / 하플링 1 / 노움 1 / 오크 1 |
| **종교** | 태양 신앙 (파차라 인티마라의 태양 신앙과는 별개의 독자 발생) |
| **경제** | 수상 농법 + 정복지 공물 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 정치
- 정치** 호수 도시 중심의 삼국 동맹

## 국가원수
_(내용 없음)_

## 경제
- 경제 기반** 수상 농법 + 정복지 공물

## 사회
- 본거지** 메츠야 호 (Metzya, '달의 호수')
- 힘의 원천** 군사력 + 호수 도시의 방어력

## 종족 구성
- 종족** [수인](../../02_종족/수인.md)+[인간](../../02_종족/인간.md) — [카툰야](../카툰야/카툰야.md)에서 벗어난 인간들이 합류
  - 역할 유동적 (전공 따라) — 카툰야의 '인간=고정 하층'과 대비되는 기회의 땅

## 종교
- 종교** 태양 신앙 (파차라 [인티마라](../인티마라/인티마라.md)의 태양 신앙과는 별개의 독자 발생)
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 활력·불굴 가호 (태양의 힘)

## 외교
- 동맹명 유래** 맹주 도시 테노치(Tenoch)에서. 세 도시 = 테노치/테츠쿠아/틀라코야

## 대외 인식
- 대외 인지** 카툰야와 유사 (북미 남부~남미 북부) + [카이리제도](../카이리제도/카이리제도.md)
