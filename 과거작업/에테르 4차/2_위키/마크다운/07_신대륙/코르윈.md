# 코르윈
> 코르윈 (Korwin) — 넬바라의 구리 광산 마을

**Korwin**

| | |
|---|---|
| **소속** | 넬바라 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |
| **성격** | 드워프 운영형 — 두르가른 출신 이주·영입 드워프(분포표 드워프 7)가 |

## 개요
- [넬바라](넬바라/넬바라.md)의 지명. 넬바라의 구리 광산 마을
- 성격** [드워프](../02_종족/드워프.md) 운영형 — 두르가른 출신 이주·영입 드워프(분포표 드워프 7)가
  - 흩어져 살지 않고 이곳에 몰려 삶
- 산출** 구리 (마정석 아님 — [신대륙](신대륙.md) 최대 마정석 산지는 [스카르둔](스카르둔.md)으로 기존 설정, 그 자리를 흐리지 않음)

## 정치적 무게
- 구조
  - 넬바라의 광산은 남의 손으로 굴러가는 산업
  - [테스카론](테스카론/테스카론.md) 조공의 상당분이 이 구리 → 넬바라의 순응은 드워프의 노동을 팔아 사는 평화
    - → 불만의 실제 주체가 자국민이 아니라 이주민이라는 뒤틀림

## 갈등과 불씨
- 씨앗** 드워프가 돌아가버리는 날 —
  - 광산이 멈추면 조공 품목이 비고 종주 관계가 흔들림.
  - 종속국이 종주에게 내밀 수 있는 유일한 지렛대가 정작 자국민이 아닌 손님인 구조
