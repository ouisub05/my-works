# 헤르바나
> 헤르바나 (Hervana) — 초원 유목 연합체 (대평원 대응)

**Hervana**

| | |
|---|---|
| **위치** | 신대륙 · 대평원 대응 |
| **정치체제** | 유목 연합체 (테우엘라 유사) |

- 경제 기반** 여러 종류의 유목·목축

## 종족 구성
- 종족** [수인](../../02_종족/수인.md)+[오크](../../02_종족/오크.md) 중심
- 종족 역할** 유동적

## 종교
- 종교** 자연·정령 신앙
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 시야·추적 가호 (평원의 눈)

## 외교
- vs [조르가트](../조르가트/조르가트.md)** 약탈 표적 (테우엘라와 같은 처지)
  - ※ 조르가트는 남([테노치아](../테노치아/테노치아.md)·[카툰야](../카툰야/카툰야.md))·동([테스카론](../테스카론/테스카론.md))·북(헤르바나)을 전방위로 약탈
