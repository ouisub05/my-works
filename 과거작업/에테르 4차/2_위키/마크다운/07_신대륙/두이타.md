# 두이타
> 두이타 (Duita) — 지파라 서쪽 산맥의 드워프 금광 도시

**Duita**

| | |
|---|---|
| **소속** | 지파라 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |
| **성격** | 드워프 채굴 + 바카타 세공의 분업 구조 |

## 개요
- [지파라](지파라/지파라.md)의 지명. 지파라 서쪽 산맥의 드워프 금광 도시
- 성격** [드워프](../02_종족/드워프.md) 채굴 + 바카타 세공의 분업 구조

## 이름의 유래
- 대구** [인티마라](인티마라/인티마라.md)는 국부를 사제단([안다마르카](안다마르카.md))에게 맡기고,
  - 지파라는 드워프(두이타)에게 맡김 — 앞은 신앙이 식으면 무너지고 뒤는 곡괭이가 멈추면 무너짐

## 정치적 무게
- 구조적 의미** [티스케](티스케.md)는 금을 '가진' 왕이 아니라 금이 지나가는 길목을 쥔 왕
  - 산에서 캔 것이 왕도로 흘러야만 부가 됨 → 확장가형 왕의 밑천이 남의 곡괭이에 달림
  - 기존 설정 "역할 분담 + 평등 공존"과 정합: 드워프는 예속민이 아니라 연합 왕권의 지분자
    - → 지파라 안에서 유일하게 왕이 함부로 못 하는 땅
