# 우루비
> 우루비 (Urubi) — 파라나수 강의 지류 분기 관문 [야쿠아라]

**Urubi**

| | |
|---|---|
| **소속** | 야쿠아라 |
| **대륙** | 신대륙 |
| **유형** | 자연지형 |
| **성격** | 지류 분기 수로 관문 + 공물 집산지 겸임 |

## 개요
- [야쿠아라](야쿠아라/야쿠아라.md)의 지명. 파라나수 강의 지류 분기 관문 [야쿠아라]
- 성격** 지류 분기 수로 관문 + 공물 집산지 겸임
  - 밀림에는 길이 없음 — 이 나라의 도로는 강. 통치란 곧 '어느 지류까지 배가 올라가느냐'
  - 여기까지는 마나우아의 명령이 하루면 닿으나, 지류로 들면 며칠씩 멀어짐
    - → 기존 설정 "너무 넓어 변경 관리가 안 됨"이 감상이 아니라 지리적 사실로
  - → [카우아리](카우아리.md)의 통치가 팽창일 수밖에 없는 이유: 쥔 것이 물줄기뿐이라
    - 통치를 넓히려면 더 멀리 노를 저어야 함 (지도가 넓어질수록 손아귀는 얇아짐)

## 정치적 무게
- 잠식 은폐 구조** [지파라](지파라/지파라.md)에게 뜯긴 부족의 공물이 안 들어와도
  - 장부에는 '지류라 늦는 것'으로 기록됨 → 영토 상실이 지연으로 기록되는 나라
    - 누군가 몇 년치 장부를 나란히 놓고 세어 보는 순간
  - 대구: [조르가트](조르가트/조르가트.md)는 장부([모르칸](모르칸.md))가 왕을 흔들고, 야쿠아라는 장부를 보는 자가 없어 나라를 잃음
