# 틀락사르
> 틀락사르 (Tlaxar) — 카툰야-테노치아 전선의 격전지 [E3]

**Tlaxar**

| | |
|---|---|
| **소속** | 카툰야 |
| **대륙** | 신대륙 |
| **유형** | 요새·군사시설 |
| **성격** | 국경 요새 도시 |

## 개요
- [카툰야](카툰야/카툰야.md)의 지명. 카툰야-[테노치아](테노치아/테노치아.md) 전선의 격전지 [E3]
- 성격** 국경 요새 도시

## 이름의 유래
- 이름이 테노치아풍 → 테노치아가 지키는 요새이며, 밀리는 쪽의 방벽
  - 카툰야 우세와 정합
  - 틀라코야 왕 [시우코](시우코.md)의 "[조르가트](조르가트/조르가트.md)를 달래고 카툰야에 집중" 구상 =
    - 실질적으로 틀락사르를 지키겠다는 뜻
