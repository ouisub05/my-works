# 마쿠안
> 테스카론 신왕

**Makuan**

| | |
|---|---|
| **소속** | 테스카론 |
| **대륙** | 신대륙 |
| **지위** | 오만한 전성기 군주 — 의심을 모르는 절대자 |
| **능력** | 가호 없음 — 가호는 사제단(엘프)이 대행 (증거가 남의 손에) |

## 개요
- [테스카론](테스카론/테스카론.md)의 테스카론 신왕.
- 이름** 마쿠안 (Makuan)
- 유형** 오만한 전성기 군주 — 의심을 모르는 절대자

## 성격
- 자기 인식** 진심으로 자신을 신의 화신이라 믿음
  - (F2 연동: '테스카론 신왕=신의 화신'은 솔교 '빛의 화신' 이사리우스와 구조 평행 —
  - 폭로 시 연쇄 붕괴 후보 중 하나)

## 능력
- 능력** 가호 없음 — 가호는 사제단([엘프](../02_종족/엘프.md))이 대행 (증거가 남의 손에)

## 주변 인물
_(내용 없음)_

## 갈등과 불씨
- 약점·이야기 씨앗
  - **1)** 사제단이 손을 거두는 날 — 가호 대행 구조의 약점
    - ([이스켈](이스켈.md)이 침묵을 깨거나 거두는 순간, 신왕의 신성은 공중에 뜸)
