# 카이리 제도
> 카이리 제도 (Kairi) — 해상 교역 연맹 (카리브 대응)

**Kairi**

| | |
|---|---|
| **위치** | 신대륙 · 카리브 대응 |
| **정치체제** | 해상 교역 연맹 (섬들이 느슨히 연결. 통일 권력 없음) |
| **인구** | 약 80만 |
| **종족 구성** | 수인 52 / 인간 43 / 엘프 2 / 하플링 1 / 노움 1 / 오크 1 |
| **종교** | 바다·항해 신앙 |
| **경제** | 과나바 (Guanaba) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [신대륙](../신대륙.md)에 속한 세력.

## 정치
- 정치** 해상 교역 연맹 (섬들이 느슨히 연결. 통일 권력 없음)

## 경제
- 최대 교역 섬** 과나바 (Guanaba)
- 경제 기반** 중개 교역 전문 (생산은 부차적)
  - 대륙 문명들([지파라](../지파라/지파라.md)·[테노치아](../테노치아/테노치아.md) 등)을 잇는 중개자. "황금의 나라" 소문의 발원지

## 사회
- [마리스텔라](../../03_아우로라/마리스텔라/마리스텔라.md) 접촉
  - 접촉 소식을 주변 국가들에 전함 — [벨사르](../벨사르/벨사르.md)(북미 동부) + 지파라
    - → 구대륙에서는 완벽한 비밀이지만, 신대륙에서는 이미 소문이 새는 중
  - 마리스텔라에 대한 태도: 섬마다 갈림 (느슨한 연맹이라 통일된 입장 없음)

## 종족 구성
- 종족** [수인](../../02_종족/수인.md)+[인간](../../02_종족/인간.md) 혼합

## 종교
- 종교** 바다·항해 신앙
  - [신성력](../../01_세계관_코어/신성력.md) 가호 형태: 항해·물길 가호

## 주요 지명과 시설
_(내용 없음)_

## 법의 세 줄과 승계
- 법의 꼭대기 — 연맹 규약
- 조문에 종족 — 아니오
- 조문에 성별 — 아니오
- 승계 — 세습 아님 (섬별 · 연맹)
- 비고
  - 규약국끼리는 명분의 언어가 통한다. 마리스텔라가 첫 접촉한 곳이 이곳이라는 확정이 여기서 값을 한다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
