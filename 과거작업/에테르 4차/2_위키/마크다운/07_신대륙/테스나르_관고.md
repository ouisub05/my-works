# 테스나르 관고
> 테스나르 관고 (Tesnar) — 넬윈 안의 테스카론 조공 접수 시설 [건물]

**Tesnar**

| | |
|---|---|
| **소속** | 테스카론 |
| **대륙** | 신대륙 |
| **유형** | 요새·군사시설 |

## 개요
- [테스카론](테스카론/테스카론.md)의 지명. 넬윈 안의 테스카론 조공 접수 시설 [건물]
- 자리** 넬윈 시가 한복판 (국경 밖 집하장 아님)

## 군사
- 수비** 테스카론이 보낸 상주 수비병 있음
  - → 무방비한 창고가 '오만'이라면, 병사가 선 창고는 축소판 점령
  - 넬윈 주민은 제 도시 한복판에서 매일 외국 군복을 보며 삶
    - → 기존 설정 "불만은 있으나 이득에 순응"이 계산이면서 동시에 눈에 보이는 굴욕이 됨
- 연동** [코르윈](코르윈.md)의 구리가 흘러드는 종착점.
  - 구리가 끊기는 날 가장 먼저 피가 나는 자리는 국경이 아니라 이 시가지
  - (병사와 주민의 사소한 마찰 하나가 종속 관계 전체를 건드리는 뇌관)
