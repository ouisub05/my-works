| | |
|---|---|
| **지구 대응** | 아메리카 대응 |
| **세력 수** | 24 |
| **인구** | 약 2,938만 |

## 개요
- 아메리카 대응 대륙. 등재 세력 24.
  - 11. 신대륙 (아메리카 대응)
  - 종족 재설정(7종 체제) 일괄 반영
- 기본 종족 7종** [인간](../02_종족/인간.md)/[수인](../02_종족/수인.md)/[하플링](../02_종족/하플링.md)/[노움](../02_종족/노움.md)/[드워프](../02_종족/드워프.md)/[엘프](../02_종족/엘프.md)/[오크](../02_종족/오크.md) + [용족](../02_종족/용족.md)·[혼혈](../02_종족/혼혈.md)(하프엘프·드라킨)
- 전 세계 공통** 농촌·도시에 하플링 혼재(도시는 길드에 다수) / 도시에 노움 소수 혼재(마공학) /
  - 도시에 오크 전사·용병 소수 (단 북방·툰드라권 — [노르가르드](../03_아우로라/노르가르드/노르가르드.md)권·에조라·신대륙 북방 — 은 오크 다수)
- 다크엘프 = 엘프의 [갈래](../01_세계관_코어/갈래.md)
- 개별 서술과 구성표가 어긋날 때는 개별 서술을 따름
  - ※ 구대륙에서는 [마리스텔라](../03_아우로라/마리스텔라/마리스텔라.md)의 극소수만 존재를 앎 (최대 비밀)
  - ※ 확정 국명 사용. 괄호는 지구 대응(대조용)

## 대륙 공통
- 종족** 구대륙과 같은 종족 (7종 체제 동일: 인간·수인·하플링·노움·드워프·엘프·오크 + 용족)
  - 독자 발생이 아니라 '아주 먼 옛날 같은 조상'에서 갈라진 것 → (떡밥 여지) 먼 옛날 두 대륙이 이어졌거나 왕래가 있었을 가능성. 06에 메모
  - 오크: 신대륙 북방([헤르바나](헤르바나/헤르바나.md)·[조르가트](조르가트/조르가트.md)권 등)은 오크 다수 지대
- 종교** 구대륙(솔교·알 딘)과 무관한 독자 신앙들
- 발전 수준** 지역·문명마다 갈림 (대등/약세/추월이 섞임)
- 구성** 여러 문명 (하나의 대문명으로 뭉뚱그리지 않음)
- 지리 전제** 안타라(안데스)·스카르드(로키) 대응 산맥 → 마정석 농도 극히 높음
  - 마리스텔라가 [카이리제도](카이리제도/카이리제도.md)(카리브 대응) 주민과 첫 접촉, 북미·남미 대응에 다수 문명 소문

## 파차라(남미) 관계망
- [야쿠아라](야쿠아라/야쿠아라.md) → [인티마라](인티마라/인티마라.md) 압박 원인** 영토 팽창
- [지파라](지파라/지파라.md) → 인티마라 압박 원인** 교역로 차단
- 야쿠아라 ↔ 지파라** 지파라가 야쿠아라 영토를 은근슬쩍 잠식 중
  - 야쿠아라가 너무 넓어 변경 관리가 안 됨 → 야쿠아라 제국에 속한 줄도 몰랐던 변방 부족들을 지파라가 복속 중
- [차쿠아](차쿠아/차쿠아.md) ↔ 인티마라** 인티마라의 정복 시도를 격퇴한 적대 관계
- 차쿠아 ↔ 지파라** 교역 불가 (야쿠아라 제국의 팽창이 사이를 가로막음)
- [아라우카](아라우카/아라우카.md) → 인티마라** 종속(조공) 관계이나 반발 중. 무장 봉기 준비 단계
- 아라우카 → [테우엘라](테우엘라/테우엘라.md)** 봉기 준비 물자 확보를 위해 잦은 약탈
- 야쿠아라 → [이타마라](이타마라/이타마라.md)** 화전 농경에 대한 외교적 항의 (신생 제국이라 거침없음)

## 중미 전쟁
- 구도** [카툰야](카툰야/카툰야.md) 동맹 vs [테노치아](테노치아/테노치아.md) 삼국 동맹. 수년째 진행 중
- 원인** 영토 + 카툰야 이탈 인간들을 둘러싼 갈등
  - (카툰야에서 하층이던 인간들이 테노치아로 흘러듦 → 종족 갈등의 결)
- 전황** 카툰야 동맹 우세
  - 테노치아는 북쪽의 조르가트(텍사스 대응)에게서도 추가 공격을 받는 중 → 양면 전쟁
  - 텍사스 대응 세력의 정체: 조르가트로 (영토 확장 겸 약탈)

## 노르카엔(북미)
  - ※ 알래스카·아북극 등 용족 서식지: 모든 대륙의 국가 설정이 어느 정도 끝난 뒤 설정

## 북미 관계망
- 조르가트 → 테노치아** 영토 확장 겸 약탈 (중미 전쟁의 북쪽 축)
- 조르가트 → 카툰야** 계속 정복·약탈할 예정 (남방 전체가 표적)
- 조르가트 → [테스카론](테스카론/테스카론.md)** 거리가 있는데도 가끔 약탈 (제국엔 성가신 존재 수준)
- 조르가트 → 헤르바나** 약탈 표적
- 테스카론 → [넬바라](넬바라/넬바라.md)** 조공·종속 (넬바라는 불만 있으나 이득 때문에 순응)
- [셀루아](셀루아/셀루아.md)** 이웃들과 대체로 평화적 교역
- 셀루아 ↔ 넬바라** 물 신앙 같은 계열 (정화·치유 가호 공유권)
- 두르가른 ↔ 도르베나** 연합 (두르가른이 뚫은 통로로 도르베나가 산맥 왕래, 광물 교역)
- 두르가른 → 넬바라** 드워프 이주·영입의 출신지
- [벨사르](벨사르/벨사르.md) ↔ 카이리 제도** 중개 교역 + 마리스텔라 소식 수신 (경계 중)
- [발니아르](발니아르/발니아르.md) ↔ [케다른](케다른/케다른.md)** 목재·어장 자원 경쟁 (긴장)
- [일바렌](일바렌/일바렌.md)** 은둔이나 소규모 교역 허용
- 남미(파차라)·중미·카이리·북미** 설계·작명·주요 도시 완료
- 규칙** 대륙 소속이 애매한 권역(중미, 구대륙의 [미세아](../03_아우로라/미세아/미세아.md) 등)은 소속을 정하지 않는다
- 용족 서식지(알래스카·아북극 포함)는 모든 대륙의 국가** 용족 서식지(알래스카·아북극 포함)는 모든 대륙의 국가 설정이 어느 정도 끝난 뒤 설정
- ※ 발전 수준(추월/대등/약세) 항목은 문서에서 삭제함.
  - 사용자가 자발적으로 지정한 것만 기록 (예: 차쿠아=약세, 인티마라=도로 기술 추월).
  - 어시스턴트가 발전 수준을 먼저 질문하는 것 금지
- 차쿠아 회합지 — 테콰라(Tekuara)로. 그 외 잔여 소지명은 필요 시
