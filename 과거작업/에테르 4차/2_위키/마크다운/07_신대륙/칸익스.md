# 칸익스
> 칸익스 (Kanix) — 치첸야의 천문 관측 신전 [건물]

**Kanix**

| | |
|---|---|
| **소속** | 카툰야 |
| **대륙** | 신대륙 |
| **유형** | 성지·종교시설 |
| **성격** | 역법 관리 + 전쟁 자문 겸임 |

## 개요
- [카툰야](카툰야/카툰야.md)의 지명. 치첸야의 천문 관측 신전 [건물]
- 성격** 역법 관리 + 전쟁 자문 겸임
  - ① 역법 관리 — 장주기력(20년 단위 '카툰', [신대륙](신대륙.md) 최정밀 력법. ) 관리.
    - 국명의 어원이 여기서 나옴 → 시간을 세는 권한이 곧 권력
    - ([케메트](../05_아자니아/케메트/케메트.md) 신관단의 범람 예측형 신정 권력과 같은 계열의 사례)
  - ② 전쟁 자문 — 예지·점성 가호의 본산. 전시에는 작전 자문 기구
  - ③ [엘프](../02_종족/엘프.md) 사제·학자 계층의 심장 — [이츠칸](이츠칸.md)이 자란 곳

## 군사
- 입장** 이츠칸 편 (하늘이 강경 노선을 받침)
  - → 도시 왕들의 회의가 전후를 계산해도 별과 논쟁해야 함.
    - 계산으로 신성을 반박해야 하니 사실상 이길 수 없는 싸움 → 이츠칸 씨앗 1이 최악의 형태로 완성: 그는 욕망을 하늘의 뜻으로 '포장하는' 자가 아니라
    - 하늘의 뜻이 실제로 자기 욕망과 같은 말을 하는 자.
    - 본인도 바깥도 구분 불가 → 전쟁을 멈추려면 별이 틀렸음이 드러나는 사건이 필요
  - 법칙 연동: 예지·점성 가호는 실재하므로 관측도 진짜.
    - 다만 힘의 출처는 하늘이 아니라 믿는 사람들 자신 —
    - 카툰야는 제 믿음이 만든 힘으로 제 전쟁을 정당화하는 중 (떡밥 1 보강)
