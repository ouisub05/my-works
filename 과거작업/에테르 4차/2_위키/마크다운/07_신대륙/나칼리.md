# 나칼리
> 나칼리 (Nakali) — 콘벨트 대응 곡창 관구 [테스카론]

**Nakali**

| | |
|---|---|
| **소속** | 테스카론 |
| **대륙** | 신대륙 |
| **유형** | 산업·자원지 |
| **성격** | 풍작 가호 시연형 |

## 개요
- [테스카론](테스카론/테스카론.md)의 지명. 콘벨트 대응 곡창 관구 [테스카론]
- 성격** 풍작 가호 시연형
  - 교리 "왕 = 신의 화신"의 증거는 풍작 → 신왕이 해마다 이 관구에 가호를 내리고,
    - 그 해의 수확이 곧 왕의 신성 성적표가 됨

## 갈등과 불씨
- 떡밥 1 보강** 이 땅은 원래 고농도 [에테르](../01_세계관_코어/에테르.md) 평원이라 가호가 없어도 풍요로움
  - → 신왕이 내리는 은혜와 땅이 본래 가진 힘이 구분 불가능
  - [냐사연맹](../05_아자니아/냐사연맹/냐사연맹.md)(풍요가 신 덕인지 땅 덕인지 모름)에 이은 두 번째 사례이자 대구:
    - 냐사는 아무도 왕이 아닌 곳에서 생긴 의문 / 테스카론은
    - 한 사람이 그 풍요를 제 것이라 주장하는 곳에서 생기는 의문
- [마쿠안](마쿠안.md) 씨앗 1의 최종 형태** 이 제국의 신성은 이중으로 빌린 것 —
  - 왕은 가호가 없어 사제단([이스켈](이스켈.md))에게 빌리고, 사제단은 사실 땅에게 빌리고 있음
  - → 이스켈이 침묵을 깨거나 손을 거두어도 나칼리는 여전히 풍년일 것
    - = 신성이 벗겨지는 방식은 흉작이 아니라 아무 일도 일어나지 않는 것
