# 네게스타
> 네게스타 (Negesta, '왕의 것') — 악수미아 시조 솔로몬 전승의 성소 (고원)

| | |
|---|---|
| **소속** | 악수미아 |
| **대륙** | 아자니아 |
| **유형** | 성지·종교시설 |

## 개요
- [악수미아](악수미아/악수미아.md)의 지명. 악수미아 시조 솔로몬 전승의 성소 (고원)

## 갈등과 불씨
- 파생
  - 악수미아 왕조는 '아무도 확인하지 못하는 것' 위에 세워진 나라 —
    - 사제단은 그것을 지키는 것만으로 왕권 위에 손을 얹을 수 있음 [에자나르](에자나르.md) 씨앗 1)(고원 사제단과의 긴장)의 물리적 근거지 —
    - 무게중심을 바다로 옮기려 할수록 '고원에 있는 것'이 왕을 붙들어 맴
  - 악수미아 ↔ [솔라티움](../03_아우로라/솔라티움/솔라티움.md) 접점(시조 솔로몬 전승)이 구체적 물건을 갖게 됨
    - → 훗날 솔교 학자가 그것을 보겠다고 나서는 사건의 자리 떡밥 1 연동 여지: 검증 불가능한 성물이 왕조 정통성을 떠받치는 구조
