# 바가모예
> 바가모예 (Bagamoye, '짐을 내려놓는 곳') — 키탐바의 인도양 해안 항구

| | |
|---|---|
| **소속** | 냐사 연맹 |
| **대륙** | 아자니아 |
| **유형** | 항구 |

## 개요
- [냐사연맹](냐사연맹/냐사연맹.md)의 지명. 키탐바의 인도양 해안 항구

## 갈등과 불씨
- 파생
  - 인도양 축 변경: 기존 킬레마 → (육로) → [바하르](바하르.md) → [나가팟](../06_수리아/나가팟.md) 라인에 더해,
    - 킬레마 → 바가모예 → 바다 라인이 새로 생김 = 바하르를 거치지 않는 우회로
  - [악수미아](악수미아/악수미아.md) 압박: [에자나르](에자나르.md)의 '바다로' 노선과 정면으로 겹침.
    - [자레마](자레마.md)가 관계로만 유지 중인 바하르 균형에 가격 경쟁이라는 변수 추가
    - (자레마 씨앗 D — 인도양 마찰이 책상 위로 — 의 구체적 촉발원) [나스타카](나스타카.md) 씨앗 B(악수미아 상권 편입)와 정반대 방향의 힘 —
    - [쿠쉬](쿠쉬/쿠쉬.md)는 빨려 들어가고, 키탐바는 빠져나가는 중
  - 키탐바의 연맹 내 위상 상승: '심장이자 관문'이 바다까지 쥠

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 신전** 알 딘(북에서 흘러옴) + 토착 호수 신의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
