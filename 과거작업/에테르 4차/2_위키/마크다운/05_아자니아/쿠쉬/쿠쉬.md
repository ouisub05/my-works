# 쿠쉬
> 쿠쉬 (Kush) — 누비아 대응, 나일 상류 고대 교역 왕국

**Kush**

| | |
|---|---|
| **위치** | 아자니아 · 누비아 대응 |
| **수도** | 타르마 |
| **국가원수** | 나스타카 |
| **인구** | 약 150만 |
| **종족 구성** | 인간 52 / 수인 41 / 하플링 4 / 노움 1 / 엘프 1 / 오크 1 |
| **종교** | 알 딘 수용 (이집트와 달리) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아자니아](../아자니아.md)에 속한 세력. 이집트 바로 남쪽(수단 대응)의 유서 깊은 나일 문명. 나일 상류~홍해를 잇는 고대 교역 왕국
- 정체성** 이집트 바로 남쪽(수단 대응)의 유서 깊은 나일 문명. 나일 상류~홍해를 잇는 고대 교역 왕국

## 지리
- 지리** [악수미아](../악수미아/악수미아.md)와 매우 가까움. 홍해 건너편이 아니라
  - 강을 조금만 거슬러 오르면 닿는 사실상의 이웃
  - → 쿠쉬에게 악수미아는 '먼 곳의 원군'이 아니라 물자·사람이 실제로 오가는 옆집

## 종족 구성
- 종족** [인간](../../02_종족/인간.md) 다수 + [수인](../../02_종족/수인.md) 공존

## 종교
- 종교** 알 딘 수용 (이집트와 달리)
  - → 이집트의 '부정한 것 정화' 약탈에 종교적 색채가 덧입혀짐
    - (이집트에겐 알 딘 믿는 누비아가 부정·이질의 대상 / 누비아에겐 신앙 다른 이교 제국에게 시달리는 것)

## 외교
- 이집트와의 관계
  - 대등한 교역 상대 → 피해자 → 대등한 맞수(옛엔 이집트를 정복하기도, 쿠시 제25왕조 평행) → 현재 다시 피해자
  - 지금은 쇠퇴기 — 이집트의 약탈·정화 원정에 시달리는 중. 옛 영광을 아는 만큼 굴욕이 쓰라림
