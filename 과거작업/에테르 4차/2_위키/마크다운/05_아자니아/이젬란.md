# 이젬란
> 티네리 좌장

**Izemran**

| | |
|---|---|
| **소속** | 티네리 |
| **대륙** | 아자니아 |
| **종족** | 사막여우 계열 수인 |
| **능력** | 가호 없음 (감응 체질 아님) |

## 개요
- [티네리](티네리/티네리.md)의 티네리 좌장.
- 이름** 이젬란 (Izemran) — 베르베르어 '이젬(izem, 사자)' 계열 창작
- 종족** 사막여우 계열 [수인](../02_종족/수인.md)

## 생애
- 위치** 원로 회의의 좌장 (연맹 중재자) — 좌장을 맡은 지 얼마 안 된 장년

## 성격
- 성격** 온화한 화합형 — 설득과 인덕으로 독립적인 부족들을 묶는 어른

## 능력
- 능력** 가호 없음 (감응 체질 아님)

## 주변 인물
- 주변 인물** 없음 — 단독 설계

## 갈등과 불씨
- 약점·이야기 씨앗
  - **1)** [케메트](케메트/케메트.md) 방면 위협 재발 우려: 과거 침략('약탈 원정+정화')의 기억 위에 선 연맹.
    - 케메트가 다시 움직이는 날, 신임 좌장의 화합력이 시험대에 오름
