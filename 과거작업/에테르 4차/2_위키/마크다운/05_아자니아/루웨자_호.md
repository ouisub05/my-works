# 루웨자 호
> 루웨자 호 (Ruweza) — 말라위호 대응 대호수

**Ruweza**

| | |
|---|---|
| **소속** | 말라니 |
| **대륙** | 아자니아 |
| **유형** | 자연지형 |
| **성격** | 어장·생계 기반 — 말라니에게 호수는 길이기 전에 밥줄 |

## 개요
- 말라니의 지명. 말라위호 대응 대호수
- 명명. 국명 [말라니](말라니/말라니.md)와 별개의 고유 호수명 ([냐사연맹](냐사연맹/냐사연맹.md) ↔ [무완자 호](무완자_호.md) 전례와 동일
- 성격** 어장·생계 기반 — 말라니에게 호수는 길이기 전에 밥줄
  - 기존 '물길의 중개상' 서술과 병존하되, 호수 자체가 갖는 첫째 의미는 자급 식량

## 갈등과 불씨
- 파생
  - 말라니는 작은 소국들이면서 식량을 스스로 대는 지대 —
    - 교역이 끊겨도 굶지 않으나, 남을 굶길 지렛대도 없음
  - C1로 남방 교역망이 재편되면 말라니는 가난해질 뿐 무너지지는 않는 구조
