# 티네리
> 티네리 (Tineri) — 알제리·사하라 대응, 사막 수인 부족연합

**Tineri**

| | |
|---|---|
| **위치** | 아자니아 · 알제리·사하라 대응 |
| **정치체제** | 느슨한 씨족 연맹 (평시엔 독립 부족, 큰일에만 원로 회의) |
| **국가원수** | 이젬란 |
| **인구** | 약 80만 |
| **종족 구성** | 수인 86 / 인간 11 / 하플링 1 / 엘프 1 / 노움 1 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아자니아](../아자니아.md)에 속한 세력. 사막·사바나의 유목 부족연합. 남북을 오가며 물자를 나르는 중계 상인
- 정체성** 사막·사바나의 유목 부족연합. 남북을 오가며 물자를 나르는 중계 상인
  - 아즈간(사하라) 대상 무역의 운송을 담당 (말리의 부 ↔ 지중해·[마리스텔라](../../03_아우로라/마리스텔라/마리스텔라.md)를 잇는 손발)
  - 종단로의 물자리 = 아그미르

## 역사
- 과거** 몇몇 부족이 약탈에 손댔다가 이집트에게 침략당함
  - 이집트의 '약탈 원정 + 부정한 것 정화' 방침의 표적이 됨

## 지리
- 현재** 이집트의 박해를 피해 윗 대륙([아우로라](../../03_아우로라/아우로라.md) 방면)으로 대거 진출 중
  - = 마리스텔라가 중개하는 '아프리카 [수인](../../02_종족/수인.md) 이주'의 출신지·이유가 바로 이곳
    - (마리스텔라·아우로라 각지의 수인 상당수가 이 사막 출신)
  - 대륙을 가로지르는 난민·이주의 물결 (10↔ 마리스텔라 설정 연결)

## 정치
- 정치** 느슨한 씨족 연맹 (평시엔 독립 부족, 큰일에만 원로 회의)
