# 냐사 연맹
> 냐사 연맹 (Nyanza) — 빅토리아호 대응 대호수 지대, 3왕국 혼인 동맹

**Nyanza**

| | |
|---|---|
| **위치** | 아자니아 · 빅토리아호 대응 |
| **왕도** | 무샤바 |
| **국가원수** | 하미시 (왕) |
| **정치체제** | 3개 왕국이 경쟁·협력하는 연맹. 지리·산업으로 색이 갈림 + 왕가들의  |
| **인구** | 약 500만 |
| **종교** | 알 딘(북에서 흘러옴) + 토착 호수 신앙 혼합 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아자니아](../아자니아.md)에 속한 세력.

## 정치
- 구성** 3개 왕국이 경쟁·협력하는 연맹. 지리·산업으로 색이 갈림 + 왕가들의 혼인 동맹으로 결속

## 사회
- 개요** 마정석([에테르](../../01_세계관_코어/에테르.md) 요지) + 비옥한 토지 + 큰 호수를 갖춘 풍요로운 대호수 지대
  - 아프리카에서 드물게 자원·농업이 모두 풍족한 축복받은 땅 (지구대 화산 활동 → 에테르 요지)
- 배치** 호수 기준 좌측 위 / 우측 아래 / 아래의 세 방향

## 종족 구성
- 종족** [인간](../../02_종족/인간.md)·[수인](../../02_종족/수인.md)·[엘프](../../02_종족/엘프.md) 공존. 호수 좌측(서안)에 수인·엘프가 더 많음

## 종교
- 종교** 알 딘(북에서 흘러옴) + 토착 호수 신앙 혼합
  - [연맹 1] 음바리 (Mbari) — 서안 왕국 (좌측 위)
  - 산업: 삼림 + 수상 교역 (호반 서쪽 숲의 임산물·약초 + 호수 뱃길 교역. 숲과 물을 함께 쥠)
  - 정치: 엘프·수인 이원 통치. 현재 왕은 엘프 (장수 엘프의 신중함 + 수인의 활력이 권력 분점)
  - 연맹 내 역할: 방패 (콩고 대밀림 왕국 대항 방향의 군사 담당)
  - vs 콩고 대밀림 왕국: '마물 유입에 따른 불신'
  - 콩고 밀림의 마물이 국경을 넘어와 서안을 위협 → 은둔한 밀림 왕국을 향한 불신으로 이어짐
  - "사냥을 제대로 안 해서 넘어오나 / 일부러 몰아내나" 같은 의심 (속을 알 수 없는 이웃)
  - 실제 충돌보다는 마물이라는 실질 피해에서 비롯된 심리적 경계
    - [연맹 2] 키탐바 (Kitamba) — 동안 왕국 (우측 아래)
  - 항구: [바가모예](../바가모예.md) (Bagamoye) — 동해안에 직접 낸 인도양 항구.
    - 키탐바 소유 + 연맹 통행권 → [바하르](../바하르.md)를 거치지 않는 바닷길 확보
  - 산업: 마정석 채굴 + 농업 + 에티오피아와 교역
  - 에티오피아 인도양 항구와 연결 → 연맹의 부(마정석·곡물)가 바닷길로 아시아·인도 대응까지 뻗음
  - 내륙 대호수의 물산이 바다에 닿는 교역 동맥 (동안이 그 출구)
  - 정치: 인간 주도 + 수인 공존 (서안의 엘프·수인 이원과 대비되는 인간 중심 정착 왕국)
  - 연맹 내 역할: 곳간(식량) + 지갑(마정석·교역의 부) + 외교(바깥 교섭)
  - = 연맹의 경제·대외 중심. 서안이 '방패'라면 동안은 '심장이자 관문'
    - [연맹 3] 루펨바 (Rufemba) — 남안 왕국 (아래)
  - 산업: 목축 + 마정석 가공 + 수공업
  - 동안(원석 채굴) ↔ 남안(가공)의 분업: 동안이 캔 마정석 원석 + 목축 산물(가죽·뿔·힘줄)
    - → 남안이 도구·무기·공예품·배로 가공 = 연맹의 생산 공방
  - 정치: 수인 주도 + 인간 공존 (서안=엘프·수인, 동안=인간과 또 다른 색)
  - 연맹 내 역할: 생산(병참) + 남방 관문
  - 남방 관문: 연맹 최남단에서 다른 아프리카 남부 세력(콩고 아래·말라위호·짐바브웨·최남단)과 잇는 창구
  - 연맹은 북문(동안→에티오피아→바다·아시아)과 남문(남안→아프리카 남부 내륙)을 각각 가짐
    - [루펨바 왕 캐릭터]
  - 이름: 무카밤바 (Mukambwa)
  - 종족·나이: 수인 / 40대 후반
  - 계열 = 코뿔소 — 먼저 덤비지 않으나 선을 넘으면 밀어버리는 결.
    - 물소 계열인 [카짐베](../카짐베.md)([줄라니](../줄라니/줄라니.md))와 겹치지 않게 배치
  - 배경: 남문을 지키던 전사 출신 왕
  - 루펨바 왕가 방계로 태어났으나 왕궁이 아니라 남방 관문 수비대에서 자라 지휘관까지 오름
    - → 혼인 동맹의 왕가 혈통 요건은 충족하되, 정치가 아니라 국경에서 만들어진 사람
  - 연맹 세 왕 중 유일하게 '바깥의 위험'을 몸으로 겪은 인물 —
    - 음바리가 마물이라는 보이지 않는 압박을 겪는다면, 그는 사람이 몰려오는 것을 눈으로 봄
  - 구조적 뒤틀림: 루펨바의 본업은 목축·마정석 가공, 즉 연맹의 살림을 대는 공방인데
    - 그 나라의 왕은 살림꾼이 아니라 창잡이 (키탐바가 연맹 회의에서 속을 태우는 이유)
    - [음바리 왕 캐릭터 + 냐사 호수 신앙 가호 ]
  - 이름: 시렌가 (Silenga)
  - 종족: 엘프 (음바리 이원 통치의 엘프 몫 대표)
  - 배경: 숲·약초 계통 출신 — 정령·신앙 쪽에서 올라온 왕
  - 서안 숲의 임산물·약초를 관장하던 계통 → 음바리는 곧 연맹 전체의 약재 곳간
  - 세계 규칙 연동: 치유 마법은 응급처치가 한계이고 진짜 기적은 교단 독점이므로,
    - 일상 의료는 약초·의술이 감당함 → 시렌가는 연맹의 목숨줄을 쥔 왕
    - ([카벤가](../카벤가.md) 씨앗 [B]무행동·[C]단일 창구의 음바리 쪽 반대편 얼굴)
  - 남안 무카밤바(문을 굳힐 뿐)와 대비: 같은 위협에 한쪽은 문을 닫고 한쪽은 사람을 보냄
  - 능력: 감응 체질 — 호수 신앙 가호 보유
  - 연맹 세 왕 중 유일하게 신성으로 서 있는 왕 (무카밤바=가호 없는 순수 무력과 정반대 축)
  - [음웰루](../음웰루/음웰루.md) 카벤가(정령술 상위·가호 평범)와 결 구분 — 두 엘프 왕이 겹치지 않도록 배치 약점·이야기 씨앗: 돌아오지 않는 사절
  - 교섭은 결렬조차 되지 않음 — 거절이 아니라 무응답이 돌아옴 (카벤가의 방침이 곧 침묵)
  - 사절이 빈손으로 오갈수록 국내 강경파(주로 수인 전사층)가 "말로는 안 된다"며 세를 얻음
    - → 음바리 이원 통치(엘프·수인 권력 분점)의 균열선이 바로 이 지점
  - 즉 시렌가의 온건 노선이 길어질수록 그 자신의 권력 기반이 깎이는 구조 —
    - 성과가 없으면 노선이 아니라 왕이 교체 압박을 받음
  - C4가 '실충돌 전 단계'에 머무는 이유이자, 그 단계가 끝나는 방아쇠
  - 연동: C4(음웰루-음바리 마물 불신) / [카살로](../카살로.md)·[쿠붐바](../쿠붐바/쿠붐바.md) / 냐사 혼인 동맹 / 신앙 지형
    - [냐사 토착 호수 신앙 — 가호 형태 ]
  - 신앙: 알 딘(북에서 흘러옴) + 토착 호수 신앙 혼합 중 토착 호수 신앙 쪽
  - 믿음의 내용: "호수가 우리를 먹여 살린다" → 가호 = 풍요·번성 가호
  - 어획·수확·가축의 번성에 작용하는 생산형 가호 ("가호는 믿음 내용을 따른다" 적용)
  - 기존 물 신앙들과 결 구분: [셀루아](../../07_신대륙/셀루아/셀루아.md)·[넬바라](../../07_신대륙/넬바라/넬바라.md)=치유 / [바하리아](../../06_수리아/바하리아/바하리아.md)=항해 / [히노와](../../06_수리아/히노와/히노와.md)=진재 /
    - [악수미아](../악수미아/악수미아.md)=수호·안정 → 냐사만 생산·풍요 계열 떡밥 보강 : 냐사는 지구대 화산 활동으로 인한 고농도 에테르 요지라
    - 가호가 없어도 원래 풍요로운 땅 → 이 땅의 풍요가 '신 덕인지 땅 덕인지' 아무도 구분 못 함
    - = [신성력](../../01_세계관_코어/신성력.md)의 진실(떡밥 1)에 붙는 새 사례
    - [키탐바 왕 캐릭터 / 냐사 3왕 완결]
  - 이름: [하미시](../하미시.md) (Hamisi)
  - 어감 계열 = 교역권(알 딘·인도양)풍 — 동안만 문화적으로 바깥 물이 들었다는 결이
    - 이름에서부터 드러남 (서안 시렌가=숲·정령풍과 대비)
  - 종족: 인간 (키탐바 인간 주도 구조와 정합)
  - 배경: 혼인 동맹의 산물 — 조정자형 / 루펨바(수인) 왕가 혈통
  - 어머니가 루펨바 왕가 출신 수인 → 하미시의 외가가 곧 무카밤바의 왕가
    - = 동안의 지갑과 남안의 창이 인척으로 묶임
  - [혼혈](../../02_종족/혼혈.md) 규칙 적용: 인간×수인 조합의 자식은 부모 중 한쪽 종족으로 랜덤 결정
    - → 하미시는 인간으로 태어났고, 형제 중에는 수인이 있음
    - (같은 배에서 나와 하나는 동안의 왕관을, 하나는 남안의 피붙이가 된 집안)
  - 성격·노선: 연맹 결속 우선 — 세 왕을 붙이는 중재자
  - 연맹 회의를 굴러가게 하는 실질적 축. 봉쇄론(무카밤바)·사절 비용(시렌가) 양쪽을
    - 조율하고 돈을 대는 자리
  - 단, 중재자가 남안 왕가의 피를 받은 자라 중립이 처음부터 반쯤 기울어 있음
  - 능력: 힘은 평범 — 협상·행정으로만 서는 왕
  - 3왕 배치 완성: 남안 무카밤바=순수 무력(가호 없음) / 서안 시렌가=신성(풍요 가호)
    - / 동안 하미시=아무 힘도 없음
    - → 셋 중 가장 약한 자가 셋을 붙들고 있는 구조. 그 손이 풀리는 때가 곧 연맹의 수명 약점·이야기 씨앗
  - [A] 종족이 다른 형제라는 뇌관:
    - 수인 형제의 존재 자체가 정치. 강경파나 남안 쪽에 형제가 서면
    - 왕의 중립이 곧바로 혈연 편향으로 읽힘 / 반대로 형제가 동안에 남으면
    - "수인을 앞세워 루펨바를 관리한다"는 의심을 삼국이 동시에 품음
    - → 종족으로 갈린 세 나라에서 한 집안이 세 나라의 축소판이 되는 구조
  - [B] 바가모예 통행권이라는 분열선:
    - 항구는 키탐바 소유 + 연맹 통행권. 즉 소유와 이용이 갈라진 물건
    - → 결속을 말하는 왕이 실은 연맹 최대의 지렛대를 혼자 쥐고 있음.
    - 조이면 중재자 자격을 잃고, 놓으면 키탐바 국익을 잃음
    - → 무카밤바의 남방 무기 유출 봉쇄론과 정면 충돌
    - (남문을 막자는 왕 vs 바닷길로 우회시키면 그만인 왕)
    - (※ 둘 다 배경·능력란에 구조로는 이미 반영됨)
  - 연동: C1(줄라니) / C4(음웰루-음바리) / 바가모예 인도양 라인 / 남부·인도양 축
