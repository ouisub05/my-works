# 말라니
> 말라니 (Malani) — 말라위호 대응 대호수 지대, 강을 낀 중계 소국들

**Malani**

| | |
|---|---|
| **위치** | 아자니아 · 말라위호 대응 |
| **인구** | 약 100만 |
| **종족 구성** | 수인 50 / 인간 26 / 엘프 19 / 하플링 3 / 노움 1 / 오크 1 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아자니아](../아자니아.md)에 속한 세력. 긴 호수와 물줄기(강)를 낀 작은 나라들이 흩어진 지대 (빅토리아호 3왕국 연맹과 대비)
- 정체성** 긴 호수와 물줄기(강)를 낀 작은 나라들이 흩어진 지대 (빅토리아호 3왕국 연맹과 대비)
  - 큰 왕국 없음. 주변 큰 세력들 사이에서 물자를 중계하며 사는 소국들

## 지리
- 지리** 위쪽 빅토리아호 연맹 ↔ 아래쪽 짐바브웨 석조 도시국가 ↔ 동해안 사이의 길목
  - 뱃길·강길로 물자를 실어나르는 '물길의 중개상'. 작지만 길목을 쥔 생존력

## 산업과 자원
- 특색·자원** 어업(자급) + 교통 (길고 깊은 호수·강을 교통로 삼아 남북·동서를 잇는 중계)

## 사회
- 호수명** [루웨자 호](../루웨자_호.md) (Ruweza) — 성격=어장·생계 기반 (길이기 전에 밥줄)

## 종족 구성
- 종족·종교** [수인](../../02_종족/수인.md) 다수 + [엘프](../../02_종족/엘프.md)·[인간](../../02_종족/인간.md) 공존 + 토착 신앙
  - [말라니 인물 / 아자니아 잔여 라운드 완결]
  - 이름: 은코사 (Nkosa) / 직위 = 루웨자 호 어촌들의 원로
  - 말라니에는 큰 왕국이 없으므로 군주가 아닌 생계 공동체의 대표를 세운 건
  - 최초의 비(非)군주·비상인 인물
  - 배경: 어촌 분쟁을 오래 조정해 온 신뢰가 권위의 전부
  - 재산도 신탁도 아님 — "저 사람이 갈라 준 몫이면 다들 수긍한다"는 세월만이 근거
  - 대구 구조 : [네콰시](../네콰시.md)=형식(의례)이 권위 / 은코사=세월(신뢰)이 권위
    - — 왕도 문서도 없는 두 땅이 각각 다른 방식으로 질서를 세운 사례
  - 능력: 어로·뱃길의 달인 — 정령술·가호 없음
  - 물때·고기 길·수로를 읽는 순수한 기술과 경험. 초자연적 요소 전무
  - 성격·노선: 바깥 세력과 직접 줄대기
  - 말라니 소국 군주들을 건너뛰고 [냐사연맹](../냐사연맹/냐사연맹.md)(루펨바 남문·키탐바)·[드짐바웨](../드짐바웨/드짐바웨.md)([치사니](../치사니.md)·[키방가](../키방가.md)) 쪽과
    - 직접 교섭 — 어획·뱃길·중계 물량을 놓고 어촌이 스스로 조건을 맞추러 나감
  - 근거: 물고기와 뱃길을 실제로 쥔 것은 궁이 아니라 어촌이라는 현실
  - 배경 구조: 말라니는 루웨자 호 덕에 자급이 되므로
    - C1로 남방 교역망이 재편되어도 가난해질 뿐 무너지지 않음
    - → 굶기지 못하니 협박도 통하지 않고, 동시에 아무도 두려워하지 않는 땅 약점·이야기 씨앗
  - [A] 소국 군주들이 월권으로 본다:
    - 나라의 외교를 왕이 아닌 자가 제 발로 나가서 하는 꼴 →
    - 소국 군주들 입장에선 통치권 침해. 다만 어촌을 적으로 돌리면 세수·식량이 끊기므로
    - 묵인과 견제 사이에서 어정쩡하게 방치 중 (터질 때까지 미뤄지는 갈등)
  - [B] 그의 약속은 문서가 아니라 구두뿐:
    - 말라니에는 통산력도 문서 행정도 약함(남부=구전 기준) →
    - 은코사가 맺은 조건은 전부 말과 신뢰로만 존재
    - → 그가 죽거나 물러나는 순간 모든 약속이 동시에 증발함
  - [C] 밖은 그를 '말라니 대표'로 착각한다:
    - 바깥 세력들은 창구가 하나면 그것을 국가 대표로 간주 →
    - 냐사·드짐바웨 쪽 장부에는 사실상 '말라니와 합의함'으로 기록됨
    - → 실제로는 아무 권한도 없는 어촌 원로와의 사담. 합의가 이행되지 않을 때
    - 바깥은 "말라니가 약속을 어겼다"고 판단하게 됨
    - → 세 씨앗의 합류점: 권한 없는 자의 구두 약속이 국가 간 신뢰로 오인되어 쌓이는 구조
    - — 은코사 한 사람이 사라지면 남방 교역망의 신뢰가 통째로 무너짐
  - 연동: C1(남방 교역망 재편) / 루펨바 남문·키탐바 / 드짐바웨 치사니 / 남부 라인
