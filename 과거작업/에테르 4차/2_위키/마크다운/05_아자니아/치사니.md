# 치사니
> 치사니 (Chisani) — 드짐바웨 동해안 교역로의 중견 석벽 도시

**Chisani**

| | |
|---|---|
| **소속** | 드짐바웨 |
| **대륙** | 아자니아 |
| **유형** | 교통로 |
| **위상** | 키방가(금·성벽)만큼 강하지 않고, 무시당할 만큼 작지도 않은 중간 도시 |

## 개요
- [드짐바웨](드짐바웨/드짐바웨.md)의 지명. 드짐바웨 동해안 교역로의 중견 석벽 도시
- 위상** [키방가](키방가.md)(금·성벽)만큼 강하지 않고, 무시당할 만큼 작지도 않은 중간 도시
  - 동해안 인도양 항로로 금이 빠져나가는 길목에 위치 → '벽'이 아니라 '길'의 도시
  - 그래서 어느 파벌에도 속하지 않는다는 이유로 순번 의장직이 돌아옴 ([네콰시](네콰시.md)의 모도시)
