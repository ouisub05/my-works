# 악수미아
> 악수미아 (Axumia) — 에티오피아 대응, 고원+해안 신성 왕국

**Axumia**

| | |
|---|---|
| **위치** | 아자니아 · 에티오피아 대응 |
| **왕도** | 아마란 |
| **국가원수** | 자레마 |
| **인구** | 약 400만 |
| **종족 구성** | 인간 51 / 수인 39 / 하플링 6 / 노움 2 / 엘프 1 / 오크 1 |
| **종교** | 독자 신앙. 단 시조 솔로몬 왕이 솔교 신앙사에 등장하는 인물이라 솔라티 |
| **경제** | 고원: 왕국의 심장부 — 왕궁·신전·요새 (정복 불가의 근거지) |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아자니아](../아자니아.md)에 속한 세력. 신화적 시조 '솔로몬 왕'의 후예를 자처하는 유서 깊은 왕국
- 정체성** 신화적 시조 '솔로몬 왕'의 후예를 자처하는 유서 깊은 왕국
  - 이중 정통성: 험준한 고원(난공불락의 방패) + 신성 왕조의 혈통

## 경제
- 국토 이원 구조
  - 고원: 왕국의 심장부 — 왕궁·신전·요새 (정복 불가의 근거지)
  - 해안: 부두·교역 시설이 늘어선 항구 지대 — 인도양 대응 바닷길 교역으로 번영
  - = 악숨 왕국(홍해·인도양 교역 번영 + 고원 요새 방어) 평행
- 인도양 교역 → 아프리카에 고립된 게 아니라 동쪽(아시아·인도 대응) 바닷길과
  - 판디라([수리아](../../06_수리아/수리아.md) 남인도 대응 대왕국)와의 인도양 향신료 항로로 연결됨

## 종족 구성
- 종족** [인간](../../02_종족/인간.md) + [수인](../../02_종족/수인.md) 공존

## 종교
- 종교** 독자 신앙. 단 시조 솔로몬 왕이 솔교 신앙사에 등장하는 인물이라 [솔라티움](../../03_아우로라/솔라티움/솔라티움.md)과 가느다란 접점
  - 도움을 주고받는 사이는 아님. 솔라티움이 이 나라를 '흥미로워하는' 정도
  - = 완전한 남도 형제도 아닌, 먼 친척을 보는 호기심의 거리감 ('프레스터 존의 왕국' 전설과 통함)
  - 가호: 악수미아 독자 신앙의 가호 형태 =
    - 수호·안정 가호 (고원 방패형) — "가호는 믿음 내용을 따름" 법칙 적용
