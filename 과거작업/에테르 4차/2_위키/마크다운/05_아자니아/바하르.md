# 바하르
> 바하르 (Bahar, '바다') — 악수미아 해안 항구

| | |
|---|---|
| **소속** | 악수미아 |
| **대륙** | 아자니아 |
| **유형** | 항구 |

## 개요
- [악수미아](악수미아/악수미아.md)의 지명. 악수미아 해안 항구
- 인도양 축의 서쪽 축이 이제 전 구간 유명화** 킬레마 → 바하르 → 판디라

## 갈등과 불씨
- 파생 정합
  - [에자나르](에자나르.md)의 "무게중심을 바다로" 노선은 아직 의지 단계 — 고원 사제단의 견제가 유효함
    - (씨앗 1)의 현재 상태를 지리로 확정한 셈)
  - 새 인물 자리 (해소 완료): [자레마](자레마.md) — 왕국의 돈줄을 쥔 실무 실권자.
    - 왕이 바다로 기울수록 힘이 커지고, 사제단이 이기면 잘려나갈 자리
    - → 자레마 (Zarema)로 — 28호

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 신전** 독자 신앙의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
