# 인부헤지
> 인부헤지 (Inbu-Hedj, '흰 성벽') — 케메트-쿠쉬 국경 요새선

| | |
|---|---|
| **소속** | 케메트 |
| **대륙** | 아자니아 |
| **유형** | 요새·군사시설 |
| **성격** | 요새선 군사 국경 |

## 개요
- [케메트](케메트/케메트.md)의 지명. 케메트-[쿠쉬](쿠쉬/쿠쉬.md) 국경 요새선
- 성격** 요새선 군사 국경

## 기능
- 기능** 방어선이 아니라 약탈 원정의 출격 기지
  - 케메트는 영토를 넓히지 않는 나라 → 이 선은 정복의 전진선이 아니라
    - "여기까지가 신성한 땅"이라는 경계 표시이자, 원정대가 드나드는 문
  - 공격 기지라는 것은 곧 케메트가 쿠쉬를 두려워하지 않는다는 뜻

## 경제와 산업
- 교역** 요새 관문에서만 최소한 허용
  - 약탈하러 나가는 문과 물건을 사고파는 문이 같음 [네페르카](네페르카.md) 씨앗 2)(쿠쉬의 원한 축적)가 쌓이는 자리
