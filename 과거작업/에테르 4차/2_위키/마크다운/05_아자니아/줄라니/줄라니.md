# 줄라니
> 줄라니 (Zulani) — 최남단(케이프타운~에스와티니 대응)

**Zulani**

| | |
|---|---|
| **위치** | 아자니아 · 에스와티니 대응 |
| **정치체제** | 전사들을 양성하며 전제정치를 준비하는 세력이 태동 중 |
| **국가원수** | 카짐베 |
| **인구** | 약 120만 |
| **종족 구성** | 수인 81 / 인간 16 / 하플링 1 / 엘프 1 / 오크 1 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아자니아](../아자니아.md)에 속한 세력.

## 정치
- 격동의 여명기** 전사들을 양성하며 전제정치를 준비하는 세력이 태동 중
  - 분권적 부족 사회 → 강력한 군사 왕국으로 결집하기 직전 (줄루 왕국 태동기 평행) 아직 왕국은 없으나 부족들을 묶을 전사 왕이 등장할 씨앗 → '새로운 강자의 탄생' 예고 지대

## 법의 세 줄과 승계
- 법의 꼭대기 — 관습법
- 조문에 종족 — 아니오
- 조문에 성별 — 아니오
- 승계 — 아직 세습 아님 (전사 왕 태동 중)
- 비고
