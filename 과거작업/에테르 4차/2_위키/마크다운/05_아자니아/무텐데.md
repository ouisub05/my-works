# 무텐데
> 무텐데 (Mutende, '고요') — 드짐바웨 정치 중심 도시 (안쪽)

| | |
|---|---|
| **소속** | 드짐바웨 |
| **대륙** | 아자니아 |
| **유형** | 도시 |
| **성격** | 연합 회의장 — 각 석벽 도시 대표가 모이는 자리. |

## 개요
- 드짐바웨의 지명. 드짐바웨 정치 중심 도시 (안쪽)
- 성격** 연합 회의장 — 각 석벽 도시 대표가 모이는 자리.
  - 상주 권력은 약하고, 회의 기간에만 중심이 되는 도시
  - 따라서 [드짐바웨](드짐바웨/드짐바웨.md)에는 왕이 없음 (석조 도시국가 연합 설정과 정합)

## 정치적 무게
- 드짐바웨에는 별도의 정치 중심 도시가 존재

## 갈등과 불씨
- 파생
  - 실질 무게중심은 [키방가](키방가.md)로 쏠림 — 금과 성벽을 쥔 도시가 상설 권력,
    - 무텐데는 모이는 자리일 뿐
  - 이원 구조: 남쪽 = 돈과 칼(키방가) / 안쪽 = 합의와 정통(무텐데)
  - C1 취약점: [카짐베](카짐베.md)가 한 사람의 명령으로 움직이는 왕국을 세울 때,
    - 드짐바웨는 '모여서 의논부터 해야 하는 나라' — 속도의 격차가 곧 약점
  - 위기 시 바깥 도시(키방가)가 안쪽 도시의 합의를 기다리지 않기 시작하는 자리

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. [하플링](../02_종족/하플링.md)과 [노움](../02_종족/노움.md)이 특히 많다
- 대상 숙소** 낙타와 짐을 함께 재우는 안뜰형 숙소. 먼 길의 소문이 가장 먼저 닿는 자리
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
