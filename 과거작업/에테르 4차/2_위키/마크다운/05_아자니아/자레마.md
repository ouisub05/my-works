# 자레마
> 바하르 총독

**Zarema**

| | |
|---|---|
| **소속** | 악수미아 |
| **대륙** | 아자니아 |
| **지위** | 상인회와 밀착한 사교형 |
| **종족** | 수인 (해안 계열) |
| **능력** | 가호 없음 — 순수 실무가 |

## 개요
- 악수미아의 [바하르](바하르.md) 총독.
- 이름** 자레마 (Zarema)
- 종족** [수인](../02_종족/수인.md) (해안 계열)
  - 근거: 위 [악수미아](악수미아/악수미아.md) 항목에 "수인은 왕조 주변·군부·해안 상인층에 배치 가능"
  - [인간](../02_종족/인간.md) 신성 왕조([에자나르](에자나르.md))와의 대비 효과
- 유형·운영 스타일** 상인회와 밀착한 사교형

## 성격
- 소속** 왕이 임명한 심복 — 왕의 사람

## 능력
- 능력** 가호 없음 — 순수 실무가
  - 구조적 의미: 신성 왕조의 나라에서 신성 없이 오직 실무 능력만으로 돈줄을 쥔 사람
    - → 고원 사제단에게는 "바다의 부는 신성하지 않다"는 공격의 표적
    - → 동시에 에자나르가 무게중심을 바다로 옮기려면 반드시 지켜내야 하는 패

## 갈등과 불씨
- 약점·이야기 씨앗
  - **1)** [B] 밀착의 대가
  - 상인회와 가까울수록 [아마란](아마란.md)에서는 "저자는 이미 바하르 사람"이라는 의심이 자람
  - 균형을 지키는 방법 자체가 의심의 근거가 되는 구조
  - 왕궁 관료 출신 파견이라는 경위가 이 의심을 더 날카롭게 만듦 (배신 서사가 성립함)
  - **2)** [D] 인도양 마찰이 책상 위로 에자나르 씨앗 2)(판디라·키탐바와의 교역 마찰)가 실제로 터지는 현장은
    - 왕궁이 아니라 항구 — 즉 자레마의 책상
  - 인도양 축(킬레마 → 바하르 → [나가팟](../06_수리아/나가팟.md)) 연동
