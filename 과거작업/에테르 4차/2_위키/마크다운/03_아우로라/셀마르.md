# 셀마르
> 셀마르 (Selmar, '해협의 바다' 어감) — 로렌시아 해군 모항

| | |
|---|---|
| **소속** | 로렌시아 |
| **대륙** | 아우로라 |
| **유형** | 항구 |
| **성격** | 해군 모항 — 왕립 함대 주둔지. A1(로렌시아-마르네스 전쟁)의 최전선 항구 |

## 개요
- 로렌시아의 지명. 로렌시아 해군 모항
- 성격** 해군 모항 — 왕립 함대 주둔지. A1([로렌시아](로렌시아/로렌시아.md)-[마르네스](마르네스/마르네스.md) 전쟁)의 최전선 항구

## 위치와 지형
- 위치** 해협 방면 (도버 해협 대응 — 마르네스와 최단거리 해안)

## 군사
- A1 개전 전야 상황
  - **1)** 함대 집결 중: [플로랑 3세](플로랑_3세.md)의 명으로 각지 함선이 모여드는 중 —
    - 항구 전체가 전쟁 경기(景氣)로 들썩임 (개전 임박의 체감 무대)
  - **2)** 첩자의 항구 — [마리스텔라](마리스텔라/마리스텔라.md) 한정: 마리스텔라의 눈이 상인으로 [위장](../06_수리아/위장/위장.md)해 상주,
    - 함대 규모·출항일을 읽는 중 (균형 외교+전쟁 특수 노림의 실행 현장.
    - 마르네스 첩보망은 없음 — 사용자 한정)

## 주민
- 종족 구성** [인간](../02_종족/인간.md) 58 / [수인](../02_종족/수인.md) 17 / [하플링](../02_종족/하플링.md) 8 / [노움](../02_종족/노움.md) 7
  - / [드워프](../02_종족/드워프.md) 5 / [엘프](../02_종족/엘프.md) 3 / [오크](../02_종족/오크.md) 2
  - 군항 특성: 인간(왕립 해군 주축)·수인(선원·해병)·노움(조선소 마공학 공방)
  - 드워프(선구·병기 대장간)가 국가 평균 대비 높음

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. 하플링과 노움이 특히 많다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
