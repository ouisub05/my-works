# 마르네스
> 마르네스 (Marnes) — 잉글랜드 대응

**Marnes**

| | |
|---|---|
| **위치** | 아우로라 · 잉글랜드 대응 |
| **수도** | 알비온 |
| **정치체제** | 대헌장 이후형. 귀족·의회가 왕권을 견제 |
| **국가원수** | 알드렌 |
| **인구** | 약 400만 |
| **종족 구성** | 엘프 54 / 수인 33 / 인간 9 / 하플링 2 / 드워프 1 / 노움 1 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아우로라](../아우로라.md)에 속한 세력. 엘프 54 / 수인 33 / 인간 9 / 하플링 2 / 드워프 1 / 노움 1의 섬나라
- 정체성** [엘프](../../02_종족/엘프.md) 54 / [수인](../../02_종족/수인.md) 33 / [인간](../../02_종족/인간.md) 9 / [하플링](../../02_종족/하플링.md) 2 / [드워프](../../02_종족/드워프.md) 1 / [노움](../../02_종족/노움.md) 1의 섬나라
  - 수인은 해군·해적에 다수 종사(갑판 위 주역은 사실상 수인)

## 지리
- 강점** 전투 특화 해군(붙으면 이기는 해군, 항해술보다 전투) + 이간질
  - 정령술은 부차적 보조 카드

## 정치
- 정치** 대헌장 이후형. 귀족·의회가 왕권을 견제

## 군사
- 전쟁 동기** 경제 재편([로렌시아](../로렌시아/로렌시아.md) 독주 저지, 해협·플랑드르 교역권) + 내부 문제 회피
- 개전 상황** '계산되지 못한 도발'. 언젠가 전쟁할 생각으로 도발 수위를 올리던 중
  - 로렌시아 왕의 급발진은 예상 밖 → 준비 덜 된 채 예정보다 빨리 끌려 들어가는 중
  - ("양쪽 다 전쟁을 원했지만 누구도 지금을 원하지 않았다")

## 사회
- 브렌모어 (Brenmore, '큰 산' 어감) — 스코틀랜드 대응 지역 통칭
  - 마르네스 섬 북부 고지대. 드워프+다크엘프 소수 마을 수준. 국가 아님, 정세 변수 아님

## 외교
- vs [실바리스](../실바리스/실바리스.md)** 먼 동족. 교류 거의 없고 서로 낯설어함
