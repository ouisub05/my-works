# 발디르
> 발디르 (Valdir, '계곡' 어감) — 몬스 페라 계곡 지대 (레만 호 동쪽~마조레 호 관문 축)

| | |
|---|---|
| **소속** | 베르가 동맹 |
| **대륙** | 아우로라 |
| **유형** | 자연지형 |

## 개요
- [베르가동맹](베르가동맹/베르가동맹.md)의 지명. 몬스 페라 계곡 지대 (레만 호 동쪽~마조레 호 관문 축)

## 위치와 지형
- 위치** 몬스 페라 산맥의 지상 계곡들 (발레 계곡~알프스 고갯길~밀라니아 방면 관문 대응)

## 정치적 무게
- 정치** 계곡 마을들의 느슨한 연합

## 종교
- 신앙** 혼재 (솔교+산악 전통) — 가호 발현 없음 (저신앙지)
- 특징
  - **1)** 용병의 산실: 가난한 계곡의 젊은이들이 각국에 용병으로 나감 (스위스 용병 평행) —
    - [미세아](미세아/미세아.md) 용병 시장·각국 궁정 호위와 연결되는 인력 수출지
  - **2)** 겨울 폐쇄의 리듬: 겨울마다 고개가 닫혀 세상과 끊기는 삶 — 봄 개통을 알리는 축제 문화
  - **3)** 고갯길 구호 수도원: 험로의 솔교 수도원이 조난자 구호소 운영 (세인트 버나드 평행) —
    - 혼재 신앙 속 솔교가 실질 선행으로 뿌리내리는 창구
