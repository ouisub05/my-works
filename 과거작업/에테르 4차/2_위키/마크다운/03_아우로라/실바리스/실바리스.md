# 실바리스
> 실바리스 (Silvaris) — 대삼림 엘프 왕국

**Silvaris**

| | |
|---|---|
| **위치** | 아우로라 |
| **왕도** | 아르보렌 |
| **국가원수** | 아엘두인 (왕) |
| **정치체제** | 단일 왕국. 대륙 유일의 비인간 대국(면적 기준 제국과 견줄 만함) |
| **인구** | 약 200만 |
| **종족 구성** | 엘프 97 / 수인 2 / 인간 1 |
| **경제** | 비아워비에자 대응 ~ 스칸디나비아까지 이어지는 발트 연안 초대형 원시림 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아우로라](../아우로라.md)에 속한 세력.

## 정치
- 정치** 단일 왕국. 대륙 유일의 비[인간](../../02_종족/인간.md) 대국(면적 기준 제국과 견줄 만함)
- 인간과 최소 접촉. 출림(出林)은 법으로 금하나 숲이 너무 넓어 다 막지 못함
  - 젊은 [엘프](../../02_종족/엘프.md)들이 제국의 문화·아카데미에 이끌려 이탈 → 왕국의 고민 (문화로는 뚫리는 중)
- 현 상태** 왕은 "경고했더니 개간이 멈췄다"며 관망(현상 유지)
  - 그러나 실제로는 제국이 숲을 피해 주변을 흡수 중 → 왕의 눈엔 승리, 지도상으론 포위
  - 양쪽 다 "지금 잘 되고 있다"고 믿는 안정된 오해가 갈등의 진짜 얼굴
  - 내부에 "외교·협상이 필요한 시점"이라 주장하는 목소리 존재

## 군사
- 군사** 숲이 존재하는 한 제국군도 못 뚫음(마법+지형+정령술).
  - + 검·활을 쓰는 무력/마법 계열 친위대 별도

## 경제
- 영역** 비아워비에자 대응 ~ 스칸디나비아까지 이어지는 발트 연안 초대형 원시림
  - 본거지: [아르보렌](../아르보렌.md)(라트비아 대응). 심장부 일부만 [에테르](../../01_세계관_코어/에테르.md) 농도가 조금 높음

## 외교
- vs [노르가르드](../노르가르드/노르가르드.md)** 북쪽 끝에서 남하하는 북방인과 마찰(식량·거주지·땔감). 아직 강도 약함

## 법의 세 줄과 승계
- 법의 꼭대기 — 국가법
- 조문에 종족 — 적을 상대 없음 (작중 조문에는 없음)
- 조문에 성별 — 아니오
- 승계 — 장자 · 모두 가능
- 비고
  - 단일 종족 왕국이라 종족을 적을 상대가 없다. 빈칸이 아니라 제3의 값이다
  - 일바렌·두르가른에서도 같은 답이 나와 세계 공통 패턴으로 굳었다
  - 위험도 같다. 바깥 사람이 들어오는 날 기준이 아무것도 없다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
