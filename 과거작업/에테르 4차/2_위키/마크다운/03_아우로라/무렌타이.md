# 무렌타이
> 칸

| | |
|---|---|
| **소속** | 코르타이 |
| **대륙** | 수리아 |
| **지위** | 칸 |

## 개요
- [코르타이](../06_수리아/코르타이/코르타이.md)의 칸.
- 정체성** 통일 직전의 초원. 곧 칭기즈칸 대응 인물이 통일 예정
  - → 아시아 최대의 시한폭탄 ([아우로라](아우로라.md)의 [노르가르드](노르가르드/노르가르드.md) 대이주와 평행하는 '터지기 직전' 구도)

## 생애
- 통일 직전** 칭기즈칸 대응 인물이 이미 초원의 절반 이상을 규합. 남은 것은 소수
- 무렌타이가 초원 절반 이상을 규합한 중심지이자, 통일** 무렌타이가 초원 절반 이상을 규합한 중심지이자, 통일 선언(텡기르 칸 즉위)이 이뤄질 자리

## 치세와 정책
- 칭기즈칸 대응 인물** 본명 무렌타이 (Murentai, '강' — 모든 물줄기를 모으는 강)
  - / 통일 시 칸호: 텡기르 칸 (Tengir Khan, '하늘의 칸' — 기동 가호 "하늘이 정한 왕"의 공식 선언)
- 칭기즈칸 대응 인물 — 본명 무렌타이 / 통일 시 칸호 텡기르 칸으로
