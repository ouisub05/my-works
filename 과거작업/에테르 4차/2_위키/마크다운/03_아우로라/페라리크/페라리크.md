# 페라리크 제국
> 페라리크 제국 (Ferrarich) — 독일 대응

| | |
|---|---|
| **위치** | 아우로라 · 독일 대응 |
| **수도** | 프라가 |
| **국가원수** | 오토카르 3세 (황제) |
| **인구** | 약 1,000만 |
| **종족 구성** | 인간 47 / 수인 15 / 하플링 15 / 드워프 8 / 노움 6 / 오크 5… |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아우로라](../아우로라.md)에 속한 세력. 선제후 연방 → 몇 대에 걸쳐 중앙집권화를 이룬 균형 강국
- 정체성** 선제후 연방 → 몇 대에 걸쳐 중앙집권화를 이룬 균형 강국

## 국가원수
- 교황 질서 이탈** 주권 문제(황제 대관에 교황 승인이 필요하다는 것 자체를 거부)
  - 단 교회 조직은 안 건드림. 승인·간섭만 거부하는 냉담 노선
  - 교황청과 냉전 (파문·봉쇄 협박은 오가나 실행은 안 함. 초조한 쪽은 교황청)

## 사회
- 국력** 종족 차별 적음(국익형 포용), 교육·군사·경제 모두 상위권. 넓고 비옥한 땅 + 광산
- 수도** [프라가](../프라가.md) / 상징: 철관(교황 승인 없이 스스로 씀)
- 동방 개척** 제국 기사단이 포섭 위주로 진행. 우크라이나 대응 지대가 목표선(도달 시 정지 예정)

## 교육과 학문
- 아카데미** 베르크슐레 (Werkschule, '일·공방의 학교')
  - 학문적 성격보다 실용·실생활 적용에 초점
  - 콜레기움 마그눔과는 특화 경쟁 (같은 무대에서 겨루기보다 실용 분야로 차별화)

## 외교
- vs [실바리스](../실바리스/실바리스.md)** 갈등. 현재는 숲을 '피해서' 개간·정복 중 (→ 실질적으로는 숲을 포위)

## 법의 세 줄과 승계
- 법의 꼭대기 — 국가법
- 조문에 종족 — 아니오
- 조문에 성별 — 아니오
- 승계 — 장자 · 모두 가능
- 비고
  - 세 줄이 전부 열린 나라다. 대륙에서 드문 경우다
  - 성직 우위에서 세속 우위로 넘어가는 중이며, 그 이탈은 교리 다툼이 아니라 서열표를 고쳐 쓰는 일이다
  - 연회에서 주교와 백작 중 누가 먼저 불리는가가 그날 제국의 노선을 알리는 신호가 된다
  - 성장 회로의 마지막 단계를 밟는 중이다. 법의 꼭대기가 국가법으로 넘어간 자리에서 신분의 서열표도 따라 뒤집힌다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
