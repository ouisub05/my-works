# 코르시오
> 베네시아 수장

**Corsio**

| | |
|---|---|
| **소속** | 베르가 동맹 |
| **대륙** | 아우로라 |
| **지위** | 해상 확장가 — 교역로·항로 경쟁에 적극적 |
| **종족** | 수인 — 수달 계열 (물가 상인 어감. 도시 다수파 출신) |

## 개요
- [베르가동맹](베르가동맹/베르가동맹.md)의 베네시아 수장.
- 이름** 코르시오 (Corsio)
- 종족** [수인](../02_종족/수인.md) — 수달 계열 (물가 상인 어감. 도시 다수파 출신)
- 유형** 해상 확장가 — 교역로·항로 경쟁에 적극적
  - (임기가 있는 자리에 앉은 확장가라는 긴장)

## 갈등과 불씨
- 약점·이야기 씨앗
  - **1)** 연임 도박 : 임기 안에 확장 성과를 보여줘야 연임 명분이 생김 —
    - 무리한 항로 개척·투자 유인. [로렌시아](로렌시아/로렌시아.md)-[마르네스](마르네스/마르네스.md) 전쟁이 터지면 해상 물류 특수가
    - 곧 연임 티켓이라, 남의 전쟁을 내심 기다리는 처지
