# 바르단
> 바르단 (Vardan, '지키는 곳' 어감) — 미세아 동방 국경 요새 도시

| | |
|---|---|
| **소속** | 미세아 |
| **대륙** | 아우로라 |
| **유형** | 요새·군사시설 |
| **성격** | 군사 요새 + 군사·용병·통행 상권 겸영 |

## 개요
- [미세아](미세아/미세아.md)의 지명. 미세아 동방 국경 요새 도시
- 성격** 군사 요새 + 군사·용병·통행 상권 겸영
  - 수비 병력은 대부분 국가 소속 — 용병 왕국이지만 국경 요새만은
    - 왕국 정규군이 지킴 (용병에게 국경을 맡기지 않는다는 원칙이 드러나는 곳)

## 위치와 지형
- 위치** 미세아 완충 회랑의 동쪽 끝, [마슈리크](../04_마슈리크/마슈리크.md) 방면 국경

## 군사
- 맞은편 (마슈리크** 국경 반대편 = [미슈마르](../04_마슈리크/미슈마르/미슈마르.md)의 [바브 알샴](../04_마슈리크/바브_알샴.md) (Bab al-Sham) —
  - 군사 대치선 + 용병 고용 시장. 바르단을 나선 동방행 용병단이 실제로 계약되는 자리
  - 바르단(정규군이 지키는 국경) ↔ 바브 알샴(용병을 사서 지키는 국경)의 대조 구도
  - A4 재점화 시 이 두 요새가 최전선의 양쪽이 됨
