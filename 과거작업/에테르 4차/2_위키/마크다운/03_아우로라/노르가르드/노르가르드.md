# 노르가르드
> 노르가르드 (Norgard) — 스칸디나비아 대응

**Norgard**

| | |
|---|---|
| **위치** | 아우로라 · 스칸디나비아 대응 |
| **중심지** | 스카르비크 |
| **국가원수** | 하랄디르 (국왕) |
| **정치체제** | 남부=연합 왕국 / 북부 내륙·피오르=부족국가들 (중심-위성. 왕국 종주 |
| **인구** | 약 150만 |
| **종족 구성** | 인간 51 / 오크 39 / 수인 5 / 드워프 3 / 엘프 1 / 하플링 1 |
| **종교** | 미개종. 전쟁신 신앙 → 전투 가호형 신성력(광전사). 대륙 최후의 대형 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아우로라](../아우로라.md)에 속한 세력.

## 지리
- 중심지** [스카르비크](../스카르비크.md) (Skarvik, '바위 만') — 남부 연합 왕국의 중심, 피오르 안쪽 항구 도시

## 정치
- 정치** 남부=연합 왕국 / 북부 내륙·피오르=부족국가들 (중심-위성. 왕국 종주권은 명목상)

## 국가원수
_(내용 없음)_

## 군사
- 남하 두 [갈래](../../01_세계관_코어/갈래.md)
  - 약탈 루트: 폴란드 대응 북쪽 연안 → 제국 동방 개척지의 해안과 충돌 코스
  - 이주 루트: 핀란드 대응 경유 남동진 → 대삼림 왕국 심장부 방향
- 왕실 입장** 약탈은 공식적으로 "모르는 일"(부인권 유지한 백성의 숨구멍)

## 사회
- 배경** 소빙기(점진적 한랭화) 시작. 북방이 최전선 → 남하 압력의 근본 원인

## 종족 구성
- 종족** [인간](../../02_종족/인간.md)+[오크](../../02_종족/오크.md) 혼재 왕국 — 오크 북방·툰드라권의 중심 세력.
  - 기존 인물([하랄디르](../하랄디르.md)·[오르바르](../오르바르.md)·[요르문드](../요르문드.md))은 유지

## 종교
- 종교** 미개종. 전쟁신 신앙 → 전투 가호형 [신성력](../../01_세계관_코어/신성력.md)(광전사). 대륙 최후의 대형 이교도 세력
  - 교황청 십자군의 잠재 표적 (제1성지는 멀지만 북방 이교도는 바로 옆. 발트 십자군 평행)

## 법의 세 줄과 승계
- 법의 꼭대기 — 국가법
- 조문에 종족 — 아니오
- 조문에 성별 — 아니오
- 승계 — (남부) 장자·모두 가능 / (북부) 세습 아님
- 비고
  - 한 나라 안에 두 체계가 공존한다. 남부는 작위로, 북부는 거느린 전사 수로 신분을 잰다
  - 종주권이 명목상이라는 확정이 신분 쪽에서도 반복된다
  - 환산이 국경 밖이 아니라 나라 안에서 벌어지는 유일한 사례다
- 상세는 [국가별 — 법의 세 줄과 승계](../../11_제도_전쟁_역병/국가별_-_법의_세_줄과_승계.md) 참조
