# 헬라디아
> 헬라디아 (Helladia) — 그리스 대응 도시연합

**Helladia**

| | |
|---|---|
| **위치** | 아우로라 · 그리스 대응 |
| **국가원수** | 테오필로스 |
| **인구** | 약 400만 |
| **종족 구성** | 인간 57 / 수인 15 / 하플링 12 / 엘프 5 / 노움 5 / 드워프 3… |
| **종교** | 보편 종교의 동방 교회 계열. 서방과 교리 차이(신성력 해석)로 분열 |
| **경제** | 베네시아 ~ 헬라디아 ~ 미세아 삼각 무역 + 베네시아와 주도권 경쟁 |
| **통화** | 금화 (국제) · 자국 통화 별도 |

## 개요
- [아우로라](../아우로라.md)에 속한 세력. 고대 헬라스 → 아우렐 제국에 합병 → 반란기에 '헬라스로서' 재건
- 정체성** 고대 헬라스 → 아우렐 제국에 합병 → 반란기에 '헬라스로서' 재건
  - 재건 초기엔 제국형(무너지는 옛 제국 동방을 흡수) → 옛 제국 완전 소멸 후 도시국가 연합으로
  - "우리는 너희 제국보다 오래됐다"는 초연한 위치. 철학·학문의 원류라는 자부심

## 경제
- 지중해 동부 교역** 베네시아 ~ 헬라디아 ~ [미세아](../미세아/미세아.md) 삼각 무역 + 베네시아와 주도권 경쟁

## 사회
- 제1도시** 아테리아 (Atheria) — 연합 회의가 열리는 대표 도시 ('수도' 아님)

## 종교
- 종교** 보편 종교의 동방 교회 계열. 서방과 교리 차이([신성력](../../01_세계관_코어/신성력.md) 해석)로 분열
  - 분열이 영토가 아니라 거주지 단위 → 도시 내 구역 정치·폭동·혼인 갈등 등 미시적 갈등

## 외교
- vs 미세아** 공생(용병의 주요 고객이자 공급처, 마레 헬라스 단골)
