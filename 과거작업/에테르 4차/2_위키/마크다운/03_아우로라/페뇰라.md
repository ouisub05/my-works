# 페뇰라
> 페뇰라 (Peñola, '바위' 어감) — 지브롤터 해협 북안 이주 전용 항구

| | |
|---|---|
| **소속** | 마리스텔라 |
| **대륙** | 아우로라 |
| **유형** | 항구 |
| **성격** | 이주 관문 항구 — 티네리 수인 북상 이주 항로의 상륙 관문 |

## 개요
- [마리스텔라](마리스텔라/마리스텔라.md)의 지명. 지브롤터 해협 북안 이주 전용 항구
- 성격** 이주 관문 항구 — [티네리](../05_아자니아/티네리/티네리.md) [수인](../02_종족/수인.md) 북상 이주 항로의 상륙 관문
  - (해협 이주 항로는 이주 전용) + 구 [트라베사](트라베사.md)의 무역 기능 흡수
  - 트라베사는 해군 거점으로 용도 변경 (아래 트라베사 항목 참조)

## 위치와 지형
- 위치** 마리스텔라 남부, 해협 북안 (알헤시라스/지브롤터 대응) — 남안 트라베사와 마주 봄

## 주민
- 종족 구성** 수인 44 / [인간](../02_종족/인간.md) 34 / [하플링](../02_종족/하플링.md) 8 / [엘프](../02_종족/엘프.md) 4
  - / [노움](../02_종족/노움.md) 4 / [오크](../02_종족/오크.md) 4 / [드워프](../02_종족/드워프.md) 2 — 티네리계 수인 체류·통과 인구 최다 (마리스텔라 내 수인 1위 도시)

## 주요 시설
- 총독부** 중앙이 임명한 관리가 앉는 청사. 세금과 재판이 여기서 처리된다
- 대시장** 성문 안쪽의 상설 시장. 도시의 하루가 이 소리로 시작된다
- 길드 회관** 직능별 길드가 모여 규약과 값을 정하는 건물. 하플링과 노움이 특히 많다
- 신전** 솔교 + 알 딘 혼재의 예배 시설. 도시의 절기와 의례가 여기서 정해진다
- 부두 창고** 짐을 부리고 쟁여 두는 석조 창고 줄. 세관이 나란히 붙어 있다
- 성벽과 문루** 도시를 두른 성벽과 그 문. 야간 통행은 문루의 허락을 받아야 한다
- 병영** 수비대가 주둔하는 구역. 유사시 성문 방어의 중심이 된다
