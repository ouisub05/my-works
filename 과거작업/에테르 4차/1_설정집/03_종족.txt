====================================
03. 종족 (★전면 재설정판 — 7종 체제)
====================================
[상태] 최종 갱신 = 정합성 세션 / 반영 완료 = 21~26·29 / 미반영 = 없음
[담당] 7종 체제·용족·혼혈 — ★종족 정본 (수치는 15)
[규칙] 값이 다른 파일과 어긋나면 ★정본 파일이 이김. 이력의 정본은 ★99_변경이력
※ 종족 재설정 세션에서 전면 개편
※ 연쇄 수정 대상: 01(문명 수준·세계 대원칙) / 02(룬 각인) / 06·14(D4 재조정)
   / 07(노르가르드) / 10(케메트) / 11(신대륙 북방) / 12(해솔·에조라) / 00·HANDOFF

------------------------------------
[★세계 대원칙 — 확정 (01에도 반영)]
------------------------------------
- 이 세계는 종 분화(특히 지성 종족), 마정석, 무력, 마법 등의
  판타지 요소만 걷어내면 실제 세계와 똑같음
- 일반적인 과학이 그대로 적용됨

------------------------------------
[기본 종족 — 7종 체제]
------------------------------------
※ 특화 = 종족적 경향·적성이지 개인의 한계가 아님

1) 인간 — 범용
2) 수인 — 신체능력 특화
3) 하플링 — 농경 특화
4) 노움 — 마공학·공학 특화
5) 드워프 — 대장장이(룬 각인 등)·도끼 전사 특화
6) 엘프 — 정령술·궁술 특화
7) 오크 — 근접 전사 특화

+ 별개 존재: 용족 (7종 외 은둔·희소 종족)
+ 혼혈: 하프엘프 (인간×엘프) / 드라킨 (인간×용족)

[종족 비율 — ★사용자 확정]
- 인간 38% / 수인 22% / 하플링 12% / 엘프 9% / 드워프 7% / 오크 6% / 노움 6%
- 하프엘프·드라킨·용족은 통계에 잡히지 않는 극소수

[분포 원칙 — 유지]
- 고향 대륙 개념은 약함. 서식 환경(생태)에 따라 분포
- 아래는 평균적 경향이며, 섞여 사는 지역도 많음

------------------------------------
[종족별 상세]
------------------------------------

[인간]
- 특화: 없음 (범용)
- 전 세계에 고르게 분포
- 수명: 지구 인간과 동일

[수인]
- 특화: 신체능력
- 전체적으로 퍼져 있으나 사바나, 울창한 숲에 특히 많음
- 외형: 귀·꼬리 정도가 보편적. 파충류 계열은 일부 신체 부위에 비늘이 있기도 함 (전신 아님)
- 수명: 인간과 비슷

[하플링]
- 특화: 농경
- 수명: 100~120년 (인간보다 약간 김)
- 외형: '작은 인간'에 가까움 (곱슬머리·맨발 등 전형적 목가풍 클리셰는 배제)
- 분포 (★확정):
  · 전 세계 농촌에 혼재
  · 각지 도시에도 혼재 — 특히 길드에 많음
  · 풍요한 땅(곡창 지대)에는 하플링 자치 마을이 존재
- ★예외 — 케메트에는 자치 마을 없음:
  · 케메트에는 노예라는 신분 자체가 존재하지 않음 — 모든 일은 국민을 돈 주고 고용
  · 자신들의 땅·국민을 신성히 여기고, 그 외는 정화 대상이거나 침략을 막아야 하는 존재로 봄
  · 따라서 외부인은 노예로조차 들이지 않음. 단순 교역만 함
  → 하플링이 발붙일 자리 자체가 없음 (10 케메트 항목에도 반영)

[노움]
- 특화: 마공학·공학
- 수명: 150년 안팎 (인간의 2배쯤)
- 외형: 하플링보다 조금 더 작은 키, 마른 체형. 눈이 특징적 (정밀 작업 적성)
- 분포 (★확정): 독자 왕국·집단 거주지 없음 —
  실제 세계에서 인종이 섞여 있듯, 각지 도시에 섞여 삶
- ★생업의 세 갈래 (19 길드 세션에서 확정):
  · ★개인 공방을 운영하는 노움 / ★어딘가에 소속되어 공방 일을 하는 노움
  / ★공방 일과는 전혀 상관없는 일을 하는 노움
  · 해솔의 공방 단위 편성은 그중 한 사례일 뿐 (상세 19-III-5·III-8)
- ★세계 문명 수준 연동 (01 수정): 노움이 있는 곳마다 마공학 보유 — 세계의 마공학 수준 전반 상향
  · 해솔 '인형'은 해솔 거주 노움 집단의 작품으로 수정 —
    ★개발 구조: 드워프(바우둔) 설계 + 노움 제작 협업 (12 수정)
  · 인형의 위상: 세계 유일이 아니라 여러 마공학 성과 중 하나 (D4 시한폭탄 재조정, 14 수정)

[드워프]
- 특화: 대장장이 — 특히 룬 각인 — + 도끼 전사
- ★룬 각인 (02에도 반영): 마법을 특수한 돌에 새기는 기술 (마법 계통의 드워프식 응용)
  · 새기는 돌: 마정석 + 마정석과는 다른 별도의 광석 (마정석 쪽이 더 가치가 높음)
- 큰 산맥 근처에 많음. 보통 지하에 거주. 지상에는 타종족과 교류하는 마을을 만듦
- 수명: 200~300년
- 산맥 = 고농도 에테르 지대이므로, 드워프는 에테르 요지의 주인인 셈 (교역·갈등의 핵)
- 산맥마다 독립된 지하왕국 (통일된 단일 드워프 국가는 없음)
  · 그라니타 산맥(우랄 대응): 최대 규모·개방형. 관문 2개(베스가르·타쉬둔), 왕도 그란둠 (상세 12)
  · 몬스 페라 산맥(알프스 대응): 소규모, 지상 교역이 생존 전략 → 베르가 동맹의 대등한 동반자
- 종교: 대장장이 신 + 조상 숭배 (04 참조)

[엘프]
- 특화: 정령술 (적성 보유 종족) + 궁술
- ★정령술 적성의 유래 (16에서 확정): 종 적성 + 오랜 세월 정령이 엘프와 응해 온 결과의
  ★공진화 — 엘프·정령·정령술이 서로를 빚어 지금 모습이 됨
  · ★그 대가: 정령의 지성 퇴화는 이 관계의 결과, 사실상 ★가축화 (떡밥. 상세 16·06)
  · 자연의 수호자를 자처하는 종족이 자연의 일부를 길들여 놓았다는 아이러니 —
    엘프 자신조차 모름
- 매우 큰 숲, 자연이 잘 보존된 곳일수록 많음
- 수명: 수백 년
- ★갈래 — 엘프(백색) / 다크엘프 (확정):
  · 엘프 종족 안에 백색 엘프와 다크엘프가 존재
  · 발생: 돌연변이 + 혈통 혼합 — 어디서나 나올 수 있으며, 진화의 결과일 수도 있음
  · 다크엘프 집단에서도 일반(백색) 엘프가 태어나기도 함
  · 차별 존재. 브렌모어·마슈리크 도심 등에 소수
  · 콩고 대밀림 왕국(음웰루)은 다크엘프가 많이 모인/많이 태어난 곳일 뿐, 본향은 아님
    (그곳과 바깥 다크엘프는 완전히 단절)
- ★실바리스·마르네스 등의 차이는 단순 사는 곳 차이일 뿐, 종족적 갈래가 아님 (확정)

[오크]
- 특화: 근접 전사
- 수명: 50~60년 (짧고 굵게)
- 외형: 녹색~회록색 피부, 아래엄니, 대형 체격
- 분포 (★확정):
  · 북방·툰드라권 중심 — 노르가르드권·에조라 등 + ★신대륙 북방(헤르바나·조르가트권 등) 포함
    (전쟁신 신앙권과 궁합. 노르가르드는 인간+오크 혼재 왕국으로 수정 — 기존 인물 유지. 07 수정)
  · 각지 도시에도 혼재 — 주로 전사·용병 계층 (독자 세력 없음)
  · ★보강 (19 길드 세션에서 확정): 전사·용병만 하는 것은 아님 —
    ★힘쓰는 일에 많고 ★다른 일에도 있으며, ★의외로 기사나 귀족도 가끔 있음
    (특화는 경향이지 개인의 한계가 아니라는 대전제와 합치. 상세 19-III-8)

------------------------------------
[용족]
------------------------------------
- 최장수 종족. 7종 체제 밖의 별개 존재로 유지 (★확정)
- ★규모 (확정): 세계 전체 약 3천
- ★거주 (확정): 4할은 정체를 숨긴 채 타종족 사회에 섞여 삶
  / 나머지 6할은 타종족이 오지 않는 오지에 서식
- 인간으로 변신 가능. 강할수록 용족의 흔적이 남지 않음
  (약하면 변신 시 뿔, 짧은 꼬리, 작은 날개, 약간의 비늘이 보일 수 있음)
- 은둔 이유: 무관심·초연. 타종족 일에 관심이 없음. 섞여 사는 것은 개인 취향
  (박해나 율법 때문이 아님. 섞여 사는 개체는 종족 내에서 별난 취향 취급)
- 서식지 (확정, 열린 목록):
  · 그린란드 대응 / 극지 / 히말라야(최고봉 등에만) / 파타고니아 남쪽(아오니아 너머)
  · 크레타 대응 섬 — 숨은 서식지 (사람들은 험한 무인도로 앎)
  · 히말라야는 다른 서식지와 동급 (세계 최대 에테르 요지라는 지리 속성과 별개. 특별 위상 없음)
  · 시브란 유목 부족은 극지로 가지 않음(확정) → 극지 서식과 충돌 없음
- 사회 형태: 완전 개별 — 무리·조직 없음. 서식지는 그냥 겹칠 뿐
- ★타종족의 인지: 전설 취급이 다수. 목격담·역사서 기록은 존재하나
  사람들은 목격한 용을 다른 마물(드레이크 등)로 여김
  → '용족'이라는 종족의 존재 자체는 알려지지 않음 (목격담은 전부 마물 기록으로 분류. 떡밥 소재)

------------------------------------
[혼혈 규칙 — ★확정 (유지+확장)]
------------------------------------
- 진짜 혼혈이 태어나는 조합은 둘뿐:
  1) 인간 × 엘프 → 하프엘프
  2) ★인간 × 용족 → 드라킨 [신규]
- 그 외 모든 조합: 자식은 부모 둘 중 한쪽 종족으로 랜덤 결정 (순서 무관, 둘 다 가능)
  → 형제가 서로 다른 종족인 가족이 존재 (차별 지역에서는 강력한 비극 소재)

[하프엘프 — 유지]
- 인간-하프엘프 조합: 자식은 인간/엘프/하프엘프 중 하나
  · 비율 확정: 인간 50% / 하프엘프 25% / 엘프 25%
  · 하프엘프에게서 순혈 엘프가 태어날 수도 있음 (4분의 1 확률)
- 정령술 적성: 엘프보다 약간 약하나 큰 차이 없음

[드라킨 — ★신규 확정]
- 인간 × 용족의 혼혈. 하프 용족
- 드래곤(용) 변신 불가 (확정)
- 수명: 엘프급 — 수백 년
- 능력: 높은 에테르 친화 + 약식 브레스 + 탁월한 신체
- 외형: 비늘·뿔·날개 — 날개는 없는 경우가 더 많음
- 세간 인지: 극희소 + 정체는 아무도 모름 —
  세간에서는 파충류 계열 수인 정도로 여김
  (부모가 정체를 숨긴 경우, 본인조차 자신을 파충류 수인으로 아는 경우도 있음)


------------------------------------
[★마물 체계 연쇄 반영 — 17 연동]
------------------------------------
- ★용족 오분류 보강: 드레이크는 ★실재하는 토착 마물이므로, 용족 목격을 드레이크로 여기는 것은
  오인이 아니라 ★합리적 추정이 됨. 게다가 용족·드레이크·드라킨의 브레스는
  ★밖에서 보면 구분되지 않음 (드라킨의 약식 브레스 포함)
- ★'드래곤' = 세간이 용족을 가리켜 부르는 이름. 실제 피해 사례가 없는데도
  신화적 공포 때문에 ★마물로 분류됨 — "피해를 준 적 없는데 가장 무서운 마물"
- ★'리저드맨' = 마물이 아니라 ★변경 파충류 수인 부족을 부르는 멸칭.
  · 사람이 사람을 마물이라 부르는 사례 → 차별 소재
  · ★드라킨이 정체를 숨기기에 가장 좋은 이름이기도 함
- ★'워울프' = 오칭. 사람은 변신하지도 포화하지도 않음
  · 실체 ⓐ 포화한 늑대(맹수 → 마물) / ⓑ ★늑대형 수인에 대한 모함 → 변경의 수인 마녀사냥 소재
- ★마녀사냥 3사례 (수인 차별 소재): ★몽마(실체 없는 마물. 표적이 불특정이라 누구든 지목 가능)
  / 워울프(늑대형 수인) / 리저드맨(파충류 수인) → ★사람이 마물 판정을 받는 경로 [17-V]
- ★오크 주의: 지성 의심군(고블린)과 겉보기가 겹쳐 변경·전선에서 오인·차별이 발생
  (오크는 어엿한 지성 종족이며 마물이 아님)
- 하플링 연동: 농경 특화 종족의 최대 골칫거리는 ★가시토끼(농촌 해수) — 자치 마을 단위의 상시 과제
- 마물 상세 = 17 참조


------------------------------------
[★법·전쟁·마법일상 연쇄 반영 — 21~23 연동]
------------------------------------
- ★[법 앞의 종족] (21-I-6): ★나라마다 다름 —
  종족을 신분으로 못 박은 나라와 그렇지 않은 나라가 공존
