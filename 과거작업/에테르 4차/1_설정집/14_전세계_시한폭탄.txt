====================================
14. 전세계 시한폭탄 목록 (전 대륙 통합)
====================================
[상태] 최종 갱신 = ★정리 세션 (D1 직후) / 반영 완료 = 21~26·29 + 역병 연표 1단계 + D1
       미반영 = 없음
[담당] 전세계 시한폭탄 목록 — ★폭탄 코드(A1·C1·G3 등)의 정본
[규칙] 값이 다른 파일과 어긋나면 ★정본 파일이 이김. 이력의 정본은 ★99_변경이력
※ 구 아우로라 관계도 파일의 시한폭탄 + 각 대륙 확정 사실에서 정리. 관계도는 13 파일
※ [초읽기] > [수년] > [잠복] > [장기] 순의 유예 표기
※ ★F4(제3차 대역병)만 이 사다리에 앉지 않음 — ★[진행 중]. 터질지 말지가 아니라 이미 출발한 것
※ ★계열: A 아우로라 / B 마슈리크 / C 아자니아 / D 수리아 / E 신대륙 / F 세계급 / ★G 제도·판정
※ "정리 해석(변경 가능)" 표시분만 새 해석

====================
[A] 아우로라 — 구 관계도 파일에서 이관
====================
A1) 로렌시아-마르네스 전쟁 [초읽기]
   - 국왕의 급발진 + 마르네스의 준비 안 된 도발. 곧 터짐
   - 파급: 마리스텔라 특수, 아르카디아·미세아 용병 수요 폭증, 로렌시아 야심귀족 기회
   - ★인물 확정: 국왕 플로랑 3세 (나르시스트, 만류 불능화 진행) / 만류파 재상 르노
     vs 주전파 고드프루아 공작 (상세 07)
   - ★연동 인물: 베네시아 수장 코르시오 — 개전 시 해상 물류 특수가 연임 티켓이라
     남의 전쟁을 내심 기다리는 처지 (코르시오의 이야기 씨앗. 상세 07)
   - ★마르네스 측 인물 확정: 국왕 알드렌 (노회한 선동가 — 내부 불만[경제→정치 압박]을
     전쟁으로 돌리는 중, 시간표는 상실) / 해군 제독 드레이번 (수인, "싸우면 이긴다"파.
     씨앗: 이기고도 지는 전쟁 / 되돌아오는 불만. 상세 07)
   - ★④단계 2차 추가: 그레이븐(마르네스 남안 밀수항)이 알드렌의 비공식 뒷문 —
     로렌시아 불만분자 접촉·코르비아 해적에게 항로 흘리기의 통로.
     ★제2뇌관: 의회가 그레이븐과 그 돈의 행방을 알아내는 순간이 왕권을 조이는 손잡이 (상세 07)
A2) 페라리크의 실바리스 포위 [수십 년, 서서히]
   - 왕은 승리로 착각, 실제론 포위. 완성되면 대삼림은 제국 안의 섬
   - ★재해석 확정 (사용자 확정): '착각'은 실바리스 왕 쪽만 — 페라리크 황제 오토카르 3세는
     포위 형태를 인지된 부수 이득으로 계산에 넣고 있음 (본목적: 흑토지대 흡수 +
     아르카디아 접근 + 그라니타 체감 교역 거리 단축. 상세 07)
   - ★군사 전제 (사용자 확정): 숲 안=실바리스 불패 / 숲 밖 회전=제국 우세 가능성 큼
     — 위험은 패배가 아니라 숲발 비정규전 소모
   - ★실바리스 측 인물 확정: 왕 아엘두인 (수백 년 재위 노왕, 오만+정보 부족의 오해자,
     협상파 무시·좌천) / 친위대장 파엘로르 (좌천자들을 국경에 모아온 복선) /
     리넬 (이탈 직전의 젊은 엘프. 상세 07)
   - ★④단계 2차 추가: 개간 전선의 실물 = 로둥(개척 전진 도시 + 동방 기사단 본부).
     숲에서 본 로둥은 해마다 커지는 불빛 덩어리 →
     ★점화는 황제의 계산도 왕의 관망도 아닌 ★개간꾼과 엘프 순찰대의 우발적 조우 하나로 충분 (상세 07)
A3) 노르가르드 대이주 [수년 유예]
   - 소빙기가 안 물러나면 남부 대이동 개시 (약탈 루트→페라리크 해안 / 이주 루트→실바리스)
   - ★인물 확정: 국왕 하랄디르 (타고난 냉정, 부족장 회의 추대, 언변·정치력의 왕.
     대이주는 "피하고 싶지만 어쩔 수 없는 것") / 전사장 오르바르(왕국 측 광전사)
     / 요르문드(북부 남하 강경파 — 폭주 시 시간표가 왕의 손을 떠남. 상세 07)
   - ★④단계 2차 추가:
     · 켈다르 산맥이 서(피오르 해안=약탈 루트) / 동(내륙=이주 루트)을 가름 → 두 갈래의 지리적 근거
     · ★이스가르(아이슬란드 대응)가 먼저 죽고 귀환민이 스카르비크에 상륙해 증언 →
       남하가 '왕의 야심'이 아니라 ★눈으로 본 이웃의 증언에서 오는 공포가 됨
     · ★미드외(셸란 대응) 섬 어부들이 대륙을 눈앞에 두고 있음 →
       대이주의 첫 발자국이 왕의 시간표 밖에서 먼저 시작될 수 있음
     · 스카르비크 통행료=보호세 구조 → 약탈이 사라지면 세수도 사라져 하랄디르는 근절할 수 없음
A4) 솔라티움 십자군의 불씨 [잠복]
   - 이단 심문단(70%)이 언제든 십자군화 가능. 현 교황은 생각 없음
   - 표적 후보: 노르가르드(가까운 이교도). 점화 시 마슈리크 3국은 연합으로 전환
   - ★④단계 2차 — 물리적 조건 확정 (상세 07):
     · ★상징 표적 확보: 발가르드(전쟁신 대신전 겸 부족장 회의장) — 십자군에 필요한 것은
       넓은 땅이 아니라 무너뜨릴 우상 하나
     · ★명분 확보: 스카르비크 보호세 — "이교도가 기독 상인의 목을 쥐고 있다"는,
       신학 논쟁 없이 모두를 화나게 하는 이야기
     · ★최대 제약: 노르가르드는 페라리크와 육상 국경국이라 육로 원정은 ★제국 영토를 지나야 함
       → 교황청은 철관을 쓴 파문 직전의 황제에게 길을 빌려야 하고, 황제의 대가는 ★철관 승인
       = A4와 A2가 같은 도화선을 공유하게 됨 [최대 수확]
     · 집결지: 쿼드리비움(베르가 영토) → A5 동시 점화 / 해상 축: 페트룸(기사단 자치령)·키프라(발판)
     · ★사르가 공작령의 함대 징발 거부 가능성 = 교황 측 해상력의 구조적 불안
     · 미세아 5대 길드의 이해가 정반대라 바야르는 어느 쪽도 만족시킬 수 없음
   - ★인적 도화선: 추기경 세베리안 (인간중심파+십자군 재개파, 교황 루치도르의 정적.
     교황의 '무기적'을 캐는 중 — 상세 05)
   - ★연동 인물: 미세아 국왕 바야르 — 재점화 시 완충 회랑이 최전선이 되어
     "양쪽에 칼을 팔던 나라"의 중립이 끝나는 구도 (바야르의 이야기 씨앗. 상세 07)
A5) 베르가 동맹 '부분 개종' 환상 [잠복]
   - 교단이 권위(십일조·승인권)를 요구하는 순간 깨짐
   - ★④단계 2차 추가: 임페리알 가도 대결절점 ★쿼드리비움이 베르가 영토 내 →
     십자군 집결지가 곧 베르가 땅. 성직자·기사가 몇 달 체류하면
     ★환상은 거리를 두어야 유지된다는 원리에 따라 A4 점화와 ★동시에 A5가 터짐 (상세 07)
A6) 로렌시아 야심 귀족 [잠복]
   - 전쟁으로 왕실이 휘청이면 "나도 왕국을" 세력이 움직임
   - ★인적 도화선: 고드프루아 공작 (주전파 가면의 최대 거물 — 상세 07)
A7) 신대륙 비밀 [장기 — 세계급, 아래 E5·F1 연동]
   - 마리스텔라의 정찰이 독점 진출로 전환되는 순간 세계사가 바뀜

[B] 마슈리크
====================
B1) 아케메니아의 야심 [잠복]
   - 바벨리아(학문+농업)·카람(부) 정복을 노리나 국력 미달+명분 부족으로 대기 중
   - 같은 알 딘 형제를 치는 순수 세속 야심 → 터지는 순간 신앙권 내전
   - ★인물 확정: 샤한샤 바흐람 (40대 중반, 통일 주역 선대의 2대. 명성-실속 격차를
     알면서 운용하는 극장적 군주. 야심=수복 사명. 명분을 만들 유일한 사건=십자군 재래를
     기다림 — A4와 위험하게 맞물림) / 미흐란(조기 개전파) vs 파르비즈(내실파. 상세 09)
   - ★연동 인물: 아르카디아 국왕 바흐탄 — 콜레기움의 뿌리인 바벨리아가 표적이 되는 날,
     아르카디아 중립이 시험받음 (바흐탄의 이야기 씨앗. 상세 07)
   - ★지리 연동 [④단계 2차]: 바벨리아는 바다에 닿지 못함 —
     곳간(키샨)의 물자가 나가는 문은 카람령 ★미프타흐, 그 바깥 목은 아케메니아령 ★샤반다르
     · 아케메니아가 곳간을 삼키는 순간 카람과 국경을 맞대고 마주 앉게 됨
       → 미흐란 조기 개전론의 숨은 비용 / 파르비즈 반대론의 새 근거
     · 반대로 샤반다르는 개전 없이도 형제의 목을 누르는 손 — 바흐람의 '기다림'이
       무위가 아니라 압박인 이유가 지리로 성립
     · ★첫 성벽 = 아슈란 [④단계 2차 신설]: 나흐르 샤르크 상류의 동북 국경 도시.
       수비는 ★미세아 용병 → 아케메니아가 값을 더 부르면 벽은 남고 사람만 바뀜.
       B1의 방아쇠가 군사력이 아니라 ★돈이 될 수 있는 경로
     · ★카람 국부도 같은 목을 지남: 자우하르(동부 마정석 산지) → 미프타흐 → 만 출구.
       카람이 정세에 따라 중요한 물자만 무카르 육로로 우회시키는 것 자체가
       아케메니아를 두려워한다는 신호 → 미흐란 개전론의 심리적 연료
       · ★판정 주체 확정 [④단계 2차]: ★술탄 직결 — 제도명 ★미잔 알하람('성역의 저울').
         성도 하람의 정청에서 노선을 정하므로 칙령이 정세보다 한 박자 늦게 도착함
         → 카람의 국부 물류에 ★시차라는 구조적 약점이 생김.
         또한 술탄 개인에게 붙은 판정이라 ★단일 실패점 (술탄 유고 시 물류 정지)
         = 미흐란이 노릴 수 있는 비군사적 틈 (상세 09)
   - ★씨앗 [의도 없이 쌓이는 준비물] — ★누반다르 [④단계 2차 신설]:
     카스피 남안의 아랄샨 교역 상항이자 ★수군·조선 기지. 명목은 상선 호위·해적 억제
     · 파르비즈는 상업으로 짓고, 미흐란은 서쪽만 보느라 관심이 없음 →
       ★아무도 동방 원정을 의도하지 않았는데 원정의 준비물만 갖춰지는 구조
     · ★개전 결정보다 개전 능력이 먼저 도착하는 형태 — 누군가 뒤늦게 그것을 발견하는 날이 방아쇠
     · B1의 야심 방향이 서쪽(바벨리아·카람)으로만 정의돼 있던 데 대한 ★동쪽 변수 (상세 09·13)
B2) 성지 살렘 [잠복 — A4 연동]
   - 다섯 세력의 신앙이 겹치는 공유 성지. 십자군 재점화 시 폭심지
   - 평시의 미슈마르-카람 성지 위상 경쟁은 불씨라기보다 자존심 싸움 수준

[C] 아자니아
====================
C1) 줄라니 전사 왕국의 태동 [★임박 — 왕국 선언 직전으로 조정]
   - 분권 부족 사회에서 전사들을 양성하는 전제정치 세력이 결집 직전 (줄루 태동 평행)
   - 세계의 관심 밖에서 조용히 힘을 키우는 새로운 강자의 예고
   - ★인물 확정: 카짐베 (물소 계열 수인, 정통 후계 야심가, 무력 최상위·가호 없음.
     이미 여러 부족 복속 — 왕국 선언 직전) / 조언자 마둘라.
     씨앗: 왕국이 서면 드짐바웨·루펨바·말라니 교역망과 충돌 — "관심 밖"의 종말 (상세 10)
   - ★지명 확정 연동 (④단계 2차): 드짐바웨 키방가 = 금 곳간 + 남부 요새.
     ★그 성벽은 '통일 이전의 산발적 약탈자'용 설계인데, 카짐베가 바로 그들을 묶는 중
     → 상대만 바뀌는 구조 (군영 도시 음혼도 vs 곳간 도시 키방가)
   - ★대응 속도 취약: 드짐바웨 정치 중심 무텐데는 ★연합 회의장(왕 없음) —
     한 사람의 명령으로 움직이는 왕국 앞에서 '모여 의논부터 해야 하는 나라' (상세 10)
     · ★근거 확정 (26-XI-5. ★28 세션): 드짐바웨 연합이 공유하는 관례의 내용은
       ★자격 요건 + ★분쟁 처리 방식 + ★"왕을 세우지 않는다"는 약속
       — ★승인 절차는 공유하지 않음
