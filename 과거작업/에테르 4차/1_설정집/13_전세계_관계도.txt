====================================
13. 전세계 관계도 (전 대륙 통합)
====================================
[상태] 최종 갱신 = ★역병 2-a 세션 (격리의 지형) / 반영 완료 = 21~26·29 + D1 + ★2-a / 미반영 = 없음
[담당] 전세계 관계도
[규칙] 값이 다른 파일과 어긋나면 ★정본 파일이 이김. 이력의 정본은 ★99_변경이력
※ 구 아우로라 관계도·구 수리아 관계도와 각 대륙 파일의 관계망을 한 파일로 통합
※ 시한폭탄 목록은 14 파일 별도. 상세 근거는 각 대륙 파일(05,07,09,10,11,12) 참조
※ "정리 해석(변경 가능)" 표시분만 새 해석, 나머지는 확정 사실의 재정리
※ ★21~26(법·마법일상·전쟁·역병·이동·신분) 반영분은 ★[G] 절에 별도로 세움
   — 기존 [A]~[F]는 손대지 않았음

====================
[A] 아우로라 (유럽 대응) — 상세 07
====================
▷ 핵심 삼각: 솔라티움(신앙 정통) ← 조종 — 로렌시아 / ← 이탈 — 페라리크(철관)
- 솔라티움은 늑대(페라리크)를 막으려 여우(로렌시아)에 기댐
- 솔라티움 ↔ 베르가 동맹: 최대 무역 상대. '부분 개종' 착각 (뇌관)
- 솔라티움 ↔ 노르가르드: 잠재적 십자군 표적 / (서방) ↔ 헬라디아(동방): 교리 분열
- 페라리크 ↔ 실바리스: 숲을 피한 개간 = 사실상 포위 (양측 다 오해 중)
- 페라리크 ↔ 노르가르드: 동방 개척지 해안이 약탈 표적
- 로렌시아 ↔ 마르네스: 전쟁 전야 (우발적 개전 위기)
- 마리스텔라: 균형 외교 + 전쟁 특수 노림. 대륙의 혼란 = 신대륙 비밀의 연막
- 베르가(베네시아) ↔ 헬라디아 ↔ 미세아: 마레 솔리스 동부 삼각 무역
- 아르카디아: 열강 각축장 + 동문 네트워크 / ↔ 미세아: 지식→무력 파이프라인
- 아르카디아 ↔ 그라니타: 마정석·마도구 재료 큰손 거래 (그라니타의 서방 창구) [신규]
▷ ★④단계 신규 소권역 3곳 — 관계도 반영 [정합 세션. 상세 07·15]
- 키어런 ↔ 마르네스: 상호 약탈이 제도화된 사이 (장물 시장·몸값 협상) + 마르네스 정쟁
  패자의 망명 뒷문 / ↔ 솔라티움: 선교사 소수 잠입 단계 (개종 경쟁의 씨앗)
- 푸스타르 → 페라리크: 잉여 곡물의 최대 판로가 제국 — 시장이 이미 묶여 편입 선호가 대세
  · 서부 일부는 이미 제국 귀족 영지 / ★부다르만 독립 고집 (푸스타르 내부 갈등축)
- 발디르 → 미세아·각국 궁정: 계곡 청년의 용병 수출지 (인력 파이프라인)
  · ↔ 몬스 페라 드워프 왕국: 마주치지 않음 (지하왕국 입구가 베르가 쪽에만 있음)
  · ↔ 솔라티움: 고갯길 구호 수도원이 실질 선행으로 뿌리내리는 창구

▷ ★④단계 2차 신규 관계 (상세 07)
- ★페라리크 ↔ 노르가르드: 육상 국경 국가 (순드 남안=제국 / 북안=노르가르드)
  · 정면 육로를 안 쓰는 이유=제국 정규군 → 요르문드가 배를 타는 이유가 성립
  · ★A4-A2 연결: 십자군 육로가 제국 영토를 지나야 함 → 교황청은 철관 황제에게 길을 빌려야 하고
    대가는 철관 승인 → 두 폭탄이 같은 도화선을 공유
- 노르가르드 → 노르트분트·각국 상선: 스카르비크 통행료 = 사실상 ★보호세
  (내면 통과, 안 내면 요르문드가 찾아옴) → 하랄디르는 약탈을 근절할 수 없는 구조
- 노르트분트(한자 대응 상인 동맹) ↔ 제국·노르가르드: 발트 두 목을 남에게 잡힌 처지
  · 단비크 특권장 협상 중 / 긴타르는 동맹 항구
- 제국(게르하르트) → 르보르·코레브 방면: 곡물 값과 시장 접근권으로 매수
  · ★목적은 곡물이 아니라 ★관세 없는 강길(아르카디아→바투르→타우리스→볼로크 강→코레브→르보르)
  · → 포르피라의 스테논 관세 독점을 우회 = 포르피라의 새 근심
- 헬라디아 ↔ 라구르: 이탈 자유 도시, ★아테리아 미승인 (철관 분쟁의 축소판, 이탈 선례의 전염성)
- 헬라디아 ↔ 타우리스·로디아: 원거리 식민 항구망 (라구르 상실이 아픈 이유=남은 자산이 적음)
- 아르카디아 ↔ 타우리스: 마정석·마도구 ↔ 곡물·소금의 북방 축 / 바투르=각국 상관 난립 항구
- 아르카디아 ↔ 그라니타: 부재료는 젬나르에서 자급, ★핵심 마정석만 의존 (목줄)
- 솔라티움 ↔ 사르가 공작령: 종주-자치. ★교황 측 유일 해상력이나 커질수록 덜 순종
  (A4 수송 징발 거부 가능) / ↔ 페트룸: 성지 원정 기사단 자치령
- 마르네스(알드렌) → 코르비아 해적·키어런: 그레이븐 후미를 통한 비공식 거래·이간질 통로
  · ★의회가 그레이븐을 알아내는 순간이 왕권을 조이는 손잡이
- 베르가 ↔ 대륙 전체: 포르타 페라(산 밑 관문) + 쿼드리비움(육로 결절점) 이중 수취
  · ★십자군 집결지가 베르가 땅 → 떡밥 6('부분 개종'의 환상)이 A4와 동시에 터짐
- 마리스텔라: 벤투라 제도·칼레타가 F1의 실물 축 / 안도르 고갯길이 유일한 육상 누출 경로
- 미세아: 5대 길드(세페르·케르반·타렙·하베르·게진) + 비공인 골게 →
  ★A4 시 각 길드의 이해가 정반대라 바야르는 어느 쪽도 만족시킬 수 없음

[B] 마슈리크 (중동 대응) — 상세 09
====================
▷ 핵심 구도: 3국(카람·바벨리아·미슈마르) 이합집산 + 신흥 아케메니아
- 3국: 십자군이 오면 연합, 평시엔 정통·성지 위상 다툼 (서로 이단시하지 않음)
- 카람 ↔ 솔라티움: 종교적 앙숙이나 미세아 경유 교역 상대
- 미슈마르(살렘): 다섯 세력의 신앙이 겹치는 성지를 깔고 앉은 작지만 단단한 나라
  · 카람에 성지 위상 서운함 (하람으로 순례·돈이 쏠림)
- 아케메니아 → 바벨리아·카람: 정복 야심. 명분 부족+국력 미달로 때를 노리는 중
- 바벨리아 ↔ 아르카디아: 빼앗긴 지적 심장이나 지금은 학문 교류 (원한보다 협력)
- 아케메니아 ↔ 아랄샨(수리아): 좋은 교역 상대. 카스피 해상 포함 (동쪽엔 아직 무관심) [신규]
  · ★[④단계 2차] 카스피 남안 항구 ★누반다르 신설 — 아랄샨 교역 전담 상항 + ★수군·조선 기지 겸용
    · 우회 해로(카스피를 건너 실크로드를 잘라내는 길)는 ★사실상 없는 수준 →
      ★실크로드 축은 육로 그대로 유지. 오아시스 도시 통행세 구조에 변동 없음
    · 단 조선소가 서면서 "좋은 교역 상대"에 ★첫 그늘 — 아랄샨은 카스피 어업·해상 교역이
      경제의 한 축이라 맞은편 군선 골조에 민감 (상세 09)
- 카람의 마정석: 그라니타와 시장을 나누는 구도로 변경됨 [신규 — 09에 반영 완료]
- ★페르시아만 3자 구도 [④단계 2차 신규]: 곳간=바벨리아(키샨) / 문=카람(미프타흐) /
  바깥 목=아케메니아(샤반다르)
  · 바벨리아는 ★바다에 닿지 못하는 나라로 확정 — 물자가 나가는 마지막 문이 카람령
  · 카람의 배조차 인도양으로 나가려면 아케메니아의 샤반다르 앞을 지남
  · ∴ 마슈리크의 바닷길은 세 나라가 서로의 목을 순환적으로 쥔 구조
- ★미세아 용병 축 확대 [④단계 2차 신규]: 미슈마르 하리산 + ★바벨리아 아슈란
  · 마슈리크의 두 국경을 모두 미세아 용병이 떠받침 → 미세아 길드가 마슈리크의 ★균형추
  · 아케메니아가 더 높은 값을 부르면 성벽 위의 사람이 그대로 반대편이 됨 (B1 연동)
  · 바벨리아 국방비가 미세아의 용병 가격 상한 정책에 연동되는 구조
- ★마정석 물류축 [④단계 2차 신규]: 자우하르(동부 산지) → 미프타흐 → 만 → 샤반다르
  · 카람 국부의 반출로가 ★가변 — 평시는 미프타흐, 정세 악화 시 중요 물자만 무카르 육로 우회
  · 세계 마정석 시장은 카람(자우하르) + 그라니타(그란둠) 양대 산지 구도 유지
- ★카람 바닷길 이원화 [④단계 2차 신규]: 무카르(자원·향료) / 부슈라(순례 전담)
  · 해상 순례객과 자원선이 갈라짐 → 미슈마르의 '순례 쏠림' 서운함은 오히려 심화

[C] 아자니아 (아프리카 대응) — 상세 10
====================
▷ 대륙 관통 흐름: 케메트 박해 → 티네리 수인 북상 → 마리스텔라 경유 아우로라행
- 케메트: 순수주의 결벽 제국. 바깥을 약탈·'정화'하되 들이지 않음
  · → 쿠쉬(약탈 피해, 알 딘이라 이질시됨) / 티네리(과거 침략당함 → 북상 이주의 원인)
- 자한: 황금·소금의 부로 바깥의 마정석·인재를 사들임 (카람 마정석의 큰손)
  · 티네리가 사하라 대상 운송의 손발 (자한 ↔ 지중해·마리스텔라 연결)
- 악수미아: 고원+해안 이원 구조. 인도양 교역으로 동방과 연결
  · ↔ 키탐바(냐사 동안): 내륙 대호수의 부가 악수미아 항구로 나가는 동맥
  · ↔ 판디라(수리아): 인도양 향신료 항로의 서쪽 축 [신규]
  · ↔ 솔라티움: 시조 솔로몬 왕 전승의 가느다란 접점 (호기심의 거리감)
- 음웰루(콩고): 반개방 은둔 — 쿠붐바(교역 창구) vs 음바리(마물 유입 불신)
- 냐사 연맹: 음바리(방패)·키탐바(심장·관문)·루펨바(공방·남방 관문)의 혼인 동맹
- 남부: 드짐바웨 금 → 루펨바·동해안으로 수출 / 말라니 = 물길의 중개상 / 줄라니 = 태동기
  · ★드짐바웨 구조 (④단계 2차): 키방가(금 곳간+남부 요새) vs 무텐데(연합 회의장, 왕 없음)
    — 옛 약탈자 대비용 성벽 앞에 통일 왕국(C1)이 서는 중
  · ★말라니: 루웨자 호 = 어장·생계 기반 (자급은 되나 남을 굶길 지렛대는 없음)

[D] 수리아 (아시아 대응) — 상세 12
====================
▷ 핵심 구도 1 — 화련 중심의 조공 질서
            화련 (문화·유흥의 대제국, 안정기)
          /   |    \       \
       조공  조공   조공    사실상 조공
        /     |      \        \
     해솔  앙사라  바하리아    위장
- 화련: 회사품을 더 얹어주는 큰손이자 "거스를 수 없는 착취자"
  · 해솔은 실속을 알고 너무 자주 옴 / 앙사라는 품목 변경(쌀→향신료 등)에 불만
- 위장: 공식 조공 없이 국민들이 알아서 화련에 돈을 씀 → 화련은 "언젠가 삼킬 땅"으로 봄
- 경제 순환: 화련이 문화를 팔고 → 위장이 쌀을 팔고 → 번 돈이 화련 유흥으로 회귀

▷ 핵심 구도 2 — 북방 삼각
- 코르타이(통일 직전) ↔ 아신: 반(反)화련 공동 전선. 코르타이가 아신을 아래로 봄.
  아신은 화련전 후 자신이 다음 표적임을 알면서도 손잡는 중
- 코르타이 → 화련: 침략·약탈 반복. 화련의 토벌 원정은 격퇴당함
- 아신 ↔ 화련: 냉전 (주적) / 코르타이·아신 → 시브란: 약탈 (투항론까지 등장)

▷ 핵심 구도 3 — 남방 축
- 앙사라 ↔ 바하리아: 최우선 파트너 (말라칸 교역소 경유, 해적 없는 항로)
